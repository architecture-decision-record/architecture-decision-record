# [000] శీర్షిక
*సులభమైన సూచన, కేటలాగింగ్ కోసం ప్రతి ADRకు ఒక సంఖ్యను కేటాయించండి* \
*గమనిక: ఇటాలిక్ చేసిన పాఠ్యమంతా సూచనలు ఇస్తుంది, ఉత్పత్తి వెర్షన్కు ముందు తొలగించాలి*

## స్థితి - డ్రాఫ్ట్ / క్రియాశీలం / [000] ద్వారా వాడుకలో లేనిది / [000]ను భర్తీ చేస్తుంది

## సందర్భం
*ఈ ADR పరిష్కరించాలనుకుంటున్న సమస్య(ల)ను, ఆ సమస్యలు ఎందుకు ఉన్నాయో క్లుప్తంగా వివరించండి.*

## నిర్ణయించిన విధానం
*తీసుకున్న / తీసుకోబోయే ఆర్కిటెక్చర్ పరంగా ముఖ్యమైన నిర్ణయాన్ని వివరంగా తెలిపి, సందర్భం విభాగంలో పేర్కొన్న సమస్యలను అది ఎలా పరిష్కరిస్తుందో వివరించండి.*

## పర్యవసానాలు
*ఈ నిర్ణయం వ్యవస్థ ఆర్కిటెక్చర్ లక్షణాలపై, ఫంక్షనల్ అవసరాలపై ఎలాంటి ప్రభావం చూపుతుంది?*

## పాలన
*ఈ నిర్ణయం ఫలితాలను ఎలా పర్యవేక్షిస్తారు?* \
*ఈ నిర్ణయానికి అనుగుణంగా ఉండటాన్ని ఎలా నిర్ధారిస్తారు?*

## ఎంపికల విశ్లేషణ
*వర్తిస్తే, ఈ పత్రంలోని నిర్ణయానికి రావడానికి చేసిన ఏదైనా రాజీ విశ్లేషణను చేర్చండి లేదా దానికి లింక్ ఇవ్వండి.*
