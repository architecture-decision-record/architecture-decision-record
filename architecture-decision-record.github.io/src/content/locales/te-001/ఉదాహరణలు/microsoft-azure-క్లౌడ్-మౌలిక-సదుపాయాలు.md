# ఆర్కిటెక్చర్ నిర్ణయ రికార్డు: Microsoft Azure క్లౌడ్ ఇన్ఫ్రాస్ట్రక్చర్" 

నిర్ణయ శీర్షిక: మా సంస్థ క్లౌడ్ ఇన్ఫ్రాస్ట్రక్చర్గా Microsoft Azureను స్వీకరించడం

నిర్ణయకర్త: చీఫ్ ఇన్ఫర్మేషన్ ఆఫీసర్

తేదీ: 2021-10-15

స్థితి: ఆమోదించబడింది

## నేపథ్యం

సంస్థ సంప్రదాయ ఆన్-ప్రిమిసెస్ ఇన్ఫ్రాస్ట్రక్చర్ నుండి క్లౌడ్ ఇన్ఫ్రాస్ట్రక్చర్కు వలస వెళ్లాలని ప్రణాళిక వేస్తోంది. దీన్ని సాధించడానికి, సంస్థ Amazon Web Services (AWS), Google Cloud Platform (GCP), Microsoft Azure, IBM Cloud వంటి అనేక క్లౌడ్ సేవా ప్రదాతలను మూల్యాంకనం చేసింది. ప్రతి ప్రదాతకు దాని స్వంత ఫీచర్లు, ప్రయోజనాలు, ధరల నిర్మాణం ఉన్నాయి. వివరణాత్మక విశ్లేషణ తర్వాత, మా సంస్థకు Microsoft Azure అత్యంత అనువైన ఎంపిక అని నిర్ధారించారు.

## నిర్ణయం

మా సంస్థ క్లౌడ్ ఇన్ఫ్రాస్ట్రక్చర్గా Microsoft Azureను స్వీకరించండి.

## హేతువు

Microsoft Azureను స్వీకరించడానికి కారణాలు ఇవి:

1. సమగ్ర సేవలు: Azure ఇన్ఫ్రాస్ట్రక్చర్ యాజ్ ఎ సర్వీస్ (IaaS) నుండి సాఫ్ట్వేర్ యాజ్ ఎ సర్వీస్ (SaaS), ప్లాట్ఫారమ్ యాజ్ ఎ సర్వీస్ (PaaS) వరకు పూర్తి శ్రేణి క్లౌడ్ సేవలను అందిస్తుంది. ఇది స్టోరేజ్, కంప్యూట్, నెట్వర్కింగ్, అనలిటిక్స్ వంటి సంస్థ అవసరాలను పరిష్కరించడానికి Azure సేవలను ఉపయోగించుకోవడానికి మాకు వీలు కల్పిస్తుంది.

2. విస్తరణ సామర్థ్యం, వెసులుబాటు: Azureతో, మా వ్యాపార అవసరాల ఆధారంగా వనరులను సులభంగా పెంచవచ్చు లేదా తగ్గించవచ్చు. ఆపరేటింగ్ సిస్టమ్, ప్రోగ్రామింగ్ భాష, ఫ్రేమ్వర్క్లను ఎంచుకోవడంలో కూడా Azure వెసులుబాటును అందిస్తుంది.

3. భద్రత, వర్తింపు: ISO, SOC, HIPAA, PCI DSS వంటి అనేక పరిశ్రమ ప్రమాణాలకు అనుగుణంగా ఉండటం వల్ల Azure అధిక స్థాయి భద్రతను, వర్తింపును అందిస్తుంది. నెట్వర్క్ సెక్యూరిటీ గ్రూపులు, ఫైర్వాల్లు, DDoS రక్షణ వంటి అధునాతన భద్రతా ఫీచర్లను కూడా Azure అందిస్తుంది.

4. హైబ్రిడ్ క్లౌడ్: Azure సజావైన హైబ్రిడ్ క్లౌడ్ అనుభవాన్ని అందిస్తుంది, సంస్థలు తమ ఆన్-ప్రిమిసెస్ ఇన్ఫ్రాస్ట్రక్చర్ను Azureతో అనుసంధానించడానికి వీలు కల్పిస్తుంది. ఇది వర్క్లోడ్లను క్లౌడ్కు వలస చేయడం మాకు సులభం చేస్తుంది, డేటాను ఎక్కడ నిల్వ చేయాలో ఎంచుకునే వెసులుబాటును ఇస్తుంది.

5. ఖర్చు-సమర్థత: Azure వాడినంత చెల్లించే ధరల నమూనాను అందిస్తుంది, అంటే మేము ఉపయోగించిన వనరులకు మాత్రమే చెల్లిస్తాం. సంప్రదాయ ఆన్-ప్రిమిసెస్ ఇన్ఫ్రాస్ట్రక్చర్తో పోలిస్తే ఇది ఖర్చులను ఆదా చేయడంలో సహాయపడుతుంది.

## ముగింపు

మా సంస్థ క్లౌడ్ ఇన్ఫ్రాస్ట్రక్చర్గా Microsoft Azureను స్వీకరించడం మా వ్యాపార అవసరాలకు అనుగుణంగా ఉంది, విస్తరణ సామర్థ్యం, వెసులుబాటు, భద్రత, ఖర్చు-సమర్థత వంటి అనేక ప్రయోజనాలను అందిస్తుంది. అందువల్ల, మా క్లౌడ్ ఇన్ఫ్రాస్ట్రక్చర్గా Azureను స్వీకరించాలని సిఫార్సు చేయబడింది.
