# Template ng tala ng desisyon para sa Important Technical Decisions (ITD)

Ito ang template ng Important Technical Decisions (ITD) na inilarawan sa
[ITDs: a lean ADR for executive technical decision-making at scale - Ignacio Larrañaga](https://ignaciolarranaga.medium.com/itds-a-lean-adr-for-executive-technical-decision-making-at-scale-e18bb3f6a563).

Ang mga ITD ay nakatuong ebolusyon ng mga ADR, na na-optimize para sa bilis,
kalinawan, at pagpapatunay ng mga executive. Kung dinodokumento ng ADR kung ano
ang napagdesisyunan, ang ITD naman ay isang payat na artifact na inuuna ang
desisyon at ginagawang masusuri ang mismong desisyon, para mabilis itong
mabasa at madaling kuwestiyunin ng mga stakeholder. Angkop ang mga ITD sa mga
teknikal na desisyong hindi mahigpit na pang-arkitektura, tulad ng pagpili ng
model, library, o estratehiya sa CI/CD.

Sa bawat ITD file, isulat ang mga seksyong ito:

# Pamagat

Sabihin ang mismong desisyon, hindi ang paglalarawan ng paksa.
Halimbawa, "Gamitin ang Qwen2.5 1.5B Instruct para sa on-device na pagsasalin".

## Ang Problema

Isang pangungusap na nagsasabi kung ano ang sinisikap naming lutasin.

## Mga Isinaalang-alang na Opsyon

Ang mga alternatibong nasa mesa, na ang napiling opsyon ay naka-**bold**.

## Rasyonal

Ang mga mapagpasyang salik lamang na humantong sa pagpili, hindi ang
kumpletong listahan ng bawat pro at con.

## Mga Tala

Opsyonal. Anumang karagdagang konteksto na sulit itala, tulad ng mga limitasyon,
palagay, o link.
