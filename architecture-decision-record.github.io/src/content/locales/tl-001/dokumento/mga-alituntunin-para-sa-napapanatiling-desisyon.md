# Mga Alituntunin para Makamit ang Napapanatiling mga Desisyon

<https://www.infoq.com/articles/sustainable-architectural-design-decisions/>

Natutunan namin ang sumusunod na mga aral sa aming trabaho na maaaring magsilbing mga alituntunin at pagtatasa para makamit ang napapanatiling mga desisyon:

1. Gumamit ng payat/minimalistang pamamaraan para sa paunang dokumentasyon ng desisyon.

2. Bigyang-priyoridad at itala ang lahat ng mahahalagang desisyong sapat na may kaugnayan para idokumento at para maunawaan ang target na arkitektura.

3. Idetalye ang mga partikular na mahahalagang desisyon gamit ang ganap na mga template pagkatapos lamang magawa ang paunang gawain (ibig sabihin, kapag kontento na ang mga gumagawa ng desisyon sa mga desisyon sa arkitektura at tiwala silang hindi na kailangang repasuhin ang mga desisyong ito anumang oras sa lalong madaling panahon).

4. Gamitin ang mga payat/minimalistang bersyon mula sa hakbang 1 bilang maikling bersyon ng mga nadokumentong desisyon na may tamang antas ng granularity para magbigay ng pangkalahatang larawan ng mga detalyadong desisyon, gayundin para sa mga walang halagang o halatang desisyon.

5. Hangga't maaari, gamitin ang umiiral na kaalaman sa arkitektura, mula man sa mga guidance model o sa iba pang pinagmulan. Repasuhin at palawakin ang gayong kaalaman at iangkop ito sa konteksto ng partikular na desisyon.

6. Tiyaking may mga traceability link sa pagitan ng mga desisyon at ng parehong mga requirement at mga disenyo/code ng arkitektura. 

7. Magbigay ng awtomatikong consistency checking para matiyak na magkasabay ang mga traceability link pagkatapos ng pagbabago. Limitahan ang bilang ng mga dependency sa pagitan ng mga desisyon at ng iba pang software artifact.

8. Ilapat nang tuloy-tuloy at buong-lakas ang mga alituntunin para sa mga katwiran—sila ang pinakamahalagang bahagi ng dokumentasyon ng desisyon dahil sila ang nagbibigay ng rasyonal.
