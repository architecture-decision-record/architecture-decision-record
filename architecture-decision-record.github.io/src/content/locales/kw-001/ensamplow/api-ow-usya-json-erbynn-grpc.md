# Kovskrif dyberth arkitektoryeth: API ow usya JSON erbynn gRPC

## Studh

Degemmerys

## Kettesten

Ni a ziswinya API rag gwassaneth nowydh a vydh usys gans lies kerys. Ni re beu ow kemeres yn kyfrif dew dhewis rag gweythi an API: usya JSON dres HTTP po usya gRPC.

JSON dres HTTP yw fordh usys yn ledan rag drehevel APIyow, ha skoodhys yw gans lies yeth towlennans ha framweyth. An fordh ma yw sempel, skav, hag es dhe gonvedhes, ha rakhenna dewis da rag lies towl. Byttele, ev a hyll bos le effeythus es dewisyow erell, arbennik pan dhe dhe rewlya bonn a ddata.

gRPC, a-barth aral, yw teknologieth nowydhek a re fordh moy effeythus dhe drehevel APIyow. Ev a usya serializyans binari rag treusfurvya data, a hyll bos skavell ha moy kuv es usya JSON. gRPC a skoodh ynwedh streaming dew-ardh, a wra dewis da rag aplikasyons real-termyn.

## Dyberth

Wosa kemeres yn kyfrif a-dhesk ha drog an dhew dhewis, ni re dhewisas usya gRPC rag agan API. Kyn fo JSON dres HTTP dewis moy sempel, ni a gryj may hwra gRPC ri solusyon moy effeythus ha skalyek rag agan gwassaneth. Ni a rakwel ynwedh may hwra agan API rewlya bonn bras a ddata, ha serializyans binari gRPC a vydh moy effeythus rag an kas usadow ma.

Dhe-ves, ni a gryj may fydh skoodh gRPC rag streaming dew-ardh prow rag aplikasyons real-termyn a hyllyn displegya y'n termyn a dheu.

## Sewyansow

Dre dhewis gRPC, res vydh dhyn usya set dyffrans a doulys ha lyvervaow rag drehevel agan API, orth an keth gwrys dre usya JSON dres HTTP. Hemma a hyll gul termyn ha strivyans ychwanek dhe dhyski ha gweythi an teknologiow ma. Ynwedh, kerysyow a vynn usya agan API a res dhedha usya lyvervaow kesson gans gRPC, na vons martesen skoodhys mar ledan avel lyvervaow JSON dres HTTP.

Byttele, ni a gryj may fo prow usya gRPC a-ugh an dyskoweth gallus ma, ha ni yw fydhek may hwra an dyberth ma dri API moy effeythus ha skalyek.
