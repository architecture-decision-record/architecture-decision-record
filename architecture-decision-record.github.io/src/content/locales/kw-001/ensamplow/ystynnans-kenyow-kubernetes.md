# Kovskrif dyberth arkitektoryeth: ystynnans kenyow Kubernetes

## Derivans kudyn 

Res yw dhyn dewis platform ystynnans kenyow rag agan portfolio aplikasyons kommol-genesek ow tevi. Agan displegyans platform hen lemmyn yw re hweg, ha nyns yw skav lowr dhe holya agan othommow ow tevi. Ni a hwila system a gonsent dhyn skalyi agan gwassanethow y'n fordh moyha effeythus heb kompromisya war skavder po es dhe usya.

## Dewisyow aral kemerys yn kyfrif

1. Docker Swarm

2. Kubernetes

3. Apache Mesos

## Dyberth gwrys

Wosa gul dasdhesk dien a bub platform ystynnans kenyow, ni re dhewisas degemmeres Kubernetes avel an gwella dewis rag agan othommow kowethasek. Agan ressons rag dewis Kubernetes yw an re a sew:

1. **Skalyadewder:**  Disinyans unnik Kubernetes yw perfydh rag skalyi aplikasyons, ha pan dhe agan othommow rag skalyadewder dhe dhevi dre an termyn, Kubernetes a'n jeves an gallos genesek dhe gyfarth an chanjyow ma heb kudynyow vyth.

2. **Arkitektoryeth dispoyntys:**  Topologieth master-worker Kubernetes a surha arkitektoryeth dispoyntys a surha na vo poynt unnik a fyllel.

3. **Skoodh kemeneth:**  Kubernetes a'n jeves an gemeneth ygor-fenten brassa ha moyha bewek, hen yw, ev a'n jeves niver bras a gevrysyoryon, displegyoryon, ha gwerthoryon, ow wul es dhyn kavos gweres ha fentennow.

4. **Skoodh ekosystem:**  Kubernetes a'n jeves ekosystem ow tevi gans lies toul trydhes-parti, junyansow gans gwithvaow kenyow, pibellow CI/CD, gwithyans data, ha moy.

Rakhenna, ni re dhewisas degemmeres Kubernetes avel agan platform ystynnans kenyow rag an termyn lemmyn ha'n termyn nes.
