# Skantlyn kovskrif dyberth ow usya Planguage

## Pyth yw Planguage?

Planguage yw yeth towlennans a usya an geryow-alhwedh ma:

* Tag: Aswonnyer unnik ha pesys
* Gist: Berrskrif verr a'n othom po tiredh a vo gorthybys
* Requirement: An tekst a vanyl an othom y honan
* Rationale: An ressons a viadh an othom
* Priority: Derivadow a briorita ha govyn war yskerdh
* Stakeholders: Perghennow a vo drehedhys yn materyel gans an othom
* Status: Studh an othom (dresyth, dehwelys, ymrys, hag yn)
* Owner: An den dyghtys rag gweythi an othom
* Author: An den a skrifas an othom
* Revision: Niver gwersyon rag an derivadow
* Date: Dydhyas an dehwelans nessa
* Assumptions: Pynag tra a hyll dhe dhri kudynyow mar nyns yw gwir lemmyn po wosa
* Risks: Pynag tra a hyll dhe dhri fyllel, drohedh, po effeythyow negatif erell
* Defined: An styryans a dherm (gwell yw usya geryor)
