# Etengabeko integraziorako erabaki-erregistroa

Izenburua: Etengabeko integrazioa ezartzeko erabakia

## Testuingurua

Enpresak garapen-prozesuan erronkak izan ditu eskuzko probak, build-prozesuak eta hedapenak direla eta. Horrek atzerapen, errore eta inkoherentzia maiztasunez eragin ditu softwarearen kalitatean eta entregan.

## Erabakia

Etengabeko integrazioa ezartzea, garapen-prozesuan izandako erronken irtenbide gisa.

## Arrazoibidea

Etengabeko integrazioak kode-aldaketak automatikoki eraikiko, probatuko eta entrega-ingurunean hedatuko ditu garaiz eta eraginkortasunez. Ezaugarri berrien integrazioa kode-oinarrian ahalbidetuko du softwarearen egonkortasunean oztoporik sortu gabe. Etengabeko integrazioak softwarearen kalitatea eta entrega hobetuko ditu, erroreak konpontzeko behar den denbora murriztuko du eta interesdunen asebetetzea hobetuko du.

## Ondorioak

Positiboak:

- Softwarearen kalitate eta entrega hobeak 

- Denbora- eta kostu-aurrezpena automatizazioaren bidez 

- Garapen-taldearen barruko lankidetza eta integrazio hobeak 

Negatiboak:

- Teknologia ezartzearekin lotutako hasierako kostuak 

- Etengabeko integrazioa ezartzeko behar diren pertsonetan, tresnetan eta prozesuetan aldez aurreko inbertsioa 

- Ezarpenean zehar zailtasun teknikoak izateko arrisku potentziala.

## Ondorioa

Etengabeko integrazioa ezartzearen onurak inbertsio-kostuak eta arrisku potentzialak baino handiagoak dira. Beraz, etengabeko integrazioa ezartzeko erabakia onartu da.
