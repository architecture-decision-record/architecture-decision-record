# Arkitektura-erabakien erregistroa: Microsoft Azure hodei-azpiegitura" 

Erabakiaren izenburua: Microsoft Azure gure erakundearen hodei-azpiegitura gisa hartzea

Erabakitzailea: Informazio Zuzendari Nagusia

Data: 2021-10-15

Egoera: Onartua

## Atzeko planoa

Erakundea ohiko ekipamendu-barneko (on-premises) azpiegituratik hodei-azpiegiturara migratzeko asmoa du. Hori lortzeko, erakundeak hodei-zerbitzuen hornitzaile anitz ebaluatu ditu, hala nola Amazon Web Services (AWS), Google Cloud Platform (GCP), Microsoft Azure eta IBM Cloud. Hornitzaile bakoitzak bere ezaugarri, onura eta prezio-egitura multzoa du. Analisi xehatu baten ondoren, ondorioztatu zen Microsoft Azure dela gure erakundearentzat aukerarik egokiena.

## Erabakia

Microsoft Azure gure erakundearen hodei-azpiegitura gisa hartzea.

## Arrazoibidea

Hauek dira Microsoft Azure hartzeko arrazoiak:

1. Zerbitzu osoak: Azure-k hodei-zerbitzuen sorta osoa eskaintzen du, zerbitzu gisa azpiegituratik (IaaS) zerbitzu gisa softwarera (SaaS) eta zerbitzu gisa plataformara (PaaS). Horrek gure erakundearen eskakizunak, hala nola biltegiratzea, konputazioa, sareak eta analitika, konpontzeko Azure zerbitzuak aprobetxatzeko aukera ematen digu.

2. Eskalagarritasuna eta malgutasuna: Azure-rekin, erraz handitu edo txikitu ditzakegu baliabideak gure negozio-beharren arabera. Azure-k sistema eragilea, programazio-lengoaia eta esparruak aukeratzeko malgutasuna ere eskaintzen du.

3. Segurtasuna eta betetzea: Azure-k segurtasun- eta betetze-maila handia eskaintzen du, industria-estandar anitzekin bat datorrelako, hala nola ISO, SOC, HIPAA eta PCI DSS. Azure-k, gainera, segurtasun-ezaugarri aurreratuak eskaintzen ditu, hala nola sare-segurtasuneko taldeak, suebakiak eta DDoS babesa.

4. Hodei hibridoa: Azure-k hodei hibridoaren esperientzia ezin hobea eskaintzen du, erakundeei beren ekipamendu-barneko azpiegitura Azure-rekin konektatzeko aukera emanez. Horrek errazten digu lan-kargak hodeira migratzea eta datuak non gorde aukeratzeko malgutasuna ematen digu.

5. Kostu-eraginkorra: Azure-k erabilitakoaren arabera ordaintzeko prezio-eredua eskaintzen du, hau da, erabilitako baliabideengatik bakarrik ordaintzen dugu. Horrek ohiko ekipamendu-barneko azpiegiturarekin alderatuta kostuak aurrezten laguntzen digu.

## Ondorioa

Microsoft Azure gure erakundearen hodei-azpiegitura gisa hartzea gure negozio-eskakizunekin bat dator eta onura anitz eskaintzen ditu, hala nola eskalagarritasuna, malgutasuna, segurtasuna eta kostu-eraginkortasuna. Beraz, Azure gure hodei-azpiegitura gisa hartzea gomendatzen da.
