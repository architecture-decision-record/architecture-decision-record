# Taifead Cinnidh Ailtireachta: ceolrú coimeádán Kubernetes

## Ráiteas Faidhbe 

Ní mór dúinn ardán ceolraithe coimeádán a roghnú dár mbailiúchán feidhmchlár dúchasach scamall atá ag fás. Tá ár n-imlonnú ardáin oidhreachta reatha rómhall, agus níl sé gasta go leor chun coinneáil suas lenár riachtanais atá ag fás. Táimid ag lorg córais a ligfidh dúinn ár seirbhísí a scálú ar an mbealach is éifeachtúla is féidir gan dul i gcontúirt le gastacht ná éascaíocht úsáide.

2. Kubernetes

## An Cinneadh a Rinneadh

Tar éis anailís chúramach a dhéanamh ar gach ardán ceolraithe coimeádán, tá cinneadh déanta againn Kubernetes a ghlacadh mar an rogha is fearr dár riachtanais fiontair. Is iad seo a leanas ár gcúiseanna le Kubernetes a roghnú:

1. **Inscálaitheacht:**  Tá dearadh uathúil Kubernetes foirfe chun feidhmchláir a scálú, agus de réir mar a fhorbraíonn ár riachtanais inscálaitheachta le himeacht ama, tá an cumas ionsuite ag Kubernetes na hathruithe seo a shásamh gan aon fhadhbanna.

2. **Ailtireacht Dhíláraithe:**  Cinntíonn topeolaíocht máistir-oibrí Kubernetes ailtireacht dhíláraithe a chinntíonn nach bhfuil aon phointe teipe amháin ann.

3. **Tacaíocht ón bPobal:**  Tá an pobal foinse oscailte is mó agus is gníomhaí ag Kubernetes, rud a chiallaíonn go bhfuil líon mór rannpháirtithe, forbróirí, agus díoltóirí aige, rud a fhágann go bhfuil sé níos éasca dúinn cabhair a fháil agus acmhainní a aimsiú.

4. **Tacaíocht Éiceachórais:**  Tá éiceachóras atá ag fás ag Kubernetes le héagsúlacht uirlisí tríú páirtí, comhtháthaithe le clárlanna coimeádán, píblínte CI/CD, stóráil sonraí, agus níos mó.

Dá bhrí sin, tá cinneadh déanta againn Kubernetes a ghlacadh mar ár n-ardán ceolraithe coimeádán don am i láthair agus don todhchaí láithreach.
