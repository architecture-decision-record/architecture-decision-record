# Cathetan Keputusan Arsitektur: Pustaka JavaScript Front-end Svelte

Status: Ditampa

## Konteks

Kita lagi ngembangake aplikasi web nggunakake framework JavaScript front-end modern. Kita pengin milih pustaka sing entheng, cepet, lan gampang digunakake. Kita wis ngevaluasi sawetara pustaka, kalebu React, Vue, lan Angular. Kita uga wis krungu babagan Svelte, sing ngaku minangka jinis framework entheng anyar. Kita kudu ngevaluasi Svelte lan mutusake apa cocog kanggo aplikasi kita.

## Keputusan

Sawise nimbang kaluwihan lan kekurangan saben pustaka, kita mutusake nggunakake Svelte minangka pustaka JavaScript front-end kita kanthi alasan-alasan iki:

1. **Entheng:**  Svelte salah sawijining pustaka paling entheng sing kasedhiya, sing bakal mbiyantu kita njaga ukuran aplikasi cilik lan nambah wektu pemuatan kaca.

2. **Cepet:**  Svelte dikenal amarga kacepetan rendering sing cepet, sing bakal ndadekake aplikasi kita rumangsa responsif lan trengginas.

3. **Gampang digunakake:**  Sintaksis Svelte prasaja lan gampang dimangerteni, sing bakal nggampangake tim kita ngadopsi lan nulis kode sing resik.

4. **Dioptimalake kanggo rendering UI:**  Svelte dioptimalake kanggo rendering komponen UI, sing bakal nggampangake kita nggawe unsur UI dinamis lan bisa digunakake maneh.

5. **Dokumentasi lan dhukungan komunitas sing apik:**  Svelte nduwe komunitas sing saya tuwuh lan dokumentasi sing apik, sing bakal mbiyantu kita miwiti kanthi cepet lan ngrampungake masalah apa wae sing muncul.

## Alternatif

Kita nimbang React, Vue, lan Angular, nanging mutusake ora nggunakake amarga alasan-alasan iki:

1. **React:**  Sanajan React nduwe basis pangguna gedhe lan akeh pustaka lan sumber daya, bisa rumit lan angel disinaoni, utamane kanggo pamula.

2. **Vue:**  Vue yaiku pustaka entheng sing gampang disinaoni lan digunakake, nanging mbok menawa ora sacepet utawa sadioptimalake Svelte.

3. **Angular:**  Angular yaiku framework lengkap sing nawakake akeh fitur lan piranti, nanging bisa abot lan rumit, lan mbok menawa mbutuhake pangopènan luwih akeh tinimbang Svelte.

## Akibat

Nggunakake Svelte minangka pustaka JavaScript front-end kita bakal nduwe akibat-akibat iki:

1. Aplikasi kita bakal entheng lan cepet, sing bakal nambah pengalaman lan keterlibatan pangguna.

2. Tim kita kudu sinau pustaka anyar, nanging sintaksis Svelte prasaja lan gampang dimangerteni, mula kurva sinau kudune bisa diatur.

3. Svelte isih pustaka sing relatif anyar, mula kita mbok menawa nemoni sawetara masalah sing ora didokumentasi kanthi apik utawa didhukung komunitas.

4. Komunitas pangguna Svelte saya tuwuh, mula kita mbok menawa bakal weruh luwih akeh pustaka pihak katelu lan sumber daya sing kasedhiya ing mbesuk sing bisa digunakake kanggo nglengkapi pustaka inti.
