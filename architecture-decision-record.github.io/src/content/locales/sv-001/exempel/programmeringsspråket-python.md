## Motivering

Python är ett mångsidigt programmeringsspråk som används brett inom dataanalys, maskininlärning och webb-
utveckling. Det är ett tolkat språk, vilket innebär att det inte behöver kompileras, och det har en lättläst och lättförstådd syntax. Andra viktiga faktorer för vårt beslut inkluderar följande:

1. **Tillgång till bibliotek:** Python har en enorm samling bibliotek och ramverk, som NumPy, Pandas och Scikit-learn, vilket gör det enklare för utvecklare att implementera algoritmer för maskininlärning och dataanalys.

2. **Communitystöd:** Python har en stor och aktiv gemenskap av utvecklare som bidrar till dess utveckling och ger stöd och vägledning på olika forum och webbplatser. Det gör det enklare för nybörjare att hitta hjälp och lära sig språket.

3. **Skalbarhet:** Python är skalbart, vilket innebär att det kan hantera stora datamängder och komplexa applikationer. Det kan också användas för snabb prototypframställning eller för att bygga små applikationer med minimal ansträngning, vilket gör det enklare för oss att starta vårt projekt och iterera snabbt.

4. **Flexibilitet:** Python kan användas för olika typer av projekt, inklusive webbutveckling, vetenskapliga beräkningar, maskininlärning osv. Det är också kompatibelt med andra programmeringsspråk, som Java och C++, vilket gör det enklare att integrera med andra system.

Det finns några potentiella konsekvenser av att använda Python som vårt programmeringsspråk, till exempel:

3. **Versionskompatibilitet:** Olika versioner av Python kan ha olika syntax och förmågor, vilket kan göra det svårt att underhålla och uppdatera projekt. Det är viktigt att välja en version av Python som stöds brett och är kompatibel med våra projektkrav.
