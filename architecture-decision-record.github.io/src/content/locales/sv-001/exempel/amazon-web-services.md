# Arkitekturbeslutspost för Amazon Web Services

Titel: Införande av Amazon Web Services för molninfrastruktur

## Beslut

Efter en grundlig utvärdering av olika molninfrastrukturplattformar har det beslutats att Amazon Web Services (AWS) ska införas av vår organisation för våra behov av molninfrastruktur.

## Bakgrund

Vår organisation växer snabbt och vi behöver en pålitlig och skalbar molninfrastruktur för att möta vår verksamhets krav. Efter att ha övervägt ett antal leverantörer av molninfrastruktur drogs slutsatsen att AWS erbjuder det mest lämpliga utbudet av tjänster för att möta våra nuvarande och framtida krav.

## Överväganden

Det finns många leverantörer av molninfrastruktur på marknaden som har visat sig vara pålitliga och effektiva. AWS erbjuder dock inte bara en omfattande uppsättning tjänster som svarar mot våra behov, utan har också en omfattande kundbas och en meritlista av framgångsrika driftsättningar. AWS tillhandahåller också ett brett utbud av support- och utbildningsresurser för att säkerställa att vårt team kan arbeta effektivt med plattformen.

Dessutom har AWS en omfattande global närvaro med datacenter i olika regioner runt om i världen. Detta säkerställer att våra data är säkra och att våra applikationer och tjänster kommer att ha hög tillgänglighet. AWS har också ett robust säkerhetsramverk som är avgörande för vår verksamhet.

Slutligen erbjuder AWS en betala-per-användning-modell som ger oss flexibiliteten att skala vår infrastruktur utifrån efterfrågan. Det innebär att vi bara debiteras för det vi använder, vilket gör att vi kan optimera våra kostnader och investera i andra delar av verksamheten.

## Beslut

Baserat på de utvärderingar som gjorts och de fördelar som AWS erbjuder har det beslutats att AWS ska införas för våra behov av molninfrastruktur.

## Konsekvenser

Införandet av AWS kan kräva utbildning av våra team för att säkerställa att de är bekanta med plattformen och kan utnyttja den effektivt. Det kan också finnas vissa initiala kostnader för att flytta vår nuvarande infrastruktur till AWS-plattformen.

## Ägarskap

Ansvaret för att säkerställa ett effektivt utnyttjande av AWS och hanteringen av tillhörande risker ligger inom ansvarsområdet för teamet för molninfrastruktur. Eventuella problem som uppstår måste hanteras av det här teamet.

## Översyn

Beslutet att anta AWS kommer att ses över årligen för att säkerställa att det fortsätter att möta våra behov och att plattformens fördelar utnyttjas fullt ut.
