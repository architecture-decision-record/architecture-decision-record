# Mall för beslutspost med Planguage

Se https://www.iaria.org/conferences2012/filesICCGI12/Tutorial%20Specifying%20Effective%20Non-func.pdf

## Vad är Planguage?

Planguage är ett planeringsspråk som använder dessa nyckelord:

* Tag: En unik, beständig identifierare
* Gist: En kort sammanfattning av kravet eller det område som behandlas
* Requirement: Texten som i detalj beskriver själva kravet
* Rationale: Resonemanget som motiverar kravet
* Priority: Ett uttalande om prioritet och anspråk på resurser
* Stakeholders: Parter som i väsentlig mån påverkas av kravet
* Status: Kravets status (draft, reviewed, committed osv.)
* Owner: Personen som ansvarar för att genomföra kravet
* Author: Personen som skrev kravet
* Revision: Ett versionsnummer för uttalandet
* Date: Datumet för den senaste revideringen
* Assumptions: Allt som kan orsaka problem om det inte stämmer nu eller senare
* Risks: Allt som kan orsaka fel, förseningar eller andra negativa effekter
* Defined: Definitionen av en term (bättre att använda en ordlista)
