# Cofnod penderfyniad saernïaeth: cronfa ddata PostgreSQL

Teitl: Defnyddio cronfa ddata PostgreSQL

## Cyd-destun

Ar hyn o bryd mae ein sefydliad yn gwerthuso dewisiadau ar gyfer y system rheoli cronfa ddata fwyaf addas i'w defnyddio yn ein prosiect nesaf. Rydym wedi culhau ein chwiliad i ddau ddewis – PostgreSQL a MySQL. Ar ôl ystyried yn ofalus, rydym wedi penderfynu defnyddio PostgreSQL oherwydd ei nodweddion uwch a'i alluoedd perfformiad.

## Penderfyniad

Byddwn yn defnyddio PostgreSQL fel y system rheoli cronfa ddata a ffefrir ar gyfer prosiect nesaf ein sefydliad.

## Cyfiawnhad

Ar ôl dadansoddi a chymharu nodweddion PostgreSQL a MySQL, rydym wedi dod i'r casgliad mai PostgreSQL yw'r dewis gwell am y rhesymau canlynol:

1. **Nodweddion uwch:**  Mae gan PostgreSQL ystod eang o nodweddion uwch fel cefnogaeth i JSON, chwilio testun llawn, a rheoli data gofodol, sy'n hanfodol i'n prosiect.

2. **Perfformiad:**  Mae gan PostgreSQL hanes profedig o alluoedd perfformiad rhagorol, a fydd yn sicrhau bod ein prosiect yn rhedeg yn esmwyth heb unrhyw broblemau perfformiad.

3. **Cefnogaeth gan y gymuned:**  Mae gan PostgreSQL gymuned fawr a gweithgar sy'n darparu diweddariadau a chefnogaeth reolaidd, sy'n ei gwneud hi'n haws datrys unrhyw broblemau a godir yn ystod cyfnod datblygu'r prosiect.

4. **Graddadwyedd:**  Mae PostgreSQL yn hynod raddadwy, a gall ymdrin â llawer iawn o ddata'n rhwydd, a fydd yn hanfodol i'n prosiect.

5. **Diogelwch:**  Mae gan PostgreSQL fecanwaith diogelwch cadarn a fydd yn sicrhau bod data ein prosiect yn ddiogel bob amser, ac mae'n bodloni holl ofynion diogelwch ein sefydliad.

## Dewisiadau amgen

Y dewis arall a ystyriwyd gennym oedd MySQL. Mae MySQL hefyd yn system rheoli cronfa ddata hynod alluog, ond mae'n brin o rai o'r nodweddion uwch y mae PostgreSQL yn eu cynnig, ac nid yw ei allu perfformiad cystal â gallu PostgreSQL.
