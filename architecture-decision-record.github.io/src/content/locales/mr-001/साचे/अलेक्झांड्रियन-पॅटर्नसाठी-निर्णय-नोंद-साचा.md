# अलेक्झांड्रियन पॅटर्नसाठी निर्णय नोंद साचा

## प्रस्तावना

* प्रस्तावना (सारांश)
* चर्चा (संदर्भ)
* उपाय (निर्णय)
* परिणाम (निष्पत्ती)

## तपशील ##

* प्रस्तावना (सारांश)
  * सारांश देणारे विधान:
    * (वापर प्रकरणाच्या) संदर्भात<br>
      (चिंतेला) सामोरे जाताना<br>
      आम्ही (पर्याय) निवडला<br>
      (गुणवत्ता) साध्य करण्यासाठी<br>
      (तोटा) स्वीकारून.
* चर्चा (संदर्भ)
  * कार्यरत शक्ती (तांत्रिक, राजकीय, सामाजिक, प्रकल्प) स्पष्ट करते.
  * आपण सोडवू पाहत असलेल्या समस्येचे स्पष्टीकरण देणारी ही कथा आहे.
* उपाय
  * निर्णय समस्या कशी सोडवेल हे स्पष्ट करते.
* परिणाम
  * निर्णयाचे दीर्घकालीन निकाल स्पष्ट करते.
  * तो यशस्वी झाला, झाला नाही, बदलला गेला, श्रेणीसुधारित केला गेला इत्यादी.
