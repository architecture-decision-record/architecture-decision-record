# Python Django फ्रेमवर्कसाठी आर्किटेक्चर निर्णय नोंद

निर्णयाची तारीख: 2021-07-15

स्थिती: स्वीकारले

## संदर्भ

आमची संस्था ग्राहक डेटा व्यवस्थापित करणारा वेब अनुप्रयोग विकसित करण्याची योजना आखत आहे. आम्ही प्रोग्रामिंग भाषा म्हणून Python निवडली आहे आणि अनुप्रयोगाच्या विकासासाठी वेब फ्रेमवर्क म्हणून Django चा विचार करत आहोत.

## निर्णय

वेब अनुप्रयोगाच्या विकासासाठी Django वेब फ्रेमवर्क वापरण्याचा आम्ही निर्णय घेतला आहे. Django वेब अनुप्रयोग जलद आणि कार्यक्षमतेने बनवण्यासाठी साधने आणि वैशिष्ट्यांचा मजबूत संच पुरवते. 

## घटक

आमच्या निर्णयावर प्रभाव टाकणाऱ्या काही घटकांमध्ये पुढील गोष्टींचा समावेश आहे:

१. ऑब्जेक्ट-रिलेशनल मॅपिंग (ORM): Django मध्ये अंगभूत ORM आहे जे आम्हाला SQL क्वेरी न लिहिता डेटाबेसशी परस्परक्रिया करू देते. यामुळे अनुप्रयोग विकसित करणे आणि दीर्घकाळात सांभाळणे सोपे होते.

२. MVC फ्रेमवर्क: Django Model-View-Controller (MVC) आर्किटेक्चर पाळते, ज्यामुळे अनुप्रयोगाचा व्यावसायिक तर्क आणि सादरीकरण स्तर वेगळे करणे सोपे होते.

३. प्रमाण वाढवण्याची क्षमता: Django त्याच्या प्रमाण वाढवण्याच्या क्षमतांसाठी ओळखले जाते, ज्यामुळे मोठ्या प्रमाणातील अनुप्रयोग विकसित करण्यासाठी तो उत्कृष्ट पर्याय ठरतो.

४. सुरक्षा: Django मध्ये क्रॉस-साइट स्क्रिप्टिंग (XSS) आणि SQL इंजेक्शन यांसारख्या सामान्य वेब हल्ल्यांपासून संरक्षणासह अंगभूत सुरक्षा वैशिष्ट्ये आहेत.

५. समुदाय समर्थन: Django चा मोठा आणि सक्रिय समुदाय आहे जो समर्थन पुरवतो आणि फ्रेमवर्कच्या विकासात योगदान देतो.

## विचारात घेतलेले पर्याय

आम्ही Flask आणि Pyramid सारख्या इतर वेब फ्रेमवर्कचा विचार केला. तथापि, आम्हाला आढळले की Django हे अधिक परिपक्व आणि सुस्थापित फ्रेमवर्क आहे ज्यात वैशिष्ट्यांचा मजबूत संच आहे.

आम्ही वेब फ्रेमवर्कशिवाय अनुप्रयोग विकसित करण्याबद्दल आणि SQLAlchemy व Flask-RESTful सारख्या लायब्ररी वापरण्याबद्दलही चर्चा केली. तथापि, आम्हाला आढळले की Django व्यापक कार्यक्षमता देते, ज्यामुळे ते संपूर्ण वेब अनुप्रयोगासाठी चांगला पर्याय ठरते.

## परिणाम

Django च्या अवलंबामुळे पुढील परिणाम होतील:

१. Django च्या अंगभूत साधनांमुळे आणि वैशिष्ट्यांमुळे अनुप्रयोग विकसित करणे आणि सांभाळणे सोपे.

२. व्यावसायिक तर्क आणि सादरीकरण स्तराचे विभाजन, ज्यामुळे कोड अधिक सुव्यवस्थित आणि सांभाळण्यास सोपा होतो.

३. अनुप्रयोगाची प्रमाण वाढवण्याची क्षमता आणि मजबुती.

४. अनुप्रयोगाला सामान्य वेब हल्ल्यांपासून संरक्षित करण्यास मदत करणारी अंगभूत सुरक्षा वैशिष्ट्ये.

५. समर्थनासाठी मोठ्या आणि सक्रिय समुदायाचा लाभ.

आम्हाला समजते की इतर फ्रेमवर्कपेक्षा Django साठी शिकण्याची चढण अधिक तीव्र आहे, पण ते देत असलेल्या दीर्घकालीन फायद्यांसाठी ही गुंतवणूक योग्य आहे असे आम्हाला वाटते.

## निष्कर्ष

विचारात घेतलेल्या घटकांवर आधारित, वेब अनुप्रयोगाच्या विकासासाठी Django वेब फ्रेमवर्क वापरण्याचा आम्ही निर्णय घेतला आहे. आमचा विश्वास आहे की Django ची वैशिष्ट्ये, समुदाय समर्थन आणि प्रमाण वाढवण्याच्या क्षमता यामुळे ते संपूर्ण वेब अनुप्रयोग बनवण्यासाठी सर्वोत्तम पर्याय ठरते. फ्रेमवर्क प्रभावीपणे आणि कार्यक्षमतेने वापरले जाईल याची खात्री करण्यासाठी आम्ही आमच्या विकासकांना Django वापरण्याचे प्रशिक्षण देऊ.
