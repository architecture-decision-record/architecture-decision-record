# Amazon Web Services 的架构决策记录

标题:采用 Amazon Web Services 作为云基础设施

## 决策

在对各种云基础设施平台进行全面评估之后,我们决定组织将采用 Amazon Web Services(AWS)来满足云基础设施需求。

## 背景

我们的组织正在快速成长,需要可靠且可扩展的云基础设施来满足业务需求。在考察了多家云基础设施提供商之后,我们得出结论:AWS 提供的服务范围最适合满足我们当前和未来的需求。

## 考量

市场上有许多已被证明可靠且高效的云基础设施提供商。然而,AWS 不仅提供全面的服务来满足我们的需求,还拥有庞大的客户群和成功部署的业绩记录。AWS 还提供广泛的支持和培训资源,以确保我们的团队能够有效地使用该平台。

此外,AWS 在全球拥有广泛的布局,其数据中心遍布世界各地的多个区域。这确保了我们的数据安全,以及我们的应用和服务具有高可用性。AWS 还拥有稳健的安全框架,这对我们的业务至关重要。

最后,AWS 提供按使用量付费的模式,使我们可以根据需求灵活地扩展基础设施。这意味着我们只需为使用的部分付费,从而优化成本,并将资金投入业务的其他方面。

## 决策

基于已完成的评估以及 AWS 所提供的优势,我们决定采用 AWS 来满足云基础设施需求。

## 后果

采用 AWS 可能需要对团队进行培训,以确保他们熟悉该平台并能有效地使用它。将现有基础设施迁移到 AWS 平台也可能产生一些初始成本。

## 责任归属

确保 AWS 的有效利用以及管理相关风险的责任,将由云基础设施团队承担。出现的任何问题都必须由该团队处理。

## 复审

采用 AWS 的决策将每年复审一次,以确保它持续满足我们的需求,并确保充分实现该平台的收益。
