# แม่แบบบันทึกการตัดสินใจสำหรับกรณีทางธุรกิจ

แม่แบบ ADR นี้เน้นการจัดทำกรณีทางธุรกิจสำหรับการตัดสินใจ รวมถึงเกณฑ์ ผู้สมัคร และต้นทุน


## ระดับบนสุด

* ชื่อเรื่อง
* สถานะ
* เกณฑ์การประเมิน
* ผู้สมัครที่ต้องพิจารณา
* การค้นคว้าและวิเคราะห์ผู้สมัครแต่ละราย
  * ตรงหรือไม่ตรงตามเกณฑ์และเพราะเหตุใด
  * การวิเคราะห์ต้นทุน
  * การวิเคราะห์ SWOT
  * ความเห็นและข้อเสนอแนะ
* ข้อเสนอแนะ


## ระดับลึกลงไป

**ชื่อเรื่อง**:

  * วลีสั้นแบบคำสั่งในกาลปัจจุบัน น้อยกว่า 50 อักขระ เหมือนข้อความ git commit

**สถานะ**:

  * หนึ่งใน: proposed, accepted, rejected, deprecated, superseded ฯลฯ

**เกณฑ์การประเมิน**:

  * สรุป: อธิบายสั้น ๆ ว่าคุณพยายามค้นหาอะไรและทำไม

  * รายละเอียด

**ผู้สมัครที่ต้องพิจารณา**:

  * สรุป: อธิบายสั้น ๆ ว่าคุณพบผู้สมัครอย่างไร และชี้ให้เห็นค่าผิดปกติ

  * ระบุผู้สมัครและทางเลือกที่เกี่ยวข้องทั้งหมด คุณกำลังประเมินอะไรเป็นวิธีแก้ปัญหาที่เป็นไปได้

  * รายละเอียด

**การค้นคว้าและวิเคราะห์ผู้สมัครแต่ละราย**:

  * สรุป: อธิบายสั้น ๆ ว่าคุณค้นคว้าอย่างไร และชี้ให้เห็นรูปแบบ กลุ่ม และค่าผิดปกติ

  * ตรงหรือไม่ตรงตามเกณฑ์และเพราะเหตุใด

    * สรุป

    * รายละเอียด

  * การวิเคราะห์ต้นทุน

    * สรุป

    * ตัวอย่าง

      * ใบอนุญาต เช่น ข้อตกลงตามสัญญาและพันธะทางกฎหมาย

      * การฝึกอบรม เช่น การพัฒนาขีดความสามารถและการจัดการการเปลี่ยนแปลง

      * การดำเนินงาน เช่น การสนับสนุนและการบำรุงรักษา

      * การวัดการใช้งาน เช่น แบนด์วิดท์และการใช้ CPU

  * การวิเคราะห์ SWOT

    * สรุป

    * จุดแข็ง (Strengths)

    * จุดอ่อน (Weaknesses)

    * โอกาส (Opportunities)

    * ภัยคุกคาม (Threats)

  * ความเห็นและข้อเสนอแนะภายใน

    * สรุป

    * ตัวอย่าง

      * จากทีม โดยเหมาะที่สุดเขียนโดยผู้เกี่ยวข้องจริง

      * จากผู้มีส่วนได้ส่วนเสียอื่น

      * คุณลักษณะด้านคุณภาพ หรือที่เรียกว่าข้อกำหนดข้ามฟังก์ชัน 

  * ความเห็นและข้อเสนอแนะภายนอก

    * สรุป

    * ใครให้ความเห็น

    * พวกเขาพิจารณาผู้สมัครรายอื่นใดบ้าง

    * พวกเขากำลังสร้างอะไร 

      * ตัวอย่าง

        * B2B หรือ B2C

        * หันหน้าสู่ภายนอกหรือสำหรับพนักงานเท่านั้น

        * เดสก์ท็อปหรือมือถือ

        * นำร่องหรือใช้งานจริง

        * โมโนลิธหรือไมโครเซอร์วิส

    * พวกเขาประเมินผู้สมัครอย่างไร

    * ทำไมพวกเขาจึงเลือกผู้ชนะ

    * หลังจากนั้นเกิดอะไรขึ้นบ้าง

      * ตัวอย่าง

        * ผู้ชนะทำงานได้ดีเพียงใด

        * ปริมาณการใช้งานจริงของผู้ใช้กี่เปอร์เซ็นต์ที่ไหลผ่านผู้ชนะ

        * เกี่ยวข้องกับการบูรณาการประเภทใด เช่น การบูรณาการกับไปป์ไลน์การส่งมอบอย่างต่อเนื่อง ระบบจัดการเนื้อหา การวิเคราะห์และเมตริก ฯลฯ

        * จากสิ่งที่พวกเขารู้ในตอนนี้ พวกเขาจะแนะนำให้ผู้คนทำอะไรต่างออกไป

  * เกร็ดเล่า

**ข้อเสนอแนะ**:

  * สรุป

  * รายละเอียด
