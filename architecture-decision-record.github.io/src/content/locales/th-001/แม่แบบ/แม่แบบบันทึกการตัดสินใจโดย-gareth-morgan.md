# [000] ชื่อเรื่อง
*กำหนดหมายเลขให้แต่ละ ADR เพื่อให้อ้างอิงและจัดหมวดหมู่ได้ง่าย* \
*หมายเหตุ: ข้อความตัวเอียงทั้งหมดเป็นคำใบ้และควรลบออกเมื่อใช้งานจริง*

## สถานะ - DRAFT / ACTIVE /  DEPRECATED by [000] / SUPERSEDES [000]

## บริบท
*อธิบายสั้น ๆ ถึงปัญหาที่ ADR นี้ต้องการแก้ไขและสาเหตุที่ปัญหามีอยู่*

## แนวทางที่เลือก
*อธิบายอย่างละเอียดถึงการตัดสินใจที่มีนัยสำคัญด้านสถาปัตยกรรมที่ได้ทำหรือจะทำ และอธิบายว่าแก้ปัญหาที่ระบุในส่วนบริบทอย่างไร*

## ผลที่ตามมา
*การตัดสินใจนี้ส่งผลต่อคุณลักษณะด้านสถาปัตยกรรมและข้อกำหนดเชิงฟังก์ชันของระบบอย่างไร*

## ธรรมาภิบาล
*ติดตามผลที่ตามมาของการตัดสินใจนี้อย่างไร* \
*ทำให้แน่ใจว่าปฏิบัติตามการตัดสินใจนี้อย่างไร*

## การวิเคราะห์ทางเลือก
*หากเกี่ยวข้อง ให้รวมหรือลิงก์การวิเคราะห์ข้อแลกเปลี่ยนที่ทำเพื่อให้ได้การตัดสินใจในเอกสารนี้*

### คำอธิบายสัญลักษณ์
*ทางเลือก: จัดให้มีสื่อช่วยทางสายตาที่ช่วยให้ผู้มีส่วนได้ส่วนเสียเห็นข้อแลกเปลี่ยนเชิงบวกและเชิงลบได้อย่างรวดเร็ว เช่น การเน้นแบบไฟจราจรอย่างง่ายพร้อมคำนำหน้าเชิงบวกหรือลบ*
