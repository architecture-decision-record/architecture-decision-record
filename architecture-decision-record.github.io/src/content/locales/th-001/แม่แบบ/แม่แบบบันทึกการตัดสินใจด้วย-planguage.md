# แม่แบบบันทึกการตัดสินใจด้วย Planguage

ดู https://www.iaria.org/conferences2012/filesICCGI12/Tutorial%20Specifying%20Effective%20Non-func.pdf

## Planguage คืออะไร

Planguage เป็นภาษาสำหรับการวางแผนที่ใช้คำสำคัญดังต่อไปนี้:

* Tag: ตัวระบุที่ไม่ซ้ำและคงอยู่
* Gist: สรุปสั้น ๆ ของข้อกำหนดหรือพื้นที่ที่ครอบคลุม
* Requirement: ข้อความที่อธิบายตัวข้อกำหนดโดยละเอียด
* Rationale: การให้เหตุผลที่ยืนยันข้อกำหนด
* Priority: คำแถลงลำดับความสำคัญและการอ้างสิทธิ์ในทรัพยากร
* Stakeholders: ฝ่ายที่ได้รับผลกระทบอย่างมากจากข้อกำหนด
* Status: สถานะของข้อกำหนด (draft, reviewed, committed ฯลฯ)
* Owner: ผู้รับผิดชอบในการนำข้อกำหนดไปใช้
* Author: ผู้เขียนข้อกำหนด
* Revision: หมายเลขเวอร์ชันของคำแถลง
* Date: วันที่ของการปรับปรุงล่าสุด
* Assumptions: อะไรก็ตามที่อาจก่อให้เกิดปัญหาหากไม่เป็นจริง ไม่ว่าตอนนี้หรือภายหลัง
* Risks: อะไรก็ตามที่อาจก่อให้เกิดความล้มเหลว ความล่าช้า หรือผลกระทบเชิงลบอื่น
* Defined: นิยามของคำศัพท์ (ควรใช้อภิธานศัพท์จะดีกว่า)
