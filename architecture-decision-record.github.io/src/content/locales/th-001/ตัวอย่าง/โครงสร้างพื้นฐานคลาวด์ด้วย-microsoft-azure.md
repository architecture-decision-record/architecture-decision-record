# บันทึกการตัดสินใจด้านสถาปัตยกรรม: โครงสร้างพื้นฐานคลาวด์ด้วย Microsoft Azure

ชื่อการตัดสินใจ: การนำ Microsoft Azure มาใช้เป็นโครงสร้างพื้นฐานคลาวด์ขององค์กรเรา

ผู้ตัดสินใจ: ประธานเจ้าหน้าที่ฝ่ายสารสนเทศ (CIO)

วันที่: 2021-10-15

สถานะ: อนุมัติ

## ภูมิหลัง

องค์กรวางแผนย้ายจากโครงสร้างพื้นฐานภายในองค์กรแบบดั้งเดิมไปยังโครงสร้างพื้นฐานคลาวด์ เพื่อบรรลุเป้าหมายนี้ องค์กรได้ประเมินผู้ให้บริการคลาวด์หลายราย เช่น Amazon Web Services (AWS), Google Cloud Platform (GCP), Microsoft Azure และ IBM Cloud แต่ละผู้ให้บริการมีชุดฟีเจอร์ ประโยชน์ และโครงสร้างราคาของตนเอง หลังจากการวิเคราะห์โดยละเอียด สรุปได้ว่า Microsoft Azure เป็นตัวเลือกที่เหมาะสมที่สุดสำหรับองค์กรของเรา

## การตัดสินใจ

นำ Microsoft Azure มาใช้เป็นโครงสร้างพื้นฐานคลาวด์ขององค์กรเรา

## เหตุผล

ต่อไปนี้คือเหตุผลในการนำ Microsoft Azure มาใช้:

1. บริการที่ครอบคลุม: Azure ให้บริการคลาวด์ครบทุกด้านตั้งแต่โครงสร้างพื้นฐานเป็นบริการ (IaaS) ไปจนถึงซอฟต์แวร์เป็นบริการ (SaaS) และแพลตฟอร์มเป็นบริการ (PaaS) ทำให้เราใช้บริการ Azure เพื่อแก้ข้อกำหนดขององค์กรได้ เช่น การจัดเก็บ การประมวลผล เครือข่าย และการวิเคราะห์

2. ความสามารถในการปรับขนาดและความยืดหยุ่น: ด้วย Azure เราปรับขนาดทรัพยากรขึ้นหรือลงได้ง่ายตามความต้องการทางธุรกิจ Azure ยังให้ความยืดหยุ่นในการเลือกระบบปฏิบัติการ ภาษาโปรแกรม และเฟรมเวิร์ก

3. ความปลอดภัยและการปฏิบัติตามข้อกำหนด: Azure ให้ความปลอดภัยและการปฏิบัติตามข้อกำหนดในระดับสูง เพราะสอดคล้องกับมาตรฐานอุตสาหกรรมหลายอย่าง เช่น ISO, SOC, HIPAA และ PCI DSS Azure ยังให้ฟีเจอร์ความปลอดภัยขั้นสูง เช่น กลุ่มความปลอดภัยเครือข่าย ไฟร์วอลล์ และการป้องกัน DDoS

4. ไฮบริดคลาวด์: Azure ให้ประสบการณ์ไฮบริดคลาวด์ที่ราบรื่น ช่วยให้องค์กรเชื่อมต่อโครงสร้างพื้นฐานภายในองค์กรกับ Azure ทำให้เราย้ายภาระงานไปยังคลาวด์ได้ง่ายและให้ความยืดหยุ่นในการเลือกที่จัดเก็บข้อมูล

5. คุ้มค่าต้นทุน: Azure เสนอโมเดลราคาจ่ายตามที่ใช้ หมายความว่าเราจ่ายเฉพาะทรัพยากรที่ใช้ ซึ่งช่วยให้เราประหยัดต้นทุนเมื่อเทียบกับโครงสร้างพื้นฐานภายในองค์กรแบบดั้งเดิม

## บทสรุป

การนำ Microsoft Azure มาใช้เป็นโครงสร้างพื้นฐานคลาวด์ขององค์กรเราสอดคล้องกับข้อกำหนดทางธุรกิจของเราและให้ประโยชน์หลายอย่าง เช่น ความสามารถในการปรับขนาด ความยืดหยุ่น ความปลอดภัย และความคุ้มค่าด้านต้นทุน ดังนั้นจึงแนะนำให้นำ Azure มาใช้เป็นโครงสร้างพื้นฐานคลาวด์ของเรา
