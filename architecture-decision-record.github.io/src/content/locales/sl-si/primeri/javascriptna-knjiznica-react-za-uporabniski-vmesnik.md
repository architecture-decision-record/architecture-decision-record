# Zapis arhitekturne odločitve: JavaScriptna knjižnica React za uporabniški vmesnik

## Kontekst

Za svojo aplikacijo moramo izbrati JavaScriptno knjižnico za uporabniški del, s katero bomo razvili odziven in interaktiven uporabniški vmesnik.
  
## Preučene možnosti

1. React
  
2. Vue

3. Svelte
   
## Odločitev

Kot svojo JavaScriptno knjižnico za uporabniški del bomo uporabili React.
  
## Utemeljitev

1. **Arhitektura, temelječa na komponentah:**  React zagotavlja arhitekturo, temelječo na komponentah, ki nam omogoča razčlenitev uporabniškega vmesnika na majhne ponovno uporabne komponente. To pomaga izboljšati modularnost naše kode ter olajša vzdrževanje, skaliranje in posodabljanje aplikacije.
  
2. **Deklarativno programiranje:**  React uporablja deklarativni slog programiranja, zaradi katerega je naša koda intuitivnejša in lažje berljiva. Zagotavlja tudi virtualni DOM, ki omogoča, da se naša koda izvaja hitreje in učinkoviteje.
  
3. **Velika skupnost:**  React ima veliko in dejavno skupnost ter je ena najbolj priljubljenih knjižnic za uporabniški del. To pomeni, da je na voljo veliko virov, orodij in knjižnic, ki nam lahko pomagajo hitreje in učinkoviteje razviti aplikacijo.
  
4. **Boljša zmogljivost:**  React uporablja enosmerni pretok podatkov, ki pomaga poenostaviti logiko aplikacije in jo naredi učinkovitejšo. Zagotavlja tudi upodabljanje na strani strežnika, ki pomaga izboljšati zmogljivost in SEO naše aplikacije.
  
5. **Prilagodljivost:**  React je mogoče uporabljati z drugimi knjižnicami in ogrodji, kar nam daje svobodo, da izberemo najboljši tehnološki sklad, ki ustreza zahtevam našega projekta.
  
## Posledice

1. **Krivulja učenja:**  React ima krivuljo učenja in razvijalcem, ki React šele spoznavajo, lahko traja nekaj časa, da se vpeljejo.
  
2. **Orodja za gradnjo:**  React zahteva dodatna orodja za gradnjo, kot sta Babel in Webpack, kar lahko doda kompleksnost razvojnemu procesu.
  
3. **Združljivost z brskalniki:**  React ima težave z združljivostjo s starejšimi brskalniki, ker uporablja funkcije ES6, ki jih starejši brskalniki ne podpirajo.
  
 4. Strma krivulja učenja: Razvijalcem, ki Reacta ne poznajo, lahko traja nekaj časa, da se naučijo učinkovite uporabe, kar lahko vodi do počasnejših časov razvoja.
