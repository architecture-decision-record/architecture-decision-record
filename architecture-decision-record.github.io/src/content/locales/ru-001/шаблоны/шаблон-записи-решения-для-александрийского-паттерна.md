# Шаблон записи решения для александрийского паттерна

## Введение

* Пролог (Резюме)
* Обсуждение (Контекст)
* Решение (Решение)
* Последствия (Результаты)

## Особенности ##

* Пролог (Резюме)
  * Утверждение для резюмирования:
    * В контексте (сценарий использования)<br>
      столкнувшись с (проблема)<br>
      мы решили выбрать (вариант)<br>
      чтобы достичь (качество)<br>
      смирившись с (недостаток).
* Обсуждение (Контекст)
  * Объясняет действующие силы (технические, политические, социальные, проектные).
  * Это история, объясняющая проблему, которую мы стремимся решить.
* Решение
  * Объясняет, как решение разрешит проблему.
* Последствия
  * Объясняет результаты решения в долгосрочной перспективе.
  * Сработало ли оно, не сработало, было ли изменено, обновлено и т. д.
