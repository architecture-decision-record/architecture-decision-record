## Решение

Мы решили использовать Docker Swarm в качестве инструмента оркестрации контейнеров. Docker Swarm предлагает простой и интуитивный способ управления контейнеризированными приложениями на кластере узлов. Он также позволяет нам использовать наши существующие рабочие процессы и инфраструктуру на основе Docker. С Docker Swarm мы можем легко развёртывать, масштабировать и обслуживать наши приложения, пользуясь встроенной балансировкой нагрузки.

## Преимущества

- **Простота:**  Docker Swarm следует тем же принципам, что и Docker, поэтому изучать новую технологию не нужно. Кривая обучения для разработчиков, знакомых с Docker, относительно пологая.

- **Интеграция:**  Docker Swarm бесшовно интегрируется с инструментами Docker, такими как Docker Compose, что упрощает управление всеми нашими контейнерами и сервисами из одного места.

- **Балансировка нагрузки:**  Docker Swarm обеспечивает встроенную балансировку нагрузки, гарантируя, что наши приложения всегда доступны и равномерно распределены по кластеру.

- **Масштабируемость:**  Docker Swarm позволяет легко масштабировать наши приложения горизонтально, добавляя узлы в кластер или удаляя их.

- **Высокая доступность:**  Docker Swarm автоматически распределяет наши сервисы по узлам, обеспечивая высокую доступность в случае отказа узла.

## Риски

- **Ограниченная функциональность:**  В Docker Swarm могут отсутствовать некоторые расширенные возможности, имеющиеся в Kubernetes или Mesosphere DC/OS, например автоматическое масштабирование или самовосстановление.

- **Ориентация на Docker:**  Docker Swarm тесно связан с Docker, что может ограничить нашу гибкость, если когда-либо понадобится отказаться от решений на основе Docker.

- **Незрелость:**  Docker Swarm — всё ещё относительно новая технология, и возможны проблемы со стабильностью или пробелы в документации.

## Альтернативы

- **Kubernetes:**  Kubernetes — самая широко используемая платформа оркестрации контейнеров, предлагающая расширенные возможности и более зрелую экосистему. Однако у неё более крутая кривая обучения, и она может быть избыточной для наших нужд.

- **Mesosphere DC/OS:**  Mesosphere DC/OS — мощный инструмент, предоставляющий расширенные возможности, такие как поддержка нескольких облаков и встроенные возможности платформы больших данных и ИИ. Однако для его внедрения требуется значительный опыт, и он может быть слишком сложным для наших требований.

Хотя в нём могут отсутствовать некоторые расширенные возможности, мы считаем, что преимущества Docker Swarm перевешивают его риски при наших текущих требованиях.
