# Запись архитектурного решения: облачная инфраструктура Microsoft Azure

Название решения: принятие Microsoft Azure в качестве облачной инфраструктуры нашей организации

Принявший решение: директор по информационным технологиям

Дата: 2021-10-15

Состояние: утверждено

## Предыстория

Организация планирует перейти с традиционной локальной инфраструктуры на облачную. Для этого организация оценила нескольких поставщиков облачных услуг, таких как Amazon Web Services (AWS), Google Cloud Platform (GCP), Microsoft Azure и IBM Cloud. У каждого поставщика свой набор функций, преимуществ и структура цен. После детального анализа был сделан вывод, что Microsoft Azure — наиболее подходящий вариант для нашей организации.

## Решение

Принять Microsoft Azure в качестве облачной инфраструктуры нашей организации.

## Обоснование

Вот причины принятия Microsoft Azure:

1. Комплексные сервисы: Azure предоставляет полный спектр облачных услуг — от инфраструктуры как услуги (IaaS) до программного обеспечения как услуги (SaaS) и платформы как услуги (PaaS). Это позволяет нам использовать сервисы Azure для решения потребностей организации, таких как хранение, вычисления, сети и аналитика.

2. Масштабируемость и гибкость: с Azure мы можем легко увеличивать или уменьшать ресурсы в зависимости от потребностей бизнеса. Azure также даёт гибкость в выборе операционной системы, языка программирования и фреймворков.

3. Безопасность и соответствие требованиям: Azure обеспечивает высокий уровень безопасности и соответствия требованиям, так как соответствует нескольким отраслевым стандартам, таким как ISO, SOC, HIPAA и PCI DSS. Azure также предоставляет расширенные функции безопасности, такие как группы безопасности сети, межсетевые экраны и защита от DDoS.

4. Гибридное облако: Azure обеспечивает бесшовную работу с гибридным облаком, позволяя организациям подключать свою локальную инфраструктуру к Azure. Это упрощает перенос рабочих нагрузок в облако и даёт гибкость в выборе места хранения данных.

5. Экономичность: Azure предлагает модель ценообразования с оплатой по факту использования, то есть мы платим только за используемые ресурсы. Это помогает нам экономить по сравнению с традиционной локальной инфраструктурой.

## Заключение

Принятие Microsoft Azure в качестве облачной инфраструктуры нашей организации соответствует нашим бизнес-требованиям и предлагает ряд преимуществ, таких как масштабируемость, гибкость, безопасность и экономичность. Поэтому рекомендуется принять Azure в качестве нашей облачной инфраструктуры.
