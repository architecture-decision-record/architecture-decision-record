# កំណត់ត្រាការសម្រេចចិត្តខាងស្ថាបត្យកម្ម៖ ការគ្រប់គ្រងកុងតឺន័រដោយ Kubernetes

## សេចក្តីថ្លែងបញ្ហា 

យើងត្រូវជ្រើសរើសវេទិកាគ្រប់គ្រងកុងតឺន័រសម្រាប់បណ្តុំកម្មវិធីដើមកំណើតពពករបស់យើងដែលកំពុងលូតលាស់។ ការដាក់ពង្រាយវេទិកាចាស់បច្ចុប្បន្នរបស់យើងយឺតពេក ហើយមិនបត់បែនគ្រប់គ្រាន់ដើម្បីតាមទាន់តម្រូវការដែលកំពុងកើនឡើងរបស់យើងទេ។ យើងកំពុងស្វែងរកប្រព័ន្ធដែលអនុញ្ញាតឱ្យយើងពង្រីកសេវាកម្មរបស់យើងតាមវិធីដែលមានប្រសិទ្ធភាពបំផុតតាមដែលអាចធ្វើបាន ដោយមិនធ្វើឱ្យប៉ះពាល់ដល់ភាពបត់បែន ឬភាពងាយប្រើ។

## ការសម្រេចចិត្តដែលបានធ្វើ

បន្ទាប់ពីធ្វើការវិភាគដ៏ហ្មត់ចត់លើវេទិកាគ្រប់គ្រងកុងតឺន័រនីមួយៗ យើងបានសម្រេចទទួលយក Kubernetes ជាជម្រើសល្អបំផុតសម្រាប់តម្រូវការសហគ្រាសរបស់យើង។ ហេតុផលរបស់យើងក្នុងការជ្រើសរើស Kubernetes មានដូចតទៅ៖

1. **ភាពអាចពង្រីកបាន៖**  ការរចនាប្លែករបស់ Kubernetes ល្អឥតខ្ចោះសម្រាប់ការពង្រីកកម្មវិធី ហើយនៅពេលតម្រូវការភាពអាចពង្រីកបានរបស់យើងវិវត្តតាមពេលវេលា Kubernetes មានសមត្ថភាពភ្ជាប់មកស្រាប់ដើម្បីបំពេញការផ្លាស់ប្តូរទាំងនេះដោយគ្មានបញ្ហា។

2. **ស្ថាបត្យកម្មវិមជ្ឈការ៖**  ភូមិសាស្ត្រមេ-កម្មករ (master-worker) របស់ Kubernetes ធានាស្ថាបត្យកម្មវិមជ្ឈការ ដែលធានាថាគ្មានចំណុចខ្សោយតែមួយ។

3. **ការគាំទ្រពីសហគមន៍៖**  Kubernetes មានសហគមន៍កូដចំហធំបំផុត និងសកម្មបំផុត ដែលមានន័យថាវាមានអ្នកចូលរួមចំណែក អ្នកអភិវឌ្ឍន៍ និងអ្នកលក់ជាច្រើន ដែលធ្វើឱ្យយើងងាយទទួលបានជំនួយ និងរកធនធាន។

4. **ការគាំទ្រពីប្រព័ន្ធអេកូឡូស៊ី៖**  Kubernetes មានប្រព័ន្ធអេកូឡូស៊ីដែលកំពុងលូតលាស់ ជាមួយឧបករណ៍ភាគីទីបីផ្សេងៗ ការរួមបញ្ចូលជាមួយ container registry បំពង់ CI/CD ការផ្ទុកទិន្នន័យ និងច្រើនទៀត។

ដូច្នេះ យើងបានសម្រេចទទួលយក Kubernetes ជាវេទិកាគ្រប់គ្រងកុងតឺន័ររបស់យើងសម្រាប់បច្ចុប្បន្ន និងអនាគតដ៏ខ្លីខាងមុខ។
