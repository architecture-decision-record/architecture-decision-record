## សង្ខេប


### បញ្ហា

យើងត្រូវផ្ទុកសម្ងាត់ ដូចជាពាក្យសម្ងាត់ កូនសោឯកជន ថូខឹនផ្ទៀងផ្ទាត់ភាពត្រឹមត្រូវ ។ល។

សម្ងាត់ខ្លះផ្តោតលើអ្នកប្រើ។ ឧទាហរណ៍ អ្នកអភិវឌ្ឍន៍របស់យើងចង់អាចប្រើទូរស័ព្ទចល័តរបស់ពួកគេដើម្បីរកពាក្យសម្ងាត់ទៅកាន់សេវាកម្មមួយ។

សម្ងាត់ខ្លះផ្តោតលើប្រព័ន្ធ។ ឧទាហរណ៍ បំពង់ផ្តល់ជូនជាបន្តបន្ទាប់របស់យើងត្រូវអាចរកព័ត៌មានសម្ងាត់ចូលប្រើសម្រាប់ការបង្ហោះពពករបស់យើង។


### ការសម្រេចចិត្ត

Bitwarden សម្រាប់សម្ងាត់ដែលផ្តោតលើអ្នកប្រើ

Vault ដោយ HashiCorp សម្រាប់សម្ងាត់ដែលផ្តោតលើប្រព័ន្ធ។


### ស្ថានភាព

បានសម្រេច។ យើងបើកចំហចំពោះជម្រើសជំនួសថ្មីៗនៅពេលដែលវាកើតមាន។


## ព័ត៌មានលម្អិត


### ការសន្មត់

សម្រាប់គោលបំណងនេះ និងស្ថានភាពបច្ចុប្បន្នរបស់យើង យើងឱ្យតម្លៃលើភាពងាយស្រួលដែលផ្តោតលើអ្នកប្រើ ដូចជាកម្មវិធីចល័តដែលអាចប្រើបាន។

  * យើងចង់ធានាការចូលប្រើលឿន និងងាយស្រួលពេលធ្វើដំណើរ ដូចជាសម្រាប់អ្នកអភិវឌ្ឍន៍ដែលកំពុងធ្វើវិស្វកម្មភាពអាចទុកចិត្តបាននៃប្រព័ន្ធពេលត្រូវទទួលបន្ទុក។

  * យើងចង់អាចចែករំលែកសម្ងាត់មួយចំនួនក្នុងចំណោមមនុស្សដែលបានជ្រើសរើស ដូចជាក្រុមមួយ។

យើងមិនព្យាយាមដោះស្រាយសម្រាប់អ្នកផ្តល់តែមួយទេ ដូចជាការផ្ទុកសម្ងាត់ទាំងអស់តែលើ Amazon ឬ Azure ឬ Google ប៉ុណ្ណោះ។

យើងមិនចង់បានវិធីសាស្ត្រតាមឱកាសដូចជា “ចងចាំវា” ឬ “សរសេរវាលើក្រដាសកំណត់ចំណាំ” ឬ “រកវិធីផ្ទុកវាដោយខ្លួនឯង” ទេ។

ម៉ូដែលសុវត្ថិភាពរបស់យើងសម្រាប់គោលបំណងនេះ មិនមានបញ្ហាជាមួយការប្រើអ្នកលក់ COTS ដែលមានកេរ្តិ៍ឈ្មោះល្អ ដូចជាឧបករណ៍គ្រប់គ្រងពាក្យសម្ងាត់ SaaS។


### ឧបសគ្គ

ឥឡូវនេះយើងចង់បានអ្វីមួយដែលងាយស្រួល ពោលគឺមិនចាំបាច់សរសេរកូដ មិនចាំបាច់ដំឡើងម៉ាស៊ីនមេ មិនចាំបាច់ប្តេជ្ញាធំ មិនចាំបាច់ធ្វើស្តង់ដារឱ្យមនុស្សគ្រប់គ្នា។


### ជំហរ

យើងបានពិចារណា៖

1. ឧបករណ៍គ្រប់គ្រងពាក្យសម្ងាត់ដែលមានស្រាប់ដែលផ្តោតលើអ្នកប្រើ៖ LastPass, 1Password, Bitwarden, Dashlane, KeePass, pass, GPG ។ល។

2. ឧបករណ៍គ្រប់គ្រងពាក្យសម្ងាត់ COTS ដែលផ្តោតលើប្រព័ន្ធ៖ AWS KMS, Vault ដោយ HashiCorp, EnvKy, Secret Server ដោយ Thycotic, Devolutions Password Server, Confidant ដោយ Lyft។

3. វិធីសាស្ត្រដែលផ្តោតលើការចែករំលែក៖ ការប្រើឯកសារ Google ដែលចែករំលែក ឬឆានែល Slack ដែលចែករំលែក ឬថតបណ្តាញដែលចែករំលែក ។ល។

4. វិធីសាស្ត្រតាមឱកាសបច្ចេកវិទ្យាទាប ដូចជាការចងចាំ ការសរសេរកំណត់ចំណាំ ឬការពឹងផ្អែកលើអ្នកប្រើម្នាក់ៗឱ្យរកវិធីផ្ទាល់ខ្លួន។


### អាគុយម៉ង់

Bitwarden, LastPass, 1Password និង Dashlane សុទ្ធតែជាផលិតផលពាណិជ្ជកម្មដែលមានស្រាប់។

  * មុខងារប្រភេទស្រដៀងគ្នាសម្រាប់អ្នកប្រើ ក្រុម អង្គការ ។ល។

  * សមត្ថភាពកុំព្យូទ័រតុសម្រាប់ Windows និង Mac និងសមត្ថភាពទូរស័ព្ទចល័តសម្រាប់ Android និង iOS។

  * កម្មវិធីបន្ថែមកម្មវិធីរុករកសម្រាប់ Chrome និង Firefox សម្រាប់បំពេញទម្រង់បែបបទដោយស្វ័យប្រវត្តិ ។ល។

Bitwarden មានអត្ថប្រយោជន៍ពីរលើអ្នកដទៃ៖

  * Bitwarden ជាកូដចំហ ដែលមានន័យថាសុវត្ថិភាពអាចត្រូវបានពិនិត្យដោយមិត្តរួមការងារ ហើយក្រុមហ៊ុនក៏ត្រូវបានអ្នកអភិវឌ្ឍន៍ដែលផ្តោតលើសុវត្ថិភាពកោតសរសើរយ៉ាងទូលំទូលាយ។

  * រឿងរ៉ាវពីអ្នកធ្វើការកម្មវិធីរៀបរាប់ពីចំណូលចិត្តយ៉ាងខ្លាំងចំពោះ Bitwarden ជាងអ្នកដទៃ។

ឧទាហរណ៍អត្ថបទសរសេរល្អធម្មតា៖ https://jcs.org/2017/11/17/bitwarden

គេហទំព័របោះឆ្នោតប្រៀបធៀបគ្នាធម្មតា៖ https://stackshare.io/stackups/bitwarden-vs-dashlane

យើងពន្យារ KeyPass, pass, GPG ។ល។ ព្រោះមានភាពស្មុគស្មាញបន្ថែម។ ទាំងអស់នេះមើលទៅដូចជាដំណោះស្រាយល្អសម្រាប់អ្នកប្រើបច្ចេកទេស។ GPG មើលទៅល្អជាពិសេសសម្រាប់អ្នកប្រើបច្ចេកទេសដែលចង់បានសមត្ថភាពផ្អែកលើពាក្យបញ្ជាឆ្លងប្រព័ន្ធ។

យើងពន្យារ KMS ព្រោះវាមានការជាប់ចំណងនឹងអ្នកផ្តល់តែមួយ។

យើងជ្រើស Vault សម្រាប់តម្រូវការផ្តោតលើប្រព័ន្ធ ព្រោះការពិនិត្យឡើងវិញវិជ្ជមានគួរឱ្យអស្ចារ្យ ហើយព្រោះ HashiCorp មានកំណត់ត្រាដ៏ល្អឥតខ្ចោះសម្រាប់កម្មវិធី និងការគាំទ្រគុណភាពកំពូល។

យើងបដិសេធវិធីសាស្ត្រចែករំលែក ដូចជាតាមរយៈឯកសារដែលចែករំលែក ឆានែលដែលចែករំលែក ថតបណ្តាញដែលចែករំលែក ។ល។ ទាំងនេះមិនផ្តល់គុណភាពសុវត្ថិភាពដែលយើងចង់បានទេ។

យើងបដិសេធវិធីសាស្ត្រតាមឱកាសបច្ចេកវិទ្យាទាប ព្រោះយើងទាំងអស់គ្នាយល់ស្របថាវាមិនមែនជាផ្លូវទៅមុខរយៈពេលវែងទេ។


### ផលវិបាក

អ្នកអភិវឌ្ឍន៍អាចត្រូវតាមដានសម្ងាត់នៅកន្លែងពីរ៖ Bitwarden សម្រាប់ការចូលប្រើដែលផ្តោតលើអ្នកប្រើ និង Vault សម្រាប់ការចូលប្រើដែលផ្តោតលើប្រព័ន្ធ។


## ពាក់ព័ន្ធ


### ការសម្រេចចិត្តពាក់ព័ន្ធ

ការសម្រេចចិត្តថាម៉ាស៊ីនមេ CI/CD មួយណា ត្រូវតែរួមបញ្ចូលភស្តុតាងនៃសមត្ថភាពក្នុងការចូលប្រើសម្ងាត់។

យើងនឹងត្រូវសម្រេចរបៀបគ្រប់គ្រងសម្ងាត់ ទាក់ទងនឹងគោលនយោបាយ ការបង្វិល អង្គការ ។ល។


### តម្រូវការពាក់ព័ន្ធ

សម្ងាត់នឹងមានតម្រូវការពាក់ព័ន្ធសម្រាប់ការអនុលោម សវនកម្ម និងការទទួលបុគ្គលិកចូល/ចេញរបស់ធនធានមនុស្ស។


### វត្ថុពាក់ព័ន្ធ

យើងរំពឹងថាយើងអាចនាំចេញសម្ងាត់មួយចំនួនទៅអថេរបរិស្ថាន។
