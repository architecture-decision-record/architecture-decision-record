# ਆਰਕੀਟੈਕਚਰ ਫੈਸਲਾ ਰਿਕਾਰਡ: Svelte ਫਰੰਟ-ਐਂਡ JavaScript ਲਾਇਬ੍ਰੇਰੀ

ਸਥਿਤੀ: ਸਵੀਕਾਰ

## ਪ੍ਰਸੰਗ

ਅਸੀਂ ਆਧੁਨਿਕ ਫਰੰਟ-ਐਂਡ JavaScript ਫਰੇਮਵਰਕ ਵਰਤ ਕੇ ਇੱਕ ਵੈੱਬ ਐਪਲੀਕੇਸ਼ਨ ਵਿਕਸਿਤ ਕਰ ਰਹੇ ਹਾਂ। ਅਸੀਂ ਅਜਿਹੀ ਲਾਇਬ੍ਰੇਰੀ ਚੁਣਨਾ ਚਾਹੁੰਦੇ ਹਾਂ ਜੋ ਹਲਕੀ, ਤੇਜ਼ ਅਤੇ ਵਰਤਣ ਵਿੱਚ ਆਸਾਨ ਹੋਵੇ। ਅਸੀਂ React, Vue ਅਤੇ Angular ਸਮੇਤ ਕਈ ਲਾਇਬ੍ਰੇਰੀਆਂ ਦਾ ਮੁਲਾਂਕਣ ਕੀਤਾ ਹੈ। ਅਸੀਂ Svelte ਬਾਰੇ ਵੀ ਸੁਣਿਆ ਹੈ, ਜੋ ਦਾਅਵਾ ਕਰਦੀ ਹੈ ਕਿ ਇਹ ਨਵੀਂ ਕਿਸਮ ਦਾ ਹਲਕਾ ਫਰੇਮਵਰਕ ਹੈ। ਸਾਨੂੰ Svelte ਦਾ ਮੁਲਾਂਕਣ ਕਰਨ ਅਤੇ ਇਹ ਤੈਅ ਕਰਨ ਦੀ ਲੋੜ ਹੈ ਕਿ ਕੀ ਇਹ ਸਾਡੀ ਐਪਲੀਕੇਸ਼ਨ ਲਈ ਢੁਕਵੀਂ ਹੈ।

## ਫੈਸਲਾ

ਹਰ ਲਾਇਬ੍ਰੇਰੀ ਦੇ ਫਾਇਦਿਆਂ ਅਤੇ ਨੁਕਸਾਨਾਂ ਉੱਤੇ ਵਿਚਾਰ ਕਰਨ ਤੋਂ ਬਾਅਦ, ਅਸੀਂ ਹੇਠ ਲਿਖੇ ਕਾਰਨਾਂ ਕਰਕੇ ਆਪਣੀ ਫਰੰਟ-ਐਂਡ JavaScript ਲਾਇਬ੍ਰੇਰੀ ਵਜੋਂ Svelte ਵਰਤਣ ਦਾ ਫੈਸਲਾ ਕੀਤਾ ਹੈ:

1. **ਹਲਕੀ:**  Svelte ਉਪਲਬਧ ਸਭ ਤੋਂ ਹਲਕੀਆਂ ਲਾਇਬ੍ਰੇਰੀਆਂ ਵਿੱਚੋਂ ਇੱਕ ਹੈ, ਜੋ ਸਾਨੂੰ ਆਪਣੀ ਐਪਲੀਕੇਸ਼ਨ ਦਾ ਆਕਾਰ ਛੋਟਾ ਰੱਖਣ ਅਤੇ ਪੰਨਾ ਲੋਡ ਹੋਣ ਦੇ ਸਮੇਂ ਨੂੰ ਸੁਧਾਰਨ ਵਿੱਚ ਮਦਦ ਕਰੇਗੀ।

2. **ਤੇਜ਼:**  Svelte ਆਪਣੀ ਤੇਜ਼ ਰੈਂਡਰਿੰਗ ਗਤੀ ਲਈ ਜਾਣੀ ਜਾਂਦੀ ਹੈ, ਜੋ ਸਾਡੀ ਐਪਲੀਕੇਸ਼ਨ ਨੂੰ ਜਵਾਬਦੇਹ ਅਤੇ ਫੁਰਤੀਲੀ ਮਹਿਸੂਸ ਕਰਵਾਏਗੀ।

3. **ਵਰਤਣ ਵਿੱਚ ਆਸਾਨ:**  Svelte ਦਾ ਸਿੰਟੈਕਸ ਸਾਦਾ ਅਤੇ ਸਮਝਣ ਵਿੱਚ ਆਸਾਨ ਹੈ, ਜਿਸ ਨਾਲ ਸਾਡੀ ਟੀਮ ਲਈ ਇਸ ਨੂੰ ਅਪਣਾਉਣਾ ਅਤੇ ਸਾਫ਼-ਸੁਥਰਾ ਕੋਡ ਲਿਖਣਾ ਆਸਾਨ ਹੋ ਜਾਵੇਗਾ।

4. **UI ਰੈਂਡਰਿੰਗ ਲਈ ਅਨੁਕੂਲਿਤ:**  Svelte UI ਕੰਪੋਨੈਂਟਾਂ ਨੂੰ ਰੈਂਡਰ ਕਰਨ ਲਈ ਅਨੁਕੂਲਿਤ ਹੈ, ਜਿਸ ਨਾਲ ਸਾਡੇ ਲਈ ਗਤੀਸ਼ੀਲ ਅਤੇ ਮੁੜ-ਵਰਤੋਂ ਯੋਗ UI ਤੱਤ ਬਣਾਉਣਾ ਆਸਾਨ ਹੋ ਜਾਵੇਗਾ।

5. **ਚੰਗੇ ਦਸਤਾਵੇਜ਼ ਅਤੇ ਭਾਈਚਾਰਕ ਸਹਾਇਤਾ:**  Svelte ਦਾ ਵਧ ਰਿਹਾ ਭਾਈਚਾਰਾ ਅਤੇ ਚੰਗੇ ਦਸਤਾਵੇਜ਼ ਹਨ, ਜੋ ਸਾਨੂੰ ਜਲਦੀ ਸ਼ੁਰੂ ਕਰਨ ਅਤੇ ਉੱਠਣ ਵਾਲੇ ਕਿਸੇ ਵੀ ਮਸਲੇ ਨੂੰ ਹੱਲ ਕਰਨ ਵਿੱਚ ਮਦਦ ਕਰਨਗੇ।

## ਬਦਲ

ਅਸੀਂ React, Vue ਅਤੇ Angular ਬਾਰੇ ਵਿਚਾਰ ਕੀਤਾ, ਪਰ ਹੇਠ ਲਿਖੇ ਕਾਰਨਾਂ ਕਰਕੇ ਉਨ੍ਹਾਂ ਦੇ ਵਿਰੁੱਧ ਫੈਸਲਾ ਕੀਤਾ:

1. **React:**  ਭਾਵੇਂ React ਦਾ ਵੱਡਾ ਵਰਤੋਂਕਾਰ ਆਧਾਰ ਅਤੇ ਲਾਇਬ੍ਰੇਰੀਆਂ ਤੇ ਸਰੋਤਾਂ ਦਾ ਭੰਡਾਰ ਹੈ, ਇਹ ਗੁੰਝਲਦਾਰ ਅਤੇ ਸਿੱਖਣ ਵਿੱਚ ਔਖਾ ਹੋ ਸਕਦਾ ਹੈ, ਖਾਸ ਕਰਕੇ ਸ਼ੁਰੂਆਤ ਕਰਨ ਵਾਲਿਆਂ ਲਈ।

2. **Vue:**  Vue ਇੱਕ ਹਲਕੀ ਲਾਇਬ੍ਰੇਰੀ ਹੈ ਜੋ ਸਿੱਖਣ ਅਤੇ ਵਰਤਣ ਵਿੱਚ ਆਸਾਨ ਹੈ, ਪਰ ਇਹ ਸ਼ਾਇਦ Svelte ਜਿੰਨੀ ਤੇਜ਼ ਜਾਂ ਅਨੁਕੂਲਿਤ ਨਾ ਹੋਵੇ।

3. **Angular:**  Angular ਇੱਕ ਵਿਆਪਕ ਫਰੇਮਵਰਕ ਹੈ ਜੋ ਕਈ ਵਿਸ਼ੇਸ਼ਤਾਵਾਂ ਅਤੇ ਟੂਲ ਦਿੰਦਾ ਹੈ, ਪਰ ਇਹ ਭਾਰੀ ਅਤੇ ਗੁੰਝਲਦਾਰ ਹੋ ਸਕਦਾ ਹੈ, ਅਤੇ Svelte ਨਾਲੋਂ ਵੱਧ ਸਾਂਭ-ਸੰਭਾਲ ਦੀ ਲੋੜ ਪੈ ਸਕਦੀ ਹੈ।

## ਨਤੀਜੇ

ਆਪਣੀ ਫਰੰਟ-ਐਂਡ JavaScript ਲਾਇਬ੍ਰੇਰੀ ਵਜੋਂ Svelte ਵਰਤਣ ਦੇ ਹੇਠ ਲਿਖੇ ਨਤੀਜੇ ਹੋਣਗੇ:

1. ਸਾਡੀ ਐਪਲੀਕੇਸ਼ਨ ਹਲਕੀ ਅਤੇ ਤੇਜ਼ ਹੋਵੇਗੀ, ਜੋ ਵਰਤੋਂਕਾਰ ਤਜਰਬੇ ਅਤੇ ਜੁੜਾਅ ਨੂੰ ਸੁਧਾਰੇਗੀ।

2. ਸਾਡੀ ਟੀਮ ਨੂੰ ਨਵੀਂ ਲਾਇਬ੍ਰੇਰੀ ਸਿੱਖਣੀ ਪਵੇਗੀ, ਪਰ Svelte ਦਾ ਸਿੰਟੈਕਸ ਸਾਦਾ ਅਤੇ ਸਮਝਣ ਵਿੱਚ ਆਸਾਨ ਹੈ, ਇਸ ਲਈ ਸਿੱਖਣ ਦਾ ਵਕਰ ਸੰਭਾਲਣਯੋਗ ਹੋਣਾ ਚਾਹੀਦਾ ਹੈ।

3. Svelte ਅਜੇ ਵੀ ਮੁਕਾਬਲਤਨ ਨਵੀਂ ਲਾਇਬ੍ਰੇਰੀ ਹੈ, ਇਸ ਲਈ ਸਾਨੂੰ ਕੁਝ ਅਜਿਹੇ ਮਸਲੇ ਮਿਲ ਸਕਦੇ ਹਨ ਜੋ ਭਾਈਚਾਰੇ ਵੱਲੋਂ ਚੰਗੀ ਤਰ੍ਹਾਂ ਦਸਤਾਵੇਜ਼ੀ ਰੂਪ ਵਿੱਚ ਜਾਂ ਸਮਰਥਿਤ ਨਾ ਹੋਣ।

4. Svelte ਵਰਤੋਂਕਾਰਾਂ ਦਾ ਭਾਈਚਾਰਾ ਵਧ ਰਿਹਾ ਹੈ, ਇਸ ਲਈ ਅਸੀਂ ਭਵਿੱਖ ਵਿੱਚ ਹੋਰ ਤੀਜੀ ਧਿਰ ਦੀਆਂ ਲਾਇਬ੍ਰੇਰੀਆਂ ਅਤੇ ਸਰੋਤ ਉਪਲਬਧ ਹੁੰਦੇ ਵੇਖ ਸਕਦੇ ਹਾਂ ਜੋ ਮੁੱਖ ਲਾਇਬ੍ਰੇਰੀ ਦੇ ਪੂਰਕ ਵਜੋਂ ਵਰਤੇ ਜਾ ਸਕਦੇ ਹਨ।

## ਸਿੱਟਾ

ਸਾਡੇ ਮੁਲਾਂਕਣ ਦੇ ਆਧਾਰ ਉੱਤੇ, ਅਸੀਂ ਆਪਣੀ ਵੈੱਬ ਐਪਲੀਕੇਸ਼ਨ ਲਈ ਫਰੰਟ-ਐਂਡ JavaScript ਲਾਇਬ੍ਰੇਰੀ ਵਜੋਂ Svelte ਵਰਤਣ ਦਾ ਫੈਸਲਾ ਕੀਤਾ ਹੈ। ਸਾਡਾ ਮੰਨਣਾ ਹੈ ਕਿ Svelte ਦਾ ਹਲਕਾ ਅਤੇ ਤੇਜ਼ ਸੁਭਾਅ, ਵਰਤੋਂ ਦੀ ਸੌਖ ਅਤੇ ਅਨੁਕੂਲਿਤ UI ਰੈਂਡਰਿੰਗ ਇਸ ਨੂੰ ਸਾਡੀਆਂ ਲੋੜਾਂ ਲਈ ਸਭ ਤੋਂ ਵਧੀਆ ਚੋਣ ਬਣਾਉਂਦੇ ਹਨ। ਅਸੀਂ Svelte ਅਤੇ ਇਸ ਦੇ ਭਾਈਚਾਰੇ ਦੇ ਵਿਕਾਸ ਦੀ ਨਿਗਰਾਨੀ ਕਰਦੇ ਰਹਾਂਗੇ ਅਤੇ ਲੋੜ ਪੈਣ ਉੱਤੇ ਆਪਣੀ ਚੋਣ ਵਿੱਚ ਸੋਧਾਂ ਕਰਾਂਗੇ।
