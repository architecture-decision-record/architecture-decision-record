# ਆਰਕੀਟੈਕਚਰ ਫੈਸਲਾ ਰਿਕਾਰਡ: REST API ਲਈ snake_case ਬਨਾਮ camelCase?

ਫੈਸਲਾ: REST API ਐਂਡਪੁਆਇੰਟਾਂ ਲਈ snake_case ਨਾਮਕਰਨ ਪਰੰਪਰਾ ਵਰਤੀ ਜਾਵੇਗੀ

ਸਥਿਤੀ: ਸਵੀਕਾਰ

## ਪ੍ਰਸੰਗ

REST API ਲਈ ਨਾਮਕਰਨ ਪਰੰਪਰਾਵਾਂ ਵਿੱਚ ਦੋ ਪ੍ਰਸਿੱਧ ਫਾਰਮੈਟ ਹਨ: snake_case ਅਤੇ camelCase। snake_case ਫਾਰਮੈਟ ਵਿੱਚ ਨਾਮ ਦੇ ਹਰ ਸ਼ਬਦ ਨੂੰ ਅੰਡਰਸਕੋਰ ਨਾਲ ਵੱਖ ਕੀਤਾ ਜਾਂਦਾ ਹੈ, ਜਦਕਿ camelCase ਵਿੱਚ ਨਾਮ ਦਾ ਪਹਿਲਾ ਸ਼ਬਦ ਛੋਟੇ ਅੱਖਰਾਂ ਵਿੱਚ ਹੁੰਦਾ ਹੈ, ਅਤੇ ਅਗਲੇ ਸ਼ਬਦਾਂ ਦਾ ਪਹਿਲਾ ਅੱਖਰ ਵੱਡਾ ਹੁੰਦਾ ਹੈ। ਇਹ ਫੈਸਲਾ ਤੈਅ ਕਰੇਗਾ ਕਿ REST API ਲਈ ਕਿਹੜੀ ਨਾਮਕਰਨ ਪਰੰਪਰਾ ਵਰਤੀ ਜਾਣੀ ਚਾਹੀਦੀ ਹੈ।

## ਫੈਸਲੇ ਦੇ ਚਾਲਕ

- ਪ੍ਰੋਜੈਕਟ ਵਿੱਚ ਮੌਜੂਦਾ ਨਾਮਕਰਨ ਪਰੰਪਰਾਵਾਂ ਨਾਲ ਇਕਸਾਰਤਾ

- API ਉੱਤੇ ਕੰਮ ਕਰ ਸਕਣ ਵਾਲੇ ਕਿਸੇ ਵੀ ਵਿਅਕਤੀ ਲਈ ਪੜ੍ਹਨਯੋਗਤਾ ਅਤੇ ਸਪੱਸ਼ਟਤਾ

- REST API ਨਾਮਕਰਨ ਪਰੰਪਰਾਵਾਂ ਲਈ ਉਦਯੋਗ ਦੇ ਸਭ ਤੋਂ ਵਧੀਆ ਅਭਿਆਸਾਂ ਨਾਲ ਮੇਲ

- ਲਾਗੂ ਕਰਨ ਅਤੇ ਸਾਂਭ-ਸੰਭਾਲ ਦੀ ਸੌਖ

## ਫੈਸਲਾ

REST API ਐਂਡਪੁਆਇੰਟਾਂ ਲਈ snake_case ਨਾਮਕਰਨ ਪਰੰਪਰਾ ਵਰਤੀ ਜਾਵੇਗੀ। ਇਹ ਚੋਣ ਹੇਠ ਲਿਖੇ ਕਾਰਕਾਂ ਵੱਲੋਂ ਚਲਾਈ ਗਈ ਹੈ:

1. **ਇਕਸਾਰਤਾ**: ਪ੍ਰੋਜੈਕਟ ਪਹਿਲਾਂ ਹੀ ਸਾਰੇ ਐਂਡਪੁਆਇੰਟਾਂ ਲਈ snake_case ਨਾਮਕਰਨ ਪਰੰਪਰਾ ਵਰਤਦਾ ਹੈ, ਅਤੇ ਪੂਰੇ ਪ੍ਰੋਜੈਕਟ ਵਿੱਚ ਇਕਸਾਰਤਾ ਯਕੀਨੀ ਬਣਾਉਣ ਲਈ ਇਸ ਪਰੰਪਰਾ ਨੂੰ ਕਾਇਮ ਰੱਖਣਾ ਲਾਭਦਾਇਕ ਹੋਵੇਗਾ।

2. **ਪੜ੍ਹਨਯੋਗਤਾ ਅਤੇ ਸਪੱਸ਼ਟਤਾ**: snake_case ਪਰੰਪਰਾ ਵਧੇਰੇ ਪੜ੍ਹਨਯੋਗ ਅਤੇ ਸਮਝਣ ਵਿੱਚ ਆਸਾਨ ਹੈ। ਅੰਡਰਸਕੋਰ ਸ਼ਬਦਾਂ ਵਿਚਕਾਰ ਸਪੱਸ਼ਟ ਵਿਭਾਜਨ ਦਿੰਦੇ ਹਨ, ਜਿਸ ਨਾਲ ਨਾਮ ਦੇ ਅਰਥ ਨੂੰ ਪਾੜਨਾ ਅਤੇ ਸਮਝਣਾ ਆਸਾਨ ਹੋ ਜਾਂਦਾ ਹੈ।

3. **ਉਦਯੋਗ ਦੇ ਸਭ ਤੋਂ ਵਧੀਆ ਅਭਿਆਸਾਂ ਨਾਲ ਮੇਲ**: snake_case ਪਰੰਪਰਾ ਉਦਯੋਗ ਵਿੱਚ ਵਿਆਪਕ ਤੌਰ ਉੱਤੇ ਵਰਤੀ ਜਾਂਦੀ ਹੈ ਅਤੇ REST API ਲਈ ਸਭ ਤੋਂ ਵਧੀਆ ਅਭਿਆਸ ਮੰਨੀ ਜਾਂਦੀ ਹੈ, ਜੋ ਇਸ ਨੂੰ ਪ੍ਰੋਜੈਕਟ ਲਈ ਚੰਗੀ ਚੋਣ ਬਣਾਉਂਦੀ ਹੈ।

4. **ਲਾਗੂ ਕਰਨ ਅਤੇ ਸਾਂਭ-ਸੰਭਾਲ ਦੀ ਸੌਖ**: ਮੌਜੂਦਾ ਨਾਮਕਰਨ ਪਰੰਪਰਾ ਨਾਲ ਜੁੜੇ ਰਹਿਣਾ ਲਾਗੂ ਕਰਨਾ ਅਤੇ ਸੰਭਾਲਣਾ ਸੌਖਾ ਹੈ, ਕਿਉਂਕਿ ਜੇ ਨਵੀਂ ਪਰੰਪਰਾ ਚੁਣੀ ਜਾਂਦੀ ਤਾਂ ਸਾਰੇ ਮੌਜੂਦਾ ਕੋਡ ਅਤੇ ਦਸਤਾਵੇਜ਼ ਅੱਪਡੇਟ ਕਰਨੇ ਪੈਂਦੇ।

## ਨਤੀਜੇ

ਇਸ ਫੈਸਲੇ ਦੇ ਸੰਭਾਵੀ ਨਤੀਜੇ ਹਨ। 

* ਜੇ ਪ੍ਰੋਜੈਕਟ ਵਿੱਚ ਸ਼ਾਮਲ ਹੋਣ ਵਾਲੇ ਕੋਈ ਨਵੇਂ ਟੀਮ ਮੈਂਬਰ snake_case ਨਾਮਕਰਨ ਪਰੰਪਰਾ ਤੋਂ ਅਣਜਾਣ ਹਨ, ਤਾਂ ਇਹ ਵਿਕਾਸ ਵਿੱਚ ਭੁਲੇਖੇ ਅਤੇ ਗਲਤੀਆਂ ਦਾ ਕਾਰਨ ਬਣ ਸਕਦਾ ਹੈ। ਫਿਰ ਵੀ, ਕਿਉਂਕਿ snake_case ਵਿਆਪਕ ਤੌਰ ਉੱਤੇ ਵਰਤੀ ਜਾਣ ਵਾਲੀ ਪਰੰਪਰਾ ਹੈ, ਅਜਿਹਾ ਜੋਖਮ ਘੱਟੋ-ਘੱਟ ਹੈ। 
  
* ਜੇ ਪ੍ਰੋਜੈਕਟ ਵਿੱਚ ਹੋਰ ਟੂਲ ਜਾਂ ਫਰੇਮਵਰਕ ਵਰਤੇ ਜਾਂਦੇ ਹਨ ਜੋ camelCase ਪਰੰਪਰਾ ਉੱਤੇ ਬਹੁਤ ਆਧਾਰਿਤ ਹਨ, ਤਾਂ ਨਾਮਕਰਨ ਪਰੰਪਰਾਵਾਂ ਵਿਚਕਾਰ ਤਬਦੀਲੀ ਕਰਨ ਲਈ ਵਾਧੂ ਮਿਹਨਤ ਦੀ ਲੋੜ ਪੈ ਸਕਦੀ ਹੈ। ਫਿਰ ਵੀ, ਇਹ ਕੋਈ ਵੱਡੀ ਚਿੰਤਾ ਨਹੀਂ ਹੈ ਕਿਉਂਕਿ ਪ੍ਰੋਜੈਕਟ ਨੇ snake_case ਪਰੰਪਰਾ ਨੂੰ ਮਿਆਰੀ ਬਣਾ ਲਿਆ ਹੈ। 
 
ਕੁੱਲ ਮਿਲਾ ਕੇ, REST API ਐਂਡਪੁਆਇੰਟਾਂ ਲਈ snake_case ਨਾਮਕਰਨ ਪਰੰਪਰਾ ਵਰਤਣ ਦਾ ਫੈਸਲਾ ਇਕਸਾਰ, ਪੜ੍ਹਨਯੋਗ ਅਤੇ ਉਦਯੋਗ-ਮਿਆਰੀ ਪਹੁੰਚ ਦਿੰਦਾ ਹੈ, ਜਦਕਿ ਇਸ ਨੂੰ ਲਾਗੂ ਕਰਨਾ ਅਤੇ ਸੰਭਾਲਣਾ ਸੌਖਾ ਹੈ।
