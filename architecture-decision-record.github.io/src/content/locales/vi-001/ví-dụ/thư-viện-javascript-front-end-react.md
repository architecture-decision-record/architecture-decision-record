# Bản ghi quyết định kiến trúc: Thư viện JavaScript Front-End React

## Bối cảnh

Chúng tôi cần chọn một thư viện JavaScript front-end cho ứng dụng của mình để phát triển giao diện người dùng đáp ứng và tương tác.
  
## Các lựa chọn đã cân nhắc

1. React
  
2. Vue

3. Svelte
   
## Quyết định

Chúng tôi sẽ dùng React làm thư viện JavaScript front-end của mình.
  
## Cơ sở lý luận

1. **Kiến trúc dựa trên thành phần:**  React cung cấp một kiến trúc dựa trên thành phần cho phép chúng tôi chia UI thành các thành phần nhỏ có thể tái sử dụng. Điều này giúp cải thiện tính mô-đun của mã và giúp dễ bảo trì, mở rộng và cập nhật ứng dụng hơn.
  
2. **Lập trình khai báo:**  React dùng phong cách lập trình khai báo giúp mã của chúng tôi trực quan hơn và dễ đọc hơn. Nó cũng cung cấp DOM ảo, cho phép mã của chúng tôi chạy nhanh hơn và hiệu quả hơn.
  
3. **Cộng đồng lớn:**  React có cộng đồng lớn và năng động, và là một trong những thư viện front-end phổ biến nhất. Điều này có nghĩa là có rất nhiều tài nguyên, công cụ và thư viện có thể giúp chúng tôi phát triển ứng dụng nhanh hơn và hiệu quả hơn.
  
4. **Hiệu năng tốt hơn:**  React dùng luồng dữ liệu một chiều, giúp đơn giản hóa logic ứng dụng và làm nó hiệu quả hơn. Nó cũng cung cấp kết xuất phía máy chủ, giúp cải thiện hiệu năng và SEO của ứng dụng.
  
5. **Tính linh hoạt:**  React có thể dùng với các thư viện và framework khác, mang lại cho chúng tôi sự tự do chọn ngăn xếp công nghệ tốt nhất phù hợp với yêu cầu của dự án.
  
## Hệ quả

1. **Đường cong học tập:**  React có đường cong học tập, và các nhà phát triển mới với React có thể mất một thời gian để bắt kịp.
  
2. **Công cụ build:**  React yêu cầu các công cụ build bổ sung như Babel và Webpack, có thể làm tăng độ phức tạp của quy trình phát triển.
  
3. **Tương thích trình duyệt:**  React có các vấn đề tương thích với trình duyệt cũ vì nó dùng các tính năng ES6 không được hỗ trợ trong trình duyệt cũ.
  
 4. Đường cong học tập dốc: Các nhà phát triển không quen với React có thể mất thời gian để học cách dùng nó hiệu quả, điều này có thể dẫn đến thời gian phát triển chậm hơn.
