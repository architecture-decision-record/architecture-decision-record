# Bản ghi quyết định kiến trúc: Tailwind CSS

Quyết định: Dùng Tailwind CSS làm framework CSS để tạo kiểu cho giao diện người dùng.

## Tailwind CSS là gì?

Tailwind là một framework CSS ưu tiên tiện ích (utility-first) cho phép phát triển và tùy chỉnh giao diện người dùng nhanh chóng. Nó được thiết kế để có thể tùy chỉnh cao và cho phép các nhà phát triển viết CSS gọn hơn và hiệu quả hơn. Framework này cung cấp một bộ các lớp được định nghĩa sẵn để tạo kiểu UI rất nhanh.

## Bối cảnh

Chúng tôi đang xây dựng một ứng dụng web cho một khách hàng đòi hỏi giao diện người dùng đáp ứng và có thể tùy chỉnh. Khách hàng đã yêu cầu kiểu dáng nhất quán và hiện đại. Nhóm phát triển có kinh nghiệm dùng CSS tùy chỉnh nhưng muốn khám phá các framework CSS có thể tiết kiệm thời gian và công sức. Chúng tôi đang tìm một framework dễ dùng, có thể tùy chỉnh và có cộng đồng lớn để hỗ trợ.

## Các yếu tố thúc đẩy quyết định

- **Dễ dùng:**  Chúng tôi muốn một framework đơn giản để học và có thể tích hợp vào quy trình phát triển của chúng tôi.

- **Có thể tùy chỉnh:**  Chúng tôi muốn một framework có thể tùy chỉnh để khớp với hướng dẫn thương hiệu và chủ đề của khách hàng.

- **Hỗ trợ cộng đồng lớn:**  Chúng tôi muốn một framework có cộng đồng nhà phát triển và nhà thiết kế năng động có thể cung cấp trợ giúp và tài nguyên khi cần.

- **Tiết kiệm thời gian:**  Chúng tôi muốn một framework có thể tiết kiệm thời gian và công sức khi tạo kiểu UI.

## Các lựa chọn đã cân nhắc

- **Bootstrap:**  Một framework CSS phổ biến với nhiều thành phần dựng sẵn và cộng đồng nhà phát triển lớn.

- **Foundation:**  Một framework CSS phổ biến khác được thiết kế cho phát triển ưu tiên di động.

- **Materialize:**  Một framework CSS dựa trên ngôn ngữ Material Design của Google với các thành phần dựng sẵn cho phát triển UI.

- **Tailwind CSS:**  Một framework CSS ưu tiên tiện ích tập trung vào tùy chỉnh và hiệu quả.

## Kết quả quyết định

Sau khi cân nhắc các lựa chọn, chúng tôi đã quyết định dùng Tailwind CSS vì các lý do sau:

- **Dễ dùng:**  Cách tiếp cận của Tailwind đơn giản và dễ hiểu. Các lớp tiện ích của nó giúp xây dựng UI nhanh hơn.

- **Có thể tùy chỉnh:**  Tailwind cho phép tùy chỉnh bằng cách cung cấp một bộ tệp cấu hình cho phép các nhà phát triển dễ dàng sửa đổi các kiểu mặc định của framework.

- **Hỗ trợ cộng đồng lớn:**  Tailwind có một cộng đồng nhà phát triển và nhà thiết kế rất năng động liên tục tạo ra các tài nguyên, plugin và công cụ mới.

- **Tiết kiệm thời gian:**  Tailwind có thể tiết kiệm thời gian, cho phép các nhà phát triển tập trung vào các lĩnh vực khác của dự án.
