# Rekord ta' deċiżjoni arkitettonika: infrastruttura tal-cloud Microsoft Azure" 

Titlu tad-Deċiżjoni: L-adozzjoni ta' Microsoft Azure bħala l-infrastruttura tal-cloud għall-organizzazzjoni tagħna

Min Ħa d-Deċiżjoni: Chief Information Officer

Data: 2021-10-15

Stat: Approvat

## Sfond

L-organizzazzjoni qed tippjana li timigra mill-infrastruttura tradizzjonali on-premises għal infrastruttura tal-cloud. Biex tilħaq dan, l-organizzazzjoni evalwat fornituri multipli ta' servizzi tal-cloud bħal Amazon Web Services (AWS), Google Cloud Platform (GCP), Microsoft Azure, u IBM Cloud. Kull fornitur għandu s-sett tiegħu ta' karatteristiċi, benefiċċji, u struttura tal-prezzijiet. Wara analiżi dettaljata, ġie konkluż li Microsoft Azure hija l-aktar għażla adattata għall-organizzazzjoni tagħna.

## Deċiżjoni

Adotta Microsoft Azure bħala l-infrastruttura tal-cloud għall-organizzazzjoni tagħna.

## Raġunament

Dawn huma r-raġunijiet għall-adozzjoni ta' Microsoft Azure:

1. Servizzi komprensivi: Azure tipprovdi firxa kompluta ta' servizzi tal-cloud mill-infrastruttura bħala servizz (IaaS) sas-software bħala servizz (SaaS) u l-pjattaforma bħala servizz (PaaS). Dan jippermettilna nisfruttaw is-servizzi ta' Azure biex insolvu r-rekwiżiti tal-organizzazzjoni, bħall-ħażna, il-compute, in-netwerking, u l-analitika.

2. Skalabbiltà u flessibbiltà: B'Azure, nistgħu faċilment niskalaw 'il fuq jew 'l isfel ir-riżorsi abbażi tar-rekwiżiti tan-negozju tagħna. Azure toffri wkoll flessibbiltà fl-għażla tas-sistema operattiva, tal-lingwa tal-programmazzjoni, u tal-frameworks.

3. Sigurtà u konformità: Azure toffri livell għoli ta' sigurtà u konformità, billi hija konformi ma' diversi standards tal-industrija bħal ISO, SOC, HIPAA, u PCI DSS. Azure tipprovdi wkoll karatteristiċi avvanzati ta' sigurtà bħal network security groups, firewalls, u protezzjoni minn DDoS.

4. Cloud ibridu: Azure tipprovdi esperjenza ta' cloud ibridu bla xkiel, li tippermetti lill-organizzazzjonijiet jgħaqqdu l-infrastruttura on-premises tagħhom ma' Azure. Dan jagħmilha faċli għalina biex nimigraw workloads lejn il-cloud u jagħtina l-flessibbiltà li nagħżlu fejn naħżnu d-data.

5. Kosteffettiva: Azure toffri mudell ta' prezzijiet pay-as-you-go, li jfisser li nħallsu biss għar-riżorsi użati. Dan jgħinna nfrankaw l-ispejjeż meta mqabbel mal-infrastruttura tradizzjonali on-premises.

## Konklużjoni

L-adozzjoni ta' Microsoft Azure bħala l-infrastruttura tal-cloud għall-organizzazzjoni tagħna taqbel mar-rekwiżiti tan-negozju tagħna u toffri diversi benefiċċji bħall-iskalabbiltà, il-flessibbiltà, is-sigurtà, u l-kosteffettività. Għalhekk, huwa rakkomandat li tiġi adottata Azure bħala l-infrastruttura tal-cloud tagħna.
