# Decision record templet wey Michael Nygard mek

Dis na di templet for [Documenting architecture decisions - Michael Nygard](http://thinkrelevance.com/blog/2011/11/15/documenting-architecture-decisions).
You fit use [adr-tools](https://github.com/npryce/adr-tools) to manage di ADR files.

For each ADR file, write dis sections:

# Title

## Status

Wetin be di status, like proposed, accepted, rejected, deprecated, superseded, etc.?

## Context

Wetin be di issue wey we dey see wey dey push dis decision or change?

## Decision

Wetin be di change wey we dey propose and/or dey do?

## Consequences

Wetin go easier or more difficult to do because of dis change?
