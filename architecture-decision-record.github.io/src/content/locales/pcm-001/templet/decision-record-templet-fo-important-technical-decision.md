# Decision record templet fo Important Technical Decisions (ITDs)

Dis na di Important Technical Decisions (ITD) templet wey dem describe for
[ITDs: a lean ADR for executive technical decision-making at scale - Ignacio Larrañaga](https://ignaciolarranaga.medium.com/itds-a-lean-adr-for-executive-technical-decision-making-at-scale-e18bb3f6a563).

ITDs na focused evolution of ADRs, wey dem optimize for speed, clarity, and
executive validation. Where ADR dey document wetin dem decide, ITD na
lean, decision-first artifact wey dey make di decision itself reviewable, so
stakeholders fit scan am quick and challenge am easy. ITDs dey suit
technical decisions wey no strictly architectural, like to choose
model, library, or CI/CD strategy.

For each ITD file, write dis sections:

# Title

State di decision itself, no be description of di topic.
For example, "Use Qwen2.5 1.5B Instruct for on-device translation".

## The Problem

One sentence wey state wetin we dey try solve.

## Options Considered

Di alternatives wey dey on di table, with di selected option for **bold**.

## Rationale

Only di decisive factors wey lead to di choice, no be exhaustive list of
every pro and con.

## Notes

Optional. Any additional context wey worth to record, like constraints,
assumptions, or links.
