# سجل قرار البنية المعمارية: Tailwind CSS

القرار: استخدام Tailwind CSS إطارَ CSS لتنسيق واجهة المستخدم.

## ما هو Tailwind CSS؟

Tailwind إطار CSS يعتمد منهج الأدوات المساعدة أولًا (utility-first) يتيح التطوير السريع لواجهات المستخدم وتخصيصها. وهو مصمم ليكون شديد القابلية للتخصيص ويتيح للمطورين كتابة CSS أخف وأكفأ. ويوفر هذا الإطار مجموعة من الأصناف المعرَّفة مسبقًا لتنسيق واجهة المستخدم بسرعة كبيرة.

## السياق

نبني تطبيق ويب لعميل يتطلب واجهة مستخدم متجاوبة وقابلة للتخصيص. وقد طلب العميل تنسيقًا متسقًا وحديثًا. ولدى فريق التطوير خبرة في استخدام CSS المخصص لكنه يريد استكشاف أطر CSS التي يمكن أن توفر الوقت والجهد. ونبحث عن إطار سهل الاستخدام وقابل للتخصيص ولديه مجتمع كبير للدعم.

## محركات القرار

- **سهل الاستخدام:**  نريد إطارًا بسيط التعلم يمكن دمجه في سير عمل التطوير لدينا.

- **قابل للتخصيص:**  نريد إطارًا يمكن تخصيصه ليتوافق مع إرشادات العلامة التجارية للعميل وسمته.

- **دعم مجتمعي كبير:**  نريد إطارًا لديه مجتمع نشط من المطورين والمصممين يستطيع تقديم المساعدة والموارد عند الحاجة.

- **توفير الوقت:**  نريد إطارًا يستطيع توفير الوقت والجهد في تنسيق واجهة المستخدم.

## الخيارات المدروسة

- **Bootstrap:**  إطار CSS شائع فيه كثير من المكونات الجاهزة ومجتمع كبير من المطورين.

- **Foundation:**  إطار CSS شائع آخر صُمم للتطوير الذي يبدأ بالجوّال (mobile-first).

- **Materialize:**  إطار CSS قائم على لغة التصميم Material Design من Google، مع مكونات جاهزة لتطوير واجهة المستخدم.

- **Tailwind CSS:**  إطار CSS يعتمد منهج الأدوات المساعدة أولًا، ويركّز على التخصيص والكفاءة.

## نتيجة القرار

بعد النظر في الخيارات، قررنا استخدام Tailwind CSS للأسباب التالية:

- **سهل الاستخدام:**  نهج Tailwind بسيط وسهل الفهم. وتجعل أصنافه المساعدة بناء واجهة المستخدم أسرع.

- **قابل للتخصيص:**  يتيح Tailwind التخصيص بتوفير مجموعة من ملفات الإعداد تتيح للمطورين تعديل الأنماط الافتراضية للإطار بسهولة.

- **دعم مجتمعي كبير:**  لدى Tailwind مجتمع نشط جدًا من المطورين والمصممين يبتكرون باستمرار موارد وإضافات وأدوات جديدة.

- **توفير الوقت:**  يستطيع Tailwind توفير الوقت، مما يتيح للمطورين التركيز على مجالات أخرى في المشروع.

سنستخدم الأصناف المساعدة في Tailwind CSS لبناء واجهة المستخدم لمشروعنا. وسيستخدم فريق التطوير نظام تصميمه الذري والوحدوي لكتابة شيفرة CSS كفؤة وقابلة للتوسع. وسنستفيد من القوالب الجاهزة والمكونات المرئية في Tailwind لتسريع عملية التطوير، مع استخدام أنماط مخصصة لتتوافق مع العلامة التجارية للعميل وسمته.
