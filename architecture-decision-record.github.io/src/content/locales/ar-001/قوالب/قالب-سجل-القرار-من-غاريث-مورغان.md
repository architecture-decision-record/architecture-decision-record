# [000] العنوان
*أعطِ كل سجل ADR رقمًا لتسهيل الإحالة إليه وفهرسته* \
*ملاحظة: كل النص المائل إرشادات ويجب حذفه في النسخة النهائية*

## الحالة - مسودة (DRAFT) / نشط (ACTIVE) / مهجور (DEPRECATED) بواسطة [000] / يستبدل (SUPERSEDES) [000]

## السياق
*صِف باختصار المشكلة أو المشكلات التي يهدف هذا السجل إلى معالجتها، ولماذا هي موجودة.*

## النهج المقرَّر
*فصّل القرار ذا الأثر المعماري الذي اتُّخذ / سيُتخذ، وصِف كيف يعالج المشكلات المذكورة في قسم السياق.*

## العواقب
*ما أثر هذا القرار في الخصائص المعمارية والمتطلبات الوظيفية للنظام؟*

## الحوكمة
*كيف ستُراقب نتائج هذا القرار؟* \
*كيف سيُضمن الامتثال لهذا القرار؟*

## تحليل الخيارات
*إن كان ذلك مناسبًا، ضمّن أو اربط أي تحليل مفاضلات أُجري للوصول إلى القرار المتخذ في هذه الوثيقة.*

### مفتاح الألوان
*اختياري: وفّر وسائل بصرية لأصحاب المصلحة تساعد على رؤية المفاضلات الإيجابية والسلبية بسرعة، مثل تظليل بسيط بألوان إشارة المرور مع بادئات إيجابية أو سلبية.*

تشير الخلفية <span style="background-color:#4bce97; color:black;">الخضراء</span> إلى ملاءمة جيدة، تسوء مرورًا بـ<span style="background-color:#f1c232; color:black;">الكهرماني</span>، وتمثل <span style="background-color:#e06666; color:black;">الحمراء</span> أسوأ ملاءمة. \
\+ يشير إلى تعليق ذي أثر إيجابي \
\- يشير إلى تعليق ذي أثر سلبي
