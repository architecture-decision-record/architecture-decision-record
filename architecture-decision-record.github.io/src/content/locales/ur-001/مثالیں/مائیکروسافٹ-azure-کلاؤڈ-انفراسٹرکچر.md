# آرکیٹیکچر فیصلے کا ریکارڈ: مائیکروسافٹ Azure کلاؤڈ انفراسٹرکچر

فیصلے کا عنوان: اپنی تنظیم کے کلاؤڈ انفراسٹرکچر کے طور پر مائیکروسافٹ Azure کو اپنانا

فیصلہ ساز: چیف انفارمیشن آفیسر

تاریخ: 2021-10-15

حالت: منظور شدہ

## پس منظر

تنظیم روایتی آن پریمائسز انفراسٹرکچر سے کلاؤڈ انفراسٹرکچر پر منتقلی کی منصوبہ بندی کر رہی ہے۔ اسے حاصل کرنے کے لیے تنظیم نے Amazon Web Services (AWS)، Google Cloud Platform (GCP)، Microsoft Azure اور IBM Cloud جیسے متعدد کلاؤڈ سروس فراہم کنندگان کا جائزہ لیا ہے۔ ہر فراہم کنندہ کی اپنی خصوصیات، فوائد اور قیمتوں کا ڈھانچہ ہے۔ تفصیلی تجزیے کے بعد یہ نتیجہ نکالا گیا کہ مائیکروسافٹ Azure ہماری تنظیم کے لیے سب سے موزوں اختیار ہے۔

## فیصلہ

اپنی تنظیم کے کلاؤڈ انفراسٹرکچر کے طور پر مائیکروسافٹ Azure کو اپنانا۔

## جواز

مائیکروسافٹ Azure کو اپنانے کی وجوہات درج ذیل ہیں:

1. جامع خدمات: Azure انفراسٹرکچر بطور سروس (IaaS) سے لے کر سافٹ ویئر بطور سروس (SaaS) اور پلیٹ فارم بطور سروس (PaaS) تک کلاؤڈ خدمات کی مکمل رینج فراہم کرتا ہے۔ یہ ہمیں اسٹوریج، کمپیوٹ، نیٹ ورکنگ اور اینالیٹکس جیسی تنظیم کی ضروریات حل کرنے کے لیے Azure خدمات سے فائدہ اٹھانے کے قابل بناتا ہے۔

2. وسعت پذیری اور لچک: Azure کے ساتھ ہم اپنے کاروباری تقاضوں کے مطابق وسائل آسانی سے بڑھا یا گھٹا سکتے ہیں۔ Azure آپریٹنگ سسٹم، پروگرامنگ زبان اور فریم ورکس کے انتخاب میں بھی لچک پیش کرتا ہے۔

3. سیکیورٹی اور تعمیل: Azure اعلیٰ سطح کی سیکیورٹی اور تعمیل پیش کرتا ہے، کیونکہ وہ ISO، SOC، HIPAA اور PCI DSS جیسے متعدد صنعتی معیارات کے مطابق ہے۔ Azure نیٹ ورک سیکیورٹی گروپس، فائر والز اور DDoS تحفظ جیسی جدید سیکیورٹی خصوصیات بھی فراہم کرتا ہے۔

4. ہائبرڈ کلاؤڈ: Azure بے ربط ہائبرڈ کلاؤڈ تجربہ فراہم کرتا ہے جو تنظیموں کو اپنے آن پریمائسز انفراسٹرکچر کو Azure سے جوڑنے کے قابل بناتا ہے۔ یہ ہمارے لیے ورک لوڈز کو کلاؤڈ میں منتقل کرنا آسان بناتا ہے اور ہمیں یہ چننے کی لچک دیتا ہے کہ ڈیٹا کہاں محفوظ کریں۔

5. کفایتی: Azure جتنا استعمال اتنی ادائیگی (pay-as-you-go) کا قیمتوں کا ماڈل پیش کرتا ہے، جس کا مطلب ہے کہ ہم صرف استعمال شدہ وسائل کی ادائیگی کرتے ہیں۔ یہ روایتی آن پریمائسز انفراسٹرکچر کے مقابلے میں لاگت بچانے میں ہماری مدد کرتا ہے۔

## اختتامیہ

اپنی تنظیم کے کلاؤڈ انفراسٹرکچر کے طور پر مائیکروسافٹ Azure کو اپنانا ہمارے کاروباری تقاضوں سے ہم آہنگ ہے اور وسعت پذیری، لچک، سیکیورٹی اور کفایت جیسے کئی فوائد پیش کرتا ہے۔ لہٰذا Azure کو ہمارے کلاؤڈ انفراسٹرکچر کے طور پر اپنانے کی سفارش کی جاتی ہے۔
