# آرکیٹیکچر فیصلے کا ریکارڈ: Svelte فرنٹ اینڈ JavaScript لائبریری

حالت: قبول شدہ

## سیاق و سباق

ہم جدید فرنٹ اینڈ JavaScript فریم ورک کے ساتھ ویب ایپلیکیشن تیار کر رہے ہیں۔ ہم ایسی لائبریری چننا چاہتے ہیں جو ہلکی پھلکی، تیز اور استعمال میں آسان ہو۔ ہم نے React، Vue اور Angular سمیت کئی لائبریریوں کا جائزہ لیا ہے۔ ہم نے Svelte کے بارے میں بھی سنا ہے، جو دعویٰ کرتی ہے کہ وہ نئی قسم کا ہلکا پھلکا فریم ورک ہے۔ ہمیں Svelte کا جائزہ لینا اور فیصلہ کرنا ہے کہ آیا وہ ہماری ایپلیکیشن کے لیے مناسب ہے۔

## فیصلہ

ہر لائبریری کے فوائد اور نقصانات پر غور کرنے کے بعد ہم نے درج ذیل وجوہات کی بنا پر اپنی فرنٹ اینڈ JavaScript لائبریری کے طور پر Svelte استعمال کرنے کا فیصلہ کیا ہے:

1. **ہلکی پھلکی:**  Svelte دستیاب ہلکی ترین لائبریریوں میں سے ایک ہے، جو ہمیں اپنی ایپلیکیشن کا سائز چھوٹا رکھنے اور صفحہ لوڈ ہونے کا وقت بہتر بنانے میں مدد دے گی۔

2. **تیز:**  Svelte اپنی تیز رینڈرنگ رفتار کے لیے جانی جاتی ہے، جو ہماری ایپلیکیشن کو ریسپانسیو اور تیز محسوس کرائے گی۔

3. **استعمال میں آسان:**  Svelte کی نحو سادہ اور سمجھنے میں آسان ہے، جو ہماری ٹیم کے لیے اسے اپنانا اور صاف کوڈ لکھنا آسان بنائے گی۔

4. **UI رینڈرنگ کے لیے بہتر بنائی گئی:**  Svelte UI اجزا کی رینڈرنگ کے لیے بہتر بنائی گئی ہے، جو ہمارے لیے متحرک اور قابلِ دوبارہ استعمال UI عناصر بنانا آسان بنائے گی۔

5. **اچھی دستاویزات اور کمیونٹی سپورٹ:**  Svelte کی بڑھتی ہوئی کمیونٹی اور اچھی دستاویزات ہیں، جو ہمیں جلدی شروع کرنے اور پیش آنے والے کسی بھی مسئلے کو حل کرنے میں مدد دیں گی۔

## متبادل

ہم نے React، Vue اور Angular پر غور کیا، لیکن درج ذیل وجوہات کی بنا پر انہیں نہ اپنانے کا فیصلہ کیا:

1. **React:**  اگرچہ React کی صارفین کی بڑی بنیاد اور لائبریریوں اور وسائل کا خزانہ ہے، یہ پیچیدہ اور سیکھنے میں مشکل ہو سکتی ہے، خاص طور پر ابتدائی افراد کے لیے۔

2. **Vue:**  Vue ایک ہلکی پھلکی لائبریری ہے جو سیکھنے اور استعمال کرنے میں آسان ہے، لیکن ہو سکتا ہے کہ وہ Svelte جتنی تیز یا بہتر بنائی گئی نہ ہو۔

3. **Angular:**  Angular ایک جامع فریم ورک ہے جو بہت سی خصوصیات اور ٹولز پیش کرتا ہے، لیکن یہ بھاری اور پیچیدہ ہو سکتا ہے، اور Svelte سے زیادہ دیکھ بھال کا متقاضی ہو سکتا ہے۔

## نتائج

Svelte کو اپنی فرنٹ اینڈ JavaScript لائبریری کے طور پر استعمال کرنے کے درج ذیل نتائج ہوں گے:

1. ہماری ایپلیکیشن ہلکی پھلکی اور تیز ہوگی، جو صارف کے تجربے اور شمولیت کو بہتر بنائے گی۔

2. ہماری ٹیم کو نئی لائبریری سیکھنی ہوگی، لیکن Svelte کی نحو سادہ اور سمجھنے میں آسان ہے، اس لیے سیکھنے کا خم قابلِ انتظام ہونا چاہیے۔

3. Svelte اب بھی نسبتاً نئی لائبریری ہے، اس لیے ہمیں کچھ ایسے مسائل کا سامنا ہو سکتا ہے جو اچھی طرح دستاویزی یا کمیونٹی کی طرف سے سپورٹڈ نہ ہوں۔

4. Svelte کے صارفین کی کمیونٹی بڑھ رہی ہے، اس لیے ہم مستقبل میں مزید تیسرے فریق کی لائبریریاں اور وسائل دستیاب ہوتے دیکھ سکتے ہیں جو بنیادی لائبریری کی تکمیل کے لیے استعمال ہو سکیں۔
