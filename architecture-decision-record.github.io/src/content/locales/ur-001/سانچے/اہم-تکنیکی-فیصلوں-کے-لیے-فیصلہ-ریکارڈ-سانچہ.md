# اہم تکنیکی فیصلوں (ITD) کے لیے فیصلہ ریکارڈ سانچہ

یہ اہم تکنیکی فیصلوں (ITD) کا سانچہ ہے جو
[ITDs: a lean ADR for executive technical decision-making at scale - Ignacio Larrañaga](https://ignaciolarranaga.medium.com/itds-a-lean-adr-for-executive-technical-decision-making-at-scale-e18bb3f6a563) میں بیان کیا گیا ہے۔

ITD، ADR کا ایک مرکوز ارتقا ہیں، جو رفتار، وضاحت اور
انتظامی توثیق کے لیے بہتر بنائے گئے ہیں۔ جہاں ADR دستاویز کرتا ہے کہ کیا فیصلہ ہوا، وہاں ITD ایک
مختصر، فیصلے کو اوّلیت دینے والا آرٹیفیکٹ ہے جو خود فیصلے کو قابلِ جائزہ بناتا ہے، تاکہ
اسٹیک ہولڈرز اسے جلدی دیکھ سکیں اور آسانی سے چیلنج کر سکیں۔ ITD ان تکنیکی فیصلوں کے لیے موزوں ہیں
جو سختی سے آرکیٹیکچر کے نہیں ہیں، جیسے کسی ماڈل، لائبریری یا CI/CD حکمتِ عملی کا انتخاب۔

ہر ITD فائل میں یہ حصے لکھیں:

# عنوان

خود فیصلہ بیان کریں، موضوع کی وضاحت نہیں۔
مثلاً، “آن ڈیوائس ترجمے کے لیے Qwen2.5 1.5B Instruct استعمال کریں”۔

## مسئلہ

ایک جملہ جو بتائے کہ ہم کیا حل کرنے کی کوشش کر رہے ہیں۔

## زیرِ غور اختیارات

وہ متبادل جو میز پر تھے، منتخب اختیار **گہرے (bold)** حروف میں۔

## جواز

صرف وہ فیصلہ کن عوامل جو انتخاب تک لے گئے، نہ کہ ہر
فائدے اور نقصان کی مکمل فہرست۔

## نوٹس

اختیاری۔ کوئی بھی اضافی سیاق و سباق جسے درج کرنا مناسب ہو، جیسے پابندیاں،
مفروضات یا لنکس۔
