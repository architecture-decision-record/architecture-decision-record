# ແນວທາງເພື່ອບັນລຸການຕັດສິນໃຈທີ່ຍືນຍົງ

<https://www.infoq.com/articles/sustainable-architectural-design-decisions/>

ພວກເຮົາໄດ້ຮຽນຮູ້ບົດຮຽນຕໍ່ໄປນີ້ຈາກການເຮັດວຽກ ເຊິ່ງສາມາດເປັນແນວທາງ ແລະ ການປະເມີນເພື່ອບັນລຸການຕັດສິນໃຈທີ່ຍືນຍົງ:

1. ໃຊ້ແນວທາງແບບກະທັດຮັດ/ໜ້ອຍທີ່ສຸດສຳລັບການບັນທຶກການຕັດສິນໃຈໃນເບື້ອງຕົ້ນ.

2. ຈັດລຳດັບຄວາມສຳຄັນ ແລະ ບັນທຶກການຕັດສິນໃຈທີ່ສຳຄັນທັງໝົດທີ່ກ່ຽວຂ້ອງພຽງພໍສຳລັບການບັນທຶກເອກະສານ ແລະ ການເຂົ້າໃຈສະຖາປັດຕະຍະກຳເປົ້າໝາຍ.

3. ລົງລາຍລະອຽດການຕັດສິນໃຈທີ່ສຳຄັນເປັນພິເສດດ້ວຍແມ່ແບບແບບເຕັມຮູບແບບ ຫຼັງຈາກວຽກເບື້ອງຕົ້ນສຳເລັດແລ້ວເທົ່ານັ້ນ (ນັ້ນຄື ເມື່ອຜູ້ຕັດສິນໃຈພໍໃຈກັບການຕັດສິນໃຈດ້ານສະຖາປັດຕະຍະກຳທີ່ເຮັດໄປແລ້ວ ແລະ ໝັ້ນໃຈວ່າການຕັດສິນໃຈເຫຼົ່ານີ້ບໍ່ຈຳເປັນຕ້ອງທົບທວນໃນໄວໆນີ້).

4. ໃຊ້ສະບັບກະທັດຮັດ/ໜ້ອຍທີ່ສຸດຈາກຂັ້ນຕອນທີ 1 ເປັນສະບັບຫຍໍ້ຂອງການຕັດສິນໃຈທີ່ບັນທຶກໄວ້ ໃນລະດັບຄວາມລະອຽດທີ່ເໝາະສົມ ເພື່ອໃຫ້ພາບລວມຂອງການຕັດສິນໃຈທີ່ລະອຽດ ລວມທັງສຳລັບການຕັດສິນໃຈທີ່ເລັກນ້ອຍ ຫຼື ຊັດເຈນຢູ່ແລ້ວ.

5. ເມື່ອເປັນໄປໄດ້ ໃຫ້ໃຊ້ຄວາມຮູ້ດ້ານສະຖາປັດຕະຍະກຳທີ່ມີຢູ່ແລ້ວ ບໍ່ວ່າຈະຈາກແບບຈຳລອງແນະນຳ ຫຼື ແຫຼ່ງອື່ນ. ທົບທວນ ແລະ ຂະຫຍາຍຄວາມຮູ້ດັ່ງກ່າວ ແລະ ປັບໃຫ້ເໝາະກັບບໍລິບົດຂອງການຕັດສິນໃຈສະເພາະນັ້ນ.

6. ຮັບປະກັນວ່າມີການສ້າງລິ້ງຕິດຕາມລະຫວ່າງການຕັດສິນໃຈກັບທັງຄວາມຕ້ອງການ ແລະ ການອອກແບບສະຖາປັດຕະຍະກຳ/ໂຄ້ດ.

7. ສະໜອງການກວດສອບຄວາມສອດຄ່ອງແບບອັດຕະໂນມັດ ເພື່ອໃຫ້ແນ່ໃຈວ່າລິ້ງຕິດຕາມຍັງຖືກຕ້ອງຫຼັງຈາກມີການປ່ຽນແປງ. ຈຳກັດຈຳນວນຄວາມຂຶ້ນກັບກັນລະຫວ່າງການຕັດສິນໃຈ ແລະ ຜະລິດຕະພັນຊອບແວອື່ນໆ.

8. ນຳໃຊ້ແນວທາງສຳລັບການໃຫ້ເຫດຜົນຢ່າງຕໍ່ເນື່ອງ ແລະ ເຂັ້ມງວດ—ເພາະມັນເປັນສ່ວນທີ່ສຳຄັນທີ່ສຸດຂອງການບັນທຶກການຕັດສິນໃຈ ເນື່ອງຈາກໃຫ້ເຫດຜົນພື້ນຖານ.
