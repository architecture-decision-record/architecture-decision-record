# ແມ່ແບບບັນທຶກການຕັດສິນໃຈສຳລັບຮູບແບບ Alexandrian

## ບົດນຳ

* ບົດນຳ (ບົດສະຫຼຸບ)
* ການສົນທະນາ (ບໍລິບົດ)
* ວິທີແກ້ໄຂ (ການຕັດສິນໃຈ)
* ຜົນສະທ້ອນ (ຜົນລັບ)

## ລາຍລະອຽດສະເພາະ ##

* ບົດນຳ (ບົດສະຫຼຸບ)
  * ຂໍ້ຄວາມເພື່ອສະຫຼຸບ:
    * ໃນບໍລິບົດຂອງ (ກໍລະນີການນຳໃຊ້)<br>
      ທີ່ປະເຊີນກັບ (ຄວາມກັງວົນ)<br>
      ພວກເຮົາຕັດສິນໃຈເລືອກ (ທາງເລືອກ)<br>
      ເພື່ອບັນລຸ (ຄຸນນະພາບ)<br>
      ໂດຍຍອມຮັບ (ຂໍ້ເສຍ).
* ການສົນທະນາ (ບໍລິບົດ)
  * ອະທິບາຍແຮງຜັກດັນທີ່ມີຜົນ (ດ້ານເຕັກນິກ, ການເມືອງ, ສັງຄົມ, ໂຄງການ).
  * ນີ້ແມ່ນເລື່ອງລາວທີ່ອະທິບາຍບັນຫາທີ່ພວກເຮົາກຳລັງຊອກຫາທາງແກ້ໄຂ.
* ວິທີແກ້ໄຂ
  * ອະທິບາຍວ່າການຕັດສິນໃຈຈະແກ້ບັນຫາແນວໃດ.
* ຜົນສະທ້ອນ
  * ອະທິບາຍຜົນຂອງການຕັດສິນໃຈໃນໄລຍະຍາວ.
  * ມັນໃຊ້ໄດ້ຜົນ, ບໍ່ໄດ້ຜົນ, ຖືກປ່ຽນແປງ, ຖືກຍົກລະດັບ ແລະ ອື່ນໆ.
