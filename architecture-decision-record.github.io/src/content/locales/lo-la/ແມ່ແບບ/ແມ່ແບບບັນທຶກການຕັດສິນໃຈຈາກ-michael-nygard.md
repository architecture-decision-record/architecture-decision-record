# ແມ່ແບບບັນທຶກການຕັດສິນໃຈຈາກ Michael Nygard

ນີ້ແມ່ນແມ່ແບບໃນ [Documenting architecture decisions - Michael Nygard](http://thinkrelevance.com/blog/2011/11/15/documenting-architecture-decisions).
ທ່ານສາມາດໃຊ້ [adr-tools](https://github.com/npryce/adr-tools) ເພື່ອຈັດການໄຟລ໌ ADR.

ໃນແຕ່ລະໄຟລ໌ ADR ໃຫ້ຂຽນສ່ວນເຫຼົ່ານີ້:

# ຫົວຂໍ້

## ສະຖານະ

ສະຖານະແມ່ນຫຍັງ ເຊັ່ນ ສະເໜີ, ຍອມຮັບ, ປະຕິເສດ, ເລີກໃຊ້, ຖືກແທນທີ່ ແລະ ອື່ນໆ?

## ບໍລິບົດ

ບັນຫາທີ່ພວກເຮົາເຫັນ ເຊິ່ງເປັນແຮງຈູງໃຈໃຫ້ມີການຕັດສິນໃຈ ຫຼື ການປ່ຽນແປງນີ້ແມ່ນຫຍັງ?

## ການຕັດສິນໃຈ

ການປ່ຽນແປງທີ່ພວກເຮົາກຳລັງສະເໜີ ແລະ/ຫຼື ກຳລັງເຮັດແມ່ນຫຍັງ?

## ຜົນສະທ້ອນ

ສິ່ງໃດທີ່ເຮັດໄດ້ງ່າຍຂຶ້ນ ຫຼື ຍາກຂຶ້ນເນື່ອງຈາກການປ່ຽນແປງນີ້?
