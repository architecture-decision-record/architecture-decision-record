## ຂໍ້ຄວາມບັນຫາ 

ພວກເຮົາຕ້ອງເລືອກແພລດຟອມຈັດການຄອນເທນເນີສຳລັບພອດໂຟລິໂອແອັບພລິເຄຊັນແບບ cloud-native ທີ່ກຳລັງເຕີບໂຕຂອງພວກເຮົາ. ການຕິດຕັ້ງແພລດຟອມເກົ່າໃນປັດຈຸບັນຂອງພວກເຮົາຊ້າເກີນໄປ ແລະ ບໍ່ວ່ອງໄວພໍທີ່ຈະຕາມທັນຄວາມຕ້ອງການທີ່ເຕີບໂຕຂອງພວກເຮົາ. ພວກເຮົາກຳລັງຊອກຫາລະບົບທີ່ຈະຊ່ວຍໃຫ້ພວກເຮົາຂະຫຍາຍບໍລິການຂອງພວກເຮົາໃນວິທີທີ່ມີປະສິດທິພາບທີ່ສຸດເທົ່າທີ່ເປັນໄປໄດ້ ໂດຍບໍ່ເສຍຄວາມວ່ອງໄວ ຫຼື ຄວາມງ່າຍໃນການໃຊ້ງານ.

## ການຕັດສິນໃຈທີ່ເຮັດ

ຫຼັງຈາກການວິເຄາະແພລດຟອມຈັດການຄອນເທນເນີແຕ່ລະອັນຢ່າງລະອຽດ ພວກເຮົາໄດ້ຕັດສິນໃຈນຳເອົາ Kubernetes ມາໃຊ້ເປັນທາງເລືອກທີ່ດີທີ່ສຸດສຳລັບຄວາມຕ້ອງການຂອງວິສາຫະກິດຂອງພວກເຮົາ. ເຫດຜົນຂອງພວກເຮົາໃນການເລືອກ Kubernetes ມີດັ່ງນີ້:

1. **ຄວາມສາມາດໃນການຂະຫຍາຍ:**  ການອອກແບບທີ່ເປັນເອກະລັກຂອງ Kubernetes ເໝາະສົມຢ່າງສົມບູນສຳລັບການຂະຫຍາຍແອັບພລິເຄຊັນ ແລະ ເມື່ອຄວາມຕ້ອງການດ້ານການຂະຫຍາຍຂອງພວກເຮົາພັດທະນາຕາມເວລາ Kubernetes ມີຄວາມສາມາດໃນຕົວທີ່ຈະຕອບສະໜອງການປ່ຽນແປງເຫຼົ່ານີ້ໂດຍບໍ່ມີບັນຫາ.

2. **ສະຖາປັດຕະຍະກຳແບບກະຈາຍອຳນາດ:**  ໂທໂປໂລຢີ master-worker ຂອງ Kubernetes ຮັບປະກັນສະຖາປັດຕະຍະກຳແບບກະຈາຍອຳນາດ ເຊິ່ງຮັບປະກັນວ່າບໍ່ມີຈຸດລົ້ມເຫຼວດຽວ.

3. **ການສະໜັບສະໜູນຈາກຊຸມຊົນ:**  Kubernetes ມີຊຸມຊົນຊອດເປີດທີ່ໃຫຍ່ທີ່ສຸດ ແລະ ຄຶກຄັກທີ່ສຸດ ເຊິ່ງໝາຍຄວາມວ່າມີຜູ້ປະກອບສ່ວນ, ນັກພັດທະນາ ແລະ ຜູ້ຂາຍຈຳນວນຫຼາຍ ເຮັດໃຫ້ພວກເຮົາຂໍຄວາມຊ່ວຍເຫຼືອ ແລະ ຊອກຫາຊັບພະຍາກອນໄດ້ງ່າຍຂຶ້ນ.

4. **ການສະໜັບສະໜູນຈາກລະບົບນິເວດ:**  Kubernetes ມີລະບົບນິເວດທີ່ກຳລັງເຕີບໂຕພ້ອມເຄື່ອງມືຈາກບຸກຄົນທີສາມຫຼາກຫຼາຍ, ການເຊື່ອມໂຍງກັບ container registries, ທໍ່ CI/CD, ການເກັບຂໍ້ມູນ ແລະ ອື່ນໆ.

ດັ່ງນັ້ນ ພວກເຮົາຈຶ່ງໄດ້ຕັດສິນໃຈນຳເອົາ Kubernetes ມາໃຊ້ເປັນແພລດຟອມຈັດການຄອນເທນເນີຂອງພວກເຮົາໃນປັດຈຸບັນ ແລະ ອະນາຄົດອັນໃກ້.
