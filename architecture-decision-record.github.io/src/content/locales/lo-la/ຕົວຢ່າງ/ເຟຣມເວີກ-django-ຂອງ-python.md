# ບັນທຶກການຕັດສິນໃຈດ້ານສະຖາປັດຕະຍະກຳສຳລັບເຟຣມເວີກ Django ຂອງ Python

ວັນທີຕັດສິນໃຈ: 2021-07-15

ສະຖານະ: ຍອມຮັບ

## ບໍລິບົດ

ອົງກອນຂອງພວກເຮົາວາງແຜນພັດທະນາເວັບແອັບພລິເຄຊັນທີ່ຈັດການຂໍ້ມູນລູກຄ້າ. ພວກເຮົາໄດ້ເລືອກ Python ເປັນພາສາການຂຽນໂປຣແກຣມ ແລະ ກຳລັງພິຈາລະນາ Django ເປັນເຟຣມເວີກເວັບສຳລັບການພັດທະນາແອັບພລິເຄຊັນ.

## ການຕັດສິນໃຈ

ພວກເຮົາໄດ້ຕັດສິນໃຈໃຊ້ເຟຣມເວີກເວັບ Django ສຳລັບການພັດທະນາເວັບແອັບພລິເຄຊັນ. Django ໃຫ້ຊຸດເຄື່ອງມື ແລະ ຄຸນສົມບັດທີ່ແຂງແກ່ນສຳລັບການສ້າງເວັບແອັບພລິເຄຊັນຢ່າງວ່ອງໄວ ແລະ ມີປະສິດທິພາບ. 

## ປັດໄຈ

ບາງປັດໄຈທີ່ມີອິດທິພົນຕໍ່ການຕັດສິນໃຈຂອງພວກເຮົາລວມມີ:

1. Object-Relational Mapping (ORM): Django ມີ ORM ໃນຕົວທີ່ຊ່ວຍໃຫ້ພວກເຮົາໂຕ້ຕອບກັບຖານຂໍ້ມູນໂດຍບໍ່ຕ້ອງຂຽນຄຳສັ່ງ SQL. ສິ່ງນີ້ເຮັດໃຫ້ພັດທະນາແອັບພລິເຄຊັນໄດ້ງ່າຍຂຶ້ນ ແລະ ບຳລຸງຮັກສາໄດ້ງ່າຍໃນໄລຍະຍາວ.

2. ເຟຣມເວີກ MVC: Django ປະຕິບັດຕາມສະຖາປັດຕະຍະກຳ Model-View-Controller (MVC) ເຮັດໃຫ້ແຍກຕັກກະທາງທຸລະກິດ ແລະ ຊັ້ນການນຳສະເໜີຂອງແອັບພລິເຄຊັນໄດ້ງ່າຍຂຶ້ນ.

3. ຄວາມສາມາດໃນການຂະຫຍາຍ: Django ເປັນທີ່ຮູ້ຈັກໃນດ້ານຄວາມສາມາດໃນການຂະຫຍາຍ ເຮັດໃຫ້ເປັນທາງເລືອກທີ່ດີເລີດສຳລັບການພັດທະນາແອັບພລິເຄຊັນຂະໜາດໃຫຍ່.

4. ຄວາມປອດໄພ: Django ມີຄຸນສົມບັດຄວາມປອດໄພໃນຕົວ ເຊັ່ນ ການປ້ອງກັນການໂຈມຕີເວັບທົ່ວໄປ ເຊັ່ນ cross-site scripting (XSS) ແລະ SQL injection.

5. ການສະໜັບສະໜູນຈາກຊຸມຊົນ: Django ມີຊຸມຊົນໃຫຍ່ ແລະ ຄຶກຄັກທີ່ໃຫ້ການສະໜັບສະໜູນ ແລະ ປະກອບສ່ວນໃນການພັດທະນາເຟຣມເວີກ.

## ທາງເລືອກທີ່ພິຈາລະນາ

ພວກເຮົາໄດ້ພິຈາລະນາເຟຣມເວີກເວັບອື່ນ ເຊັ່ນ Flask ແລະ Pyramid. ແນວໃດກໍຕາມ ພວກເຮົາພົບວ່າ Django ເປັນເຟຣມເວີກທີ່ເຕັມທີ່ກວ່າ ແລະ ມີຊື່ສຽງຫຼາຍກວ່າ ພ້ອມຊຸດຄຸນສົມບັດທີ່ແຂງແກ່ນ.

ພວກເຮົາຍັງໄດ້ສົນທະນາການພັດທະນາແອັບພລິເຄຊັນໂດຍບໍ່ໃຊ້ເຟຣມເວີກເວັບ ແລະ ໃຊ້ໄລບຣາຣີເຊັ່ນ SQLAlchemy ແລະ Flask-RESTful. ແນວໃດກໍຕາມ ພວກເຮົາພົບວ່າ Django ໃຫ້ໜ້າທີ່ກວ້າງກວ່າ ເຮັດໃຫ້ເປັນທາງເລືອກທີ່ດີກວ່າສຳລັບເວັບແອັບພລິເຄຊັນທີ່ສົມບູນ.

## ຜົນສະທ້ອນ

ການນຳເອົາ Django ມາໃຊ້ຈະນຳໄປສູ່ຜົນສະທ້ອນຕໍ່ໄປນີ້:

1. ພັດທະນາ ແລະ ບຳລຸງຮັກສາແອັບພລິເຄຊັນໄດ້ງ່າຍຂຶ້ນເນື່ອງຈາກເຄື່ອງມື ແລະ ຄຸນສົມບັດໃນຕົວຂອງ Django.

2. ການແຍກຕັກກະທາງທຸລະກິດ ແລະ ຊັ້ນການນຳສະເໜີ ນຳໄປສູ່ໂຄ້ດທີ່ເປັນລະບຽບກວ່າ ແລະ ບຳລຸງຮັກສາງ່າຍກວ່າ.

3. ຄວາມສາມາດໃນການຂະຫຍາຍ ແລະ ຄວາມແຂງແກ່ນຂອງແອັບພລິເຄຊັນ.

4. ຄຸນສົມບັດຄວາມປອດໄພໃນຕົວທີ່ຊ່ວຍປົກປ້ອງແອັບພລິເຄຊັນຈາກການໂຈມຕີເວັບທົ່ວໄປ.

5. ເຂົ້າເຖິງຊຸມຊົນໃຫຍ່ ແລະ ຄຶກຄັກເພື່ອຂໍການສະໜັບສະໜູນ.

ພວກເຮົາເຂົ້າໃຈວ່າ Django ມີເສັ້ນໂຄ້ງການຮຽນຮູ້ທີ່ຊັນກວ່າເຟຣມເວີກອື່ນ ແຕ່ພວກເຮົາເຫັນວ່າຄຸ້ມຄ່າກັບການລົງທຶນສຳລັບຜົນປະໂຫຍດໄລຍະຍາວທີ່ມັນໃຫ້.

## ບົດສະຫຼຸບ

ອີງຕາມປັດໄຈທີ່ພິຈາລະນາ ພວກເຮົາໄດ້ຕັດສິນໃຈໃຊ້ເຟຣມເວີກເວັບ Django ສຳລັບການພັດທະນາເວັບແອັບພລິເຄຊັນ. ພວກເຮົາເຊື່ອວ່າຄຸນສົມບັດຂອງ Django, ການສະໜັບສະໜູນຈາກຊຸມຊົນ ແລະ ຄວາມສາມາດໃນການຂະຫຍາຍເຮັດໃຫ້ມັນເປັນທາງເລືອກທີ່ດີທີ່ສຸດສຳລັບການສ້າງເວັບແອັບພລິເຄຊັນທີ່ສົມບູນ. ພວກເຮົາຈະຝຶກອົບຮົມນັກພັດທະນາຂອງພວກເຮົາໃຫ້ໃຊ້ Django ເພື່ອຮັບປະກັນວ່າເຟຣມເວີກຖືກໃຊ້ຢ່າງມີປະສິດທິພາບ ແລະ ປະສິດທິຜົນ.
