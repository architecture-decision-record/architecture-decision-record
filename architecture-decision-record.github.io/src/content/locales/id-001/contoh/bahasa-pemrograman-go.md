## Konteks

Organisasi kami selama ini terutama menggunakan bahasa pemrograman Java untuk membangun aplikasi web. Namun, kami mengalami beberapa tantangan akibat kerumitan penulisan Java dan kompleksitas beberapa kerangka kerja. Selain itu, tim kami menunjukkan minat untuk menjajaki bahasa pemrograman modern demi pengembangan yang lebih efisien dan tangguh. Setelah melakukan riset, kami mengidentifikasi Go sebagai solusi potensial untuk masalah yang kami hadapi dengan Java.

## Keputusan

Kami akan mengadopsi bahasa pemrograman Go untuk membangun aplikasi web ke depannya.

## Alasan

1. **Kesederhanaan dan keterbacaan:** Go dikenal karena kesederhanaan dan sintaksisnya yang ringkas. Hal ini membuat kode mudah dibaca dan ditulis, mengurangi kompleksitas proses pengembangan kami.

2. **Kinerja tinggi dan skalabilitas:** Go dikompilasi menjadi kode mesin yang berjalan secara native di server. Hal ini menghasilkan waktu eksekusi yang lebih cepat dan kinerja yang lebih baik dibandingkan bahasa yang diinterpretasikan seperti Java. Selain itu, model konkurensi Go menangani banyak permintaan secara bersamaan, sehingga sangat skalabel.

3. **Dukungan komunitas yang kuat:** Go memiliki komunitas pengembang yang bersemangat yang telah berkontribusi pada pertumbuhannya selama bertahun-tahun. Ini berarti ada banyak sumber daya, pustaka, dan kerangka kerja untuk membantu kami memulai dan membangun aplikasi yang tangguh.

4. **Fleksibilitas:** Go dapat digunakan untuk pengembangan frontend maupun backend. Ini berarti kami dapat memanfaatkan keunggulannya di kedua area tersebut untuk proyek pengembangan kami.

## Implikasi

1. **Pelatihan:** Para pengembang kami perlu mengikuti pelatihan untuk mempelajari bahasa pemrograman Go dan seluk-beluknya.

2. **Pengalaman:**  Kami mungkin menghadapi beberapa tantangan saat bertransisi dari Java ke Go. Mungkin diperlukan waktu bagi para pengembang kami untuk mahir dengan bahasa baru ini.

3. **Perangkat:**  Kami perlu mengadopsi alat dan kerangka kerja baru yang khusus untuk Go. Namun, kami dapat memanfaatkan infrastruktur yang sudah ada untuk meminimalkan dampak perubahan ini.

4. **Ketergantungan pada vendor:**  Go adalah bahasa pemrograman sumber terbuka, dan kami tidak akan terikat pada vendor atau penyedia layanan mana pun.

## Kesimpulan

Adopsi bahasa pemrograman Go akan membantu kami meningkatkan proses pengembangan dan membangun aplikasi yang tangguh. Kami perlu menginvestasikan sumber daya untuk pelatihan dan alat guna mendukung transisi ini, tetapi kami yakin bahwa manfaat keputusan ini lebih besar daripada biayanya.
