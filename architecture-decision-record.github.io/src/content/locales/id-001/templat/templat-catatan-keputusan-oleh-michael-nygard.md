# Templat catatan keputusan oleh Michael Nygard

Ini adalah templat dalam [Documenting architecture decisions - Michael Nygard](http://thinkrelevance.com/blog/2011/11/15/documenting-architecture-decisions).
Anda dapat menggunakan [adr-tools](https://github.com/npryce/adr-tools) untuk mengelola file ADR.

Di setiap file ADR, tulis bagian-bagian berikut:

# Judul

## Status

Apa statusnya, seperti proposed, accepted, rejected, deprecated, superseded, dll.?

## Konteks

Apa isu yang kita lihat yang memotivasi keputusan atau perubahan ini?

## Keputusan

Apa perubahan yang kita usulkan dan/atau lakukan?

## Konsekuensi

Apa yang menjadi lebih mudah atau lebih sulit dilakukan karena perubahan ini?
