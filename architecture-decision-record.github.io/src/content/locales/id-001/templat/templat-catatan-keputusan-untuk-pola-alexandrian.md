# Templat catatan keputusan untuk pola Alexandrian

## Pendahuluan

* Prolog (Ringkasan)
* Diskusi (Konteks)
* Solusi (Keputusan)
* Konsekuensi (Hasil)

## Rincian ##

* Prolog (Ringkasan)
  * Pernyataan untuk meringkas:
    * Dalam konteks (kasus penggunaan)<br>
      menghadapi (kekhawatiran)<br>
      kami memutuskan untuk (opsi)<br>
      untuk mencapai (kualitas)<br>
      dengan menerima (kerugian).
* Diskusi (Konteks)
  * Menjelaskan kekuatan-kekuatan yang berperan (teknis, politik, sosial, proyek).
  * Ini adalah kisah yang menjelaskan masalah yang ingin kita selesaikan.
* Solusi
  * Menjelaskan bagaimana keputusan akan menyelesaikan masalah.
* Konsekuensi
  * Menjelaskan hasil keputusan dalam jangka panjang.
  * Apakah berhasil, tidak berhasil, diubah, ditingkatkan, dsb.
