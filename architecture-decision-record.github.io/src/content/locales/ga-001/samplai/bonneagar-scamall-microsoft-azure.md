# Taifead Cinnidh Ailtireachta: bonneagar scamall Microsoft Azure" 

Teideal an Chinnidh: Microsoft Azure a ghlacadh mar bhonneagar scamall dár n-eagraíocht

Cinnteoir: Príomhoifigeach Faisnéise

Dáta: 2021-10-15

Stádas: Formheasta

## Cúlra

Tá an eagraíocht ag pleanáil bogadh ó bhonneagar traidisiúnta ar fhoirgnimh go bonneagar scamall. Chun é seo a bhaint amach, rinne an eagraíocht meastóireacht ar sholáthraithe seirbhíse scamall iomadúla amhail Amazon Web Services (AWS), Google Cloud Platform (GCP), Microsoft Azure, agus IBM Cloud. Tá a tacar gnéithe, buntáistí, agus struchtúr praghsála féin ag gach soláthraí. Tar éis anailís mhionsonraithe, tháinig muid ar an gconclúid gurb é Microsoft Azure an rogha is oiriúnaí dár n-eagraíocht.

## Cinneadh

Microsoft Azure a ghlacadh mar bhonneagar scamall dár n-eagraíocht.

## Réasúnaíocht

Seo a leanas na cúiseanna le Microsoft Azure a ghlacadh:

1. Seirbhísí Cuimsitheacha: Soláthraíonn Azure raon iomlán seirbhísí scamall ó bhonneagar mar sheirbhís (IaaS) go bogearraí mar sheirbhís (SaaS) agus ardán mar sheirbhís (PaaS). Cuireann sé seo ar ár gcumas leas a bhaint as seirbhísí Azure chun riachtanais na heagraíochta a réiteach, amhail stóráil, ríomh, líonrú, agus anailísíocht.

2. Inscálaitheacht agus Solúbthacht: Le Azure, is féidir linn acmhainní a mhéadú nó a laghdú go héasca bunaithe ar riachtanais ár ngnó. Tairgeann Azure solúbthacht freisin maidir le córas oibriúcháin, teanga ríomhchlárúcháin, agus creataí a roghnú.

3. Slándáil agus Comhlíonadh: Tairgeann Azure leibhéal ard slándála agus comhlíonta, mar go bhfuil sé comhlíontach le roinnt caighdeán tionscail amhail ISO, SOC, HIPAA, agus PCI DSS. Soláthraíonn Azure gnéithe slándála casta freisin amhail grúpaí slándála líonra, balla dóiteáin, agus cosaint DDoS.

4. Scamall Hibrideach: Soláthraíonn Azure taithí scamall hibrideach gan uaim, rud a chuireann ar chumas eagraíochtaí a mbonneagar ar fhoirgnimh a nascadh le Azure. Fágann sé seo go bhfuil sé éasca dúinn ualaí oibre a aistriú go dtí an scamall agus tugann sé an tsolúbthacht dúinn a roghnú cá stórálfar sonraí.

5. Costéifeachtach: Tairgeann Azure múnla praghsála íoc-mar-a-úsáideann-tú, rud a chiallaíonn nach n-íocaimid ach as na hacmhainní a úsáidtear. Cabhraíonn sé seo linn costais a shábháil i gcomparáid le bonneagar traidisiúnta ar fhoirgnimh.

## Conclúid

Tá Microsoft Azure a ghlacadh mar bhonneagar scamall dár n-eagraíocht ag teacht le riachtanais ár ngnó agus tairgeann sé roinnt buntáistí amhail inscálaitheacht, solúbthacht, slándáil, agus costéifeachtúlacht. Dá bhrí sin, moltar Azure a ghlacadh mar ár mbonneagar scamall.
