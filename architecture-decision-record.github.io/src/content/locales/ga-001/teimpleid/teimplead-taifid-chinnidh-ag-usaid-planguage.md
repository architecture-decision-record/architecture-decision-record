# Teimpléad taifid chinnidh ag úsáid Planguage

Féach https://www.iaria.org/conferences2012/filesICCGI12/Tutorial%20Specifying%20Effective%20Non-func.pdf

## Cad is Planguage ann?

Is teanga phleanála é Planguage a úsáideann na heochairfhocail seo:

* Tag (Clib): Aitheantóir uathúil buan
* Gist (Eisint): Achoimre ghairid ar an riachtanas nó ar an réimse a bhfuil aghaidh á tabhairt air
* Requirement (Riachtanas): An téacs a thugann mionsonraí an riachtanais féin
* Rationale (Réasúnaíocht): An réasúnaíocht a thugann údar leis an riachtanas
* Priority (Tosaíocht): Ráiteas tosaíochta agus éileamh ar acmhainní
* Stakeholders (Geallsealbhóirí): Páirtithe a bhfuil tionchar ábhartha ag an riachtanas orthu
* Status (Stádas): Stádas an riachtanais (dréacht, athbhreithnithe, tiomanta, srl.)
* Owner (Úinéir): An duine atá freagrach as an riachtanas a chur i bhfeidhm
* Author (Údar): An duine a scríobh an riachtanas
* Revision (Athbhreithniú): Uimhir leagain don ráiteas
* Date (Dáta): Dáta an athbhreithnithe is deireanaí
* Assumptions (Toimhdí): Aon rud a d'fhéadfadh fadhbanna a chruthú mura bhfuil sé fíor anois nó níos déanaí
* Risks (Rioscaí): Aon rud a d'fhéadfadh mífheidhmiú, moill, nó tionchair dhiúltacha eile a chruthú
* Defined (Sainmhínithe): Sainmhíniú ar théarma (is fearr gluais a úsáid)
