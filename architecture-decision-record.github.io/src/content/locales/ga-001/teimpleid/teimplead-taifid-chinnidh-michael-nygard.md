# Teimpléad taifid chinnidh le Michael Nygard

Is é seo an teimpléad in [Documenting architecture decisions - Michael Nygard](http://thinkrelevance.com/blog/2011/11/15/documenting-architecture-decisions).
Is féidir leat [adr-tools](https://github.com/npryce/adr-tools) a úsáid chun comhaid ADR a bhainistiú.

I ngach comhad ADR, scríobh na hailt seo:

# Teideal

## Stádas

Cad é an stádas, amhail molta, glactha, diúltaithe, imithe i léig, curtha ina ionad, srl.?

## Comhthéacs

Cad é an tsaincheist atá le feiceáil againn atá ag spreagadh an chinnidh nó an athraithe seo?

## Cinneadh

Cad é an t-athrú atá á mholadh againn agus/nó á dhéanamh againn?

## Iarmhairtí

Cad a éiríonn níos éasca nó níos deacra a dhéanamh mar gheall ar an athrú seo?
