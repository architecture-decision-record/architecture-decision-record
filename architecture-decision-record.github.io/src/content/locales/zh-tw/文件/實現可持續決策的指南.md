# 實現可持續決策的指南

<https://www.infoq.com/articles/sustainable-architectural-design-decisions/>

我們在工作中總結了以下經驗教訓,可作為實現可持續決策的指南和評估依據:

1. 在最初的決策文件中採用精益/極簡的方法。

2. 對所有重要且值得記錄、有助於理解目標架構的決策進行優先順序排序並加以記錄。

3. 只有在初始工作完成之後(即決策者對所做的架構決策感到滿意,並確信這些決策短期內無需修訂),才使用完整的範本詳細記錄特別重要的決策。

4. 將第 1 步中的精益/極簡版本作為已記錄決策的簡短版本,以合適的粒度提供詳細決策的概覽,同時也用於記錄瑣碎或顯而易見的決策。

5. 儘可能利用現有的架構知識,無論來自指導模型還是其他來源。對這些知識進行評審和擴充套件,並使其適應具體決策的背景。

6. 確保在決策與需求之間,以及決策與架構設計/程式碼之間建立可追溯性連結。

7. 提供自動化一致性檢查,確保變更後可追溯性連結保持同步。限制決策之間以及決策與其他軟體製品之間的依賴數量。

8. 堅決而有力地應用關於論證的指南——它們是決策文件中最重要的部分,因為它們給出了理由。
