# 決策可持續性標準

<https://www.infoq.com/articles/sustainable-architectural-design-decisions/>

為了詳細定義決策的可持續性,我們歸納出五項關鍵標準。

## 戰略性

在制定決策時,關注戰略性後果的人應當考慮諸如決策的長期影響等事項,例如未來的運營和維護工作量。

## 可衡量且可管理

你可以根據客觀標準(最好是數值標準)隨時間推移來衡量和評估決策的結果(例如品質屬性場景和工作坊所倡導的方式)。不可能記錄所有細粒度的決策,因此架構師必須將決策的粒度限制在一定的細節層級(例如建立一個設計類)。這將帶來一組更具可持續性的決策,以及更少的可追溯性連結。此外,限制決策之間的依賴數量,可以減少變更的連鎖反應。

## 可實現且現實

使解決方案契合問題的理由應當務實地選擇並明確說明。例如,架構師可以表明他們已注意避免過度設計或設計不足(也就是說,應採用「夠用就好」的方法)。

## 植根於需求

決策應建立在特定領域的架構經驗和背景之上。它應考慮公司環境以及專案需求和約束,包括開發團隊當前的技能、培訓預算和流程。

## 持久不過時

決策應基於不會很快過時的經驗和知識。例如,架構師可以選擇與平臺無關的架構模式或策略。
