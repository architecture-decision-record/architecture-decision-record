# 架構決策記錄:Microsoft Azure 雲基礎設施

決策標題:採用 Microsoft Azure 作為我們組織的雲基礎設施

決策者:資訊長

日期:2021-10-15

狀態:已批准

## 背景

組織計劃從傳統的本地部署基礎設施遷移到雲基礎設施。為此,組織評估了多家雲服務提供商,例如 Amazon Web Services(AWS)、Google Cloud Platform(GCP)、Microsoft Azure 和 IBM Cloud。每家提供商都有自己的一套功能、優勢和定價結構。經過詳細分析,得出的結論是 Microsoft Azure 是最適合我們組織的選擇。

## 決策

採用 Microsoft Azure 作為我們組織的雲基礎設施。

## 理由

採用 Microsoft Azure 的理由如下:

1. 全面的服務:Azure 提供從基礎設施即服務(IaaS)到軟體即服務(SaaS)和平臺即服務(PaaS)的完整雲服務。這使我們能夠利用 Azure 服務來滿足組織的需求,例如儲存、計算、網路和分析。

2. 可擴充套件性和靈活性:藉助 Azure,我們可以根據業務需求輕鬆地擴大或縮小資源。Azure 在作業系統、程式語言和框架的選擇上也很靈活。

3. 安全性與合規性:Azure 提供高水平的安全性與合規性,因為它符合 ISO、SOC、HIPAA 和 PCI DSS 等多項行業標準。Azure 還提供網路安全組、防火牆和 DDoS 防護等高階安全功能。

4. 混合雲:Azure 提供無縫的混合雲體驗,使組織能夠將其本地基礎設施與 Azure 連線起來。這使我們能夠輕鬆地將工作負載遷移到雲端,併為我們選擇資料儲存位置提供了靈活性。

5. 經濟高效:Azure 提供按使用量付費的定價模式,這意味著我們只需為使用的資源付費。與傳統的本地部署基礎設施相比,這有助於我們節省成本。

## 結論

採用 Microsoft Azure 作為我們組織的雲基礎設施符合我們的業務需求,並帶來了可擴充套件性、靈活性、安全性和成本效益等諸多好處。因此,建議採用 Azure 作為我們的雲基礎設施。
