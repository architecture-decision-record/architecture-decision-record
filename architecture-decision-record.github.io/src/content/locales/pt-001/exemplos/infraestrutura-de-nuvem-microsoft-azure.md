# Registro de decisão de arquitetura: infraestrutura de nuvem Microsoft Azure

Título da decisão: adoção do Microsoft Azure como infraestrutura de nuvem da nossa organização

Responsável pela decisão: diretor de tecnologia da informação

Data: 2021-10-15

Estado: aprovado

## Contexto

A organização está planejando migrar da infraestrutura local tradicional para a infraestrutura de nuvem. Para isso, a organização avaliou vários provedores de serviços de nuvem, como Amazon Web Services (AWS), Google Cloud Platform (GCP), Microsoft Azure e IBM Cloud. Cada provedor tem seu próprio conjunto de recursos, benefícios e estrutura de preços. Após uma análise detalhada, concluiu-se que o Microsoft Azure é a opção mais adequada para a nossa organização.

## Decisão

Adotar o Microsoft Azure como infraestrutura de nuvem da nossa organização.

## Justificativa

Estes são os motivos para adotar o Microsoft Azure:

1. Serviços abrangentes: o Azure oferece uma gama completa de serviços de nuvem, de infraestrutura como serviço (IaaS) a software como serviço (SaaS) e plataforma como serviço (PaaS). Isso nos permite aproveitar os serviços do Azure para atender às necessidades da organização, como armazenamento, computação, rede e análise.

2. Escalabilidade e flexibilidade: com o Azure, podemos aumentar ou reduzir recursos com facilidade conforme as necessidades do negócio. O Azure também oferece flexibilidade na escolha do sistema operacional, da linguagem de programação e dos frameworks.

3. Segurança e conformidade: o Azure oferece um alto nível de segurança e conformidade, pois atende a diversos padrões do setor, como ISO, SOC, HIPAA e PCI DSS. O Azure também fornece recursos avançados de segurança, como grupos de segurança de rede, firewalls e proteção contra DDoS.

4. Nuvem híbrida: o Azure oferece uma experiência de nuvem híbrida contínua, permitindo que as organizações conectem sua infraestrutura local ao Azure. Isso facilita a migração de cargas de trabalho para a nuvem e nos dá flexibilidade para escolher onde armazenar os dados.

5. Custo-benefício: o Azure oferece um modelo de preços de pagamento conforme o uso, o que significa que pagamos apenas pelos recursos utilizados. Isso nos ajuda a economizar custos em comparação com a infraestrutura local tradicional.

## Conclusão

Adotar o Microsoft Azure como infraestrutura de nuvem da nossa organização se alinha aos nossos requisitos de negócio e oferece vários benefícios, como escalabilidade, flexibilidade, segurança e custo-benefício. Portanto, recomenda-se adotar o Azure como nossa infraestrutura de nuvem.
