# Registro delle decisioni architetturali: infrastruttura cloud con Microsoft Azure

Titolo della decisione: adozione di Microsoft Azure come infrastruttura cloud per la nostra organizzazione

Decisore: Chief Information Officer

Data: 2021-10-15

Stato: Approvato

## Contesto

L'organizzazione sta pianificando di migrare da un'infrastruttura on-premises tradizionale a un'infrastruttura cloud. Per raggiungere questo obiettivo, l'organizzazione ha valutato più fornitori di servizi cloud come Amazon Web Services (AWS), Google Cloud Platform (GCP), Microsoft Azure e IBM Cloud. Ogni fornitore ha il proprio insieme di funzionalità, vantaggi e struttura dei prezzi. Dopo un'analisi dettagliata, si è concluso che Microsoft Azure è l'opzione più adatta per la nostra organizzazione.

## Decisione

Adottare Microsoft Azure come infrastruttura cloud per la nostra organizzazione.

## Motivazione

Di seguito sono riportate le ragioni per adottare Microsoft Azure:

1. Servizi completi: Azure offre una gamma completa di servizi cloud, dall'infrastructure as a service (IaaS) al software as a service (SaaS) e al platform as a service (PaaS). Ciò ci permette di sfruttare i servizi Azure per risolvere i requisiti dell'organizzazione, come archiviazione, calcolo, rete e analisi.

2. Scalabilità e flessibilità: con Azure possiamo facilmente scalare le risorse verso l'alto o verso il basso in base alle esigenze aziendali. Azure offre anche flessibilità nella scelta del sistema operativo, del linguaggio di programmazione e dei framework.

3. Sicurezza e conformità: Azure offre un alto livello di sicurezza e conformità, poiché è conforme a diversi standard di settore come ISO, SOC, HIPAA e PCI DSS. Azure fornisce inoltre funzionalità di sicurezza avanzate come gruppi di sicurezza di rete, firewall e protezione DDoS.

4. Cloud ibrido: Azure offre un'esperienza di cloud ibrido fluida, che consente alle organizzazioni di collegare la propria infrastruttura on-premises ad Azure. Ciò ci rende facile migrare i carichi di lavoro nel cloud e ci dà la flessibilità di scegliere dove archiviare i dati.

5. Conveniente: Azure offre un modello di prezzo pay-as-you-go, il che significa che paghiamo solo per le risorse utilizzate. Ciò ci aiuta a risparmiare sui costi rispetto all'infrastruttura on-premises tradizionale.

## Conclusione

Adottare Microsoft Azure come infrastruttura cloud per la nostra organizzazione è in linea con i nostri requisiti aziendali e offre diversi vantaggi come scalabilità, flessibilità, sicurezza e convenienza. Pertanto, si raccomanda di adottare Azure come nostra infrastruttura cloud.
