# Registro delle decisioni architetturali: linguaggio di programmazione Java

Titolo: scelta del linguaggio di programmazione Java per il progetto

Decisione: dopo aver valutato più linguaggi di programmazione, abbiamo deciso di usare Java per il nostro progetto.

### Contesto

Intendevamo costruire un'applicazione basata sul web che potesse girare su più sistemi operativi. Il nostro progetto richiedeva un linguaggio in grado di offrire solide funzionalità di sicurezza, gestire la concorrenza, supportare grandi basi di codice ed essere abbastanza versatile da soddisfare i nostri requisiti di crescita futuri. Abbiamo valutato diversi linguaggi, considerandone punti di forza e limiti, prima di decidere per Java.

### Considerazioni

1. **Sicurezza:**  Java offre eccellenti funzionalità di sicurezza grazie a politiche di sicurezza ben definite e al controllo degli accessi. Incorpora anche funzionalità come la verifica del bytecode, che aiuta a impedire l'esecuzione di software dannoso su un sistema.

2. **Concorrenza:**  Java ha supporto integrato per il multithreading, che consente alle applicazioni di eseguire più attività contemporaneamente. Questa caratteristica rende Java un'ottima scelta per sviluppare applicazioni grandi e complesse con molte funzionalità.

3. **Grandi basi di codice:**  Java supporta la programmazione orientata agli oggetti, il che lo rende una scelta adatta per sviluppare grandi basi di codice. La sua natura modulare e l'uso di pattern di incapsulamento e astrazione contribuiscono ulteriormente alla facilità del processo di sviluppo software.

4. **Versatilità:**  Java è versatile e offre la possibilità di usare un'ampia gamma di librerie e framework, rendendolo un'ottima scelta sia per applicazioni basate sul web sia per applicazioni di livello enterprise.

### Esito della decisione

Abbiamo deciso di usare il linguaggio di programmazione Java per il nostro progetto, considerando le sue funzionalità di sicurezza, il supporto alla concorrenza, la capacità di gestire grandi basi di codice e la versatilità. Questa decisione è in linea con i requisiti del nostro progetto e crediamo che scegliere Java ne garantirà il successo. 

### Conseguenze

1. Avremo bisogno di sviluppatori che abbiano esperienza con Java e sappiano usarlo con competenza.

2. Qualsiasi codice scritto nel linguaggio deve essere compatibile con la Java Virtual Machine (JVM).

3. Incorporare nuove funzionalità, funzioni o framework potrebbe presentare alcune difficoltà.

4. Progetti grandi e complessi in Java possono richiedere più tempo e risorse per essere sviluppati.
