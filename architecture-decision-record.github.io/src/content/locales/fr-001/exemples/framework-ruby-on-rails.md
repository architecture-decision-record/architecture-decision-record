# Enregistrement de décision d’architecture : framework Ruby on Rails

## Contexte

- L’organisation développe une application web dotée d’une logique métier complexe et de multiples intégrations avec des services tiers.

- L’équipe a de l’expérience dans la construction d’applications web avec Ruby on Rails.

- Il faut choisir un framework web qui favorise le développement rapide, l’évolutivité et la maintenabilité.

## Décision

- Utiliser Ruby on Rails comme framework pour développer l’application web.

## Justification

- Ruby on Rails est un framework web mature, stable et largement adopté, qui a prouvé son efficacité dans la construction d’applications web complexes.

- Le framework suit le patron d’architecture Modèle-Vue-Contrôleur (MVC), qui favorise la séparation des préoccupations et améliore la réutilisabilité et la maintenabilité du code.

- Rails fournit de nombreuses fonctionnalités intégrées, comme ActiveRecord pour les interactions avec la base de données et ActionMailer pour la gestion du courrier électronique, qui peuvent faire gagner du temps de développement et simplifier le code.

- Le framework dispose d’une communauté vaste et active, avec de nombreux modules et plugins réutilisables disponibles pour améliorer les fonctionnalités et résoudre les problèmes courants.

- Ruby on Rails prend en charge le développement piloté par les tests (TDD) et le développement piloté par le comportement (BDD), ce qui permet aux développeurs d’écrire des tests automatisés pour leur code, en garantissant qu’il fonctionne comme prévu et en réduisant les bogues et les régressions.

- Ruby est un langage de haut niveau qui favorise la productivité des développeurs et la lisibilité du code, et qui sert de puissant langage « colle » pour l’intégration avec un large éventail de services et d’API tiers.

## Conséquences

- L’équipe doit veiller à ce que l’architecture et la conception de l’application web suivent les conventions et les bonnes pratiques de Rails afin de maximiser les avantages du framework.

- Les développeurs doivent bien comprendre le langage Ruby et le framework Rails, même si la documentation et la communauté de Rails peuvent fournir conseils et soutien.

- Il peut y avoir une courbe d’apprentissage pour les développeurs nouveaux dans Ruby et Rails, même si les avantages du framework peuvent justifier l’investissement dans la formation et l’intégration.

- L’équipe doit surveiller la performance et l’évolutivité de l’application, et il pourra être nécessaire d’affiner les requêtes de base de données et d’optimiser la mise en cache pour traiter de grandes quantités de données et de trafic.
