# アレクサンドリアン・パターンのための決定記録テンプレート

## はじめに

* プロローグ(要約)
* 議論(コンテキスト)
* 解決策(決定)
* 結果(成果)

## 詳細 ##

* プロローグ(要約)
  * 要約するための記述:
    * (ユースケース)の文脈で<br>
      (懸念)に直面し、<br>
      (品質)を達成するために<br>
      (欠点)を受け入れて<br>
      (選択肢)に決定した。
* 議論(コンテキスト)
  * 作用している力(技術的、政治的、社会的、プロジェクト上)を説明します。
  * これは、私たちが解決しようとしている問題を説明する物語です。
* 解決策
  * 決定がどのように問題を解決するかを説明します。
* 結果
  * 長期にわたる決定の結果を説明します。
  * うまくいったか、いかなかったか、変更された、アップグレードされたなど。
