# Michael Nygard による決定記録テンプレート

これは [Documenting architecture decisions - Michael Nygard](http://thinkrelevance.com/blog/2011/11/15/documenting-architecture-decisions) のテンプレートです。
ADR ファイルの管理には [adr-tools](https://github.com/npryce/adr-tools) を使用できます。

各 ADR ファイルに、次のセクションを書きます:

# タイトル

## 状態

状態は何ですか。たとえば proposed、accepted、rejected、deprecated、superseded など。

## コンテキスト

この決定または変更を動機づけている、私たちが目にしている課題は何ですか?

## 決定

私たちが提案している、および/または行っている変更は何ですか?

## 結果

この変更によって、何が容易になり、または困難になりますか?
