# 持続可能な意思決定を実現するためのガイドライン

<https://www.infoq.com/articles/sustainable-architectural-design-decisions/>

私たちの作業で得られた次の教訓は、持続可能な決定を実現するためのガイドラインおよび評価として役立ちます:

1. 最初の意思決定の文書化には、リーン/ミニマルなアプローチを使用する。

2. ターゲットアーキテクチャを文書化し理解するのに十分関連性のある、すべての重要な決定に優先順位を付けて記録する。

3. 特に重要な決定は、最初の作業が完了した後(つまり、意思決定者が下したアーキテクチャ上の決定に満足し、それらの決定がすぐには見直す必要がないと確信した時点)で、本格的なテンプレートを用いて詳細化する。

4. ステップ 1 のリーン/ミニマルな版を、詳細な決定の概要を示すため、また自明または些細な決定のために、適切な粒度レベルの文書化された決定の短縮版として使用する。

5. 可能な限り、ガイダンスモデルまたはその他の情報源からの既存のアーキテクチャ知識を使用する。そのような知識をレビューして拡張し、特定の決定のコンテキストに適合させる。

6. 決定と、要件およびアーキテクチャ設計/コードの両方との間に、トレーサビリティリンクを確立する。 

7. 変更後にトレーサビリティリンクが同期していることを確認するため、自動整合性チェックを提供する。決定とその他のソフトウェア成果物との間の依存関係の数を制限する。

8. 正当化に関するガイドラインを一貫して強力に適用する。それらは根拠を与えるため、決定の文書化の中で最も重要な部分である。
