## Zdôvodnenie

Python je univerzálny programovací jazyk, ktorý sa široko používa v oblastiach analýzy dát, strojového učenia a webového
vývoja. Je to interpretovaný jazyk, čo znamená, že sa nemusí kompilovať, a má ľahko čitateľnú a zrozumiteľnú syntax. Medzi ďalšie dôležité faktory nášho rozhodnutia patria tieto:

1. **Dostupnosť knižníc:** Python má obrovskú zbierku knižníc a frameworkov, ako sú NumPy, Pandas a Scikit-learn, čo vývojárom uľahčuje implementáciu algoritmov strojového učenia a analýzu dát.

2. **Podpora komunity:** Python má veľkú a aktívnu komunitu vývojárov, ktorí prispievajú k jeho vývoju a poskytujú podporu a usmernenia na rôznych fórach a webových stránkach. To začiatočníkom uľahčuje nájsť pomoc a naučiť sa jazyk.

3. **Škálovateľnosť:** Python je škálovateľný, čo znamená, že zvládne veľké súbory dát a zložité aplikácie. Dá sa tiež použiť na rýchle prototypovanie alebo budovanie malých aplikácií s minimálnym úsilím, čo nám uľahčuje začať projekt a rýchlo iterovať.

4. **Flexibilita:** Python sa dá použiť na rôzne typy projektov vrátane webového vývoja, vedeckých výpočtov, strojového učenia atď. Je tiež kompatibilný s inými programovacími jazykmi, ako sú Java a C++, čo uľahčuje integráciu s inými systémami.

## Dôsledky

Používanie Pythonu ako nášho programovacieho jazyka má niektoré potenciálne dôsledky, napríklad:

1. **Výkon:** Python môže byť pomalší než kompilované jazyky ako C++ pri vykonávaní určitých algoritmov, ale to sa dá zmierniť použitím optimalizovaných knižníc alebo napísaním kritického kódu v C++ a jeho prepojením s Pythonom.

2. **Krivka učenia:** Hoci má Python ľahko naučiteľnú syntax, môže byť náročné naučiť sa osvedčené postupy písania efektívneho a škálovateľného kódu. To sa dá prekonať dodržiavaním konvencií, používaním frameworkov a knižníc a vyhľadávaním rád od skúsených vývojárov.

3. **Kompatibilita verzií:** Rôzne verzie Pythonu môžu mať odlišnú syntax a schopnosti, čo môže sťažiť údržbu a aktualizáciu projektov. Je dôležité zvoliť verziu Pythonu, ktorá je široko podporovaná a kompatibilná s požiadavkami nášho projektu.
