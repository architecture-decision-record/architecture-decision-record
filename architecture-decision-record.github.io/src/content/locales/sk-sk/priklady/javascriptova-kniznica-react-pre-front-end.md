# Záznam architektonického rozhodnutia: front-endová JavaScriptová knižnica React

## Kontext

Musíme pre našu aplikáciu zvoliť front-endovú JavaScriptovú knižnicu, aby sme vyvinuli responzívne a interaktívne používateľské rozhranie.
  
## Zvažované možnosti

1. React
  
2. Vue

3. Svelte
   
## Rozhodnutie

Ako našu front-endovú JavaScriptovú knižnicu použijeme React.
  
## Zdôvodnenie

1. **Komponentová architektúra:**  React poskytuje komponentovú architektúru, ktorá nám umožňuje rozdeliť UI na malé opakovane použiteľné komponenty. To pomáha zlepšiť modularitu nášho kódu a uľahčuje údržbu, škálovanie a aktualizáciu aplikácie.
  
2. **Deklaratívne programovanie:**  React používa deklaratívny štýl programovania, vďaka ktorému je náš kód intuitívnejší a ľahšie čitateľný. Poskytuje tiež virtuálny DOM, ktorý umožňuje, aby náš kód bežal rýchlejšie a efektívnejšie.
  
3. **Veľká komunita:**  React má veľkú a aktívnu komunitu a je jednou z najpopulárnejších front-endových knižníc. To znamená, že je k dispozícii množstvo zdrojov, nástrojov a knižníc, ktoré nám môžu pomôcť vyvinúť aplikáciu rýchlejšie a efektívnejšie.
  
4. **Lepší výkon:**  React používa jednosmerný tok dát, ktorý pomáha zjednodušiť logiku aplikácie a robí ju efektívnejšou. Poskytuje tiež vykresľovanie na strane servera, ktoré pomáha zlepšiť výkon a SEO našej aplikácie.
  
5. **Flexibilita:**  React sa dá používať s inými knižnicami a frameworkmi, čo nám dáva slobodu zvoliť najlepší technologický stack, ktorý vyhovuje požiadavkám nášho projektu.
  
## Dôsledky

1. **Krivka učenia:**  React má krivku učenia a vývojárom, ktorí sú v Reacte noví, môže chvíľu trvať, kým sa zorientujú.
  
2. **Nástroje na zostavenie:**  React vyžaduje dodatočné nástroje na zostavenie, ako sú Babel a Webpack, čo môže do vývojového procesu priniesť zložitosť.
  
3. **Kompatibilita s prehliadačmi:**  React má problémy s kompatibilitou so staršími prehliadačmi, pretože používa funkcie ES6, ktoré staršie prehliadače nepodporujú.
  
 4. Strmá krivka učenia: Vývojárom, ktorí Reactu nerozumejú, môže trvať, kým sa naučia, ako ho efektívne používať, čo môže viesť k pomalšiemu vývoju.

## Záver

Rozhodli sme sa použiť React ako front-endovú JavaScriptovú knižnicu našej aplikácie. Hoci môže mať krivku učenia, prínosy, ktoré React poskytuje, ako sú komponentová architektúra, deklaratívny štýl programovania, lepší výkon, flexibilita a veľká komunita, prevažujú nad potenciálnymi nevýhodami.
