# Záznam architektonického rozhodnutia: Tailwind CSS

Rozhodnutie: Použiť Tailwind CSS ako CSS framework na štylizovanie používateľského rozhrania.

## Čo je Tailwind CSS?

Tailwind je utility-first CSS framework, ktorý umožňuje rýchly vývoj a prispôsobenie používateľských rozhraní. Je navrhnutý tak, aby bol vysoko prispôsobiteľný a umožňuje vývojárom písať štíhlejší a efektívnejší CSS. Tento framework poskytuje súbor preddefinovaných tried na veľmi rýchle štylizovanie UI.

## Kontext

Budujeme webovú aplikáciu pre klienta, ktorá vyžaduje responzívne a prispôsobiteľné používateľské rozhranie. Klient požiadal o konzistentné a moderné štylizovanie. Vývojový tím má skúsenosti s používaním vlastného CSS, ale chce preskúmať CSS frameworky, ktoré môžu ušetriť čas a úsilie. Hľadáme framework, ktorý je ľahko použiteľný, prispôsobiteľný a má veľkú komunitu na podporu.

## Hnacie sily rozhodnutia

- **Jednoduchý na používanie:**  Chceme framework, ktorý sa jednoducho učí a dá sa integrovať do nášho vývojového pracovného postupu.

- **Prispôsobiteľný:**  Chceme framework, ktorý sa dá prispôsobiť pokynom značky a téme klienta.

- **Podpora veľkej komunity:**  Chceme framework, ktorý má aktívnu komunitu vývojárov a dizajnérov, ktorí môžu v prípade potreby poskytnúť pomoc a zdroje.

- **Úspora času:**  Chceme framework, ktorý môže ušetriť čas a úsilie pri štylizovaní UI.

## Zvažované možnosti

- **Bootstrap:**  Populárny CSS framework s množstvom vopred pripravených komponentov a veľkou komunitou vývojárov.

- **Foundation:**  Ďalší populárny CSS framework, ktorý bol navrhnutý pre vývoj s prioritou mobilných zariadení.

- **Materialize:**  CSS framework založený na jazyku dizajnu Material Design od Googlu s vopred pripravenými komponentmi na vývoj UI.

- **Tailwind CSS:**  Utility-first CSS framework so zameraním na prispôsobenie a efektivitu.

## Výsledok rozhodnutia

Po zvážení možností sme sa rozhodli použiť Tailwind CSS z týchto dôvodov:

- **Jednoduchý na používanie:**  Prístup Tailwindu je jednoduchý a ľahko zrozumiteľný. Jeho utility triedy urýchľujú budovanie UI.

- **Prispôsobiteľný:**  Tailwind umožňuje prispôsobenie poskytnutím sady konfiguračných súborov, ktoré vývojárom umožňujú ľahko upraviť predvolené štýly frameworku.

- **Podpora veľkej komunity:**  Tailwind má veľmi aktívnu komunitu vývojárov a dizajnérov, ktorí neustále vytvárajú nové zdroje, zásuvné moduly a nástroje.

- **Úspora času:**  Tailwind môže ušetriť čas, čo vývojárom umožňuje sústrediť sa na iné oblasti projektu.

Na vybudovanie UI nášho projektu použijeme utility triedy Tailwind CSS. Vývojový tím využije jeho atómový a modulárny dizajnový systém na písanie efektívneho a škálovateľného CSS kódu. Využijeme vopred pripravené šablóny a vizuálne komponenty Tailwindu na urýchlenie vývojového procesu a zároveň použijeme vlastné štýly, aby zodpovedali značke a téme klienta.
