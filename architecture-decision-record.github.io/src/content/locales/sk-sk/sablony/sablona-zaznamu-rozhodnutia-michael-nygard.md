# Šablóna záznamu rozhodnutia od Michaela Nygarda

Toto je šablóna z [Documenting architecture decisions - Michael Nygard](http://thinkrelevance.com/blog/2011/11/15/documenting-architecture-decisions).
Na správu súborov ADR môžete použiť [adr-tools](https://github.com/npryce/adr-tools).

Do každého súboru ADR napíšte tieto sekcie:

# Názov

## Stav

Aký je stav, napríklad navrhnuté, prijaté, zamietnuté, zastarané, nahradené atď.?

## Kontext

Aký je problém, ktorý vidíme a ktorý motivuje toto rozhodnutie alebo zmenu?

## Rozhodnutie

Akú zmenu navrhujeme a/alebo robíme?

## Dôsledky

Čo sa vďaka tejto zmene stane ľahším alebo ťažším?
