# Clàr co-dhùnaidh ailtireachd: Cànan prògramachaidh Java

Tiotal: Cànan prògramachaidh Java a thaghadh don phròiseact

Co-dhùnadh: Às dèidh measadh a dhèanamh air grunn chànanan prògramachaidh, chuir sinn romhainn Java a chleachdadh airson ar pròiseact.

### Cùl-fhiosrachadh

Bha sinn an dùil aplacaid stèidhichte air an lìon a thogail as urrainn ruith air grunn shiostaman obrachaidh. Dh’fheumadh am pròiseact againn cànan a bheireadh feartan tèarainteachd làidir, a làimhsicheadh co-aontachd, a bheireadh taic do bhonnan còd mòra, agus a bhiodh iol-chleachdaidh gu leòr gus coinneachadh ri ar riatanasan fàis san àm ri teachd. Rinn sinn measadh air grunn chànanan, a’ beachdachadh air na neartan is cuingeadan aca, mus do chuir sinn romhainn Java.

### Beachdachaidhean

1. **Tèarainteachd:**  Bheir Java feartan tèarainteachd sàr-mhath tro na poileasaidhean tèarainteachd agus smachd ruigsinneachd a tha air am mìneachadh gu math. Tha e cuideachd a’ gabhail a-steach feartan leithid dearbhadh bytecode, a chuidicheas le bhith a’ casg bathar-bog droch-rùnach bho bhith ag ruith air siostam.

2. **Co-aontachd:**  Tha taic togte a-staigh aig Java airson multithreading, a leigeas le aplacaidean grunn dhleastanasan a dhèanamh aig an aon àm. Tha am feart seo a’ dèanamh Java na roghainn sàr-mhath airson aplacaidean mòra, toinnte le iomadh feart is gnìomhachd a leasachadh.

3. **Bonnan còd mòra:**  Bheir Java taic do phrògramachadh stèidhichte air oibseactan, a tha ga dhèanamh na roghainn freagarrach airson bonnan còd mòra a leasachadh. Tha a nàdar modalach agus cleachdadh phàtranan encapsulation is eas-tharraing a’ cur nas motha ri furasta pròiseas leasachadh bathar-bog.

4. **Iol-chleachdadh:**  Tha Java iol-chleachdaidh agus bheir e comas raon farsaing de leabharlannan agus frèamaichean a chleachdadh, a tha ga dhèanamh na roghainn sàr-mhath airson aplacaidean stèidhichte air an lìon agus aig ìre iomairt.

### Toradh a’ cho-dhùnaidh

Chuir sinn romhainn an cànan prògramachaidh Java a chleachdadh airson ar pròiseact, a’ beachdachadh air na feartan tèarainteachd aige, taic co-aontachd, comas bonnan còd mòra a làimhseachadh, agus iol-chleachdadh. Tha an co-dhùnadh seo a’ freagairt ri riatanasan ar pròiseict, agus tha sinn a’ creidsinn gun dèan taghadh Java cinnteach à soirbheachas. 

### Builean

1. Bidh feum againn air luchd-leasachaidh aig a bheil eòlas air Java agus as urrainn a chleachdadh gu comasach.

2. Feumaidh còd sam bith a sgrìobhar sa chànan a bhith co-chòrdail ris an Java Virtual Machine (JVM).

3. Dh’fhaodadh gun cuir toirt a-steach fheartan, ghnìomhachdan, no fhrèamaichean ùra cuid de dhùbhlain.

4. Dh’fhaodadh gum feum pròiseactan mòra, toinnte ann an Java barrachd ùine is ghoireasan airson an leasachadh.
