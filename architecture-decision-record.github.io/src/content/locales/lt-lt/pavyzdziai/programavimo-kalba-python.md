# Architektūros sprendimo įrašas: programavimo kalba Python

## Kontekstas

Turime nuspręsti, ar savo projektui naudoti Python kaip programavimo kalbą. Mūsų projektas apima duomenų analizę, mašininį mokymąsi ir interneto programų kūrimą.

## Sprendimas

Nusprendėme savo projektui kaip pagrindinę programavimo kalbą naudoti Python.

## Pagrindimas

Python yra universali programavimo kalba, plačiai naudojama duomenų analizės, mašininio mokymosi ir interneto programų kūrimo srityse. Tai interpretuojama kalba, o tai reiškia, kad jos nereikia kompiliuoti, ir ji turi lengvai skaitomą bei suprantamą sintaksę. Kiti svarbūs mūsų sprendimo veiksniai yra šie:

1. **Bibliotekų prieinamumas:** Python turi didžiulį bibliotekų ir karkasų rinkinį, pavyzdžiui, NumPy, Pandas ir Scikit-learn, todėl programuotojams lengviau įgyvendinti mašininio mokymosi algoritmus ir duomenų analizę.

2. **Bendruomenės parama:** Python turi didelę ir aktyvią programuotojų bendruomenę, kuri prisideda prie jos kūrimo ir teikia paramą bei patarimus įvairiuose forumuose ir svetainėse. Tai pradedantiesiems palengvina rasti pagalbos ir išmokti kalbą.

3. **Mastelio keitimas:** Python keičia mastelį, o tai reiškia, kad ji gali tvarkyti didelius duomenų rinkinius ir sudėtingas programas. Ją taip pat galima naudoti greitam prototipų kūrimui ar mažoms programoms kurti minimaliomis pastangomis, todėl mums lengviau pradėti projektą ir greitai iteruoti.

4. **Lankstumas:** Python galima naudoti įvairių tipų projektams, įskaitant interneto programų kūrimą, mokslinius skaičiavimus, mašininį mokymąsi ir kt. Ji taip pat suderinama su kitomis programavimo kalbomis, pavyzdžiui, Java ir C++, todėl lengviau integruoti su kitomis sistemomis.

## Pasekmės

Naudojant Python kaip programavimo kalbą, gali būti tam tikrų pasekmių, pavyzdžiui:

1. **Našumas:** Python gali būti lėtesnė nei kompiliuojamos kalbos, pavyzdžiui, C++, vykdant tam tikrus algoritmus, tačiau tai galima sušvelninti naudojant optimizuotas bibliotekas arba rašant kritinį kodą C++ ir sąveikaujant su juo per Python.

2. **Mokymosi kreivė:** nors Python turi lengvai išmokstamą sintaksę, gali būti sunku išmokti geriausias efektyvaus ir keičiamo mastelio kodo rašymo praktikas. Tai galima įveikti laikantis konvencijų, naudojant karkasus ir bibliotekas bei kreipiantis patarimo į patyrusius programuotojus.

3. **Versijų suderinamumas:** skirtingos Python versijos gali turėti skirtingą sintaksę ir galimybes, o tai gali apsunkinti projektų priežiūrą ir atnaujinimą. Svarbu pasirinkti Python versiją, kuri būtų plačiai palaikoma ir suderinama su mūsų projekto reikalavimais.
