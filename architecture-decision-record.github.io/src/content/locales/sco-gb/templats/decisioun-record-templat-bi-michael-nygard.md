# Decisioun record templat bi Michael Nygard

This is the templat in [Documenting architecture decisions - Michael Nygard](http://thinkrelevance.com/blog/2011/11/15/documenting-architecture-decisions).
Ye can uise [adr-tools](https://github.com/npryce/adr-tools) for managin the ADR files.

In each ADR file, scrieve thir sections:

# Title

## Status

Whit is the status, sic as proposed, accepted, rejected, deprecated, superseded, etc.?

## Context

Whit is the issue that we're seein that is motivatin this decisioun or chynge?

## Decision

Whit is the chynge that we're proposin and/or daein?

## Consequences

Whit becomes easier or mair dreich tae dae acause o this chynge?
