# Decisioun record templat uisin Planguage

See https://www.iaria.org/conferences2012/filesICCGI12/Tutorial%20Specifying%20Effective%20Non-func.pdf

## Whit is Planguage?

Planguage is a plannin leid that uises thir keywirds:

* Tag: A unique, persistent identifier
* Gist: A brief summary o the requirement or area addressed
* Requirement: The text that details the requirement itsel
* Rationale: The reasonin that justifies the requirement
* Priority: A statement o priority an claim on resources
* Stakeholders: Pairties materially affectit bi the requirement
* Status: The status o the requirement (draft, reviewed, committed, etc.)
* Owner: The person responsible for implementin the requirement
* Author: The person that wrate the requirement
* Revision: A version nummer for the statement
* Date: The date o the maist recent revision
* Assumptions: Onie thing that could cause problems if untrue noo or efter
* Risks: Onie thing that could cause malfunction, delay, or ither negative impacts
* Defined: The definition o a term (better tae uise a glossary)
