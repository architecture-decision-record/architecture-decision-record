# Arkitektúrákvörðunarskrá um Amazon Web Services

Titill: Að taka upp Amazon Web Services fyrir skýjainnviði

## Ákvörðun

Eftir ítarlegt mat á ýmsum skýjainnviðavettvangum hefur verið ákveðið að stofnun okkar taki upp Amazon Web Services (AWS) fyrir þarfir sínar í skýjainnviðum.

## Bakgrunnur

Stofnun okkar vex hratt og við þurfum áreiðanlega og stigstærða skýjainnviði til að mæta kröfum starfseminnar. Eftir að hafa skoðað fjölda veitenda skýjainnviða var niðurstaðan sú að AWS bjóði upp á hentugasta úrval þjónustu til að mæta núverandi og framtíðarkröfum okkar.

## Sjónarmið

Fjöldi veitenda skýjainnviða á markaðnum hefur sannað sig sem áreiðanlegur og skilvirkur. AWS býður hins vegar ekki aðeins upp á alhliða safn þjónustu sem mætir þörfum okkar, heldur hefur einnig breiðan viðskiptavinahóp og sögu árangursríkra innleiðinga. AWS veitir einnig fjölbreytt úrval stuðnings- og þjálfunarefnis til að tryggja að teymi okkar geti unnið á skilvirkan hátt með vettvanginn.

Þar að auki hefur AWS umfangsmikla alþjóðlega viðveru með gagnaver á ýmsum svæðum um allan heim. Þetta tryggir að gögn okkar séu örugg og að forrit okkar og þjónustur verði mjög aðgengileg. AWS hefur einnig öflugan öryggisramma sem er mikilvægur fyrir starfsemi okkar.

Að lokum býður AWS upp á greiðslulíkan þar sem greitt er fyrir notkun, sem veitir okkur sveigjanleika til að stækka innviði okkar eftir eftirspurn. Þetta þýðir að við greiðum aðeins fyrir það sem við notum, sem gerir okkur kleift að hámarka kostnað og fjárfesta á öðrum sviðum starfseminnar.

## Ákvörðun

Á grundvelli þess mats sem framkvæmt var og kosta AWS hefur verið ákveðið að AWS verði tekið upp fyrir þarfir okkar í skýjainnviðum.

## Afleiðingar

Innleiðing AWS gæti krafist þjálfunar fyrir teymi okkar til að tryggja að þau þekki vettvanginn og geti nýtt hann á skilvirkan hátt. Einnig gæti fallið til einhver upphafskostnaður við að flytja núverandi innviði okkar yfir á AWS-vettvanginn.

## Eignarhald

Ábyrgð á skilvirkri nýtingu AWS og stýringu tengdrar áhættu verður á könnu skýjainnviðateymisins. Öll vandamál sem koma upp verða að vera meðhöndluð af því teymi.

## Endurskoðun

Ákvörðunin um að taka upp AWS verður endurskoðuð árlega til að tryggja að hún haldi áfram að mæta þörfum okkar og að ávinningur vettvangsins sé nýttur til fulls.
