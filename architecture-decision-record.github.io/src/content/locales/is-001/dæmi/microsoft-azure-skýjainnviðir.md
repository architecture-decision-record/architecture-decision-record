# Arkitektúrákvörðunarskrá: Microsoft Azure skýjainnviðir" 

Titill ákvörðunar: Að taka upp Microsoft Azure sem skýjainnviði stofnunarinnar

Ákvörðunaraðili: Upplýsingatæknistjóri

Dagsetning: 2021-10-15

Staða: Samþykkt

## Bakgrunnur

Stofnunin áformar að flytja úr hefðbundnum innviðum á staðnum yfir í skýjainnviði. Til að ná því hefur stofnunin metið marga skýjaþjónustuveitendur eins og Amazon Web Services (AWS), Google Cloud Platform (GCP), Microsoft Azure og IBM Cloud. Hver veitandi hefur sitt eigið safn eiginleika, kosta og verðskipan. Eftir ítarlega greiningu var niðurstaðan sú að Microsoft Azure sé hentugasti kosturinn fyrir stofnun okkar.

## Ákvörðun

Taka upp Microsoft Azure sem skýjainnviði stofnunarinnar.

## Rökstuðningur

Eftirfarandi eru ástæður fyrir því að taka upp Microsoft Azure:

1. Alhliða þjónusta: Azure býður upp á fullt úrval skýjaþjónustu frá innviðum sem þjónustu (IaaS) til hugbúnaðar sem þjónustu (SaaS) og vettvangs sem þjónustu (PaaS). Þetta gerir okkur kleift að nýta Azure-þjónustur til að mæta kröfum stofnunarinnar, svo sem geymslu, útreikninga, netkerfi og greiningar.

2. Stigstærð og sveigjanleiki: Með Azure getum við auðveldlega stækkað eða minnkað auðlindir eftir viðskiptakröfum okkar. Azure býður einnig upp á sveigjanleika í vali á stýrikerfi, forritunarmáli og römmum.

3. Öryggi og fylgni: Azure býður upp á mikið öryggi og fylgni, þar sem það uppfyllir nokkra iðnaðarstaðla eins og ISO, SOC, HIPAA og PCI DSS. Azure veitir einnig háþróaða öryggiseiginleika eins og netöryggishópa, eldveggi og DDoS-vörn.

4. Blandað ský: Azure veitir snurðulausa upplifun af blönduðu skýi, sem gerir stofnunum kleift að tengja innviði sína á staðnum við Azure. Þetta gerir okkur auðvelt að flytja vinnuálag yfir í skýið og veitir okkur sveigjanleika til að velja hvar við geymum gögn.

5. Hagkvæmt: Azure býður upp á verðlíkan þar sem greitt er fyrir notkun, sem þýðir að við greiðum aðeins fyrir auðlindirnar sem notaðar eru. Þetta hjálpar okkur að spara kostnað samanborið við hefðbundna innviði á staðnum.

## Niðurstaða

Að taka upp Microsoft Azure sem skýjainnviði stofnunarinnar samræmist viðskiptakröfum okkar og býður upp á nokkurn ávinning eins og stigstærð, sveigjanleika, öryggi og hagkvæmni. Því er mælt með því að taka upp Azure sem skýjainnviði okkar.
