# رکورد تصمیم معماری: کتابخانهٔ جاوااسکریپت فرانت‌اند Svelte

وضعیت: پذیرفته‌شده

## زمینه

در حال توسعهٔ یک برنامهٔ وب با استفاده از یک چارچوب جاوااسکریپت فرانت‌اند مدرن هستیم. می‌خواهیم کتابخانه‌ای انتخاب کنیم که سبک، سریع و آسان برای استفاده باشد. چندین کتابخانه از جمله React، Vue و Angular را ارزیابی کرده‌ایم. همچنین دربارهٔ Svelte شنیده‌ایم که ادعا می‌کند نوع جدیدی از چارچوب سبک است. باید Svelte را ارزیابی کنیم و تصمیم بگیریم که آیا برای برنامهٔ ما مناسب است.

## تصمیم

پس از بررسی مزایا و معایب هر کتابخانه، به دلایل زیر تصمیم گرفته‌ایم Svelte را به‌عنوان کتابخانهٔ جاوااسکریپت فرانت‌اند خود به کار ببریم:

1. **سبک:**  Svelte یکی از سبک‌ترین کتابخانه‌های موجود است که به ما کمک می‌کند حجم برنامه را کوچک نگه داریم و زمان بارگذاری صفحه را بهبود دهیم.

2. **سریع:**  Svelte به سرعت رندر بالایش شناخته شده است که برنامهٔ ما را واکنش‌گرا و چابک خواهد کرد.

3. **آسان برای استفاده:**  نحو Svelte ساده و قابل‌فهم است که اتخاذ آن و نوشتن کد تمیز را برای تیم ما آسان‌تر می‌کند.

4. **بهینه برای رندر UI:**  Svelte برای رندر مؤلفه‌های UI بهینه شده است که ساخت عناصر UI پویا و قابل استفادهٔ مجدد را برای ما آسان‌تر می‌کند.

5. **مستندات خوب و پشتیبانی جامعه:**  Svelte جامعه‌ای رو به رشد و مستندات خوب دارد که به ما کمک می‌کند سریع شروع کنیم و هر مشکلی را که پیش می‌آید حل کنیم.

## جایگزین‌ها

React، Vue و Angular را بررسی کردیم، اما به دلایل زیر آن‌ها را کنار گذاشتیم:

1. **React:**  هرچند React پایگاه کاربری بزرگ و مجموعه‌ای از کتابخانه‌ها و منابع دارد، می‌تواند پیچیده و یادگیری آن دشوار باشد، به‌ویژه برای مبتدیان.

2. **Vue:**  Vue کتابخانه‌ای سبک است که یادگیری و استفاده از آن آسان است، اما ممکن است به سرعت یا بهینگی Svelte نباشد.

3. **Angular:**  Angular چارچوبی جامع است که ویژگی‌ها و ابزارهای بسیاری ارائه می‌دهد، اما می‌تواند سنگین و پیچیده باشد و ممکن است نسبت به Svelte نگهداری بیشتری بطلبد.

## پیامدها

استفاده از Svelte به‌عنوان کتابخانهٔ جاوااسکریپت فرانت‌اند ما پیامدهای زیر را خواهد داشت:

1. برنامهٔ ما سبک و سریع خواهد بود که تجربهٔ کاربری و مشارکت را بهبود می‌دهد.

2. تیم ما باید کتابخانه‌ای جدید بیاموزد، اما نحو Svelte ساده و قابل‌فهم است، بنابراین منحنی یادگیری باید قابل‌مدیریت باشد.

3. Svelte هنوز کتابخانه‌ای نسبتاً جدید است، بنابراین ممکن است با مشکلاتی روبه‌رو شویم که به‌خوبی مستند نشده‌اند یا جامعه از آن‌ها پشتیبانی نمی‌کند.

4. جامعهٔ کاربران Svelte رو به رشد است، بنابراین ممکن است در آینده کتابخانه‌ها و منابع شخص ثالث بیشتری در دسترس قرار گیرند که برای تکمیل کتابخانهٔ اصلی قابل استفاده‌اند.

## نتیجه‌گیری
