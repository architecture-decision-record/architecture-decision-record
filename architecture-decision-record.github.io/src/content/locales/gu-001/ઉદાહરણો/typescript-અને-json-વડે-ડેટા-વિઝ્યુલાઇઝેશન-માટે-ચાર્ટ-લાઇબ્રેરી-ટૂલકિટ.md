**મુખ્ય ઉદ્દેશ્ય:**  
TypeScript અને JSON વાપરીને નાણાકીય ડેટા, વૈજ્ઞાનિક ડેટા અને સરકારી ડેટા પર ધ્યાન કેન્દ્રિત કરતા ઇન્ટરેક્ટિવ વિઝ્યુલાઇઝેશન બનાવવા માટે અદ્યતન ચાર્ટિંગ ટૂલકિટ પસંદ કરવી. લાઇબ્રેરીએ મજબૂત સુવિધાઓ, લવચીકતા પૂરી પાડવી જોઈએ અને ઓપન-સોર્સ હોવી જોઈએ. 

### સંદર્ભ અને જરૂરિયાતો:

1. **ચપળ વિકાસ (ઉચ્ચ અગ્રતા)**: સ્ટાર્ટઅપ તરીકે, ઝડપી પુનરાવર્તન, પ્રોટોટાઇપિંગ અને વિકાસમાં લવચીકતા આવશ્યક છે. ચાર્ટ લાઇબ્રેરીએ ઝડપી વિકાસ ચક્રો માટે પરવાનગી આપવી જોઈએ.
   
2. **ચાર્ટ પ્રકારો (ઉચ્ચ અગ્રતા)**:
   - **ડોનટ ચાર્ટ**
   - **રડાર ચાર્ટ**
   - **ક્લસ્ટરિંગ પ્રક્રિયા ચાર્ટ**
   - **સમય અક્ષ સાથે એરિયા ચાર્ટ**
   - **કેન્ડલસ્ટિક ચાર્ટ**
   - **નાઇટિંગેલ ચાર્ટ**
   - **Geo SVG નકશો**
   
   આ ચાર્ટ પ્રકારો જટિલ ડેટાસેટ્સ, જેમ કે નાણાકીય વલણો, વૈજ્ઞાનિક માપદંડો અને ભૌગોલિક માહિતી, ના વિઝ્યુલાઇઝેશન માટે ખાસ મહત્વના છે.

3. **મફત અને ઓપન સોર્સ (ઉચ્ચ અગ્રતા)**: લાઇસન્સ ખર્ચ ટાળવા, પારદર્શિતા આપવા અને કસ્ટમાઇઝેશન માટે લવચીકતા આપવા ટૂલકિટ ઓપન-સોર્સ હોવી જોઈએ.

4. **ઓછી મહત્વની માપદંડો**:
   - **રનટાઇમ ઝડપ**: કામગીરી મહત્વની હોવા છતાં, આ નિર્ણય માટે તે ટોચની અગ્રતા નથી.
   - **માપનીયતા**: માપનીયતા સામાન્ય રીતે મહત્વની હોવા છતાં, તાત્કાલિક જરૂરિયાત એવો MVP બનાવવાની છે જે સમય સાથે વિકસી શકે. માપનીયતાની ચિંતાઓ પછી સંબોધી શકાય.
   - **પાછળની સુસંગતતા**: પ્રારંભિક નિર્માણ માટે પ્રાથમિક ચિંતા નથી, જ્યાં સુધી લાઇબ્રેરી આધુનિક અને સક્રિય રીતે જાળવાયેલી હોય.

### 1. **Apache ECharts**

**ઝાંખી**:  
Apache ECharts ઇન્ટરેક્ટિવ, કસ્ટમાઇઝ કરી શકાય તેવા વિઝ્યુલાઇઝેશન માટે શક્તિશાળી, લવચીક ચાર્ટિંગ લાઇબ્રેરી છે. તે ચાર્ટની વિશાળ શ્રેણીને સપોર્ટ કરે છે અને જટિલ, ગતિશીલ વિઝ્યુલાઇઝેશનમાં ખાસ કરીને મજબૂત છે.

**શક્તિઓ**:
- **અદ્યતન ઇન્ટરેક્ટિવિટી**: ECharts ઇન્ટરેક્ટિવ ચાર્ટ પૂરા પાડવામાં ઉત્કૃષ્ટ છે, ઝૂમિંગ, પેનિંગ અને ગતિશીલ ડેટા અપડેટ જેવી સુવિધાઓ આપે છે.
- **ડોનટ, રડાર, કેન્ડલસ્ટિક, Geo SVG નકશા**: ECharts જરૂરી ઘણા ચાર્ટ પ્રકારોને સપોર્ટ કરે છે, જેમાં ડોનટ, રડાર, કેન્ડલસ્ટિક અને ભૌગોલિક નકશા વિઝ્યુલાઇઝેશન શામેલ છે.
- **મફત અને ઓપન સોર્સ**: ECharts ઓપન-સોર્સ લાઇબ્રેરી છે, જે સ્ટાર્ટઅપના બજેટ-સભાન સ્વભાવ સાથે બંધબેસે છે અને કોડ બદલવાની સ્વતંત્રતા આપે છે.
- **લવચીકતા અને વિસ્તરણક્ષમતા**: અત્યંત કસ્ટમાઇઝ કરી શકાય તેવું, એનિમેશન, કસ્ટમ વિઝ્યુલાઇઝેશન અને અદ્યતન ચાર્ટિંગ તકનીકો માટે વ્યાપક સપોર્ટ સાથે.
  
**નબળાઈઓ**:
- **શીખવાની કઠિનતા**: ECharts શક્તિશાળી હોવા છતાં, તેની લવચીકતા અને વ્યાપક API ને કારણે વધુ ઊભી શીખવાની કઠિનતા હોઈ શકે.
- **દસ્તાવેજીકરણની જટિલતા**: દસ્તાવેજીકરણ વ્યાપક છે પરંતુ તેની સાથે નવા શરૂ કરતા ડેવલપર્સ માટે ભારે લાગી શકે.

**ચુકાદો**:  
ECharts આ પ્રોજેક્ટ માટે ખૂબ યોગ્ય છે કારણ કે તે ઇન્ટરેક્ટિવ ચાર્ટને સપોર્ટ કરે છે, જેમાં કેન્ડલસ્ટિક ચાર્ટ, રડાર ચાર્ટ અને જીઓ નકશા જેવા બધા જરૂરી પ્રકારો શામેલ છે. તેની ઓપન-સોર્સ પ્રકૃતિ પ્રોજેક્ટની લવચીકતા અને ખર્ચ-અસરકારકતાની જરૂરિયાત સાથે સુસંગત છે.

### 2. **Chart.js**

**ઝાંખી**:  
Chart.js સામાન્ય ચાર્ટ પ્રકારો બનાવવા માટે સરળ, વાપરવામાં સહેલી ચાર્ટિંગ લાઇબ્રેરી છે. તે તેની સરળતા અને ઇન્ટિગ્રેશનની સરળતા માટે જાણીતી છે.

**શક્તિઓ**:
- **ઉપયોગની સરળતા**: Chart.js સેટ અપ કરવા અને વાપરવા ખૂબ સરળ છે, ન્યૂનતમ શીખવાની કઠિનતા સાથે.
- **ઓપન સોર્સ**: Chart.js મફત અને ઓપન-સોર્સ છે, જે ખર્ચ ઘટાડવા માટે નિર્ણાયક છે.
- **સામાન્ય ચાર્ટ પ્રકારો**: તે ડોનટ, એરિયા, રડાર અને લાઇન ચાર્ટ જેવા મૂળભૂત ચાર્ટને સપોર્ટ કરે છે, જે મોટાભાગની પ્રાથમિક જરૂરિયાતો આવરે છે.

**નબળાઈઓ**:
- **મર્યાદિત અદ્યતન ચાર્ટ**: Chart.js કેન્ડલસ્ટિક ચાર્ટ, geo SVG નકશા કે ક્લસ્ટરિંગ પ્રક્રિયા ચાર્ટ જેવા જટિલ ચાર્ટ પ્રકારોને મૂળ રૂપે સપોર્ટ કરતું નથી. આ સુવિધાઓ પ્લગઇન કે કસ્ટમાઇઝેશન દ્વારા ઉમેરી શકાય હોવા છતાં, તે અન્ય લાઇબ્રેરીઓ જેટલું સીધું નથી.
- **ઇન્ટરેક્ટિવિટી**: Chart.js મૂળભૂત ઇન્ટરેક્ટિવિટી (દા.ત. ટૂલટિપ અને હોવર અસરો) ને સપોર્ટ કરે છે, પરંતુ તે ECharts કે D3.js જેટલી અદ્યતન સુવિધાઓ આપતું નથી.

**ચુકાદો**:  
Chart.js સરળ, ઝડપી પ્રોજેક્ટ્સ માટે ઉત્તમ છે, પરંતુ જટિલ ચાર્ટ પ્રકારોના સપોર્ટનો અભાવ તેને કેન્ડલસ્ટિક ચાર્ટ અને જીઓ નકશા જેવી અદ્યતન જરૂરિયાતોવાળી ડેટા-ભારે એપ્લિકેશન માટે અયોગ્ય બનાવે છે. તે પ્રોટોટાઇપિંગ માટે સારી પસંદગી છે, પરંતુ જરૂરી ચાર્ટ પ્રકારો માટે, વધુ અદ્યતન સાધનોની ભલામણ કરવામાં આવે છે.

### 3. **ApexCharts**

**ઝાંખી**:  
ApexCharts આધુનિક ચાર્ટિંગ લાઇબ્રેરી છે જે ચાર્ટ પ્રકારોની વિવિધતા પૂરી પાડે છે અને વાપરવામાં સરળ API સાથે ઇન્ટરેક્ટિવ વિઝ્યુલાઇઝેશન પર ધ્યાન કેન્દ્રિત કરે છે.

**શક્તિઓ**:
- **ઇન્ટરેક્ટિવ સુવિધાઓ**: ApexCharts ટૂલટિપ, ઝૂમિંગ, પેનિંગ અને અપડેટ સાથે ઇન્ટરેક્ટિવ ચાર્ટ આપે છે.
- **નાણાકીય અને વૈજ્ઞાનિક ચાર્ટ માટે સપોર્ટ**: તે કેન્ડલસ્ટિક ચાર્ટ, રડાર ચાર્ટ અને એરિયા ચાર્ટ સહિત ચાર્ટ પ્રકારોની વિશાળ વિવિધતાને સપોર્ટ કરે છે.
- **ઉપયોગની સરળતા**: તેની પાસે સીધું API છે અને પ્રોજેક્ટમાં ઇન્ટિગ્રેટ કરવું સરળ છે.
- **મફત અને ઓપન સોર્સ**: ApexCharts ઘણા ઉપયોગ કેસ માટે યોગ્ય મફત ઓપન-સોર્સ સંસ્કરણ આપે છે.
  
**નબળાઈઓ**:
- **જટિલ કસ્ટમાઇઝેશન**: તે ઘણી સુવિધાઓ આપે છે, પરંતુ અત્યંત જટિલ કે કસ્ટમ ચાર્ટિંગ જરૂરિયાતો માટે કસ્ટમાઇઝેશન વિકલ્પો ECharts કે D3.js જેટલા લવચીક નથી.
- **જીઓ નકશા**: ApexCharts જીઓ નકશા કે ક્લસ્ટરિંગ પ્રક્રિયા ચાર્ટને મૂળ રૂપે સપોર્ટ કરતું નથી, જે આ પ્રોજેક્ટ માટે જરૂરી છે.

**ચુકાદો**:  
ApexCharts તેની ઉપયોગની સરળતા અને ઇન્ટરેક્ટિવિટીને કારણે મજબૂત દાવેદાર છે, પરંતુ કેટલાક અદ્યતન ચાર્ટ પ્રકારો પર, ખાસ કરીને જીઓ નકશા અને ક્લસ્ટરિંગ ચાર્ટની જરૂરિયાત પર, ઓછું ઊતરે છે. તે સરળ ચાર્ટ માટે સારો વિકલ્પ છે પરંતુ કેટલીક જરૂરી સુવિધાઓનો અભાવ છે.

### 4. **AG Charts**

**ઝાંખી**:  
AG Charts કામગીરી અને ચોકસાઈ માટે ડિઝાઇન કરાયેલ વાણિજ્યિક-ગ્રેડ ચાર્ટિંગ લાઇબ્રેરી છે. તે નાણાકીય, વૈજ્ઞાનિક અને વ્યવસાયિક ડેશબોર્ડ બનાવવા માટે ખૂબ યોગ્ય છે.

**શક્તિઓ**:
- **અદ્યતન ચાર્ટ પ્રકારો**: AG Charts ઘણા અદ્યતન ચાર્ટ પ્રકારોને સપોર્ટ કરે છે, જેમાં કેન્ડલસ્ટિક ચાર્ટ, એરિયા ચાર્ટ, રડાર ચાર્ટ અને વધુ શામેલ છે. તે અન્ય AG-Grid ઉત્પાદનો સાથે ઊંડું ઇન્ટિગ્રેશન પણ આપે છે.
- **ઉચ્ચ કામગીરી**: તે ઉત્તમ કામગીરી આપે છે, ખાસ કરીને મોટા ડેટાસેટ્સ સાથે વ્યવહાર કરતી વખતે.
- **ઇન્ટરેક્ટિવિટી**: AG Charts ઝૂમિંગ, ટૂલટિપ અને ગતિશીલ અપડેટ જેવી વિવિધ ઇન્ટરેક્ટિવ સુવિધાઓને સપોર્ટ કરે છે.

**નબળાઈઓ**:
- **સંપૂર્ણ મફત નથી**: AG Charts મફત સંસ્કરણ આપે છે, પરંતુ પૂર્ણ-સુવિધા સંસ્કરણ ચૂકવણીવાળું છે, જે ખર્ચ ઓછો કરવા માગતા સ્ટાર્ટઅપ્સ માટે અવરોધ બની શકે.
- **જટિલતા**: લાઇબ્રેરી સુવિધાઓથી ભરપૂર હોવા છતાં, તે સરળ પ્રોજેક્ટ્સ માટે વધુ પડતી હોઈ શકે અને અન્ય વિકલ્પોની સરખામણીમાં વધુ સેટઅપ અને રૂપરેખાંકનની જરૂર પડી શકે.

**ચુકાદો**:  
AG Charts શક્તિશાળી અને સુવિધાસભર છે, પરંતુ તેની વાણિજ્યિક પ્રકૃતિ અને ખર્ચ માળખાને કારણે સૌથી યોગ્ય ન પણ હોય. તેની યોગ્યતા એ પર આધાર રાખે છે કે બજેટ ચૂકવણીવાળા સંસ્કરણો સમાવી શકે છે કે ઓપન-સોર્સ વિકલ્પો પસંદ છે.

### 5. **Highcharts**

**ઝાંખી**:  
Highcharts ચાર્ટ પ્રકારોની વિશાળ શ્રેણી અને શક્તિશાળી કસ્ટમાઇઝેશન વિકલ્પો માટે જાણીતી લોકપ્રિય ચાર્ટિંગ લાઇબ્રેરી છે.

**શક્તિઓ**:
- **વ્યાપક ચાર્ટ પ્રકારો**: Highcharts કેન્ડલસ્ટિક, રડાર, એરિયા અને જીઓ નકશા સહિત ચાર્ટની વિશાળ વિવિધતાને સપોર્ટ કરે છે.
- **ઇન્ટરેક્ટિવ અને ગતિશીલ**: Highcharts ડ્રિલ-ડાઉન, ઝૂમિંગ અને પેનિંગ સહિતની સમૃદ્ધ ઇન્ટરેક્ટિવ સુવિધાઓ પૂરી પાડે છે.
- **ઉપયોગની સરળતા**: તેની પાસે વપરાશકર્તા-મૈત્રીપૂર્ણ API અને સારું દસ્તાવેજીકરણ છે, જે શરૂ કરવાનું સરળ બનાવે છે.

**નબળાઈઓ**:
- **વાણિજ્યિક લાઇસન્સ**: Highcharts બિન-વાણિજ્યિક ઉપયોગ માટે મફત સંસ્કરણ આપે છે, પરંતુ વાણિજ્યિક લાઇસન્સ મોંઘું છે, જે સ્ટાર્ટઅપ્સ માટે નોંધપાત્ર ગેરલાભ હોઈ શકે.
- **શીખવાની કઠિનતા**: ECharts જેટલું ઊભું ન હોવા છતાં, શરૂઆત કરનારાઓ માટે Highcharts ની શીખવાની કઠિનતા હજુ પડકારજનક હોઈ શકે.

**ચુકાદો**:  
Highcharts સુવિધાસભર લાઇબ્રેરી છે, પરંતુ તેનું વાણિજ્યિક લાઇસન્સિંગ તેને ઓપન-સોર્સ, ખર્ચ-સંવેદનશીલ પ્રોજેક્ટ્સ માટે ઓછું યોગ્ય બનાવે છે. તેના વ્યાપક ચાર્ટિંગ વિકલ્પો પ્લસ છે, પરંતુ લાઇસન્સિંગ મુદ્દો આ ઉપયોગ કેસ માટે તેની આકર્ષણશક્તિ મર્યાદિત કરે છે.

### 6. **Carbon Charts**

**ઝાંખી**:  
Carbon Charts IBM દ્વારા વિકસાવાયેલી ચાર્ટિંગ લાઇબ્રેરી છે, જે દૃશ્ય રીતે આકર્ષક અને અત્યંત કસ્ટમાઇઝ કરી શકાય તેવા ચાર્ટ બનાવવા માટે ડિઝાઇન કરાઈ છે.

**શક્તિઓ**:
- **કસ્ટમાઇઝ કરવાની ક્ષમતા**: Carbon Charts ચાર્ટના દેખાવ અને વર્તનનું વ્યાપક કસ્ટમાઇઝેશન શક્ય બનાવે છે.
- **ઓપન સોર્સ**: તે મફત અને ઓપન-સોર્સ છે, જે બજેટ-અનુકૂળ ઉકેલો માટે પ્રોજેક્ટની જરૂરિયાત સાથે સુસંગત છે.
- **સામાન્ય ચાર્ટ માટે સપોર્ટ**: તે ડોનટ, રડાર અને એરિયા ચાર્ટ જેવા સામાન્ય ચાર્ટ પ્રકારોને સપોર્ટ કરે છે, જોકે જીઓ નકશા કે કેન્ડલસ્ટિક ચાર્ટ જેવા વધુ અદ્યતન પ્રકારોના સપોર્ટનો અભાવ છે.

**નબળાઈઓ**:
- **મર્યાદિત અદ્યતન ચાર્ટ પ્રકારો**: તે જીઓ નકશા, ક્લસ્ટરિંગ પ્રક્રિયા ચાર્ટ કે કેન્ડલસ્ટિક ચાર્ટને સપોર્ટ કરતું નથી, જે પ્રોજેક્ટ માટે આવશ્યક છે.
- **નાની ઇકોસિસ્ટમ**: ECharts કે Highcharts જેવી મોટી ચાર્ટ લાઇબ્રેરીઓની સરખામણીમાં Carbon Charts નો સમુદાય અને ઇકોસિસ્ટમ નાનો છે.

**ચુકાદો**:  
Carbon Charts ઓપન-સોર્સ અને કસ્ટમાઇઝ કરી શકાય તેવી છે, પરંતુ આ પ્રોજેક્ટ માટે જરૂરી વધુ જટિલ ચાર્ટ પ્રકારોના સપોર્ટનો અભાવ છે. તે સરળ ચાર્ટિંગ જરૂરિયાતો માટે વધુ યોગ્ય છે.

### 7. **Layer Cake**

**ઝાંખી**:  
Layer Cake લવચીક, સ્તરવાળા વિઝ્યુલાઇઝેશન બનાવવા માટે ડિઝાઇન કરાયેલ ડેટા વિઝ્યુલાઇઝેશન લાઇબ્રેરી છે.

**શક્તિઓ**:
- **કસ્ટમાઇઝ કરી શકાય તેવા સ્તરો**: તે જટિલ વિઝ્યુલાઇઝેશન માટે શક્તિશાળી સ્તરીકરણ વિકલ્પો આપે છે.
- **ઓપન સોર્સ**: તે મફત અને ઓપન-સોર્સ છે, જે તેને બજેટ-સભાન પ્રોજેક્ટ્સ માટે વ્યવહારુ વિકલ્પ બનાવે છે.

**નબળાઈઓ**:
- **મર્યાદિત દસ્તાવેજીકરણ**: Layer Cake પાસે વ્યાપક દસ્તાવેજીકરણ અને સમુદાય સપોર્ટનો અભાવ છે, જે વધુ સ્થાપિત લાઇબ્રેરીઓની સરખામણીમાં તેની સાથે કામ કરવું વધુ મુશ્કેલ બનાવે છે.
- **ચાર્ટ માટે બનાવાયું નથી**: Layer Cake બિન-ચાર્ટ વિઝ્યુલાઇઝેશન માટે વધુ યોગ્ય છે, તેથી તેના તૈયાર ચાર્ટિંગ વિકલ્પો મર્યાદિત છે.

**ચુકાદો**:  
અનન્ય વિઝ્યુલાઇઝેશન માટે રસપ્રદ હોવા છતાં, Layer Cake કેન્ડલસ્ટિક ચાર્ટ કે રડાર ચાર્ટ જેવી પરંપરાગત ચાર્ટિંગ જરૂરિયાતો માટે આદર્શ નથી. તે પ્રમાણભૂત ચાર્ટના વ્યાપની બહારના કસ્ટમ વિઝ્યુલાઇઝેશન માટે વધુ યોગ્ય છે.

### 8. **D3.js**

**ઝાંખી**:  
D3.js HTML, SVG અને CSS દ્વારા ડેટા-સંચાલિત વિઝ્યુલાઇઝેશન બનાવવા માટે શક્તિશાળી JavaScript લાઇબ્રેરી છે.

**શક્તિઓ**:
- **અજોડ લવચીકતા**: D3.js વાસ્તવમાં કોઈપણ પ્રકારનું કસ્ટમ વિઝ્યુલાઇઝેશન બનાવવાની મંજૂરી આપે છે, જે તેને અદ્યતન અને ઇન્ટરેક્ટિવ ચાર્ટ માટે અત્યંત શક્તિશાળી બનાવે છે.
- **વ્યાપક સુવિધાઓ**: તે જીઓ નકશા, ક્લસ્ટરિંગ ચાર્ટ અને વધુ સહિત તમામ જરૂરી ચાર્ટ પ્રકારોને સપોર્ટ કરે છે.
- **કસ્ટમાઇઝ કરી શકાય તેવું**: D3.js માં કસ્ટમાઇઝેશનનું સ્તર અજોડ છે, જે ડેવલપર્સને અત્યંત અનુરૂપ વિઝ્યુલાઇઝેશન બનાવવા દે છે.

**નબળાઈઓ**:
- **ઊભી શીખવાની કઠિનતા**: D3.js ની શીખવાની કઠિનતા ઊભી છે અને અન્ય લાઇબ્રેરીઓની સરખામણીમાં તેને ઇન્ટિગ્રેટ કરવું વધુ જટિલ છે.
- **સમય લેતું**: D3.js માં ચાર્ટ બનાવવા સમય લેતા હોઈ શકે, ખાસ કરીને કેન્ડલસ્ટિક કે ડોનટ ચાર્ટ જેવા સામાન્ય ચાર્ટ માટે.

**ચુકાદો**:  
D3.js અદ્યતન, કસ્ટમ ચાર્ટ માટે અવિશ્વસનીય રીતે શક્તિશાળી છે પરંતુ તેની ઊભી શીખવાની કઠિનતા અને વિકાસ સમયને કારણે ઘણા લાક્ષણિક ઉપયોગ કેસ માટે વધુ પડતું છે. અન્ય ચાર્ટ લાઇબ્રેરીઓ જરૂરી સ્તરનું કસ્ટમાઇઝેશન ન આપતી હોય તેવી પરિસ્થિતિઓ માટે તે શ્રેષ્ઠ છે.

### નિષ્કર્ષ

પ્રોજેક્ટની જરૂરિયાતોના આધારે લાઇબ્રેરીઓનું મૂલ્યાંકન કર્યા પછી, **Apache ECharts** શ્રેષ્ઠ વિકલ્પ તરીકે ઊભરે છે. તે જીઓ નકશા, કેન્ડલસ્ટિક ચાર્ટ અને ક્લસ્ટરિંગ ચાર્ટ સહિત જરૂરી ચાર્ટની સંપૂર્ણ શ્રેણીને સપોર્ટ કરે છે. તે ઓપન-સોર્સ, સુવિધાસભર અને અત્યંત ઇન્ટરેક્ટિવ છે, જે પ્રોજેક્ટના લક્ષ્યો સાથે સંપૂર્ણ રીતે બંધબેસે છે. જોકે **D3.js** સૌથી વધુ લવચીકતા આપે છે, તેની જટિલતા અને સમયનું રોકાણ તેને ઝડપથી પુનરાવર્તન કરવા માગતા સ્ટાર્ટઅપ માટે ઓછું આદર્શ બનાવે છે. **ApexCharts** અને **Chart.js** સરળ પ્રોજેક્ટ્સ માટે સારા વિકલ્પો છે પરંતુ અદ્યતન ચાર્ટ પ્રકારોના સપોર્ટનો અભાવ છે.
