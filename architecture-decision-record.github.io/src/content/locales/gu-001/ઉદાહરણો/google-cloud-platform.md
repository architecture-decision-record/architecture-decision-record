# Google Cloud Platform માટે આર્કિટેક્ચર નિર્ણય રેકોર્ડ

## સંદર્ભ

Google Cloud Platform (GCP) એક અગ્રણી ક્લાઉડ કમ્પ્યુટિંગ પ્લેટફોર્મ છે જે કમ્પ્યુટિંગ, સંગ્રહ અને નેટવર્કિંગ ઉકેલો સહિત વિવિધ ક્લાઉડ સેવાઓ આપે છે. આ ADR નો હેતુ અમારી સંસ્થા માટે GCP-આધારિત ઇન્ફ્રાસ્ટ્રક્ચર વિકસાવવા અને અમલમાં મૂકવા માટે લેવાયેલા આર્કિટેક્ચરલ નિર્ણયોનું દસ્તાવેજીકરણ કરવાનો છે.

## નિર્ણય

અમારી સંસ્થાએ અમારી એપ્લિકેશન માટે ક્લાઉડ ઇન્ફ્રાસ્ટ્રક્ચર તરીકે Google Cloud Platform વાપરવાનું નક્કી કર્યું છે. આ નિર્ણય માટેની મુખ્ય વિચારણાઓ છે:

   - ખર્ચ-અસરકારકતા

   - માપનીયતા

   - વિશ્વસનીયતા

   - લવચીકતા

## પસંદગીઓ

અમારી જરૂરિયાતો પૂરી કરવા માટે GCP ની નીચેની સેવાઓ પસંદ કરવામાં આવી છે:

   - વર્ચ્યુઅલ મશીનો અને કમ્પ્યુટિંગ સંસાધનો માટે Compute Engine

   - ઓબ્જેક્ટ સ્ટોરેજ અને ફાઇલ હોસ્ટિંગ માટે Cloud Storage

   - મેનેજ્ડ ડેટાબેઝ સેવા માટે Cloud SQL

   - એપ્લિકેશન વિકાસ અને હોસ્ટિંગ માટે Firebase

## તર્ક

   - ખર્ચ-અસરકારકતા: Google Cloud Platform અન્ય ક્લાઉડ પ્લેટફોર્મની સરખામણીમાં અત્યંત ખર્ચ-અસરકારક છે, જે બજેટ મર્યાદાઓ ધરાવતી સંસ્થાઓ માટે તેને આકર્ષક વિકલ્પ બનાવે છે.

   - માપનીયતા: GCP નું સરળતાથી માપી શકાય તેવું ઇન્ફ્રાસ્ટ્રક્ચર રિયલ-ટાઇમમાં કોઈપણ પ્રમાણના ટ્રાફિકને સંભાળવાનું શક્ય બનાવે છે.

   - વિશ્વસનીયતા: GCP ની મેનેજ્ડ સેવાઓ ઉચ્ચ વિશ્વસનીયતા આપે છે, સ્વચાલિત બેકઅપ અને આપત્તિ પુનઃપ્રાપ્તિ ક્ષમતાઓ સાથે જે સંસાધનો અને ડેટાની ઉચ્ચ ઉપલબ્ધતા સુનિશ્ચિત કરે છે.

   - લવચીકતા: પ્લેટફોર્મ AI, ડેટા એનાલિટિક્સ અને IoT જેવા વિવિધ ક્ષેત્રોમાં વિવિધ સાધનો અને સેવાઓ પૂરી પાડે છે, જે તેને અત્યંત બહુમુખી બનાવે છે.

## પરિણામો

Google Cloud Platform પર સ્થળાંતર કરવા માટે અમારી ટીમોને GCP સેવાઓ પર તાલીમ આપવી, પસંદ કરેલી સેવાઓ સાથે સુસંગત થવા એપ્લિકેશનને ફરીથી આર્કિટેક્ટ કરવી, અને GCP સેવાઓને સપોર્ટ કરવા ઇન્ફ્રાસ્ટ્રક્ચર કોડ અપડેટ કરવાની જરૂર પડશે. જોકે, અપેક્ષા છે કે સ્થળાંતર પૂર્ણ થયા પછી, અમારી પાસે અમારી એપ્લિકેશન હોસ્ટ કરવા માટે અત્યંત માપી શકાય તેવું, વિશ્વસનીય અને ખર્ચ-અસરકારક ઇન્ફ્રાસ્ટ્રક્ચર હશે. ઉપરાંત, અમારે GCP પર સંસાધનો પૂરા પાડવાના ચાલુ ખર્ચનું સંચાલન કરવું પડશે.

## નિષ્કર્ષ

Google Cloud Platform તેની ખર્ચ-અસરકારકતા, માપનીયતા, વિશ્વસનીયતા અને લવચીકતાને કારણે અમારા ક્લાઉડ ઇન્ફ્રાસ્ટ્રક્ચર માટે ઉત્તમ પસંદગી છે. પસંદ કરેલી સેવાઓનો ઉપયોગ કરીને, અમે અમારી એપ્લિકેશન માટે અત્યંત ઉપલબ્ધ અને મજબૂત ઇન્ફ્રાસ્ટ્રક્ચર પૂરું પાડી શકીએ છીએ.
