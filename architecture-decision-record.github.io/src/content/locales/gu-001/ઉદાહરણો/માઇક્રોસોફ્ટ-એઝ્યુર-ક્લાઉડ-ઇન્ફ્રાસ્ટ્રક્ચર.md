# આર્કિટેક્ચર નિર્ણય રેકોર્ડ: Microsoft Azure ક્લાઉડ ઇન્ફ્રાસ્ટ્રક્ચર" 

નિર્ણયનું શીર્ષક: અમારી સંસ્થા માટે ક્લાઉડ ઇન્ફ્રાસ્ટ્રક્ચર તરીકે Microsoft Azure અપનાવવું

નિર્ણયકર્તા: મુખ્ય માહિતી અધિકારી

તારીખ: 2021-10-15

સ્થિતિ: મંજૂર

## પૃષ્ઠભૂમિ

સંસ્થા પરંપરાગત ઓન-પ્રિમાઇસિસ ઇન્ફ્રાસ્ટ્રક્ચરમાંથી ક્લાઉડ ઇન્ફ્રાસ્ટ્રક્ચરમાં સ્થળાંતર કરવાનું આયોજન કરી રહી છે. આ પ્રાપ્ત કરવા માટે, સંસ્થાએ Amazon Web Services (AWS), Google Cloud Platform (GCP), Microsoft Azure અને IBM Cloud જેવા અનેક ક્લાઉડ સેવા પ્રદાતાઓનું મૂલ્યાંકન કર્યું છે. દરેક પ્રદાતાની પોતાની સુવિધાઓ, લાભો અને કિંમત માળખું છે. વિગતવાર વિશ્લેષણ પછી, નિષ્કર્ષ આવ્યો કે Microsoft Azure અમારી સંસ્થા માટે સૌથી યોગ્ય વિકલ્પ છે.

## નિર્ણય

અમારી સંસ્થા માટે ક્લાઉડ ઇન્ફ્રાસ્ટ્રક્ચર તરીકે Microsoft Azure અપનાવવું.

## તર્ક

Microsoft Azure અપનાવવાના કારણો નીચે મુજબ છે:

1. વ્યાપક સેવાઓ: Azure infrastructure as a service (IaaS) થી software as a service (SaaS) અને platform as a service (PaaS) સુધીની ક્લાઉડ સેવાઓની સંપૂર્ણ શ્રેણી પૂરી પાડે છે. આ અમને સંગ્રહ, કમ્પ્યુટ, નેટવર્કિંગ અને એનાલિટિક્સ જેવી સંસ્થાની જરૂરિયાતો ઉકેલવા Azure સેવાઓનો લાભ લેવા દે છે.

2. માપનીયતા અને લવચીકતા: Azure સાથે, અમે અમારી વ્યવસાયિક જરૂરિયાતોના આધારે સંસાધનોને સરળતાથી વધારી કે ઘટાડી શકીએ છીએ. Azure ઓપરેટિંગ સિસ્ટમ, પ્રોગ્રામિંગ ભાષા અને ફ્રેમવર્ક પસંદ કરવામાં પણ લવચીકતા આપે છે.

3. સુરક્ષા અને અનુપાલન: Azure ઉચ્ચ સ્તરની સુરક્ષા અને અનુપાલન આપે છે, કારણ કે તે ISO, SOC, HIPAA અને PCI DSS જેવા અનેક ઉદ્યોગ ધોરણોનું પાલન કરે છે. Azure નેટવર્ક સુરક્ષા જૂથો, ફાયરવોલ અને DDoS સુરક્ષા જેવી અદ્યતન સુરક્ષા સુવિધાઓ પણ આપે છે.

4. હાઇબ્રિડ ક્લાઉડ: Azure સીમલેસ હાઇબ્રિડ ક્લાઉડ અનુભવ પૂરો પાડે છે, જે સંસ્થાઓને તેમના ઓન-પ્રિમાઇસિસ ઇન્ફ્રાસ્ટ્રક્ચરને Azure સાથે જોડવા દે છે. આ અમારા માટે કાર્યભારને ક્લાઉડમાં સ્થળાંતરિત કરવાનું સરળ બનાવે છે અને ડેટા ક્યાં સંગ્રહવો તે પસંદ કરવાની લવચીકતા આપે છે.

5. ખર્ચ-અસરકારક: Azure ઉપયોગ મુજબ ચૂકવણીનું કિંમત મોડેલ આપે છે, જેનો અર્થ અમે જે સંસાધનો વાપરીએ તેના જ પૈસા ચૂકવીએ છીએ. આ પરંપરાગત ઓન-પ્રિમાઇસિસ ઇન્ફ્રાસ્ટ્રક્ચરની સરખામણીમાં ખર્ચ બચાવવામાં મદદ કરે છે.

## નિષ્કર્ષ

અમારી સંસ્થા માટે ક્લાઉડ ઇન્ફ્રાસ્ટ્રક્ચર તરીકે Microsoft Azure અપનાવવું અમારી વ્યવસાયિક જરૂરિયાતો સાથે સુસંગત છે અને માપનીયતા, લવચીકતા, સુરક્ષા અને ખર્ચ-અસરકારકતા જેવા અનેક લાભો આપે છે. તેથી, Azure ને અમારા ક્લાઉડ ઇન્ફ્રાસ્ટ્રક્ચર તરીકે અપનાવવાની ભલામણ કરવામાં આવે છે.
