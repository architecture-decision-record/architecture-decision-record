# આર્કિટેક્ચર નિર્ણય રેકોર્ડ: કુબર્નેટિસ કન્ટેનર ઓર્કેસ્ટ્રેશન

## સમસ્યા વિધાન 

અમારે અમારા વધતા ક્લાઉડ-નેટિવ એપ્લિકેશન પોર્ટફોલિયો માટે કન્ટેનર ઓર્કેસ્ટ્રેશન પ્લેટફોર્મ પસંદ કરવાની જરૂર છે. અમારું વર્તમાન જૂનું પ્લેટફોર્મ ડિપ્લોયમેન્ટ ખૂબ ધીમું છે, અને અમારી વધતી જરૂરિયાતો સાથે તાલ મિલાવવા પૂરતું ચપળ નથી. અમે એવી સિસ્ટમ શોધી રહ્યા છીએ જે અમને ચપળતા કે ઉપયોગની સરળતા સાથે સમાધાન કર્યા વિના અમારી સેવાઓને સૌથી કાર્યક્ષમ રીતે માપવા દે.

## લેવાયેલો નિર્ણય

દરેક કન્ટેનર ઓર્કેસ્ટ્રેશન પ્લેટફોર્મનું સંપૂર્ણ વિશ્લેષણ કર્યા પછી, અમે અમારી એન્ટરપ્રાઇઝ જરૂરિયાતો માટે શ્રેષ્ઠ વિકલ્પ તરીકે Kubernetes અપનાવવાનું નક્કી કર્યું છે. Kubernetes પસંદ કરવાના અમારા કારણો આ છે:

1. **માપનીયતા:**  Kubernetes ની અનન્ય ડિઝાઇન એપ્લિકેશનોને માપવા માટે સંપૂર્ણ છે, અને સમય સાથે અમારી માપનીયતાની જરૂરિયાતો વિકસે તેમ, Kubernetes પાસે આ ફેરફારોને કોઈપણ સમસ્યા વિના પહોંચી વળવાની બિલ્ટ-ઇન ક્ષમતા છે.

2. **વિકેન્દ્રિત આર્કિટેક્ચર:**  Kubernetes ની master-worker ટોપોલોજી વિકેન્દ્રિત આર્કિટેક્ચર સુનિશ્ચિત કરે છે જે ખાતરી કરે છે કે કોઈ એક નિષ્ફળતા બિંદુ નથી.

3. **સમુદાય સમર્થન:**  Kubernetes પાસે સૌથી મોટો અને સૌથી સક્રિય ઓપન-સોર્સ સમુદાય છે, એનો અર્થ એ કે તેની પાસે યોગદાનકર્તાઓ, ડેવલપર્સ અને વિક્રેતાઓની મોટી સંખ્યા છે જે અમારા માટે મદદ મેળવવી અને સંસાધનો શોધવાનું સરળ બનાવે છે.

4. **ઇકોસિસ્ટમ સમર્થન:**  Kubernetes પાસે તૃતીય-પક્ષ સાધનો, કન્ટેનર રજિસ્ટ્રી, CI/CD પાઇપલાઇન, ડેટા સ્ટોરેજ અને વધુ સાથે ઇન્ટિગ્રેશનની વિવિધતા સાથેની વિકસતી ઇકોસિસ્ટમ છે.

તેથી, અમે Kubernetes ને અમારા કન્ટેનર ઓર્કેસ્ટ્રેશન પ્લેટફોર્મ તરીકે વર્તમાન અને નજીકના ભવિષ્ય માટે અપનાવવાનું નક્કી કર્યું છે.
