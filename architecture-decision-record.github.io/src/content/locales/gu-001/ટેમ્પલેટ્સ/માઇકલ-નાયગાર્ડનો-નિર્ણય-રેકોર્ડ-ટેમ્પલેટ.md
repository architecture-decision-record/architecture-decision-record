# Michael Nygard નો નિર્ણય રેકોર્ડ ટેમ્પલેટ

આ [Documenting architecture decisions - Michael Nygard](http://thinkrelevance.com/blog/2011/11/15/documenting-architecture-decisions) માંનો ટેમ્પલેટ છે.
ADR ફાઇલોનું સંચાલન કરવા માટે તમે [adr-tools](https://github.com/npryce/adr-tools) વાપરી શકો છો.

દરેક ADR ફાઇલમાં, આ વિભાગો લખો:

# શીર્ષક

## સ્થિતિ

સ્થિતિ શું છે, જેમ કે પ્રસ્તાવિત, સ્વીકૃત, નકારાયેલ, અપ્રચલિત, બદલાયેલ, વગેરે?

## સંદર્ભ

આપણે કઈ સમસ્યા જોઈ રહ્યા છીએ જે આ નિર્ણય અથવા ફેરફાર માટે પ્રેરણા આપી રહી છે?

## નિર્ણય

આપણે કયો ફેરફાર પ્રસ્તાવિત કરી રહ્યા છીએ અને/અથવા કરી રહ્યા છીએ?

## પરિણામો

આ ફેરફારને કારણે શું કરવું વધુ સરળ અથવા વધુ મુશ્કેલ બને છે?
