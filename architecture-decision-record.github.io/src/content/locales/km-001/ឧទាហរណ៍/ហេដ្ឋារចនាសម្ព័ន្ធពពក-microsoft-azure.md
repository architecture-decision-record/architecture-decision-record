# កំណត់ត្រាការសម្រេចចិត្តខាងស្ថាបត្យកម្ម៖ ហេដ្ឋារចនាសម្ព័ន្ធពពក Microsoft Azure

ចំណងជើងការសម្រេចចិត្ត៖ ការទទួលយក Microsoft Azure ជាហេដ្ឋារចនាសម្ព័ន្ធពពកសម្រាប់អង្គការរបស់យើង

អ្នកសម្រេចចិត្ត៖ នាយកព័ត៌មាន

កាលបរិច្ឆេទ៖ 2021-10-15

ស្ថានភាព៖ បានអនុម័ត

## ប្រវត្តិ

អង្គការកំពុងគ្រោងផ្លាស់ប្តូរពីហេដ្ឋារចនាសម្ព័ន្ធនៅនឹងទីតាំងបែបប្រពៃណីទៅហេដ្ឋារចនាសម្ព័ន្ធពពក។ ដើម្បីសម្រេចបាននេះ អង្គការបានវាយតម្លៃអ្នកផ្តល់សេវាកម្មពពកច្រើន ដូចជា Amazon Web Services (AWS), Google Cloud Platform (GCP), Microsoft Azure និង IBM Cloud។ អ្នកផ្តល់សេវានីមួយៗមានសំណុំមុខងារ អត្ថប្រយោជន៍ និងរចនាសម្ព័ន្ធតម្លៃផ្ទាល់ខ្លួន។ បន្ទាប់ពីការវិភាគលម្អិត គេបានសន្និដ្ឋានថា Microsoft Azure គឺជាជម្រើសសមស្របបំផុតសម្រាប់អង្គការរបស់យើង។

## ការសម្រេចចិត្ត

ទទួលយក Microsoft Azure ជាហេដ្ឋារចនាសម្ព័ន្ធពពកសម្រាប់អង្គការរបស់យើង។

## ហេតុផល

ខាងក្រោមនេះជាហេតុផលសម្រាប់ការទទួលយក Microsoft Azure៖

1. សេវាកម្មពេញលេញ៖ Azure ផ្តល់សេវាកម្មពពកពេញលេញ ពីហេដ្ឋារចនាសម្ព័ន្ធជាសេវា (IaaS) ដល់កម្មវិធីជាសេវា (SaaS) និងវេទិកាជាសេវា (PaaS)។ នេះអនុញ្ញាតឱ្យយើងប្រើសេវាកម្ម Azure ដើម្បីដោះស្រាយតម្រូវការរបស់អង្គការ ដូចជាការផ្ទុក កុំព្យូទ័រ បណ្តាញ និងការវិភាគ។

2. ភាពអាចពង្រីកបាន និងភាពបត់បែន៖ ជាមួយ Azure យើងអាចពង្រីក ឬបន្ថយធនធានបានយ៉ាងងាយ ដោយផ្អែកលើតម្រូវការអាជីវកម្មរបស់យើង។ Azure ក៏ផ្តល់ភាពបត់បែនក្នុងការជ្រើសរើសប្រព័ន្ធប្រតិបត្តិការ ភាសាសរសេរកម្មវិធី និងក្របខ័ណ្ឌ។

3. សុវត្ថិភាព និងការអនុលោម៖ Azure ផ្តល់កម្រិតសុវត្ថិភាព និងការអនុលោមខ្ពស់ ដោយសារវាអនុលោមតាមស្តង់ដារឧស្សាហកម្មជាច្រើនដូចជា ISO, SOC, HIPAA និង PCI DSS។ Azure ក៏ផ្តល់មុខងារសុវត្ថិភាពទំនើបដូចជាក្រុមសុវត្ថិភាពបណ្តាញ ជញ្ជាំងភ្លើង និងការការពារ DDoS។

4. ពពកកូនកាត់៖ Azure ផ្តល់បទពិសោធន៍ពពកកូនកាត់រលូន ដែលអនុញ្ញាតឱ្យអង្គការភ្ជាប់ហេដ្ឋារចនាសម្ព័ន្ធនៅនឹងទីតាំងរបស់ពួកគេជាមួយ Azure។ នេះធ្វើឱ្យយើងងាយផ្លាស់ប្តូរបន្ទុកការងារទៅពពក និងផ្តល់ភាពបត់បែនក្នុងការជ្រើសរើសកន្លែងផ្ទុកទិន្នន័យ។

5. ប្រសិទ្ធភាពថ្លៃដើម៖ Azure ផ្តល់គំរូតម្លៃបង់ប្រាក់តាមការប្រើប្រាស់ ដែលមានន័យថាយើងបង់ប្រាក់តែសម្រាប់ធនធានដែលបានប្រើប៉ុណ្ណោះ។ នេះជួយយើងសន្សំថ្លៃដើមធៀបនឹងហេដ្ឋារចនាសម្ព័ន្ធនៅនឹងទីតាំងបែបប្រពៃណី។

## សេចក្តីសន្និដ្ឋាន

ការទទួលយក Microsoft Azure ជាហេដ្ឋារចនាសម្ព័ន្ធពពកសម្រាប់អង្គការរបស់យើង ស្របនឹងតម្រូវការអាជីវកម្មរបស់យើង ហើយផ្តល់អត្ថប្រយោជន៍ជាច្រើនដូចជាភាពអាចពង្រីកបាន ភាពបត់បែន សុវត្ថិភាព និងប្រសិទ្ធភាពថ្លៃដើម។ ដូច្នេះ គេណែនាំឱ្យទទួលយក Azure ជាហេដ្ឋារចនាសម្ព័ន្ធពពករបស់យើង។
