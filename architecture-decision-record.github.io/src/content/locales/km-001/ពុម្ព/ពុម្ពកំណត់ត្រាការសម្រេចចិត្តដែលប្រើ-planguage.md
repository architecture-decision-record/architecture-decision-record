# ពុម្ពកំណត់ត្រាការសម្រេចចិត្តដែលប្រើ Planguage

សូមមើល https://www.iaria.org/conferences2012/filesICCGI12/Tutorial%20Specifying%20Effective%20Non-func.pdf

## Planguage គឺជាអ្វី?

Planguage គឺជាភាសារៀបចំផែនការដែលប្រើពាក្យគន្លឹះទាំងនេះ៖

* Tag: អត្តសញ្ញាណតែមួយគត់ និងអចិន្ត្រៃយ៍
* Gist: សេចក្តីសង្ខេបខ្លីនៃតម្រូវការ ឬផ្នែកដែលបានដោះស្រាយ
* Requirement: អត្ថបទដែលពិពណ៌នាលម្អិតអំពីតម្រូវការខ្លួនឯង
* Rationale: ហេតុផលដែលបញ្ជាក់ភាពត្រឹមត្រូវនៃតម្រូវការ
* Priority: សេចក្តីថ្លែងអំពីអាទិភាព និងការទាមទារធនធាន
* Stakeholders: ភាគីដែលរងផលប៉ះពាល់ជាសារវន្តដោយតម្រូវការ
* Status: ស្ថានភាពនៃតម្រូវការ (សេចក្តីព្រាង បានពិនិត្យ បានប្តេជ្ញា ។ល។)
* Owner: អ្នកទទួលខុសត្រូវក្នុងការអនុវត្តតម្រូវការ
* Author: អ្នកដែលបានសរសេរតម្រូវការ
* Revision: លេខកំណែសម្រាប់សេចក្តីថ្លែង
* Date: កាលបរិច្ឆេទនៃការកែសម្រួលចុងក្រោយបំផុត
* Assumptions: អ្វីៗដែលអាចបង្កបញ្ហា ប្រសិនបើមិនពិតឥឡូវនេះ ឬពេលក្រោយ
* Risks: អ្វីៗដែលអាចបង្កការដំណើរការខុស ការពន្យារពេល ឬផលប៉ះពាល់អវិជ្ជមានផ្សេងទៀត
* Defined: និយមន័យនៃពាក្យមួយ (ប្រសើរជាងប្រើសទ្ទានុក្រម)
