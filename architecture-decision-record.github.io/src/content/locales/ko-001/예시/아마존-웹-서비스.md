# Amazon Web Services에 대한 아키텍처 의사결정 기록

제목: 클라우드 인프라를 위한 Amazon Web Services 도입

## 결정

다양한 클라우드 인프라 플랫폼에 대한 철저한 평가 끝에, 우리 조직의 클라우드 인프라 요구를 위해 Amazon Web Services(AWS)를 도입하기로 결정했습니다.

## 배경

우리 조직은 빠르게 성장하고 있으며 비즈니스의 요구를 충족할 신뢰할 수 있고 확장 가능한 클라우드 인프라가 필요합니다. 여러 클라우드 인프라 제공업체를 검토한 결과, AWS가 현재와 미래의 요구사항을 충족하기에 가장 적합한 서비스 범위를 제공한다고 결론 내렸습니다.

## 고려 사항

시장에는 신뢰할 수 있고 효율적임이 입증된 클라우드 인프라 제공업체가 많습니다. 그러나 AWS는 우리의 요구를 충족하는 포괄적인 서비스 집합을 제공할 뿐 아니라 광범위한 고객 기반과 성공적인 배포 실적을 가지고 있습니다. 또한 AWS는 우리 팀이 플랫폼을 효과적으로 다룰 수 있도록 폭넓은 지원 및 교육 자원을 제공합니다.

더욱이 AWS는 전 세계 여러 리전에 데이터 센터를 둔 광범위한 글로벌 입지를 갖추고 있습니다. 이는 우리의 데이터가 안전하고 애플리케이션과 서비스가 높은 가용성을 갖도록 보장합니다. 또한 AWS는 우리 비즈니스에 매우 중요한 견고한 보안 프레임워크를 갖추고 있습니다.

마지막으로 AWS는 사용한 만큼 지불하는 모델을 제공하여 수요에 따라 인프라를 확장할 수 있는 유연성을 줍니다. 이는 사용한 것에 대해서만 비용이 청구된다는 뜻이며, 비용을 최적화하고 사업의 다른 영역에 투자할 수 있게 해 줍니다.

## 결정

수행한 평가와 AWS가 제공하는 이점을 바탕으로, 클라우드 인프라 요구를 위해 AWS를 도입하기로 결정했습니다.

## 결과

AWS 도입에는 팀이 플랫폼에 익숙해지고 효과적으로 활용할 수 있도록 하는 교육이 필요할 수 있습니다. 또한 현재 인프라를 AWS 플랫폼으로 옮기는 데 일부 초기 비용이 들 수 있습니다.

## 소유권

AWS의 효과적인 활용과 관련 위험 관리를 보장할 책임은 클라우드 인프라 팀의 소관입니다. 발생하는 모든 문제는 이 팀이 해결해야 합니다.

## 검토

AWS 도입 결정은 우리의 요구를 계속 충족하는지, 그리고 플랫폼의 이점이 충분히 실현되고 있는지 확인하기 위해 매년 검토합니다.
