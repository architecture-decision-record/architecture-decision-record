# 알렉산드리아 패턴을 위한 의사결정 기록 템플릿

## 소개

* 프롤로그(요약)
* 논의(맥락)
* 해결책(결정)
* 결과(성과)

## 세부 사항 ##

* 프롤로그(요약)
  * 요약하는 진술:
    * (사용 사례)의 맥락에서<br>
      (우려)에 직면하여<br>
      우리는 (선택지)를 결정했다<br>
      (품질)을 달성하기 위해<br>
      (단점)을 감수하면서.
* 논의(맥락)
  * 작용하는 힘(기술적, 정치적, 사회적, 프로젝트상)을 설명합니다.
  * 이것은 우리가 해결하려는 문제를 설명하는 이야기입니다.
* 해결책
  * 결정이 문제를 어떻게 해결할지 설명합니다.
* 결과
  * 장기적으로 결정의 결과를 설명합니다.
  * 효과가 있었는지, 없었는지, 변경되었는지, 업그레이드되었는지 등.
