# Planguage를 사용한 의사결정 기록 템플릿

https://www.iaria.org/conferences2012/filesICCGI12/Tutorial%20Specifying%20Effective%20Non-func.pdf 를 참조하십시오

## Planguage란?

Planguage는 다음 키워드를 사용하는 계획 언어입니다:

* Tag: 고유하고 지속적인 식별자
* Gist: 다루는 요구사항이나 영역의 간단한 요약
* Requirement: 요구사항 자체를 상세히 기술하는 텍스트
* Rationale: 요구사항을 정당화하는 추론
* Priority: 우선순위와 자원에 대한 청구권의 진술
* Stakeholders: 요구사항에 실질적으로 영향을 받는 당사자
* Status: 요구사항의 상태(draft, reviewed, committed 등)
* Owner: 요구사항 구현에 책임이 있는 사람
* Author: 요구사항을 작성한 사람
* Revision: 진술의 버전 번호
* Date: 가장 최근 개정 날짜
* Assumptions: 지금 또는 나중에 사실이 아니면 문제를 일으킬 수 있는 모든 것
* Risks: 오작동, 지연 또는 기타 부정적 영향을 일으킬 수 있는 모든 것
* Defined: 용어의 정의(용어집을 사용하는 편이 더 좋음)
