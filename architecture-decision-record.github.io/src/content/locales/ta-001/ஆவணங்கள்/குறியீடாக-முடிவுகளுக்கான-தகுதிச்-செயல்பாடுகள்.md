# குறியீடாக முடிவுகளுக்கான தகுதிச் செயல்பாடுகள்

தகுதிச் செயல்பாடுகள் (fitness functions) என்பவை நிரலாக்கக் குறியீட்டால் எழுதப்பட்ட, முடிவுகள் பேணப்படுகின்றனவா என்பதைச் சரிபார்க்கும் புறநிலைத் தானியங்கிச் சோதனைகள்.

- தகுதிச் செயல்பாடுகள் முடிவுகளைச் சோதிக்கக்கூடியவையாகவும் உறுதிப்படுத்தக்கூடியவையாகவும் ஆக்குகின்றன.

- முடிவுகளுக்கான தகுதிச் செயல்பாடுகள் தர உறுதி, ஒழுங்குமுறைச் செயல்முறைகள், நிர்வாக இலக்குகளுக்கு பெரிதும் உதவும்.

## தகுதிச் செயல்பாடுகள் முடிவுகளுடன் எவ்வாறு இணைகின்றன

முடிவுப் பதிவு முடிவை ஆவணப்படுத்துகிறது, தகுதிச் செயல்பாடு முடிவை உறுதிப்படுத்துகிறது.

- எடுத்துக்காட்டு முடிவு: தணிக்கைத் தேவைகளுக்காக நாங்கள் event sourcing ஐப் பயன்படுத்துகிறோம்.

- எடுத்துக்காட்டுத் தகுதிச் செயல்பாடு: அனைத்து நிலை மாற்றங்களும் நிகழ்வுகளை உருவாக்க வேண்டும் என்பதைச் சோதிக்கத் தொடர்ச்சியான ஒருங்கிணைப்புச் சேவையகத்தைப் பயன்படுத்துகிறோம்.

## தகுதிச் செயல்பாடுகள் முடிவுகளுக்கு ஏன் உதவுகின்றன

புறநிலை அளவீடுகள்: தகுதிச் செயல்பாடுகள் தேர்ச்சி அல்லது தோல்வி அடைகின்றன, எனவே வேலை புலப்படும்படியும் தெளிவாகவும் உள்ளது.

தொடர்ச்சியான பயன்பாடு: தகுதிச் செயல்பாடுகள் உங்கள் உயிருள்ள விதிகள், ஒவ்வொரு commit மற்றும் build இலும் இயக்கப்படுகின்றன.

மறுசீரமைக்கும் நம்பிக்கை: தகுதிச் செயல்பாடுகள் முடிவு விதிப் பிழைகளைத் தானாகவே பிடிக்கின்றன.

அளவிடக்கூடிய நிர்வாகம்: தகுதிச் செயல்பாடுகள் தடைகளை உருவாக்காமல் தரநிலைகளை உறுதிப்படுத்துகின்றன.

## தகுதிச் செயல்பாடுகள் AI ஐப் பயன்படுத்த முடியுமா?

தகுதிச் செயல்பாடுகள் உங்கள் திட்டங்கள், குறியீடு, வரைவுகள், API கள் மற்றும் பலவற்றைப் பற்றிய உங்கள் வேலைக்கான கேள்விகளைக் கேட்பதன் மூலம் முடிவுகளுக்கு AI LLM களைப் பயன்படுத்தலாம்:

```txt
IMPORTANT: Prefer retrieval-led reasoning over pre-training-led reasoning.
IMPORTANT: Turn on extended thinking. Turn on expert advice. Turn on search.

This is a fitness function to evaluate if our work is
using all our decisions, and is correct and accurate.

- Our decisions are here: {url}
- Our work to evaluate is here: {url}

Explain any errors, problems, gaps, weaknesses. Be direct. Be decisive.
```

[ArchUnitTS](https://github.com/LukasNiessen/ArchUnitTS): Jest, Vitest, Jasmine போன்றவற்றைப் பயன்படுத்தி TypeScript குறியீடு மற்றும் JavaScript குறியீட்டின் கட்டமைப்பு விதிகளைச் சரிபார்க்கவும்.
