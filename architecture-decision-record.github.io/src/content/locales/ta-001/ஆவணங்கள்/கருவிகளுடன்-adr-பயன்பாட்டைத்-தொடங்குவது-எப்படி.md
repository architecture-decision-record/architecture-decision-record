## கருவிகளுடன் ADR பயன்பாட்டைத் தொடங்குவது எப்படி

- [MySpec](https://myspec.dev) — திட்ட அரசியலமைப்பு, தொழில்நுட்பக் கட்டமைப்பு, ADR களைத் தூய்மையான Markdown ஆக ஒழுங்குபடுத்தி MCP வழியாக வழங்கும் தானியங்கு விவரக்குறிப்பு மற்றும் கட்டமைப்பு முடிவுத் தளம்.

கருவிகளுடன் ADR பயன்பாட்டை நீங்கள் விரும்பிய வழியில் தொடங்கலாம்.

எடுத்துக்காட்டாக:

  * Google Drive மற்றும் இணையவழித் திருத்தத்தை விரும்பினால், நீங்கள் ஒரு Google Doc அல்லது Google Sheet உருவாக்கலாம்.

  * git போன்ற மூலக் குறியீட்டுப் பதிப்புக் கட்டுப்பாட்டை விரும்பினால், ஒவ்வொரு ADR க்கும் ஒரு கோப்பை உருவாக்கலாம்.

  * Atlassian Jira போன்ற திட்டத் திட்டமிடல் கருவிகளை விரும்பினால், கருவியின் திட்டமிடல் கண்காணிப்பானைப் பயன்படுத்தலாம்.

  * MediaWiki போன்ற விக்கிகளை விரும்பினால், ஒரு ADR விக்கியை உருவாக்கலாம்.
