# Planguage பயன்படுத்தும் முடிவு பதிவு வார்ப்புரு

பார்க்க: https://www.iaria.org/conferences2012/filesICCGI12/Tutorial%20Specifying%20Effective%20Non-func.pdf

## Planguage என்றால் என்ன?

Planguage என்பது இந்த முக்கியச் சொற்களைப் பயன்படுத்தும் திட்டமிடல் மொழி:

* Tag: தனித்துவமான, நிலையான அடையாளங்காட்டி
* Gist: தேவை அல்லது குறிப்பிடப்படும் பகுதியின் சுருக்கமான சுருக்கம்
* Requirement: தேவையையே விவரிக்கும் உரை
* Rationale: தேவையை நியாயப்படுத்தும் காரணம்
* Priority: முன்னுரிமை மற்றும் வளங்கள் மீதான உரிமைகோரலின் கூற்று
* Stakeholders: தேவையால் கணிசமாகப் பாதிக்கப்படும் தரப்பினர்
* Status: தேவையின் நிலை (வரைவு, மதிப்பாய்வு செய்யப்பட்டது, உறுதியளிக்கப்பட்டது போன்றவை)
* Owner: தேவையை நடைமுறைப்படுத்தப் பொறுப்பான நபர்
* Author: தேவையை எழுதிய நபர்
* Revision: கூற்றின் பதிப்பு எண்
* Date: சமீபத்திய திருத்தத்தின் தேதி
* Assumptions: இப்போது அல்லது பின்னர் உண்மையாக இல்லாவிட்டால் சிக்கல்களை ஏற்படுத்தக்கூடிய எதுவும்
* Risks: செயலிழப்பு, தாமதம் அல்லது பிற எதிர்மறைத் தாக்கங்களை ஏற்படுத்தக்கூடிய எதுவும்
* Defined: ஒரு சொல்லின் வரையறை (சொற்களஞ்சியத்தைப் பயன்படுத்துவது நல்லது)
