# Michael Nygard இன் முடிவு பதிவு வார்ப்புரு

இது [Documenting architecture decisions - Michael Nygard](http://thinkrelevance.com/blog/2011/11/15/documenting-architecture-decisions) இல் உள்ள வார்ப்புரு.
ADR கோப்புகளை நிர்வகிக்க [adr-tools](https://github.com/npryce/adr-tools) ஐப் பயன்படுத்தலாம்.

ஒவ்வொரு ADR கோப்பிலும், இந்தப் பகுதிகளை எழுதுங்கள்:

# தலைப்பு

## நிலை

நிலை என்ன, எடுத்துக்காட்டாக முன்மொழியப்பட்டது, ஏற்கப்பட்டது, நிராகரிக்கப்பட்டது, நிறுத்தப்பட்டது, மாற்றியமைக்கப்பட்டது போன்றவை?

## சூழல்

இந்த முடிவு அல்லது மாற்றத்தைத் தூண்டும், நாங்கள் காணும் சிக்கல் என்ன?

## முடிவு

நாங்கள் முன்மொழியும் மற்றும்/அல்லது செய்யும் மாற்றம் என்ன?

## விளைவுகள்

இந்த மாற்றத்தால் எது எளிதாகிறது அல்லது செய்ய கடினமாகிறது?
