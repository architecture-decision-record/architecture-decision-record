# கட்டமைப்பு முடிவு பதிவு: Svelte முன்-முனை JavaScript நூலகம்

நிலை: ஏற்கப்பட்டது

## சூழல்

நவீன முன்-முனை JavaScript கட்டமைப்பைப் பயன்படுத்தி வலைப் பயன்பாட்டை உருவாக்கி வருகிறோம். எடை குறைந்த, வேகமான, பயன்படுத்த எளிதான நூலகத்தைத் தேர்ந்தெடுக்க விரும்புகிறோம். React, Vue, Angular உள்ளிட்ட பல நூலகங்களை மதிப்பீடு செய்துள்ளோம். புதிய வகை எடை குறைந்த கட்டமைப்பு என்று கூறிக்கொள்ளும் Svelte பற்றியும் கேள்விப்பட்டுள்ளோம். Svelte ஐ மதிப்பீடு செய்து அது எங்கள் பயன்பாட்டிற்குப் பொருத்தமானதா என்பதை முடிவு செய்ய வேண்டும்.

## முடிவு

ஒவ்வொரு நூலகத்தின் நன்மை தீமைகளையும் பரிசீலித்த பிறகு, பின்வரும் காரணங்களுக்காக எங்கள் முன்-முனை JavaScript நூலகமாக Svelte ஐப் பயன்படுத்த முடிவு செய்துள்ளோம்:

1. **எடை குறைந்தது:**  Svelte கிடைக்கும் மிக எடை குறைந்த நூலகங்களில் ஒன்று, இது எங்கள் பயன்பாட்டின் அளவைச் சிறியதாக வைத்திருக்கவும் பக்க ஏற்ற நேரங்களை மேம்படுத்தவும் உதவும்.

2. **வேகமானது:**  Svelte அதன் வேகமான ரெண்டரிங் வேகத்திற்கு அறியப்படுகிறது, இது எங்கள் பயன்பாட்டைத் துலங்குவதாகவும் சுறுசுறுப்பாகவும் உணரச் செய்யும்.

3. **பயன்படுத்த எளிது:**  Svelte இன் தொடரியல் எளிமையானது, புரிந்துகொள்ள எளிதானது, இது எங்கள் குழு அதை ஏற்கவும் தூய்மையான குறியீட்டை எழுதவும் எளிதாக்கும்.

4. **UI ரெண்டரிங்கிற்கு உகந்தது:**  Svelte UI கூறுகளை ரெண்டர் செய்வதற்கு உகந்ததாக்கப்பட்டுள்ளது, இது இயங்குநிலை, மறுபயன்பாட்டு UI கூறுகளை உருவாக்குவதை எளிதாக்கும்.

5. **நல்ல ஆவணங்களும் சமூக ஆதரவும்:**  Svelte க்கு வளர்ந்து வரும் சமூகமும் நல்ல ஆவணங்களும் உள்ளன, இது விரைவாகத் தொடங்கவும் எழும் எந்தச் சிக்கலையும் தீர்க்கவும் உதவும்.

## மாற்றுகள்

React, Vue, Angular ஆகியவற்றைப் பரிசீலித்தோம், ஆனால் பின்வரும் காரணங்களுக்காக அவற்றுக்கு எதிராக முடிவு செய்தோம்:

1. **React:**  React க்குப் பெரிய பயனர் தளமும் நூலகங்கள் மற்றும் வளங்களின் செல்வமும் இருந்தாலும், அது சிக்கலானதாகவும், குறிப்பாகத் தொடக்கநிலையாளர்களுக்குக் கற்கக் கடினமாகவும் இருக்கலாம்.

2. **Vue:**  Vue என்பது கற்கவும் பயன்படுத்தவும் எளிதான எடை குறைந்த நூலகம், ஆனால் அது Svelte அளவுக்கு வேகமாகவோ உகந்ததாகவோ இல்லாமல் இருக்கலாம்.

3. **Angular:**  Angular என்பது பல அம்சங்களையும் கருவிகளையும் வழங்கும் விரிவான கட்டமைப்பு, ஆனால் அது கனமாகவும் சிக்கலாகவும் இருக்கலாம், Svelte ஐ விட அதிகப் பராமரிப்பு தேவைப்படலாம்.

## விளைவுகள்

எங்கள் முன்-முனை JavaScript நூலகமாக Svelte ஐப் பயன்படுத்துவது பின்வரும் விளைவுகளை ஏற்படுத்தும்:

1. எங்கள் பயன்பாடு எடை குறைந்ததாகவும் வேகமாகவும் இருக்கும், இது பயனர் அனுபவத்தையும் ஈடுபாட்டையும் மேம்படுத்தும்.

2. எங்கள் குழு புதிய நூலகத்தைக் கற்க வேண்டும், ஆனால் Svelte இன் தொடரியல் எளிமையானது, புரிந்துகொள்ள எளிதானது, எனவே கற்றல் வளைவு நிர்வகிக்கக்கூடியதாக இருக்க வேண்டும்.

3. Svelte இன்னும் ஒப்பீட்டளவில் புதிய நூலகம், எனவே சமூகத்தால் நன்கு ஆவணப்படுத்தப்படாத அல்லது ஆதரிக்கப்படாத சில சிக்கல்களை எதிர்கொள்ளலாம்.

4. Svelte பயனர்களின் சமூகம் வளர்ந்து வருகிறது, எனவே மைய நூலகத்தை நிரப்பப் பயன்படுத்தக்கூடிய மேலும் மூன்றாம் தரப்பு நூலகங்களும் வளங்களும் எதிர்காலத்தில் கிடைப்பதைக் காணலாம்.
