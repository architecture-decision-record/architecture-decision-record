# கட்டமைப்பு முடிவு பதிவு: Rust நிரலாக்க மொழி

முடிவு எண்: AR-001

முடிவுத் தலைப்பு: Rust நிரலாக்க மொழியை ஏற்றல்

தேதி: டிசம்பர் 1, 2021

நிலை: ஏற்கப்பட்டது

### சிக்கல் கூற்று

மென்பொருள் பயன்பாடுகளை நாங்கள் தொடர்ந்து உருவாக்கும்போது, சாத்தியமான பாதுகாப்புப் பாதிப்புகளைத் தணிப்பதும் இயக்கநேரப் பிழைகளைத் தடுப்பதும் அதிகரித்து வரும் சவாலாக இருப்பதை நாங்கள் கவனித்துள்ளோம். C மற்றும் C++ போன்ற இருக்கும் நிரலாக்க மொழிகளில், buffer overflow, நினைவகக் கசிவுகள், வரையறுக்கப்படாத நடத்தை போன்ற சிக்கல்களை நாங்கள் தொடர்ந்து சந்திக்கிறோம், இவை பயன்பாடுகள் செயலிழக்க வழிவகுக்கின்றன. நினைவகப் பாதுகாப்பு உத்தரவாதங்களை வழங்கும், செயல்திறன்-முக்கியப் பயன்பாடுகளை ஆதரிக்கும் அளவுக்குத் திறமையான நிரலாக்க மொழி எங்களுக்குத் தேவை.

### பரிசீலனைகள்

இருக்கும் சிக்கல்களைக் கையாள பல நிரலாக்க மொழிகள் வடிவமைக்கப்பட்டுள்ளன. அவற்றில், Rust நிரலாக்க மொழி அதன் தனித்துவமான வடிவமைப்பு அம்சங்களால் உருவாக்குநர்கள் சமூகத்தின் குறிப்பிடத்தக்க கவனத்தைப் பெற்றுள்ளது. பரிசீலனைகள் பின்வருமாறு;

1. நினைவகப் பாதுகாப்பும் பாதுகாப்பும்

2. செயல்திறனும் திறனும்

3. சமூக ஆதரவும் ஏற்பும்

4. கற்றல் வளைவு

5. கருவிகளும் சூழல்மண்டலமும்

6. இருக்கும் மென்பொருள் அமைப்புகளுடன் இணக்கத்தன்மை.

### கட்டுப்பாடுகள்

புதிய நிரலாக்க மொழியை ஏற்பதற்கு உருவாக்குநர்களுக்கு மறுபயிற்சி அளிக்க வேண்டும், இதற்கு நேரமும் வளங்களும் ஆகும். மொழியை இருக்கும் மேம்பாட்டுப் பணிப்பாய்வில் ஒருங்கிணைப்பது சவாலாக இருக்கலாம். இருக்கும் அமைப்புகளுடன் இணக்கத்தன்மையை உறுதிசெய்து, தொடர்ச்சியைப் பேண உடைக்கும் மாற்றங்களைத் தவிர்க்க வேண்டும்.

### நடைமுறைப்படுத்தல்

1. எங்கள் மேம்பாட்டுக் குழு Rust நிரலாக்க மொழியைக் கற்றுப் பரிச்சயம் பெற பயிற்சி பெறும்.

2. எங்கள் மேம்பாட்டு நோக்கங்களுக்கு அதன் இணக்கத்தன்மையையும் பொருத்தத்தையும் மதிப்பிட Rust ஐப் பயன்படுத்தி சோதனை அடிப்படையில் புதிய திட்டத்தை உருவாக்குவோம்.

3. C மற்றும் C++ இல் எழுதப்பட்ட இருக்கும் அமைப்புகளை படிப்படியாக Rust க்கு இடம்பெயர்ப்போம்.

4. எங்கள் மேம்பாட்டுப் பணிப்பாய்வை மேம்படுத்தக்கூடிய கிடைக்கும் கருவிகளையும் நூலகங்களையும் ஆராய Rust சமூகத்துடன் ஒத்துழைப்போம்.

5. Rust இன் செயல்திறனைக் கண்காணித்து, இருக்கும் நிரலாக்க மொழிகளின் செயல்திறனுடன் தவறாமல் ஒப்பிடுவோம்.

6. பயிற்சி, ஒருங்கிணைப்பின் செலவுகளையும் Rust ஐப் பயன்படுத்துவதன் சாத்தியமான நன்மைகளையும் சமநிலைப்படுத்தும் நீண்டகால அணுகுமுறையை ஏற்போம்.

### நியாயம்

செயல்திறனையும் திறனையும் பேணும் அதே வேளையில் நினைவகப் பாதுகாப்பு மற்றும் பாதுகாப்பு உத்தரவாதங்களை வழங்க வடிவமைக்கப்பட்ட அதன் தனித்துவமான அம்சங்களால் Rust ஐ ஏற்றுள்ளோம். Rust இன் வலுவான வகை அமைப்பு, borrow checker, நினைவகப் பாதுகாப்புக் கருத்துகள் செயல்திறன்-முக்கிய மற்றும் பாதுகாப்பு-முக்கியப் பயன்பாடுகளை உருவாக்க அதை மிகவும் பொருத்தமாக்குகின்றன. மேலும், Rust க்கு உருவாக்குநர்களின் குறிப்பிடத்தக்க சமூகம் உள்ளது, இது எங்கள் மேம்பாட்டுப் பணிப்பாய்வை ஆதரிக்கும் கருவிகள், நூலகங்கள், சூழல்மண்டலத்தின் பரந்த வரம்பை அணுக எங்களை அனுமதிக்கிறது. Rust க்குக் கற்றல் வளைவு இருந்தாலும், Rust ஐ ஏற்பதன் நன்மைகள் செலவுகளை விட அதிகம் என்றும், தொடர்ச்சியான வளர்ச்சி மற்றும் புதுமைக்கு சிறந்த வாய்ப்பை வழங்குகின்றன என்றும் நம்புகிறோம்.

### விளைவுகள்

1. Rust ஐ ஏற்பதற்கு உருவாக்குநர்களுக்குப் பயிற்சி அளிக்கவும் மொழியை இருக்கும் மேம்பாட்டுப் பணிப்பாய்வில் ஒருங்கிணைக்கவும் நேரத்திலும் வளங்களிலும் குறிப்பிடத்தக்க முதலீடு தேவைப்படும்.

2. Rust ஐ ஏற்பது இருக்கும் அமைப்புகளுடன் சிறிதளவு இணக்கத்தன்மைச் சிக்கல்களை ஏற்படுத்தலாம், மறுசீரமைப்பும் மாற்றங்களும் தேவைப்படும்.

3. உற்சாகமான திட்டங்களில் பணியாற்ற விரும்பும் Rust உருவாக்குநர்களை ஈர்ப்பதன் மூலம் Rust ஐ ஏற்பது எங்கள் திட்டத்துக்குப் பங்களிக்கக்கூடிய உருவாக்குநர்களின் எண்ணிக்கையை அதிகரிக்கலாம்.

4. இந்த ஏற்பு இருக்கும் மொழிகளுடன் ஒப்பிடும்போது மேம்பட்ட செயல்திறன், திறன், பாதுகாப்புக்கு வழிவகுக்கலாம்.

5. இறுதியாக, Rust ஐ ஏற்பது எங்கள் பயன்பாடுகளில் பாதுகாப்புப் பாதிப்புகளைக் குறைக்கும் சாத்தியமான நன்மையுடன் வருகிறது.
