# கட்டமைப்பு முடிவு பதிவு: நிரலாக்கக் குறியீட்டுத் தொகுப்பான்கள்

## சூழல்

நிரலாக்கக் குறியீட்டுத் தொகுப்பான்கள் உருவாக்குநர்கள் குறியீட்டை எழுதவும் திருத்தவும் அத்தியாவசியக் கருவி. பல குறியீட்டுத் தொகுப்பான்கள் உள்ளன, ஒவ்வொன்றுக்கும் அதன் சொந்த அம்சங்கள், நன்மைகள், தீமைகள் உள்ளன. நிரலாக்கக் குறியீட்டுத் தொகுப்பான்களுக்காக எடுக்கப்பட்ட கட்டமைப்பு முடிவுகளை ஆவணப்படுத்துவதே இந்த ADR இன் நோக்கம்.

## முன்னுரிமைகள்

நிரலாக்கக் குறியீட்டுத் தொகுப்பான்களுக்கான கட்டமைப்பு பின்வருவனவற்றுக்கு முன்னுரிமை அளிக்க வேண்டும்:

* **தொகுதித்தன்மை**: குறியீட்டுத் தொகுப்பான் தொகுதித்தன்மையுடன் வடிவமைக்கப்பட வேண்டும், உருவாக்குநர்கள் தேவைக்கேற்ப அதைத் தனிப்பயனாக்கவும் விரிவுபடுத்தவும் அனுமதிக்க வேண்டும். இது வெவ்வேறு உருவாக்குநர்கள் மற்றும் குழுக்களின் தேவைகளுக்கு ஏற்ப தகவமைக்கக்கூடிய நெகிழ்வான கட்டமைப்பை அனுமதிக்கிறது.

* **செயல்திறன்**: குறியீட்டுத் தொகுப்பான் செயல்திறன்மிக்கதாகவும் துலங்குவதாகவும் இருக்க வேண்டும், உருவாக்குநர்கள் தாங்கள் பயன்படுத்தும் கருவியால் மெதுவாக்கப்படாமல் திறமையாக வேலை செய்ய அனுமதிக்க வேண்டும்.

* **பயனர் இடைமுகம்**: பயனர் இடைமுகம் உள்ளுணர்வுடையதாகவும் பயன்படுத்த எளிதாகவும் இருக்க வேண்டும், உருவாக்குநர்கள் தொகுப்பானுடன் போராடாமல் தங்கள் குறியீட்டில் கவனம் செலுத்த அனுமதிக்க வேண்டும்.

* **விரிவாக்கத்திறன்**: குறியீட்டுத் தொகுப்பான் மூன்றாம் தரப்புச் செருகுநிரல்கள் மற்றும் ஒருங்கிணைப்புகளுடன் எளிதில் விரிவாக்க அனுமதிக்கும் வகையில் வடிவமைக்கப்பட வேண்டும்.

* **இணக்கத்தன்மை**: குறியீட்டுத் தொகுப்பான் நிரலாக்க மொழிகள் மற்றும் தொழில்நுட்பங்களின் பரந்த வரம்புடன் இணக்கமாக இருக்க வேண்டும், இது பரந்த அளவிலான உருவாக்குநர்களுக்குப் பயனுள்ள கருவியாக்குகிறது.

## முடிவு

இந்த முன்னுரிமைகளின் அடிப்படையில், நிரலாக்கக் குறியீட்டுத் தொகுப்பான்களுக்கான கட்டமைப்பு பின்வரும் கூறுகளுடன் வடிவமைக்கப்பட வேண்டும்:

* **மையம்**: இந்தக் கூறு தொடரியல் சிறப்பம்சம், உரைத் திருத்தம், கோப்பு மேலாண்மை போன்ற குறியீட்டுத் தொகுப்பானின் அடிப்படைச் செயல்பாட்டை வழங்குகிறது.

* **UI**: இந்தக் கூறு பட்டிகள், கருவிப்பட்டைகள், விசைப்பலகைக் குறுக்குவழிகள் உட்பட குறியீட்டுத் தொகுப்பானுக்கான பயனர் இடைமுகத்தை வழங்குகிறது.

* **செருகுநிரல்கள்**: இந்தக் கூறு மூன்றாம் தரப்புச் செருகுநிரல்களை நிறுவுவதன் மூலம் குறியீட்டுத் தொகுப்பானின் செயல்பாட்டை விரிவுபடுத்த உருவாக்குநர்களை அனுமதிக்கிறது. செருகுநிரல்கள் குறியீடு நிறைவு, linting அல்லது பிழைதிருத்தம் போன்ற கூடுதல் அம்சங்களை வழங்கலாம்.

* **ஒருங்கிணைப்புகள்**: இந்தக் கூறு பதிப்புக் கட்டுப்பாட்டு அமைப்புகள், உருவாக்க அமைப்புகள் அல்லது பிழைதிருத்தக் கருவிகள் போன்ற பிற கருவிகள் மற்றும் தொழில்நுட்பங்களுடன் குறியீட்டுத் தொகுப்பான் ஒருங்கிணைய அனுமதிக்கிறது.

## நியாயம்

குறியீட்டுத் தொகுப்பானின் தொகுதித்தன்மை உருவாக்குநர்கள் தேவைக்கேற்ப அதைத் தனிப்பயனாக்கவும் விரிவுபடுத்தவும் அனுமதிக்கிறது. இது முக்கியம், ஏனெனில் வெவ்வேறு உருவாக்குநர்களுக்கும் குழுக்களுக்கும் வெவ்வேறு தேவைகளும் பணிப்பாய்வுகளும் உள்ளன, நெகிழ்வான கட்டமைப்பு இந்த வேறுபாடுகளுக்கு இடமளிக்க முடியும்.

* **செயல்திறன்**: முக்கியமானது, ஏனெனில் உருவாக்குநர்கள் தங்கள் கருவிகளால் மெதுவாக்கப்படாமல் திறமையாக வேலை செய்ய முடிய வேண்டும். செயல்திறன்மிக்க குறியீட்டுத் தொகுப்பான் உற்பத்தித்திறனுக்கு அவசியம், உருவாக்குநர்கள் தங்கள் கவனத்தையும் ஒருமுகப்பாட்டையும் பராமரிக்க உதவும்.

* **UI**: முக்கியமானது, ஏனெனில் இது உருவாக்குநர்கள் தொகுப்பானுடன் போராடாமல் தங்கள் குறியீட்டில் கவனம் செலுத்த அனுமதிக்கிறது. இது உருவாக்குநர்களுக்குச் சிறந்த உற்பத்தித்திறனுக்கும் குறைந்த விரக்திக்கும் வழிவகுக்கும்.

* **விரிவாக்கத்திறன்**: சக்திவாய்ந்தது, ஏனெனில் இது குறியீட்டுத் தொகுப்பானை வெவ்வேறு தேவைகள் மற்றும் பணிப்பாய்வுகளுக்கு ஏற்ப தகவமைக்க அனுமதிக்கிறது. மூன்றாம் தரப்புச் செருகுநிரல்கள் மற்றும் ஒருங்கிணைப்புகள் மைய தொகுப்பானில் சேர்க்கப்படாத கூடுதல் அம்சங்களையும் திறன்களையும் வழங்கலாம்.

* **இணக்கத்தன்மை**: மதிப்புமிக்கது, ஏனெனில் இது குறியீட்டுத் தொகுப்பானை நிரலாக்க மொழிகள் மற்றும் தொழில்நுட்பங்களின் பரந்த வரம்புடன் பயன்படுத்த அனுமதிக்கிறது. இது தொகுப்பானைப் பரந்த அளவிலான உருவாக்குநர்களுக்கு மிகவும் பயனுள்ள கருவியாக்குகிறது.

மையம், செருகுநிரல்கள், ஒருங்கிணைப்புகள், UI கூறுகள் கவலைகளின் தெளிவான பிரிப்பை வழங்குகின்றன, எளிதில் விரிவாக்கவும் தனிப்பயனாக்கவும் கூடிய தொகுதி கட்டமைப்பை அனுமதிக்கின்றன. இந்தக் கட்டமைப்பு நெகிழ்வானது, செயல்திறன்மிக்கது, நிரலாக்க மொழிகள் மற்றும் தொழில்நுட்பங்களின் பரந்த வரம்புடன் இணக்கமானது, இது உருவாக்குநர்களுக்குப் பயனுள்ள கருவியாக்குகிறது.
