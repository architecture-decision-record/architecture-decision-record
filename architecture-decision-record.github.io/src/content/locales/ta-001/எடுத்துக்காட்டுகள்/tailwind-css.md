# கட்டமைப்பு முடிவு பதிவு: Tailwind CSS

முடிவு: பயனர் இடைமுகத்துக்குப் பாணியிட CSS கட்டமைப்பாக Tailwind CSS ஐப் பயன்படுத்தவும்.

## Tailwind CSS என்றால் என்ன?

Tailwind என்பது பயனர் இடைமுகங்களை விரைவாக உருவாக்கவும் தனிப்பயனாக்கவும் அனுமதிக்கும் utility-first CSS கட்டமைப்பு. இது மிகவும் தனிப்பயனாக்கக்கூடியதாக வடிவமைக்கப்பட்டுள்ளது, உருவாக்குநர்கள் மெலிந்த, திறமையான CSS எழுத அனுமதிக்கிறது. UI ஐ மிக வேகமாகப் பாணியிட, முன்பே வரையறுக்கப்பட்ட வகுப்புகளின் தொகுப்பை இந்தக் கட்டமைப்பு வழங்குகிறது.

## சூழல்

துலங்கும், தனிப்பயனாக்கக்கூடிய பயனர் இடைமுகம் தேவைப்படும் வாடிக்கையாளருக்கு வலைப் பயன்பாட்டை உருவாக்குகிறோம். வாடிக்கையாளர் சீரான, நவீனப் பாணியைக் கேட்டுள்ளார். மேம்பாட்டுக் குழுவுக்குத் தனிப்பயன் CSS ஐப் பயன்படுத்தும் அனுபவம் உள்ளது, ஆனால் நேரத்தையும் முயற்சியையும் சேமிக்கக்கூடிய CSS கட்டமைப்புகளை ஆராய விரும்புகிறது. பயன்படுத்த எளிதான, தனிப்பயனாக்கக்கூடிய, ஆதரவுக்குப் பெரிய சமூகம் கொண்ட கட்டமைப்பைத் தேடுகிறோம்.

## முடிவுக்கான உந்து காரணிகள்

- **பயன்படுத்த எளிது:**  கற்க எளிதான, எங்கள் மேம்பாட்டுப் பணிப்பாய்வில் ஒருங்கிணைக்கக்கூடிய கட்டமைப்பு எங்களுக்கு வேண்டும்.

- **தனிப்பயனாக்கக்கூடியது:**  வாடிக்கையாளரின் வர்த்தகமுத்திரை வழிகாட்டுதல்கள் மற்றும் கருப்பொருளுக்கு ஏற்ப தனிப்பயனாக்கக்கூடிய கட்டமைப்பு எங்களுக்கு வேண்டும்.

- **பெரிய சமூக ஆதரவு:**  தேவைப்படும்போது உதவியும் வளங்களும் வழங்கக்கூடிய உருவாக்குநர்கள் மற்றும் வடிவமைப்பாளர்களின் செயலில் உள்ள சமூகம் கொண்ட கட்டமைப்பு எங்களுக்கு வேண்டும்.

- **நேரம் சேமிப்பு:**  UI க்குப் பாணியிடுவதில் நேரத்தையும் முயற்சியையும் சேமிக்கக்கூடிய கட்டமைப்பு எங்களுக்கு வேண்டும்.

## பரிசீலிக்கப்பட்ட விருப்பங்கள்

- **Bootstrap:**  பல முன்-உருவாக்கப்பட்ட கூறுகளும் உருவாக்குநர்களின் பெரிய சமூகமும் கொண்ட பிரபலமான CSS கட்டமைப்பு.

- **Foundation:**  மொபைல்-முதல் மேம்பாட்டுக்காக வடிவமைக்கப்பட்ட மற்றொரு பிரபலமான CSS கட்டமைப்பு.

- **Materialize:**  UI மேம்பாட்டுக்கான முன்-உருவாக்கப்பட்ட கூறுகளுடன் Google இன் Material Design மொழியை அடிப்படையாகக் கொண்ட CSS கட்டமைப்பு.

- **Tailwind CSS:**  தனிப்பயனாக்கம் மற்றும் செயல்திறனில் கவனம் செலுத்தும் utility-first CSS கட்டமைப்பு.

## முடிவு விளைவு

விருப்பங்களைப் பரிசீலித்த பிறகு, பின்வரும் காரணங்களுக்காக Tailwind CSS ஐப் பயன்படுத்த முடிவு செய்தோம்:

- **பயன்படுத்த எளிது:**  Tailwind இன் அணுகுமுறை எளிமையானது, புரிந்துகொள்ள எளிதானது. அதன் utility வகுப்புகள் UI ஐ உருவாக்குவதை வேகமாக்குகின்றன.

- **தனிப்பயனாக்கக்கூடியது:**  Tailwind உருவாக்குநர்கள் கட்டமைப்பின் இயல்புநிலைப் பாணிகளை எளிதில் மாற்ற அனுமதிக்கும் உள்ளமைவுக் கோப்புகளின் தொகுப்பை வழங்குவதன் மூலம் தனிப்பயனாக்கத்தை அனுமதிக்கிறது.

- **பெரிய சமூக ஆதரவு:**  Tailwind க்கு தொடர்ந்து புதிய வளங்கள், செருகுநிரல்கள், கருவிகளை உருவாக்கும் உருவாக்குநர்கள் மற்றும் வடிவமைப்பாளர்களின் மிகவும் செயலில் உள்ள சமூகம் உள்ளது.

- **நேரம் சேமிப்பு:**  Tailwind நேரத்தைச் சேமிக்க முடியும், உருவாக்குநர்கள் திட்டத்தின் பிற பகுதிகளில் கவனம் செலுத்த உதவுகிறது.

எங்கள் திட்டத்துக்கான UI ஐ உருவாக்க Tailwind CSS இன் utility வகுப்புகளைப் பயன்படுத்துவோம். மேம்பாட்டுக் குழு திறமையான, அளவிடக்கூடிய CSS குறியீட்டை எழுத அதன் அணு மற்றும் தொகுதி வடிவமைப்பு அமைப்பைப் பயன்படுத்தும். வாடிக்கையாளரின் வர்த்தகமுத்திரை மற்றும் கருப்பொருளுக்குப் பொருந்தத் தனிப்பயன் பாணிகளைப் பயன்படுத்தும் அதே வேளையில், மேம்பாட்டுச் செயல்முறையை விரைவுபடுத்த Tailwind இன் முன்-உருவாக்கப்பட்ட வார்ப்புருக்களையும் காட்சிக் கூறுகளையும் பயன்படுத்துவோம்.
