# கட்டமைப்பு முடிவு பதிவு: Java நிரலாக்க மொழி

தலைப்பு: திட்டத்துக்கு Java நிரலாக்க மொழியைத் தேர்ந்தெடுத்தல்

முடிவு: பல நிரலாக்க மொழிகளை மதிப்பீடு செய்த பிறகு, எங்கள் திட்டத்துக்கு Java ஐப் பயன்படுத்த முடிவு செய்துள்ளோம்.

### பின்னணி

பல இயக்க முறைமைகளில் இயங்கக்கூடிய இணைய-அடிப்படையிலான பயன்பாட்டை உருவாக்க நாங்கள் எண்ணினோம். எங்கள் திட்டத்துக்கு வலுவான பாதுகாப்பு அம்சங்களை வழங்கக்கூடிய, ஒரே நேரச் செயல்பாட்டைக் கையாளக்கூடிய, பெரிய குறியீட்டு அடிப்படைகளை ஆதரிக்கக்கூடிய, எங்கள் எதிர்கால வளர்ச்சித் தேவைகளைப் பூர்த்தி செய்யும் அளவுக்குப் பல்துறை கொண்ட மொழி தேவைப்பட்டது. Java ஐ முடிவு செய்வதற்கு முன் அவற்றின் பலங்களையும் வரம்புகளையும் பரிசீலித்து பல மொழிகளை மதிப்பீடு செய்தோம்.

### பரிசீலனைகள்

1. **பாதுகாப்பு:**  Java அதன் நன்கு வரையறுக்கப்பட்ட பாதுகாப்புக் கொள்கைகள் மற்றும் அணுகல் கட்டுப்பாடு மூலம் சிறந்த பாதுகாப்பு அம்சங்களை வழங்குகிறது. தீங்கிழைக்கும் மென்பொருள் அமைப்பில் இயங்குவதைத் தடுக்க உதவும் bytecode சரிபார்ப்பு போன்ற அம்சங்களையும் இது கொண்டுள்ளது.

2. **ஒரே நேரச் செயல்பாடு:**  Java க்கு multithreading க்கான உள்ளமைந்த ஆதரவு உள்ளது, இது பயன்பாடுகள் ஒரே நேரத்தில் பல பணிகளைச் செய்ய அனுமதிக்கிறது. இந்த அம்சம் பல அம்சங்களும் செயல்பாடுகளும் கொண்ட பெரிய, சிக்கலான பயன்பாடுகளை உருவாக்க Java வை சிறந்த தேர்வாக்குகிறது.

3. **பெரிய குறியீட்டு அடிப்படைகள்:**  Java பொருள்-சார்ந்த நிரலாக்கத்தை ஆதரிக்கிறது, இது பெரிய குறியீட்டு அடிப்படைகளை உருவாக்க ஏற்ற தேர்வாக்குகிறது. அதன் தொகுதித் தன்மையும் உறையிடல் மற்றும் சுருக்க வடிவங்களின் பயன்பாடும் மென்பொருள் மேம்பாட்டுச் செயல்முறையின் எளிமையை மேலும் கூட்டுகின்றன.

4. **பல்துறைத்திறன்:**  Java பல்துறை கொண்டது, நூலகங்கள் மற்றும் கட்டமைப்புகளின் பரந்த வரம்பைப் பயன்படுத்தும் திறனை வழங்குகிறது, இது இணைய-அடிப்படையிலான மற்றும் நிறுவன-நிலைப் பயன்பாடுகள் இரண்டிற்கும் சிறந்த தேர்வாக்குகிறது.

### முடிவு விளைவு

அதன் பாதுகாப்பு அம்சங்கள், ஒரே நேரச் செயல்பாட்டு ஆதரவு, பெரிய குறியீட்டு அடிப்படைகளைக் கையாளும் திறன், பல்துறைத்திறன் ஆகியவற்றைக் கருத்தில் கொண்டு, எங்கள் திட்டத்துக்கு Java நிரலாக்க மொழியைப் பயன்படுத்த முடிவு செய்துள்ளோம். இந்த முடிவு எங்கள் திட்டத் தேவைகளுடன் ஒத்துப்போகிறது, Java ஐத் தேர்ந்தெடுப்பது அதன் வெற்றியை உறுதிசெய்யும் என்று நம்புகிறோம். 

### விளைவுகள்

1. Java வில் அனுபவமுள்ள, அதைத் திறம்படப் பயன்படுத்தக்கூடிய உருவாக்குநர்கள் எங்களுக்குத் தேவைப்படுவார்கள்.

2. இந்த மொழியில் எழுதப்படும் எந்தக் குறியீடும் Java Virtual Machine (JVM) உடன் இணக்கமாக இருக்க வேண்டும்.

3. புதிய அம்சங்கள், செயல்பாடுகள் அல்லது கட்டமைப்புகளை இணைப்பது சில சவால்களை ஏற்படுத்தலாம்.

4. Java வில் பெரிய, சிக்கலான திட்டங்களை உருவாக்க அதிக நேரமும் வளங்களும் தேவைப்படலாம்.
