# Arhitektūras lēmuma ieraksts: Microsoft Azure mākoņinfrastruktūra" 

Lēmuma nosaukums: Microsoft Azure ieviešana kā mūsu organizācijas mākoņinfrastruktūra

Lēmuma pieņēmējs: informācijas direktors (CIO)

Datums: 2021-10-15

Statuss: apstiprināts

## Fons

Organizācija plāno migrēt no tradicionālās uz vietas esošās infrastruktūras uz mākoņinfrastruktūru. Lai to panāktu, organizācija ir izvērtējusi vairākus mākoņpakalpojumu sniedzējus, piemēram, Amazon Web Services (AWS), Google Cloud Platform (GCP), Microsoft Azure un IBM Cloud. Katram sniedzējam ir sava funkciju kopa, priekšrocības un cenu struktūra. Pēc detalizētas analīzes tika secināts, ka Microsoft Azure ir mūsu organizācijai vispiemērotākā iespēja.

## Lēmums

Ieviest Microsoft Azure kā mūsu organizācijas mākoņinfrastruktūru.

## Pamatojums

Tālāk norādīti iemesli Microsoft Azure ieviešanai:

1. Visaptveroši pakalpojumi: Azure nodrošina pilnu mākoņpakalpojumu klāstu, sākot no infrastruktūras kā pakalpojuma (IaaS) līdz programmatūrai kā pakalpojumam (SaaS) un platformai kā pakalpojumam (PaaS). Tas ļauj mums izmantot Azure pakalpojumus, lai apmierinātu organizācijas prasības, piemēram, glabāšanu, skaitļošanu, tīklošanu un analītiku.

2. Mērogojamība un elastība: ar Azure mēs varam viegli palielināt vai samazināt resursus atbilstoši mūsu uzņēmējdarbības prasībām. Azure piedāvā arī elastību operētājsistēmas, programmēšanas valodas un ietvaru izvēlē.

3. Drošība un atbilstība: Azure piedāvā augstu drošības un atbilstības līmeni, jo tas atbilst vairākiem nozares standartiem, piemēram, ISO, SOC, HIPAA un PCI DSS. Azure nodrošina arī uzlabotas drošības funkcijas, piemēram, tīkla drošības grupas, ugunsmūrus un DDoS aizsardzību.

4. Hibrīdais mākonis: Azure nodrošina nevainojamu hibrīdā mākoņa pieredzi, ļaujot organizācijām savienot savu uz vietas esošo infrastruktūru ar Azure. Tas mums atvieglo darba slodžu migrēšanu uz mākoni un dod elastību izvēlēties, kur glabāt datus.

5. Rentabilitāte: Azure piedāvā maksājuma par izmantoto (pay-as-you-go) cenu modeli, kas nozīmē, ka mēs maksājam tikai par izmantotajiem resursiem. Tas palīdz ietaupīt izmaksas salīdzinājumā ar tradicionālo uz vietas esošo infrastruktūru.

## Secinājums

Microsoft Azure ieviešana kā mūsu organizācijas mākoņinfrastruktūra atbilst mūsu uzņēmējdarbības prasībām un piedāvā vairākus ieguvumus, piemēram, mērogojamību, elastību, drošību un rentabilitāti. Tāpēc tiek ieteikts pieņemt Azure kā mūsu mākoņinfrastruktūru.
