# Arhitektūras lēmuma ieraksts par Amazon Web Services

Nosaukums: Amazon Web Services ieviešana mākoņinfrastruktūrai

## Lēmums

Pēc rūpīgas dažādu mākoņinfrastruktūras platformu izvērtēšanas ir nolemts, ka mūsu organizācija mākoņinfrastruktūras vajadzībām ieviesīs Amazon Web Services (AWS).

## Fons

Mūsu organizācija strauji aug, un mums nepieciešama uzticama un mērogojama mākoņinfrastruktūra, lai apmierinātu mūsu uzņēmējdarbības prasības. Apsverot vairākus mākoņinfrastruktūras nodrošinātājus, tika secināts, ka AWS piedāvā vispiemērotāko pakalpojumu klāstu mūsu pašreizējo un nākotnes prasību apmierināšanai.

## Apsvērumi

Tirgū ir daudz mākoņinfrastruktūras nodrošinātāju, kas ir pierādījuši savu uzticamību un efektivitāti. Tomēr AWS ne tikai piedāvā visaptverošu pakalpojumu kopumu mūsu vajadzībām, bet arī ir plaša klientu bāze un veiksmīgu ieviešanu rezultāti. AWS nodrošina arī plašu atbalsta un apmācības resursu klāstu, lai mūsu komanda varētu efektīvi strādāt ar platformu.

Turklāt AWS ir plaša globāla klātbūtne ar datu centriem dažādos pasaules reģionos. Tas nodrošina mūsu datu drošību un mūsu lietojumprogrammu un pakalpojumu augstu pieejamību. AWS ir arī stabils drošības ietvars, kas ir kritiski svarīgs mūsu uzņēmējdarbībai.

Visbeidzot, AWS nodrošina maksājuma par izmantoto (pay-as-you-go) modeli, kas mums dod elastību mērogot infrastruktūru atbilstoši pieprasījumam. Tas nozīmē, ka mums tiks iekasēts tikai par izmantoto, kas ļauj optimizēt izmaksas un ieguldīt citās uzņēmējdarbības jomās.

## Lēmums

Pamatojoties uz veiktajiem izvērtējumiem un AWS piedāvātajām priekšrocībām, ir nolemts, ka mūsu mākoņinfrastruktūras vajadzībām tiks ieviests AWS.

## Sekas

AWS ieviešana var prasīt apmācību mūsu komandām, lai nodrošinātu, ka tās pārzina platformu un spēj to efektīvi izmantot. Var būt arī daži sākotnējie izdevumi mūsu pašreizējās infrastruktūras pārcelšanai uz AWS platformu.

## Īpašumtiesības

Atbildība par AWS efektīvas izmantošanas nodrošināšanu un saistīto risku pārvaldību būs mākoņinfrastruktūras komandas kompetencē. Visi radušies jautājumi jārisina šai komandai.

## Pārskatīšana

Lēmums ieviest AWS tiks pārskatīts katru gadu, lai nodrošinātu, ka tas joprojām atbilst mūsu vajadzībām un platformas ieguvumi tiek pilnībā izmantoti.
