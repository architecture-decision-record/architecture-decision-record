# Architektūros sprendimo įrašas dėl Amazon Web Services

Pavadinimas: Amazon Web Services pasirinkimas debesijos infrastruktūrai

## Sprendimas

Kruopščiai įvertinus įvairias debesijos infrastruktūros platformas, nuspręsta, kad mūsų organizacija debesijos infrastruktūros poreikiams naudos Amazon Web Services (AWS).

## Fonas

Mūsų organizacija sparčiai auga, todėl mums reikia patikimos ir keičiamo mastelio debesijos infrastruktūros, atitinkančios mūsų verslo poreikius. Apsvarsčius keletą debesijos infrastruktūros teikėjų, padaryta išvada, kad AWS siūlo tinkamiausią paslaugų spektrą mūsų dabartiniams ir būsimiems reikalavimams tenkinti.

## Svarstymai

Rinkoje yra daug debesijos infrastruktūros teikėjų, pasitvirtinusių kaip patikimi ir efektyvūs. Tačiau AWS ne tik siūlo išsamų paslaugų rinkinį mūsų poreikiams tenkinti, bet ir turi didelę klientų bazę bei sėkmingų diegimų patirtį. AWS taip pat teikia plačią palaikymo ir mokymo išteklių įvairovę, kad mūsų komanda galėtų efektyviai dirbti su platforma.

Be to, AWS turi plačią pasaulinę aprėptį su duomenų centrais įvairiuose pasaulio regionuose. Tai užtikrina, kad mūsų duomenys yra saugūs, o mūsų programos ir paslaugos bus labai prieinamos. AWS taip pat turi tvirtą saugumo sistemą, kuri yra labai svarbi mūsų verslui.

Galiausiai AWS siūlo mokėjimo už naudojimą modelį, suteikiantį mums lankstumą keisti infrastruktūros mastelį pagal poreikį. Tai reiškia, kad mokėsime tik už tai, ką naudosime, o tai leidžia optimizuoti išlaidas ir investuoti į kitas verslo sritis.

## Sprendimas

Remiantis atliktais vertinimais ir AWS siūlomais privalumais, nuspręsta, kad AWS bus naudojama mūsų debesijos infrastruktūros poreikiams.

## Pasekmės

Pereinant prie AWS gali prireikti apmokyti mūsų komandas, kad jos susipažintų su platforma ir galėtų ją veiksmingai naudoti. Taip pat gali būti pradinių išlaidų perkeliant dabartinę infrastruktūrą į AWS platformą.

## Atsakomybė

Atsakomybė už veiksmingą AWS naudojimą ir susijusių rizikų valdymą priklausys debesijos infrastruktūros komandos kompetencijai. Visas iškilusias problemas turi spręsti ši komanda.

## Peržiūra

Sprendimas naudoti AWS bus peržiūrimas kasmet, siekiant užtikrinti, kad jis ir toliau atitiktų mūsų poreikius ir kad platformos privalumai būtų visiškai išnaudojami.
