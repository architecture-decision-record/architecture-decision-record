# Cofnod penderfyniad saernïaeth: yr iaith raglennu Java

Teitl: Dewis yr iaith raglennu Java ar gyfer y prosiect

Penderfyniad: Ar ôl gwerthuso sawl iaith raglennu, rydym wedi penderfynu defnyddio Java ar gyfer ein prosiect.

### Cefndir

Roeddem yn bwriadu adeiladu cymhwysiad ar y we a allai redeg ar sawl system weithredu. Roedd ein prosiect angen iaith a allai ddarparu nodweddion diogelwch cryf, ymdrin â chydredeg, cefnogi sylfeini cod mawr, a bod yn ddigon amlbwrpas i ddiwallu ein gofynion twf yn y dyfodol. Gwerthusasom sawl iaith, gan ystyried eu cryfderau a'u cyfyngiadau, cyn penderfynu ar Java.

### Ystyriaethau

1. **Diogelwch:**  Mae Java yn darparu nodweddion diogelwch rhagorol drwy ei bolisïau diogelwch a'i reolaeth mynediad wedi'u diffinio'n dda. Mae hefyd yn cynnwys nodweddion fel gwirio beitgod (bytecode), sy'n helpu i atal meddalwedd faleisus rhag rhedeg ar system.

2. **Cydredeg:**  Mae gan Java gefnogaeth adeiledig ar gyfer aml-edafu, sy'n caniatáu i gymwysiadau gyflawni sawl tasg ar yr un pryd. Mae'r nodwedd hon yn gwneud Java yn ddewis ardderchog ar gyfer datblygu cymwysiadau mawr a chymhleth gyda nifer o nodweddion a swyddogaethau.

3. **Sylfeini cod mawr:**  Mae Java yn cefnogi rhaglennu gwrthrychol, sy'n ei wneud yn ddewis addas ar gyfer datblygu sylfeini cod mawr. Mae ei natur fodiwlaidd a'i ddefnydd o batrymau amgapsiwleiddio a haniaethu yn ychwanegu ymhellach at rwyddineb y broses datblygu meddalwedd.

4. **Amlbwrpasedd:**  Mae Java yn amlbwrpas ac yn rhoi'r gallu i ddefnyddio ystod eang o lyfrgelloedd a fframweithiau, sy'n ei wneud yn ddewis ardderchog ar gyfer cymwysiadau ar y we a chymwysiadau lefel menter.

### Canlyniad y penderfyniad

Rydym wedi penderfynu defnyddio'r iaith raglennu Java ar gyfer ein prosiect, gan ystyried ei nodweddion diogelwch, ei chefnogaeth i gydredeg, ei gallu i ymdrin â sylfeini cod mawr, a'i hamlbwrpasedd. Mae'r penderfyniad hwn yn cyd-fynd â gofynion ein prosiect, a chredwn y bydd dewis Java yn sicrhau ei lwyddiant. 

### Canlyniadau

1. Bydd angen datblygwyr arnom sydd â phrofiad o Java ac sy'n gallu ei ddefnyddio'n hyfedr.

2. Rhaid i unrhyw god a ysgrifennir yn yr iaith fod yn gydnaws â'r Peiriant Rhithwir Java (JVM).

3. Gall ymgorffori nodweddion, swyddogaethau neu fframweithiau newydd gyflwyno rhai heriau.

4. Gall prosiectau mawr, cymhleth yn Java fod angen mwy o amser ac adnoddau i'w datblygu.
