# Cofnod penderfyniad saernïaeth: Tailwind CSS

Penderfyniad: Defnyddio Tailwind CSS fel y fframwaith CSS i steilio rhyngwyneb defnyddiwr.

## Beth yw Tailwind CSS?

Fframwaith CSS sy'n rhoi blaenoriaeth i ddosbarthiadau cyfleustodau (utility-first) yw Tailwind, sy'n caniatáu datblygu ac addasu rhyngwynebau defnyddiwr yn gyflym. Fe'i cynlluniwyd i fod yn hynod addasadwy ac mae'n caniatáu i ddatblygwyr ysgrifennu CSS main a mwy effeithlon. Mae'r fframwaith hwn yn darparu set o ddosbarthiadau wedi'u diffinio ymlaen llaw i steilio'r rhyngwyneb defnyddiwr yn gyflym iawn.

## Cyd-destun

Rydym yn adeiladu cymhwysiad gwe ar gyfer cleient sydd angen rhyngwyneb defnyddiwr ymatebol ac addasadwy. Mae'r cleient wedi gofyn am steilio cyson a modern. Mae gan y tîm datblygu brofiad o ddefnyddio CSS wedi'i deilwra ond mae am archwilio fframweithiau CSS a all arbed amser ac ymdrech. Rydym yn chwilio am fframwaith sy'n hawdd ei ddefnyddio, yn addasadwy, ac sydd â chymuned fawr i'w gefnogi.

## Ysgogwyr y penderfyniad

- **Hawdd ei ddefnyddio:**  Rydym am gael fframwaith sy'n syml i'w ddysgu ac y gellir ei integreiddio i'n llif gwaith datblygu.

- **Addasadwy:**  Rydym am gael fframwaith y gellir ei addasu i gyd-fynd â chanllawiau a thema brand y cleient.

- **Cefnogaeth gymunedol fawr:**  Rydym am gael fframwaith sydd â chymuned weithgar o ddatblygwyr a dylunwyr a all ddarparu cymorth ac adnoddau pan fo angen.

- **Arbed amser:**  Rydym am gael fframwaith a all arbed amser ac ymdrech wrth steilio'r rhyngwyneb defnyddiwr.

## Dewisiadau a ystyriwyd

- **Bootstrap:**  Fframwaith CSS poblogaidd gyda llawer o gydrannau parod a chymuned fawr o ddatblygwyr.

- **Foundation:**  Fframwaith CSS poblogaidd arall a gynlluniwyd ar gyfer datblygu sy'n rhoi blaenoriaeth i ddyfeisiau symudol.

- **Materialize:**  Fframwaith CSS sy'n seiliedig ar iaith Material Design Google gyda chydrannau parod ar gyfer datblygu rhyngwynebau defnyddiwr.

- **Tailwind CSS:**  Fframwaith CSS sy'n rhoi blaenoriaeth i ddosbarthiadau cyfleustodau, gyda ffocws ar addasu ac effeithlonrwydd.

## Canlyniad y penderfyniad

Ar ôl ystyried y dewisiadau, penderfynasom ddefnyddio Tailwind CSS am y rhesymau canlynol:

- **Hawdd ei ddefnyddio:**  Mae dull Tailwind yn syml ac yn hawdd ei ddeall. Mae ei ddosbarthiadau cyfleustodau yn gwneud adeiladu rhyngwyneb defnyddiwr yn gyflymach.

- **Addasadwy:**  Mae Tailwind yn caniatáu addasu drwy ddarparu set o ffeiliau ffurfweddu sy'n caniatáu i ddatblygwyr addasu arddulliau rhagosodedig y fframwaith yn hawdd.

- **Cefnogaeth gymunedol fawr:**  Mae gan Tailwind gymuned weithgar iawn o ddatblygwyr a dylunwyr sy'n creu adnoddau, ategion ac offer newydd yn gyson.

- **Arbed amser:**  Gall Tailwind arbed amser, gan alluogi datblygwyr i ganolbwyntio ar feysydd eraill o'r prosiect.

Byddwn yn defnyddio dosbarthiadau cyfleustodau Tailwind CSS i adeiladu rhyngwyneb defnyddiwr ein prosiect. Bydd y tîm datblygu yn defnyddio ei system ddylunio atomig a modiwlaidd i ysgrifennu cod CSS effeithlon a graddadwy. Byddwn yn manteisio ar dempledi parod a chydrannau gweledol Tailwind i gyflymu'r broses ddatblygu gan ddefnyddio arddulliau wedi'u teilwra ar yr un pryd i gyd-fynd â brand a thema'r cleient.
