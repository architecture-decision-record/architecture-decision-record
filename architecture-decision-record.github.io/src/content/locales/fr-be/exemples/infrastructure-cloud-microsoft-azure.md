# Enregistrement de décision d’architecture : infrastructure cloud Microsoft Azure

Titre de la décision : adoption de Microsoft Azure comme infrastructure cloud de notre organisation

Décideur : directeur des systèmes d’information (DSI)

Date : 2021-10-15

État : Approuvé

## Contexte

L’organisation prévoit de migrer d’une infrastructure sur site traditionnelle (on-premises) vers une infrastructure cloud. Pour y parvenir, l’organisation a évalué plusieurs fournisseurs de services cloud, tels qu’Amazon Web Services (AWS), Google Cloud Platform (GCP), Microsoft Azure et IBM Cloud. Chaque fournisseur a son propre ensemble de fonctionnalités, d’avantages et de structure tarifaire. Après une analyse détaillée, il a été conclu que Microsoft Azure est l’option la plus adaptée à notre organisation.

## Décision

Adopter Microsoft Azure comme infrastructure cloud de notre organisation.

## Justification

Voici les raisons d’adopter Microsoft Azure :

1. Services complets : Azure fournit une gamme complète de services cloud, de l’infrastructure en tant que service (IaaS) au logiciel en tant que service (SaaS) et à la plateforme en tant que service (PaaS). Cela nous permet d’exploiter les services Azure pour répondre aux besoins de l’organisation, tels que le stockage, le calcul, le réseau et l’analyse.

2. Évolutivité et flexibilité : avec Azure, nous pouvons facilement augmenter ou réduire les ressources selon nos besoins métier. Azure offre aussi de la flexibilité dans le choix du système d’exploitation, du langage de programmation et des frameworks.

3. Sécurité et conformité : Azure offre un haut niveau de sécurité et de conformité, car il est conforme à plusieurs normes du secteur telles que ISO, SOC, HIPAA et PCI DSS. Azure fournit aussi des fonctionnalités de sécurité avancées telles que les groupes de sécurité réseau, les pare-feu et la protection contre les DDoS.

4. Cloud hybride : Azure offre une expérience de cloud hybride fluide, permettant aux organisations de connecter leur infrastructure sur site à Azure. Cela nous facilite la migration des charges de travail vers le cloud et nous donne la souplesse de choisir où stocker les données.

5. Rentable : Azure propose un modèle tarifaire de paiement à l’usage, ce qui signifie que nous ne payons que pour les ressources utilisées. Cela nous aide à économiser par rapport à une infrastructure sur site traditionnelle.

## Conclusion

Adopter Microsoft Azure comme infrastructure cloud de notre organisation s’aligne sur nos exigences métier et offre plusieurs avantages tels que l’évolutivité, la flexibilité, la sécurité et la rentabilité. Il est donc recommandé d’adopter Azure comme infrastructure cloud.
