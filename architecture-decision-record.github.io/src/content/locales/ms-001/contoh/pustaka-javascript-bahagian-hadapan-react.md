# Rekod Keputusan Seni Bina: Pustaka JavaScript Bahagian Hadapan React

## Konteks

Kami perlu memilih pustaka JavaScript bahagian hadapan untuk aplikasi kami bagi membangunkan antara muka pengguna yang responsif dan interaktif.
  
## Pilihan yang Dipertimbangkan

1. React
  
2. Vue

3. Svelte
   
## Keputusan

Kami akan menggunakan React sebagai pustaka JavaScript bahagian hadapan kami.
  
## Rasional

1. **Seni Bina Berasaskan Komponen:**  React menyediakan seni bina berasaskan komponen yang membolehkan kami memecahkan UI kepada komponen kecil yang boleh digunakan semula. Ini membantu meningkatkan kemodularan kod kami dan memudahkan penyelenggaraan, penskalaan dan pengemaskinian aplikasi.
  
2. **Pengaturcaraan deklaratif:**  React menggunakan gaya pengaturcaraan deklaratif yang menjadikan kod kami lebih intuitif dan lebih mudah dibaca. Ia juga menyediakan DOM maya, yang membolehkan kod kami berjalan lebih pantas dan lebih cekap.
  
3. **Komuniti Besar:**  React mempunyai komuniti yang besar dan aktif, dan ia salah satu pustaka bahagian hadapan paling popular. Ini bermakna terdapat banyak sumber, alat dan pustaka yang boleh membantu kami membangunkan aplikasi kami dengan lebih pantas dan cekap.
  
4. **Prestasi yang lebih baik:**  React menggunakan aliran data sehala, yang membantu memudahkan logik aplikasi dan menjadikannya lebih cekap. Ia juga menyediakan pemaparan bahagian pelayan, yang membantu meningkatkan prestasi dan SEO aplikasi kami.
  
5. **Fleksibiliti:**  React boleh digunakan dengan pustaka dan rangka kerja lain, yang memberi kami kebebasan memilih timbunan teknologi terbaik yang sesuai dengan keperluan projek kami.
  
## Akibat

1. **Keluk Pembelajaran:**  React mempunyai keluk pembelajaran, dan mungkin mengambil sedikit masa untuk pembangun yang baru kepada React menguasainya.
  
2. **Alat Binaan:**  React memerlukan alat binaan tambahan seperti Babel dan Webpack, yang mungkin menambah kerumitan kepada proses pembangunan.
  
3. **Keserasian pelayar:**  React mempunyai isu keserasian dengan pelayar lama kerana ia menggunakan ciri ES6 yang tidak disokong dalam pelayar lama.
  
 4. Keluk pembelajaran yang curam: Mungkin mengambil masa untuk pembangun yang tidak biasa dengan React mempelajari cara menggunakannya dengan cekap, yang boleh membawa kepada masa pembangunan yang lebih perlahan.

## Kesimpulan

Kami telah memutuskan untuk menggunakan React untuk pustaka JavaScript bahagian hadapan aplikasi kami. Walaupun ia mungkin mempunyai keluk pembelajaran, faedah yang disediakan React, seperti seni bina berasaskan komponen, gaya pengaturcaraan deklaratif, prestasi lebih baik, fleksibiliti dan komuniti besar, melebihi kelemahan yang berpotensi.
