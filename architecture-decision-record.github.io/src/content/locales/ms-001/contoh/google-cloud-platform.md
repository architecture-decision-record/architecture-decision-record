# Rekod Keputusan Seni Bina untuk Google Cloud Platform

## Konteks

Google Cloud Platform (GCP) ialah platform pengkomputeran awan yang terkemuka yang menawarkan pelbagai perkhidmatan awan, termasuk penyelesaian pengkomputeran, storan dan rangkaian. ADR ini bertujuan mendokumenkan keputusan seni bina yang dibuat untuk membangun dan melaksanakan infrastruktur berasaskan GCP untuk organisasi kami.

## Keputusan

Organisasi kami telah memutuskan untuk menggunakan Google Cloud Platform sebagai infrastruktur awan untuk aplikasi kami. Pertimbangan utama untuk keputusan ini ialah:

   - Keberkesanan kos

   - Kebolehskalaan

   - Kebolehpercayaan

   - Fleksibiliti

## Pilihan

Perkhidmatan berikut daripada GCP telah dipilih untuk memenuhi keperluan kami:

   - Compute Engine untuk mesin maya dan sumber pengkomputeran

   - Cloud Storage untuk storan objek dan pengehosan fail

   - Cloud SQL untuk perkhidmatan pangkalan data terurus

   - Firebase untuk pembangunan dan pengehosan aplikasi

## Rasional

   - Keberkesanan Kos: Google Cloud Platform sangat berkesan dari segi kos berbanding platform awan lain, menjadikannya pilihan menarik untuk organisasi yang mempunyai kekangan bajet.

   - Kebolehskalaan: Infrastruktur GCP yang mudah diskalakan membolehkan pengendalian sebarang jumlah trafik secara masa nyata.

   - Kebolehpercayaan: Perkhidmatan terurus GCP menawarkan kebolehpercayaan tinggi, dengan sandaran automatik dan keupayaan pemulihan bencana yang memastikan ketersediaan tinggi sumber dan data.

   - Fleksibiliti: Platform ini menyediakan pelbagai alat dan perkhidmatan merentasi domain berbeza seperti AI, analitik data dan IoT, menjadikannya sangat serba boleh.

## Akibat

Berpindah ke Google Cloud Platform akan memerlukan latihan pasukan kami mengenai perkhidmatan GCP, penyusunan semula seni bina aplikasi supaya serasi dengan perkhidmatan yang dipilih, dan mengemas kini kod infrastruktur untuk menyokong perkhidmatan GCP. Namun, dijangkakan bahawa setelah penghijrahan selesai, kami akan mempunyai infrastruktur yang sangat boleh diskalakan, boleh dipercayai dan menjimatkan kos untuk menghoskan aplikasi kami. Selain itu, kami perlu mengurus kos berterusan penyediaan sumber di GCP.

## Kesimpulan

Google Cloud Platform ialah pilihan yang sangat baik untuk infrastruktur awan kami kerana keberkesanan kos, kebolehskalaan, kebolehpercayaan dan fleksibilitinya. Dengan menggunakan perkhidmatan yang dipilih, kami boleh menyediakan infrastruktur yang sangat tersedia dan mantap untuk aplikasi kami.
