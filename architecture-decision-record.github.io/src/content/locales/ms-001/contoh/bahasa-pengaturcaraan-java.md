### Latar belakang

Projek kami memerlukan bahasa yang boleh menyediakan ciri keselamatan yang kukuh, mengendalikan keserentakan, menyokong pangkalan kod yang besar dan cukup serba boleh untuk memenuhi keperluan pertumbuhan masa hadapan kami. Kami menilai beberapa bahasa, mempertimbangkan kekuatan dan batasan masing-masing, sebelum memutuskan Java.

### Pertimbangan

1. **Keselamatan:**  Java menyediakan ciri keselamatan yang sangat baik melalui dasar keselamatan dan kawalan akses yang ditakrifkan dengan baik. Ia juga menggabungkan ciri seperti pengesahan bytecode, yang membantu menghalang perisian berniat jahat daripada berjalan pada sistem.

2. **Keserentakan:**  Java mempunyai sokongan terbina dalam untuk multithreading, yang membolehkan aplikasi melaksanakan beberapa tugas serentak. Ciri ini menjadikan Java pilihan yang sangat baik untuk membangunkan aplikasi besar dan kompleks dengan pelbagai ciri dan fungsi.

3. **Pangkalan kod besar:**  Java menyokong pengaturcaraan berorientasikan objek, yang menjadikannya pilihan yang sesuai untuk membangunkan pangkalan kod besar. Sifat modularnya dan penggunaan corak enkapsulasi dan abstraksi menambah lagi kemudahan proses pembangunan perisian.

4. **Serba boleh:**  Java serba boleh dan menyediakan keupayaan menggunakan pelbagai pustaka dan rangka kerja, menjadikannya pilihan yang sangat baik untuk aplikasi berasaskan web dan aras perusahaan.
