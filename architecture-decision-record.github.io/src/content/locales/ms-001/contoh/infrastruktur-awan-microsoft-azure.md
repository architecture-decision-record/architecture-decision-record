# Rekod Keputusan Seni Bina: Infrastruktur awan Microsoft Azure" 

Tajuk Keputusan: Menggunakan Microsoft Azure sebagai infrastruktur awan untuk organisasi kami

Pembuat Keputusan: Ketua Pegawai Maklumat

Tarikh: 2021-10-15

Status: Diluluskan

## Latar belakang

Organisasi merancang untuk berhijrah daripada infrastruktur tradisional di premis kepada infrastruktur awan. Untuk mencapai ini, organisasi telah menilai beberapa penyedia perkhidmatan awan seperti Amazon Web Services (AWS), Google Cloud Platform (GCP), Microsoft Azure dan IBM Cloud. Setiap penyedia mempunyai set ciri, faedah dan struktur harga tersendiri. Selepas analisis terperinci, disimpulkan bahawa Microsoft Azure ialah pilihan yang paling sesuai untuk organisasi kami.

## Keputusan

Menggunakan Microsoft Azure sebagai infrastruktur awan untuk organisasi kami.

## Rasional

Berikut ialah sebab menggunakan Microsoft Azure:

1. Perkhidmatan Komprehensif: Azure menyediakan julat lengkap perkhidmatan awan daripada infrastruktur sebagai perkhidmatan (IaaS) hingga perisian sebagai perkhidmatan (SaaS) dan platform sebagai perkhidmatan (PaaS). Ini membolehkan kami memanfaatkan perkhidmatan Azure untuk menyelesaikan keperluan organisasi, seperti storan, pengiraan, rangkaian dan analitik.

2. Kebolehskalaan dan Fleksibiliti: Dengan Azure, kami boleh dengan mudah menaikkan atau menurunkan skala sumber berdasarkan keperluan perniagaan kami. Azure juga menawarkan fleksibiliti dalam memilih sistem pengendalian, bahasa pengaturcaraan dan rangka kerja.

3. Keselamatan dan Pematuhan: Azure menawarkan tahap keselamatan dan pematuhan yang tinggi, kerana ia mematuhi beberapa piawaian industri seperti ISO, SOC, HIPAA dan PCI DSS. Azure juga menyediakan ciri keselamatan termaju seperti kumpulan keselamatan rangkaian, tembok api dan perlindungan DDoS.

4. Awan Hibrid: Azure menyediakan pengalaman awan hibrid yang lancar, membolehkan organisasi menyambungkan infrastruktur di premis mereka dengan Azure. Ini memudahkan kami memindahkan beban kerja ke awan dan memberi kami fleksibiliti untuk memilih tempat menyimpan data.

5. Menjimatkan kos: Azure menawarkan model harga bayar-semasa-guna, yang bermakna kami hanya membayar untuk sumber yang digunakan. Ini membantu kami menjimatkan kos berbanding infrastruktur tradisional di premis.

## Kesimpulan

Menggunakan Microsoft Azure sebagai infrastruktur awan untuk organisasi kami selaras dengan keperluan perniagaan kami dan menawarkan beberapa faedah seperti kebolehskalaan, fleksibiliti, keselamatan dan keberkesanan kos. Oleh itu, disyorkan untuk menggunakan Azure sebagai infrastruktur awan kami.
