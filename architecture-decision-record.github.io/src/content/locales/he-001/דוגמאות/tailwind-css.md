# רשומת החלטה ארכיטקטונית: Tailwind CSS

החלטה: להשתמש ב-Tailwind CSS כמסגרת ה-CSS לעיצוב ממשק משתמש.

## מהו Tailwind CSS?

Tailwind היא מסגרת CSS מסוג utility-first שמאפשרת פיתוח מהיר והתאמה אישית של ממשקי משתמש. היא תוכננה להיות ניתנת להתאמה אישית רבה ומאפשרת למפתחים לכתוב CSS רזה ויעיל יותר. המסגרת הזו מספקת קבוצת מחלקות מוגדרות מראש לעיצוב ממשק המשתמש במהירות רבה.

## הקשר

אנו בונים יישום ווב עבור לקוח שדורש ממשק משתמש רספונסיבי וניתן להתאמה אישית. הלקוח ביקש עיצוב עקבי ומודרני. לצוות הפיתוח יש ניסיון בשימוש ב-CSS מותאם אך הוא רוצה לבחון מסגרות CSS שיכולות לחסוך זמן ומאמץ. אנו מחפשים מסגרת שקל להשתמש בה, ניתנת להתאמה אישית, ובעלת קהילה גדולה לתמיכה.

## גורמים מניעים להחלטה

- **קלה לשימוש:**  אנו רוצים מסגרת שפשוט ללמוד ואפשר לשלב בזרימת העבודה של הפיתוח שלנו.

- **ניתנת להתאמה אישית:**  אנו רוצים מסגרת שאפשר להתאים להנחיות המותג ולערכת הנושא של הלקוח.

- **תמיכת קהילה גדולה:**  אנו רוצים מסגרת עם קהילה פעילה של מפתחים ומעצבים שיכולה לספק עזרה ומשאבים בעת הצורך.

- **חוסכת זמן:**  אנו רוצים מסגרת שיכולה לחסוך זמן ומאמץ בעיצוב ממשק המשתמש.

## אפשרויות שנשקלו

- **Bootstrap:**  מסגרת CSS פופולרית עם הרבה רכיבים מובנים וקהילה גדולה של מפתחים.

- **Foundation:**  מסגרת CSS פופולרית נוספת שתוכננה לפיתוח mobile-first.

- **Materialize:**  מסגרת CSS מבוססת שפת העיצוב Material Design של Google, עם רכיבים מובנים לפיתוח ממשק משתמש.

- **Tailwind CSS:**  מסגרת CSS מסוג utility-first עם מיקוד בהתאמה אישית וביעילות.

## תוצאת ההחלטה

לאחר ששקלנו את האפשרויות, החלטנו להשתמש ב-Tailwind CSS מהסיבות הבאות:

- **קלה לשימוש:**  הגישה של Tailwind פשוטה וקלה להבנה. מחלקות ה-utility שלה מהירות יותר לבניית ממשק משתמש.

- **ניתנת להתאמה אישית:**  Tailwind מאפשרת התאמה אישית על ידי אספקת קובצי הגדרות שמאפשרים למפתחים לשנות בקלות את סגנונות ברירת המחדל של המסגרת.

- **תמיכת קהילה גדולה:**  ל-Tailwind יש קהילה פעילה מאוד של מפתחים ומעצבים שיוצרים כל הזמן משאבים, תוספים וכלים חדשים.

- **חוסכת זמן:**  Tailwind יכולה לחסוך זמן ולאפשר למפתחים להתמקד בתחומים אחרים בפרויקט.

נשתמש במחלקות ה-utility של Tailwind CSS כדי לבנות את ממשק המשתמש של הפרויקט שלנו. צוות הפיתוח ישתמש במערכת העיצוב האטומית והמודולרית שלה כדי לכתוב קוד CSS יעיל וניתן להרחבה. ננצל את התבניות והרכיבים החזותיים המובנים של Tailwind כדי להאיץ את תהליך הפיתוח, תוך שימוש בסגנונות מותאמים כדי להתאים למיתוג ולערכת הנושא של הלקוח.
