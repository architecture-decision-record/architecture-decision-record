# רשומת החלטה ארכיטקטונית: תשתית ענן Microsoft Azure" 

כותרת ההחלטה: אימוץ Microsoft Azure כתשתית הענן של הארגון שלנו

מקבל ההחלטה: מנהל מערכות המידע הראשי

תאריך: 2021-10-15

מצב: אושרה

## רקע

הארגון מתכנן לעבור מתשתית מסורתית מקומית (on-premises) לתשתית ענן. כדי להשיג זאת, הארגון העריך מספר ספקי שירותי ענן כמו Amazon Web Services (AWS), ‏Google Cloud Platform (GCP), ‏Microsoft Azure ו-IBM Cloud. לכל ספק יש קבוצת יכולות, יתרונות ומבנה תמחור משלו. לאחר ניתוח מפורט, הגענו למסקנה ש-Microsoft Azure היא האפשרות המתאימה ביותר לארגון שלנו.

## החלטה

לאמץ את Microsoft Azure כתשתית הענן של הארגון שלנו.

## נימוק

אלה הסיבות לאימוץ Microsoft Azure:

1. שירותים מקיפים: Azure מספקת מגוון מלא של שירותי ענן, מתשתית כשירות (IaaS) ועד תוכנה כשירות (SaaS) ופלטפורמה כשירות (PaaS). זה מאפשר לנו לנצל את שירותי Azure כדי לענות על דרישות הארגון, כמו אחסון, חישוב, רשתות וניתוח נתונים.

2. יכולת הרחבה וגמישות: עם Azure אפשר להגדיל או להקטין משאבים בקלות בהתאם לדרישות העסק שלנו. Azure מציעה גם גמישות בבחירת מערכת ההפעלה, שפת התכנות והמסגרות.

3. אבטחה וציות: Azure מציעה רמה גבוהה של אבטחה וציות, מפני שהיא עומדת בכמה תקני תעשייה כמו ISO, ‏SOC, ‏HIPAA ו-PCI DSS. Azure מספקת גם יכולות אבטחה מתקדמות כמו קבוצות אבטחת רשת, חומות אש והגנה מפני DDoS.

4. ענן היברידי: Azure מספקת חוויית ענן היברידי חלקה, שמאפשרת לארגונים לחבר את התשתית המקומית שלהם ל-Azure. זה מקל עלינו להעביר עומסי עבודה לענן ומעניק לנו גמישות לבחור היכן לאחסן נתונים.

5. חסכונית: Azure מציעה מודל תמחור של תשלום לפי שימוש, כלומר אנו משלמים רק על המשאבים שבשימוש. זה עוזר לנו לחסוך בעלויות בהשוואה לתשתית מקומית מסורתית.

## סיכום

אימוץ Microsoft Azure כתשתית הענן של הארגון שלנו מתיישב עם דרישות העסק שלנו ומציע כמה יתרונות כמו יכולת הרחבה, גמישות, אבטחה ויעילות עלויות. לכן מומלץ לאמץ את Azure כתשתית הענן שלנו.
