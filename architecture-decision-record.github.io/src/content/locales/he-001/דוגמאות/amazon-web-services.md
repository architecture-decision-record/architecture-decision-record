# רשומת החלטה ארכיטקטונית ל-Amazon Web Services

כותרת: אימוץ Amazon Web Services לתשתית ענן

## החלטה

לאחר הערכה מקיפה של פלטפורמות תשתית ענן שונות, הוחלט שהארגון שלנו יאמץ את Amazon Web Services (AWS) לצורכי תשתית הענן שלנו.

## רקע

הארגון שלנו גדל במהירות ואנו זקוקים לתשתית ענן אמינה וניתנת להרחבה כדי לעמוד בדרישות העסק שלנו. לאחר ששקלנו מספר ספקי תשתית ענן, הגענו למסקנה ש-AWS מציעה את מגוון השירותים המתאים ביותר לדרישותינו הנוכחיות והעתידיות.

## שיקולים

יש בשוק ספקי תשתית ענן רבים שהוכיחו את עצמם כאמינים ויעילים. עם זאת, AWS לא רק מציעה מערך שירותים מקיף שעונה על צרכינו, אלא גם בעלת בסיס לקוחות נרחב והיסטוריה של פריסות מוצלחות. AWS מספקת גם מגוון רחב של משאבי תמיכה והדרכה כדי להבטיח שהצוות שלנו יוכל לעבוד ביעילות עם הפלטפורמה.

יתרה מזו, ל-AWS נוכחות גלובלית נרחבת עם מרכזי נתונים הממוקמים באזורים שונים ברחבי העולם. כך מובטח שהנתונים שלנו מאובטחים ושהיישומים והשירותים שלנו יהיו זמינים מאוד. ל-AWS יש גם מסגרת אבטחה חזקה שקריטית לעסק שלנו.

לבסוף, AWS מספקת מודל תשלום לפי שימוש שמציע לנו גמישות להרחיב את התשתית בהתאם לביקוש. משמעות הדבר היא שנחויב רק על מה שנשתמש בו, מה שמאפשר לנו לייעל את העלויות ולהשקיע בתחומים אחרים בעסק.

## החלטה

בהתבסס על ההערכות שבוצעו ועל היתרונות ש-AWS מציעה, הוחלט שנאמץ את AWS לצורכי תשתית הענן שלנו.

## השלכות

אימוץ AWS עשוי לדרוש הדרכה לצוותים שלנו כדי להבטיח שיכירו את הפלטפורמה ויוכלו להשתמש בה ביעילות. ייתכנו גם עלויות ראשוניות להעברת התשתית הנוכחית שלנו לפלטפורמת AWS.

## בעלות

האחריות להבטחת ניצול יעיל של AWS ולניהול הסיכונים הקשורים תהיה בתחום סמכותו של צוות תשתית הענן. כל בעיה שתתעורר חייבת להיות מטופלת על ידי הצוות הזה.

## סקירה

ההחלטה לאמץ את AWS תיסקר מדי שנה כדי להבטיח שהיא ממשיכה לענות על צרכינו ושתועלות הפלטפורמה ממומשות במלואן.
