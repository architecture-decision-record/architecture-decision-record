# הנחיות להשגת החלטות בנות קיימא

<https://www.infoq.com/articles/sustainable-architectural-design-decisions/>

למדנו בעבודתנו את הלקחים הבאים, שיכולים לשמש הנחיות והערכה להשגת החלטות בנות קיימא:

1. השתמשו בגישה רזה/מינימליסטית לתיעוד ההחלטות הראשוני.

2. תעדפו ותעדו את כל ההחלטות החשובות שרלוונטיות מספיק לתיעוד ולהבנה של ארכיטקטורת היעד.

3. פרטו את ההחלטות החשובות במיוחד בתבניות מלאות רק אחרי שהעבודה הראשונית הושלמה (כלומר, כשמקבלי ההחלטות מרוצים מההחלטות הארכיטקטוניות שהתקבלו ובטוחים שאין צורך לשנות את ההחלטות האלה בקרוב).

4. השתמשו בגרסאות הרזות/המינימליסטיות משלב 1 כגרסה קצרה של ההחלטות המתועדות, ברמת פירוט נכונה, כדי לספק סקירה של ההחלטות המפורטות וכן להחלטות טריוויאליות או מובנות מאליהן.

5. בכל מקום אפשרי, השתמשו בידע ארכיטקטוני קיים, ממודלי הנחיה או ממקורות אחרים. סקרו והרחיבו ידע כזה והתאימו אותו להקשר ההחלטה הספציפית.

6. ודאו שנקבעים קישורי עקיבות בין החלטות לבין דרישות ועיצובי ארכיטקטורה/קוד.

7. ספקו בדיקת עקביות אוטומטית כדי לוודא שקישורי העקיבות מסונכרנים אחרי שינוי. הגבילו את מספר התלויות בין החלטות לבין תוצרי תוכנה אחרים.

8. יישמו את ההנחיות לנימוקים באופן עקבי ונחרץ, כי הם החלק החשוב ביותר בתיעוד ההחלטה, מפני שהם מספקים את הרציונל.
