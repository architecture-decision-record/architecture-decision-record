## Begrunnelse

1. **Enkelhet og lesbarhet:** Go er kjent for enkelhet og kortfattet syntaks. Det gjør koden lett å lese og skrive, og reduserer kompleksiteten i utviklingsprosessen vår.

2. **Høy ytelse og skalerbarhet:** Go kompileres til maskinkode som kjøres direkte på serveren. Det gir raskere kjøretid og bedre ytelse sammenlignet med tolkede språk som Java. I tillegg håndterer Go sin samtidighetsmodell flere forespørsler samtidig, noe som gjør det svært skalerbart.

3. **Sterk støtte fra miljøet:** Go har et levende miljø av utviklere som har bidratt til veksten gjennom årene. Det betyr at det finnes mange ressurser, biblioteker og rammeverk som hjelper oss å komme i gang og bygge robuste applikasjoner.

4. **Fleksibilitet:** Go kan brukes til både frontend- og backend-utvikling. Det betyr at vi kan utnytte fordelene i begge områder i utviklingsprosjektene våre.

## Implikasjoner

1. **Opplæring:** Utviklerne våre må gjennomgå opplæring for å lære programmeringsspråket Go og nyansene i det.

2. **Erfaring:**  Vi kan møte noen utfordringer når vi går fra Java til Go. Det kan ta litt tid før utviklerne våre blir dyktige i det nye språket.

3. **Verktøy:**  Vi må ta i bruk nye verktøy og rammeverk som er spesifikke for Go. Vi kan imidlertid utnytte infrastrukturen vi allerede har på plass for å minimere virkningen av denne endringen.

4. **Leverandørlåsing:**  Go er et programmeringsspråk med åpen kildekode, og vi blir ikke bundet til noen leverandør eller tjenesteyter.
