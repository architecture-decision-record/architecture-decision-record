# Mal for beslutningslogg med Planguage

Se https://www.iaria.org/conferences2012/filesICCGI12/Tutorial%20Specifying%20Effective%20Non-func.pdf

## Hva er Planguage?

Planguage er et planleggingsspråk som bruker disse nøkkelordene:

* Tag: En unik og varig identifikator
* Gist: Et kort sammendrag av kravet eller området det gjelder
* Requirement: Teksten som beskriver selve kravet i detalj
* Rationale: Begrunnelsen som rettferdiggjør kravet
* Priority: En erklæring om prioritet og krav på ressurser
* Stakeholders: Parter som kravet berører vesentlig
* Status: Kravets status (utkast, gjennomgått, forpliktet og så videre)
* Owner: Personen som er ansvarlig for å implementere kravet
* Author: Personen som skrev kravet
* Revision: Et versjonsnummer for erklæringen
* Date: Datoen for den siste revisjonen
* Assumptions: Alt som kan skape problemer hvis det ikke stemmer nå eller senere
* Risks: Alt som kan forårsake feilfunksjon, forsinkelse eller andre negative virkninger
* Defined: Definisjonen av et begrep (bruk helst en ordliste)
