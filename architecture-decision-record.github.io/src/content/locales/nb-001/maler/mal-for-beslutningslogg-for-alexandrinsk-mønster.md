# Mal for beslutningslogg for alexandrinsk mønster

## Innledning

* Prolog (sammendrag)
* Diskusjon (kontekst)
* Løsning (beslutning)
* Konsekvenser (resultater)

## Detaljer ##

* Prolog (sammendrag)
  * Setning som oppsummerer:
    * I sammenheng med (bruksområde)<br>
      og med (bekymring)<br>
      bestemte vi oss for (alternativ)<br>
      for å oppnå (kvalitet)<br>
      og godtar (ulempe).
* Diskusjon (kontekst)
  * Forklarer kreftene som er i spill (tekniske, politiske, sosiale, prosjektmessige).
  * Dette er fortellingen som forklarer problemet vi ønsker å løse.
* Løsning
  * Forklarer hvordan beslutningen vil løse problemet.
* Konsekvenser
  * Forklarer resultatene av beslutningen på lang sikt.
  * Fungerte det, fungerte det ikke, ble det endret, oppgradert og så videre.
