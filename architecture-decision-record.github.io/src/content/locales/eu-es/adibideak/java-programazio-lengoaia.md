# Arkitektura-erabakien erregistroa: Java programazio-lengoaia

Izenburua: Java programazio-lengoaia aukeratzea proiekturako

Erabakia: Hainbat programazio-lengoaia ebaluatu ondoren, gure proiekturako Java erabiltzea erabaki dugu.

### Atzeko planoa

Hainbat sistema eragiletan exekutatu zitekeen web oinarritutako aplikazio bat eraiki nahi genuen. Gure proiektuak segurtasun-ezaugarri sendoak eskaini, konkurrentzia kudeatu, kode-oinarri handiak onartu eta etorkizuneko hazkunde-eskakizunak betetzeko nahikoa polifazetikoa izan zitekeen lengoaia bat behar zuen. Hainbat lengoaia ebaluatu genituen, haien indarrak eta mugak kontuan hartuz, Java erabakitzeko aurretik.

### Kontuan hartzekoak

1. **Segurtasuna:**  Javak segurtasun-ezaugarri bikainak eskaintzen ditu bere segurtasun-politika eta sarbide-kontrol ongi definituen bidez. Bytecode egiaztapena bezalako ezaugarriak ere barne hartzen ditu, softwarea maltzurrak sisteman exekutatzea saihesten laguntzen duena.

2. **Konkurrentzia:**  Javak multithreading-erako euskarri integratua du, aplikazioei hainbat zeregin aldi berean egiten uzten diena. Ezaugarri honek Java aukera bikaina bihurtzen du ezaugarri eta funtzionalitate anitzeko aplikazio handi eta konplexuak garatzeko.

3. **Kode-oinarri handiak:**  Javak objektuei zuzendutako programazioa onartzen du, eta horrek kode-oinarri handiak garatzeko aukera egokia egiten du. Bere izaera modularrak eta kapsulatze- eta abstrakzio-ereduen erabilerak software-garapen prozesuaren erraztasuna areagotzen dute.

4. **Polifazetikotasuna:**  Java polifazetikoa da eta liburutegi eta esparru sorta zabala erabiltzeko gaitasuna eskaintzen du, web oinarritutako zein enpresa-mailako aplikazioetarako aukera bikaina bihurtuz.

### Erabakiaren emaitza

Gure proiekturako Java programazio-lengoaia erabiltzea erabaki dugu, bere segurtasun-ezaugarriak, konkurrentzia-euskarria, kode-oinarri handiak kudeatzeko gaitasuna eta izaera polifazetikoa kontuan hartuta. Erabaki hau gure proiektuaren eskakizunekin bat dator, eta uste dugu Java aukeratzeak bere arrakasta bermatuko duela. 

### Ondorioak

1. Javarekin esperientzia duten eta trebetasunez erabil dezaketen garatzaileak beharko ditugu.

2. Lengoaia honetan idatzitako edozein kodek Java Virtual Machine-ekin (JVM) bateragarria izan behar du.

3. Ezaugarri, funtzionalitate edo esparru berriak sartzeak erronka batzuk ekar ditzake.

4. Javan proiektu handi eta konplexuek denbora eta baliabide gehiago behar ditzakete garatzeko.
