## Justificación

SvelteKit es una solución de front end nueva e integral que ofrece una serie de funciones, como renderizado del lado del servidor, recarga en caliente, configuración simplificada y muchas más. Nos permite crear una arquitectura de front end de alta calidad que puede manejar con facilidad las aplicaciones más grandes.

La arquitectura basada en componentes de SvelteKit nos permite desarrollar componentes de interfaz de usuario reutilizables y escalables que pueden integrarse sin problemas entre distintos proyectos. El framework ofrece un excelente soporte para TypeScript, lo que nos permite crear código limpio y estructurado, fácil de mantener.

Además, SvelteKit ofrece un sistema de gestión de documentos fácil de usar que nos permite hacer un seguimiento de todas las decisiones de arquitectura y los cambios de nuestro proyecto.

## Alternativas consideradas

Hemos evaluado varias alternativas, como React, Vue, Angular y Next.js, pero por sus funciones, facilidad de uso y robustez, SvelteKit fue la elección clara para nuestro proyecto.
