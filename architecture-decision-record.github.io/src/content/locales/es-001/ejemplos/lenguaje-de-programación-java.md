# Registro de decisión de arquitectura: lenguaje de programación Java

Título: Elección del lenguaje de programación Java para el proyecto

Decisión: tras evaluar varios lenguajes de programación, hemos decidido usar Java para nuestro proyecto.

### Antecedentes

Pretendíamos construir una aplicación basada en la web que pudiera ejecutarse en varios sistemas operativos. Nuestro proyecto requería un lenguaje que pudiera ofrecer sólidas funciones de seguridad, manejar la concurrencia, admitir bases de código grandes y ser lo bastante versátil para atender nuestros requisitos de crecimiento futuro. Evaluamos varios lenguajes, considerando sus puntos fuertes y sus limitaciones, antes de decidirnos por Java.

### Consideraciones

1. **Seguridad:**  Java ofrece excelentes funciones de seguridad mediante sus políticas de seguridad y su control de acceso bien definidos. También incorpora funciones como la verificación de bytecode, que ayuda a impedir que se ejecute software malicioso en un sistema.

2. **Concurrencia:**  Java tiene compatibilidad integrada con el multihilo, lo que permite que las aplicaciones realicen varias tareas simultáneamente. Esta característica convierte a Java en una excelente opción para desarrollar aplicaciones grandes y complejas con múltiples funciones y funcionalidades.

3. **Bases de código grandes:**  Java admite la programación orientada a objetos, lo que la hace una opción adecuada para desarrollar bases de código grandes. Su naturaleza modular y el uso de patrones de encapsulación y abstracción facilitan aún más el proceso de desarrollo de software.

4. **Versatilidad:**  Java es versátil y permite usar una amplia gama de bibliotecas y frameworks, lo que la convierte en una excelente opción tanto para aplicaciones web como de nivel empresarial.

### Resultado de la decisión

Hemos decidido usar el lenguaje de programación Java para nuestro proyecto, considerando sus funciones de seguridad, su compatibilidad con la concurrencia, su capacidad para manejar bases de código grandes y su versatilidad. Esta decisión se alinea con los requisitos de nuestro proyecto, y creemos que elegir Java garantizará su éxito. 

### Consecuencias

1. Necesitaremos desarrolladores con experiencia en Java que puedan usarlo con soltura.

2. Cualquier código escrito en el lenguaje debe ser compatible con la máquina virtual de Java (JVM).

3. Incorporar nuevas funciones, funcionalidades o frameworks puede plantear algunas dificultades.

4. Los proyectos grandes y complejos en Java pueden requerir más tiempo y recursos para desarrollarse.
