# Pautas para lograr decisiones sostenibles

<https://www.infoq.com/articles/sustainable-architectural-design-decisions/>

En nuestro trabajo aprendimos las siguientes lecciones, que pueden servir como pautas y como evaluación para lograr decisiones sostenibles:

1. Use un enfoque ligero y minimalista para la documentación inicial de las decisiones.

2. Priorice y registre todas las decisiones importantes que sean lo bastante relevantes para documentar y comprender la arquitectura objetivo.

3. Detalle las decisiones especialmente importantes con plantillas completas solo después de haber terminado el trabajo inicial (es decir, cuando quienes toman las decisiones estén conformes con las decisiones de arquitectura adoptadas y confíen en que no será necesario revisarlas pronto).

4. Use las versiones ligeras y minimalistas del paso 1 como una versión corta de las decisiones documentadas, con el nivel de granularidad adecuado para ofrecer una visión general de las decisiones detalladas, así como para las decisiones triviales u obvias.

5. Siempre que sea posible, use el conocimiento de arquitectura existente, ya sea de modelos de orientación o de otras fuentes. Revise y amplíe ese conocimiento y adáptelo al contexto de la decisión específica.

6. Asegúrese de que se establezcan vínculos de trazabilidad entre las decisiones y tanto los requisitos como los diseños de arquitectura y el código.

7. Proporcione una comprobación de coherencia automatizada para asegurarse de que los vínculos de trazabilidad se mantengan sincronizados tras un cambio. Limite el número de dependencias entre decisiones y otros artefactos de software.

8. Aplique las pautas de justificación de forma consecuente y enérgica: son la parte más importante de la documentación de las decisiones, porque aportan el fundamento.
