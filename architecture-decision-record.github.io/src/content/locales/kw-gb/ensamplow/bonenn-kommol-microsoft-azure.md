# Kovskrif dyberth arkitektoryeth: bonenn kommol Microsoft Azure

Titel an dyberth: Degemmeres Microsoft Azure avel an infrastruktur kommol rag agan kowethas

Dyberthor: Penn Kedhlow

Dydhyas: 2021-10-15

Studh: Gwarthys

## Downva

An kowethas a dowl treylya dhyworth infrastruktur hengovek war-le dhe infrastruktur kommol. Rag kavos hemma, an kowethas re jydjas lies profyer gwassanath kommol avel Amazon Web Services (AWS), Google Cloud Platform (GCP), Microsoft Azure, ha IBM Cloud. Pub profyer a'n jeves y set y honan a nodhow, prow, ha strokturyeth prys. Wosa dasdhesk manylys, dyberthys o may fo Microsoft Azure an dewis moyha gwiw rag agan kowethas.

## Dyberth

Degemmeres Microsoft Azure avel an infrastruktur kommol rag agan kowethas.

## Rason

An re a sew yw an ressons rag degemmeres Microsoft Azure:

1. Gwassanethow kowlwir: Azure a re ystynnans leun a wassanethow kommol dhyworth infrastruktur avel gwassaneth (IaaS) bys y medhelweyth avel gwassaneth (SaaS) ha platform avel gwassaneth (PaaS). Hemma a gonsent dhyn usya gwassanethow Azure dhe dhisolva othommow an kowethas, avel gwithyans, kompoterya, rosow, ha dasdhesk.

2. Skalyadewder ha fexibilita: Gans Azure, ni a hyll skalyi fentennow a-ugh po a-woles yn es herwydh agan othommow negys. Azure a re ynwedh fexibilita yn dewis kolonn-oberi, yeth towlennans, ha framweythow.

3. Sawder ha kesstowans: Azure a re live uhel a sawder ha kesstowans, awos y vos kesson gans lies savon diwysyans avel ISO, SOC, HIPAA, ha PCI DSS. Azure a re ynwedh nodhow sawder avonsys avel bagas sawder ros, fayerwallow, ha difresyans DDoS.

4. Kommol hibrid: Azure a re skians kommol hibrid heb ankombrans, ow konsentya dhe gowethasow junya aga infrastruktur war-le gans Azure. Hemma a wra es dhyn treylya gweythrysow dhe'n kommol ha re dhyn fexibilita dhe ddewis ple y with data.

5. Kost-effeythus: Azure a re model prys tal-pan-usys, hen yw ni a dal hepken rag an fentennow usys. Hemma a weres dhyn gwitha kostow erbynn infrastruktur hengovek war-le.

## Diwedhyans

Degemmeres Microsoft Azure avel an infrastruktur kommol rag agan kowethas a gesson gans agan othommow negys ha re lies prow avel skalyadewder, fexibilita, sawder, ha kost-effeythusrwydd. Rakhenna, kusulys yw degemmeres Azure avel agan infrastruktur kommol.
