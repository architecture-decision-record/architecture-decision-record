# Amazon Web Services 嘅架構決策記錄

標題：採用 Amazon Web Services 作為雲端基礎設施

## 決策

經過對各個雲端基礎設施平台嘅全面評估，已決定我哋組織會採用 Amazon Web Services（AWS）嚟滿足雲端基礎設施需要。

## 背景

我哋組織發展迅速，需要可靠而且可擴展嘅雲端基礎設施去應付業務需求。經過考慮多個雲端基礎設施供應商之後，結論係 AWS 提供最合適嘅服務範圍，可以滿足我哋現時同未來嘅需求。

## 考慮因素

市場上有好多已證明可靠而且高效嘅雲端基礎設施供應商。不過，AWS 唔單止提供一套全面嘅服務去滿足我哋嘅需要，仲擁有龐大嘅客戶基礎，同埋成功部署嘅往績。AWS 亦提供廣泛嘅支援同培訓資源，確保我哋嘅團隊可以有效咁使用呢個平台。

此外，AWS 喺全球有廣泛嘅佈局，數據中心設於世界各地多個區域。咁可以確保我哋嘅數據安全，而我哋嘅應用程式同服務亦會有極高嘅可用性。AWS 亦有穩健嘅保安框架，對我哋嘅業務至關重要。

最後，AWS 提供用幾多畀幾多（pay-as-you-go）嘅模式，令我哋可以按需求靈活擴展基礎設施。即係話我哋只需為實際使用量付費，咁就可以優化成本，並將資源投放喺業務其他範疇。

## 決策

基於所作評估同 AWS 提供嘅優勢，已決定採用 AWS 嚟滿足我哋嘅雲端基礎設施需要。

## 後果

採用 AWS 可能需要為團隊提供培訓，確保佢哋熟悉呢個平台並能夠有效使用。將我哋現有嘅基礎設施遷移到 AWS 平台，亦可能涉及一些初期成本。

## 擁有權

確保有效使用 AWS 同管理相關風險嘅責任，將屬於雲端基礎設施團隊嘅職權範圍。出現嘅任何問題都必須由呢個團隊處理。

## 檢討

採用 AWS 嘅決策會每年檢討一次，確保佢繼續滿足我哋嘅需要，並且平台帶來嘅好處得到充分體現。
