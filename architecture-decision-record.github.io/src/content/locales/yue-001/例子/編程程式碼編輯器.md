# 架構決策記錄：編程程式碼編輯器

## 背景

編程程式碼編輯器係開發人員撰寫同編輯程式碼嘅必備工具。市面上有好多程式碼編輯器，各有自己嘅功能、優點同缺點。本 ADR 旨在記錄為編程程式碼編輯器所作出嘅架構決策。

## 優先事項

編程程式碼編輯器嘅架構應該優先考慮以下各項：

* **模組化**：程式碼編輯器應該以模組化方式設計，讓開發人員按需要自訂同擴展。咁樣可以形成靈活嘅架構，適應不同開發人員同團隊嘅需要。

* **效能**：程式碼編輯器應該表現良好而且反應靈敏，令開發人員可以高效工作，唔會被所用工具拖慢。

* **用戶介面**：用戶介面應該直觀易用，令開發人員可以專注於自己嘅程式碼，而唔使同編輯器糾纏。

* **可擴展性**：程式碼編輯器應該設計成容許輕鬆用第三方外掛同整合擴展。

* **兼容性**：程式碼編輯器應該兼容多種程式語言同技術，成為廣大開發人員嘅有用工具。

## 決策

基於呢啲優先事項，編程程式碼編輯器嘅架構應該設計成包含以下組件：

* **核心**：呢個組件提供程式碼編輯器嘅基本功能，例如語法突顯、文字編輯同檔案管理。

* **UI**：呢個組件提供程式碼編輯器嘅用戶介面，包括選單、工具列同鍵盤快捷鍵。

* **外掛**：呢個組件容許開發人員透過安裝第三方外掛擴展程式碼編輯器嘅功能。外掛可以提供額外功能，例如程式碼補全、程式碼檢查（linting）或者除錯。

* **整合**：呢個組件容許程式碼編輯器同版本控制系統、建置系統或者除錯工具等其他工具同技術整合。

## 理據

程式碼編輯器嘅模組化，令開發人員可以按需要自訂同擴展。呢點好重要，因為唔同嘅開發人員同團隊有唔同嘅需要同工作流程，而靈活嘅架構可以遷就呢啲差異。

* **效能**：至關重要，因為開發人員需要高效工作，唔會被工具拖慢。效能良好嘅程式碼編輯器對生產力不可或缺，可以幫助開發人員保持專注同集中。

* **UI**：重要，因為佢令開發人員可以專注於程式碼，而唔使同編輯器糾纏。咁樣可以帶來更高嘅生產力，同更少嘅挫折感。

* **可擴展性**：強大，因為佢令程式碼編輯器可以適應唔同嘅需要同工作流程。第三方外掛同整合可以提供核心編輯器冇包括嘅額外功能同能力。

* **兼容性**：有價值，因為佢令程式碼編輯器可以配合多種程式語言同技術使用。咁樣令編輯器成為廣大開發人員更有用嘅工具。

核心、外掛、整合同 UI 組件提供清晰嘅關注點分離，並容許模組化架構，可以輕鬆擴展同自訂。呢個架構靈活、效能良好，而且兼容多種程式語言同技術，成為開發人員嘅有用工具。
