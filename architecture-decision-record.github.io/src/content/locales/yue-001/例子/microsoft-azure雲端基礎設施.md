# 架構決策記錄：Microsoft Azure 雲端基礎設施" 

決策標題：採用 Microsoft Azure 作為我哋組織嘅雲端基礎設施

決策者：資訊總監（Chief Information Officer）

日期：2021-10-15

狀態：已批准

## 背景

組織計劃由傳統本地基礎設施遷移到雲端基礎設施。為此，組織評估過多個雲端服務供應商，例如 Amazon Web Services（AWS）、Google Cloud Platform（GCP）、Microsoft Azure 同 IBM Cloud。每個供應商都有自己嘅功能、好處同定價結構。經過詳細分析，結論係 Microsoft Azure 係最適合我哋組織嘅選擇。

## 決策

採用 Microsoft Azure 作為我哋組織嘅雲端基礎設施。

## 理據

以下係採用 Microsoft Azure 嘅原因：

1. 服務全面：Azure 提供完整嘅雲端服務，由基礎設施即服務（IaaS）到軟件即服務（SaaS）同平台即服務（PaaS）一應俱全。咁樣令我哋可以善用 Azure 服務，去解決組織嘅需求，例如儲存、運算、網絡同分析。

2. 可擴展性同靈活性：用 Azure，我哋可以根據業務需要輕鬆擴大或者縮小資源。Azure 亦提供靈活性，可以自由揀選作業系統、程式語言同框架。

3. 保安同合規：Azure 提供高水平嘅保安同合規，因為佢符合 ISO、SOC、HIPAA 同 PCI DSS 等多項行業標準。Azure 亦提供網絡安全群組、防火牆同 DDoS 防護等進階保安功能。

4. 混合雲：Azure 提供無縫嘅混合雲體驗，令組織可以將本地基礎設施連接到 Azure。咁樣令我哋容易將工作負載遷移到雲端，並讓我哋靈活揀選數據儲存嘅位置。

5. 具成本效益：Azure 提供用幾多畀幾多嘅定價模式，意味住我哋只需為使用嘅資源付費。同傳統本地基礎設施相比，咁樣有助我哋節省成本。

## 結論

採用 Microsoft Azure 作為我哋組織嘅雲端基礎設施，符合我哋嘅業務需求，並帶來可擴展性、靈活性、保安同成本效益等多項好處。因此，建議採用 Azure 作為我哋嘅雲端基礎設施。
