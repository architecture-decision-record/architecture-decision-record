# 四日工作週嘅決策記錄

標題：實施四日工作週

## 背景同問題陳述

我哋組織一直考慮轉為四日工作週。現行每週 5 日、每日 8 小時嘅工作時間表，已經導致生產力偏低、員工倦怠同高流失率。建議嘅改變旨在提升員工滿意度、投入度同留任率，最終改善組織表現。

## 決策

我哋決定由下一個季度開始，喺全個組織為所有員工實施四日工作週。

## 理據

呢個決策基於以下因素：

1. 員工回饋：喺員工之間進行嘅問卷調查顯示，大家希望有更具彈性嘅工作時間表，以及更好嘅工作與生活平衡。大多數受訪者表示對四日工作週有興趣。

2. 研究結果：對已經實施四日工作週嘅公司所作嘅研究顯示，員工生產力提高、缺勤減少，工作與生活平衡亦有改善。

3. 競爭優勢：提供四日工作週對潛在員工嚟講可以係一項吸引嘅福利，亦有助留住現有人才。

4. 組織目標：轉為四日工作週符合我哋建立更健康、更高生產力工作環境嘅組織目標。

## 實施計劃

為實施四日工作週，將會採取以下步驟：

1. 溝通：會透過全公司電郵同同團隊主管開會，向所有員工傳達呢個決策。

2. 時間表：新時間表為全職員工逢星期一至四工作，兼職員工可以選擇彈性時間表。每日工作時數會延長至 10 小時。

3. 政策更新：會更新人力資源政策（例如假期政策同福利），令其配合新時間表。

4. 培訓：會培訓經理點樣喺新時間表下管理團隊，以及點樣妥善追蹤員工表現同生產力。

5. 評估：新工作時間表會喺六個月後進行評估，以確定佢對員工滿意度、投入度同留任率嘅影響。

## 預期成果

預期實施四日工作週會帶來以下成果：

1. 員工滿意度、投入度同留任率提升。

2. 員工嘅工作與生活平衡得到改善。

3. 生產力提高，缺勤減少。

4. 員工福利待遇更具吸引力，喺招聘市場上更具競爭優勢。

## 結論

我哋相信，實施四日工作週會令我哋嘅組織同員工受惠。我哋期待睇到呢個決策對員工同整體組織表現帶來嘅正面影響。
