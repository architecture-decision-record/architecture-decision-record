# Arkitekturbeslutningslogg: Skyinfrastruktur med Microsoft Azure

Tittel på beslutningen: Innføring av Microsoft Azure som skyinfrastruktur for organisasjonen vår

Beslutningstaker: Informasjonsdirektør (CIO)

Dato: 2021-10-15

Status: Godkjent

## Bakgrunn

Organisasjonen planlegger å migrere fra tradisjonell lokal infrastruktur til skyinfrastruktur. For å oppnå dette har organisasjonen evaluert flere leverandører av skytjenester, som Amazon Web Services (AWS), Google Cloud Platform (GCP), Microsoft Azure og IBM Cloud. Hver leverandør har sitt eget sett med funksjoner, fordeler og prisstruktur. Etter en detaljert analyse ble det konkludert med at Microsoft Azure er det best egnede alternativet for organisasjonen vår.

## Beslutning

Ta i bruk Microsoft Azure som skyinfrastruktur for organisasjonen vår.

## Begrunnelse

Følgende er grunnene til å ta i bruk Microsoft Azure:

1. Omfattende tjenester: Azure tilbyr et komplett spekter av skytjenester, fra infrastruktur som en tjeneste (IaaS) til programvare som en tjeneste (SaaS) og plattform som en tjeneste (PaaS). Det gjør at vi kan bruke Azure-tjenester til å løse organisasjonens behov, for eksempel lagring, databehandling, nettverk og analyse.

2. Skalerbarhet og fleksibilitet: Med Azure kan vi enkelt skalere ressurser opp eller ned etter forretningsbehovene våre. Azure gir også fleksibilitet i valg av operativsystem, programmeringsspråk og rammeverk.

3. Sikkerhet og etterlevelse: Azure har høy grad av sikkerhet og etterlevelse, siden det oppfyller flere bransjestandarder som ISO, SOC, HIPAA og PCI DSS. Azure har også avanserte sikkerhetsfunksjoner som nettverkssikkerhetsgrupper, brannmurer og DDoS-beskyttelse.

4. Hybridsky: Azure gir en sømløs opplevelse med hybridsky og gjør det mulig for organisasjoner å koble sin lokale infrastruktur til Azure. Det gjør det enkelt for oss å migrere arbeidsbelastninger til skyen og gir oss fleksibilitet til å velge hvor data skal lagres.

5. Kostnadseffektivt: Azure har en prismodell med betaling etter bruk, som betyr at vi bare betaler for ressursene som brukes. Det hjelper oss å spare kostnader sammenlignet med tradisjonell lokal infrastruktur.

## Konklusjon

Å ta i bruk Microsoft Azure som skyinfrastruktur for organisasjonen vår stemmer med forretningsbehovene våre og gir flere fordeler som skalerbarhet, fleksibilitet, sikkerhet og kostnadseffektivitet. Derfor anbefales det å ta i bruk Azure som skyinfrastruktur.
