# Arkkitehtuuripäätöstietue: Microsoft Azure -pilvi-infrastruktuuri

Päätöksen otsikko: Microsoft Azuren käyttöönotto organisaatiomme pilvi-infrastruktuurina

Päätöksentekijä: Tietohallintojohtaja

Päivämäärä: 2021-10-15

Tila: Hyväksytty

## Tausta

Organisaatio suunnittelee siirtymistä perinteisestä paikallisesta infrastruktuurista pilvi-infrastruktuuriin. Tämän saavuttamiseksi organisaatio on arvioinut useita pilvipalveluntarjoajia, kuten Amazon Web Services (AWS), Google Cloud Platform (GCP), Microsoft Azure ja IBM Cloud. Jokaisella tarjoajalla on omat ominaisuutensa, etunsa ja hinnoittelurakenteensa. Yksityiskohtaisen analyysin jälkeen todettiin, että Microsoft Azure on organisaatiollemme sopivin vaihtoehto.

## Päätös

Otetaan Microsoft Azure käyttöön organisaatiomme pilvi-infrastruktuurina.

## Perustelut

Seuraavat ovat syyt Microsoft Azuren käyttöönotolle:

1. Kattavat palvelut: Azure tarjoaa täydellisen valikoiman pilvipalveluja infrastruktuurista palveluna (IaaS) ohjelmistoon palveluna (SaaS) ja alustaan palveluna (PaaS). Tämä mahdollistaa Azure-palvelujen hyödyntämisen organisaation vaatimusten, kuten tallennuksen, laskennan, verkottumisen ja analytiikan, ratkaisemiseen.

2. Skaalautuvuus ja joustavuus: Azuren avulla voimme helposti skaalata resursseja ylös tai alas liiketoimintavaatimustemme mukaan. Azure tarjoaa myös joustavuutta käyttöjärjestelmän, ohjelmointikielen ja kehysten valinnassa.

3. Tietoturva ja vaatimustenmukaisuus: Azure tarjoaa korkean tason tietoturvan ja vaatimustenmukaisuuden, sillä se noudattaa useita alan standardeja, kuten ISO, SOC, HIPAA ja PCI DSS. Azure tarjoaa myös edistyneitä tietoturvaominaisuuksia, kuten verkon suojausryhmät, palomuurit ja DDoS-suojauksen.

4. Hybridipilvi: Azure tarjoaa saumattoman hybridipilvikokemuksen, jonka avulla organisaatiot voivat yhdistää paikallisen infrastruktuurinsa Azureen. Tämä helpottaa työkuormien siirtämistä pilveen ja antaa meille joustavuuden valita, minne tiedot tallennetaan.

5. Kustannustehokas: Azure tarjoaa käyttöperusteisen hinnoittelumallin, mikä tarkoittaa, että maksamme vain käytetyistä resursseista. Tämä auttaa säästämään kustannuksissa verrattuna perinteiseen paikalliseen infrastruktuuriin.

## Johtopäätös

Microsoft Azuren käyttöönotto organisaatiomme pilvi-infrastruktuurina on linjassa liiketoimintavaatimustemme kanssa ja tarjoaa useita etuja, kuten skaalautuvuuden, joustavuuden, tietoturvan ja kustannustehokkuuden. Siksi suositellaan Azuren käyttöönottoa pilvi-infrastruktuurinamme.
