# Päätöstietueen mallipohja: Planguage

Katso https://www.iaria.org/conferences2012/filesICCGI12/Tutorial%20Specifying%20Effective%20Non-func.pdf

## Mikä on Planguage?

Planguage on suunnittelukieli, joka käyttää näitä avainsanoja:

* Tag (tunniste): Yksilöllinen, pysyvä tunniste
* Gist (ydinkuvaus): Lyhyt yhteenveto vaatimuksesta tai käsiteltävästä alueesta
* Requirement (vaatimus): Teksti, joka kuvaa itse vaatimuksen yksityiskohtaisesti
* Rationale (perustelu): Päättely, joka oikeuttaa vaatimuksen
* Priority (prioriteetti): Lausuma prioriteetista ja resurssivaatimuksesta
* Stakeholders (sidosryhmät): Osapuolet, joihin vaatimus vaikuttaa olennaisesti
* Status (tila): Vaatimuksen tila (luonnos, katselmoitu, sitouduttu jne.)
* Owner (omistaja): Henkilö, joka vastaa vaatimuksen toteuttamisesta
* Author (kirjoittaja): Henkilö, joka kirjoitti vaatimuksen
* Revision (versio): Lausuman versionumero
* Date (päivämäärä): Viimeisimmän version päivämäärä
* Assumptions (oletukset): Kaikki, mikä voisi aiheuttaa ongelmia, jos se ei pidä paikkaansa nyt tai myöhemmin
* Risks (riskit): Kaikki, mikä voisi aiheuttaa toimintahäiriön, viiveen tai muita kielteisiä vaikutuksia
* Defined (määritelty): Termin määritelmä (parempi käyttää sanastoa)
