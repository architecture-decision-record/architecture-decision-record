# Запис архітектурного рішення: хмарна інфраструктура Microsoft Azure

Назва рішення: впровадження Microsoft Azure як хмарної інфраструктури нашої організації

Особа, що ухвалює рішення: директор з інформаційних технологій (CIO)

Дата: 2021-10-15

Статус: затверджено

## Передумови

Організація планує мігрувати з традиційної локальної інфраструктури на хмарну інфраструктуру. Для цього організація оцінила кількох постачальників хмарних послуг, як-от Amazon Web Services (AWS), Google Cloud Platform (GCP), Microsoft Azure та IBM Cloud. Кожен постачальник має власний набір можливостей, переваг і структуру цін. Після детального аналізу було зроблено висновок, що Microsoft Azure є найбільш придатним варіантом для нашої організації.

## Рішення

Впровадити Microsoft Azure як хмарну інфраструктуру нашої організації.

## Обґрунтування

Нижче наведено причини впровадження Microsoft Azure:

1. Комплексні послуги: Azure надає повний спектр хмарних послуг — від інфраструктури як послуги (IaaS) до програмного забезпечення як послуги (SaaS) і платформи як послуги (PaaS). Це дозволяє нам використовувати послуги Azure для задоволення вимог організації, таких як сховище, обчислення, мережі та аналітика.

2. Масштабованість і гнучкість: з Azure ми можемо легко збільшувати чи зменшувати ресурси залежно від наших бізнес-вимог. Azure також пропонує гнучкість у виборі операційної системи, мови програмування та фреймворків.

3. Безпека та відповідність: Azure пропонує високий рівень безпеки та відповідності, оскільки відповідає кільком галузевим стандартам, як-от ISO, SOC, HIPAA і PCI DSS. Azure також надає просунуті можливості безпеки, як-от мережеві групи безпеки, брандмауери та захист від DDoS.

4. Гібридна хмара: Azure забезпечує безшовний досвід гібридної хмари, дозволяючи організаціям з’єднувати свою локальну інфраструктуру з Azure. Це полегшує нам перенесення робочих навантажень у хмару та дає гнучкість вибирати, де зберігати дані.

5. Економічна ефективність: Azure пропонує модель ціноутворення з оплатою за фактичне використання, що означає, що ми платимо лише за використані ресурси. Це допомагає заощаджувати кошти порівняно з традиційною локальною інфраструктурою.

## Висновок

Впровадження Microsoft Azure як хмарної інфраструктури нашої організації відповідає нашим бізнес-вимогам і пропонує кілька переваг, як-от масштабованість, гнучкість, безпека та економічна ефективність. Тому рекомендовано впровадити Azure як нашу хмарну інфраструктуру.
