# Шаблон запису рішення Майкла Найгарда

Це шаблон зі статті [Documenting architecture decisions - Michael Nygard](http://thinkrelevance.com/blog/2011/11/15/documenting-architecture-decisions).
Для керування файлами ADR можна використовувати [adr-tools](https://github.com/npryce/adr-tools).

У кожному файлі ADR напишіть такі розділи:

# Назва

## Статус

Який статус: запропоновано, прийнято, відхилено, застаріло, замінено тощо?

## Контекст

Яку проблему ми бачимо, що спонукає до цього рішення чи зміни?

## Рішення

Яку зміну ми пропонуємо та/або вносимо?

## Наслідки

Що стає легшим або складнішим через цю зміну?
