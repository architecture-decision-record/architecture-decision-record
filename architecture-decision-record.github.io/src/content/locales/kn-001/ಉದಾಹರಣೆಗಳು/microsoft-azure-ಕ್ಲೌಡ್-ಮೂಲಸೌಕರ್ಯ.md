# ವಾಸ್ತುಶಿಲ್ಪ ನಿರ್ಧಾರ ದಾಖಲೆ: Microsoft Azure ಕ್ಲೌಡ್ ಮೂಲಸೌಕರ್ಯ" 

ನಿರ್ಧಾರದ ಶೀರ್ಷಿಕೆ: ನಮ್ಮ ಸಂಸ್ಥೆಯ ಕ್ಲೌಡ್ ಮೂಲಸೌಕರ್ಯವಾಗಿ Microsoft Azure ಅನ್ನು ಅಳವಡಿಸಿಕೊಳ್ಳುವುದು

ನಿರ್ಧಾರ ತೆಗೆದುಕೊಂಡವರು: ಮುಖ್ಯ ಮಾಹಿತಿ ಅಧಿಕಾರಿ

ದಿನಾಂಕ: 2021-10-15

ಸ್ಥಿತಿ: ಅನುಮೋದಿತ

## ಹಿನ್ನೆಲೆ

ಸಂಸ್ಥೆಯು ಸಾಂಪ್ರದಾಯಿಕ ಆನ್-ಪ್ರೆಮಿಸಸ್ ಮೂಲಸೌಕರ್ಯದಿಂದ ಕ್ಲೌಡ್ ಮೂಲಸೌಕರ್ಯಕ್ಕೆ ವಲಸೆ ಹೋಗಲು ಯೋಜಿಸುತ್ತಿದೆ. ಇದನ್ನು ಸಾಧಿಸಲು, ಸಂಸ್ಥೆಯು Amazon Web Services (AWS), Google Cloud Platform (GCP), Microsoft Azure ಮತ್ತು IBM Cloud ನಂತಹ ಹಲವು ಕ್ಲೌಡ್ ಸೇವಾ ಪೂರೈಕೆದಾರರನ್ನು ಮೌಲ್ಯಮಾಪನ ಮಾಡಿದೆ. ಪ್ರತಿ ಪೂರೈಕೆದಾರರು ತನ್ನದೇ ಆದ ವೈಶಿಷ್ಟ್ಯಗಳು, ಪ್ರಯೋಜನಗಳು ಮತ್ತು ಬೆಲೆ ರಚನೆಯನ್ನು ಹೊಂದಿದ್ದಾರೆ. ವಿವರವಾದ ವಿಶ್ಲೇಷಣೆಯ ನಂತರ, Microsoft Azure ನಮ್ಮ ಸಂಸ್ಥೆಗೆ ಅತ್ಯಂತ ಸೂಕ್ತ ಆಯ್ಕೆ ಎಂದು ತೀರ್ಮಾನಿಸಲಾಯಿತು.

## ನಿರ್ಧಾರ

ನಮ್ಮ ಸಂಸ್ಥೆಯ ಕ್ಲೌಡ್ ಮೂಲಸೌಕರ್ಯವಾಗಿ Microsoft Azure ಅನ್ನು ಅಳವಡಿಸಿಕೊಳ್ಳಿ.

## ತಾರ್ಕಿಕತೆ

Microsoft Azure ಅಳವಡಿಸಿಕೊಳ್ಳಲು ಕಾರಣಗಳು ಹೀಗಿವೆ:

1. ಸಮಗ್ರ ಸೇವೆಗಳು: Azure ಸೇವೆಯಾಗಿ ಮೂಲಸೌಕರ್ಯ (IaaS) ದಿಂದ ಸೇವೆಯಾಗಿ ತಂತ್ರಾಂಶ (SaaS) ಮತ್ತು ಸೇವೆಯಾಗಿ ವೇದಿಕೆ (PaaS) ವರೆಗೆ ಕ್ಲೌಡ್ ಸೇವೆಗಳ ಸಂಪೂರ್ಣ ಶ್ರೇಣಿಯನ್ನು ಒದಗಿಸುತ್ತದೆ. ಸಂಗ್ರಹಣೆ, ಕಂಪ್ಯೂಟ್, ನೆಟ್‌ವರ್ಕಿಂಗ್ ಮತ್ತು ವಿಶ್ಲೇಷಣೆಯಂತಹ ಸಂಸ್ಥೆಯ ಅವಶ್ಯಕತೆಗಳನ್ನು ಪರಿಹರಿಸಲು Azure ಸೇವೆಗಳನ್ನು ಬಳಸಿಕೊಳ್ಳಲು ಇದು ನಮಗೆ ಅನುವು ಮಾಡಿಕೊಡುತ್ತದೆ.

2. ವಿಸ್ತರಣೀಯತೆ ಮತ್ತು ನಮ್ಯತೆ: Azure ನೊಂದಿಗೆ, ನಮ್ಮ ವ್ಯವಹಾರದ ಅವಶ್ಯಕತೆಗಳ ಆಧಾರದ ಮೇಲೆ ನಾವು ಸಂಪನ್ಮೂಲಗಳನ್ನು ಸುಲಭವಾಗಿ ಹೆಚ್ಚಿಸಬಹುದು ಅಥವಾ ಕಡಿಮೆ ಮಾಡಬಹುದು. ಆಪರೇಟಿಂಗ್ ಸಿಸ್ಟಮ್, ಪ್ರೋಗ್ರಾಮಿಂಗ್ ಭಾಷೆ ಮತ್ತು ಚೌಕಟ್ಟುಗಳನ್ನು ಆರಿಸುವಲ್ಲಿಯೂ Azure ನಮ್ಯತೆಯನ್ನು ನೀಡುತ್ತದೆ.

3. ಭದ್ರತೆ ಮತ್ತು ಅನುಸರಣೆ: Azure ಉನ್ನತ ಮಟ್ಟದ ಭದ್ರತೆ ಮತ್ತು ಅನುಸರಣೆಯನ್ನು ನೀಡುತ್ತದೆ, ಏಕೆಂದರೆ ಇದು ISO, SOC, HIPAA ಮತ್ತು PCI DSS ನಂತಹ ಹಲವಾರು ಉದ್ಯಮ ಮಾನದಂಡಗಳಿಗೆ ಅನುಗುಣವಾಗಿದೆ. Azure ನೆಟ್‌ವರ್ಕ್ ಭದ್ರತಾ ಗುಂಪುಗಳು, ಫೈರ್‌ವಾಲ್‌ಗಳು ಮತ್ತು DDoS ರಕ್ಷಣೆಯಂತಹ ಸುಧಾರಿತ ಭದ್ರತಾ ವೈಶಿಷ್ಟ್ಯಗಳನ್ನೂ ಒದಗಿಸುತ್ತದೆ.

4. ಹೈಬ್ರಿಡ್ ಕ್ಲೌಡ್: Azure ಅಡೆತಡೆಯಿಲ್ಲದ ಹೈಬ್ರಿಡ್ ಕ್ಲೌಡ್ ಅನುಭವವನ್ನು ಒದಗಿಸುತ್ತದೆ, ಸಂಸ್ಥೆಗಳು ತಮ್ಮ ಆನ್-ಪ್ರೆಮಿಸಸ್ ಮೂಲಸೌಕರ್ಯವನ್ನು Azure ನೊಂದಿಗೆ ಸಂಪರ್ಕಿಸಲು ಅನುವು ಮಾಡಿಕೊಡುತ್ತದೆ. ಇದು ಕೆಲಸದ ಹೊರೆಗಳನ್ನು ಕ್ಲೌಡ್‌ಗೆ ವಲಸೆ ಮಾಡುವುದನ್ನು ನಮಗೆ ಸುಲಭಗೊಳಿಸುತ್ತದೆ ಮತ್ತು ಡೇಟಾವನ್ನು ಎಲ್ಲಿ ಸಂಗ್ರಹಿಸಬೇಕೆಂದು ಆಯ್ಕೆ ಮಾಡುವ ನಮ್ಯತೆಯನ್ನು ನೀಡುತ್ತದೆ.

5. ವೆಚ್ಚ-ಪರಿಣಾಮಕಾರಿ: Azure ಬಳಸಿದಷ್ಟು-ಪಾವತಿಸುವ ಬೆಲೆ ಮಾದರಿಯನ್ನು ನೀಡುತ್ತದೆ, ಅಂದರೆ ನಾವು ಬಳಸಿದ ಸಂಪನ್ಮೂಲಗಳಿಗೆ ಮಾತ್ರ ಪಾವತಿಸುತ್ತೇವೆ. ಸಾಂಪ್ರದಾಯಿಕ ಆನ್-ಪ್ರೆಮಿಸಸ್ ಮೂಲಸೌಕರ್ಯಕ್ಕೆ ಹೋಲಿಸಿದರೆ ಇದು ವೆಚ್ಚ ಉಳಿಸಲು ನಮಗೆ ಸಹಾಯ ಮಾಡುತ್ತದೆ.

## ತೀರ್ಮಾನ

ನಮ್ಮ ಸಂಸ್ಥೆಯ ಕ್ಲೌಡ್ ಮೂಲಸೌಕರ್ಯವಾಗಿ Microsoft Azure ಅನ್ನು ಅಳವಡಿಸಿಕೊಳ್ಳುವುದು ನಮ್ಮ ವ್ಯವಹಾರದ ಅವಶ್ಯಕತೆಗಳಿಗೆ ಹೊಂದುತ್ತದೆ ಮತ್ತು ವಿಸ್ತರಣೀಯತೆ, ನಮ್ಯತೆ, ಭದ್ರತೆ ಮತ್ತು ವೆಚ್ಚ-ಪರಿಣಾಮಕಾರಿತ್ವದಂತಹ ಹಲವಾರು ಪ್ರಯೋಜನಗಳನ್ನು ನೀಡುತ್ತದೆ. ಆದ್ದರಿಂದ, ನಮ್ಮ ಕ್ಲೌಡ್ ಮೂಲಸೌಕರ್ಯವಾಗಿ Azure ಅನ್ನು ಅಳವಡಿಸಿಕೊಳ್ಳಲು ಶಿಫಾರಸು ಮಾಡಲಾಗಿದೆ.
