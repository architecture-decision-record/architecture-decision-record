# git ನೊಂದಿಗೆ ADR ಬಳಕೆಯನ್ನು ಪ್ರಾರಂಭಿಸುವುದು ಹೇಗೆ

ನೀವು git ಆವೃತ್ತಿ ನಿಯಂತ್ರಣವನ್ನು ಬಳಸಲು ಇಷ್ಟಪಡುವುದಾದರೆ, ಮೂಲ ಕೋಡ್ ಇರುವ ಒಂದು ಸಾಮಾನ್ಯ ತಂತ್ರಾಂಶ ಯೋಜನೆಗಾಗಿ git ನೊಂದಿಗೆ ADR ಬಳಸಲು ನಾವು ಹೇಗೆ ಪ್ರಾರಂಭಿಸಲು ಇಷ್ಟಪಡುತ್ತೇವೆ ಎಂಬುದು ಇಲ್ಲಿದೆ.

ADR ಕಡತಗಳಿಗಾಗಿ ಒಂದು ಡೈರೆಕ್ಟರಿ ರಚಿಸಿ:

```sh
$ mkdir adr
```

ಪ್ರತಿ ADR ಗೂ `choose-database.md` ನಂತಹ ಒಂದು ಪಠ್ಯ ಕಡತವನ್ನು ರಚಿಸಿ:

```sh
$ vi choose-database.md
```

ADR ನಲ್ಲಿ ನಿಮಗೆ ಬೇಕಾದುದನ್ನು ಬರೆಯಿರಿ. ಕಲ್ಪನೆಗಳಿಗಾಗಿ ಈ ರೆಪೊಸಿಟರಿಯಲ್ಲಿರುವ ಟೆಂಪ್ಲೇಟುಗಳನ್ನು ನೋಡಿ.

ADR ಅನ್ನು ನಿಮ್ಮ git ರೆಪೊಗೆ ಕಮಿಟ್ ಮಾಡಿ.
