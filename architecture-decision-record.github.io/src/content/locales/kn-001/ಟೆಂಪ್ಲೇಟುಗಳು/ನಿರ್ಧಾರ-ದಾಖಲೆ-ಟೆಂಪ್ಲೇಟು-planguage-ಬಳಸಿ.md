# Planguage ಬಳಸುವ ನಿರ್ಧಾರ ದಾಖಲೆ ಟೆಂಪ್ಲೇಟು

https://www.iaria.org/conferences2012/filesICCGI12/Tutorial%20Specifying%20Effective%20Non-func.pdf ನೋಡಿ

## Planguage ಎಂದರೇನು?

Planguage ಎಂಬುದು ಈ ಕೀವರ್ಡ್‌ಗಳನ್ನು ಬಳಸುವ ಯೋಜನಾ ಭಾಷೆ:

* Tag: ಅನನ್ಯ, ಶಾಶ್ವತ ಗುರುತು
* Gist: ಅವಶ್ಯಕತೆಯ ಅಥವಾ ಪರಿಹರಿಸಲಾದ ಕ್ಷೇತ್ರದ ಸಂಕ್ಷಿಪ್ತ ಸಾರಾಂಶ
* Requirement: ಅವಶ್ಯಕತೆಯ ವಿವರಗಳನ್ನು ನೀಡುವ ಪಠ್ಯ
* Rationale: ಅವಶ್ಯಕತೆಯನ್ನು ಸಮರ್ಥಿಸುವ ತರ್ಕ
* Priority: ಆದ್ಯತೆಯ ಹೇಳಿಕೆ ಮತ್ತು ಸಂಪನ್ಮೂಲಗಳ ಮೇಲಿನ ಹಕ್ಕು
* Stakeholders: ಅವಶ್ಯಕತೆಯಿಂದ ಗಣನೀಯವಾಗಿ ಪ್ರಭಾವಿತರಾದ ಪಕ್ಷಗಳು
* Status: ಅವಶ್ಯಕತೆಯ ಸ್ಥಿತಿ (ಕರಡು, ಪರಿಶೀಲಿತ, ಬದ್ಧ, ಇತ್ಯಾದಿ)
* Owner: ಅವಶ್ಯಕತೆಯನ್ನು ಅನುಷ್ಠಾನಗೊಳಿಸುವ ಜವಾಬ್ದಾರಿ ಹೊಂದಿರುವ ವ್ಯಕ್ತಿ
* Author: ಅವಶ್ಯಕತೆಯನ್ನು ಬರೆದ ವ್ಯಕ್ತಿ
* Revision: ಹೇಳಿಕೆಯ ಆವೃತ್ತಿ ಸಂಖ್ಯೆ
* Date: ಇತ್ತೀಚಿನ ಪರಿಷ್ಕರಣೆಯ ದಿನಾಂಕ
* Assumptions: ಈಗ ಅಥವಾ ನಂತರ ನಿಜವಲ್ಲದಿದ್ದರೆ ಸಮಸ್ಯೆಗಳನ್ನು ಉಂಟುಮಾಡಬಹುದಾದ ಯಾವುದೇ ವಿಷಯ
* Risks: ದೋಷ, ವಿಳಂಬ ಅಥವಾ ಇತರ ಋಣಾತ್ಮಕ ಪರಿಣಾಮಗಳನ್ನು ಉಂಟುಮಾಡಬಹುದಾದ ಯಾವುದೇ ವಿಷಯ
* Defined: ಒಂದು ಪದದ ವ್ಯಾಖ್ಯಾನ (ಪದಕೋಶ ಬಳಸುವುದು ಉತ್ತಮ)
