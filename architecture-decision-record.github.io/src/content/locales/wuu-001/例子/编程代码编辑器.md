# 架构决策记录：编程代码编辑器

## 背景

编程代码编辑器是开发者写搭编辑代码必不可少的工具。市面上有许许多多代码编辑器，各有各个功能、优点搭缺点。迭份 ADR 个目的，是记录为编程代码编辑器做个架构决策。

## 优先级

编程代码编辑器个架构应该优先考虑下底几点：

* **模块化**：代码编辑器应该设计成模块化个，让开发者可以按需要定制搭扩展。迭能形成灵活个架构，适应勿同开发者搭团队个需要。

* **性能**：代码编辑器应该性能好、响应快，让开发者可以高效工作，勿会被用个工具拖慢。

* **用户界面**：用户界面应该直观、容易用，让开发者可以专心写代码，而勿是搭编辑器较劲。

* **可扩展性**：代码编辑器应该设计成容易用第三方插件搭集成来扩展。

* **兼容性**：代码编辑器应该兼容各种各样个编程语言搭技术，让伊成为适合广大开发者个有用工具。

## 决策

根据迭眼优先级，编程代码编辑器个架构应该设计成有下底几个组件：

* **核心**：迭个组件提供代码编辑器个基本功能，比方语法高亮、文本编辑搭文件管理。

* **UI**：迭个组件提供代码编辑器个用户界面，包括菜单、工具栏搭键盘快捷键。

* **插件**：迭个组件让开发者通过安装第三方插件来扩展代码编辑器个功能。插件可以提供额外个功能，比方代码补全、代码检查或者调试。

* **集成**：迭个组件让代码编辑器可以搭其他工具搭技术集成，比方版本控制系统、构建系统或者调试工具。

## 理据

代码编辑器个模块化让开发者可以按需要定制搭扩展。迭点蛮重要，因为勿同个开发者搭团队有勿同个需要搭工作流，灵活个架构可以容纳迭眼差异。

* **性能**：至关重要，因为开发者需要能够高效工作，勿被工具拖慢。性能好个代码编辑器对生产力必不可少，可以帮助开发者保持专注搭集中精神。

* **UI**：重要，因为伊让开发者可以专心写代码，而勿是搭编辑器较劲。迭能带来更加高个生产力，也让开发者少一眼烦恼。

* **可扩展性**：强大，因为伊让代码编辑器可以适应勿同个需要搭工作流。第三方插件搭集成可以提供核心编辑器里呒没个额外功能搭能力。

* **兼容性**：有价值，因为伊让代码编辑器可以搭各种各样个编程语言搭技术一道用。迭让编辑器成为适合广大开发者个更加有用个工具。

核心、插件、集成搭 UI 组件做到关注点清爽分离，形成容易扩展搭定制个模块化架构。迭个架构灵活、性能好，而且搭各种各样个编程语言搭技术兼容，让伊成为开发者个有用工具。
