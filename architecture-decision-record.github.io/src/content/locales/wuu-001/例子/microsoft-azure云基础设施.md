# 架构决策记录：Microsoft Azure 云基础设施

决策标题：阿拉组织采用 Microsoft Azure 作为云基础设施

决策者：首席信息官

日期：2021-10-15

状态：已批准

## 背景

组织打算从传统个本地基础设施迁移到云基础设施。为了做到迭点，组织评估了好几家云服务提供商，比方 Amazon Web Services（AWS）、Google Cloud Platform（GCP）、Microsoft Azure 搭 IBM Cloud。每家提供商侪有自家一套功能、好处搭定价结构。经过详细分析，得出个结论是 Microsoft Azure 是最适合阿拉组织个选项。

## 决策

采用 Microsoft Azure 作为阿拉组织个云基础设施。

## 理据

采用 Microsoft Azure 个理由如下：

1. 服务全面：Azure 提供从基础设施即服务（IaaS）到软件即服务（SaaS）、平台即服务（PaaS）个整套云服务。迭让阿拉可以利用 Azure 服务来解决组织个需求，比方存储、计算、网络搭分析。

2. 可扩展性搭灵活性：用 Azure，阿拉可以根据业务需要，容易地扩大或者缩小资源。Azure 还让阿拉可以灵活选择操作系统、编程语言搭框架。

3. 安全搭合规：Azure 提供高水平个安全搭合规，因为伊符合 ISO、SOC、HIPAA 搭 PCI DSS 等好几个行业标准。Azure 还提供网络安全组、防火墙搭 DDoS 防护迭类高级安全功能。

4. 混合云：Azure 提供无缝个混合云体验，让组织可以拿本地基础设施搭 Azure 连起来。迭让阿拉容易拿工作负载迁移到云上，也让阿拉可以灵活选择数据存辣啥地方。

5. 成本划算：Azure 提供按用量付费个定价模式，也就是阿拉只要为用掉个资源付费。搭传统个本地基础设施比起来，迭帮助阿拉节省成本。

## 结论

阿拉组织采用 Microsoft Azure 作为云基础设施，搭阿拉个业务需求一致，而且带来好几个好处，比方可扩展性、灵活性、安全搭成本效益。所以，建议采用 Azure 作为阿拉个云基础设施。
