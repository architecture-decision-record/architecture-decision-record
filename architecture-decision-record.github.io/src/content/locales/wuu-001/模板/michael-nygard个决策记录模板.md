# Michael Nygard 个决策记录模板

迭是[《Documenting architecture decisions - Michael Nygard》](http://thinkrelevance.com/blog/2011/11/15/documenting-architecture-decisions)里个模板。
侬可以用 [adr-tools](https://github.com/npryce/adr-tools) 来管理 ADR 文件。

每份 ADR 文件里，写下底迭几节：

# 标题

## 状态

状态是啥，比方建议中、已接受、已否决、已弃用、已取代等等？

## 背景

阿拉看到个是啥问题，促使阿拉做迭个决策或者更改？

## 决策

阿拉提议和／或者正在做个更改是啥？

## 后果

因为迭个更改，啥事体变得更加容易或者更加困难？
