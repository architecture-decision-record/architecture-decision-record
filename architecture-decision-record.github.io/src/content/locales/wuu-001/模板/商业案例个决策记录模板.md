# 商业案例个决策记录模板

迭个 ADR 模板强调为决策建立商业案例，包括标准、候选方案搭成本。


## 顶层

* 标题
* 状态
* 评估标准
* 要考虑个候选方案
* 每个候选方案个调研搭分析
  * 满足／勿满足标准，搭原因
  * 成本分析
  * SWOT 分析
  * 意见搭反馈
* 推荐


## 底层深入

**标题**：

  * 一个简短个现在时祈使短语，少于 50 个字符，像 git 提交信息一样。

**状态**：

  * 建议中、已接受、已否决、已弃用、已取代等等之一。

**评估标准**：

  * 摘要：简单讲明阿拉想发现啥，为啥。

  * 具体内容

**要考虑个候选方案**：

  * 摘要：简单讲明阿拉哪能发现候选方案，并且提醒注意任何离群个。

  * 列出所有候选方案搭相关选项；阿拉评估个潜在解决方案有啥？

  * 具体内容

**每个候选方案个调研搭分析**：

  * 摘要：简单讲明调研方法，并且提醒注意模式、聚类搭离群个。

  * 满足／勿满足标准，搭原因

    * 摘要

    * 具体内容

  * 成本分析

    * 摘要

    * 例子

      * 许可，比方合同协议搭法律承诺

      * 培训，比方技能提升搭变更管理

      * 运营，比方支持搭维护

      * 计量，比方带宽搭 CPU 使用量

  * SWOT 分析

    * 摘要

    * 优势

    * 劣势

    * 机会

    * 威胁

  * 内部意见搭反馈

    * 摘要

    * 例子

      * 团队个意见，最好由本人亲自写

      * 其他利益相关者个意见

      * 质量属性，又叫跨职能需求

  * 外部意见搭反馈

    * 摘要

    * 啥人提供迭个意见？

    * 侬考虑过个其他候选方案有啥？

    * 侬辣创建啥？

      * 例子

        * B2B 还是 B2C

        * 对外还是只给员工用

        * 桌面还是移动

        * 试点还是生产

        * 单体还是微服务

    * 侬是哪能评估候选方案个？

    * 为啥选了胜出个迭个？

    * 从那以后发生了啥？

      * 例子

        * 胜出个方案表现哪能？

        * 真实生产环境用户流量里向有百分之几流经胜出个方案？

        * 牵涉到啥种集成，比方搭持续交付流水线、内容管理系统、分析搭指标等等？

        * 现在晓得了迭眼，侬会建议大家有啥勿同个做法？

  * 轶事

**推荐**：

  * 摘要

  * 具体内容
