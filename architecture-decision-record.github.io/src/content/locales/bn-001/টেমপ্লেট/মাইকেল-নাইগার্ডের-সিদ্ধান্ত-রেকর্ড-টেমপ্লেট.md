# মাইকেল নাইগার্ডের সিদ্ধান্ত রেকর্ড টেমপ্লেট

এটি [Documenting architecture decisions - Michael Nygard](http://thinkrelevance.com/blog/2011/11/15/documenting-architecture-decisions)-এর টেমপ্লেট।
ADR ফাইল পরিচালনার জন্য আপনি [adr-tools](https://github.com/npryce/adr-tools) ব্যবহার করতে পারেন।

প্রতিটি ADR ফাইলে এই অংশগুলো লিখুন:

# শিরোনাম

## অবস্থা

অবস্থা কী, যেমন proposed, accepted, rejected, deprecated, superseded ইত্যাদি?

## প্রেক্ষাপট

আমরা কোন সমস্যাটি দেখছি, যা এই সিদ্ধান্ত বা পরিবর্তনের প্রেরণা দিচ্ছে?

## সিদ্ধান্ত

আমরা কোন পরিবর্তনের প্রস্তাব করছি এবং/অথবা করছি?

## পরিণতি

এই পরিবর্তনের ফলে কী করা সহজ বা কঠিন হয়ে যায়?
