# Catatan Keputusan Arsitektur: Tailwind CSS

Keputusan: Menggunakan Tailwind CSS sebagai kerangka CSS untuk menata gaya antarmuka pengguna.

## Apa itu Tailwind CSS?

Tailwind adalah kerangka CSS yang mengutamakan utilitas (utility-first) yang memungkinkan pengembangan dan kustomisasi antarmuka pengguna dengan cepat. Kerangka ini dirancang agar sangat dapat dikustomisasi dan memungkinkan pengembang menulis CSS yang lebih ramping dan efisien. Kerangka ini menyediakan sekumpulan kelas yang sudah ditentukan sebelumnya untuk menata gaya UI dengan sangat cepat.

## Konteks

Kami sedang membangun aplikasi web untuk klien yang memerlukan antarmuka pengguna yang responsif dan dapat dikustomisasi. Klien meminta gaya yang konsisten dan modern. Tim pengembangan berpengalaman menggunakan CSS kustom tetapi ingin menjajaki kerangka CSS yang dapat menghemat waktu dan tenaga. Kami mencari kerangka yang mudah digunakan, dapat dikustomisasi, dan memiliki komunitas besar untuk dukungan.

## Opsi yang Dipertimbangkan

- **Bootstrap:**  Kerangka CSS populer dengan banyak komponen siap pakai dan komunitas pengembang yang besar.

- **Foundation:**  Kerangka CSS populer lainnya yang dirancang untuk pengembangan mobile-first.

- **Materialize:**  Kerangka CSS berdasarkan bahasa Material Design milik Google dengan komponen siap pakai untuk pengembangan UI.

- **Tailwind CSS:**  Kerangka CSS yang mengutamakan utilitas dengan fokus pada kustomisasi dan efisiensi.
