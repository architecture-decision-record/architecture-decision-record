# Python Django ఫ్రేమ్వర్క్ కోసం ఆర్కిటెక్చర్ నిర్ణయ రికార్డు

నిర్ణయ తేదీ: 2021-07-15

స్థితి: అంగీకరించబడింది

## సందర్భం

కస్టమర్ డేటాను నిర్వహించే ఒక వెబ్ అప్లికేషన్ను అభివృద్ధి చేయాలని మా సంస్థ ప్రణాళిక వేస్తోంది. మేము ప్రోగ్రామింగ్ భాషగా Pythonను ఎంచుకున్నాం, అప్లికేషన్ అభివృద్ధికి వెబ్ ఫ్రేమ్వర్క్గా Djangoను పరిశీలిస్తున్నాం.

## నిర్ణయం

వెబ్ అప్లికేషన్ అభివృద్ధికి Django వెబ్ ఫ్రేమ్వర్క్ను వాడాలని మేము నిర్ణయించాం. వెబ్ అప్లికేషన్లను త్వరగా, సమర్థవంతంగా నిర్మించడానికి Django బలమైన సాధనాలు, ఫీచర్ల సమితిని అందిస్తుంది. 

## అంశాలు

మా నిర్ణయాన్ని ప్రభావితం చేసిన కొన్ని అంశాలు:

1. ఆబ్జెక్ట్-రిలేషనల్ మ్యాపింగ్ (ORM): Djangoకు అంతర్నిర్మిత ORM ఉంది, ఇది SQL క్వెరీలు రాయకుండా డేటాబేస్తో పరస్పర చర్య చేయడానికి మాకు వీలు కల్పిస్తుంది. ఇది అప్లికేషన్ను అభివృద్ధి చేయడం, దీర్ఘకాలంలో నిర్వహించడం సులభతరం చేస్తుంది.

2. MVC ఫ్రేమ్వర్క్: Django మోడల్-వ్యూ-కంట్రోలర్ (MVC) ఆర్కిటెక్చర్ను అనుసరిస్తుంది, అప్లికేషన్ వ్యాపార తర్కం, ప్రెజెంటేషన్ పొరలను వేరు చేయడం సులభం చేస్తుంది.

3. విస్తరణ సామర్థ్యం: Django దాని విస్తరణ సామర్థ్యాలకు ప్రసిద్ధి, పెద్ద స్థాయి అప్లికేషన్లను అభివృద్ధి చేయడానికి దీన్ని అద్భుతమైన ఎంపికగా చేస్తుంది.

4. భద్రత: Djangoకు క్రాస్-సైట్ స్క్రిప్టింగ్ (XSS), SQL ఇంజెక్షన్ వంటి సాధారణ వెబ్ దాడుల నుండి రక్షణ వంటి అంతర్నిర్మిత భద్రతా ఫీచర్లు ఉన్నాయి.

5. సముదాయ మద్దతు: Djangoకు మద్దతునిచ్చే, ఫ్రేమ్వర్క్ అభివృద్ధికి తోడ్పడే పెద్ద, చురుకైన సముదాయం ఉంది.

## పరిశీలించిన ప్రత్యామ్నాయాలు

మేము Flask, Pyramid వంటి ఇతర వెబ్ ఫ్రేమ్వర్క్లను పరిశీలించాం. అయితే, Django మరింత పరిపక్వమైన, బాగా స్థిరపడిన, బలమైన ఫీచర్ల సమితి గల ఫ్రేమ్వర్క్ అని మేము కనుగొన్నాం.

వెబ్ ఫ్రేమ్వర్క్ లేకుండా, SQLAlchemy, Flask-RESTful వంటి లైబ్రరీలను వాడుతూ అప్లికేషన్ను అభివృద్ధి చేయడం గురించి కూడా చర్చించాం. అయితే, Django విస్తృత ఫంక్షనాలిటీని అందిస్తుందని, పూర్తి వెబ్ అప్లికేషన్కు ఇది మెరుగైన ఎంపిక అని మేము కనుగొన్నాం.

## పర్యవసానాలు

Django స్వీకరణ ఈ క్రింది పర్యవసానాలకు దారి తీస్తుంది:

1. Django అంతర్నిర్మిత సాధనాలు, ఫీచర్ల కారణంగా అప్లికేషన్ను అభివృద్ధి చేయడం, నిర్వహించడం సులభం.

2. వ్యాపార తర్కం, ప్రెజెంటేషన్ పొర వేరు కావడం, ఇది మరింత క్రమబద్ధమైన, నిర్వహించడానికి సులభమైన కోడ్కు దారి తీస్తుంది.

3. అప్లికేషన్ విస్తరణ సామర్థ్యం, దృఢత్వం.

4. సాధారణ వెబ్ దాడుల నుండి అప్లికేషన్ను రక్షించడంలో సహాయపడే అంతర్నిర్మిత భద్రతా ఫీచర్లు.

5. మద్దతు కోసం పెద్ద, చురుకైన సముదాయానికి ప్రాప్యత.

Djangoకు ఇతర ఫ్రేమ్వర్క్ల కంటే నిటారైన నేర్చుకునే వక్రరేఖ ఉందని మేము అర్థం చేసుకున్నాం, కానీ అది అందించే దీర్ఘకాలిక ప్రయోజనాలకు ఆ పెట్టుబడి విలువైనదని మేము భావిస్తున్నాం.

## ముగింపు

పరిగణించిన అంశాల ఆధారంగా, వెబ్ అప్లికేషన్ అభివృద్ధికి Django వెబ్ ఫ్రేమ్వర్క్ను వాడాలని మేము నిర్ణయించాం. Django ఫీచర్లు, సముదాయ మద్దతు, విస్తరణ సామర్థ్యాలు పూర్తి వెబ్ అప్లికేషన్ను నిర్మించడానికి దీన్ని ఉత్తమ ఎంపికగా చేస్తాయని మేము నమ్ముతున్నాం. ఫ్రేమ్వర్క్ను సమర్థవంతంగా, ప్రభావవంతంగా వాడేలా చూసుకోవడానికి మా డెవలపర్లకు Django వాడకంలో శిక్షణ ఇస్తాం.
