# Registro de decisão de arquitetura para a Amazon Web Services

Título: adoção da Amazon Web Services para a infraestrutura de nuvem

## Decisão

Após uma avaliação minuciosa de várias plataformas de infraestrutura de nuvem, decidiu-se que a Amazon Web Services (AWS) será adotada pela nossa organização para as nossas necessidades de infraestrutura de nuvem.

## Contexto

Nossa organização está crescendo rapidamente e precisamos de uma infraestrutura de nuvem confiável e escalável para atender às demandas do nosso negócio. Após considerar vários provedores de infraestrutura de nuvem, concluiu-se que a AWS oferece a gama de serviços mais adequada para atender aos nossos requisitos atuais e futuros.

## Considerações

Há inúmeros provedores de infraestrutura de nuvem no mercado que se mostraram confiáveis e eficientes. No entanto, a AWS não só oferece um conjunto abrangente de serviços para atender às nossas necessidades, como também tem uma extensa base de clientes e um histórico de implantações bem-sucedidas. A AWS também fornece uma ampla gama de recursos de suporte e treinamento para garantir que nossa equipe possa trabalhar com eficácia na plataforma.

Além disso, a AWS tem uma extensa presença global, com data centers localizados em várias regiões do mundo. Isso garante que nossos dados estejam seguros e que nossas aplicações e serviços tenham alta disponibilidade. A AWS também tem uma estrutura de segurança robusta, que é fundamental para o nosso negócio.

Por fim, a AWS oferece um modelo de pagamento conforme o uso (pay-as-you-go), que nos dá a flexibilidade de escalar nossa infraestrutura de acordo com a demanda. Isso significa que seremos cobrados apenas pelo que usarmos, o que nos permite otimizar custos e investir em outras áreas do negócio.

## Decisão

Com base nas avaliações realizadas e nas vantagens oferecidas pela AWS, decidiu-se que a AWS será adotada para as nossas necessidades de infraestrutura de nuvem.

## Consequências

A adoção da AWS pode exigir treinamento para as nossas equipes, a fim de garantir que elas conheçam a plataforma e possam utilizá-la de modo eficaz. Também pode haver alguns custos iniciais para migrar a nossa infraestrutura atual para a plataforma AWS.

## Responsabilidade

A responsabilidade por garantir a utilização eficaz da AWS e a gestão dos riscos associados caberá à equipe de infraestrutura de nuvem. Quaisquer problemas que surgirem devem ser tratados por essa equipe.

## Revisão

A decisão de adotar a AWS será revisada anualmente para garantir que continue atendendo às nossas necessidades e que os benefícios da plataforma estejam sendo plenamente aproveitados.
