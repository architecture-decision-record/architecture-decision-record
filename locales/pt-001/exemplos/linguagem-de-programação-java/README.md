# Registro de decisão de arquitetura: linguagem de programação Java

Título: escolhendo a linguagem de programação Java para o projeto

Decisão: após avaliar várias linguagens de programação, decidimos usar Java no nosso projeto.

### Contexto

Pretendíamos construir uma aplicação web que pudesse rodar em vários sistemas operacionais. Nosso projeto exigia uma linguagem que oferecesse recursos de segurança fortes, lidasse com concorrência, suportasse grandes bases de código e fosse versátil o bastante para atender aos nossos requisitos de crescimento futuro. Avaliamos várias linguagens, considerando seus pontos fortes e limitações, antes de optar pelo Java.

### Considerações

1. **Segurança:**  o Java oferece excelentes recursos de segurança por meio de políticas de segurança bem definidas e controle de acesso. Também incorpora recursos como a verificação de bytecode, que ajuda a impedir que software malicioso seja executado em um sistema.

2. **Concorrência:**  o Java tem suporte integrado a multithreading, o que permite que as aplicações executem várias tarefas simultaneamente. Esse recurso torna o Java uma excelente escolha para desenvolver aplicações grandes e complexas, com vários recursos e funcionalidades.

3. **Grandes bases de código:**  o Java oferece suporte à programação orientada a objetos, o que o torna uma escolha adequada para desenvolver grandes bases de código. Sua natureza modular e o uso de padrões de encapsulamento e abstração facilitam ainda mais o processo de desenvolvimento de software.

4. **Versatilidade:**  o Java é versátil e permite o uso de uma ampla gama de bibliotecas e frameworks, o que o torna uma excelente escolha tanto para aplicações web quanto para aplicações de nível corporativo.

### Resultado da decisão

Decidimos usar a linguagem de programação Java no nosso projeto, considerando seus recursos de segurança, o suporte à concorrência, a capacidade de lidar com grandes bases de código e a versatilidade. Essa decisão se alinha aos requisitos do nosso projeto, e acreditamos que escolher o Java garantirá o seu sucesso. 

### Consequências

1. Precisaremos de desenvolvedores com experiência em Java que possam usá-lo com proficiência.

2. Qualquer código escrito na linguagem deve ser compatível com a Máquina Virtual Java (JVM).

3. Incorporar novos recursos, funcionalidades ou frameworks pode apresentar alguns desafios.

4. Projetos grandes e complexos em Java podem exigir mais tempo e recursos para serem desenvolvidos.
