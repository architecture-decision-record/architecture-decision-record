# Modelo de registro de decisão de Michael Nygard

Este é o modelo de [Documenting architecture decisions - Michael Nygard](http://thinkrelevance.com/blog/2011/11/15/documenting-architecture-decisions).
Você pode usar o [adr-tools](https://github.com/npryce/adr-tools) para gerenciar os arquivos de ADR.

Em cada arquivo de ADR, escreva estas seções:

# Título

## Estado

Qual é o estado, como proposed, accepted, rejected, deprecated, superseded etc.?

## Contexto

Qual é a questão que estamos vendo que motiva esta decisão ou mudança?

## Decisão

Qual é a mudança que estamos propondo e/ou fazendo?

## Consequências

O que se torna mais fácil ou mais difícil de fazer por causa desta mudança?
