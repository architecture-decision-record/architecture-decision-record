# Amazon Web Services のアーキテクチャ決定記録

タイトル: クラウドインフラストラクチャとしての Amazon Web Services の採用

## 決定

さまざまなクラウドインフラストラクチャプラットフォームを徹底的に評価した結果、当組織のクラウドインフラストラクチャのニーズに Amazon Web Services(AWS)を採用することが決定されました。

## 背景

当組織は急速に成長しており、ビジネスの需要を満たすために、信頼性が高くスケーラブルなクラウドインフラストラクチャが必要です。多数のクラウドインフラストラクチャプロバイダーを検討した結果、AWS が現在および将来の要件を満たす最も適したサービス群を提供していると結論付けられました。

## 検討事項

市場には、信頼性と効率性が実証されたクラウドインフラストラクチャプロバイダーが数多く存在します。しかし、AWS は私たちのニーズに応える包括的なサービス群を提供するだけでなく、幅広い顧客基盤と成功したデプロイメントの実績も持っています。AWS はまた、チームがプラットフォームで効果的に作業できるよう、幅広いサポートとトレーニングのリソースを提供しています。

さらに、AWS は世界のさまざまな地域にデータセンターを持つ広範なグローバルプレゼンスを有しています。これにより、データの安全性が確保され、アプリケーションとサービスの可用性が高まります。AWS には、当社のビジネスにとって極めて重要な堅牢なセキュリティフレームワークもあります。

最後に、AWS は従量課金モデルを提供しており、需要に基づいてインフラストラクチャを柔軟にスケールできます。つまり、使用した分だけが課金されるため、コストを最適化し、事業の他の分野に投資できます。

## 決定

実施した評価と AWS が提供する利点に基づき、クラウドインフラストラクチャのニーズに AWS を採用することが決定されました。

## 結果

AWS の採用には、チームがプラットフォームに習熟し、効果的に活用できるようにするためのトレーニングが必要になる場合があります。また、現在のインフラストラクチャを AWS プラットフォームに移行するための初期費用が発生する可能性もあります。

## 所有権

AWS の効果的な活用と関連リスクの管理を確保する責任は、クラウドインフラストラクチャチームの権限の範囲内にあります。発生した問題は、このチームが対処しなければなりません。

## レビュー

AWS を採用するという決定は、引き続きニーズを満たしていること、およびプラットフォームの利点が十分に実現されていることを確認するため、毎年レビューされます。
