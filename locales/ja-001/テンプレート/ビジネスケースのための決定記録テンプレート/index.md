# ビジネスケースのための決定記録テンプレート

この ADR テンプレートは、基準、候補、コストを含め、決定のためのビジネスケースを作成することを重視しています。


## トップレベル

* タイトル
* 状態
* 評価基準
* 検討する候補
* 各候補の調査と分析
  * 基準を満たす/満たさない、およびその理由
  * コスト分析
  * SWOT 分析
  * 意見とフィードバック
* 推奨事項


## 低レベルの詳細

**タイトル**:

  * git のコミットメッセージのような、50 文字未満の、短い現在形の命令形のフレーズ。

**状態**:

  * proposed、accepted、rejected、deprecated、superseded などのいずれか。

**評価基準**:

  * 要約: 何を、なぜ発見しようとしているのかを簡潔に説明します。

  * 詳細

**検討する候補**:

  * 要約: 候補をどのように発見したかを簡潔に説明し、外れ値に注意を促します。

  * すべての候補と関連する選択肢を列挙します。潜在的な解決策として何を評価しているのか。

  * 詳細

**各候補の調査と分析**:

  * 要約: 調査方法を簡潔に説明し、パターン、クラスター、外れ値に注意を促します。

  * 基準を満たす/満たさない、およびその理由

    * 要約

    * 詳細

  * コスト分析

    * 要約

    * 例

      * ライセンス。たとえば契約上の合意や法的コミットメント

      * トレーニング。たとえばスキルアップや変更管理

      * 運用。たとえばサポートや保守

      * 従量課金。たとえば帯域幅や CPU 使用量

  * SWOT 分析

    * 要約

    * 強み(Strengths)

    * 弱み(Weaknesses)

    * 機会(Opportunities)

    * 脅威(Threats)

  * 社内の意見とフィードバック

    * 要約

    * 例

      * チームによるもの。理想的には実際の本人が書いたもの

      * その他のステークホルダーから

      * 品質属性、別名クロスファンクショナル要件 

  * 社外の意見とフィードバック

    * 要約

    * 意見を提供しているのは誰ですか?

    * 検討した他の候補は何ですか?

    * 何を作成していますか? 

      * 例

        * B2B または B2C

        * 外部向けまたは従業員専用

        * デスクトップまたはモバイル

        * パイロットまたは本番

        * モノリスまたはマイクロサービス

    * 候補をどのように評価しましたか?

    * なぜ勝者を選びましたか?

    * その後、何が起きていますか?

      * 例

        * 勝者のパフォーマンスはどうですか?

        * 実世界の本番ユーザートラフィックの何 % が勝者を通過していますか?

        * 継続的デリバリーパイプライン、コンテンツ管理システム、分析とメトリクスなど、どのような種類の統合が関わっていますか?

        * 今知っていることを踏まえて、人々に何を違うようにするよう助言しますか?

  * 逸話

**推奨事項**:

  * 要約

  * 詳細
