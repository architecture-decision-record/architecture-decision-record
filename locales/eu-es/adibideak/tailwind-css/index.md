# Arkitektura-erabakien erregistroa: Tailwind CSS

Erabakia: Erabili Tailwind CSS erabiltzaile-interfaze bat estilatzeko CSS marko gisa.

## Zer da Tailwind CSS?

Tailwind utility-first CSS markoa da, erabiltzaile-interfazeen garapen eta pertsonalizazio azkarra ahalbidetzen duena. Oso pertsonalizagarria izateko diseinatuta dago eta garatzaileei CSS arinagoa eta eraginkorragoa idazten uzten die. Marko honek aldez aurretik definitutako klase multzo bat eskaintzen du UI-a oso azkar estilatzeko.

## Testuingurua

Bezero baterako web aplikazio bat eraikitzen ari gara, erabiltzaile-interfaze erantzunkor eta pertsonalizagarria behar duena. Bezeroak estilo koherente eta modernoa eskatu du. Garapen-taldeak CSS pertsonalizatua erabiltzeko esperientzia du baina denbora eta ahalegina aurreztu ditzaketen CSS markoak arakatu nahi ditu. Erabiltzeko erraza, pertsonalizagarria eta laguntza emateko komunitate handia duen marko bat bilatzen ari gara.

## Erabakiaren bultzatzaileak

- **Erabiltzeko erraza:**  Ikasteko sinplea eta gure garapen-lan-fluxuan integra daitekeen marko bat nahi dugu.

- **Pertsonalizagarria:**  Bezeroaren marka-jarraibideei eta gaiari egokitzeko pertsonaliza daitekeen marko bat nahi dugu.

- **Komunitate handiaren laguntza:**  Behar denean laguntza eta baliabideak eman ditzaketen garatzaile eta diseinatzaileen komunitate aktiboa duen marko bat nahi dugu.

- **Denbora aurrezten duena:**  UI-a estilatzeko denbora eta ahalegina aurrez dezakeen marko bat nahi dugu.

## Aztertutako aukerak

- **Bootstrap:**  Aldez aurretik eraikitako osagai asko eta garatzaileen komunitate handia dituen CSS marko ezaguna.

- **Foundation:**  Mugikorra-lehenengo garapenerako diseinatutako beste CSS marko ezagun bat.

- **Materialize:**  Google-ren Material Design lengoaian oinarritutako CSS markoa, UI garapenerako aldez aurretik eraikitako osagaiekin.

- **Tailwind CSS:**  Pertsonalizazioan eta eraginkortasunean zentratutako utility-first CSS markoa.

## Erabakiaren emaitza

Aukerak aztertu ondoren, Tailwind CSS erabiltzea erabaki dugu arrazoi hauengatik:

- **Erabiltzeko erraza:**  Tailwind-en ikuspegia sinplea eta ulertzeko erraza da. Bere utility klaseek UI bat eraikitzea azkarragoa egiten dute.

- **Pertsonalizagarria:**  Tailwind-ek pertsonalizazioa ahalbidetzen du, garatzaileek markoaren estilo lehenetsiak erraz aldatzeko aukera ematen duten konfigurazio-fitxategi multzo bat eskainiz.

- **Komunitate handiaren laguntza:**  Tailwind-ek garatzaile eta diseinatzaileen komunitate oso aktiboa du, etengabe baliabide, plugin eta tresna berriak sortzen dituena.

- **Denbora aurrezten duena:**  Tailwind-ek denbora aurrez dezake, garatzaileei proiektuaren beste arlo batzuetan zentratzeko aukera emanez.

Tailwind CSS-en utility klaseak erabiliko ditugu gure proiekturako UI-a eraikitzeko. Garapen-taldeak bere diseinu-sistema atomiko eta modularra erabiliko du CSS kode eraginkor eta eskalagarria idazteko. Tailwind-en aldez aurretik eraikitako txantiloi eta osagai bisualak aprobetxatuko ditugu garapen-prozesua azkartzeko, estilo pertsonalizatuak erabiliz bezeroaren marka eta gaiari egokitzeko.
