# Amazon Web Services-erako arkitektura-erabakien erregistroa

Izenburua: Amazon Web Services hartzea hodei-azpiegiturarako

## Erabakia

Hodei-azpiegitura-plataforma desberdinen ebaluazio sakona egin ondoren, erabaki da gure erakundeak Amazon Web Services (AWS) hartuko duela bere hodei-azpiegituraren beharretarako.

## Atzeko planoa

Gure erakundea azkar hazten ari da eta hodei-azpiegitura fidagarri eta eskalagarria behar dugu gure negozioaren eskakizunak betetzeko. Hodei-azpiegiturako hornitzaile batzuk aztertu ondoren, ondorioztatu zen AWS-k gure oraingo eta etorkizuneko eskakizunak betetzeko zerbitzu-sorta egokiena eskaintzen duela.

## Kontuan hartzekoak

Merkatuan hodei-azpiegiturako hornitzaile asko daude fidagarri eta eraginkor frogatu direnak. Hala ere, AWS-k gure beharrei erantzuteko zerbitzu-multzo osoa eskaintzeaz gain, bezero-oinarri zabala eta ezarpen arrakastatsuen aurrekaria ere badu. AWS-k laguntza- eta prestakuntza-baliabide sorta zabala ere eskaintzen du, gure taldeak plataformarekin eraginkortasunez lan egin dezan.

Gainera, AWS-k munduko eskualde desberdinetan kokatutako datu-zentroekin presentzia global zabala du. Horrek gure datuak seguruak direla eta gure aplikazio eta zerbitzuak oso eskuragarri egongo direla bermatzen du. AWS-k, gainera, gure negozioarentzat kritikoa den segurtasun-esparru sendoa du.

Azkenik, AWS-k erabilitakoaren arabera ordaintzeko eredua eskaintzen du, eskariaren arabera gure azpiegitura eskalatzeko malgutasuna ematen duena. Horrek esan nahi du erabiltzen duguna bakarrik kobratuko zaigula, eta horrek gure kostuak optimizatzeko eta negozioaren beste arlo batzuetan inbertitzeko aukera ematen digu.

## Erabakia

Egindako ebaluazioetan eta AWS-k eskaintzen dituen abantailetan oinarrituta, erabaki da AWS hartuko dela gure hodei-azpiegituraren beharretarako.

## Ondorioak

AWS hartzeak gure taldeak prestatzea eskatu dezake plataformarekin ohitzeko eta eraginkortasunez erabiltzeko. Baliteke hasierako kostu batzuk egotea gure oraingo azpiegitura AWS plataformara eramateko.

## Jabetza

AWS-ren erabilera eraginkorra eta lotutako arriskuen kudeaketa bermatzeko ardura hodei-azpiegiturako taldearen eskumenekoa izango da. Sortzen den edozein arazo talde horrek jorratu behar du.

## Berrikuspena

AWS hartzeko erabakia urtero berrikusiko da, gure beharrak betetzen jarraitzen duela eta plataformaren onurak erabat gauzatzen ari direla ziurtatzeko.
