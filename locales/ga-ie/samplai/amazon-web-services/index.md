# Taifead Cinnidh Ailtireachta do Amazon Web Services

Teideal: Amazon Web Services a Ghlacadh le haghaidh Bonneagar Scamall

## Cinneadh

Tar éis meastóireacht chúramach ar ardáin bhonneagair scamall éagsúla, socraíodh go nglacfaidh ár n-eagraíocht Amazon Web Services (AWS) le haghaidh ár riachtanais bhonneagair scamall.

## Cúlra

Tá ár n-eagraíocht ag fás go tapa agus teastaíonn bonneagar scamall iontaofa agus inscálaithe uainn chun éilimh ár ngnó a shásamh. Tar éis breithniú a dhéanamh ar roinnt soláthraithe bonneagair scamall, tháinig muid ar an gconclúid go dtugann AWS an raon seirbhísí is oiriúnaí chun ár riachtanais reatha agus amach anseo a shásamh.

## Breithnithe

Tá go leor soláthraithe bonneagair scamall sa mhargadh a bhfuil iontaofacht agus éifeachtúlacht léirithe acu. Mar sin féin, ní hamháin go dtugann AWS tacar cuimsitheach seirbhísí chun freastal ar ár riachtanais, ach tá bonn leathan custaiméirí aige agus taifead de chur chun feidhme rathúil. Soláthraíonn AWS raon leathan acmhainní tacaíochta agus oiliúna freisin chun a chinntiú gur féidir lenár bhfoireann oibriú go héifeachtach leis an ardán.

Ina theannta sin, tá láithreacht dhomhanda fhairsing ag AWS le hionaid sonraí i réigiúin éagsúla ar fud an domhain. Cinntíonn sé seo go bhfuil ár sonraí slán agus go mbeidh ár bhfeidhmchláir agus seirbhísí an-infhaighte. Tá creat slándála láidir ag AWS freisin atá ríthábhachtach dár ngnó.

Ar deireadh, soláthraíonn AWS múnla íoc-mar-a-úsáideann-tú a thugann solúbthacht dúinn bonneagar a scálú de réir éilimh. Ciallaíonn sé seo nach ngearrfar muid ach as an méid a úsáidimid, rud a ligeann dúinn ár gcostais a bharrfheabhsú agus infheistiú i réimsí eile den ghnó.

## Cinneadh

Bunaithe ar na meastóireachtaí a rinneadh agus na buntáistí a thairgeann AWS, socraíodh go nglacfar AWS le haghaidh ár riachtanais bhonneagair scamall.

## Iarmhairtí

D'fhéadfadh go mbeadh oiliúint ag teastáil dár bhfoirne chun a chinntiú go bhfuil siad eolach ar an ardán agus gur féidir leo é a úsáid go héifeachtach. D'fhéadfadh roinnt costas tosaigh a bheith ann freisin chun ár mbonneagar reatha a aistriú go dtí an t-ardán AWS.

## Úinéireacht

Beidh an fhreagracht as úsáid éifeachtach AWS a chinntiú agus as bainistiú na rioscaí gaolmhara faoi chúram na foirne bonneagair scamall. Caithfidh an fhoireann seo aghaidh a thabhairt ar aon saincheisteanna a thagann chun cinn.

## Athbhreithniú

Athbhreithneofar an cinneadh AWS a ghlacadh go bliantúil chun a chinntiú go gcomhlíonann sé ár riachtanais i gcónaí agus go bhfuil buntáistí an ardáin á réadú go hiomlán.
