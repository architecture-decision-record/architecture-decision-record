# Taifead Cinnidh Ailtireachta: API ag úsáid JSON nó gRPC

## Stádas

Glactha

## Comhthéacs

Táimid ag dearadh API do sheirbhís nua a úsáidfidh custaiméirí iomadúla. Tá dhá rogha á mbreithniú againn chun an API a chur i bhfeidhm: JSON thar HTTP a úsáid nó gRPC a úsáid.

Cur chuige a úsáidtear go forleathan chun APInna a thógáil is ea JSON thar HTTP, agus tacaíonn go leor teangacha ríomhchlárúcháin agus creataí leis. Tá an cur chuige seo simplí, éadrom, agus furasta a thuiscint, rud a fhágann gur rogha mhaith é do go leor tionscadal. Mar sin féin, féadann sé a bheith níos lú éifeachtúil ná roghanna eile, go háirithe maidir le méideanna móra sonraí a láimhseáil.

Teicneolaíocht níos nuaí is ea gRPC, áfach, a thairgeann bealach níos éifeachtúla chun APInna a thógáil. Úsáideann sé sraitheoireacht dhénártha chun sonraí a aistriú, rud a fhéadann a bheith níos tapúla agus níos dlúithe ná JSON a úsáid. Tacaíonn gRPC le sruthú déthreorach freisin, rud a fhágann gur rogha mhaith é d'fheidhmchláir fíor-ama.

## Cinneadh

Tar éis buntáistí agus míbhuntáistí an dá rogha a bhreithniú, tá cinneadh déanta againn gRPC a úsáid dár API. Cé gur rogha níos simplí é JSON thar HTTP, creidimid go dtabharfaidh gRPC réiteach níos éifeachtúla agus níos inscálaithe dár seirbhís. Táimid ag súil freisin go láimhseálfaidh ár API méid mór sonraí, agus beidh sraitheoireacht dhénártha gRPC níos éifeachtúla don chás úsáide seo.

Ina theannta sin, creidimid go mbeidh tacaíocht gRPC do shruthú déthreorach ina buntáiste d'fheidhmchláir fíor-ama a fhéadfaimid a fhorbairt amach anseo.

## Iarmhairtí

Trí gRPC a roghnú, beidh orainn tacar éagsúil uirlisí agus leabharlanna a úsáid chun ár API a thógáil i gcomparáid le JSON thar HTTP a úsáid. D'fhéadfadh go mbeadh am agus iarracht bhreise ag teastáil chun na teicneolaíochtaí seo a fhoghlaim agus a chur i bhfeidhm. Ina theannta sin, beidh ar chustaiméirí ar mian leo ár API a úsáid leabharlanna atá comhoiriúnach le gRPC a úsáid, nach mbeadh tacaíocht chomh forleathan acu le leabharlanna JSON thar HTTP.

Mar sin féin, creidimid go bhfuil buntáistí gRPC a úsáid níos mó ná na míbhuntáistí féideartha seo, agus táimid muiníneach go mbeidh API níos éifeachtúla agus níos inscálaithe mar thoradh ar an gcinneadh seo.
