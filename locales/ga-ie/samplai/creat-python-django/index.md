# Taifead Cinnidh Ailtireachta do Chreat Python Django

Dáta an Chinnidh: 2021-07-15

Stádas: Glactha

## Comhthéacs

Tá ár n-eagraíocht ag pleanáil feidhmchlár gréasáin a fhorbairt a bhainistíonn sonraí custaiméirí. Roghnaigh muid Python mar an teanga ríomhchlárúcháin agus táimid ag smaoineamh ar Django mar chreat gréasáin d'fhorbairt an fheidhmchláir.

## Cinneadh

Tá cinneadh déanta againn creat gréasáin Django a úsáid d'fhorbairt an fheidhmchláir ghréasáin. Soláthraíonn Django tacar láidir uirlisí agus gnéithe chun feidhmchláir ghréasáin a thógáil go tapa agus go héifeachtúil. 

## Fachtóirí

Áirítear ar chuid de na fachtóirí a chuaigh i bhfeidhm ar ár gcinneadh:

1. Mapáil Réad-Choibhneasta (ORM): Tá ORM ionsuite ag Django a cheadaíonn dúinn idirghníomhú leis an mbunachar sonraí gan ceisteanna SQL a scríobh. Fágann sé seo go bhfuil sé níos éasca an feidhmchlár a fhorbairt agus a chothabháil san fhadtéarma.

2. Creat MVC: Leanann Django ailtireacht Model-View-Controller (MVC), rud a fhágann go bhfuil sé níos éasca loighic ghnó agus sraitheanna cur i láthair an fheidhmchláir a scaradh.

3. Inscálaitheacht: Tá cáil ar Django as a chumais inscálaitheachta, rud a fhágann gur rogha den scoth é chun feidhmchláir mhórscála a fhorbairt.

4. Slándáil: Tá gnéithe slándála ionsuite ag Django, amhail cosaint i gcoinne ionsaithe coitianta gréasáin ar nós scriptiú tras-suímh (XSS) agus instealladh SQL.

5. Tacaíocht Phobail: Tá pobal mór gníomhach ag Django a sholáthraíonn tacaíocht agus a chuireann le forbairt an chreata.

## Roghanna Eile a Breithníodh

Bhreithnigh muid creataí gréasáin eile amhail Flask agus Pyramid. Mar sin féin, fuair muid amach gur creat níos aibí agus níos bunaithe é Django le tacar láidir gnéithe.

Phléigh muid freisin feidhmchlár a fhorbairt gan creat gréasáin agus leabharlanna cosúil le SQLAlchemy agus Flask-RESTful a úsáid. Mar sin féin, fuair muid amach go dtairgeann Django feidhmiúlacht níos leithne, rud a fhágann gur rogha níos fearr é d'fheidhmchlár gréasáin iomlán.

## Iarmhairtí

Beidh na hiarmhairtí seo a leanas mar thoradh ar Django a ghlacadh:

1. Níos éasca an feidhmchlár a fhorbairt agus a chothabháil mar gheall ar uirlisí agus gnéithe ionsuite Django.

2. Scaradh loighic ghnó agus srath cur i láthair, rud a fhágann cód níos eagraithe agus níos éasca a chothabháil.

3. Inscálaitheacht agus láidreacht an fheidhmchláir.

4. Gnéithe slándála ionsuite a chabhraíonn leis an bhfeidhmchlár a chosaint i gcoinne ionsaithe coitianta gréasáin.

5. Rochtain ar phobal mór gníomhach le haghaidh tacaíochta.

Tuigeann muid go bhfuil cuar foghlama níos géire ag Django ná creataí eile, ach is dóigh linn go bhfuil an infheistíocht fiúntach mar gheall ar na buntáistí fadtéarmacha a sholáthraíonn sé.

## Conclúid

Bunaithe ar na fachtóirí a breithníodh, tá cinneadh déanta againn creat gréasáin Django a úsáid d'fhorbairt an fheidhmchláir ghréasáin. Creidimid gurb iad gnéithe Django, tacaíocht an phobail, agus cumais inscálaitheachta an rogha is fearr chun feidhmchlár gréasáin iomlán a thógáil. Cuirfimid oiliúint ar ár bhforbróirí chun Django a úsáid chun a chinntiú go n-úsáidtear an creat go héifeachtach agus go héifeachtúil.
