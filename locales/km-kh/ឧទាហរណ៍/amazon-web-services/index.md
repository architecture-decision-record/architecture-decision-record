# កំណត់ត្រាការសម្រេចចិត្តខាងស្ថាបត្យកម្មសម្រាប់ Amazon Web Services

ចំណងជើង៖ ការទទួលយក Amazon Web Services សម្រាប់ហេដ្ឋារចនាសម្ព័ន្ធពពក

## ការសម្រេចចិត្ត

បន្ទាប់ពីការវាយតម្លៃដ៏ហ្មត់ចត់នៃវេទិកាហេដ្ឋារចនាសម្ព័ន្ធពពកផ្សេងៗ គេបានសម្រេចថា Amazon Web Services (AWS) នឹងត្រូវបានអង្គការរបស់យើងទទួលយកសម្រាប់តម្រូវការហេដ្ឋារចនាសម្ព័ន្ធពពករបស់យើង។

## ប្រវត្តិ

អង្គការរបស់យើងកំពុងលូតលាស់យ៉ាងលឿន ហើយយើងត្រូវការហេដ្ឋារចនាសម្ព័ន្ធពពកដែលអាចទុកចិត្តបាន និងអាចពង្រីកបាន ដើម្បីបំពេញតម្រូវការអាជីវកម្មរបស់យើង។ បន្ទាប់ពីពិចារណាអ្នកផ្តល់ហេដ្ឋារចនាសម្ព័ន្ធពពកជាច្រើន គេបានសន្និដ្ឋានថា AWS ផ្តល់សេវាកម្មចម្រុះដែលសមស្របបំផុតដើម្បីបំពេញតម្រូវការបច្ចុប្បន្ន និងអនាគតរបស់យើង។

## ការពិចារណា

មានអ្នកផ្តល់ហេដ្ឋារចនាសម្ព័ន្ធពពកជាច្រើនក្នុងទីផ្សារដែលបានបង្ហាញថាអាចទុកចិត្តបាន និងមានប្រសិទ្ធភាព។ ទោះយ៉ាងណា AWS មិនត្រឹមតែផ្តល់សំណុំសេវាកម្មពេញលេញដើម្បីបម្រើតម្រូវការរបស់យើងប៉ុណ្ណោះទេ ប៉ុន្តែវាក៏មានមូលដ្ឋានអតិថិជនធំទូលាយ និងកំណត់ត្រានៃការដាក់ពង្រាយដែលជោគជ័យ។ AWS ក៏ផ្តល់ធនធានគាំទ្រ និងបណ្តុះបណ្តាលយ៉ាងទូលំទូលាយ ដើម្បីធានាថាក្រុមរបស់យើងអាចធ្វើការជាមួយវេទិកាបានប្រកបដោយប្រសិទ្ធភាព។

លើសពីនេះ AWS មានវត្តមានជាសកលយ៉ាងទូលំទូលាយ ជាមួយមជ្ឈមណ្ឌលទិន្នន័យដែលស្ថិតនៅក្នុងតំបន់ផ្សេងៗជុំវិញពិភពលោក។ នេះធានាថាទិន្នន័យរបស់យើងមានសុវត្ថិភាព ហើយកម្មវិធី និងសេវាកម្មរបស់យើងនឹងមានភាពអាចរកបានខ្ពស់។ AWS ក៏មានក្របខ័ណ្ឌសុវត្ថិភាពរឹងមាំដែលមានសារៈសំខាន់សម្រាប់អាជីវកម្មរបស់យើង។

ទីបញ្ចប់ AWS ផ្តល់គំរូបង់ប្រាក់តាមការប្រើប្រាស់ ដែលផ្តល់ឱ្យយើងនូវភាពបត់បែនក្នុងការពង្រីកហេដ្ឋារចនាសម្ព័ន្ធរបស់យើងតាមតម្រូវការ។ នេះមានន័យថាយើងនឹងត្រូវគិតថ្លៃតែអ្វីដែលយើងប្រើ ដែលអនុញ្ញាតឱ្យយើងធ្វើឱ្យថ្លៃដើមល្អបំផុត និងវិនិយោគលើផ្នែកផ្សេងទៀតនៃអាជីវកម្ម។

## ការសម្រេចចិត្ត

ដោយផ្អែកលើការវាយតម្លៃដែលបានធ្វើ និងអត្ថប្រយោជន៍ដែល AWS ផ្តល់ជូន គេបានសម្រេចថា AWS នឹងត្រូវបានទទួលយកសម្រាប់តម្រូវការហេដ្ឋារចនាសម្ព័ន្ធពពករបស់យើង។

## ផលវិបាក

ការទទួលយក AWS អាចតម្រូវឱ្យមានការបណ្តុះបណ្តាលសម្រាប់ក្រុមរបស់យើង ដើម្បីធានាថាពួកគេស្គាល់វេទិកា និងអាចប្រើវាបានប្រកបដោយប្រសិទ្ធភាព។ ក៏អាចមានថ្លៃដើមដំបូងមួយចំនួនដើម្បីផ្លាស់ប្តូរហេដ្ឋារចនាសម្ព័ន្ធបច្ចុប្បន្នរបស់យើងទៅវេទិកា AWS។

## ភាពជាម្ចាស់

ទំនួលខុសត្រូវក្នុងការធានាការប្រើប្រាស់ AWS ប្រកបដោយប្រសិទ្ធភាព និងការគ្រប់គ្រងហានិភ័យដែលពាក់ព័ន្ធ នឹងស្ថិតក្នុងទំនួលខុសត្រូវរបស់ក្រុមហេដ្ឋារចនាសម្ព័ន្ធពពក។ បញ្ហាណាមួយដែលកើតឡើងត្រូវតែដោះស្រាយដោយក្រុមនេះ។

## ការពិនិត្យឡើងវិញ

ការសម្រេចចិត្តទទួលយក AWS នឹងត្រូវបានពិនិត្យឡើងវិញជារៀងរាល់ឆ្នាំ ដើម្បីធានាថាវានៅតែបំពេញតម្រូវការរបស់យើង ហើយអត្ថប្រយោជន៍នៃវេទិកាត្រូវបានសម្រេចពេញលេញ។
