# ក្បួនដាក់ឈ្មោះឯកសារ ADR

ប្រសិនបើអ្នកជ្រើសរើសបង្កើត ADR ដោយប្រើឯកសារអត្ថបទធម្មតា អ្នកប្រហែលជាចង់បង្កើតក្បួនដាក់ឈ្មោះឯកសារ ADR ផ្ទាល់ខ្លួន។

យើងចូលចិត្តប្រើក្បួនដាក់ឈ្មោះឯកសារដែលមានទម្រង់ជាក់លាក់។

ឧទាហរណ៍៖

  * choose-database.md

  * format-timestamps.md

  * handle-exceptions.md

ក្បួនដាក់ឈ្មោះឯកសាររបស់យើង៖

  * ឈ្មោះមានឃ្លាកិរិយាសព្ទបញ្ជាកាលបច្ចុប្បន្ន។ នេះជួយឱ្យងាយអាន និងត្រូវនឹងទម្រង់សារ commit របស់យើង។

  * ឈ្មោះប្រើអក្សរតូច និងសញ្ញាដាច់ (ដូចគ្នានឹង repo នេះ)។ នេះជាតុល្យភាពរវាងភាពងាយអាន និងភាពងាយប្រើប្រព័ន្ធ។

  * ផ្នែកបន្ថែមគឺ markdown។ នេះអាចមានប្រយោជន៍សម្រាប់ការធ្វើទម្រង់ដោយងាយ។
