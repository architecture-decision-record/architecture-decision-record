## Cyd-destun a datganiad o'r broblem

Mae angen i ni benderfynu pa system rheoli cronfa ddata (DBMS) i'w defnyddio ar gyfer Prosiect X. Defnyddir y gronfa ddata i storio a rheoli llawer iawn o ddata o sawl ffynhonnell. Mae angen DBMS arnom sy'n gallu ymdrin â thrafodion, cynnig graddadwyedd, a darparu dibynadwyedd a diogelwch uchel. Ymhlith y gwahanol ddewisiadau sydd ar gael, rydym yn ystyried MySQL fel dewis posibl.

## Canlyniad y penderfyniad

Ar ôl gwerthuso'r dewisiadau uchod ar sail ystyriaethau ein penderfyniad, rydym wedi penderfynu dewis MySQL fel ein DBMS ar gyfer Prosiect X.

System ffynhonnell agored boblogaidd yw MySQL gyda chymuned ddatblygu gref a chronfa fawr o adnoddau ar gyfer datrys problemau a rhannu gwybodaeth. Mae'n adnabyddus am ei alluoedd perfformiad a graddadwyedd rhagorol, sy'n ei wneud yn ddelfrydol ar gyfer ymdrin â symiau enfawr o ddata'n hynod effeithlon. Mae'r platfform yn ddiogel, yn ddibynadwy, ac mae ganddo ystod eang o nodweddion sy'n hanfodol i'n prosiect, gan gynnwys cydymffurfedd ACID ar gyfer trafodion, model data hyblyg, a chefnogaeth i amrywiol ieithoedd rhaglennu a fframweithiau.

Mae MySQL hefyd yn gydweddol â'r rhan fwyaf o'n pentwr technoleg, gan gynnwys ein fframwaith datblygu gwe, ein datrysiadau lletya, ac offer hanfodol eraill. Hefyd, mae ei delerau cost a thrwyddedu yn gystadleuol o'u cymharu â systemau perchnogol eraill fel Oracle a Microsoft SQL Server.

## Canlyniadau

Rydym yn rhagweld y deilliannau a'r canlyniadau canlynol o'n penderfyniad:

### Cadarnhaol

- **Perfformiad a graddadwyedd uchel:**  Mae MySQL yn cynnig galluoedd perfformiad a graddadwyedd eithriadol, sy'n ei wneud yn ddelfrydol ar gyfer ymdrin â llawer iawn o ddata'n effeithlon.

- **Diogel a dibynadwy:**  Mae MySQL yn darparu nodweddion diogelwch a dibynadwyedd rhagorol, sy'n hanfodol ar gyfer rheoli data hanfodol.

- **Cefnogaeth eang gan y gymuned:**  Mae gan MySQL gymuned enfawr ac amrywiol adnoddau ar-lein, sy'n ei gwneud hi'n haws gofyn am gymorth a datrys problemau.

- **Cydweddoldeb:**  Mae MySQL yn gydweddol â'n pentwr technoleg a'n hieithoedd rhaglennu, sy'n symleiddio ein proses ddatblygu.

### Negyddol

- **Cromlin ddysgu:**  Efallai y bydd cromlin ddysgu i'r tîm datblygu, yn enwedig y rhai nad oes ganddynt brofiad o MySQL a chronfeydd data SQL.

- **Cyfyngiadau:**  Efallai y bydd gan MySQL rai cyfyngiadau wrth ymdrin â rhai mathau o ddata a modelau data cymhleth, sy'n galw am ddatblygu ac optimeiddio gofalus.

## Casgliad

Ar sail y data sydd ar gael ac ystyriaethau ein penderfyniad, credwn mai MySQL yw'r dewis cywir ar gyfer ein system rheoli cronfa ddata ar gyfer Prosiect X. Mae MySQL yn cynnig galluoedd perfformiad uchel, dibynadwyedd, diogelwch a graddadwyedd ac mae'n gydweddol â'n pentwr technoleg yn eang. Bydd angen i'r tîm datblygu ymgyfarwyddo â defnyddio MySQL, ond dylai'r gefnogaeth a'r adnoddau sydd ar gael gan y gymuned helpu yn y broses.
