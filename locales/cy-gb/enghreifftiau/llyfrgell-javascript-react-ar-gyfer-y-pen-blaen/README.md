# Cofnod penderfyniad saernïaeth: llyfrgell JavaScript React ar gyfer y pen blaen

## Cyd-destun

Mae angen i ni ddewis llyfrgell JavaScript pen blaen ar gyfer ein cymhwysiad i ddatblygu rhyngwyneb defnyddiwr ymatebol a rhyngweithiol.
  
## Dewisiadau a ystyriwyd

1. React
  
2. Vue

3. Svelte
   
## Penderfyniad

Byddwn yn defnyddio React fel ein llyfrgell JavaScript pen blaen.
  
## Sail resymegol

1. **Saernïaeth sy'n seiliedig ar gydrannau:**  Mae React yn darparu saernïaeth sy'n seiliedig ar gydrannau sy'n caniatáu i ni dorri'r rhyngwyneb defnyddiwr i lawr yn gydrannau bach y gellir eu hailddefnyddio. Mae hyn yn helpu i wella modiwlaredd ein cod ac yn ei gwneud hi'n haws cynnal, graddio a diweddaru'r cymhwysiad.
  
2. **Rhaglennu datganiadol:**  Mae React yn defnyddio arddull rhaglennu datganiadol sy'n gwneud ein cod yn fwy greddfol ac yn haws ei ddarllen. Mae hefyd yn darparu DOM rhithwir, sy'n caniatáu i'n cod redeg yn gyflymach ac yn fwy effeithlon.
  
3. **Cymuned fawr:**  Mae gan React gymuned fawr a gweithgar, ac mae'n un o'r llyfrgelloedd pen blaen mwyaf poblogaidd. Mae hyn yn golygu bod llawer o adnoddau, offer a llyfrgelloedd ar gael a all ein helpu i ddatblygu ein cymhwysiad yn gyflymach ac yn fwy effeithlon.
  
4. **Gwell perfformiad:**  Mae React yn defnyddio llif data unffordd, sy'n helpu i symleiddio rhesymeg y cymhwysiad ac yn ei wneud yn fwy effeithlon. Mae hefyd yn darparu rendro ochr gweinydd, sy'n helpu i wella perfformiad a SEO ein cymhwysiad.
  
5. **Hyblygrwydd:**  Gellir defnyddio React gyda llyfrgelloedd a fframweithiau eraill, sy'n rhoi'r rhyddid i ni ddewis y pentwr technoleg gorau sy'n addas i ofynion ein prosiect.
  
## Canlyniadau

1. **Cromlin ddysgu:**  Mae gan React gromlin ddysgu, ac efallai y bydd yn cymryd peth amser i ddatblygwyr sy'n newydd i React ddod yn gyfarwydd.
  
2. **Offer adeiladu:**  Mae React yn gofyn am offer adeiladu ychwanegol fel Babel a Webpack, a all ychwanegu cymhlethdod at y broses ddatblygu.
  
3. **Cydweddoldeb porwyr:**  Mae gan React broblemau cydweddoldeb â phorwyr hŷn gan ei fod yn defnyddio nodweddion ES6 nad ydynt yn cael eu cefnogi mewn porwyr hŷn.
  
 4. Cromlin ddysgu serth: Gall gymryd amser i ddatblygwyr nad ydynt yn gyfarwydd â React ddysgu sut i'w ddefnyddio'n effeithlon, a all arwain at amseroedd datblygu arafach.

## Casgliad

Rydym wedi penderfynu defnyddio React ar gyfer llyfrgell JavaScript pen blaen ein cymhwysiad. Er y gall fod ganddo gromlin ddysgu, mae'r manteision a ddarperir gan React, fel ei saernïaeth sy'n seiliedig ar gydrannau, ei arddull rhaglennu datganiadol, gwell perfformiad, hyblygrwydd, a chymuned fawr, yn drech na'r anfanteision posibl.
