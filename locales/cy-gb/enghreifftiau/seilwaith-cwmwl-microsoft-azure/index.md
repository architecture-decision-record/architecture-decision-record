# Cofnod penderfyniad saernïaeth: seilwaith cwmwl Microsoft Azure

Teitl y penderfyniad: Mabwysiadu Microsoft Azure fel y seilwaith cwmwl ar gyfer ein sefydliad

Y penderfynwr: Y Prif Swyddog Gwybodaeth

Dyddiad: 2021-10-15

Statws: Wedi'i gymeradwyo

## Cefndir

Mae'r sefydliad yn bwriadu mudo o seilwaith traddodiadol ar y safle i seilwaith cwmwl. I gyflawni hyn, mae'r sefydliad wedi gwerthuso sawl darparwr gwasanaethau cwmwl fel Amazon Web Services (AWS), Google Cloud Platform (GCP), Microsoft Azure ac IBM Cloud. Mae gan bob darparwr ei set ei hun o nodweddion, manteision a strwythur prisio. Ar ôl dadansoddiad manwl, daethpwyd i'r casgliad mai Microsoft Azure yw'r dewis mwyaf addas ar gyfer ein sefydliad.

## Penderfyniad

Mabwysiadu Microsoft Azure fel y seilwaith cwmwl ar gyfer ein sefydliad.

## Sail resymegol

Dyma'r rhesymau dros fabwysiadu Microsoft Azure:

1. Gwasanaethau cynhwysfawr: Mae Azure yn darparu ystod gyflawn o wasanaethau cwmwl o seilwaith fel gwasanaeth (IaaS) i feddalwedd fel gwasanaeth (SaaS) a llwyfan fel gwasanaeth (PaaS). Mae hyn yn ein galluogi i fanteisio ar wasanaethau Azure i ddiwallu gofynion y sefydliad, fel storio, cyfrifiadura, rhwydweithio a dadansoddeg.

2. Graddadwyedd a hyblygrwydd: Gydag Azure, gallwn raddio adnoddau i fyny neu i lawr yn hawdd ar sail ein gofynion busnes. Mae Azure hefyd yn cynnig hyblygrwydd wrth ddewis y system weithredu, yr iaith raglennu a'r fframweithiau.

3. Diogelwch a chydymffurfedd: Mae Azure yn cynnig lefel uchel o ddiogelwch a chydymffurfedd, gan ei fod yn cydymffurfio â sawl safon diwydiant fel ISO, SOC, HIPAA a PCI DSS. Mae Azure hefyd yn darparu nodweddion diogelwch uwch fel grwpiau diogelwch rhwydwaith, waliau tân ac amddiffyniad rhag DDoS.

4. Cwmwl hybrid: Mae Azure yn darparu profiad cwmwl hybrid di-dor, gan alluogi sefydliadau i gysylltu eu seilwaith ar y safle ag Azure. Mae hyn yn ei gwneud hi'n hawdd i ni fudo llwythi gwaith i'r cwmwl ac yn rhoi'r hyblygrwydd i ni ddewis ble i storio data.

5. Cost-effeithiol: Mae Azure yn cynnig model prisio talu wrth ddefnyddio, sy'n golygu mai dim ond am yr adnoddau a ddefnyddir y byddwn yn talu. Mae hyn yn ein helpu i arbed costau o'i gymharu â seilwaith traddodiadol ar y safle.

## Casgliad

Mae mabwysiadu Microsoft Azure fel y seilwaith cwmwl ar gyfer ein sefydliad yn cyd-fynd â'n gofynion busnes ac yn cynnig sawl mantais fel graddadwyedd, hyblygrwydd, diogelwch a chost-effeithiolrwydd. Felly, argymhellir mabwysiadu Azure fel ein seilwaith cwmwl.
