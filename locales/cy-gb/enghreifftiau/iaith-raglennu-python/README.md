# Cofnod penderfyniad saernïaeth: yr iaith raglennu Python

## Cyd-destun

Mae angen i ni benderfynu a ddylem ddefnyddio Python fel iaith raglennu ar gyfer ein prosiect. Mae ein prosiect yn cynnwys dadansoddi data, dysgu peirianyddol, a datblygu gwe.

## Penderfyniad

Rydym wedi penderfynu defnyddio Python fel ein prif iaith raglennu ar gyfer ein prosiect.

## Sail resymegol

Mae Python yn iaith raglennu amlbwrpas a ddefnyddir yn eang ym meysydd dadansoddi data, dysgu peirianyddol, a datblygu gwe. Mae'n iaith wedi'i dehongli, sy'n golygu nad oes angen ei chrynhoi, ac mae ganddi gystrawen sy'n hawdd ei darllen a'i deall. Mae ffactorau pwysig eraill ar gyfer ein penderfyniad yn cynnwys y canlynol:

1. **Argaeledd llyfrgelloedd:** Mae gan Python gasgliad enfawr o lyfrgelloedd a fframweithiau, fel NumPy, Pandas a Scikit-learn, sy'n ei gwneud hi'n haws i ddatblygwyr weithredu algorithmau dysgu peirianyddol a dadansoddi data.

2. **Cefnogaeth gan y gymuned:** Mae gan Python gymuned fawr a gweithgar o ddatblygwyr sy'n cyfrannu at ei datblygiad ac yn darparu cefnogaeth ac arweiniad ar wahanol fforymau a gwefannau. Mae hyn yn ei gwneud hi'n haws i ddechreuwyr gael cymorth a dysgu'r iaith.

3. **Graddadwyedd:** Mae Python yn raddadwy, sy'n golygu y gall ymdrin â setiau data mawr a chymwysiadau cymhleth. Gellir ei defnyddio hefyd i greu prototeipiau cyflym neu adeiladu cymwysiadau bach heb fawr o ymdrech, sy'n ei gwneud hi'n haws i ni ddechrau ein prosiect ac ailadrodd yn gyflym.

4. **Hyblygrwydd:** Gellir defnyddio Python ar gyfer gwahanol fathau o brosiectau, gan gynnwys datblygu gwe, cyfrifiadura gwyddonol, dysgu peirianyddol, ac ati. Mae hefyd yn gydweddol ag ieithoedd rhaglennu eraill, fel Java a C++, sy'n ei gwneud hi'n haws integreiddio â systemau eraill.

## Canlyniadau

Mae rhai canlyniadau posibl i ddefnyddio Python fel ein hiaith raglennu, fel:

1. **Perfformiad:** Gall Python fod yn arafach nag ieithoedd wedi'u crynhoi fel C++ wrth weithredu rhai algorithmau, ond gellir lliniaru hyn drwy ddefnyddio llyfrgelloedd wedi'u optimeiddio neu ysgrifennu cod hanfodol yn C++ a rhyngwynebu ag ef gan ddefnyddio Python.

2. **Cromlin ddysgu:** Er bod gan Python gystrawen sy'n hawdd ei dysgu, gall fod yn heriol dysgu'r arferion gorau ar gyfer ysgrifennu cod effeithlon a graddadwy. Gellir goresgyn hyn drwy ddilyn confensiynau, defnyddio fframweithiau a llyfrgelloedd, a cheisio arweiniad gan ddatblygwyr profiadol.

3. **Cydweddoldeb fersiynau:** Gall fersiynau gwahanol o Python fod â chystrawen a galluoedd gwahanol, a all ei gwneud hi'n anodd cynnal a diweddaru prosiectau. Mae'n bwysig dewis fersiwn o Python a gefnogir yn eang ac sy'n gydweddol â gofynion ein prosiect.

## Casgliad

Ar ôl ystyried manteision ac anfanteision defnyddio Python fel ein hiaith raglennu, rydym wedi penderfynu mai hi yw'r dewis gorau ar gyfer ein prosiect. Credwn y bydd yn rhoi'r hyblygrwydd mwyaf i ni, argaeledd llyfrgelloedd, a chefnogaeth y gymuned, gan fod yn raddadwy ac yn addasadwy i'n hanghenion sy'n newid ar yr un pryd.
