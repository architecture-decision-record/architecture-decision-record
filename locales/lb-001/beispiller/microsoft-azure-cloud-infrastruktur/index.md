# Architektur-Decisiounsopzeechnung: Microsoft Azure Cloud-Infrastruktur" 

Decisiounstitel: Microsoft Azure als Cloud-Infrastruktur fir eis Organisatioun unhuelen

Decisiounsträger: Chief Information Officer

Datum: 2021-10-15

Zoustand: Genehmegt

## Hannergrond

D'Organisatioun plangt, vun der traditioneller On-Premises-Infrastruktur op Cloud-Infrastruktur ze migréieren. Fir dat z'erreechen, huet d'Organisatioun verschidde Cloud-Serviceprovider evaluéiert, wéi Amazon Web Services (AWS), Google Cloud Platform (GCP), Microsoft Azure an IBM Cloud. All Provider huet säi Set u Funktiounen, Virdeeler a Präisstruktur. No enger detailléierter Analyse gouf festgestallt, datt Microsoft Azure déi gëeegnetst Optioun fir eis Organisatioun ass.

## Decisioun

Microsoft Azure als Cloud-Infrastruktur fir eis Organisatioun unhuelen.

## Begrënnung

Folgend sinn d'Grënn fir d'Unhuele vu Microsoft Azure:

1. Ëmfaassend Servicer: Azure bitt eng komplett Palette u Cloud-Servicer vun Infrastructure as a Service (IaaS) bis Software as a Service (SaaS) a Platform as a Service (PaaS). Dat erlaabt eis, Azure-Servicer ze notzen, fir d'Ufuerderunge vun der Organisatioun ze léisen, wéi Storage, Compute, Networking an Analytics.

2. Skaléierbarkeet a Flexibilitéit: Mat Azure kënne mir Ressourcen op Basis vun eisen Geschäftsufuerderunge einfach erop oder erof skaléieren. Azure bitt och Flexibilitéit bei der Wiel vum Betribssystem, vun der Programméiersprooch a vun de Frameworks.

3. Sécherheet a Compliance: Azure bitt en héijen Niveau u Sécherheet a Compliance, well et mat verschiddene Branchenstandarde wéi ISO, SOC, HIPAA a PCI DSS konform ass. Azure bitt och fortgeschratt Sécherheetsfunktiounen wéi Network Security Groups, Firewalls an DDoS-Schutz.

4. Hybrid Cloud: Azure bitt eng nahtlos Hybrid-Cloud-Erfahrung, déi Organisatioune erméiglecht, hir On-Premises-Infrastruktur mat Azure ze verbannen. Dat mécht et eis einfach, Workloads an d'Cloud ze migréieren, a gëtt eis d'Flexibilitéit, ze wielen, wou mir Daten späichere.

5. Käschteneffizient: Azure bitt e Pay-as-you-go-Präismodell, wat bedeit, datt mir nëmmen fir déi benotzt Ressourcen bezuelen. Dat hëlleft eis, Käschten am Verglach zu traditioneller On-Premises-Infrastruktur ze spueren.

## Conclusioun

D'Unhuele vu Microsoft Azure als Cloud-Infrastruktur fir eis Organisatioun passt zu eise Geschäftsufuerderungen a bitt verschidde Virdeeler, wéi Skaléierbarkeet, Flexibilitéit, Sécherheet a Käschteneffizienz. Dofir gëtt recommandéiert, Azure als eis Cloud-Infrastruktur unzehuelen.
