# Architectuurbeslissingsdocument: programmeertaal Java

Titel: De programmeertaal Java kiezen voor het project

Beslissing: na evaluatie van meerdere programmeertalen hebben we besloten Java te gebruiken voor ons project.

### Achtergrond

We waren van plan een webgebaseerde applicatie te bouwen die op meerdere besturingssystemen kon draaien. Ons project vereiste een taal die sterke beveiligingsfuncties kon bieden, concurrency aankon, grote codebases ondersteunde en veelzijdig genoeg was om aan onze toekomstige groei-eisen te voldoen. We hebben verschillende talen geëvalueerd, rekening houdend met hun sterke punten en beperkingen, voordat we voor Java kozen.

### Overwegingen

1. **Beveiliging:**  Java biedt uitstekende beveiligingsfuncties dankzij goed gedefinieerd beveiligingsbeleid en toegangscontrole. Het bevat ook functies zoals bytecodeverificatie, die helpt voorkomen dat kwaadaardige software op een systeem draait.

2. **Concurrency:**  Java heeft ingebouwde ondersteuning voor multithreading, waardoor applicaties meerdere taken tegelijk kunnen uitvoeren. Deze functie maakt Java een uitstekende keuze voor het ontwikkelen van grote, complexe applicaties met meerdere functies en functionaliteiten.

3. **Grote codebases:**  Java ondersteunt objectgeoriënteerd programmeren, wat het een geschikte keuze maakt voor het ontwikkelen van grote codebases. De modulaire aard en het gebruik van inkapselings- en abstractiepatronen maken het softwareontwikkelproces bovendien gemakkelijker.

4. **Veelzijdigheid:**  Java is veelzijdig en biedt de mogelijkheid een breed scala aan bibliotheken en frameworks te gebruiken, waardoor het een uitstekende keuze is voor zowel webgebaseerde als bedrijfsapplicaties.

### Uitkomst van de beslissing

We hebben besloten de programmeertaal Java te gebruiken voor ons project, gezien de beveiligingsfuncties, de ondersteuning voor concurrency, het vermogen om grote codebases aan te kunnen en de veelzijdigheid. Deze beslissing sluit aan bij onze projecteisen en we geloven dat de keuze voor Java het succes ervan zal waarborgen. 

### Gevolgen

1. We hebben ontwikkelaars nodig die ervaring hebben met Java en het bekwaam kunnen gebruiken.

2. Alle code die in de taal wordt geschreven, moet compatibel zijn met de Java Virtual Machine (JVM).

3. Het opnemen van nieuwe functies, functionaliteiten of frameworks kan enkele uitdagingen met zich meebrengen.

4. Grote, complexe projecten in Java kunnen meer tijd en middelen vergen om te ontwikkelen.
