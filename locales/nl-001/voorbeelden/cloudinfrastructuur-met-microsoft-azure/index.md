# Architectuurbeslissingsdocument: cloudinfrastructuur met Microsoft Azure

Titel van de beslissing: Microsoft Azure invoeren als cloudinfrastructuur voor onze organisatie

Beslisser: Chief Information Officer

Datum: 2021-10-15

Status: Goedgekeurd

## Achtergrond

De organisatie is van plan te migreren van traditionele on-premises infrastructuur naar cloudinfrastructuur. Om dit te bereiken heeft de organisatie meerdere cloudserviceproviders geëvalueerd, zoals Amazon Web Services (AWS), Google Cloud Platform (GCP), Microsoft Azure en IBM Cloud. Elke provider heeft zijn eigen set functies, voordelen en prijsstructuur. Na een gedetailleerde analyse is geconcludeerd dat Microsoft Azure de meest geschikte optie is voor onze organisatie.

## Beslissing

Microsoft Azure invoeren als cloudinfrastructuur voor onze organisatie.

## Onderbouwing

Hieronder staan de redenen om Microsoft Azure in te voeren:

1. Uitgebreide diensten: Azure biedt een volledig scala aan clouddiensten, van infrastructure as a service (IaaS) tot software as a service (SaaS) en platform as a service (PaaS). Hierdoor kunnen we Azure-diensten benutten om aan de eisen van de organisatie te voldoen, zoals opslag, rekenkracht, netwerken en analyse.

2. Schaalbaarheid en flexibiliteit: met Azure kunnen we bronnen eenvoudig op- of afschalen op basis van onze bedrijfsbehoeften. Azure biedt ook flexibiliteit bij de keuze van besturingssysteem, programmeertaal en frameworks.

3. Beveiliging en naleving: Azure biedt een hoog niveau van beveiliging en naleving, omdat het voldoet aan verschillende branchestandaarden zoals ISO, SOC, HIPAA en PCI DSS. Azure biedt ook geavanceerde beveiligingsfuncties zoals netwerkbeveiligingsgroepen, firewalls en DDoS-bescherming.

4. Hybride cloud: Azure biedt een naadloze hybride cloudervaring, waarmee organisaties hun on-premises infrastructuur met Azure kunnen verbinden. Dit maakt het gemakkelijk workloads naar de cloud te migreren en geeft ons de flexibiliteit te kiezen waar data worden opgeslagen.

5. Kosteneffectief: Azure biedt een pay-as-you-go-prijsmodel, wat betekent dat we alleen betalen voor de gebruikte bronnen. Dit helpt ons kosten te besparen vergeleken met traditionele on-premises infrastructuur.

## Conclusie

Het invoeren van Microsoft Azure als cloudinfrastructuur voor onze organisatie sluit aan bij onze bedrijfseisen en biedt verschillende voordelen zoals schaalbaarheid, flexibiliteit, beveiliging en kosteneffectiviteit. Daarom wordt aanbevolen Azure in te voeren als onze cloudinfrastructuur.
