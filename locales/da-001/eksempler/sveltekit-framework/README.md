## Begrundelse

SvelteKit er en ny og omfattende frontend-løsning, der tilbyder en række funktioner såsom server-side rendering, hot reloading, forenklet konfiguration og meget mere. Det gør det muligt for os at skabe en frontend-arkitektur af høj kvalitet, der med lethed kan håndtere de største applikationer.

SvelteKits komponentbaserede arkitektur gør det muligt for os at udvikle genanvendelige og skalerbare UI-komponenter, der problemfrit kan integreres mellem forskellige projekter. Frameworket tilbyder fremragende understøttelse af TypeScript, hvilket giver os mulighed for at skabe ren og struktureret kode, der er nem at vedligeholde.

Derudover tilbyder SvelteKit et brugervenligt dokumentstyringssystem, der giver os mulighed for at spore alle vores projekts arkitekturbeslutninger og ændringer.

## Overvejede alternativer

Vi kan opnå bedre produktivitet gennem frameworkets enklere konfigurationer, komponentbaserede arkitektur og modularitet. Som følge heraf kan vores projekt blive mere effektivt og stabilt.
