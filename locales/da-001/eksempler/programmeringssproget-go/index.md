# Arkitekturbeslutningspost: programmeringssproget Go

Titel: Indførelse af programmeringssproget Go

Status: Accepteret

## Kontekst

Vores organisation har primært brugt programmeringssproget Java til at bygge webapplikationer. Vi har dog oplevet nogle udfordringer på grund af Javas ordrighed og kompleksiteten i nogle frameworks. Vores team har også vist interesse for at udforske moderne programmeringssprog til mere effektiv og robust udvikling. Efter research har vi identificeret Go som en potentiel løsning på de problemer, vi har med Java.

## Beslutning

Vi vil fremover indføre programmeringssproget Go til at bygge webapplikationer.

## Begrundelse

1. **Enkelhed og læsbarhed:** Go er kendt for sin enkelhed og kortfattede syntaks. Det gør det nemt at læse og skrive kode og reducerer kompleksiteten i vores udviklingsproces.

2. **Høj ydeevne og skalerbarhed:** Go kompileres til maskinkode, der kører nativt på serveren. Det giver hurtigere udførelsestider og bedre ydeevne sammenlignet med fortolkede sprog som Java. Derudover håndterer Gos samtidighedsmodel flere forespørgsler samtidig, hvilket gør det meget skalerbart.

3. **Stærk fællesskabsstøtte:** Go har et levende fællesskab af udviklere, som gennem årene har bidraget til dets vækst. Det betyder, at der er masser af ressourcer, biblioteker og frameworks, der kan hjælpe os i gang og med at bygge robuste applikationer.

4. **Fleksibilitet:** Go kan bruges til både frontend- og backendudvikling. Det betyder, at vi kan udnytte dets fordele på begge områder i vores udviklingsprojekter.

## Implikationer

1. **Uddannelse:** Vores udviklere skal gennemgå uddannelse for at lære programmeringssproget Go og dets nuancer.

2. **Erfaring:**  Vi kan møde nogle udfordringer, når vi skifter fra Java til Go. Det kan tage noget tid, før vores udviklere bliver dygtige i det nye sprog.

3. **Værktøjer:**  Vi skal indføre nye værktøjer og frameworks, der er specifikke for Go. Vi kan dog udnytte den eksisterende infrastruktur, vi har, for at minimere indvirkningen af denne ændring.

4. **Leverandørbinding:**  Go er et open source-programmeringssprog, og vi bliver ikke bundet til nogen leverandør eller tjenesteudbyder.

## Konklusion

Indførelsen af programmeringssproget Go vil hjælpe os med at forbedre vores udviklingsproces og bygge robuste applikationer. Vi skal investere ressourcer i uddannelse og værktøjer for at understøtte denne overgang, men vi tror, at fordelene ved denne beslutning opvejer omkostningerne.
