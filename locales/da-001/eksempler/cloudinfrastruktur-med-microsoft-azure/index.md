# Arkitekturbeslutningspost: cloudinfrastruktur med Microsoft Azure

Beslutningstitel: Indførelse af Microsoft Azure som cloudinfrastruktur for vores organisation

Beslutningstager: Chief Information Officer

Dato: 2021-10-15

Status: Godkendt

## Baggrund

Organisationen planlægger at migrere fra traditionel on-premises-infrastruktur til cloudinfrastruktur. For at opnå dette har organisationen evalueret flere cloudtjenesteudbydere, såsom Amazon Web Services (AWS), Google Cloud Platform (GCP), Microsoft Azure og IBM Cloud. Hver udbyder har sit eget sæt funktioner, fordele og prisstruktur. Efter en detaljeret analyse blev det konkluderet, at Microsoft Azure er den mest egnede mulighed for vores organisation.

## Beslutning

Indfør Microsoft Azure som cloudinfrastruktur for vores organisation.

## Begrundelse

Følgende er grundene til at indføre Microsoft Azure:

1. Omfattende tjenester: Azure tilbyder et komplet udvalg af cloudtjenester fra infrastructure as a service (IaaS) til software as a service (SaaS) og platform as a service (PaaS). Det gør det muligt for os at udnytte Azure-tjenester til at løse organisationens krav, såsom lagring, beregning, netværk og analyse.

2. Skalerbarhed og fleksibilitet: med Azure kan vi nemt skalere ressourcer op eller ned baseret på vores forretningsbehov. Azure tilbyder også fleksibilitet i valg af operativsystem, programmeringssprog og frameworks.

3. Sikkerhed og compliance: Azure tilbyder et højt niveau af sikkerhed og compliance, da det overholder flere branchestandarder som ISO, SOC, HIPAA og PCI DSS. Azure tilbyder også avancerede sikkerhedsfunktioner som netværkssikkerhedsgrupper, firewalls og DDoS-beskyttelse.

4. Hybrid cloud: Azure tilbyder en problemfri hybridcloud-oplevelse, der giver organisationer mulighed for at forbinde deres on-premises-infrastruktur med Azure. Det gør det nemt for os at migrere workloads til skyen og giver os fleksibilitet til at vælge, hvor data skal gemmes.

5. Omkostningseffektivt: Azure tilbyder en pay-as-you-go-prismodel, hvilket betyder, at vi kun betaler for de brugte ressourcer. Det hjælper os med at spare omkostninger sammenlignet med traditionel on-premises-infrastruktur.

## Konklusion

At indføre Microsoft Azure som cloudinfrastruktur for vores organisation stemmer overens med vores forretningskrav og giver flere fordele som skalerbarhed, fleksibilitet, sikkerhed og omkostningseffektivitet. Derfor anbefales det at indføre Azure som vores cloudinfrastruktur.
