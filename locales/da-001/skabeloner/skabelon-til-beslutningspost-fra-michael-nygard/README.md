# Skabelon til beslutningspost fra Michael Nygard

Dette er skabelonen fra [Documenting architecture decisions - Michael Nygard](http://thinkrelevance.com/blog/2011/11/15/documenting-architecture-decisions).
Du kan bruge [adr-tools](https://github.com/npryce/adr-tools) til at administrere ADR-filer.

I hver ADR-fil skriver du disse afsnit:

# Titel

## Status

Hvad er statussen, f.eks. proposed, accepted, rejected, deprecated, superseded osv.?

## Kontekst

Hvad er det problem, vi ser, som motiverer denne beslutning eller ændring?

## Beslutning

Hvad er den ændring, vi foreslår eller gennemfører?

## Konsekvenser

Hvad bliver nemmere eller sværere på grund af denne ændring?
