# ແມ່ແບບບັນທຶກການຕັດສິນໃຈສຳລັບກໍລະນີທຸລະກິດ

## ການເຈາະເລິກລະດັບຕ່ຳ

**ຫົວຂໍ້**:

  * ວະລີກິລິຍາຄຳສັ່ງໃນປັດຈຸບັນກາລສັ້ນໆ ຍາວບໍ່ເກີນ 50 ຕົວອັກສອນ ຄືກັບຂໍ້ຄວາມ git commit.

**ສະຖານະ**:

  * ໜຶ່ງໃນ ສະເໜີ, ຍອມຮັບ, ປະຕິເສດ, ເລີກໃຊ້, ຖືກແທນທີ່ ແລະ ອື່ນໆ.

**ເກນການປະເມີນ**:

  * ບົດສະຫຼຸບ: ອະທິບາຍສັ້ນໆວ່າພວກເຮົາຕ້ອງການຄົ້ນພົບຫຍັງ ແລະ ເປັນຫຍັງ.

  * ລາຍລະອຽດສະເພາະ

**ຜູ້ສະໝັກທີ່ຈະພິຈາລະນາ**:

  * ບົດສະຫຼຸບ: ອະທິບາຍສັ້ນໆວ່າພວກເຮົາຄົ້ນພົບຜູ້ສະໝັກແນວໃດ ແລະ ດຶງຄວາມສົນໃຈໄປຍັງຜູ້ສະໝັກທີ່ຜິດປົກກະຕິ.

  * ລະບຸຜູ້ສະໝັກທັງໝົດ ແລະ ທາງເລືອກທີ່ກ່ຽວຂ້ອງ; ພວກເຮົາກຳລັງປະເມີນອັນໃດເປັນວິທີແກ້ໄຂທີ່ເປັນໄປໄດ້?

  * ລາຍລະອຽດສະເພາະ

**ການຄົ້ນຄວ້າ ແລະ ການວິເຄາະຜູ້ສະໝັກແຕ່ລະຄົນ**:

  * ບົດສະຫຼຸບ: ອະທິບາຍສັ້ນໆກ່ຽວກັບວິທີການຄົ້ນຄວ້າ ແລະ ດຶງຄວາມສົນໃຈໄປຍັງແບບແຜນ, ກຸ່ມ ແລະ ຜູ້ສະໝັກທີ່ຜິດປົກກະຕິ.

  * ຕອບສະໜອງ/ບໍ່ຕອບສະໜອງເກນ ແລະ ເຫດຜົນ

    * ບົດສະຫຼຸບ

    * ລາຍລະອຽດສະເພາະ

  * ການວິເຄາະຕົ້ນທຶນ

    * ບົດສະຫຼຸບ

    * ຕົວຢ່າງ

      * ການອະນຸຍາດໃຊ້ງານ ເຊັ່ນ ຂໍ້ຕົກລົງສັນຍາ ແລະ ພັນທະທາງກົດໝາຍ

      * ການຝຶກອົບຮົມ ເຊັ່ນ ການເພີ່ມທັກສະ ແລະ ການຈັດການການປ່ຽນແປງ

      * ການດຳເນີນງານ ເຊັ່ນ ການສະໜັບສະໜູນ ແລະ ການບຳລຸງຮັກສາ

      * ການວັດແທກການໃຊ້ງານ ເຊັ່ນ ແບນວິດ ແລະ ການໃຊ້ CPU

  * ການວິເຄາະ SWOT

    * ບົດສະຫຼຸບ

    * ຈຸດແຂງ

    * ຈຸດອ່ອນ

    * ໂອກາດ

    * ໄພຄຸກຄາມ

  * ຄວາມຄິດເຫັນ ແລະ ຄຳຕິຊົມພາຍໃນ

    * ບົດສະຫຼຸບ

    * ຕົວຢ່າງ

      * ໂດຍທີມ ໃນທາງທີ່ດີແມ່ນຂຽນໂດຍບຸກຄົນຜູ້ນັ້ນເອງ

      * ຈາກຜູ້ມີສ່ວນໄດ້ສ່ວນເສຍຄົນອື່ນ

      * ຄຸນລັກສະນະດ້ານຄຸນນະພາບ ຫຼື ທີ່ເອີ້ນວ່າຄວາມຕ້ອງການຂ້າມໜ້າທີ່ 

  * ຄວາມຄິດເຫັນ ແລະ ຄຳຕິຊົມພາຍນອກ

    * ບົດສະຫຼຸບ

    * ຜູ້ສະໝັກຄົນອື່ນທີ່ທ່ານພິຈາລະນາມີໃຜແດ່?

        * ເດັສທັອບ ຫຼື ມືຖື

        * ທົດລອງ ຫຼື ໃຊ້ງານຈິງ

    * ທ່ານປະເມີນຜູ້ສະໝັກແນວໃດ?

    * ເປັນຫຍັງທ່ານຈຶ່ງເລືອກຜູ້ຊະນະ?

    * ຕັ້ງແຕ່ນັ້ນມາມີຫຍັງເກີດຂຶ້ນ?
