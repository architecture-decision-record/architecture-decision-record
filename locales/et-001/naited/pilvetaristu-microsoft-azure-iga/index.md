# Arhitektuuriotsuse kirje: pilvetaristu Microsoft Azure'iga

Otsuse pealkiri: Microsoft Azure'i kasutuselevõtt meie organisatsiooni pilvetaristuna

Otsustaja: infojuht (CIO)

Kuupäev: 2021-10-15

Olek: Kinnitatud

## Taust

Organisatsioon plaanib migreeruda traditsioonilisest kohapealsest taristust pilvetaristule. Selle saavutamiseks on organisatsioon hinnanud mitut pilveteenuse pakkujat, nagu Amazon Web Services (AWS), Google Cloud Platform (GCP), Microsoft Azure ja IBM Cloud. Igal pakkujal on oma funktsioonide, eeliste ja hinnastruktuuri komplekt. Pärast üksikasjalikku analüüsi jõuti järeldusele, et Microsoft Azure on meie organisatsioonile kõige sobivam valik.

## Otsus

Võtta Microsoft Azure kasutusele meie organisatsiooni pilvetaristuna.

## Põhjendus

Järgnevad on põhjused Microsoft Azure'i kasutuselevõtuks:

1. Põhjalikud teenused: Azure pakub täielikku pilveteenuste valikut alates infrastruktuurist teenusena (IaaS) kuni tarkvara teenusena (SaaS) ja platvormi teenusena (PaaS). See võimaldab meil kasutada Azure'i teenuseid organisatsiooni nõuete lahendamiseks, nagu salvestus, arvutus, võrgundus ja analüüs.

2. Skaleeritavus ja paindlikkus: Azure'iga saame ressursse oma äriliste vajaduste alusel hõlpsasti üles- või allapoole skaleerida. Azure pakub ka paindlikkust operatsioonisüsteemi, programmeerimiskeele ja raamistike valikul.

3. Turvalisus ja vastavus: Azure pakub kõrget turvalisuse ja vastavuse taset, kuna see vastab mitmetele valdkonna standarditele nagu ISO, SOC, HIPAA ja PCI DSS. Azure pakub ka täiustatud turvafunktsioone nagu võrguturberühmad, tulemüürid ja DDoS-kaitse.

4. Hübriidpilv: Azure pakub sujuvat hübriidpilve kogemust, mis võimaldab organisatsioonidel oma kohapealse taristu Azure'iga ühendada. See teeb meil töökoormuste pilve migreerimise lihtsaks ja annab paindlikkuse valida, kuhu andmeid salvestada.

5. Kulutõhus: Azure pakub kasuta-ja-maksa hinnamudelit, mis tähendab, et maksame ainult kasutatud ressursside eest. See aitab meil võrreldes traditsioonilise kohapealse taristuga kulusid säästa.

## Kokkuvõte

Microsoft Azure'i kasutuselevõtt meie organisatsiooni pilvetaristuna on kooskõlas meie ärinõuetega ja pakub mitmeid eeliseid nagu skaleeritavus, paindlikkus, turvalisus ja kulutõhusus. Seetõttu soovitatakse Azure meie pilvetaristuna kasutusele võtta.
