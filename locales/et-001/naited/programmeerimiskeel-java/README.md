# Arhitektuuriotsuse kirje: programmeerimiskeel Java

Pealkiri: programmeerimiskeele Java valimine projekti jaoks

Otsus: pärast mitme programmeerimiskeele hindamist otsustasime kasutada oma projekti jaoks Javat.

### Taust

Kavatsesime ehitada veebipõhise rakenduse, mis suudaks töötada mitmes operatsioonisüsteemis. Meie projekt nõudis keelt, mis suudaks pakkuda tugevaid turvafunktsioone, käsitleda samaaegsust, toetada suuri koodibaase ja olla piisavalt mitmekülgne meie tulevaste kasvunõuete täitmiseks. Hindasime mitut keelt, arvestades nende tugevusi ja piiranguid, enne kui Java kasuks otsustasime.

### Kaalutlused

1. **Turvalisus:**  Java pakub suurepäraseid turvafunktsioone oma hästi määratletud turvapoliitikate ja juurdepääsukontrolli kaudu. See sisaldab ka funktsioone nagu baitkoodi kontroll, mis aitab vältida pahatahtliku tarkvara töötamist süsteemis.

2. **Samaaegsus:**  Javal on sisseehitatud tugi mitmelõimelisusele, mis võimaldab rakendustel täita mitut ülesannet korraga. See funktsioon teeb Javast suurepärase valiku suurte, keerukate rakenduste arendamiseks, millel on mitu funktsiooni ja funktsionaalsust.

3. **Suured koodibaasid:**  Java toetab objektorienteeritud programmeerimist, mis teeb selle sobivaks valikuks suurte koodibaaside arendamiseks. Selle modulaarne olemus ning kapseldamise ja abstraktsiooni mustrite kasutamine muudavad tarkvaraarendusprotsessi lihtsamaks.

4. **Mitmekülgsus:**  Java on mitmekülgne ja pakub võimalust kasutada laia valikut teeke ja raamistikke, muutes selle suurepäraseks valikuks nii veebipõhiste kui ka ettevõtte tasandi rakenduste jaoks.

### Otsuse tulemus

Otsustasime kasutada oma projekti jaoks programmeerimiskeelt Java, arvestades selle turvafunktsioone, samaaegsuse tuge, võimet käsitleda suuri koodibaase ja mitmekülgsust. See otsus on kooskõlas meie projekti nõuetega ja usume, et Java valimine tagab selle edu. 

### Tagajärjed

1. Vajame arendajaid, kellel on Java kogemus ja kes oskavad seda osavalt kasutada.

2. Kogu selles keeles kirjutatud kood peab ühilduma Java virtuaalmasinaga (JVM).

3. Uute funktsioonide, funktsionaalsuste või raamistike lisamine võib kaasa tuua mõningaid väljakutseid.

4. Suured, keerukad Java projektid võivad nõuda arendamiseks rohkem aega ja ressursse.
