# Arhitektuuriotsuse kirje: JavaScripti teek React kasutajaliidese jaoks

## Kontekst

Peame valima oma rakenduse jaoks kasutajaliidese JavaScripti teegi, et arendada reageeriv ja interaktiivne kasutajaliides.
  
## Kaalutud valikud

1. React
  
2. Vue

3. Svelte
   
## Otsus

Kasutame oma kasutajaliidese JavaScripti teegina Reacti.
  
## Põhjendus

1. **Komponendipõhine arhitektuur:**  React pakub komponendipõhist arhitektuuri, mis võimaldab meil UI-d jaotada väikesteks taaskasutatavateks komponentideks. See aitab parandada meie koodi modulaarsust ning teeb rakenduse hooldamise, skaleerimise ja uuendamise lihtsamaks.
  
2. **Deklaratiivne programmeerimine:**  React kasutab deklaratiivset programmeerimisstiili, mis muudab meie koodi intuitiivsemaks ja kergemini loetavaks. See pakub ka virtuaalset DOM-i, mis võimaldab meie koodil kiiremini ja tõhusamalt töötada.
  
3. **Suur kogukond:**  Reactil on suur ja aktiivne kogukond ning see on üks populaarsemaid kasutajaliidese teeke. See tähendab, et on palju ressursse, tööriistu ja teeke, mis aitavad meil oma rakendust kiiremini ja tõhusamalt arendada.
  
4. **Parem jõudlus:**  React kasutab ühesuunalist andmevoogu, mis aitab rakenduse loogikat lihtsustada ja muudab selle tõhusamaks. See pakub ka serveripoolset renderdamist, mis aitab parandada meie rakenduse jõudlust ja SEO-d.
  
5. **Paindlikkus:**  Reacti saab kasutada koos teiste teekide ja raamistikega, mis annab meile vabaduse valida parim tehnoloogiapakett, mis sobib meie projekti nõuetega.
  
## Tagajärjed

1. **Õppimiskõver:**  Reactil on õppimiskõver ja Reactiga uutel arendajatel võib minna aega, enne kui nad on kursis.
  
2. **Ehitustööriistad:**  React nõuab lisaehitustööriistu nagu Babel ja Webpack, mis võib arendusprotsessi keerulisemaks muuta.
  
3. **Brauseriühilduvus:**  Reactil on vanemate brauseritega ühilduvusprobleeme, kuna see kasutab ES6 funktsioone, mida vanemad brauserid ei toeta.
  
 4. Järsk õppimiskõver: Reactiga mitte tuttavatel arendajatel võib minna aega, et õppida seda tõhusalt kasutama, mis võib viia aeglasemate arendusaegadeni.

## Kokkuvõte

Otsustasime kasutada oma rakenduse kasutajaliidese JavaScripti teegina Reacti. Kuigi sellel võib olla õppimiskõver, kaaluvad Reacti pakutavad eelised, nagu komponendipõhine arhitektuur, deklaratiivne programmeerimisstiil, parem jõudlus, paindlikkus ja suur kogukond, võimalikud puudused üles.
