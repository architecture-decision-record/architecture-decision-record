# แม่แบบบันทึกการตัดสินใจสำหรับการตัดสินใจทางเทคนิคที่สำคัญ (ITD)

นี่คือแม่แบบการตัดสินใจทางเทคนิคที่สำคัญ (Important Technical Decisions หรือ ITD) ตามที่อธิบายใน
[ITDs: a lean ADR for executive technical decision-making at scale - Ignacio Larrañaga](https://ignaciolarranaga.medium.com/itds-a-lean-adr-for-executive-technical-decision-making-at-scale-e18bb3f6a563)

ITD คือวิวัฒนาการที่มุ่งเน้นของ ADR ซึ่งปรับให้เหมาะสำหรับความเร็ว ความชัดเจน และ
การตรวจสอบโดยผู้บริหาร ในขณะที่ ADR บันทึกสิ่งที่ตัดสินใจ ITD เป็น
ผลงานแบบ lean ที่ให้การตัดสินใจมาก่อน ซึ่งทำให้ตัวการตัดสินใจทบทวนได้ เพื่อให้ผู้มีส่วนได้ส่วนเสียไล่ดู
ได้อย่างรวดเร็วและท้าทายได้ง่าย ITD เหมาะกับการตัดสินใจทางเทคนิคที่ไม่ได้เกี่ยวกับ
สถาปัตยกรรมโดยเคร่งครัด เช่น การเลือกโมเดล ไลบรารี หรือกลยุทธ์ CI/CD

ในแต่ละไฟล์ ITD ให้เขียนส่วนต่อไปนี้:

# ชื่อเรื่อง

ระบุตัวการตัดสินใจ ไม่ใช่คำอธิบายหัวข้อ
ตัวอย่างเช่น "ใช้ Qwen2.5 1.5B Instruct สำหรับการแปลบนอุปกรณ์"

## ปัญหา

หนึ่งประโยคที่อธิบายสิ่งที่เรากำลังพยายามแก้ไข

## ทางเลือกที่พิจารณา

ทางเลือกที่ประเมิน โดยทางเลือกที่เลือกเป็น**ตัวหนา**

## เหตุผล

เฉพาะปัจจัยชี้ขาดที่นำไปสู่การเลือก ไม่ใช่
รายการครบถ้วนของข้อดีข้อเสียทั้งหมด

## หมายเหตุ

ทางเลือก บริบทเพิ่มเติมที่ควรบันทึก เช่น ข้อจำกัด สมมติฐาน หรือลิงก์
