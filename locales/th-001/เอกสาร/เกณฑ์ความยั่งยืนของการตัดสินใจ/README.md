# เกณฑ์ความยั่งยืนของการตัดสินใจ

<https://www.infoq.com/articles/sustainable-architectural-design-decisions/>

เพื่อกำหนดความยั่งยืนของการตัดสินใจอย่างเป็นรูปธรรม เราได้สรุปเกณฑ์หลักห้าข้อ

## เชิงกลยุทธ์

ผู้ที่พิจารณาผลเชิงกลยุทธ์เมื่อตัดสินใจควรคำนึงถึงผลระยะยาวของการตัดสินใจ เช่น ความพยายามในการดำเนินงานและการบำรุงรักษาในอนาคต

## วัดได้และจัดการได้

ผลที่ตามมาของการตัดสินใจสามารถวัดและประเมินได้เมื่อเวลาผ่านไปตามเกณฑ์ที่เป็นวัตถุวิสัย โดยเหมาะที่สุดคือเชิงตัวเลข (เช่น เกณฑ์จากสถานการณ์ของคุณลักษณะด้านคุณภาพและที่เสนอในเวิร์กช็อป 4) เนื่องจากเป็นไปไม่ได้ที่จะบันทึกการตัดสินใจโดยละเอียดทั้งหมด สถาปนิกควรจำกัดความละเอียดของการตัดสินใจไว้ที่ระดับรายละเอียดหนึ่ง (เช่น การสร้างคลาสออกแบบ) ซึ่งนำไปสู่ชุดการตัดสินใจที่ยั่งยืนกว่าและมีลิงก์การติดตามน้อยลง นอกจากนี้ การจำกัดจำนวนการพึ่งพากันระหว่างการตัดสินใจช่วยลดผลกระทบแบบลูกโซ่ของการเปลี่ยนแปลง

## บรรลุได้และสมจริง

เหตุผลในการจับคู่วิธีแก้ปัญหากับปัญหาควรเลือกอย่างเป็นรูปธรรมและทำให้ชัดเจน สถาปนิกอาจระบุว่าได้ระมัดระวังไม่ให้ออกแบบเกินหรือน้อยเกินไป (กล่าวคือ ควรใช้แนวทาง "ดีพอ")

## หยั่งรากในข้อกำหนด

การตัดสินใจควรอิงจากประสบการณ์และบริบทเฉพาะโดเมนในการออกแบบสถาปัตยกรรม นอกจากข้อกำหนดและข้อจำกัดของโครงการแล้ว ควรพิจารณาสภาพแวดล้อมของบริษัทด้วย รวมถึงทักษะปัจจุบันของทีมพัฒนา งบประมาณฝึกอบรม และกระบวนการ

## ไร้กาลเวลา

การตัดสินใจควรอิงจากประสบการณ์และความรู้ที่จะไม่ล้าสมัยในเร็ววัน สถาปนิกอาจเลือกรูปแบบหรือกลยุทธ์ทางสถาปัตยกรรมที่เป็นกลางต่อแพลตฟอร์ม
