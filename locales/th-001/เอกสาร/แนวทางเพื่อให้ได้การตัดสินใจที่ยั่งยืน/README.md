# แนวทางเพื่อให้ได้การตัดสินใจที่ยั่งยืน

<https://www.infoq.com/articles/sustainable-architectural-design-decisions/>

จากการทำงานของเรา เราได้เรียนรู้บทเรียนต่อไปนี้ ซึ่งสามารถใช้เป็นแนวทางและเกณฑ์ประเมินเพื่อให้ได้การตัดสินใจที่ยั่งยืน:

1. ใช้แนวทางแบบ lean/มินิมัลสำหรับการบันทึกการตัดสินใจเบื้องต้น

2. จัดลำดับความสำคัญและบันทึกการตัดสินใจสำคัญทั้งหมดที่เกี่ยวข้องมากพอที่จะบันทึกและทำความเข้าใจสถาปัตยกรรมเป้าหมาย

3. ขยายความการตัดสินใจที่สำคัญเป็นพิเศษในแม่แบบเต็มรูปแบบหลังจากงานเบื้องต้นเท่านั้น (กล่าวคือ เมื่อผู้ตัดสินใจพอใจกับการตัดสินใจด้านสถาปัตยกรรมที่ทำไปแล้ว และมั่นใจว่าการตัดสินใจเหล่านี้ไม่ต้องทบทวนในเร็ว ๆ นี้)

4. ใช้เวอร์ชัน lean/มินิมัลจากขั้นตอนที่ 1 เป็นสรุปของการตัดสินใจที่บันทึกในระดับความละเอียดที่เหมาะสม เพื่อให้ภาพรวมของการตัดสินใจโดยละเอียด และสำหรับการตัดสินใจที่ไม่สำคัญหรือชัดเจนในตัวเองด้วย

5. ใช้ประโยชน์จากความรู้ด้านสถาปัตยกรรมที่มีอยู่เมื่อเป็นไปได้ ไม่ว่าจะเป็นแบบจำลองนำทางหรือแหล่งอื่น ทบทวนและขยายความรู้นั้น และปรับให้เข้ากับบริบทของการตัดสินใจเฉพาะ

6. ให้แน่ใจว่ามีการสร้างลิงก์การติดตามระหว่างการตัดสินใจกับทั้งข้อกำหนดและการออกแบบสถาปัตยกรรม/โค้ด 

7. จัดให้มีการตรวจสอบความสอดคล้องอัตโนมัติเพื่อให้ลิงก์การติดตามซิงโครไนซ์อยู่หลังการเปลี่ยนแปลง จำกัดจำนวนการพึ่งพากันระหว่างการตัดสินใจกับผลงานซอฟต์แวร์อื่น

8. ใช้แนวทางเรื่องเหตุผลอย่างสม่ำเสมอและเข้มแข็ง เหตุผลเป็นส่วนที่สำคัญที่สุดของการบันทึกการตัดสินใจ เพราะให้คำตอบว่าทำไม
