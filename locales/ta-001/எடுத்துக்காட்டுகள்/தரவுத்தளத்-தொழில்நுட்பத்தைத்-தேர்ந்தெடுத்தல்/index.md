# கட்டமைப்பு முடிவு பதிவு: தரவுத்தளத் தொழில்நுட்பத்தைத் தேர்ந்தெடுத்தல்

## நிலை

ஏற்கப்பட்டது

## சூழல்

அளவிடக்கூடிய, செயல்திறன்மிக்க முறையில் தரவைச் சேமிக்கவும் மீட்டெடுக்கவும் தேவைப்படும் புதிய பயன்பாட்டை நாங்கள் வடிவமைத்து வருகிறோம். பொதுவாகப் பயன்படுத்தப்படும் மூன்று வகைத் தரவுத்தளத் தொழில்நுட்பங்களை அடையாளம் கண்டுள்ளோம்: தொடர்புடைய தரவுத்தளங்கள், ஆவணத் தரவுத்தளங்கள், நிகழ்வுத் தரவுத்தளங்கள்.

தொடர்புடைய தரவுத்தளங்கள் நிலையான வரைவுகளுடன் அட்டவணைகளில் தரவைச் சேமித்து கடுமையான தரவு ஒருமைப்பாட்டுக் கட்டுப்பாடுகளை அமல்படுத்துகின்றன. சிக்கலான தரவு உறவுகளும் பரிவர்த்தனைகளும் தேவைப்படும் பயன்பாடுகளுக்கு அவை ஏற்றவை. எடுத்துக்காட்டுகள் MySQL, PostgreSQL, Oracle.

ஆவணத் தரவுத்தளங்கள் JSON-போன்ற ஆவணங்களில் தரவைச் சேமிக்கின்றன, வரைவு இல்லாதவை. நெகிழ்வான தரவு மாதிரிகளும் கிடைமட்ட அளவிடுதலும் தேவைப்படும் பயன்பாடுகளுக்கு அவை மிகவும் பொருத்தமானவை. எடுத்துக்காட்டுகள் MongoDB, Couchbase, Amazon DynamoDB.

நிகழ்வுத் தரவுத்தளங்கள் தரவில் ஏற்படும் ஒவ்வொரு மாற்றத்தையும் கைப்பற்றி, நிகழ்வுகளின் தொடராகத் தரவைச் சேமிக்கின்றன. தணிக்கை, event sourcing, சிக்கலான தரவுச் செயலாக்கம் தேவைப்படும் பயன்பாடுகளுக்கு அவை ஏற்றவை. எடுத்துக்காட்டுகள் Apache Kafka, Apache Pulsar, AWS Kinesis.
முடிவு

எங்கள் பயன்பாட்டின் தேவைகளையும் கட்டுப்பாடுகளையும் கவனமாக மதிப்பீடு செய்த பிறகு, ஆவணத் தரவுத்தளத்தைப் பயன்படுத்த முடிவு செய்துள்ளோம்.

## நியாயம்

நாங்கள் ஆவணத் தரவுத்தளத்தைத் தேர்ந்தெடுத்ததற்குக் காரணங்கள்:

1. எங்கள் பயன்பாட்டிற்குக் காலப்போக்கில் பரிணமிக்கக்கூடிய நெகிழ்வான தரவு மாதிரி தேவை. ஆவணத் தரவுத்தளங்கள் வரைவு இல்லாத வடிவத்தில் தரவைச் சேமிக்க அனுமதிக்கின்றன, அதாவது தரவுத்தள வரைவை மாற்றாமல் புதிய புலங்களைச் சேர்க்கலாம் அல்லது இருக்கும் ஆவணங்களின் அமைப்பை மாற்றலாம்.

2. பெரிய அளவிலான தரவையும் போக்குவரத்தையும் கையாள எங்கள் பயன்பாடு கிடைமட்டமாக அளவிட வேண்டும். ஆவணத் தரவுத்தளங்கள் sharding மற்றும் பிரதியெடுப்புக்கான உள்ளமைந்த ஆதரவை வழங்குகின்றன, இது பல சேவையகங்களில் தரவை விநியோகிக்கவும் உயர் வாசிப்பு மற்றும் எழுதுதல் வீதத்தைக் கையாளவும் உதவுகிறது.

3. எங்கள் பயன்பாட்டிற்கு வேகமான, திறமையான தரவு மீட்டெடுப்பு தேவை. ஆவணத் தரவுத்தளங்கள் தரவை விரைவாகவும் திறமையாகவும் மீட்டெடுக்க உதவும் சக்திவாய்ந்த குறியீட்டு மற்றும் வினவல் திறன்களை வழங்குகின்றன.

4. எங்கள் பயன்பாட்டிற்கு சிக்கலான பரிவர்த்தனைகள் அல்லது தரவு உறவுகள் தேவையில்லை. தொடர்புடைய தரவுத்தளங்கள் தரவு ஒருமைப்பாட்டுக் கட்டுப்பாடுகளை அமல்படுத்துவதிலும் சிக்கலான பரிவர்த்தனைகளைக் கையாளுவதிலும் சிறந்து விளங்கினாலும், எங்கள் பயன்பாட்டிற்கு அத்தகைய தேவைகள் இல்லை. ஆவணத் தரவுத்தளங்கள் எங்கள் பயன்பாட்டிற்குப் போதுமான நிலைத்தன்மையையும் நீடித்து நிலைப்பதற்கான உத்தரவாதங்களையும் வழங்க முடியும்.

## விளைவுகள்

ஆவணத் தரவுத்தளத்தைத் தேர்ந்தெடுப்பதன் மூலம், நாங்கள் பயன்படுத்தத் தேர்ந்தெடுக்கும் குறிப்பிட்ட தொழில்நுட்பத்தைக் கற்றுப் புரிந்துகொள்வதில் முதலீடு செய்ய வேண்டும். கூடுதலாக, செயல்திறனையும் அளவிடுதிறனையும் அதிகப்படுத்த எங்கள் பயன்பாட்டின் தரவு மாதிரி ஆவணத் தரவுத்தளத்தின் தரவு மாதிரிக்கு நன்கு பொருந்துவதை உறுதிசெய்ய வேண்டும்.

இருப்பினும், ஆவணத் தரவுத்தளத்தைப் பயன்படுத்துவதன் நன்மைகள் செலவுகளை விட அதிகம் என்றும், எங்கள் பயன்பாட்டின் தேவைகளுக்கும் கட்டுப்பாடுகளுக்கும் இதுவே சிறந்த பொருத்தம் என்றும் நம்புகிறோம்.
