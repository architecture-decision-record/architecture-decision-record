# கட்டமைப்பு முடிவு பதிவு: Go நிரலாக்க மொழி

தலைப்பு: Go நிரலாக்க மொழியை ஏற்றல்

நிலை: ஏற்கப்பட்டது

## சூழல்

எங்கள் நிறுவனம் வலைப் பயன்பாடுகளை உருவாக்க முதன்மையாக Java நிரலாக்க மொழியைப் பயன்படுத்தி வந்துள்ளது. இருப்பினும், Java வின் சொல்வளம் மற்றும் சில கட்டமைப்புகளின் சிக்கலான தன்மை காரணமாக நாங்கள் சில சவால்களை எதிர்கொண்டு வருகிறோம். மேலும், மிகவும் திறமையான, வலுவான மேம்பாட்டிற்காக நவீன நிரலாக்க மொழிகளை ஆராய்வதில் எங்கள் குழு ஆர்வம் காட்டியுள்ளது. ஆராய்ச்சிக்குப் பிறகு, Java வில் நாங்கள் எதிர்கொள்ளும் சிக்கல்களுக்குச் சாத்தியமான தீர்வாக Go வை அடையாளம் கண்டுள்ளோம்.

## முடிவு

இனி வலைப் பயன்பாடுகளை உருவாக்க Go நிரலாக்க மொழியை ஏற்போம்.

## நியாயம்

1. **எளிமையும் படிக்கும் தன்மையும்:** Go அதன் எளிமைக்கும் சுருக்கமான தொடரியலுக்கும் அறியப்படுகிறது. இது குறியீட்டைப் படிக்கவும் எழுதவும் எளிதாக்குகிறது, எங்கள் மேம்பாட்டுச் செயல்முறையின் சிக்கலைக் குறைக்கிறது.

2. **உயர் செயல்திறனும் அளவிடுதிறனும்:** Go சேவையகத்தில் நேட்டிவ் ஆக இயங்கும் இயந்திரக் குறியீடாகத் தொகுக்கப்படுகிறது. இது Java போன்ற விளக்கப்படும் மொழிகளை விட வேகமான செயல்படுத்தல் நேரங்களுக்கும் சிறந்த செயல்திறனுக்கும் வழிவகுக்கிறது. கூடுதலாக, Go வின் ஒரே நேரச் செயல்பாட்டு மாதிரி பல கோரிக்கைகளை ஒரே நேரத்தில் கையாளுகிறது, இது மிகவும் அளவிடக்கூடியதாக ஆக்குகிறது.

3. **வலுவான சமூக ஆதரவு:** பல ஆண்டுகளாக அதன் வளர்ச்சிக்குப் பங்களித்த உருவாக்குநர்களின் துடிப்பான சமூகம் Go க்கு உள்ளது. இதன் பொருள், நாங்கள் தொடங்கவும் வலுவான பயன்பாடுகளை உருவாக்கவும் உதவும் ஏராளமான வளங்கள், நூலகங்கள், கட்டமைப்புகள் உள்ளன.

4. **நெகிழ்வுத்தன்மை:** Go வை முன்-முனை மற்றும் பின்-முனை மேம்பாடு இரண்டிற்கும் பயன்படுத்தலாம். இதன் பொருள், எங்கள் மேம்பாட்டுத் திட்டங்களுக்கு இரு பகுதிகளிலும் அதன் நன்மைகளைப் பயன்படுத்திக்கொள்ளலாம்.

## தாக்கங்கள்

1. **பயிற்சி:** எங்கள் உருவாக்குநர்கள் Go நிரலாக்க மொழியையும் அதன் நுணுக்கங்களையும் கற்க பயிற்சி பெற வேண்டும்.

2. **அனுபவம்:**  Java விலிருந்து Go க்கு மாறும்போது சில சவால்களை எதிர்கொள்ளலாம். புதிய மொழியில் எங்கள் உருவாக்குநர்கள் தேர்ச்சி பெற சிறிது நேரம் ஆகலாம்.

3. **கருவிகள்:**  Go வுக்கு உரிய புதிய கருவிகளையும் கட்டமைப்புகளையும் நாங்கள் ஏற்க வேண்டும். இருப்பினும், இந்த மாற்றத்தின் தாக்கத்தைக் குறைக்க எங்களிடம் உள்ள உள்கட்டமைப்பைப் பயன்படுத்திக்கொள்ளலாம்.

4. **விற்பனையாளர் பிணைப்பு:**  Go என்பது திறந்த மூல நிரலாக்க மொழி, எந்த விற்பனையாளர் அல்லது சேவை வழங்குநருடனும் நாங்கள் பிணைக்கப்பட மாட்டோம்.
