# Amazon Web Services க்கான கட்டமைப்பு முடிவு பதிவு

தலைப்பு: கிளவுட் உள்கட்டமைப்புக்கு Amazon Web Services ஐ ஏற்றல்

## முடிவு

பல்வேறு கிளவுட் உள்கட்டமைப்புத் தளங்களின் முழுமையான மதிப்பீட்டிற்குப் பிறகு, எங்கள் கிளவுட் உள்கட்டமைப்புத் தேவைகளுக்கு எங்கள் நிறுவனம் Amazon Web Services (AWS) ஐ ஏற்க முடிவு செய்யப்பட்டுள்ளது.

## பின்னணி

எங்கள் நிறுவனம் வேகமாக வளர்ந்து வருகிறது, எங்கள் வணிகத்தின் கோரிக்கைகளைப் பூர்த்தி செய்ய நம்பகமான, அளவிடக்கூடிய கிளவுட் உள்கட்டமைப்பு தேவை. பல கிளவுட் உள்கட்டமைப்பு வழங்குநர்களைப் பரிசீலித்த பிறகு, எங்கள் தற்போதைய மற்றும் எதிர்காலத் தேவைகளைப் பூர்த்தி செய்ய மிகவும் பொருத்தமான சேவைகளின் வரம்பை AWS வழங்குகிறது என்று முடிவு செய்யப்பட்டது.

## பரிசீலனைகள்

நம்பகமானவை, திறமையானவை என நிரூபிக்கப்பட்ட பல கிளவுட் உள்கட்டமைப்பு வழங்குநர்கள் சந்தையில் உள்ளனர். இருப்பினும், AWS எங்கள் தேவைகளைப் பூர்த்தி செய்யும் விரிவான சேவைகளை மட்டும் வழங்கவில்லை, பரந்த வாடிக்கையாளர் தளமும் வெற்றிகரமான வரிசைப்படுத்தல்களின் சாதனைப் பதிவும் கொண்டுள்ளது. எங்கள் குழு தளத்துடன் திறம்பட வேலை செய்ய முடியும் என்பதை உறுதிசெய்ய, ஆதரவு மற்றும் பயிற்சி வளங்களின் பரந்த வரம்பையும் AWS வழங்குகிறது.

மேலும், AWS உலகெங்கிலும் பல்வேறு பிராந்தியங்களில் தரவு மையங்களுடன் விரிவான உலகளாவிய இருப்பைக் கொண்டுள்ளது. இது எங்கள் தரவு பாதுகாப்பாக இருப்பதையும், எங்கள் பயன்பாடுகளும் சேவைகளும் மிகவும் கிடைக்கும் தன்மையுடன் இருக்கும் என்பதையும் உறுதிசெய்கிறது. AWS எங்கள் வணிகத்துக்கு முக்கியமான வலுவான பாதுகாப்புக் கட்டமைப்பையும் கொண்டுள்ளது.

கடைசியாக, AWS பயன்படுத்தியதற்கு மட்டும் பணம் செலுத்தும் மாதிரியை வழங்குகிறது, இது தேவைக்கேற்ப எங்கள் உள்கட்டமைப்பை அளவிடும் நெகிழ்வுத்தன்மையை வழங்குகிறது. இதன் பொருள், நாங்கள் பயன்படுத்தியவற்றுக்கு மட்டுமே கட்டணம் வசூலிக்கப்படும், இது எங்கள் செலவுகளை உகந்ததாக்கவும் வணிகத்தின் பிற பகுதிகளில் முதலீடு செய்யவும் அனுமதிக்கிறது.

## முடிவு

செய்யப்பட்ட மதிப்பீடுகளையும் AWS வழங்கும் நன்மைகளையும் அடிப்படையாகக் கொண்டு, எங்கள் கிளவுட் உள்கட்டமைப்புத் தேவைகளுக்கு AWS ஏற்கப்படும் என்று முடிவு செய்யப்பட்டுள்ளது.

## விளைவுகள்

AWS ஐ ஏற்பதற்கு எங்கள் குழுக்கள் தளத்துடன் பரிச்சயமாகி அதைத் திறம்படப் பயன்படுத்த முடியும் என்பதை உறுதிசெய்ய பயிற்சி தேவைப்படலாம். எங்கள் தற்போதைய உள்கட்டமைப்பை AWS தளத்திற்கு நகர்த்த சில ஆரம்பச் செலவுகளும் இருக்கலாம்.

## உரிமை

AWS இன் திறம்பட பயன்பாட்டை உறுதிசெய்வதும் தொடர்புடைய ஆபத்துகளை நிர்வகிப்பதும் கிளவுட் உள்கட்டமைப்புக் குழுவின் அதிகார வரம்புக்குள் இருக்கும். எழும் எந்தச் சிக்கல்களும் இந்தக் குழுவால் தீர்க்கப்பட வேண்டும்.

## மதிப்பாய்வு

AWS ஐ ஏற்கும் முடிவு, அது தொடர்ந்து எங்கள் தேவைகளைப் பூர்த்தி செய்கிறதா, தளத்தின் நன்மைகள் முழுமையாக உணரப்படுகின்றனவா என்பதை உறுதிசெய்ய ஆண்டுதோறும் மதிப்பாய்வு செய்யப்படும்.
