# கட்டமைப்பு முடிவு பதிவு: Ruby on Rails கட்டமைப்பு

## சூழல்

- நிறுவனம் சிக்கலான வணிகத் தர்க்கத்துடனும் மூன்றாம் தரப்புச் சேவைகளுடன் பல ஒருங்கிணைப்புகளுடனும் வலைப் பயன்பாட்டை உருவாக்கி வருகிறது.

- குழுவுக்கு Ruby on Rails உடன் வலைப் பயன்பாடுகளை உருவாக்கிய அனுபவம் உள்ளது.

- விரைவான மேம்பாடு, அளவிடுதிறன், பராமரிப்புத்திறனை ஊக்குவிக்கும் வலைக் கட்டமைப்பைத் தேர்ந்தெடுக்க வேண்டிய தேவை உள்ளது.

## முடிவு

- வலைப் பயன்பாட்டை உருவாக்குவதற்கான கட்டமைப்பாக Ruby on Rails ஐப் பயன்படுத்தவும்.

## நியாயப்படுத்தல்

- Ruby on Rails என்பது சிக்கலான வலைப் பயன்பாடுகளை உருவாக்குவதில் தனது செயல்திறனை நிரூபித்துள்ள முதிர்ந்த, நிலையான, பரவலாக ஏற்றுக்கொள்ளப்பட்ட வலைக் கட்டமைப்பு.

- கட்டமைப்பு Model-View-Controller (MVC) கட்டமைப்பு வடிவத்தைப் பின்பற்றுகிறது, இது கவலைகளைப் பிரிப்பதை ஊக்குவித்து, குறியீட்டு மறுபயன்பாட்டையும் பராமரிப்புத்திறனையும் மேம்படுத்துகிறது.

- தரவுத்தளத் தொடர்புகளுக்கு ActiveRecord மற்றும் மின்னஞ்சல் மேலாண்மைக்கு ActionMailer போன்ற பல உள்ளமைந்த அம்சங்களை Rails வழங்குகிறது, இது மேம்பாட்டு நேரத்தைச் சேமித்து குறியீட்டை எளிமைப்படுத்தும்.

- கட்டமைப்புக்குப் பெரிய, செயலில் உள்ள சமூகம் உள்ளது, செயல்பாட்டை மேம்படுத்தவும் பொதுவான சிக்கல்களைத் தீர்க்கவும் பல மறுபயன்பாட்டுத் தொகுதிகளும் செருகுநிரல்களும் கிடைக்கின்றன.

- Ruby on Rails சோதனை-இயக்க மேம்பாடு (TDD) மற்றும் நடத்தை-இயக்க மேம்பாடு (BDD) ஆகியவற்றை ஆதரிக்கிறது, இது உருவாக்குநர்கள் தங்கள் குறியீட்டிற்கு தானியங்கிச் சோதனைகளை எழுத உதவி, அது எதிர்பார்த்தபடி செயல்படுவதை உறுதிசெய்து பிழைகளையும் பின்னடைவுகளையும் குறைக்கிறது.

- Ruby என்பது உருவாக்குநர் உற்பத்தித்திறனையும் குறியீட்டுப் படிக்கும் தன்மையையும் ஊக்குவிக்கும் உயர்நிலை மொழி, மேலும் மூன்றாம் தரப்புச் சேவைகள் மற்றும் API களின் பரந்த வரம்புடன் ஒருங்கிணைக்கும் சக்திவாய்ந்த பிணைப்பு மொழியாக செயல்படுகிறது.

## விளைவுகள்

- கட்டமைப்பின் நன்மைகளை அதிகப்படுத்த, வலைப் பயன்பாட்டின் கட்டமைப்பும் வடிவமைப்பும் Rails மரபுகளையும் சிறந்த நடைமுறைகளையும் பின்பற்றுவதை குழு உறுதிசெய்ய வேண்டும்.

- உருவாக்குநர்களுக்கு Ruby மொழி மற்றும் Rails கட்டமைப்பைப் பற்றிய நல்ல புரிதல் தேவை, ஆனால் Rails ஆவணமும் சமூகமும் வழிகாட்டுதலையும் ஆதரவையும் வழங்க முடியும்.

- Ruby மற்றும் Rails க்குப் புதிய உருவாக்குநர்களுக்குக் கற்றல் வளைவு இருக்கலாம், ஆனால் கட்டமைப்பின் நன்மைகள் பயிற்சி மற்றும் இணைத்தலில் முதலீட்டை நியாயப்படுத்தலாம்.

- குழு பயன்பாட்டின் செயல்திறனையும் அளவிடுதிறனையும் கண்காணிக்க வேண்டும், மேலும் பெரிய அளவிலான தரவையும் போக்குவரத்தையும் கையாள தரவுத்தளக் கேள்விகளை நுணுக்கமாகச் சரிசெய்து தற்காலிகச் சேமிப்பை உகந்ததாக்க வேண்டியிருக்கலாம்.
