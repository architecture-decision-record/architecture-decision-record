# கட்டமைப்பு முடிவு பதிவு: Microsoft Azure கிளவுட் உள்கட்டமைப்பு" 

முடிவுத் தலைப்பு: எங்கள் நிறுவனத்தின் கிளவுட் உள்கட்டமைப்பாக Microsoft Azure ஐ ஏற்றல்

முடிவெடுத்தவர்: தலைமைத் தகவல் அதிகாரி

தேதி: 2021-10-15

நிலை: அங்கீகரிக்கப்பட்டது

## பின்னணி

நிறுவனம் பாரம்பரிய உள்வளாக உள்கட்டமைப்பிலிருந்து கிளவுட் உள்கட்டமைப்புக்கு இடம்பெயரத் திட்டமிட்டுள்ளது. இதை அடைய, நிறுவனம் Amazon Web Services (AWS), Google Cloud Platform (GCP), Microsoft Azure, IBM Cloud போன்ற பல கிளவுட் சேவை வழங்குநர்களை மதிப்பிட்டுள்ளது. ஒவ்வொரு வழங்குநருக்கும் அவரவருக்கான அம்சங்கள், நன்மைகள், விலை அமைப்பு உள்ளன. விரிவான பகுப்பாய்விற்குப் பிறகு, எங்கள் நிறுவனத்துக்கு Microsoft Azure மிகவும் பொருத்தமான விருப்பம் என்று முடிவு செய்யப்பட்டது.

## முடிவு

எங்கள் நிறுவனத்தின் கிளவுட் உள்கட்டமைப்பாக Microsoft Azure ஐ ஏற்கவும்.

## நியாயம்

Microsoft Azure ஐ ஏற்பதற்கான காரணங்கள் பின்வருமாறு:

1. விரிவான சேவைகள்: Azure உள்கட்டமைப்பு-ஒரு-சேவையாக (IaaS) முதல் மென்பொருள்-ஒரு-சேவையாக (SaaS) மற்றும் தளம்-ஒரு-சேவையாக (PaaS) வரை கிளவுட் சேவைகளின் முழு வரம்பையும் வழங்குகிறது. சேமிப்பு, கணினி, வலையமைப்பு, பகுப்பாய்வு போன்ற நிறுவனத்தின் தேவைகளைத் தீர்க்க Azure சேவைகளைப் பயன்படுத்த இது எங்களை அனுமதிக்கிறது.

2. அளவிடுதிறனும் நெகிழ்வுத்தன்மையும்: Azure மூலம், எங்கள் வணிகத் தேவைகளுக்கு ஏற்ப வளங்களை எளிதாக அதிகரிக்கவோ குறைக்கவோ முடியும். இயக்க முறைமை, நிரலாக்க மொழி, கட்டமைப்புகளைத் தேர்ந்தெடுப்பதிலும் Azure நெகிழ்வுத்தன்மையை வழங்குகிறது.

3. பாதுகாப்பும் இணக்கமும்: Azure ISO, SOC, HIPAA, PCI DSS போன்ற பல தொழில் தரநிலைகளுடன் இணங்குவதால், அது உயர்மட்டப் பாதுகாப்பையும் இணக்கத்தையும் வழங்குகிறது. வலைப் பாதுகாப்புக் குழுக்கள், ஃபயர்வால்கள், DDoS பாதுகாப்பு போன்ற மேம்பட்ட பாதுகாப்பு அம்சங்களையும் Azure வழங்குகிறது.

4. கலப்பு கிளவுட்: Azure தடையற்ற கலப்பு கிளவுட் அனுபவத்தை வழங்குகிறது, நிறுவனங்கள் தங்கள் உள்வளாக உள்கட்டமைப்பை Azure உடன் இணைக்க உதவுகிறது. இது பணிச்சுமைகளை கிளவுடுக்கு நகர்த்துவதை எளிதாக்குவதோடு, தரவை எங்கே சேமிப்பது என்பதைத் தேர்ந்தெடுக்கும் நெகிழ்வுத்தன்மையையும் வழங்குகிறது.

5. செலவு-திறன்: Azure பயன்படுத்தியதற்கு மட்டும் பணம் செலுத்தும் விலை மாதிரியை வழங்குகிறது, அதாவது பயன்படுத்தப்படும் வளங்களுக்கு மட்டுமே நாங்கள் பணம் செலுத்துகிறோம். பாரம்பரிய உள்வளாக உள்கட்டமைப்புடன் ஒப்பிடும்போது செலவுகளைச் சேமிக்க இது உதவுகிறது.

## முடிவுரை

எங்கள் நிறுவனத்தின் கிளவுட் உள்கட்டமைப்பாக Microsoft Azure ஐ ஏற்பது எங்கள் வணிகத் தேவைகளுடன் ஒத்துப்போகிறது; அளவிடுதிறன், நெகிழ்வுத்தன்மை, பாதுகாப்பு, செலவு-திறன் போன்ற பல நன்மைகளை வழங்குகிறது. எனவே, எங்கள் கிளவுட் உள்கட்டமைப்பாக Azure ஐ ஏற்கப் பரிந்துரைக்கப்படுகிறது.
