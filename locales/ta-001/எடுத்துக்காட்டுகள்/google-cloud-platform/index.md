# Google Cloud Platform க்கான கட்டமைப்பு முடிவு பதிவு

## சூழல்

Google Cloud Platform (GCP) என்பது கணினி, சேமிப்பு, வலையமைப்புத் தீர்வுகள் உட்பட பல்வேறு கிளவுட் சேவைகளை வழங்கும் முக்கியமான கிளவுட் கணினித் தளம். எங்கள் நிறுவனத்துக்கு GCP-அடிப்படையிலான உள்கட்டமைப்பை உருவாக்கி நடைமுறைப்படுத்த எடுக்கப்பட்ட கட்டமைப்பு முடிவுகளை ஆவணப்படுத்துவதே இந்த ADR இன் நோக்கம்.

## முடிவு

எங்கள் பயன்பாட்டுக்கான கிளவுட் உள்கட்டமைப்பாக Google Cloud Platform ஐப் பயன்படுத்த எங்கள் நிறுவனம் முடிவு செய்துள்ளது. இந்த முடிவுக்கான முதன்மைப் பரிசீலனைகள்:

   - செலவு-திறன்

   - அளவிடுதிறன்

   - நம்பகத்தன்மை

   - நெகிழ்வுத்தன்மை

## தேர்வுகள்

எங்கள் தேவைகளைப் பூர்த்தி செய்ய GCP யிலிருந்து பின்வரும் சேவைகள் தேர்ந்தெடுக்கப்பட்டுள்ளன:

   - மெய்நிகர் இயந்திரங்கள் மற்றும் கணினி வளங்களுக்கு Compute Engine

   - பொருள் சேமிப்பு மற்றும் கோப்பு ஹோஸ்டிங்கிற்கு Cloud Storage

   - நிர்வகிக்கப்படும் தரவுத்தளச் சேவைக்கு Cloud SQL

   - பயன்பாட்டு உருவாக்கம் மற்றும் ஹோஸ்டிங்கிற்கு Firebase

## நியாயம்

   - செலவு-திறன்: பிற கிளவுட் தளங்களுடன் ஒப்பிடும்போது Google Cloud Platform மிகவும் செலவு-திறன் கொண்டது, இது வரவுசெலவுக் கட்டுப்பாடுகள் உள்ள நிறுவனங்களுக்கு ஈர்க்கக்கூடிய விருப்பமாக அமைகிறது.

   - அளவிடுதிறன்: GCP இன் எளிதில் அளவிடக்கூடிய உள்கட்டமைப்பு எந்த அளவு போக்குவரத்தையும் நிகழ்நேரத்தில் கையாள உதவுகிறது.

   - நம்பகத்தன்மை: GCP இன் நிர்வகிக்கப்படும் சேவைகள் தானியங்கி காப்புப் பிரதிகள் மற்றும் பேரிடர் மீட்புத் திறன்களுடன் உயர் நம்பகத்தன்மையை வழங்குகின்றன, இது வளங்கள் மற்றும் தரவின் உயர் கிடைப்பை உறுதிசெய்கிறது.

   - நெகிழ்வுத்தன்மை: இந்தத் தளம் AI, தரவுப் பகுப்பாய்வு, IoT போன்ற பல்வேறு களங்களில் பல்வேறு கருவிகளையும் சேவைகளையும் வழங்குகிறது, இது மிகவும் பல்துறை ஆக்குகிறது.

## விளைவுகள்

Google Cloud Platform க்கு இடம்பெயர்வது GCP சேவைகளில் எங்கள் குழுக்களுக்குப் பயிற்சி அளிப்பது, தேர்ந்தெடுக்கப்பட்ட சேவைகளுடன் இணக்கமாக இருக்க பயன்பாட்டை மறுகட்டமைப்பது, GCP சேவைகளை ஆதரிக்க உள்கட்டமைப்புக் குறியீட்டைப் புதுப்பிப்பது ஆகியவற்றைத் தேவைப்படுத்தும். இருப்பினும், இடம்பெயர்வு முடிந்தவுடன், எங்கள் பயன்பாட்டை ஹோஸ்ட் செய்ய மிகவும் அளவிடக்கூடிய, நம்பகமான, செலவு-திறன் கொண்ட உள்கட்டமைப்பு இருக்கும் என எதிர்பார்க்கப்படுகிறது. மேலும், GCP யில் வளங்களை வழங்குவதற்கான தொடர் செலவுகளை நாங்கள் நிர்வகிக்க வேண்டும்.

## முடிவுரை

செலவு-திறன், அளவிடுதிறன், நம்பகத்தன்மை, நெகிழ்வுத்தன்மை ஆகியவற்றால் Google Cloud Platform எங்கள் கிளவுட் உள்கட்டமைப்புக்கு சிறந்த தேர்வு. தேர்ந்தெடுக்கப்பட்ட சேவைகளைப் பயன்படுத்துவதன் மூலம், எங்கள் பயன்பாட்டிற்கு மிகவும் கிடைக்கக்கூடிய, வலுவான உள்கட்டமைப்பை வழங்க முடியும்.
