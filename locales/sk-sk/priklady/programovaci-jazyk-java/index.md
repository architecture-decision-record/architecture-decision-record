### Pozadie

Náš projekt vyžadoval jazyk, ktorý dokáže poskytnúť silné bezpečnostné funkcie, zvládať súbežnosť, podporovať veľké kódové základne a byť dostatočne univerzálny na splnenie našich budúcich požiadaviek na rast. Pred rozhodnutím pre Javu sme vyhodnotili niekoľko jazykov a zvážili ich silné stránky a obmedzenia.

### Úvahy

1. **Bezpečnosť:**  Java poskytuje vynikajúce bezpečnostné funkcie prostredníctvom svojich dobre definovaných bezpečnostných politík a riadenia prístupu. Zahŕňa aj funkcie ako overovanie bajtkódu, ktoré pomáha zabrániť spusteniu škodlivého softvéru v systéme.

2. **Súbežnosť:**  Java má vstavanú podporu viacvláknového spracovania, ktoré aplikáciám umožňuje vykonávať niekoľko úloh súčasne. Táto funkcia robí z Javy vynikajúcu voľbu pre vývoj veľkých, zložitých aplikácií s viacerými funkciami a funkcionalitami.

3. **Veľké kódové základne:**  Java podporuje objektovo orientované programovanie, vďaka čomu je vhodnou voľbou pre vývoj veľkých kódových základní. Jej modulárna povaha a používanie vzorov zapuzdrenia a abstrakcie ďalej uľahčujú proces vývoja softvéru.

4. **Univerzálnosť:**  Java je univerzálna a poskytuje možnosť používať širokú škálu knižníc a frameworkov, vďaka čomu je vynikajúcou voľbou pre webové aj podnikové aplikácie.

### Výsledok rozhodnutia

Rozhodli sme sa použiť programovací jazyk Java pre náš projekt vzhľadom na jeho bezpečnostné funkcie, podporu súbežnosti, schopnosť zvládať veľké kódové základne a univerzálnosť. Toto rozhodnutie je v súlade s požiadavkami nášho projektu a veríme, že výber Javy zabezpečí jeho úspech.
