# Argerdh kovskrifow dyberth arkitektoryeth AWS

https://docs.aws.amazon.com/prescriptive-guidance/latest/architectural-decision-records/adr-process.html

Kovskrif dyberth arkitektoryeth (ADR) yw dokument a displeg dewis a wra an tim a-dro dhe gebmys poesek a'n arkitektoryeth medhelweyth may whrons towlenna drehevel. Pub ADR a displeg an dyberth arkitektoryeth, y gettesten, ha'y sewyansow. Studhow a'n jeves ADRyow ha rakhenna i a sew bywnans. Rag ensampel ADR, gwelewgh an appendix.

An argerdh ADR a dhre kuntelles a govskrifow dyberth arkitektoryeth. An kuntelles ma a wra an lyver dybyrthow. An lyver dybyrthow a re kettesten an towl hag ynwedh aswonnvos manylys a weythrys ha disinyans. Esely an towl a wel yn skav an penngevyans a bub ADR rag kavos dre-wel a gettesten an towl. I a red an ADRyow rag mos downha yn gweythrysyow ha dewisyow disinyans an towl.

Pan wra an tim degemmeres ADR, ev a dheu heb chanj. Mar kevir godhvos nowydh a dhaskor dyberth dyffrans, an tim a brof ADR nowydh. Pan wra an tim degemmeres an ADR nowydh, ev a gemmer le an ADR kyns.

## Skope an argerdh ADR

Esely an towl a dal gwul ADR rag pub dyberth poesek yn arkitektoryeth a darth an towl po produkt medhelweyth, a-rag y'n lyst ma (Richards ha Ford 2020):

* Strokturyeth (rag ensampel, patronow avel mikro-servyssyow)

* Othommow nag yw gweythresek (sawder, hegorrder uhel, ha godhevyans fal)

* Dyffendyansow (junyans a gomponennow)

* Ynterfasow (APIs ha kevambosow dyllys)

* Teknegow drehevel (lyvervaow, framweythow, toulys, hag argerdhow)

* Othommow gweythresek ha nag yw gweythresek yw an ynbusow moyha ollgemmyn a'n argerdh ADR.


## Kenwyns ADR

Pan aswonn an tim othom a ADR, esel a'n tim a dhallath skrifa an ADR herwydh skantlyn oll-an-towl. (Gwelewgh an urdhyans ADR GitHub rag skantlynyow ensampel.) An skantlyn a esya gwruthyl ADR ha surha may talgh an ADR oll an godhvos ledhwas. Dhe'n lyha, pub ADR a dal diskwedha kettesten an dyberth, an dyberth y honan, ha sewyansow an dyberth rag an towl ha'y dhelivrow. (Rag ensamplow a'n rannow ma, gwelewgh an appendix.) Unn a'n rannow moyha nerthek a strokturyeth ADR yw may fok ev war ressons an dyberth yn le fatel wrug an tim y weythrys. Konvedhes perag y wrug an tim an dyberth a wra es dhe esely erell an tim y dhegemmeres, ha lett ytho arkitektoryoryon erell na veu ynwedh y'n argerdh dyberth dhe dhisplegya an dyberth.


## Argerdh degemmeres ADR

Pub esel a'n tim a hyll gwul ADR, mes an tim a dal selya styryans perghennedh rag ADR. Pub awtour yw perghen ADR a dal gwitha ha kesklapa kenwyns an ADR yn bewek. Rag displegya an perghennedh ma, an gidys ma a elwir awtours ADR perghennow ADR y'n rannow a sew. Esely erell an tim a hyll pup-prys kevri dhe ADR. Mar chanj kenwyns ADR kyns ys an tim y dhegemmeres, an perghen a dal gwarthya an chanjyow ma.

Wosa may whra an tim aswonn dyberth arkitektoryeth ha'y berghen, perghen an ADR a re an ADR y'n studh **Profys** orth dalleth an argerdh. ADRyow y'n studh Profys yw parys rag dehwelans.

Perghen an ADR a dhalleth ytho an argerdh dehwelans rag an ADR. Mynnans an argerdh dehwelans ADR yw dybarth mar teg an tim degemmeres an ADR, mar tegys y'n othom a ober arta, po mar tegys y'n refusya. An tim an towl, an perghen ynno, a dhehwel an ADR. An kyfeth dehwelans a dal dalleth gans termyn aswonnek rag redya an ADR. Dhe'n etek, 10 bys yn 15 mynysenn a dal lowr. Y'n termyn ma, pub esel a'n tim a red an dokument hag a worr gorholyow ha govynnow rag merkya tebel dyvlas. Wosa an dhegres dehwelans, perghen an ADR a red yn ughel hag a gews a bub gorholyow gans an tim.

Mar kyv an tim poyntys-ober rag gwellhe an ADR, studh an ADR a bys **Profys**. Perghen an ADR a worr an oberow yn ger, hag, yn kesober gans an tim, a gevri trosyer dhe bub ober. Pub esel a'n tim a hyll kevri hag a dhyghtya an poyntys-ober. Yw dyghtyans perghen an ADR dh'y dhasfurvya termyn an argerdh dehwelans.

An tim a hyll ynwedh dybarth refusya an ADR. Y'n kas ma, perghen an ADR a re skila rag an refusyans rag lett kows a-dro dhe'n keth tebel y'n termyn a dheu. An perghen a chanj studh an ADR dhe **Refusys**.

Mar degemmer an ADR gans an tim, an perghen a re merkyer prys, gwersyon, ha rol a'n gerensyon. An perghen a nowydh ytho an studh dhe **Degemmerys**.

ADRyow ha'n lyver dybyrthow i a wra a dhisplek dybyrthow gwrys gans an tim hag a re istori a oll an dybyrthow. An tim a usya an ADRyow avel dyskrifa dres dehwelansow kod hag arkitektoryeth pe le bynner possybyl. Dhe-vebyn dhe wul dehwelansow kod, tasklow disinyans, ha tasklow gweythrys, esely an tim a dal kusulya ADRyow rag dybyrthow strateji rag an produkt.

Avel usadow da, pub chanj medhelweyth a dal mos dre dehwelansow kes-gowetha ha bos othom a'n lyha unn gwarthyans. Y'n dehwelans kod, dehwelor kod a hyll kavos chanjyow a dorr unn po moy ADR. Y'n kas ma, an dehwelor a wovyn orth awtour an chanj kod nowydhhe an kod, ha rannas kevrenn dhe'n ADR. Pan wra an awtour nowydhhe an kod, ev yw gwarthys gans an dehwelors kes-gowetha ha junys y'n pennfenten kod.


## Argerdh dehwelans ADR

An tim a dal tyrri ADRyow avel dokumentys heb chanj wosa may whra an tim aga degemmeres po aga refusya. Chanjyow dhe ADR a vo a res gwul ADR nowydh, selya argerdh dehwelans rag an ADR nowydh, ha gwarthya an ADR. Mar degemmer an ADR nowydh gans an tim, an perghen a dal chanjya studh an ADR koth dhe **Gorrys yn le**.
