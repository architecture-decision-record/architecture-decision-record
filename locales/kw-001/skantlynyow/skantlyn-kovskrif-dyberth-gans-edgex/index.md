## Lyver chanjyow

Dydhyas yw gevenn ISO 8601 (YYYY-MM-DD).

PR yw an pull request a brofas an chanj, ow keworra derivadow avel an diffrans, kevrerysyon, ha dehwelors.

## Disinyans profys

- gwassanethow/modulys nowydh dhe vos gorrys

- drehedhyans model ha DTO (chanjyow/ystynnansow/dilettyansow)

- drehedhyans API (chanjyow/ystynnansow/dilettyansow)

- drehedhyans kefrysyans ollgemmyn (selyans rannow nowydh, chanjyow/ystynnansow/dilettyansow)

- drehedhyans devops
