# [000] ಶೀರ್ಷಿಕೆ
*ಸುಲಭ ಉಲ್ಲೇಖ ಮತ್ತು ಪಟ್ಟಿ ಮಾಡುವಿಕೆಗಾಗಿ ಪ್ರತಿ ADR ಗೂ ಒಂದು ಸಂಖ್ಯೆ ನೀಡಿ* \
*ಗಮನಿಸಿ: ಇಟಾಲಿಕ್ ಪಠ್ಯವೆಲ್ಲವೂ ಸುಳಿವುಗಳನ್ನು ನೀಡುತ್ತದೆ ಮತ್ತು ಉತ್ಪಾದನೆಗೆ ಮೊದಲು ತೆಗೆದುಹಾಕಬೇಕು*

## ಸ್ಥಿತಿ - ಕರಡು / ಸಕ್ರಿಯ / [000] ಇಂದ ಬಳಕೆಯಿಂದ ತೆಗೆದುಹಾಕಲಾಗಿದೆ / [000] ಅನ್ನು ಅತಿಕ್ರಮಿಸುತ್ತದೆ

## ಸಂದರ್ಭ
*ಈ ADR ಪರಿಹರಿಸಲು ಉದ್ದೇಶಿಸಿರುವ ಸಮಸ್ಯೆ(ಗಳನ್ನು) ಮತ್ತು ಆ ಸಮಸ್ಯೆಗಳು ಏಕೆ ಅಸ್ತಿತ್ವದಲ್ಲಿವೆ ಎಂಬುದನ್ನು ಸಂಕ್ಷಿಪ್ತವಾಗಿ ವಿವರಿಸಿ.*

## ನಿರ್ಧರಿಸಿದ ವಿಧಾನ
*ಮಾಡಲಾದ / ಮಾಡಲಿರುವ ವಾಸ್ತುಶಿಲ್ಪದ ದೃಷ್ಟಿಯಿಂದ ಮಹತ್ವದ ನಿರ್ಧಾರವನ್ನು ವಿವರಿಸಿ ಮತ್ತು ಸಂದರ್ಭ ವಿಭಾಗದಲ್ಲಿ ರೂಪಿಸಿದ ಸಮಸ್ಯೆಗಳನ್ನು ಅದು ಹೇಗೆ ಪರಿಹರಿಸುತ್ತದೆ ಎಂಬುದನ್ನು ವಿವರಿಸಿ.*

## ಪರಿಣಾಮಗಳು
*ವ್ಯವಸ್ಥೆಯ ವಾಸ್ತುಶಿಲ್ಪ ಲಕ್ಷಣಗಳು ಮತ್ತು ಕಾರ್ಯಾತ್ಮಕ ಅವಶ್ಯಕತೆಗಳ ಮೇಲೆ ಈ ನಿರ್ಧಾರದ ಪ್ರಭಾವ ಏನು?*

## ಆಡಳಿತ
*ಈ ನಿರ್ಧಾರದ ಫಲಿತಾಂಶಗಳನ್ನು ಹೇಗೆ ಮೇಲ್ವಿಚಾರಣೆ ಮಾಡಲಾಗುತ್ತದೆ?* \
*ಈ ನಿರ್ಧಾರದ ಅನುಸರಣೆಯನ್ನು ಹೇಗೆ ಖಚಿತಪಡಿಸಲಾಗುತ್ತದೆ?*

## ಆಯ್ಕೆಗಳ ವಿಶ್ಲೇಷಣೆ
*ಅನ್ವಯಿಸಿದರೆ, ಈ ದಾಖಲೆಯಲ್ಲಿ ಮಾಡಿದ ನಿರ್ಧಾರಕ್ಕೆ ಬರಲು ನಡೆಸಿದ ಯಾವುದೇ ಸಾಧಕ-ಬಾಧಕ ಹೊಂದಾಣಿಕೆ ವಿಶ್ಲೇಷಣೆಯನ್ನು ಸೇರಿಸಿ ಅಥವಾ ಅದಕ್ಕೆ ಲಿಂಕ್ ನೀಡಿ.*

### ಸೂಚಿ
*ಐಚ್ಛಿಕ: ಧನಾತ್ಮಕ ಮತ್ತು ಋಣಾತ್ಮಕ ಸಾಧಕ-ಬಾಧಕ ಹೊಂದಾಣಿಕೆಗಳನ್ನು ತ್ವರಿತವಾಗಿ ಗುರುತಿಸಲು ಸಹಾಯ ಮಾಡುವ ದೃಶ್ಯ ಸಾಧನಗಳನ್ನು ಪಾಲುದಾರರಿಗೆ ಒದಗಿಸಿ - ಉದಾಹರಣೆಗೆ ಧನಾತ್ಮಕ ಅಥವಾ ಋಣಾತ್ಮಕ ಪೂರ್ವಪ್ರತ್ಯಯಗಳೊಂದಿಗೆ ಸರಳ ಟ್ರಾಫಿಕ್-ಲೈಟ್ ಹೈಲೈಟ್‌ಗಳು.*

<span style="background-color:#4bce97; color:black;">ಹಸಿರು</span> ಹಿನ್ನೆಲೆಯು ಉತ್ತಮ ಹೊಂದಾಣಿಕೆಯನ್ನು ಸೂಚಿಸುತ್ತದೆ, <span style="background-color:#f1c232; color:black;">ಅಂಬರ್</span> ಮೂಲಕ ಹದಗೆಡುತ್ತಾ, <span style="background-color:#e06666; color:black;">ಕೆಂಪು</span> ಅತ್ಯಂತ ಕೆಟ್ಟ ಹೊಂದಾಣಿಕೆ. \
\+ ಧನಾತ್ಮಕ ಪ್ರಭಾವದ ಕಾಮೆಂಟ್ ಅನ್ನು ಸೂಚಿಸುತ್ತದೆ \
\- ಋಣಾತ್ಮಕ ಪ್ರಭಾವದ ಕಾಮೆಂಟ್ ಅನ್ನು ಸೂಚಿಸುತ್ತದೆ

### ಕಾರ್ಯಾತ್ಮಕವಲ್ಲದ ಅವಶ್ಯಕತೆಗಳು
