# Google Cloud Platform ಗಾಗಿ ವಾಸ್ತುಶಿಲ್ಪ ನಿರ್ಧಾರ ದಾಖಲೆ

## ಸಂದರ್ಭ

Google Cloud Platform (GCP) ಎಂಬುದು ಕಂಪ್ಯೂಟಿಂಗ್, ಸಂಗ್ರಹಣೆ ಮತ್ತು ನೆಟ್‌ವರ್ಕಿಂಗ್ ಪರಿಹಾರಗಳು ಸೇರಿದಂತೆ ವಿವಿಧ ಕ್ಲೌಡ್ ಸೇವೆಗಳನ್ನು ನೀಡುವ ಪ್ರಮುಖ ಕ್ಲೌಡ್ ಕಂಪ್ಯೂಟಿಂಗ್ ವೇದಿಕೆ. ನಮ್ಮ ಸಂಸ್ಥೆಗಾಗಿ GCP ಆಧಾರಿತ ಮೂಲಸೌಕರ್ಯವನ್ನು ಅಭಿವೃದ್ಧಿಪಡಿಸಲು ಮತ್ತು ಅನುಷ್ಠಾನಗೊಳಿಸಲು ಮಾಡಿದ ವಾಸ್ತುಶಿಲ್ಪ ನಿರ್ಧಾರಗಳನ್ನು ದಾಖಲಿಸುವುದು ಈ ADR ನ ಉದ್ದೇಶ.

## ನಿರ್ಧಾರ

ನಮ್ಮ ಸಂಸ್ಥೆಯು ತನ್ನ ಅಪ್ಲಿಕೇಶನ್‌ಗಾಗಿ Google Cloud Platform ಅನ್ನು ಕ್ಲೌಡ್ ಮೂಲಸೌಕರ್ಯವಾಗಿ ಬಳಸಲು ನಿರ್ಧರಿಸಿದೆ. ಈ ನಿರ್ಧಾರದ ಪ್ರಾಥಮಿಕ ಪರಿಗಣನೆಗಳು:

   - ವೆಚ್ಚ-ಪರಿಣಾಮಕಾರಿತ್ವ

   - ವಿಸ್ತರಣೀಯತೆ

   - ವಿಶ್ವಾಸಾರ್ಹತೆ

   - ನಮ್ಯತೆ

## ಆಯ್ಕೆಗಳು

ನಮ್ಮ ಅವಶ್ಯಕತೆಗಳನ್ನು ಪೂರೈಸಲು GCP ಯ ಈ ಕೆಳಗಿನ ಸೇವೆಗಳನ್ನು ಆಯ್ಕೆ ಮಾಡಲಾಗಿದೆ:

   - ವರ್ಚುವಲ್ ಮಷಿನ್‌ಗಳು ಮತ್ತು ಕಂಪ್ಯೂಟಿಂಗ್ ಸಂಪನ್ಮೂಲಗಳಿಗಾಗಿ Compute Engine

   - ಆಬ್ಜೆಕ್ಟ್ ಸಂಗ್ರಹಣೆ ಮತ್ತು ಕಡತ ಹೋಸ್ಟಿಂಗ್‌ಗಾಗಿ Cloud Storage

   - ನಿರ್ವಹಿತ ಡೇಟಾಬೇಸ್ ಸೇವೆಗಾಗಿ Cloud SQL

   - ಅಪ್ಲಿಕೇಶನ್ ಅಭಿವೃದ್ಧಿ ಮತ್ತು ಹೋಸ್ಟಿಂಗ್‌ಗಾಗಿ Firebase

## ತಾರ್ಕಿಕತೆ

   - ವೆಚ್ಚ-ಪರಿಣಾಮಕಾರಿತ್ವ: Google Cloud Platform ಇತರ ಕ್ಲೌಡ್ ವೇದಿಕೆಗಳಿಗೆ ಹೋಲಿಸಿದರೆ ಬಹಳ ವೆಚ್ಚ-ಪರಿಣಾಮಕಾರಿಯಾಗಿದೆ, ಇದು ಬಜೆಟ್ ನಿರ್ಬಂಧಗಳಿರುವ ಸಂಸ್ಥೆಗಳಿಗೆ ಆಕರ್ಷಕ ಆಯ್ಕೆಯಾಗಿಸುತ್ತದೆ.

   - ವಿಸ್ತರಣೀಯತೆ: GCP ಯ ಸುಲಭವಾಗಿ ವಿಸ್ತರಿಸಬಹುದಾದ ಮೂಲಸೌಕರ್ಯವು ಯಾವುದೇ ಪ್ರಮಾಣದ ಟ್ರಾಫಿಕ್ ಅನ್ನು ನೈಜ ಸಮಯದಲ್ಲಿ ನಿಭಾಯಿಸಲು ಅನುವು ಮಾಡಿಕೊಡುತ್ತದೆ.

   - ವಿಶ್ವಾಸಾರ್ಹತೆ: GCP ಯ ನಿರ್ವಹಿತ ಸೇವೆಗಳು ಸ್ವಯಂಚಾಲಿತ ಬ್ಯಾಕಪ್‌ಗಳು ಮತ್ತು ವಿಪತ್ತು ಚೇತರಿಕೆ ಸಾಮರ್ಥ್ಯಗಳೊಂದಿಗೆ ಹೆಚ್ಚಿನ ವಿಶ್ವಾಸಾರ್ಹತೆಯನ್ನು ನೀಡುತ್ತವೆ, ಇದು ಸಂಪನ್ಮೂಲಗಳು ಮತ್ತು ಡೇಟಾದ ಹೆಚ್ಚಿನ ಲಭ್ಯತೆಯನ್ನು ಖಚಿತಪಡಿಸುತ್ತದೆ.

   - ನಮ್ಯತೆ: ವೇದಿಕೆಯು AI, ಡೇಟಾ ವಿಶ್ಲೇಷಣೆ ಮತ್ತು IoT ನಂತಹ ವಿವಿಧ ಕ್ಷೇತ್ರಗಳಲ್ಲಿ ವಿವಿಧ ಸಾಧನಗಳು ಮತ್ತು ಸೇವೆಗಳನ್ನು ಒದಗಿಸುತ್ತದೆ, ಇದು ಅದನ್ನು ಬಹಳ ಬಹುಮುಖವಾಗಿಸುತ್ತದೆ.

## ಪರಿಣಾಮಗಳು

Google Cloud Platform ಗೆ ವಲಸೆ ಹೋಗಲು GCP ಸೇವೆಗಳ ಬಗ್ಗೆ ನಮ್ಮ ತಂಡಗಳಿಗೆ ತರಬೇತಿ ನೀಡುವುದು, ಆಯ್ದ ಸೇವೆಗಳಿಗೆ ಹೊಂದಿಕೆಯಾಗುವಂತೆ ಅಪ್ಲಿಕೇಶನ್ ಅನ್ನು ಮರು-ವಾಸ್ತುಶಿಲ್ಪಗೊಳಿಸುವುದು ಮತ್ತು GCP ಸೇವೆಗಳನ್ನು ಬೆಂಬಲಿಸಲು ಮೂಲಸೌಕರ್ಯ ಕೋಡ್ ಅನ್ನು ನವೀಕರಿಸುವುದು ಅಗತ್ಯ. ಆದಾಗ್ಯೂ, ವಲಸೆ ಪೂರ್ಣಗೊಂಡ ಮೇಲೆ, ನಮ್ಮ ಅಪ್ಲಿಕೇಶನ್ ಅನ್ನು ಹೋಸ್ಟ್ ಮಾಡಲು ಹೆಚ್ಚು ವಿಸ್ತರಿಸಬಹುದಾದ, ವಿಶ್ವಾಸಾರ್ಹ ಮತ್ತು ವೆಚ್ಚ-ಪರಿಣಾಮಕಾರಿ ಮೂಲಸೌಕರ್ಯ ನಮ್ಮಲ್ಲಿರುತ್ತದೆ ಎಂದು ನಿರೀಕ್ಷಿಸಲಾಗಿದೆ. ಜೊತೆಗೆ, GCP ಯಲ್ಲಿ ಸಂಪನ್ಮೂಲಗಳನ್ನು ಒದಗಿಸುವ ನಿರಂತರ ವೆಚ್ಚಗಳನ್ನು ನಾವು ನಿರ್ವಹಿಸಬೇಕಾಗುತ್ತದೆ.

## ತೀರ್ಮಾನ

ವೆಚ್ಚ-ಪರಿಣಾಮಕಾರಿತ್ವ, ವಿಸ್ತರಣೀಯತೆ, ವಿಶ್ವಾಸಾರ್ಹತೆ ಮತ್ತು ನಮ್ಯತೆಯ ಕಾರಣದಿಂದ Google Cloud Platform ನಮ್ಮ ಕ್ಲೌಡ್ ಮೂಲಸೌಕರ್ಯಕ್ಕೆ ಅತ್ಯುತ್ತಮ ಆಯ್ಕೆ. ಆಯ್ದ ಸೇವೆಗಳನ್ನು ಬಳಸುವ ಮೂಲಕ, ನಮ್ಮ ಅಪ್ಲಿಕೇಶನ್‌ಗೆ ಹೆಚ್ಚು ಲಭ್ಯವಿರುವ ಮತ್ತು ದೃಢವಾದ ಮೂಲಸೌಕರ್ಯವನ್ನು ನಾವು ಒದಗಿಸಬಹುದು.
