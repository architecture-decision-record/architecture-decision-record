# ವಾಸ್ತುಶಿಲ್ಪ ನಿರ್ಧಾರ ದಾಖಲೆ: Kubernetes ಕಂಟೇನರ್ ಆರ್ಕೆಸ್ಟ್ರೇಶನ್

## ಸಮಸ್ಯೆಯ ಹೇಳಿಕೆ 

ನಮ್ಮ ಬೆಳೆಯುತ್ತಿರುವ ಕ್ಲೌಡ್-ನೇಟಿವ್ ಅಪ್ಲಿಕೇಶನ್ ಪೋರ್ಟ್‌ಫೋಲಿಯೊಗಾಗಿ ನಾವು ಕಂಟೇನರ್ ಆರ್ಕೆಸ್ಟ್ರೇಶನ್ ವೇದಿಕೆಯನ್ನು ಆಯ್ಕೆ ಮಾಡಬೇಕಾಗಿದೆ. ನಮ್ಮ ಪ್ರಸ್ತುತ ಪರಂಪರೆ ವೇದಿಕೆಯ ನಿಯೋಜನೆ ಬಹಳ ನಿಧಾನ, ಮತ್ತು ನಮ್ಮ ಬೆಳೆಯುತ್ತಿರುವ ಅಗತ್ಯಗಳಿಗೆ ತಕ್ಕಂತೆ ಚುರುಕಾಗಿಲ್ಲ. ಚುರುಕುತನ ಅಥವಾ ಬಳಕೆಯ ಸುಲಭತೆಯಲ್ಲಿ ರಾಜಿ ಮಾಡಿಕೊಳ್ಳದೆ, ಸಾಧ್ಯವಿರುವ ಅತ್ಯಂತ ದಕ್ಷ ರೀತಿಯಲ್ಲಿ ನಮ್ಮ ಸೇವೆಗಳನ್ನು ವಿಸ್ತರಿಸಲು ಅನುವು ಮಾಡಿಕೊಡುವ ವ್ಯವಸ್ಥೆಯನ್ನು ನಾವು ಹುಡುಕುತ್ತಿದ್ದೇವೆ.

## ಮಾಡಿದ ನಿರ್ಧಾರ

ಪ್ರತಿ ಕಂಟೇನರ್ ಆರ್ಕೆಸ್ಟ್ರೇಶನ್ ವೇದಿಕೆಯ ಸಮಗ್ರ ವಿಶ್ಲೇಷಣೆ ನಡೆಸಿದ ನಂತರ, ನಮ್ಮ ಎಂಟರ್‌ಪ್ರೈಸ್ ಅಗತ್ಯಗಳಿಗೆ ಅತ್ಯುತ್ತಮ ಆಯ್ಕೆಯಾಗಿ Kubernetes ಅನ್ನು ಅಳವಡಿಸಿಕೊಳ್ಳಲು ನಾವು ನಿರ್ಧರಿಸಿದ್ದೇವೆ. Kubernetes ಆರಿಸಲು ನಮ್ಮ ಕಾರಣಗಳು ಹೀಗಿವೆ:

1. **ವಿಸ್ತರಣೀಯತೆ:**  Kubernetes ನ ವಿಶಿಷ್ಟ ವಿನ್ಯಾಸವು ಅಪ್ಲಿಕೇಶನ್‌ಗಳನ್ನು ವಿಸ್ತರಿಸಲು ಪರಿಪೂರ್ಣ, ಮತ್ತು ವಿಸ್ತರಣೀಯತೆಗೆ ನಮ್ಮ ಅವಶ್ಯಕತೆಗಳು ಕಾಲಕ್ರಮೇಣ ವಿಕಸನಗೊಂಡಂತೆ, Kubernetes ಯಾವುದೇ ತೊಂದರೆಯಿಲ್ಲದೆ ಈ ಬದಲಾವಣೆಗಳನ್ನು ಪೂರೈಸುವ ಅಂತರ್ನಿರ್ಮಿತ ಸಾಮರ್ಥ್ಯವನ್ನು ಹೊಂದಿದೆ.

2. **ವಿಕೇಂದ್ರೀಕೃತ ವಾಸ್ತುಶಿಲ್ಪ:**  Kubernetes ನ ಮಾಸ್ಟರ್-ವರ್ಕರ್ ಟೊಪೊಲಜಿಯು ಒಂದೇ ವೈಫಲ್ಯ ಬಿಂದು ಇಲ್ಲ ಎಂದು ಖಚಿತಪಡಿಸುವ ವಿಕೇಂದ್ರೀಕೃತ ವಾಸ್ತುಶಿಲ್ಪವನ್ನು ಖಚಿತಪಡಿಸುತ್ತದೆ.

3. **ಸಮುದಾಯ ಬೆಂಬಲ:**  Kubernetes ಅತಿದೊಡ್ಡ ಮತ್ತು ಅತ್ಯಂತ ಸಕ್ರಿಯ ಮುಕ್ತ-ಮೂಲ ಸಮುದಾಯವನ್ನು ಹೊಂದಿದೆ, ಅಂದರೆ ಅದಕ್ಕೆ ಅಪಾರ ಸಂಖ್ಯೆಯ ಕೊಡುಗೆದಾರರು, ಡೆವಲಪರ್‌ಗಳು ಮತ್ತು ಮಾರಾಟಗಾರರಿದ್ದಾರೆ, ಇದರಿಂದ ನಮಗೆ ಸಹಾಯ ಪಡೆಯುವುದು ಮತ್ತು ಸಂಪನ್ಮೂಲಗಳನ್ನು ಹುಡುಕುವುದು ಸುಲಭವಾಗುತ್ತದೆ.

4. **ಪರಿಸರ ವ್ಯವಸ್ಥೆ ಬೆಂಬಲ:**  Kubernetes ವಿವಿಧ ಮೂರನೇ ಪಕ್ಷದ ಸಾಧನಗಳು, ಕಂಟೇನರ್ ರಿಜಿಸ್ಟ್ರಿಗಳೊಂದಿಗೆ ಏಕೀಕರಣಗಳು, CI/CD ಪೈಪ್‌ಲೈನ್‌ಗಳು, ಡೇಟಾ ಸಂಗ್ರಹಣೆ ಮತ್ತು ಇನ್ನಷ್ಟನ್ನು ಹೊಂದಿರುವ ಬೆಳೆಯುತ್ತಿರುವ ಪರಿಸರ ವ್ಯವಸ್ಥೆಯನ್ನು ಹೊಂದಿದೆ.

ಆದ್ದರಿಂದ, ಪ್ರಸ್ತುತ ಮತ್ತು ತಕ್ಷಣದ ಭವಿಷ್ಯಕ್ಕಾಗಿ ನಮ್ಮ ಕಂಟೇನರ್ ಆರ್ಕೆಸ್ಟ್ರೇಶನ್ ವೇದಿಕೆಯಾಗಿ Kubernetes ಅನ್ನು ಅಳವಡಿಸಿಕೊಳ್ಳಲು ನಾವು ನಿರ್ಧರಿಸಿದ್ದೇವೆ.
