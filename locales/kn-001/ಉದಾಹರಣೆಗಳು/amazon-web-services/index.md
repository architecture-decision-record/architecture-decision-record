# Amazon Web Services ಗಾಗಿ ವಾಸ್ತುಶಿಲ್ಪ ನಿರ್ಧಾರ ದಾಖಲೆ

ಶೀರ್ಷಿಕೆ: ಕ್ಲೌಡ್ ಮೂಲಸೌಕರ್ಯಕ್ಕಾಗಿ Amazon Web Services ಅನ್ನು ಅಳವಡಿಸಿಕೊಳ್ಳುವುದು

## ನಿರ್ಧಾರ

ವಿವಿಧ ಕ್ಲೌಡ್ ಮೂಲಸೌಕರ್ಯ ವೇದಿಕೆಗಳ ಸಮಗ್ರ ಮೌಲ್ಯಮಾಪನದ ನಂತರ, ನಮ್ಮ ಸಂಸ್ಥೆಯ ಕ್ಲೌಡ್ ಮೂಲಸೌಕರ್ಯ ಅಗತ್ಯಗಳಿಗಾಗಿ Amazon Web Services (AWS) ಅನ್ನು ಅಳವಡಿಸಿಕೊಳ್ಳಲು ನಿರ್ಧರಿಸಲಾಗಿದೆ.

## ಹಿನ್ನೆಲೆ

ನಮ್ಮ ಸಂಸ್ಥೆ ವೇಗವಾಗಿ ಬೆಳೆಯುತ್ತಿದೆ ಮತ್ತು ನಮ್ಮ ವ್ಯವಹಾರದ ಬೇಡಿಕೆಗಳನ್ನು ಪೂರೈಸಲು ನಮಗೆ ವಿಶ್ವಾಸಾರ್ಹ ಮತ್ತು ವಿಸ್ತರಿಸಬಹುದಾದ ಕ್ಲೌಡ್ ಮೂಲಸೌಕರ್ಯ ಬೇಕು. ಹಲವಾರು ಕ್ಲೌಡ್ ಮೂಲಸೌಕರ್ಯ ಪೂರೈಕೆದಾರರನ್ನು ಪರಿಗಣಿಸಿದ ನಂತರ, ನಮ್ಮ ಪ್ರಸ್ತುತ ಮತ್ತು ಭವಿಷ್ಯದ ಅವಶ್ಯಕತೆಗಳನ್ನು ಪೂರೈಸಲು AWS ಅತ್ಯಂತ ಸೂಕ್ತವಾದ ಸೇವೆಗಳ ಶ್ರೇಣಿಯನ್ನು ನೀಡುತ್ತದೆ ಎಂದು ತೀರ್ಮಾನಿಸಲಾಯಿತು.

## ಪರಿಗಣನೆಗಳು

ಮಾರುಕಟ್ಟೆಯಲ್ಲಿ ವಿಶ್ವಾಸಾರ್ಹ ಮತ್ತು ದಕ್ಷ ಎಂದು ಸಾಬೀತಾದ ಅನೇಕ ಕ್ಲೌಡ್ ಮೂಲಸೌಕರ್ಯ ಪೂರೈಕೆದಾರರಿದ್ದಾರೆ. ಆದಾಗ್ಯೂ, AWS ನಮ್ಮ ಅಗತ್ಯಗಳನ್ನು ಪೂರೈಸಲು ಸಮಗ್ರ ಸೇವೆಗಳ ಸಮೂಹವನ್ನು ನೀಡುವುದಲ್ಲದೆ, ವ್ಯಾಪಕ ಗ್ರಾಹಕ ನೆಲೆ ಮತ್ತು ಯಶಸ್ವಿ ನಿಯೋಜನೆಗಳ ಇತಿಹಾಸವನ್ನೂ ಹೊಂದಿದೆ. ನಮ್ಮ ತಂಡವು ವೇದಿಕೆಯೊಂದಿಗೆ ಪರಿಣಾಮಕಾರಿಯಾಗಿ ಕೆಲಸ ಮಾಡಬಲ್ಲದು ಎಂದು ಖಚಿತಪಡಿಸಲು AWS ವಿಶಾಲ ಶ್ರೇಣಿಯ ಬೆಂಬಲ ಮತ್ತು ತರಬೇತಿ ಸಂಪನ್ಮೂಲಗಳನ್ನು ಸಹ ಒದಗಿಸುತ್ತದೆ.

ಇದಲ್ಲದೆ, AWS ಜಗತ್ತಿನಾದ್ಯಂತ ವಿವಿಧ ಪ್ರದೇಶಗಳಲ್ಲಿರುವ ಡೇಟಾ ಕೇಂದ್ರಗಳೊಂದಿಗೆ ವ್ಯಾಪಕ ಜಾಗತಿಕ ಉಪಸ್ಥಿತಿಯನ್ನು ಹೊಂದಿದೆ. ಇದು ನಮ್ಮ ಡೇಟಾ ಸುರಕ್ಷಿತವಾಗಿರುವುದನ್ನು ಮತ್ತು ನಮ್ಮ ಅಪ್ಲಿಕೇಶನ್‌ಗಳು ಹಾಗೂ ಸೇವೆಗಳು ಹೆಚ್ಚು ಲಭ್ಯವಿರುವುದನ್ನು ಖಚಿತಪಡಿಸುತ್ತದೆ. ನಮ್ಮ ವ್ಯವಹಾರಕ್ಕೆ ನಿರ್ಣಾಯಕವಾದ ದೃಢವಾದ ಭದ್ರತಾ ಚೌಕಟ್ಟನ್ನೂ AWS ಹೊಂದಿದೆ.

ಕೊನೆಯದಾಗಿ, AWS ಬಳಸಿದಷ್ಟು-ಪಾವತಿಸುವ ಮಾದರಿಯನ್ನು ಒದಗಿಸುತ್ತದೆ, ಇದು ಬೇಡಿಕೆಯ ಆಧಾರದ ಮೇಲೆ ನಮ್ಮ ಮೂಲಸೌಕರ್ಯವನ್ನು ವಿಸ್ತರಿಸುವ ನಮ್ಯತೆಯನ್ನು ನಮಗೆ ನೀಡುತ್ತದೆ. ಇದರರ್ಥ ನಾವು ಬಳಸಿದ್ದಕ್ಕೆ ಮಾತ್ರ ಶುಲ್ಕ ವಿಧಿಸಲಾಗುತ್ತದೆ, ಇದು ನಮ್ಮ ವೆಚ್ಚಗಳನ್ನು ಅತ್ಯುತ್ತಮಗೊಳಿಸಲು ಮತ್ತು ವ್ಯವಹಾರದ ಇತರ ಕ್ಷೇತ್ರಗಳಲ್ಲಿ ಹೂಡಿಕೆ ಮಾಡಲು ಅನುವು ಮಾಡಿಕೊಡುತ್ತದೆ.

## ನಿರ್ಧಾರ

ನಡೆಸಿದ ಮೌಲ್ಯಮಾಪನಗಳು ಮತ್ತು AWS ನೀಡುವ ಅನುಕೂಲಗಳ ಆಧಾರದ ಮೇಲೆ, ನಮ್ಮ ಕ್ಲೌಡ್ ಮೂಲಸೌಕರ್ಯ ಅಗತ್ಯಗಳಿಗಾಗಿ AWS ಅನ್ನು ಅಳವಡಿಸಿಕೊಳ್ಳಲು ನಿರ್ಧರಿಸಲಾಗಿದೆ.

## ಪರಿಣಾಮಗಳು

AWS ಅಳವಡಿಕೆಗೆ, ನಮ್ಮ ತಂಡಗಳು ವೇದಿಕೆಯ ಪರಿಚಯ ಹೊಂದಿ ಅದನ್ನು ಪರಿಣಾಮಕಾರಿಯಾಗಿ ಬಳಸಿಕೊಳ್ಳಬಲ್ಲವು ಎಂದು ಖಚಿತಪಡಿಸಲು ತರಬೇತಿಯ ಅಗತ್ಯವಿರಬಹುದು. ನಮ್ಮ ಪ್ರಸ್ತುತ ಮೂಲಸೌಕರ್ಯವನ್ನು AWS ವೇದಿಕೆಗೆ ಸರಿಸಲು ಕೆಲವು ಆರಂಭಿಕ ವೆಚ್ಚಗಳೂ ಇರಬಹುದು.

## ಮಾಲೀಕತ್ವ

AWS ನ ಪರಿಣಾಮಕಾರಿ ಬಳಕೆಯನ್ನು ಖಚಿತಪಡಿಸುವ ಮತ್ತು ಸಂಬಂಧಿತ ಅಪಾಯಗಳನ್ನು ನಿರ್ವಹಿಸುವ ಜವಾಬ್ದಾರಿ ಕ್ಲೌಡ್ ಮೂಲಸೌಕರ್ಯ ತಂಡದ ವ್ಯಾಪ್ತಿಯೊಳಗೆ ಬರುತ್ತದೆ. ಉದ್ಭವಿಸುವ ಯಾವುದೇ ಸಮಸ್ಯೆಗಳನ್ನು ಈ ತಂಡವು ಪರಿಹರಿಸಬೇಕು.

## ಪರಿಶೀಲನೆ

AWS ಅನ್ನು ಅಳವಡಿಸಿಕೊಳ್ಳುವ ನಿರ್ಧಾರವು ನಮ್ಮ ಅಗತ್ಯಗಳನ್ನು ಪೂರೈಸುತ್ತಲೇ ಇದೆ ಮತ್ತು ವೇದಿಕೆಯ ಪ್ರಯೋಜನಗಳನ್ನು ಸಂಪೂರ್ಣವಾಗಿ ಪಡೆಯಲಾಗುತ್ತಿದೆ ಎಂದು ಖಚಿತಪಡಿಸಲು ವಾರ್ಷಿಕ ಆಧಾರದ ಮೇಲೆ ಪರಿಶೀಲಿಸಲಾಗುತ್ತದೆ.
