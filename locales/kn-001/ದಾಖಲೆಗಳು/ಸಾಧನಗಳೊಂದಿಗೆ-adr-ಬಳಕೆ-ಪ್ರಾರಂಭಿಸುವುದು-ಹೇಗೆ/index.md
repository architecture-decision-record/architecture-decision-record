## ಸಾಧನಗಳೊಂದಿಗೆ ADR ಬಳಕೆಯನ್ನು ಪ್ರಾರಂಭಿಸುವುದು ಹೇಗೆ

- [MySpec](https://myspec.dev) — ಯೋಜನೆಯ ಸಂವಿಧಾನ, ತಾಂತ್ರಿಕ ವಾಸ್ತುಶಿಲ್ಪ ಮತ್ತು ADR ಗಳನ್ನು MCP ಮೂಲಕ ಒದಗಿಸಲಾಗುವ ಸ್ವಚ್ಛ Markdown ಆಗಿ ರೂಪಿಸುವ ಸ್ವಯಂಚಾಲಿತ ವಿಶೇಷಣ ಮತ್ತು ವಾಸ್ತುಶಿಲ್ಪ ನಿರ್ಧಾರ ವೇದಿಕೆ.

ನೀವು ಬಯಸಿದ ರೀತಿಯಲ್ಲಿ ಸಾಧನಗಳೊಂದಿಗೆ ADR ಬಳಸಲು ಪ್ರಾರಂಭಿಸಬಹುದು.

ಉದಾಹರಣೆಗೆ:

  * ನೀವು Google Drive ಮತ್ತು ಆನ್‌ಲೈನ್ ಸಂಪಾದನೆಯನ್ನು ಇಷ್ಟಪಡುವುದಾದರೆ, Google Doc ಅಥವಾ Google Sheet ರಚಿಸಬಹುದು.

  * ನೀವು git ನಂತಹ ಮೂಲ ಕೋಡ್ ಆವೃತ್ತಿ ನಿಯಂತ್ರಣವನ್ನು ಬಳಸಲು ಇಷ್ಟಪಡುವುದಾದರೆ, ಪ್ರತಿ ADR ಗೂ ಒಂದು ಕಡತ ರಚಿಸಬಹುದು.

  * ನೀವು Atlassian Jira ನಂತಹ ಯೋಜನಾ ಯೋಜನೆ ಸಾಧನಗಳನ್ನು ಬಳಸಲು ಇಷ್ಟಪಡುವುದಾದರೆ, ಆ ಸಾಧನದ ಯೋಜನಾ ಟ್ರ್ಯಾಕರ್ ಬಳಸಬಹುದು.

  * ನೀವು MediaWiki ನಂತಹ ವಿಕಿಗಳನ್ನು ಬಳಸಲು ಇಷ್ಟಪಡುವುದಾದರೆ, ADR ವಿಕಿ ರಚಿಸಬಹುದು.
