# Arkkitehtuuripäätöstietue: Java-ohjelmointikieli

Otsikko: Java-ohjelmointikielen valinta projektiin

Päätös: Useiden ohjelmointikielten arvioinnin jälkeen olemme päättäneet käyttää Javaa projektissamme.

### Tausta

Aioimme rakentaa verkkopohjaisen sovelluksen, joka voi toimia useilla käyttöjärjestelmillä. Projektimme vaati kielen, joka voisi tarjota vahvat tietoturvaominaisuudet, käsitellä rinnakkaisuutta, tukea suuria koodikantoja ja olla riittävän monipuolinen täyttämään tulevat kasvuvaatimuksemme. Arvioimme useita kieliä niiden vahvuudet ja rajoitukset huomioiden ennen Javan valintaa.

### Huomioon otettavat seikat

1. **Tietoturva:**  Java tarjoaa erinomaiset tietoturvaominaisuudet hyvin määriteltyjen tietoturvakäytäntöjensä ja pääsynhallintansa kautta. Se sisältää myös ominaisuuksia kuten tavukoodin varmennuksen, joka auttaa estämään haitallisten ohjelmien suorittamisen järjestelmässä.

2. **Rinnakkaisuus:**  Javassa on sisäänrakennettu tuki monisäikeisyydelle, mikä sallii sovellusten suorittaa useita tehtäviä samanaikaisesti. Tämä ominaisuus tekee Javasta erinomaisen valinnan suurten, monimutkaisten sovellusten kehittämiseen, joissa on useita ominaisuuksia ja toimintoja.

3. **Suuret koodikannat:**  Java tukee olio-ohjelmointia, mikä tekee siitä sopivan valinnan suurten koodikantojen kehittämiseen. Sen modulaarinen luonne sekä kapselointi- ja abstraktiomallien käyttö lisäävät ohjelmistokehitysprosessin helppoutta.

4. **Monipuolisuus:**  Java on monipuolinen ja tarjoaa mahdollisuuden käyttää laajaa valikoimaa kirjastoja ja kehyksiä, mikä tekee siitä erinomaisen valinnan sekä verkkopohjaisiin että yritystason sovelluksiin.

### Päätöksen lopputulos

Olemme päättäneet käyttää Java-ohjelmointikieltä projektissamme sen tietoturvaominaisuuksien, rinnakkaisuustuen, suurten koodikantojen käsittelykyvyn ja monipuolisuuden vuoksi. Tämä päätös on linjassa projektimme vaatimusten kanssa, ja uskomme, että Javan valinta varmistaa sen menestyksen. 

### Seuraukset

1. Tarvitsemme kehittäjiä, joilla on kokemusta Javasta ja jotka osaavat käyttää sitä sujuvasti.

2. Kaikkien kielellä kirjoitettujen koodien on oltava yhteensopivia Java-virtuaalikoneen (JVM) kanssa.

3. Uusien ominaisuuksien, toimintojen tai kehysten sisällyttäminen voi aiheuttaa joitakin haasteita.

4. Suuret, monimutkaiset Java-projektit voivat vaatia enemmän aikaa ja resursseja kehittää.
