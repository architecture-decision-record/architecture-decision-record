# سجل قرار البنية المعمارية: تنسيق الحاويات باستخدام Docker Swarm

## السياق

ننظر في أدوات مختلفة لتنسيق الحاويات لإدارة بنيتنا المعمارية القائمة على الخدمات المصغّرة. وقد قيّمنا حلولًا مختلفة مثل Kubernetes وDocker Swarm وMesosphere DC/OS. غير أننا قررنا التركيز على Docker Swarm بسبب بساطته وتكامله مع Docker وموازنة الأحمال المدمجة فيه.

## القرار

قررنا استخدام Docker Swarm أداةً لتنسيق الحاويات لدينا. يوفر Docker Swarm طريقة بسيطة وبديهية لإدارة التطبيقات المُحوَّلة إلى حاويات عبر عنقود من العقد. كما يتيح لنا الاستفادة من سير عملنا الحالي القائم على Docker وبنيتنا التحتية. وباستخدام Docker Swarm، نستطيع نشر تطبيقاتنا وتوسيعها وإدارتها بسهولة، مع الاستفادة من موازنة الأحمال المدمجة.

## الفوائد

- **البساطة:**  يتبع Docker Swarm المبادئ نفسها التي يتبعها Docker، فلا حاجة إلى تعلّم تقنية جديدة. ومنحنى التعلم ضحل نسبيًا للمطورين المطّلعين على Docker.

- **التكامل:**  يتكامل Docker Swarm بسلاسة مع أدوات Docker مثل Docker Compose، مما يسهّل إدارة جميع حاوياتنا وخدماتنا من مكان واحد.

- **موازنة الأحمال:**  يوفر Docker Swarm موازنة أحمال مدمجة، تضمن توافر تطبيقاتنا دائمًا وتوزيعها بالتساوي عبر العنقود.

- **قابلية التوسع:**  يسهّل Docker Swarm توسيع تطبيقاتنا أفقيًا بإضافة عقد إلى العنقود أو إزالتها منه.

- **التوافر العالي:**  يوزع Docker Swarm خدماتنا تلقائيًا عبر العقد، موفرًا توافرًا عاليًا عند تعطل عقدة.

## المخاطر

- **وظائف محدودة:**  قد يفتقر Docker Swarm إلى بعض الميزات المتقدمة الموجودة في Kubernetes أو Mesosphere DC/OS، مثل التوسع التلقائي أو الإصلاح الذاتي.

- **التمركز حول Docker:**  يرتبط Docker Swarm ارتباطًا وثيقًا بـDocker، مما قد يحدّ من مرونتنا إذا احتجنا يومًا إلى الابتعاد عن الحلول القائمة على Docker.

- **عدم النضج:**  لا يزال Docker Swarm تقنية حديثة نسبيًا، وقد تكون هناك بعض مشكلات الاستقرار أو ثغرات في التوثيق.

## البدائل

- **Kubernetes:**  هي منصة تنسيق الحاويات الأكثر استخدامًا وتوفر ميزات متقدمة ونظامًا بيئيًا أنضج. غير أن منحنى التعلم فيها أشد انحدارًا وقد تكون أكبر من حاجتنا.

- **Mesosphere DC/OS:**  أداة قوية توفر ميزات متقدمة مثل دعم السحب المتعددة وقدرات أصيلة لمنصات البيانات الضخمة والذكاء الاصطناعي. غير أن تنفيذها يتطلب خبرة كبيرة وقد تكون معقدة جدًا لمتطلباتنا.

## الخلاصة

بعد دراسة متأنية، قررنا استخدام Docker Swarm أداةً لتنسيق الحاويات لدينا. يوفر Docker Swarm البساطة والتكامل وموازنة الأحمال المدمجة التي نحتاجها لإدارة تطبيقاتنا المُحوَّلة إلى حاويات. وعلى الرغم من أنه قد يفتقر إلى بعض الميزات المتقدمة، فإننا نعتقد أن فوائد Docker Swarm تفوق مخاطره لمتطلباتنا الحالية.
