# سجل قرار البنية المعمارية: البنية التحتية السحابية Microsoft Azure

عنوان القرار: اعتماد Microsoft Azure بوصفها البنية التحتية السحابية لمؤسستنا

متخذ القرار: مدير نظم المعلومات (CIO)

التاريخ: 2021-10-15

الحالة: معتمد

## الخلفية

تخطط المؤسسة للانتقال من البنية التحتية التقليدية المحلية (on-premises) إلى بنية تحتية سحابية. ولتحقيق ذلك، قيّمت المؤسسة عدة مزودي خدمات سحابية مثل Amazon Web Services (AWS) وGoogle Cloud Platform (GCP) وMicrosoft Azure وIBM Cloud. ولكل مزوّد مجموعته الخاصة من الميزات والفوائد وهيكل التسعير. وبعد تحليل تفصيلي، خلصت المؤسسة إلى أن Microsoft Azure هي الخيار الأنسب لمؤسستنا.

## القرار

اعتماد Microsoft Azure بوصفها البنية التحتية السحابية لمؤسستنا.

## المبرر

فيما يلي أسباب اعتماد Microsoft Azure:

1. خدمات شاملة: توفر Azure مجموعة كاملة من الخدمات السحابية، من البنية التحتية بوصفها خدمة (IaaS) إلى البرمجيات بوصفها خدمة (SaaS) والمنصة بوصفها خدمة (PaaS). وهذا يمكّننا من الاستفادة من خدمات Azure لحل متطلبات المؤسسة، مثل التخزين والحوسبة والشبكات والتحليلات.

2. قابلية التوسع والمرونة: مع Azure نستطيع بسهولة توسيع الموارد أو تقليصها بحسب متطلبات أعمالنا. وتوفر Azure أيضًا مرونة في اختيار نظام التشغيل ولغة البرمجة والأطر.

3. الأمان والامتثال: توفر Azure مستوى عاليًا من الأمان والامتثال، إذ تتوافق مع عدة معايير في القطاع مثل ISO وSOC وHIPAA وPCI DSS. وتوفر Azure أيضًا ميزات أمان متقدمة مثل مجموعات أمان الشبكة وجدران الحماية والحماية من هجمات DDoS.

4. السحابة الهجينة: توفر Azure تجربة سحابة هجينة سلسة، تتيح للمؤسسات ربط بنيتها التحتية المحلية بـAzure. وهذا يسهّل علينا نقل أعباء العمل إلى السحابة ويمنحنا مرونة اختيار مكان تخزين البيانات.

5. جدوى التكلفة: توفر Azure نموذج تسعير بالدفع حسب الاستخدام، مما يعني أننا ندفع فقط مقابل الموارد المستخدمة. وهذا يساعدنا على توفير التكاليف مقارنةً بالبنية التحتية المحلية التقليدية.

## الخلاصة

إن اعتماد Microsoft Azure بوصفها البنية التحتية السحابية لمؤسستنا يتماشى مع متطلبات أعمالنا ويوفر عدة فوائد مثل قابلية التوسع والمرونة والأمان وجدوى التكلفة. ولذلك يُوصى باعتماد Azure بنيةً تحتية سحابية لنا.
