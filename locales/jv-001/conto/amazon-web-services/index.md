# Cathetan Keputusan Arsitektur kanggo Amazon Web Services

Judhul: Nggunakake Amazon Web Services kanggo Infrastruktur Cloud

## Keputusan

Sawise evaluasi sing teliti marang macem-macem platform infrastruktur cloud, wis diputuske yen Amazon Web Services (AWS) bakal digunakake dening organisasi kita kanggo kabutuhan infrastruktur cloud.

## Latar Mburi

Organisasi kita saya gedhe kanthi cepet lan kita butuh infrastruktur cloud sing bisa dipercaya lan bisa mundhak kanggo nuhoni tuntutan bisnis. Sawise nimbang sawetara panyedhia infrastruktur cloud, disimpulake yen AWS nawakake rangkaian layanan sing paling cocog kanggo nuhoni kabutuhan saiki lan mbesuk.

## Pertimbangan

Ana akeh panyedhia infrastruktur cloud ing pasar sing wis kabukten bisa dipercaya lan efisien. Nanging, AWS ora mung nawakake kumpulan layanan lengkap kanggo nuhoni kabutuhan kita, nanging uga nduwe basis pelanggan sing amba lan rekam jejak deployment sing kasil. AWS uga nyedhiyakake macem-macem sumber dhukungan lan pelatihan supaya tim kita bisa makarya kanthi efektif karo platform.

Saliyane iku, AWS nduwe kehadiran global sing amba kanthi pusat data sing dumunung ing macem-macem wilayah ing saindhenging donya. Iki mesthekake yen data kita aman lan aplikasi lan layanan kita bakal nduwe ketersediaan dhuwur. AWS uga nduwe kerangka keamanan sing kuwat sing kritis kanggo bisnis kita.

Pungkasane, AWS nyedhiyakake model bayar-sakbacane-nggunakake sing menehi keluwesan kanggo ngukur infrastruktur kita adhedhasar permintaan. Iki tegese kita mung bakal ditagih kanggo apa sing digunakake, sing ngidini kita ngoptimalake biaya lan nandur modal ing bidang liya saka bisnis.

## Keputusan

Adhedhasar evaluasi sing wis ditindakake lan kaluwihan sing ditawakake AWS, wis diputuske yen AWS bakal digunakake kanggo kabutuhan infrastruktur cloud kita.

## Akibat

Nggunakake AWS mbok menawa mbutuhake pelatihan kanggo tim kita supaya padha kenal karo platform lan bisa nggunakake kanthi efektif. Mbok menawa uga ana sawetara biaya wiwitan kanggo mindhah infrastruktur kita saiki menyang platform AWS.

## Kepemilikan

Tanggung jawab kanggo mesthekake panggunaan AWS sing efektif lan pangelolaan resiko sing gegayutan bakal dadi wewenang tim infrastruktur cloud. Masalah apa wae sing muncul kudu ditangani dening tim iki.

## Review

Keputusan nggunakake AWS bakal ditinjau saben taun kanggo mesthekake yen isih nuhoni kabutuhan kita lan manfaat platform kasil dirasakake kanthi kebak.
