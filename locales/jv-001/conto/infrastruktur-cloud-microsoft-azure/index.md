# Cathetan Keputusan Arsitektur: infrastruktur cloud Microsoft Azure" 

Judhul Keputusan: Ngadopsi Microsoft Azure minangka infrastruktur cloud kanggo organisasi kita

Pengambil Keputusan: Chief Information Officer

Tanggal: 2021-10-15

Status: Disetujoni

## Latar Mburi

Organisasi ngrencanakake migrasi saka infrastruktur on-premises tradisional menyang infrastruktur cloud. Kanggo nggayuh iki, organisasi wis ngevaluasi pirang-pirang panyedhia layanan cloud kayata Amazon Web Services (AWS), Google Cloud Platform (GCP), Microsoft Azure, lan IBM Cloud. Saben panyedhia nduwe fitur, kaluwihan, lan struktur rega dhewe-dhewe. Sawise analisis rinci, disimpulake yen Microsoft Azure yaiku pilihan sing paling cocog kanggo organisasi kita.

## Keputusan

Ngadopsi Microsoft Azure minangka infrastruktur cloud kanggo organisasi kita.

## Alasan

Iki alasan kanggo ngadopsi Microsoft Azure:

1. Layanan Lengkap: Azure nyedhiyakake rangkaian layanan cloud lengkap saka infrastructure as a service (IaaS) nganti software as a service (SaaS) lan platform as a service (PaaS). Iki ngidini kita nggunakake layanan Azure kanggo ngrampungake kabutuhan organisasi, kayata panyimpenan, komputasi, jaringan, lan analitik.

2. Skalabilitas lan Keluwesan: Karo Azure, kita bisa kanthi gampang nambah utawa nyuda sumber daya adhedhasar kabutuhan bisnis. Azure uga menehi keluwesan ing milih sistem operasi, basa pamrograman, lan framework.

3. Keamanan lan Kepatuhan: Azure nawakake tingkat keamanan lan kepatuhan sing dhuwur, amarga manut sawetara standar industri kayata ISO, SOC, HIPAA, lan PCI DSS. Azure uga nyedhiyakake fitur keamanan canggih kayata kelompok keamanan jaringan, firewall, lan perlindungan DDoS.

4. Cloud Hibrida: Azure nyedhiyakake pengalaman cloud hibrida sing mulus, ngidini organisasi nyambungake infrastruktur on-premises karo Azure. Iki nggampangake kita migrasi beban kerja menyang cloud lan menehi keluwesan kanggo milih ing ngendi data disimpen.

5. Hemat Biaya: Azure nawakake model rega bayar-sakbacane-nggunakake, tegese kita mung mbayar sumber daya sing digunakake. Iki mbiyantu ngirit biaya dibandhingake infrastruktur on-premises tradisional.

## Kesimpulan

Ngadopsi Microsoft Azure minangka infrastruktur cloud kanggo organisasi kita cocog karo kabutuhan bisnis kita lan nawakake sawetara kaluwihan kayata skalabilitas, keluwesan, keamanan, lan hemat biaya. Mula, disaranake ngadopsi Azure minangka infrastruktur cloud kita.
