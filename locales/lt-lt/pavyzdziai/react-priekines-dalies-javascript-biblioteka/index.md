# Architektūros sprendimo įrašas: React priekinės dalies JavaScript biblioteka

## Kontekstas

Savo programai turime pasirinkti priekinės dalies JavaScript biblioteką, kad sukurtume prisitaikančią ir interaktyvią naudotojo sąsają.
  
## Svarstytas variantas

1. React
  
2. Vue

3. Svelte
   
## Sprendimas

Kaip savo priekinės dalies JavaScript biblioteką naudosime React.
  
## Pagrindimas

1. **Komponentais pagrįsta architektūra:**  React suteikia komponentais pagrįstą architektūrą, leidžiančią suskaidyti UI į mažus pakartotinai naudojamus komponentus. Tai padeda pagerinti mūsų kodo moduliškumą ir palengvina programos priežiūrą, mastelio keitimą ir atnaujinimą.
  
2. **Deklaratyvusis programavimas:**  React naudoja deklaratyvų programavimo stilių, dėl kurio mūsų kodas tampa intuityvesnis ir lengviau skaitomas. Ji taip pat suteikia virtualų DOM, leidžiantį mūsų kodui veikti greičiau ir efektyviau.
  
3. **Didelė bendruomenė:**  React turi didelę ir aktyvią bendruomenę ir yra viena populiariausių priekinės dalies bibliotekų. Tai reiškia, kad yra daug išteklių, įrankių ir bibliotekų, galinčių padėti mums greičiau ir efektyviau sukurti programą.
  
4. **Geresnis našumas:**  React naudoja vienakryptį duomenų srautą, kuris padeda supaprastinti programos logiką ir daro ją efektyvesnę. Ji taip pat suteikia atvaizdavimą serverio pusėje, o tai padeda pagerinti mūsų programos našumą ir SEO.
  
5. **Lankstumas:**  React galima naudoti su kitomis bibliotekomis ir karkasais, o tai suteikia laisvę pasirinkti geriausią technologijų paketą, tinkantį mūsų projekto reikalavimams.
  
## Pasekmės

1. **Mokymosi kreivė:**  React turi mokymosi kreivę, ir programuotojams, kurie nauji React srityje, gali prireikti šiek tiek laiko, kad įsisavintų.
  
2. **Kūrimo įrankiai:**  React reikalauja papildomų kūrimo įrankių, tokių kaip Babel ir Webpack, kurie gali padidinti kūrimo proceso sudėtingumą.
  
3. **Naršyklių suderinamumas:**  React turi suderinamumo problemų su senesnėmis naršyklėmis, nes naudoja ES6 funkcijas, kurių senesnės naršyklės nepalaiko.
  
 4. Staigi mokymosi kreivė: programuotojams, nesusipažinusiems su React, gali prireikti laiko išmokti ja efektyviai naudotis, o tai gali lemti lėtesnį kūrimą.

## Išvada

Nusprendėme savo programos priekinės dalies JavaScript biblioteka naudoti React. Nors ji gali turėti mokymosi kreivę, React teikiami privalumai, tokie kaip komponentais pagrįsta architektūra, deklaratyvus programavimo stilius, geresnis našumas, lankstumas ir didelė bendruomenė, nusveria galimus trūkumus.
