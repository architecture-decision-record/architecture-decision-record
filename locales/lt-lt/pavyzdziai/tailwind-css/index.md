# Architektūros sprendimo įrašas: Tailwind CSS

Sprendimas: naudoti Tailwind CSS kaip CSS karkasą naudotojo sąsajai stilizuoti.

## Kas yra Tailwind CSS?

Tailwind yra pirmiausia įrankių (utility-first) CSS karkasas, leidžiantis greitai kurti ir pritaikyti naudotojo sąsajas. Jis sukurtas taip, kad būtų labai pritaikomas ir leistų programuotojams rašyti lieknesnį ir efektyvesnį CSS. Šis karkasas pateikia iš anksto apibrėžtų klasių rinkinį, kad UI būtų stilizuojama labai greitai.

## Kontekstas

Kuriame interneto programą klientui, kuriam reikia prisitaikančios ir pritaikomos naudotojo sąsajos. Klientas paprašė nuoseklaus ir modernaus stiliaus. Kūrimo komanda turi patirties naudojant pasirinktinį CSS, bet nori išnagrinėti CSS karkasus, galinčius sutaupyti laiko ir pastangų. Ieškome karkaso, kurį būtų lengva naudoti, kuris būtų pritaikomas ir turėtų didelę bendruomenę paramai.

## Sprendimo veiksniai

- **Paprasta naudoti:**  Norime karkaso, kurį paprasta išmokti ir galima integruoti į mūsų kūrimo darbo eigą.

- **Pritaikomas:**  Norime karkaso, kurį galima pritaikyti pagal kliento prekės ženklo gaires ir temą.

- **Didelė bendruomenės parama:**  Norime karkaso, turinčio aktyvią programuotojų ir dizainerių bendruomenę, galinčią prireikus padėti ir suteikti išteklių.

- **Taupo laiką:**  Norime karkaso, galinčio sutaupyti laiko ir pastangų stilizuojant UI.

## Svarstyti variantai

- **Bootstrap:**  populiarus CSS karkasas su daugybe iš anksto sukurtų komponentų ir didele programuotojų bendruomene.

- **Foundation:**  kitas populiarus CSS karkasas, sukurtas kūrimui pirmiausia mobiliesiems.

- **Materialize:**  CSS karkasas, pagrįstas Google Material Design kalba, su iš anksto sukurtais komponentais UI kūrimui.

- **Tailwind CSS:**  pirmiausia įrankių (utility-first) CSS karkasas, orientuotas į pritaikymą ir efektyvumą.

## Sprendimo rezultatas

Apsvarstę variantus, nusprendėme naudoti Tailwind CSS dėl šių priežasčių:

- **Paprasta naudoti:**  Tailwind požiūris paprastas ir lengvai suprantamas. Jo įrankių klasės pagreitina UI kūrimą.

- **Pritaikomas:**  Tailwind leidžia pritaikyti suteikdamas konfigūracijos failų rinkinį, leidžiantį programuotojams lengvai keisti numatytuosius karkaso stilius.

- **Didelė bendruomenės parama:**  Tailwind turi labai aktyvią programuotojų ir dizainerių bendruomenę, nuolat kuriančią naujus išteklius, papildinius ir įrankius.

- **Taupo laiką:**  Tailwind gali sutaupyti laiko, leisdamas programuotojams sutelkti dėmesį į kitas projekto sritis.

Savo projekto UI kurti naudosime Tailwind CSS įrankių klases. Kūrimo komanda naudos jo atominę ir modulinę dizaino sistemą, kad rašytų efektyvų ir keičiamo mastelio CSS kodą. Pasinaudosime Tailwind iš anksto sukurtais šablonais ir vizualiniais komponentais, kad pagreitintume kūrimo procesą, kartu naudodami pasirinktinius stilius, atitinkančius kliento prekės ženklą ir temą.
