## Quyết định

Chúng tôi đã quyết định áp dụng thư viện JavaScript front-end Vue dựa trên các yếu tố sau:

1. **Nhẹ:**  Vue là một thư viện nhẹ cung cấp chức năng tương tự React và Angular nhưng với dấu chân mã nhỏ hơn.

2. **Dễ học:**  Vue có một API đơn giản và trực quan giúp dễ học và dễ dùng.

3. **Tính linh hoạt:**  Vue là một thư viện linh hoạt hoạt động tốt với các thư viện hoặc framework khác để cung cấp các chức năng khác nhau.

4. **Hiệu năng:**  Vue mang lại hiệu năng xuất sắc với kết xuất nhanh và chi phí phụ tối thiểu.

5. **Cộng đồng mạnh:**  Vue có một cộng đồng đang phát triển và mạnh mẽ cung cấp hỗ trợ và tài nguyên cho người dùng.

Quyết định dùng Vue làm thư viện JavaScript front-end chính sẽ có các hệ quả sau:

1. Việc phát triển và bảo trì sẽ nhanh hơn và dễ hơn nhờ sự đơn giản và linh hoạt của Vue.

2. Các thành viên nhóm mới với Vue có thể dễ dàng học và dùng nó nhờ API đơn giản và trực quan.

3. Việc tích hợp với các thư viện hoặc framework khác sẽ dễ hơn nhờ tính linh hoạt của Vue.

4. Ứng dụng sẽ có hiệu năng và khả năng đáp ứng tốt hơn với kết xuất nhanh hơn và chi phí phụ tối thiểu.

5. Nhóm sẽ có quyền truy cập vào một cộng đồng đang phát triển và mạnh mẽ cung cấp hỗ trợ và tài nguyên cho Vue.
