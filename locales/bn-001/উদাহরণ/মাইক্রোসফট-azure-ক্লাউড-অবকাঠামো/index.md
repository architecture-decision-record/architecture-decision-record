# আর্কিটেকচার সিদ্ধান্ত রেকর্ড: মাইক্রোসফট Azure ক্লাউড অবকাঠামো

সিদ্ধান্তের শিরোনাম: আমাদের সংগঠনের ক্লাউড অবকাঠামো হিসেবে মাইক্রোসফট Azure গ্রহণ

সিদ্ধান্ত গ্রহণকারী: প্রধান তথ্য কর্মকর্তা

তারিখ: 2021-10-15

অবস্থা: অনুমোদিত

## পটভূমি

সংগঠনটি ঐতিহ্যবাহী অন-প্রেমিসেস অবকাঠামো থেকে ক্লাউড অবকাঠামোয় স্থানান্তরের পরিকল্পনা করছে। এটি অর্জন করতে সংগঠনটি অ্যামাজন ওয়েব সার্ভিসেস (AWS), গুগল ক্লাউড প্ল্যাটফর্ম (GCP), মাইক্রোসফট Azure এবং IBM Cloud-এর মতো একাধিক ক্লাউড সেবা প্রদানকারী মূল্যায়ন করেছে। প্রতিটি প্রদানকারীর নিজস্ব বৈশিষ্ট্য, সুবিধা ও মূল্য কাঠামো আছে। বিস্তারিত বিশ্লেষণের পর সিদ্ধান্তে আসা হয়েছে যে আমাদের সংগঠনের জন্য মাইক্রোসফট Azure সবচেয়ে উপযুক্ত বিকল্প।

## সিদ্ধান্ত

আমাদের সংগঠনের ক্লাউড অবকাঠামো হিসেবে মাইক্রোসফট Azure গ্রহণ করা।

## যুক্তি

মাইক্রোসফট Azure গ্রহণের কারণগুলো নিম্নরূপ:

1. ব্যাপক সেবা: Azure সেবা হিসেবে অবকাঠামো (IaaS) থেকে সেবা হিসেবে সফটওয়্যার (SaaS) এবং সেবা হিসেবে প্ল্যাটফর্ম (PaaS) পর্যন্ত ক্লাউড সেবার একটি সম্পূর্ণ পরিসর দেয়। এটি আমাদের স্টোরেজ, কম্পিউট, নেটওয়ার্কিং ও বিশ্লেষণের মতো সংগঠনের প্রয়োজন মেটাতে Azure সেবা কাজে লাগাতে সক্ষম করে।

2. সম্প্রসারণযোগ্যতা ও নমনীয়তা: Azure দিয়ে আমরা আমাদের ব্যবসার প্রয়োজন অনুযায়ী সহজেই সম্পদ বাড়াতে বা কমাতে পারি। Azure অপারেটিং সিস্টেম, প্রোগ্রামিং ভাষা ও ফ্রেমওয়ার্ক বেছে নেওয়ার নমনীয়তাও দেয়।

3. নিরাপত্তা ও সম্মতি: Azure উচ্চ মাত্রার নিরাপত্তা ও সম্মতি দেয়, কারণ এটি ISO, SOC, HIPAA ও PCI DSS-এর মতো একাধিক শিল্প মান মেনে চলে। Azure নেটওয়ার্ক সিকিউরিটি গ্রুপ, ফায়ারওয়াল ও DDoS সুরক্ষার মতো উন্নত নিরাপত্তা বৈশিষ্ট্যও দেয়।

4. হাইব্রিড ক্লাউড: Azure নির্বিঘ্ন হাইব্রিড ক্লাউড অভিজ্ঞতা দেয়, যা সংগঠনগুলোকে তাদের অন-প্রেমিসেস অবকাঠামো Azure-এর সঙ্গে সংযুক্ত করতে সক্ষম করে। এটি আমাদের জন্য ওয়ার্কলোড ক্লাউডে স্থানান্তর সহজ করে এবং ডেটা কোথায় সংরক্ষণ করব তা বেছে নেওয়ার নমনীয়তা দেয়।

5. খরচ-সাশ্রয়ী: Azure ব্যবহার-অনুযায়ী-মূল্য (pay-as-you-go) মডেল দেয়, অর্থাৎ আমরা কেবল ব্যবহৃত সম্পদের জন্যই মূল্য দিই। ঐতিহ্যবাহী অন-প্রেমিসেস অবকাঠামোর তুলনায় এটি আমাদের খরচ বাঁচাতে সাহায্য করে।

## উপসংহার

আমাদের সংগঠনের ক্লাউড অবকাঠামো হিসেবে মাইক্রোসফট Azure গ্রহণ আমাদের ব্যবসার প্রয়োজনের সঙ্গে সামঞ্জস্যপূর্ণ এবং সম্প্রসারণযোগ্যতা, নমনীয়তা, নিরাপত্তা ও খরচ-সাশ্রয়ের মতো বেশ কয়েকটি সুবিধা দেয়। তাই আমাদের ক্লাউড অবকাঠামো হিসেবে Azure গ্রহণের সুপারিশ করা হচ্ছে।
