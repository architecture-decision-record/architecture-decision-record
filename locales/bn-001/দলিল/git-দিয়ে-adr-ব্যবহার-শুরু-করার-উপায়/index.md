# git দিয়ে ADR ব্যবহার শুরু করার উপায়

আপনি যদি git ভার্সন কন্ট্রোল ব্যবহার করতে পছন্দ করেন, তাহলে সোর্স কোডসহ একটি সাধারণ সফটওয়্যার প্রকল্পে আমরা যেভাবে git দিয়ে ADR ব্যবহার শুরু করতে পছন্দ করি, তা এখানে দেওয়া হলো।

ADR ফাইলের জন্য একটি ডিরেক্টরি তৈরি করুন:

```sh
$ mkdir adr
```

প্রতিটি ADR-এর জন্য একটি টেক্সট ফাইল তৈরি করুন, যেমন `database.txt`:

```sh
$ vi database.txt
```

ADR-এ আপনার যা খুশি লিখুন। ধারণার জন্য এই রিপোজিটরির টেমপ্লেটগুলো দেখুন।

ADR-টি আপনার git রিপোতে কমিট করুন।
