## টুল দিয়ে ADR ব্যবহার শুরু করার উপায়

আপনি যেভাবে খুশি টুল দিয়ে ADR ব্যবহার শুরু করতে পারেন।

উদাহরণস্বরূপ:

  * আপনি যদি Google Drive ও অনলাইন সম্পাদনা ব্যবহার করতে পছন্দ করেন, তাহলে একটি Google Doc বা Google Sheet তৈরি করতে পারেন।

  * আপনি যদি git-এর মতো সোর্স কোড ভার্সন কন্ট্রোল ব্যবহার করতে পছন্দ করেন, তাহলে প্রতিটি ADR-এর জন্য একটি ফাইল তৈরি করতে পারেন।

  * আপনি যদি Atlassian Jira-র মতো প্রকল্প পরিকল্পনা টুল ব্যবহার করতে পছন্দ করেন, তাহলে টুলটির পরিকল্পনা ট্র্যাকার ব্যবহার করতে পারেন।

  * আপনি যদি MediaWiki-র মতো উইকি ব্যবহার করতে পছন্দ করেন, তাহলে একটি ADR উইকি তৈরি করতে পারেন।
