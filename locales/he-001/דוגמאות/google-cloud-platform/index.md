# רשומת החלטה ארכיטקטונית ל-Google Cloud Platform

## הקשר

Google Cloud Platform (GCP) היא פלטפורמת מחשוב ענן בולטת שמציעה שירותי ענן שונים, כולל פתרונות מחשוב, אחסון ורשתות. ה-ADR הזו נועדה לתעד את ההחלטות הארכיטקטוניות שהתקבלו לפיתוח ולמימוש תשתית מבוססת GCP עבור הארגון שלנו.

## החלטה

הארגון שלנו החליט להשתמש ב-Google Cloud Platform כתשתית הענן ליישום שלנו. השיקולים העיקריים להחלטה הזו הם:

   - יעילות עלויות

   - יכולת הרחבה

   - אמינות

   - גמישות

## בחירות

השירותים הבאים של GCP נבחרו כדי לעמוד בדרישותינו:

   - Compute Engine למכונות וירטואליות ולמשאבי מחשוב

   - Cloud Storage לאחסון אובייקטים ולאירוח קבצים

   - Cloud SQL לשירות מסד נתונים מנוהל

   - Firebase לפיתוח יישומים ולאירוח

## נימוק

   - יעילות עלויות: Google Cloud Platform יעילה מאוד מבחינת עלויות בהשוואה לפלטפורמות ענן אחרות, מה שהופך אותה לאפשרות מושכת לארגונים עם מגבלות תקציב.

   - יכולת הרחבה: התשתית של GCP, שקל להרחיב, מאפשרת לטפל בכל כמות תעבורה בזמן אמת.

   - אמינות: השירותים המנוהלים של GCP מציעים אמינות גבוהה, עם גיבויים אוטומטיים ויכולות התאוששות מאסון שמבטיחות זמינות גבוהה של משאבים ונתונים.

   - גמישות: הפלטפורמה מספקת כלים ושירותים שונים בתחומים שונים כמו בינה מלאכותית, ניתוח נתונים ו-IoT, מה שהופך אותה לרב-גונית מאוד.

## השלכות

המעבר ל-Google Cloud Platform ידרוש הדרכת הצוותים שלנו בשירותי GCP, ארכיטקטורה מחדש של היישום כך שיתאים לשירותים שנבחרו, ועדכון קוד התשתית כך שיתמוך בשירותי GCP. עם זאת, צפוי שאחרי השלמת המעבר תהיה לנו תשתית ניתנת להרחבה מאוד, אמינה וחסכונית לאירוח היישום שלנו. כמו כן, נצטרך לנהל את העלויות השוטפות של הקצאת משאבים ב-GCP.

## סיכום

Google Cloud Platform היא בחירה מצוינת לתשתית הענן שלנו בשל יעילות העלויות, יכולת ההרחבה, האמינות והגמישות שלה. באמצעות השירותים שנבחרו, נוכל לספק תשתית זמינה מאוד וחסינה ליישום שלנו.
