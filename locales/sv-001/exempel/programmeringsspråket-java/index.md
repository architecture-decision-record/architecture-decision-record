Vårt projekt krävde ett språk som kunde erbjuda starka säkerhetsfunktioner, hantera samtidighet, stödja stora kodbaser och vara tillräckligt mångsidigt för att möta våra framtida tillväxtkrav. ### Överväganden

1. **Säkerhet:**  Java erbjuder utmärkta säkerhetsfunktioner genom sina väldefinierade säkerhetspolicyer och åtkomstkontroll. Det innehåller också funktioner som bytekodsverifiering, vilket hjälper till att förhindra att skadlig programvara körs på ett system.

2. **Samtidighet:**  Java har inbyggt stöd för multitrådning, vilket gör att applikationer kan utföra flera uppgifter samtidigt. Den här funktionen gör Java till ett utmärkt val för att utveckla stora, komplexa applikationer med många funktioner och funktionaliteter.

3. **Stora kodbaser:**  Java stöder objektorienterad programmering, vilket gör det till ett lämpligt val för att utveckla stora kodbaser. Dess modulära natur och användning av inkapslings- och abstraktionsmönster underlättar ytterligare programvaruutvecklingsprocessen.

4. **Mångsidighet:**  Java är mångsidigt och ger möjlighet att använda ett brett utbud av bibliotek och ramverk, vilket gör det till ett utmärkt val för både webbaserade och företagsnivåapplikationer.

3. Att införliva nya funktioner, funktionaliteter eller ramverk kan innebära vissa utmaningar.

4. Stora, komplexa projekt i Java kan kräva mer tid och resurser att utveckla.
