# Arkitekturbeslutspost: Molninfrastruktur med Microsoft Azure" 

Beslutstitel: Införande av Microsoft Azure som molninfrastruktur för vår organisation

Beslutsfattare: Informationschef

Datum: 2021-10-15

Tillstånd: Godkänd

## Bakgrund

Organisationen planerar att migrera från traditionell infrastruktur på plats till molninfrastruktur. För att uppnå detta har organisationen utvärderat flera molntjänstleverantörer som Amazon Web Services (AWS), Google Cloud Platform (GCP), Microsoft Azure och IBM Cloud. Varje leverantör har sin egen uppsättning funktioner, fördelar och prisstruktur. Efter en detaljerad analys drogs slutsatsen att Microsoft Azure är det mest lämpliga alternativet för vår organisation.

## Beslut

Anta Microsoft Azure som molninfrastruktur för vår organisation.

## Motivering

Följande är skälen för att anta Microsoft Azure:

1. Omfattande tjänster: Azure tillhandahåller ett komplett utbud av molntjänster från infrastruktur som en tjänst (IaaS) till programvara som en tjänst (SaaS) och plattform som en tjänst (PaaS). Det gör att vi kan utnyttja Azure-tjänster för att lösa organisationens krav, som lagring, beräkning, nätverk och analys.

2. Skalbarhet och flexibilitet: Med Azure kan vi enkelt skala resurser uppåt eller nedåt utifrån våra affärskrav. Azure erbjuder också flexibilitet i valet av operativsystem, programmeringsspråk och ramverk.

3. Säkerhet och efterlevnad: Azure erbjuder en hög nivå av säkerhet och efterlevnad, eftersom det uppfyller flera branschstandarder som ISO, SOC, HIPAA och PCI DSS. Azure tillhandahåller också avancerade säkerhetsfunktioner som nätverkssäkerhetsgrupper, brandväggar och DDoS-skydd.

4. Hybridmoln: Azure erbjuder en sömlös hybridmolnupplevelse som gör det möjligt för organisationer att ansluta sin infrastruktur på plats till Azure. Det gör det enkelt för oss att migrera arbetslaster till molnet och ger oss flexibiliteten att välja var data ska lagras.

5. Kostnadseffektivt: Azure erbjuder en betala-per-användning-prismodell, vilket innebär att vi bara betalar för de resurser som används. Det hjälper oss att spara kostnader jämfört med traditionell infrastruktur på plats.

## Slutsats

Att anta Microsoft Azure som molninfrastruktur för vår organisation stämmer överens med våra affärskrav och erbjuder flera fördelar som skalbarhet, flexibilitet, säkerhet och kostnadseffektivitet. Därför rekommenderas det att anta Azure som vår molninfrastruktur.
