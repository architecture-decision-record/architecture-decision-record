# आर्किटेक्चर निर्णय रिकॉर्ड: Microsoft Azure क्लाउड अवसंरचना

निर्णय का शीर्षक: हमारे संगठन की क्लाउड अवसंरचना के रूप में Microsoft Azure को अपनाना

निर्णयकर्ता: मुख्य सूचना अधिकारी

तिथि: 2021-10-15

अवस्था: अनुमोदित

## पृष्ठभूमि

संगठन पारंपरिक ऑन-प्रिमाइसेस अवसंरचना से क्लाउड अवसंरचना पर जाने की योजना बना रहा है। इसे प्राप्त करने के लिए, संगठन ने कई क्लाउड सेवा प्रदाताओं, जैसे Amazon Web Services (AWS), Google Cloud Platform (GCP), Microsoft Azure और IBM Cloud का मूल्यांकन किया है। प्रत्येक प्रदाता की अपनी सुविधाओं, लाभों और मूल्य निर्धारण संरचना का समूह है। विस्तृत विश्लेषण के बाद, यह निष्कर्ष निकला कि Microsoft Azure हमारे संगठन के लिए सबसे उपयुक्त विकल्प है।

## निर्णय

हमारे संगठन की क्लाउड अवसंरचना के रूप में Microsoft Azure अपनाएँ।

## तर्क

Microsoft Azure अपनाने के कारण ये हैं:

1. व्यापक सेवाएँ: Azure सेवा के रूप में अवसंरचना (IaaS) से लेकर सेवा के रूप में सॉफ़्टवेयर (SaaS) और सेवा के रूप में प्लेटफ़ॉर्म (PaaS) तक क्लाउड सेवाओं की पूरी श्रृंखला प्रदान करता है। इससे हम संगठन की आवश्यकताओं, जैसे स्टोरेज, कंप्यूट, नेटवर्किंग और विश्लेषण, को हल करने के लिए Azure सेवाओं का उपयोग कर सकते हैं।

2. विस्तार क्षमता और लचीलापन: Azure के साथ, हम अपनी व्यावसायिक आवश्यकताओं के आधार पर आसानी से संसाधनों को बढ़ा या घटा सकते हैं। Azure ऑपरेटिंग सिस्टम, प्रोग्रामिंग भाषा और फ़्रेमवर्क चुनने में भी लचीलापन देता है।

3. सुरक्षा और अनुपालन: Azure उच्च स्तर की सुरक्षा और अनुपालन प्रदान करता है, क्योंकि वह ISO, SOC, HIPAA और PCI DSS जैसे कई उद्योग मानकों का अनुपालन करता है। Azure नेटवर्क सुरक्षा समूह, फ़ायरवॉल और DDoS सुरक्षा जैसी उन्नत सुरक्षा सुविधाएँ भी देता है।

4. हाइब्रिड क्लाउड: Azure निर्बाध हाइब्रिड क्लाउड अनुभव देता है, जिससे संगठन अपनी ऑन-प्रिमाइसेस अवसंरचना को Azure से जोड़ सकते हैं। इससे हमारे लिए कार्यभार को क्लाउड पर ले जाना आसान होता है और डेटा कहाँ संग्रहीत करें, यह चुनने की लचीलापन मिलती है।

5. लागत-प्रभावी: Azure उपयोग के अनुसार भुगतान की मूल्य निर्धारण प्रणाली देता है, जिसका अर्थ है कि हम केवल उपयोग किए गए संसाधनों के लिए भुगतान करते हैं। पारंपरिक ऑन-प्रिमाइसेस अवसंरचना की तुलना में इससे लागत बचाने में मदद मिलती है।

## निष्कर्ष

हमारे संगठन की क्लाउड अवसंरचना के रूप में Microsoft Azure अपनाना हमारी व्यावसायिक आवश्यकताओं के अनुरूप है और विस्तार क्षमता, लचीलापन, सुरक्षा और लागत-प्रभावशीलता जैसे कई लाभ प्रदान करता है। इसलिए, Azure को हमारी क्लाउड अवसंरचना के रूप में अपनाने की अनुशंसा की जाती है।
