# 架构决策记录:编程代码编辑器

## 背景

编程代码编辑器是开发人员编写和编辑代码的必备工具。市面上有众多代码编辑器,各有其功能、优点和缺点。本 ADR 的目的是记录针对编程代码编辑器所做的架构决策。

## 优先事项

编程代码编辑器的架构应优先考虑以下几点:

* **模块化**:代码编辑器应以模块化的方式设计,使开发人员能够根据需要对其进行定制和扩展。这样可以形成灵活的架构,适应不同开发人员和团队的需求。

* **性能**:代码编辑器应当高性能且响应迅速,使开发人员能够高效工作,而不会被所用的工具拖慢。

* **用户界面**:用户界面应当直观易用,使开发人员能够专注于代码,而不必与编辑器较劲。

* **可扩展性**:代码编辑器的设计应便于通过第三方插件和集成进行扩展。

* **兼容性**:代码编辑器应兼容多种编程语言和技术,使其成为适合广大开发人员的实用工具。

## 决策

基于这些优先事项,编程代码编辑器的架构应设计为包含以下组件:

* **核心**:该组件提供代码编辑器的基本功能,例如语法高亮、文本编辑和文件管理。

* **UI**:该组件提供代码编辑器的用户界面,包括菜单、工具栏和键盘快捷键。

* **插件**:该组件允许开发人员通过安装第三方插件来扩展代码编辑器的功能。插件可以提供额外的功能,例如代码补全、代码检查(lint)或调试。

* **集成**:该组件允许代码编辑器与其他工具和技术集成,例如版本控制系统、构建系统或调试工具。

## 理由

代码编辑器的模块化使开发人员能够根据需要对其进行定制和扩展。这一点很重要,因为不同的开发人员和团队有不同的需求和工作流程,灵活的架构可以适应这些差异。

* **性能**:至关重要,因为开发人员需要能够高效工作,而不会被工具拖慢。高性能的代码编辑器对生产率至关重要,并有助于开发人员保持专注。

* **UI**:很重要,因为它使开发人员能够专注于代码,而不必与编辑器较劲。这可以带来更高的生产率,并减少开发人员的挫败感。

* **可扩展性**:很强大,因为它使代码编辑器能够适应不同的需求和工作流程。第三方插件和集成可以提供核心编辑器所不具备的额外特性和能力。

* **兼容性**:很有价值,因为它使代码编辑器能够用于多种编程语言和技术。这使该编辑器成为适合广大开发人员的更实用的工具。

核心、插件、集成和 UI 组件实现了清晰的关注点分离,形成了易于扩展和定制的模块化架构。这种架构灵活、高性能,并兼容多种编程语言和技术,使其成为对开发人员有用的工具。
