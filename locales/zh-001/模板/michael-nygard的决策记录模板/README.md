# Michael Nygard 的决策记录模板

这是 [记录架构决策 - Michael Nygard](http://thinkrelevance.com/blog/2011/11/15/documenting-architecture-decisions) 一文中的模板。
你可以使用 [adr-tools](https://github.com/npryce/adr-tools) 来管理 ADR 文件。

在每个 ADR 文件中,撰写以下章节:

# 标题

## 状态

状态是什么,例如已提议、已接受、已拒绝、已弃用、已取代等?

## 背景

我们看到了什么问题,促使我们做出这项决策或变更?

## 决策

我们提议和/或正在做出什么变更?

## 后果

由于这项变更,哪些事情会变得更容易或更困难?
