# 使用 Planguage 的决策记录模板

参见 https://www.iaria.org/conferences2012/filesICCGI12/Tutorial%20Specifying%20Effective%20Non-func.pdf

## 什么是 Planguage?

Planguage 是一种规划语言,使用以下关键字:

* Tag(标签):唯一且持久的标识符
* Gist(要点):对所涉及的需求或领域的简要概述
* Requirement(需求):详细说明需求本身的文字
* Rationale(理由):证明该需求合理的推理
* Priority(优先级):对优先级及资源占用的声明
* Stakeholders(利益相关者):受该需求实质性影响的各方
* Status(状态):需求的状态(草稿、已评审、已承诺等)
* Owner(所有者):负责实现该需求的人
* Author(作者):撰写该需求的人
* Revision(修订):该陈述的版本号
* Date(日期):最近一次修订的日期
* Assumptions(假设):如果现在或将来不成立就可能引发问题的任何事项
* Risks(风险):可能导致故障、延误或其他负面影响的任何事项
* Defined(定义):术语的定义(最好使用术语表)
