# 实现可持续决策的指南

<https://www.infoq.com/articles/sustainable-architectural-design-decisions/>

我们在工作中总结了以下经验教训,可作为实现可持续决策的指南和评估依据:

1. 在最初的决策文档中采用精益/极简的方法。

2. 对所有重要且值得记录、有助于理解目标架构的决策进行优先级排序并加以记录。

3. 只有在初始工作完成之后(即决策者对所做的架构决策感到满意,并确信这些决策短期内无需修订),才使用完整的模板详细记录特别重要的决策。

4. 将第 1 步中的精益/极简版本作为已记录决策的简短版本,以合适的粒度提供详细决策的概览,同时也用于记录琐碎或显而易见的决策。

5. 尽可能利用现有的架构知识,无论来自指导模型还是其他来源。对这些知识进行评审和扩展,并使其适应具体决策的背景。

6. 确保在决策与需求之间,以及决策与架构设计/代码之间建立可追溯性链接。

7. 提供自动化一致性检查,确保变更后可追溯性链接保持同步。限制决策之间以及决策与其他软件制品之间的依赖数量。

8. 坚决而有力地应用关于论证的指南——它们是决策文档中最重要的部分,因为它们给出了理由。
