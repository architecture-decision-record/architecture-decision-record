# Modello di registro delle decisioni di Michael Nygard

Questo è il modello tratto da [Documenting architecture decisions - Michael Nygard](http://thinkrelevance.com/blog/2011/11/15/documenting-architecture-decisions).
Puoi usare [adr-tools](https://github.com/npryce/adr-tools) per gestire i file ADR.

In ogni file ADR scrivi queste sezioni:

# Titolo

## Stato

Qual è lo stato, per esempio proposed, accepted, rejected, deprecated, superseded ecc.?

## Contesto

Qual è il problema che vediamo e che motiva questa decisione o modifica?

## Decisione

Qual è la modifica che stiamo proponendo o realizzando?

## Conseguenze

Che cosa diventa più facile o più difficile a causa di questa modifica?
