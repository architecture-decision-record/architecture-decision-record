# Arhitektūras lēmuma ieraksts: Svelte priekšpuses JavaScript bibliotēka

Statuss: pieņemts

## Konteksts

Mēs izstrādājam tīmekļa lietojumprogrammu, izmantojot modernu priekšpuses JavaScript ietvaru. Mēs vēlamies izvēlēties bibliotēku, kas ir viegla, ātra un viegli lietojama. Esam izvērtējuši vairākas bibliotēkas, tostarp React, Vue un Angular. Esam dzirdējuši arī par Svelte, kas apgalvo, ka ir jauna veida viegls ietvars. Mums jāizvērtē Svelte un jāizlemj, vai tas ir laba izvēle mūsu lietojumprogrammai.

## Lēmums

Pēc katras bibliotēkas ieguvumu un trūkumu apsvēršanas mēs nolēmām izmantot Svelte kā savu priekšpuses JavaScript bibliotēku šādu iemeslu dēļ:

1. **Viegla:**  Svelte ir viena no vieglākajām pieejamajām bibliotēkām, kas palīdzēs mums saglabāt lietojumprogrammas izmēru mazu un uzlabot lapu ielādes laikus.

2. **Ātra:**  Svelte ir pazīstama ar savu ātro renderēšanas ātrumu, kas liks mūsu lietojumprogrammai justies atsaucīgai un raitai.

3. **Viegli lietojama:**  Svelte sintakse ir vienkārša un viegli saprotama, kas mūsu komandai atvieglos tās pieņemšanu un tīra koda rakstīšanu.

4. **Optimizēta UI renderēšanai:**  Svelte ir optimizēta UI komponenšu renderēšanai, kas mums atvieglos dinamisku un atkārtoti izmantojamu UI elementu izveidi.

5. **Laba dokumentācija un kopienas atbalsts:**  Svelte ir augoša kopiena un laba dokumentācija, kas palīdzēs mums ātri sākt un atrisināt jebkuras radušās problēmas.

## Alternatīvas

Mēs apsvērām React, Vue un Angular, bet nolēmām pret tiem šādu iemeslu dēļ:

1. **React:**  lai gan React ir liela lietotāju bāze un daudz bibliotēku un resursu, tas var būt sarežģīts un grūti apgūstams, īpaši iesācējiem.

2. **Vue:**  Vue ir viegla bibliotēka, ko ir viegli apgūt un lietot, taču tā var nebūt tik ātra vai optimizēta kā Svelte.

3. **Angular:**  Angular ir visaptverošs ietvars, kas piedāvā daudz funkciju un rīku, taču tas var būt smags un sarežģīts un var prasīt vairāk uzturēšanas nekā Svelte.

## Sekas

Svelte izmantošanai kā mūsu priekšpuses JavaScript bibliotēkai būs šādas sekas:

1. Mūsu lietojumprogramma būs viegla un ātra, kas uzlabos lietotāja pieredzi un iesaisti.

2. Mūsu komandai būs jāapgūst jauna bibliotēka, taču Svelte sintakse ir vienkārša un viegli saprotama, tāpēc mācīšanās līknei vajadzētu būt pārvaldāmai.

3. Svelte joprojām ir samērā jauna bibliotēka, tāpēc mēs varam saskarties ar dažām problēmām, kas nav labi dokumentētas vai kopienas atbalstītas.

4. Svelte lietotāju kopiena aug, tāpēc nākotnē mēs varam redzēt, ka kļūst pieejami vairāk trešo pušu bibliotēku un resursu, ko var izmantot, lai papildinātu pamata bibliotēku.
