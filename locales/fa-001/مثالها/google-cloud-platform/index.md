# رکورد تصمیم معماری برای Google Cloud Platform

## زمینه

Google Cloud Platform (GCP) یک پلتفرم برجستهٔ رایانش ابری است که خدمات ابری گوناگونی از جمله راه‌حل‌های محاسبات، ذخیره‌سازی و شبکه ارائه می‌دهد. هدف این ADR مستندسازی تصمیم‌های معماری اتخاذشده برای توسعه و پیاده‌سازی زیرساخت مبتنی بر GCP برای سازمان ماست.

## تصمیم

سازمان ما تصمیم گرفته است Google Cloud Platform را به‌عنوان زیرساخت ابری برنامهٔ خود به کار ببرد. ملاحظات اصلی برای این تصمیم عبارت‌اند از:

   - مقرون‌به‌صرفه بودن

   - مقیاس‌پذیری

   - قابلیت اطمینان

   - انعطاف‌پذیری

## انتخاب‌ها

خدمات زیر از GCP برای برآورده کردن نیازمندی‌های ما انتخاب شده‌اند:

   - Compute Engine برای ماشین‌های مجازی و منابع محاسباتی

   - Cloud Storage برای ذخیره‌سازی شیء و میزبانی فایل

   - Cloud SQL برای خدمت پایگاه داده مدیریت‌شده

   - Firebase برای توسعه و میزبانی برنامه

## دلیل و منطق

   - مقرون‌به‌صرفه بودن: Google Cloud Platform در مقایسه با سایر پلتفرم‌های ابری بسیار مقرون‌به‌صرفه است و آن را برای سازمان‌های دارای محدودیت بودجه گزینه‌ای جذاب می‌کند.

   - مقیاس‌پذیری: زیرساخت به‌آسانی مقیاس‌پذیر GCP امکان مدیریت هر میزان ترافیک را به‌صورت بی‌درنگ فراهم می‌کند.

   - قابلیت اطمینان: خدمات مدیریت‌شدهٔ GCP قابلیت اطمینان بالایی دارند و با پشتیبان‌گیری خودکار و قابلیت‌های بازیابی از فاجعه، دسترس‌پذیری بالای منابع و داده‌ها را تضمین می‌کنند.

   - انعطاف‌پذیری: این پلتفرم ابزارها و خدمات گوناگونی در حوزه‌های مختلف مانند هوش مصنوعی، تحلیل داده و IoT ارائه می‌دهد و آن را بسیار همه‌کاره می‌کند.

## پیامدها

مهاجرت به Google Cloud Platform مستلزم آموزش تیم‌های ما دربارهٔ خدمات GCP، بازمعماری برنامه برای سازگاری با خدمات انتخاب‌شده و به‌روزرسانی کد زیرساخت برای پشتیبانی از خدمات GCP خواهد بود. با این حال، انتظار می‌رود پس از تکمیل مهاجرت، زیرساختی بسیار مقیاس‌پذیر، قابل‌اعتماد و مقرون‌به‌صرفه برای میزبانی برنامهٔ خود داشته باشیم. همچنین باید هزینه‌های جاری تأمین منابع روی GCP را مدیریت کنیم.

## نتیجه‌گیری

Google Cloud Platform به دلیل مقرون‌به‌صرفه بودن، مقیاس‌پذیری، قابلیت اطمینان و انعطاف‌پذیری، انتخابی عالی برای زیرساخت ابری ماست. با استفاده از خدمات انتخاب‌شده، می‌توانیم زیرساختی بسیار در دسترس و مقاوم برای برنامهٔ خود فراهم کنیم.
