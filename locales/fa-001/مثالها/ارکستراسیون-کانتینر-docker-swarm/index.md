## زمینه

در حال بررسی ابزارهای مختلف ارکستراسیون کانتینر برای مدیریت معماری مبتنی بر میکروسرویس خود هستیم. راه‌حل‌های مختلفی مانند Kubernetes، Docker Swarm و Mesosphere DC/OS را ارزیابی کرده‌ایم. با این حال، به دلیل سادگی، یکپارچگی با Docker و توزیع بار داخلی، تصمیم گرفته‌ایم روی Docker Swarm تمرکز کنیم.

## تصمیم

تصمیم گرفته‌ایم از Docker Swarm به‌عنوان ابزار ارکستراسیون کانتینر استفاده کنیم. Docker Swarm راهی ساده و شهودی برای مدیریت برنامه‌های کانتینری در یک خوشه از گره‌ها فراهم می‌کند. همچنین به ما اجازه می‌دهد از گردش‌های کار و زیرساخت مبتنی بر Docker موجود خود بهره ببریم. با Docker Swarm می‌توانیم به‌آسانی برنامه‌های خود را مستقر، مقیاس‌دهی و مدیریت کنیم و در عین حال از توزیع بار داخلی بهره‌مند شویم.

## مزایا

- **سادگی:** Docker Swarm از همان اصول Docker پیروی می‌کند، بنابراین نیازی به یادگیری فناوری جدید نیست. منحنی یادگیری برای توسعه‌دهندگانی که با Docker آشنا هستند نسبتاً کم‌شیب است.

- **یکپارچگی:** Docker Swarm به‌طور یکپارچه با ابزارهای Docker مانند Docker Compose ادغام می‌شود و مدیریت همهٔ کانتینرها و سرویس‌های ما را از یک مکان آسان‌تر می‌کند.

- **توزیع بار:** Docker Swarm توزیع بار داخلی ارائه می‌دهد و تضمین می‌کند برنامه‌های ما همیشه در دسترس‌اند و به‌طور یکنواخت در خوشه توزیع شده‌اند.

- **مقیاس‌پذیری:** Docker Swarm با افزودن یا حذف گره‌ها از خوشه، مقیاس‌دهی افقی برنامه‌های ما را آسان می‌کند.

- **دسترس‌پذیری بالا:** Docker Swarm سرویس‌های ما را به‌طور خودکار میان گره‌ها توزیع می‌کند و در صورت خرابی گره دسترس‌پذیری بالا فراهم می‌کند.

## ریسک‌ها

- **قابلیت‌های محدود:** Docker Swarm ممکن است برخی ویژگی‌های پیشرفتهٔ موجود در Kubernetes یا Mesosphere DC/OS، مانند مقیاس‌دهی خودکار یا خودترمیمی، را نداشته باشد.

- **وابستگی به Docker:** Docker Swarm به‌شدت با Docker جفت شده است، که ممکن است اگر روزی نیاز داشته باشیم از راه‌حل‌های مبتنی بر Docker دور شویم انعطاف ما را محدود کند.

- **نابالغی:** Docker Swarm هنوز فناوری نسبتاً جدیدی است و ممکن است مشکلات پایداری یا خلأهایی در مستندات وجود داشته باشد.

## جایگزین‌ها

- **Kubernetes:** Kubernetes پرکاربردترین پلتفرم ارکستراسیون کانتینر است و ویژگی‌های پیشرفته و اکوسیستم بالغ‌تری ارائه می‌دهد. با این حال، منحنی یادگیری تندتری دارد و ممکن است برای نیازهای ما زیادی باشد.

- **Mesosphere DC/OS:** Mesosphere DC/OS ابزاری قدرتمند است که ویژگی‌های پیشرفته‌ای مانند پشتیبانی چندابری و قابلیت‌های بومی پلتفرم کلان‌داده و هوش مصنوعی ارائه می‌دهد. با این حال، پیاده‌سازی آن مهارت قابل‌توجهی می‌طلبد و ممکن است برای نیازمندی‌های ما بیش‌ازحد پیچیده باشد.
