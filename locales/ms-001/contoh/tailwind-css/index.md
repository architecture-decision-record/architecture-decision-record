# Rekod Keputusan Seni Bina: Tailwind CSS

Keputusan: Gunakan Tailwind CSS sebagai rangka kerja CSS untuk menggayakan antara muka pengguna.

## Apakah Tailwind CSS?

Tailwind ialah rangka kerja CSS utiliti-dahulu yang membolehkan pembangunan pantas dan penyesuaian antara muka pengguna. Ia direka untuk sangat boleh disesuaikan dan membolehkan pembangun menulis CSS yang lebih ramping dan lebih cekap. Rangka kerja ini menyediakan set kelas pratakrif untuk menggayakan UI dengan sangat pantas.

## Konteks

Kami sedang membina aplikasi web untuk pelanggan yang memerlukan antara muka pengguna responsif dan boleh disesuaikan. Pelanggan telah meminta penggayaan yang konsisten dan moden. Pasukan pembangunan mempunyai pengalaman menggunakan CSS tersuai tetapi mahu meneroka rangka kerja CSS yang boleh menjimatkan masa dan usaha. Kami mencari rangka kerja yang mudah digunakan, boleh disesuaikan dan mempunyai komuniti besar untuk sokongan.

## Pemacu Keputusan

- **Mudah digunakan:**  Kami mahu rangka kerja yang mudah dipelajari dan boleh disepadukan ke dalam aliran kerja pembangunan kami.

- **Boleh disesuaikan:**  Kami mahu rangka kerja yang boleh disesuaikan agar sepadan dengan garis panduan jenama dan tema pelanggan.

- **Sokongan komuniti besar:**  Kami mahu rangka kerja yang mempunyai komuniti aktif pembangun dan pereka yang boleh menyediakan bantuan dan sumber apabila diperlukan.

- **Menjimatkan masa:**  Kami mahu rangka kerja yang boleh menjimatkan masa dan usaha dalam menggayakan UI.

## Pilihan yang Dipertimbangkan

- **Bootstrap:**  Rangka kerja CSS popular dengan banyak komponen pra-binaan dan komuniti besar pembangun.

- **Foundation:**  Satu lagi rangka kerja CSS popular yang direka untuk pembangunan mudah-alih-dahulu.

- **Materialize:**  Rangka kerja CSS berdasarkan bahasa Material Design Google dengan komponen pra-binaan untuk pembangunan UI.

- **Tailwind CSS:**  Rangka kerja CSS utiliti-dahulu dengan tumpuan pada penyesuaian dan kecekapan.

## Hasil Keputusan

Selepas mempertimbangkan pilihan, kami memutuskan untuk menggunakan Tailwind CSS atas sebab berikut:

- **Sokongan komuniti besar:**  Tailwind mempunyai komuniti pembangun dan pereka yang sangat aktif yang sentiasa mencipta sumber, pemalam dan alat baharu.
