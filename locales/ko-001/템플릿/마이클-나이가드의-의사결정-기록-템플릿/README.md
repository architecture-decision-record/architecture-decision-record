# Michael Nygard의 의사결정 기록 템플릿

이것은 [Documenting architecture decisions - Michael Nygard](http://thinkrelevance.com/blog/2011/11/15/documenting-architecture-decisions)의 템플릿입니다.
ADR 파일을 관리하는 데 [adr-tools](https://github.com/npryce/adr-tools)를 사용할 수 있습니다.

각 ADR 파일에 다음 섹션을 작성하십시오:

# 제목

## 상태

상태는 무엇입니까? 예: proposed, accepted, rejected, deprecated, superseded 등.

## 맥락

이 결정이나 변경을 동기 부여하는, 우리가 보고 있는 문제는 무엇입니까?

## 결정

우리가 제안하고 있거나 수행하고 있는 변경은 무엇입니까?

## 결과

이 변경으로 인해 무엇이 더 쉬워지거나 더 어려워집니까?
