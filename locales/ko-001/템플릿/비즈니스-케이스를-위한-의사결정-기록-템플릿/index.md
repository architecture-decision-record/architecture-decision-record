# 비즈니스 케이스를 위한 의사결정 기록 템플릿

이 ADR 템플릿은 기준, 후보, 비용을 포함하여 결정을 위한 비즈니스 케이스를 작성하는 것을 강조합니다.


## 최상위 수준

* 제목
* 상태
* 평가 기준
* 고려할 후보
* 각 후보에 대한 조사 및 분석
  * 기준 충족/미충족 여부와 그 이유
  * 비용 분석
  * SWOT 분석
  * 의견과 피드백
* 권고

  * git 커밋 메시지처럼 50자 미만의 짧은 현재 시제 명령형 문구.

  * 기준 충족/미충족 여부와 그 이유

  * 비용 분석

      * 운영. 예: 지원과 유지보수

      * 품질 속성, 일명 기능 간 요구사항 

  * 외부 의견과 피드백

    * 요약

        * 지금 알고 있는 것을 바탕으로, 사람들에게 무엇을 다르게 하라고 조언하겠습니까?
