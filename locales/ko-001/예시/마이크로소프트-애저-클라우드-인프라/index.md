# 아키텍처 의사결정 기록: Microsoft Azure 클라우드 인프라

결정 제목: 우리 조직의 클라우드 인프라로 Microsoft Azure 도입

결정권자: 최고정보책임자(CIO)

날짜: 2021-10-15

상태: 승인됨

## 배경

조직은 기존의 온프레미스 인프라에서 클라우드 인프라로 마이그레이션할 계획입니다. 이를 달성하기 위해 조직은 Amazon Web Services(AWS), Google Cloud Platform(GCP), Microsoft Azure, IBM Cloud 같은 여러 클라우드 서비스 제공업체를 평가했습니다. 각 제공업체는 고유한 기능, 이점, 가격 구조를 가지고 있습니다. 상세한 분석 끝에 Microsoft Azure가 우리 조직에 가장 적합한 선택지라고 결론 내렸습니다.

## 결정

우리 조직의 클라우드 인프라로 Microsoft Azure를 도입합니다.

## 근거

Microsoft Azure를 도입하는 이유는 다음과 같습니다:

1. 포괄적인 서비스: Azure는 서비스형 인프라(IaaS)부터 서비스형 소프트웨어(SaaS), 서비스형 플랫폼(PaaS)까지 전체 범위의 클라우드 서비스를 제공합니다. 이를 통해 Azure 서비스를 활용하여 스토리지, 컴퓨팅, 네트워킹, 분석 같은 조직의 요구사항을 해결할 수 있습니다.

2. 확장성과 유연성: Azure를 사용하면 비즈니스 요구사항에 따라 리소스를 쉽게 확장하거나 축소할 수 있습니다. Azure는 운영 체제, 프로그래밍 언어, 프레임워크 선택에서도 유연성을 제공합니다.

3. 보안과 규정 준수: Azure는 ISO, SOC, HIPAA, PCI DSS 같은 여러 업계 표준을 준수하므로 높은 수준의 보안과 규정 준수를 제공합니다. 또한 Azure는 네트워크 보안 그룹, 방화벽, DDoS 보호 같은 고급 보안 기능을 제공합니다.

4. 하이브리드 클라우드: Azure는 조직이 온프레미스 인프라를 Azure와 연결할 수 있는 매끄러운 하이브리드 클라우드 경험을 제공합니다. 이 덕분에 워크로드를 클라우드로 쉽게 마이그레이션할 수 있고 데이터를 어디에 저장할지 선택하는 유연성도 얻습니다.

5. 비용 효율성: Azure는 사용한 만큼 지불하는 가격 모델을 제공하므로 사용한 리소스에 대해서만 비용을 지불합니다. 이는 기존 온프레미스 인프라와 비교하여 비용을 절감하는 데 도움이 됩니다.

## 결론

우리 조직의 클라우드 인프라로 Microsoft Azure를 도입하는 것은 비즈니스 요구사항과 부합하며 확장성, 유연성, 보안, 비용 효율성 같은 여러 이점을 제공합니다. 따라서 Azure를 클라우드 인프라로 도입할 것을 권고합니다.
