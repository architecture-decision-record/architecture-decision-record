# Google Cloud Platform에 대한 아키텍처 의사결정 기록

## 맥락

Google Cloud Platform(GCP)은 컴퓨팅, 스토리지, 네트워킹 솔루션을 포함한 다양한 클라우드 서비스를 제공하는 대표적인 클라우드 컴퓨팅 플랫폼입니다. 이 ADR은 우리 조직을 위한 GCP 기반 인프라를 개발하고 구현하기 위해 내려진 아키텍처 결정을 문서화하는 것을 목표로 합니다.

## 결정

우리 조직은 애플리케이션의 클라우드 인프라로 Google Cloud Platform을 사용하기로 결정했습니다. 이 결정의 주요 고려 사항은 다음과 같습니다:

   - 비용 효율성

   - 확장성

   - 신뢰성

   - 유연성

## 선택 사항

요구사항을 충족하기 위해 GCP의 다음 서비스를 선택했습니다:

   - 가상 머신과 컴퓨팅 리소스를 위한 Compute Engine

   - 객체 스토리지와 파일 호스팅을 위한 Cloud Storage

   - 관리형 데이터베이스 서비스를 위한 Cloud SQL

   - 앱 개발과 호스팅을 위한 Firebase

## 근거

   - 비용 효율성: Google Cloud Platform은 다른 클라우드 플랫폼에 비해 비용 효율성이 매우 높아 예산 제약이 있는 조직에 매력적인 선택지입니다.

   - 확장성: GCP의 확장하기 쉬운 인프라는 어떤 양의 트래픽도 실시간으로 처리할 수 있게 합니다.

   - 신뢰성: GCP의 관리형 서비스는 자동 백업과 재해 복구 기능으로 리소스와 데이터의 높은 가용성을 보장하는 높은 신뢰성을 제공합니다.

   - 유연성: 이 플랫폼은 AI, 데이터 분석, IoT 등 다양한 영역에 걸쳐 여러 도구와 서비스를 제공하므로 매우 다재다능합니다.

## 결과

Google Cloud Platform으로 마이그레이션하려면 팀에게 GCP 서비스를 교육하고, 선택한 서비스와 호환되도록 애플리케이션을 재설계하고, GCP 서비스를 지원하도록 인프라 코드를 갱신해야 합니다. 그러나 마이그레이션이 완료되면 확장성, 신뢰성, 비용 효율성이 높은 인프라를 갖추게 될 것으로 기대됩니다. 또한 GCP에서 리소스를 프로비저닝하는 데 따르는 지속적인 비용을 관리해야 합니다.

## 결론

Google Cloud Platform은 비용 효율성, 확장성, 신뢰성, 유연성 때문에 우리 클라우드 인프라에 훌륭한 선택입니다. 선택한 서비스를 활용하여 애플리케이션에 가용성이 높고 견고한 인프라를 제공할 수 있습니다.
