# Architektur-Decisiounsopzeechnung fir Amazon Web Services

Titel: Unhuele vun Amazon Web Services fir d'Cloud-Infrastruktur

## Decisioun

No enger grëndlecher Evaluatioun vu verschiddene Cloud-Infrastrukturplattformen gouf decidéiert, datt Amazon Web Services (AWS) vun eiser Organisatioun fir eis Cloud-Infrastrukturbedierfnisser ugeholl gëtt.

## Hannergrond

Eis Organisatioun wiisst séier, an et brauch eng zouverlässeg a skaléierbar Cloud-Infrastruktur, fir d'Ufuerderunge vun eisem Geschäft ze erfëllen. Nodeems verschidde Cloud-Infrastrukturanbieter berécksiichtegt goufen, gouf festgestallt, datt AWS déi gëeegnetst Palette u Servicer bitt, fir eis aktuell a zukünfteg Ufuerderungen ze erfëllen.

## Iwwerleeungen

Et gëtt zuelräich Cloud-Infrastrukturanbieter um Maart, déi sech als zouverlässeg an effizient bewisen hunn. AWS bitt awer net nëmmen e ëmfaassende Satz u Servicer, fir eis Bedierfnisser ze decken, mee huet och eng breet Clientebasis an eng Erfolleg bei erfollegräichen Deployments. AWS stellt och eng breet Palette u Support- a Formatiounsressource zur Verfügung, fir sécherzestellen, datt eis Team effektiv mat der Plattform schaffe kann.

Ausserdeem huet AWS eng ëmfaassend global Präsenz mat Rechenzenteren a verschiddene Regioune weltwäit. Dat garantéiert, datt eis Daten sécher sinn an eis Applikatiounen a Servicer héich verfügbar sinn. AWS huet och e robuste Sécherheetsframework, deen fir eist Geschäft kritesch ass.

Schliisslech bitt AWS e Pay-as-you-go-Modell, dat eis d'Flexibilitéit gëtt, eis Infrastruktur no der Nofro ze skaléieren. Dat bedeit, datt mir nëmmen dat bezuelen, wat mir benotzen, wat et eis erlaabt, eis Käschten ze optiméieren an an aner Beräicher vum Geschäft ze investéieren.

## Decisioun

Op Basis vun den duerchgefouerten Evaluatiounen an de Virdeeler, déi AWS bitt, gouf decidéiert, datt AWS fir eis Cloud-Infrastrukturbedierfnisser ugeholl gëtt.

## Konsequenzen

D'Unhuele vun AWS kann eng Formatioun fir eis Teams erfuerderen, fir sécherzestellen, datt si mat der Plattform vertraut sinn an se effektiv notze kënnen. Et kënnen och e puer initial Käschte fir de Wiessel vun eiser aktueller Infrastruktur op d'AWS-Plattform ufalen.

## Besëtz

D'Responsabilitéit, déi effektiv Notzung vun AWS an d'Gestioun vun den domat verbonnene Risiken ze garantéieren, fällt an den Zoustännegkeetsberäich vum Cloud-Infrastrukturteam. All Problemer, déi opdauchen, musse vun dësem Team adresséiert ginn.

## Review

D'Decisioun, AWS unzehuelen, gëtt jäerlech iwwerpréift, fir sécherzestellen, datt si weiderhin eis Bedierfnisser erfëllt an datt d'Virdeeler vun der Plattform voll realiséiert ginn.
