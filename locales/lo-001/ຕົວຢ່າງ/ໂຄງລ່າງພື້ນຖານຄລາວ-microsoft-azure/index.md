# ບັນທຶກການຕັດສິນໃຈດ້ານສະຖາປັດຕະຍະກຳ: ໂຄງລ່າງພື້ນຖານຄລາວ Microsoft Azure

ຫົວຂໍ້ການຕັດສິນໃຈ: ການນຳເອົາ Microsoft Azure ມາໃຊ້ເປັນໂຄງລ່າງພື້ນຖານຄລາວຂອງອົງກອນເຮົາ

ຜູ້ຕັດສິນໃຈ: ຫົວໜ້າຝ່າຍຂໍ້ມູນຂ່າວສານ (CIO)

ວັນທີ: 2021-10-15

ສະຖານະ: ອະນຸມັດແລ້ວ

## ຂໍ້ມູນພື້ນຖານ

ອົງກອນວາງແຜນຍ້າຍຈາກໂຄງລ່າງພື້ນຖານແບບ on-premises ແບບດັ້ງເດີມໄປສູ່ໂຄງລ່າງພື້ນຖານຄລາວ. ເພື່ອບັນລຸສິ່ງນີ້ ອົງກອນໄດ້ປະເມີນຜູ້ໃຫ້ບໍລິການຄລາວຫຼາຍລາຍ ເຊັ່ນ Amazon Web Services (AWS), Google Cloud Platform (GCP), Microsoft Azure ແລະ IBM Cloud. ແຕ່ລະຜູ້ໃຫ້ບໍລິການມີຊຸດຄຸນສົມບັດ, ຜົນປະໂຫຍດ ແລະ ໂຄງສ້າງລາຄາຂອງຕົນເອງ. ຫຼັງຈາກການວິເຄາະລະອຽດ ໄດ້ສະຫຼຸບວ່າ Microsoft Azure ເປັນທາງເລືອກທີ່ເໝາະສົມທີ່ສຸດສຳລັບອົງກອນຂອງພວກເຮົາ.

## ການຕັດສິນໃຈ

ນຳເອົາ Microsoft Azure ມາໃຊ້ເປັນໂຄງລ່າງພື້ນຖານຄລາວຂອງອົງກອນເຮົາ.

## ເຫດຜົນ

ຕໍ່ໄປນີ້ແມ່ນເຫດຜົນໃນການນຳເອົາ Microsoft Azure ມາໃຊ້:

1. ບໍລິການຄົບຖ້ວນ: Azure ໃຫ້ບໍລິການຄລາວຄົບຊຸດ ຕັ້ງແຕ່ໂຄງລ່າງພື້ນຖານເປັນບໍລິການ (IaaS) ຈົນເຖິງຊອບແວເປັນບໍລິການ (SaaS) ແລະ ແພລດຟອມເປັນບໍລິການ (PaaS). ສິ່ງນີ້ຊ່ວຍໃຫ້ພວກເຮົານຳໃຊ້ບໍລິການ Azure ເພື່ອແກ້ຄວາມຕ້ອງການຂອງອົງກອນ ເຊັ່ນ ການເກັບຂໍ້ມູນ, ການຄຳນວນ, ເຄືອຂ່າຍ ແລະ ການວິເຄາະ.

2. ຄວາມສາມາດໃນການຂະຫຍາຍ ແລະ ຄວາມຢືດຢຸ່ນ: ດ້ວຍ Azure ພວກເຮົາສາມາດຂະຫຍາຍຂຶ້ນ ຫຼື ລົງຊັບພະຍາກອນໄດ້ງ່າຍຕາມຄວາມຕ້ອງການທາງທຸລະກິດ. Azure ຍັງໃຫ້ຄວາມຢືດຢຸ່ນໃນການເລືອກລະບົບປະຕິບັດການ, ພາສາການຂຽນໂປຣແກຣມ ແລະ ເຟຣມເວີກ.

3. ຄວາມປອດໄພ ແລະ ການປະຕິບັດຕາມກົດລະບຽບ: Azure ໃຫ້ລະດັບຄວາມປອດໄພ ແລະ ການປະຕິບັດຕາມກົດລະບຽບສູງ ເພາະມັນສອດຄ່ອງກັບມາດຕະຖານອຸດສາຫະກຳຫຼາຍຢ່າງ ເຊັ່ນ ISO, SOC, HIPAA ແລະ PCI DSS. Azure ຍັງມີຄຸນສົມບັດຄວາມປອດໄພຂັ້ນສູງ ເຊັ່ນ ກຸ່ມຄວາມປອດໄພເຄືອຂ່າຍ, ໄຟວໍ ແລະ ການປ້ອງກັນ DDoS.

4. ຄລາວແບບປະສົມ: Azure ໃຫ້ປະສົບການຄລາວແບບປະສົມທີ່ລຽບລື່ນ ຊ່ວຍໃຫ້ອົງກອນເຊື່ອມຕໍ່ໂຄງລ່າງພື້ນຖານ on-premises ຂອງຕົນກັບ Azure. ສິ່ງນີ້ເຮັດໃຫ້ພວກເຮົາຍ້າຍວຽກໄປຄລາວໄດ້ງ່າຍ ແລະ ໃຫ້ຄວາມຢືດຢຸ່ນໃນການເລືອກບ່ອນເກັບຂໍ້ມູນ.

5. ຄຸ້ມຄ່າດ້ານຕົ້ນທຶນ: Azure ສະເໜີຮູບແບບລາຄາຈ່າຍຕາມການໃຊ້ງານ ເຊິ່ງໝາຍຄວາມວ່າພວກເຮົາຈ່າຍສະເພາະຊັບພະຍາກອນທີ່ໃຊ້. ສິ່ງນີ້ຊ່ວຍປະຢັດຕົ້ນທຶນເມື່ອທຽບກັບໂຄງລ່າງພື້ນຖານ on-premises ແບບດັ້ງເດີມ.

## ບົດສະຫຼຸບ

ການນຳເອົາ Microsoft Azure ມາໃຊ້ເປັນໂຄງລ່າງພື້ນຖານຄລາວຂອງອົງກອນເຮົາສອດຄ່ອງກັບຄວາມຕ້ອງການທາງທຸລະກິດຂອງພວກເຮົາ ແລະ ໃຫ້ຜົນປະໂຫຍດຫຼາຍຢ່າງ ເຊັ່ນ ຄວາມສາມາດໃນການຂະຫຍາຍ, ຄວາມຢືດຢຸ່ນ, ຄວາມປອດໄພ ແລະ ຄວາມຄຸ້ມຄ່າດ້ານຕົ້ນທຶນ. ດັ່ງນັ້ນ ຈຶ່ງແນະນຳໃຫ້ນຳເອົາ Azure ມາໃຊ້ເປັນໂຄງລ່າງພື້ນຖານຄລາວຂອງພວກເຮົາ.
