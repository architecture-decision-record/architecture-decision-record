# [000] ຫົວຂໍ້
*ກຳນົດເລກໃຫ້ແຕ່ລະ ADR ເພື່ອໃຫ້ອ້າງອີງ ແລະ ຈັດລາຍການໄດ້ງ່າຍ* \
*ໝາຍເຫດ: ຂໍ້ຄວາມຕົວອຽງທັງໝົດເປັນຄຳແນະນຳ ແລະ ຄວນລຶບອອກສຳລັບເວີຊັນໃຊ້ງານຈິງ*

## ສະຖານະ - ຮ່າງ / ໃຊ້ງານ /  ເລີກໃຊ້ໂດຍ [000] / ແທນທີ່ [000]

## ບໍລິບົດ
*ອະທິບາຍສັ້ນໆກ່ຽວກັບບັນຫາທີ່ ADR ນີ້ຕັ້ງໃຈແກ້ໄຂ ແລະ ເປັນຫຍັງບັນຫາເຫຼົ່ານັ້ນຈຶ່ງເກີດຂຶ້ນ.*

## ແນວທາງທີ່ຕັດສິນໃຈ
*ລະອຽດການຕັດສິນໃຈທີ່ມີນັຍສຳຄັນຕໍ່ສະຖາປັດຕະຍະກຳທີ່ໄດ້ເຮັດ / ຈະເຮັດ ແລະ ອະທິບາຍວ່າມັນແກ້ບັນຫາທີ່ກ່າວໄວ້ໃນສ່ວນບໍລິບົດແນວໃດ.*

## ຜົນສະທ້ອນ
*ການຕັດສິນໃຈນີ້ມີຜົນກະທົບແນວໃດຕໍ່ລັກສະນະສະຖາປັດຕະຍະກຳ ແລະ ຄວາມຕ້ອງການດ້ານໜ້າທີ່ຂອງລະບົບ?*

## ການກຳກັບດູແລ
*ຈະຕິດຕາມຜົນຂອງການຕັດສິນໃຈນີ້ແນວໃດ?* \
*ຈະຮັບປະກັນການປະຕິບັດຕາມການຕັດສິນໃຈນີ້ແນວໃດ?*

## ການວິເຄາະທາງເລືອກ
*ຖ້າມີ ໃຫ້ລວມ ຫຼື ລິ້ງໄປຫາການວິເຄາະຂໍ້ແລກປ່ຽນໃດໆທີ່ໄດ້ເຮັດເພື່ອໄປເຖິງການຕັດສິນໃຈໃນເອກະສານນີ້.*

### ຄຳອະທິບາຍສີ
*ທາງເລືອກ: ສະໜອງຕົວຊ່ວຍທາງສາຍຕາໃຫ້ຜູ້ມີສ່ວນໄດ້ສ່ວນເສຍ ເພື່ອຊ່ວຍໃຫ້ເຫັນຂໍ້ແລກປ່ຽນທາງບວກ ແລະ ທາງລົບໄດ້ຢ່າງວ່ອງໄວ - ຕົວຢ່າງ ການເນັ້ນແບບໄຟຈະລາຈອນງ່າຍໆພ້ອມຄຳນຳໜ້າທາງບວກ ຫຼື ທາງລົບ.*
