# ແມ່ແບບບັນທຶກການຕັດສິນໃຈທີ່ໃຊ້ Planguage

ເບິ່ງ https://www.iaria.org/conferences2012/filesICCGI12/Tutorial%20Specifying%20Effective%20Non-func.pdf

## Planguage ແມ່ນຫຍັງ?

Planguage ແມ່ນພາສາວາງແຜນທີ່ໃຊ້ຄຳສຳຄັນເຫຼົ່ານີ້:

* Tag: ຕົວລະບຸທີ່ເປັນເອກະລັກ ແລະ ຄົງທົນ
* Gist: ບົດສະຫຼຸບສັ້ນໆຂອງຄວາມຕ້ອງການ ຫຼື ຂອບເຂດທີ່ກ່າວເຖິງ
* Requirement: ຂໍ້ຄວາມທີ່ລະບຸລາຍລະອຽດຂອງຄວາມຕ້ອງການນັ້ນເອງ
* Rationale: ເຫດຜົນທີ່ໃຊ້ຢືນຢັນຄວາມຕ້ອງການ
* Priority: ຄຳລະບຸບູລິມະສິດ ແລະ ການຮຽກຮ້ອງຊັບພະຍາກອນ
* Stakeholders: ຝ່າຍທີ່ໄດ້ຮັບຜົນກະທົບຢ່າງເປັນສາລະສຳຄັນຈາກຄວາມຕ້ອງການ
* Status: ສະຖານະຂອງຄວາມຕ້ອງການ (ຮ່າງ, ທົບທວນແລ້ວ, ຜູກມັດແລ້ວ ແລະ ອື່ນໆ)
* Owner: ບຸກຄົນທີ່ຮັບຜິດຊອບການປະຕິບັດຄວາມຕ້ອງການ
* Author: ບຸກຄົນທີ່ຂຽນຄວາມຕ້ອງການ
* Revision: ເລກເວີຊັນຂອງຂໍ້ຄວາມ
* Date: ວັນທີຂອງການແກ້ໄຂຫຼ້າສຸດ
* Assumptions: ສິ່ງໃດກໍຕາມທີ່ອາດສ້າງບັນຫາຖ້າບໍ່ເປັນຈິງໃນຕອນນີ້ ຫຼື ໃນພາຍຫຼັງ
* Risks: ສິ່ງໃດກໍຕາມທີ່ອາດເຮັດໃຫ້ເກີດຄວາມຜິດປົກກະຕິ, ຄວາມຊັກຊ້າ ຫຼື ຜົນກະທົບທາງລົບອື່ນໆ
* Defined: ນິຍາມຂອງຄຳສັບ (ດີກວ່າທີ່ຈະໃຊ້ບັນຊີຄຳສັບ)
