# Decisioun record templat for Important Technical Decisiouns (ITDs)

This is the Important Technical Decisiouns (ITD) templat described in
[ITDs: a lean ADR for executive technical decision-making at scale - Ignacio Larrañaga](https://ignaciolarranaga.medium.com/itds-a-lean-adr-for-executive-technical-decision-making-at-scale-e18bb3f6a563).

ITDs are a focused evolution o ADRs, optimised for speed, clarity, an
executive validation. Whaur an ADR documents whit wis decidit, an ITD is a
lean, decisioun-first artefact that maks the decisioun itsel reviewable, sae
stakeholders can scan it quickly an challenge it easily. ITDs are weel suitit
tae technical decisiouns that are no strictly architectural, sic as chuisin a
model, a leebrary, or a CI/CD strategy.

In each ITD file, scrieve thir sections:

# Title

State the decisioun itsel, no a description o the topic.
For example, "Use Qwen2.5 1.5B Instruct for on-device translation".

## The Problem

Ae sentence statin whit we are tryin tae solve.

## Options Considered

The alternatives that were on the table, wi the selectit option in **bold**.

## Rationale

Juist the decisive factors that led tae the chyce, no an exhaustive list o
ilka pro an con.

## Notes

Optional. Onie additional context worth takin doun, sic as constraints,
assumptiouns, or links.
