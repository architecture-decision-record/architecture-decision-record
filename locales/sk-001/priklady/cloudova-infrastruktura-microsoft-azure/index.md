# Záznam architektonického rozhodnutia: cloudová infraštruktúra Microsoft Azure" 

Názov rozhodnutia: Prijatie Microsoft Azure ako cloudovej infraštruktúry pre našu organizáciu

Rozhodovateľ: Hlavný informačný riaditeľ

Dátum: 2021-10-15

Stav: Schválené

## Pozadie

Organizácia plánuje migrovať z tradičnej lokálnej infraštruktúry na cloudovú infraštruktúru. Na dosiahnutie tohto cieľa organizácia vyhodnotila viacerých poskytovateľov cloudových služieb, ako sú Amazon Web Services (AWS), Google Cloud Platform (GCP), Microsoft Azure a IBM Cloud. Každý poskytovateľ má vlastný súbor funkcií, výhod a cenovú štruktúru. Po podrobnej analýze sa dospelo k záveru, že Microsoft Azure je pre našu organizáciu najvhodnejšou možnosťou.

## Rozhodnutie

Prijať Microsoft Azure ako cloudovú infraštruktúru pre našu organizáciu.

## Zdôvodnenie

Nasledujú dôvody na prijatie Microsoft Azure:

1. Komplexné služby: Azure poskytuje kompletný rozsah cloudových služieb od infraštruktúry ako služby (IaaS) cez softvér ako službu (SaaS) až po platformu ako službu (PaaS). To nám umožňuje využívať služby Azure na riešenie požiadaviek organizácie, ako sú úložisko, výpočty, siete a analytika.

2. Škálovateľnosť a flexibilita: S Azure môžeme jednoducho zvyšovať alebo znižovať zdroje podľa našich obchodných požiadaviek. Azure ponúka aj flexibilitu pri výbere operačného systému, programovacieho jazyka a frameworkov.

3. Bezpečnosť a súlad: Azure ponúka vysokú úroveň bezpečnosti a súladu, keďže je v súlade s viacerými odvetvovými štandardmi ako ISO, SOC, HIPAA a PCI DSS. Azure poskytuje aj pokročilé bezpečnostné funkcie ako skupiny zabezpečenia siete, firewally a ochranu pred DDoS.

4. Hybridný cloud: Azure poskytuje bezproblémový zážitok z hybridného cloudu, ktorý organizáciám umožňuje prepojiť ich lokálnu infraštruktúru s Azure. To nám uľahčuje migráciu pracovných zaťažení do cloudu a dáva nám flexibilitu vybrať si, kde ukladať dáta.

5. Nákladová efektívnosť: Azure ponúka cenový model platby podľa spotreby, čo znamená, že platíme iba za použité zdroje. To nám pomáha ušetriť náklady v porovnaní s tradičnou lokálnou infraštruktúrou.

## Záver

Prijatie Microsoft Azure ako cloudovej infraštruktúry pre našu organizáciu je v súlade s našimi obchodnými požiadavkami a ponúka niekoľko výhod, ako sú škálovateľnosť, flexibilita, bezpečnosť a nákladová efektívnosť. Preto sa odporúča prijať Azure ako našu cloudovú infraštruktúru.
