# Planguage استعمال کرنے والا فیصلہ ریکارڈ سانچہ

دیکھیں https://www.iaria.org/conferences2012/filesICCGI12/Tutorial%20Specifying%20Effective%20Non-func.pdf

## Planguage کیا ہے؟

Planguage منصوبہ بندی کی ایک زبان ہے جو یہ کلیدی الفاظ استعمال کرتی ہے:

* Tag: ایک منفرد، مستقل شناخت کنندہ
* Gist: تقاضے یا زیرِ بحث شعبے کا مختصر خلاصہ
* Requirement: وہ متن جو خود تقاضے کی تفصیل بیان کرتا ہے
* Rationale: وہ دلیل جو تقاضے کا جواز پیش کرتی ہے
* Priority: ترجیح اور وسائل پر دعوے کا بیان
* Stakeholders: وہ فریق جو تقاضے سے مادی طور پر متاثر ہوتے ہیں
* Status: تقاضے کی حالت (draft, reviewed, committed وغیرہ)
* Owner: تقاضے کو نافذ کرنے کا ذمہ دار شخص
* Author: وہ شخص جس نے تقاضا لکھا
* Revision: بیان کا ورژن نمبر
* Date: تازہ ترین نظرثانی کی تاریخ
* Assumptions: کوئی بھی چیز جو اب یا بعد میں غلط ہونے پر مسائل پیدا کر سکتی ہو
* Risks: کوئی بھی چیز جو خرابی، تاخیر یا دیگر منفی اثرات پیدا کر سکتی ہو
* Defined: کسی اصطلاح کی تعریف (بہتر ہے کہ لغت (glossary) استعمال کی جائے)
