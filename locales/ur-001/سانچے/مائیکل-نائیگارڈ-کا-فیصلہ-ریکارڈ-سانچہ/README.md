# مائیکل نائیگارڈ کا فیصلہ ریکارڈ سانچہ

یہ [Documenting architecture decisions - Michael Nygard](http://thinkrelevance.com/blog/2011/11/15/documenting-architecture-decisions) میں دیا گیا سانچہ ہے۔
ADR فائلوں کے انتظام کے لیے آپ [adr-tools](https://github.com/npryce/adr-tools) استعمال کر سکتے ہیں۔

ہر ADR فائل میں یہ حصے لکھیں:

# عنوان

## حالت

حالت کیا ہے، مثلاً proposed, accepted, rejected, deprecated, superseded وغیرہ؟

## سیاق و سباق

وہ کون سا مسئلہ ہے جو ہم دیکھ رہے ہیں اور جو اس فیصلے یا تبدیلی کی محرک ہے؟

## فیصلہ

وہ کون سی تبدیلی ہے جس کی ہم تجویز دے رہے ہیں اور/یا کر رہے ہیں؟

## نتائج

اس تبدیلی کی وجہ سے کیا کرنا آسان یا مشکل ہو جاتا ہے؟
