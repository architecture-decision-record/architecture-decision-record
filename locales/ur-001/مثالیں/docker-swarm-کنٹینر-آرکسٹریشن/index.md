## سیاق و سباق

ہم اپنے مائیکرو سروسز پر مبنی آرکیٹیکچر کو منظم کرنے کے لیے مختلف کنٹینر آرکسٹریشن ٹولز پر غور کر رہے ہیں۔ ہم نے Kubernetes، Docker Swarm اور Mesosphere DC/OS جیسے مختلف حلوں کا جائزہ لیا ہے۔ تاہم ہم نے Docker Swarm پر توجہ مرکوز کرنے کا فیصلہ کیا ہے، اس کی سادگی، Docker کے ساتھ انضمام اور اندرونی لوڈ بیلنسنگ کی وجہ سے۔

## فیصلہ

ہم نے Docker Swarm کو اپنے کنٹینر آرکسٹریشن ٹول کے طور پر استعمال کرنے کا فیصلہ کیا ہے۔ Docker Swarm نوڈز کے کلسٹر پر کنٹینرائزڈ ایپلیکیشنز کو منظم کرنے کا سادہ اور بدیہی طریقہ فراہم کرتا ہے۔ یہ ہمیں اپنے موجودہ Docker پر مبنی ورک فلو اور انفراسٹرکچر سے فائدہ اٹھانے کا موقع بھی دیتا ہے۔ Docker Swarm کے ساتھ ہم اندرونی لوڈ بیلنسنگ سے فائدہ اٹھاتے ہوئے اپنی ایپلیکیشنز کو آسانی سے ڈپلائے، اسکیل اور منظم کر سکتے ہیں۔

## فوائد

- **سادگی:**  Docker Swarm انہی اصولوں پر چلتا ہے جن پر Docker، اس لیے نئی ٹیکنالوجی سیکھنے کی ضرورت نہیں۔ Docker سے واقف ڈویلپرز کے لیے سیکھنے کا خم نسبتاً سیدھا ہے۔

- **انضمام:**  Docker Swarm، Docker Compose جیسے Docker ٹولز کے ساتھ بے ربط طور پر ضم ہوتا ہے، جس سے ہمارے تمام کنٹینرز اور سروسز کو ایک ہی جگہ سے منظم کرنا آسان ہو جاتا ہے۔

- **لوڈ بیلنسنگ:**  Docker Swarm اندرونی لوڈ بیلنسنگ فراہم کرتا ہے، جو یقینی بناتا ہے کہ ہماری ایپلیکیشنز ہمیشہ دستیاب ہوں اور کلسٹر میں یکساں طور پر تقسیم ہوں۔

- **وسعت پذیری:**  Docker Swarm کلسٹر میں نوڈز شامل یا ہٹا کر ہماری ایپلیکیشنز کو افقی طور پر اسکیل کرنا آسان بناتا ہے۔

- **اعلیٰ دستیابی:**  Docker Swarm ہماری سروسز کو نوڈز میں خودکار طور پر تقسیم کرتا ہے، جس سے نوڈ کی ناکامی کی صورت میں اعلیٰ دستیابی ملتی ہے۔

## خطرات

- **محدود فعالیت:**  Docker Swarm میں Kubernetes یا Mesosphere DC/OS میں پائی جانے والی کچھ جدید خصوصیات، جیسے خودکار اسکیلنگ یا خود علاجی، کی کمی ہو سکتی ہے۔

- **Docker مرکوز:**  Docker Swarm، Docker کے ساتھ مضبوطی سے جڑا ہوا ہے، جو ہماری لچک کو محدود کر سکتا ہے اگر ہمیں کبھی Docker پر مبنی حلوں سے ہٹنا پڑے۔

- **ناپختگی:**  Docker Swarm اب بھی نسبتاً نئی ٹیکنالوجی ہے، اور کچھ استحکام کے مسائل یا دستاویزات میں خلا ہو سکتے ہیں۔

## متبادل

- **Kubernetes:**  Kubernetes سب سے وسیع پیمانے پر استعمال ہونے والا کنٹینر آرکسٹریشن پلیٹ فارم ہے اور جدید خصوصیات اور زیادہ پختہ ماحولیاتی نظام پیش کرتا ہے۔ تاہم اس کا سیکھنے کا خم زیادہ کھڑا ہے اور یہ ہماری ضروریات کے لیے ضرورت سے زیادہ ہو سکتا ہے۔

- **Mesosphere DC/OS:**  Mesosphere DC/OS ایک طاقتور ٹول ہے جو ملٹی کلاؤڈ سپورٹ اور مقامی بگ ڈیٹا اور AI پلیٹ فارم کی صلاحیتوں جیسی جدید خصوصیات فراہم کرتا ہے۔ تاہم اسے نافذ کرنے کے لیے خاطر خواہ مہارت درکار ہے اور یہ ہمارے تقاضوں کے لیے بہت پیچیدہ ہو سکتا ہے۔
