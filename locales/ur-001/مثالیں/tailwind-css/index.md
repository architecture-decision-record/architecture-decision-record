# آرکیٹیکچر فیصلے کا ریکارڈ: Tailwind CSS

فیصلہ: صارف انٹرفیس کو اسٹائل کرنے کے لیے CSS فریم ورک کے طور پر Tailwind CSS استعمال کرنا۔

## Tailwind CSS کیا ہے؟

Tailwind ایک utility-first (یوٹیلیٹی کو اولیت دینے والا) CSS فریم ورک ہے جو صارف انٹرفیسز کی تیز ڈویلپمنٹ اور حسبِ ضرورت ترتیب کی اجازت دیتا ہے۔ یہ بہت زیادہ حسبِ ضرورت بنانے کے قابل ہونے کے لیے ڈیزائن کیا گیا ہے اور ڈویلپرز کو زیادہ سلیقے والا اور مؤثر CSS لکھنے دیتا ہے۔ یہ فریم ورک UI کو بہت تیزی سے اسٹائل کرنے کے لیے پہلے سے متعین کلاسز کا ایک سیٹ فراہم کرتا ہے۔

## سیاق و سباق

ہم ایک کلائنٹ کے لیے ویب ایپلیکیشن بنا رہے ہیں جس کے لیے ریسپانسیو اور حسبِ ضرورت بنانے کے قابل صارف انٹرفیس درکار ہے۔ کلائنٹ نے یکساں اور جدید اسٹائلنگ مانگی ہے۔ ڈویلپمنٹ ٹیم کو حسبِ ضرورت CSS استعمال کرنے کا تجربہ ہے لیکن وہ ایسے CSS فریم ورکس دریافت کرنا چاہتی ہے جو وقت اور کوشش بچا سکیں۔ ہم ایسا فریم ورک تلاش کر رہے ہیں جو استعمال میں آسان، حسبِ ضرورت بنانے کے قابل ہو اور جس کی معاونت کے لیے بڑی کمیونٹی ہو۔

## فیصلے کے محرکات

- **استعمال میں آسان:**  ہم ایسا فریم ورک چاہتے ہیں جو سیکھنے میں سادہ ہو اور ہمارے ڈویلپمنٹ ورک فلو میں ضم کیا جا سکے۔

- **حسبِ ضرورت بنانے کے قابل:**  ہم ایسا فریم ورک چاہتے ہیں جسے کلائنٹ کی برانڈ ہدایات اور تھیم کے مطابق ڈھالا جا سکے۔

- **بڑی کمیونٹی سپورٹ:**  ہم ایسا فریم ورک چاہتے ہیں جس کی ڈویلپرز اور ڈیزائنرز کی فعال کمیونٹی ہو جو ضرورت پڑنے پر مدد اور وسائل فراہم کر سکے۔

- **وقت کی بچت:**  ہم ایسا فریم ورک چاہتے ہیں جو UI کو اسٹائل کرنے میں وقت اور کوشش بچا سکے۔

## زیرِ غور اختیارات

- **Bootstrap:**  ایک مقبول CSS فریم ورک جس میں بہت سے پہلے سے بنے اجزا اور ڈویلپرز کی بڑی کمیونٹی ہے۔

- **Foundation:**  ایک اور مقبول CSS فریم ورک جو mobile-first ڈویلپمنٹ کے لیے ڈیزائن کیا گیا تھا۔

- **Materialize:**  گوگل کی Material Design زبان پر مبنی CSS فریم ورک جس میں UI ڈویلپمنٹ کے لیے پہلے سے بنے اجزا ہیں۔

- **Tailwind CSS:**  حسبِ ضرورت ترتیب اور استعداد پر توجہ کے ساتھ utility-first CSS فریم ورک۔

## فیصلے کا نتیجہ

اختیارات پر غور کرنے کے بعد ہم نے درج ذیل وجوہات کی بنا پر Tailwind CSS استعمال کرنے کا فیصلہ کیا:

- **استعمال میں آسان:**  Tailwind کا طریقہ سادہ اور سمجھنے میں آسان ہے۔ اس کی یوٹیلیٹی کلاسز UI بنانا تیز تر کر دیتی ہیں۔

- **حسبِ ضرورت بنانے کے قابل:**  Tailwind کنفیگریشن فائلوں کا ایک سیٹ فراہم کر کے حسبِ ضرورت ترتیب کی اجازت دیتا ہے جو ڈویلپرز کو فریم ورک کے ڈیفالٹ اسٹائلز آسانی سے بدلنے دیتا ہے۔

- **بڑی کمیونٹی سپورٹ:**  Tailwind کی ڈویلپرز اور ڈیزائنرز کی بہت فعال کمیونٹی ہے جو مسلسل نئے وسائل، پلگ اِنز اور ٹولز بنا رہی ہے۔

- **وقت کی بچت:**  Tailwind وقت بچا سکتا ہے، جو ڈویلپرز کو منصوبے کے دوسرے شعبوں پر توجہ دینے کے قابل بناتا ہے۔

ہم اپنے منصوبے کا UI بنانے کے لیے Tailwind CSS کی یوٹیلیٹی کلاسز استعمال کریں گے۔ ڈویلپمنٹ ٹیم مؤثر اور وسعت پذیر CSS کوڈ لکھنے کے لیے اس کا ایٹمی اور ماڈیولر ڈیزائن سسٹم استعمال کرے گی۔ ہم ڈویلپمنٹ کے عمل کو تیز کرنے کے لیے Tailwind کے پہلے سے بنے سانچوں اور بصری اجزا سے فائدہ اٹھائیں گے، ساتھ ہی کلائنٹ کی برانڈنگ اور تھیم سے ملانے کے لیے حسبِ ضرورت اسٹائلز استعمال کریں گے۔
