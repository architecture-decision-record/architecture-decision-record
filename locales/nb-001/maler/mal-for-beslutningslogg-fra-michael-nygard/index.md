# Mal for beslutningslogg fra Michael Nygard

Dette er malen i [Documenting architecture decisions - Michael Nygard](http://thinkrelevance.com/blog/2011/11/15/documenting-architecture-decisions).
Du kan bruke [adr-tools](https://github.com/npryce/adr-tools) til å håndtere ADR-filene.

Skriv disse delene i hver ADR-fil:

# Tittel

## Status

Hva er statusen, for eksempel foreslått, godtatt, avvist, foreldet, erstattet og så videre?

## Kontekst

Hvilket problem ser vi som motiverer denne beslutningen eller endringen?

## Beslutning

Hvilken endring foreslår og/eller gjør vi?

## Konsekvenser

Hva blir enklere eller vanskeligere å gjøre på grunn av denne endringen?
