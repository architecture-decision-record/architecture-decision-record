# आर्किटेक्चर निर्णय नोंद: मायक्रोसॉफ्ट अझूर क्लाउड पायाभूत सुविधा" 

निर्णयाचे शीर्षक: आमच्या संस्थेसाठी क्लाउड पायाभूत सुविधा म्हणून Microsoft Azure चा अवलंब

निर्णय घेणारा: मुख्य माहिती अधिकारी

तारीख: 2021-10-15

स्थिती: मंजूर

## पार्श्वभूमी

संस्था पारंपरिक ऑन-प्रिमाइसेस पायाभूत सुविधेवरून क्लाउड पायाभूत सुविधेकडे स्थलांतर करण्याची योजना आखत आहे. हे साध्य करण्यासाठी, संस्थेने Amazon Web Services (AWS), Google Cloud Platform (GCP), Microsoft Azure आणि IBM Cloud यांसारख्या अनेक क्लाउड सेवा पुरवठादारांचे मूल्यमापन केले आहे. प्रत्येक पुरवठादाराकडे स्वतःची वैशिष्ट्ये, फायदे आणि किंमत रचना आहे. सविस्तर विश्लेषणानंतर, असा निष्कर्ष काढला गेला की आमच्या संस्थेसाठी Microsoft Azure हा सर्वात योग्य पर्याय आहे.

## निर्णय

आमच्या संस्थेसाठी क्लाउड पायाभूत सुविधा म्हणून Microsoft Azure स्वीकारा.

## तर्क

Microsoft Azure स्वीकारण्याची कारणे पुढीलप्रमाणे आहेत:

१. सर्वसमावेशक सेवा: Azure सेवा म्हणून पायाभूत सुविधा (IaaS) पासून सेवा म्हणून सॉफ्टवेअर (SaaS) आणि सेवा म्हणून प्लॅटफॉर्म (PaaS) पर्यंत क्लाउड सेवांची संपूर्ण श्रेणी देते. यामुळे आम्हाला स्टोरेज, संगणन, नेटवर्किंग आणि विश्लेषण यांसारख्या संस्थेच्या गरजा सोडवण्यासाठी Azure सेवांचा लाभ घेता येतो.

२. प्रमाण वाढवण्याची क्षमता आणि लवचिकता: Azure सह, आम्ही आमच्या व्यावसायिक गरजांनुसार संसाधने सहज वाढवू किंवा कमी करू शकतो. Azure ऑपरेटिंग सिस्टम, प्रोग्रामिंग भाषा आणि फ्रेमवर्क निवडण्यातही लवचिकता देते.

३. सुरक्षा आणि अनुपालन: Azure उच्च पातळीची सुरक्षा आणि अनुपालन देते, कारण ते ISO, SOC, HIPAA आणि PCI DSS सारख्या अनेक उद्योग मानकांशी सुसंगत आहे. Azure नेटवर्क सुरक्षा गट, फायरवॉल आणि DDoS संरक्षण यांसारखी प्रगत सुरक्षा वैशिष्ट्येही पुरवते.

४. हायब्रिड क्लाउड: Azure अखंड हायब्रिड क्लाउड अनुभव देते, ज्यामुळे संस्थांना त्यांची ऑन-प्रिमाइसेस पायाभूत सुविधा Azure शी जोडता येते. यामुळे आम्हाला कार्यभार क्लाउडवर हलवणे सोपे जाते आणि डेटा कुठे साठवायचा हे निवडण्याची लवचिकता मिळते.

५. किफायतशीर: Azure वापरल्याप्रमाणे पैसे देण्याचे किंमत मॉडेल देते, म्हणजे आम्ही वापरलेल्या संसाधनांसाठीच पैसे देतो. पारंपरिक ऑन-प्रिमाइसेस पायाभूत सुविधेच्या तुलनेत हे आम्हाला खर्च वाचवण्यास मदत करते.

## निष्कर्ष

आमच्या संस्थेसाठी क्लाउड पायाभूत सुविधा म्हणून Microsoft Azure स्वीकारणे आमच्या व्यावसायिक गरजांशी सुसंगत आहे आणि प्रमाण वाढवण्याची क्षमता, लवचिकता, सुरक्षा आणि किफायतशीरपणा यांसारखे अनेक फायदे देते. म्हणून, आमची क्लाउड पायाभूत सुविधा म्हणून Azure स्वीकारण्याची शिफारस केली जाते.
