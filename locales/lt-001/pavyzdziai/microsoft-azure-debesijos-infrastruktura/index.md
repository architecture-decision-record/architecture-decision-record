# Architektūros sprendimo įrašas: Microsoft Azure debesijos infrastruktūra

Sprendimo pavadinimas: Microsoft Azure pasirinkimas kaip mūsų organizacijos debesijos infrastruktūros

Sprendimo priėmėjas: informacijos direktorius (CIO)

Data: 2021-10-15

Būsena: patvirtintas

## Fonas

Organizacija planuoja pereiti nuo tradicinės vietinės (on-premises) infrastruktūros prie debesijos infrastruktūros. Siekdama to, organizacija įvertino kelis debesijos paslaugų teikėjus, tokius kaip Amazon Web Services (AWS), Google Cloud Platform (GCP), Microsoft Azure ir IBM Cloud. Kiekvienas teikėjas turi savo funkcijų rinkinį, privalumus ir kainodaros struktūrą. Po išsamios analizės padaryta išvada, kad Microsoft Azure yra tinkamiausias variantas mūsų organizacijai.

## Sprendimas

Pasirinkti Microsoft Azure kaip mūsų organizacijos debesijos infrastruktūrą.

## Pagrindimas

Toliau pateikiamos Microsoft Azure pasirinkimo priežastys:

1. Išsamios paslaugos: Azure teikia visą debesijos paslaugų spektrą – nuo infrastruktūros kaip paslaugos (IaaS) iki programinės įrangos kaip paslaugos (SaaS) ir platformos kaip paslaugos (PaaS). Tai leidžia mums pasinaudoti Azure paslaugomis organizacijos reikalavimams, tokiems kaip saugojimas, skaičiavimas, tinklai ir analitika, tenkinti.

2. Mastelio keitimas ir lankstumas: su Azure galime lengvai didinti ar mažinti išteklius pagal savo verslo reikalavimus. Azure taip pat suteikia lankstumą renkantis operacinę sistemą, programavimo kalbą ir karkasus.

3. Saugumas ir atitiktis: Azure siūlo aukštą saugumo ir atitikties lygį, nes atitinka kelis pramonės standartus, tokius kaip ISO, SOC, HIPAA ir PCI DSS. Azure taip pat teikia pažangias saugumo funkcijas, tokias kaip tinklo saugumo grupės, užkardos ir apsauga nuo DDoS.

4. Hibridinė debesija: Azure suteikia sklandžią hibridinės debesijos patirtį, leidžiančią organizacijoms sujungti savo vietinę infrastruktūrą su Azure. Tai mums palengvina darbo krūvių perkėlimą į debesiją ir suteikia lankstumą pasirinkti, kur saugoti duomenis.

5. Ekonomiškumas: Azure siūlo mokėjimo už naudojimą kainodaros modelį, o tai reiškia, kad mokame tik už naudojamus išteklius. Tai padeda sutaupyti, palyginti su tradicine vietine infrastruktūra.

## Išvada

Microsoft Azure pasirinkimas kaip mūsų organizacijos debesijos infrastruktūros atitinka mūsų verslo reikalavimus ir suteikia keletą privalumų, tokių kaip mastelio keitimas, lankstumas, saugumas ir ekonomiškumas. Todėl rekomenduojama kaip debesijos infrastruktūrą pasirinkti Azure.
