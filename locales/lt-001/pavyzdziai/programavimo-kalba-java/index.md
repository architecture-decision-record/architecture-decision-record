# Architektūros sprendimo įrašas: programavimo kalba Java

Pavadinimas: programavimo kalbos Java pasirinkimas projektui

Sprendimas: įvertinę kelias programavimo kalbas, nusprendėme savo projektui naudoti Java.

### Fonas

Ketinome sukurti žiniatinklio programą, kuri galėtų veikti keliose operacinėse sistemose. Mūsų projektui reikėjo kalbos, galinčios suteikti stiprias saugumo funkcijas, tvarkyti lygiagretumą, palaikyti dideles kodo bazes ir būti pakankamai universalios, kad atitiktų mūsų būsimo augimo reikalavimus. Prieš apsispręsdami dėl Java, įvertinome kelias kalbas, atsižvelgdami į jų stipriąsias puses ir apribojimus.

### Svarstymai

1. **Saugumas:**  Java suteikia puikias saugumo funkcijas per gerai apibrėžtas saugumo politikas ir prieigos kontrolę. Ji taip pat turi tokių funkcijų kaip baitkodo tikrinimas, padedantis užkirsti kelią kenkėjiškos programinės įrangos veikimui sistemoje.

2. **Lygiagretumas:**  Java turi integruotą kelių gijų palaikymą, leidžiantį programoms vienu metu atlikti kelias užduotis. Dėl šios funkcijos Java yra puikus pasirinkimas kuriant dideles, sudėtingas programas su daugybe funkcijų ir galimybių.

3. **Didelės kodo bazės:**  Java palaiko objektinį programavimą, todėl yra tinkamas pasirinkimas didelėms kodo bazėms kurti. Jos moduliškumas ir inkapsuliacijos bei abstrakcijos šablonų naudojimas dar labiau palengvina programinės įrangos kūrimo procesą.

4. **Universalumas:**  Java yra universali ir suteikia galimybę naudoti daugybę bibliotekų ir karkasų, todėl yra puikus pasirinkimas tiek žiniatinklio, tiek įmonių lygio programoms.

### Sprendimo rezultatas

Nusprendėme savo projektui naudoti programavimo kalbą Java, atsižvelgdami į jos saugumo funkcijas, lygiagretumo palaikymą, gebėjimą tvarkyti dideles kodo bazes ir universalumą. Šis sprendimas atitinka mūsų projekto reikalavimus, ir manome, kad Java pasirinkimas užtikrins projekto sėkmę. 

### Pasekmės

1. Mums reikės programuotojų, turinčių patirties su Java ir gebančių ja puikiai naudotis.

2. Bet koks šia kalba parašytas kodas turi būti suderinamas su Java virtualiąja mašina (JVM).

3. Naujų funkcijų, galimybių ar karkasų įtraukimas gali kelti tam tikrų sunkumų.

4. Dideliems, sudėtingiems projektams Java kalba gali prireikti daugiau laiko ir išteklių.
