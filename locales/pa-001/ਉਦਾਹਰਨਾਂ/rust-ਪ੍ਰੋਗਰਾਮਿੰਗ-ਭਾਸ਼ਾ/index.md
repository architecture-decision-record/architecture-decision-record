# ਆਰਕੀਟੈਕਚਰ ਫੈਸਲਾ ਰਿਕਾਰਡ: Rust ਪ੍ਰੋਗਰਾਮਿੰਗ ਭਾਸ਼ਾ

ਫੈਸਲਾ ਨੰਬਰ: AR-001

ਫੈਸਲੇ ਦਾ ਸਿਰਲੇਖ: Rust ਪ੍ਰੋਗਰਾਮਿੰਗ ਭਾਸ਼ਾ ਨੂੰ ਅਪਣਾਉਣਾ

ਮਿਤੀ: 1 ਦਸੰਬਰ, 2021

ਸਥਿਤੀ: ਸਵੀਕਾਰ

### ਸਮੱਸਿਆ ਦਾ ਕਥਨ

ਜਿਵੇਂ-ਜਿਵੇਂ ਅਸੀਂ ਸਾਫਟਵੇਅਰ ਐਪਲੀਕੇਸ਼ਨਾਂ ਵਿਕਸਿਤ ਕਰਨਾ ਜਾਰੀ ਰੱਖਦੇ ਹਾਂ, ਅਸੀਂ ਵੇਖਿਆ ਹੈ ਕਿ ਸੰਭਾਵੀ ਸੁਰੱਖਿਆ ਕਮਜ਼ੋਰੀਆਂ ਨੂੰ ਘਟਾਉਣਾ ਅਤੇ ਰਨਟਾਈਮ ਗਲਤੀਆਂ ਨੂੰ ਰੋਕਣਾ ਵਧਦੀ ਚੁਣੌਤੀ ਬਣ ਰਿਹਾ ਹੈ। C ਅਤੇ C++ ਵਰਗੀਆਂ ਮੌਜੂਦਾ ਪ੍ਰੋਗਰਾਮਿੰਗ ਭਾਸ਼ਾਵਾਂ ਨਾਲ, ਸਾਨੂੰ ਬਫਰ ਓਵਰਫਲੋ, ਮੈਮਰੀ ਲੀਕ ਅਤੇ ਅਪਰਿਭਾਸ਼ਿਤ ਵਿਹਾਰ ਵਰਗੀਆਂ ਸਮੱਸਿਆਵਾਂ ਆਉਂਦੀਆਂ ਰਹਿੰਦੀਆਂ ਹਨ, ਜੋ ਐਪਲੀਕੇਸ਼ਨਾਂ ਦੇ ਕਰੈਸ਼ ਹੋਣ ਵੱਲ ਲੈ ਜਾਂਦੀਆਂ ਹਨ। ਸਾਨੂੰ ਅਜਿਹੀ ਪ੍ਰੋਗਰਾਮਿੰਗ ਭਾਸ਼ਾ ਦੀ ਲੋੜ ਹੈ ਜੋ ਮੈਮਰੀ ਸੁਰੱਖਿਆ ਦੀਆਂ ਗਾਰੰਟੀਆਂ ਦੇਵੇ ਅਤੇ ਕਾਰਗੁਜ਼ਾਰੀ-ਨਾਜ਼ੁਕ ਐਪਲੀਕੇਸ਼ਨਾਂ ਦਾ ਸਮਰਥਨ ਕਰਨ ਲਈ ਕਾਫ਼ੀ ਕੁਸ਼ਲ ਹੋਵੇ।

### ਵਿਚਾਰਨਯੋਗ ਗੱਲਾਂ

ਕਈ ਪ੍ਰੋਗਰਾਮਿੰਗ ਭਾਸ਼ਾਵਾਂ ਮੌਜੂਦਾ ਸਮੱਸਿਆਵਾਂ ਨੂੰ ਸੰਬੋਧਿਤ ਕਰਨ ਲਈ ਡਿਜ਼ਾਈਨ ਕੀਤੀਆਂ ਗਈਆਂ ਹਨ। ਉਨ੍ਹਾਂ ਵਿੱਚੋਂ, Rust ਪ੍ਰੋਗਰਾਮਿੰਗ ਭਾਸ਼ਾ ਨੇ ਆਪਣੀਆਂ ਵਿਲੱਖਣ ਡਿਜ਼ਾਈਨ ਵਿਸ਼ੇਸ਼ਤਾਵਾਂ ਕਾਰਨ ਡਿਵੈਲਪਰ ਭਾਈਚਾਰੇ ਦਾ ਧਿਆਨ ਖਾਸ ਤੌਰ ਉੱਤੇ ਖਿੱਚਿਆ ਹੈ। ਵਿਚਾਰਨਯੋਗ ਗੱਲਾਂ ਵਿੱਚ ਸ਼ਾਮਲ ਹਨ;

1. ਮੈਮਰੀ ਸੁਰੱਖਿਆ ਅਤੇ ਸੁਰੱਖਿਆ

2. ਕਾਰਗੁਜ਼ਾਰੀ ਅਤੇ ਕੁਸ਼ਲਤਾ

3. ਭਾਈਚਾਰਕ ਸਹਾਇਤਾ ਅਤੇ ਅਪਣਾਉਣਾ

4. ਸਿੱਖਣ ਦਾ ਵਕਰ

5. ਟੂਲ ਅਤੇ ਈਕੋਸਿਸਟਮ

6. ਮੌਜੂਦਾ ਸਾਫਟਵੇਅਰ ਸਿਸਟਮਾਂ ਨਾਲ ਅਨੁਕੂਲਤਾ।

### ਬੰਦਸ਼ਾਂ

ਨਵੀਂ ਪ੍ਰੋਗਰਾਮਿੰਗ ਭਾਸ਼ਾ ਅਪਣਾਉਣ ਲਈ ਡਿਵੈਲਪਰਾਂ ਨੂੰ ਮੁੜ ਸਿਖਲਾਈ ਦੇਣ ਦੀ ਲੋੜ ਹੈ, ਜਿਸ ਵਿੱਚ ਸਮਾਂ ਅਤੇ ਸਰੋਤ ਲੱਗਦੇ ਹਨ। ਭਾਸ਼ਾ ਨੂੰ ਮੌਜੂਦਾ ਵਿਕਾਸ ਵਰਕਫਲੋ ਵਿੱਚ ਜੋੜਨਾ ਇੱਕ ਚੁਣੌਤੀ ਹੋ ਸਕਦੀ ਹੈ। ਸਾਨੂੰ ਮੌਜੂਦਾ ਸਿਸਟਮਾਂ ਨਾਲ ਅਨੁਕੂਲਤਾ ਯਕੀਨੀ ਬਣਾਉਣੀ ਪਵੇਗੀ ਅਤੇ ਨਿਰੰਤਰਤਾ ਕਾਇਮ ਰੱਖਣ ਲਈ ਤੋੜ ਦੇਣ ਵਾਲੀਆਂ ਤਬਦੀਲੀਆਂ ਤੋਂ ਬਚਣਾ ਪਵੇਗਾ।

### ਲਾਗੂਕਰਨ

1. ਸਾਡੀ ਵਿਕਾਸ ਟੀਮ Rust ਪ੍ਰੋਗਰਾਮਿੰਗ ਭਾਸ਼ਾ ਸਿੱਖਣ ਅਤੇ ਇਸ ਤੋਂ ਜਾਣੂ ਹੋਣ ਲਈ ਸਿਖਲਾਈ ਲਵੇਗੀ।

2. ਅਸੀਂ ਆਪਣੇ ਵਿਕਾਸ ਉਦੇਸ਼ਾਂ ਲਈ ਇਸ ਦੀ ਅਨੁਕੂਲਤਾ ਅਤੇ ਢੁਕਵੇਂਪਣ ਦਾ ਮੁਲਾਂਕਣ ਕਰਨ ਲਈ ਅਜ਼ਮਾਇਸ਼ ਦੇ ਆਧਾਰ ਉੱਤੇ Rust ਵਰਤ ਕੇ ਇੱਕ ਨਵਾਂ ਪ੍ਰੋਜੈਕਟ ਬਣਾਵਾਂਗੇ।

3. ਅਸੀਂ C ਅਤੇ C++ ਵਿੱਚ ਲਿਖੇ ਮੌਜੂਦਾ ਸਿਸਟਮਾਂ ਨੂੰ ਹੌਲੀ-ਹੌਲੀ Rust ਵਿੱਚ ਤਬਦੀਲ ਕਰਾਂਗੇ।

4. ਅਸੀਂ ਆਪਣੇ ਵਿਕਾਸ ਵਰਕਫਲੋ ਨੂੰ ਵਧਾ ਸਕਣ ਵਾਲੇ ਉਪਲਬਧ ਟੂਲਾਂ ਅਤੇ ਲਾਇਬ੍ਰੇਰੀਆਂ ਦੀ ਪੜਚੋਲ ਕਰਨ ਲਈ Rust ਭਾਈਚਾਰੇ ਨਾਲ ਸਹਿਯੋਗ ਕਰਾਂਗੇ।

5. ਅਸੀਂ Rust ਦੀ ਕਾਰਗੁਜ਼ਾਰੀ ਦੀ ਨਿਗਰਾਨੀ ਕਰਾਂਗੇ ਅਤੇ ਨਿਯਮਿਤ ਤੌਰ ਉੱਤੇ ਇਸ ਦੀ ਮੌਜੂਦਾ ਪ੍ਰੋਗਰਾਮਿੰਗ ਭਾਸ਼ਾਵਾਂ ਦੀ ਕਾਰਗੁਜ਼ਾਰੀ ਨਾਲ ਤੁਲਨਾ ਕਰਾਂਗੇ।

6. ਅਸੀਂ ਲੰਬੇ ਸਮੇਂ ਦੀ ਪਹੁੰਚ ਅਪਣਾਵਾਂਗੇ ਜੋ ਸਿਖਲਾਈ, ਏਕੀਕਰਨ ਦੀਆਂ ਲਾਗਤਾਂ ਅਤੇ Rust ਵਰਤਣ ਦੇ ਸੰਭਾਵੀ ਫਾਇਦਿਆਂ ਵਿੱਚ ਸੰਤੁਲਨ ਰੱਖਦੀ ਹੈ।

### ਤਰਕ-ਆਧਾਰ

ਅਸੀਂ Rust ਨੂੰ ਇਸ ਦੀਆਂ ਵਿਲੱਖਣ ਵਿਸ਼ੇਸ਼ਤਾਵਾਂ ਕਾਰਨ ਅਪਣਾਇਆ ਹੈ ਜੋ ਕਾਰਗੁਜ਼ਾਰੀ ਅਤੇ ਕੁਸ਼ਲਤਾ ਕਾਇਮ ਰੱਖਦੇ ਹੋਏ ਮੈਮਰੀ ਸੁਰੱਖਿਆ ਅਤੇ ਸੁਰੱਖਿਆ ਦੀਆਂ ਗਾਰੰਟੀਆਂ ਦੇਣ ਲਈ ਡਿਜ਼ਾਈਨ ਕੀਤੀਆਂ ਗਈਆਂ ਹਨ। Rust ਦੀ ਮਜ਼ਬੂਤ ਕਿਸਮ ਪ੍ਰਣਾਲੀ, ਬੌਰੋ ਚੈਕਰ ਅਤੇ ਮੈਮਰੀ ਸੁਰੱਖਿਆ ਦੇ ਸੰਕਲਪ ਇਸ ਨੂੰ ਕਾਰਗੁਜ਼ਾਰੀ-ਨਾਜ਼ੁਕ ਅਤੇ ਸੁਰੱਖਿਆ-ਨਾਜ਼ੁਕ ਐਪਲੀਕੇਸ਼ਨਾਂ ਵਿਕਸਿਤ ਕਰਨ ਲਈ ਬਹੁਤ ਢੁਕਵਾਂ ਬਣਾਉਂਦੇ ਹਨ। ਇਸ ਤੋਂ ਇਲਾਵਾ, Rust ਦੇ ਡਿਵੈਲਪਰਾਂ ਦਾ ਵੱਡਾ ਭਾਈਚਾਰਾ ਹੈ, ਜੋ ਸਾਨੂੰ ਉਨ੍ਹਾਂ ਟੂਲਾਂ, ਲਾਇਬ੍ਰੇਰੀਆਂ ਅਤੇ ਈਕੋਸਿਸਟਮ ਦੀ ਵਿਆਪਕ ਲੜੀ ਤੱਕ ਪਹੁੰਚ ਕਰਨ ਦੇ ਯੋਗ ਬਣਾਉਂਦਾ ਹੈ ਜੋ ਸਾਡੇ ਵਿਕਾਸ ਵਰਕਫਲੋ ਦਾ ਸਮਰਥਨ ਕਰਦੇ ਹਨ। ਭਾਵੇਂ Rust ਦਾ ਸਿੱਖਣ ਦਾ ਵਕਰ ਹੈ, ਸਾਡਾ ਮੰਨਣਾ ਹੈ ਕਿ Rust ਅਪਣਾਉਣ ਦੇ ਫਾਇਦੇ ਲਾਗਤਾਂ ਨਾਲੋਂ ਵੱਧ ਹਨ ਅਤੇ ਲਗਾਤਾਰ ਵਿਕਾਸ ਅਤੇ ਨਵੀਨਤਾ ਦਾ ਸ਼ਾਨਦਾਰ ਮੌਕਾ ਦਿੰਦੇ ਹਨ।

### ਨਤੀਜੇ

1. Rust ਨੂੰ ਅਪਣਾਉਣ ਲਈ ਡਿਵੈਲਪਰਾਂ ਨੂੰ ਸਿਖਲਾਈ ਦੇਣ ਅਤੇ ਭਾਸ਼ਾ ਨੂੰ ਮੌਜੂਦਾ ਵਿਕਾਸ ਵਰਕਫਲੋ ਵਿੱਚ ਜੋੜਨ ਲਈ ਸਮੇਂ ਅਤੇ ਸਰੋਤਾਂ ਵਿੱਚ ਮਹੱਤਵਪੂਰਨ ਨਿਵੇਸ਼ ਦੀ ਲੋੜ ਪਵੇਗੀ।

2. Rust ਨੂੰ ਅਪਣਾਉਣ ਨਾਲ ਮੌਜੂਦਾ ਸਿਸਟਮਾਂ ਨਾਲ ਅਨੁਕੂਲਤਾ ਦੀਆਂ ਕੁਝ ਹੱਦ ਤੱਕ ਸਮੱਸਿਆਵਾਂ ਪੈਦਾ ਹੋ ਸਕਦੀਆਂ ਹਨ, ਜਿਨ੍ਹਾਂ ਲਈ ਰੀਫੈਕਟਰਿੰਗ ਅਤੇ ਸੋਧਾਂ ਦੀ ਲੋੜ ਹੋਵੇਗੀ।

3. Rust ਨੂੰ ਅਪਣਾਉਣ ਨਾਲ ਸਾਡੇ ਪ੍ਰੋਜੈਕਟ ਵਿੱਚ ਯੋਗਦਾਨ ਪਾ ਸਕਣ ਵਾਲੇ ਡਿਵੈਲਪਰਾਂ ਦੀ ਗਿਣਤੀ ਵਧ ਸਕਦੀ ਹੈ, ਕਿਉਂਕਿ ਇਹ ਉਨ੍ਹਾਂ Rust ਡਿਵੈਲਪਰਾਂ ਨੂੰ ਆਕਰਸ਼ਿਤ ਕਰੇਗਾ ਜੋ ਦਿਲਚਸਪ ਪ੍ਰੋਜੈਕਟਾਂ ਉੱਤੇ ਕੰਮ ਕਰਨਾ ਚਾਹੁੰਦੇ ਹਨ।

4. ਇਸ ਨੂੰ ਅਪਣਾਉਣ ਨਾਲ ਮੌਜੂਦਾ ਭਾਸ਼ਾਵਾਂ ਦੇ ਮੁਕਾਬਲੇ ਸੁਧਰੀ ਕਾਰਗੁਜ਼ਾਰੀ, ਕੁਸ਼ਲਤਾ ਅਤੇ ਸੁਰੱਖਿਆ ਮਿਲ ਸਕਦੀ ਹੈ।

5. ਅੰਤ ਵਿੱਚ, Rust ਅਪਣਾਉਣ ਨਾਲ ਸਾਡੀਆਂ ਐਪਲੀਕੇਸ਼ਨਾਂ ਵਿੱਚ ਸੁਰੱਖਿਆ ਕਮਜ਼ੋਰੀਆਂ ਘਟਾਉਣ ਦਾ ਸੰਭਾਵੀ ਫਾਇਦਾ ਜੁੜਿਆ ਹੈ।
