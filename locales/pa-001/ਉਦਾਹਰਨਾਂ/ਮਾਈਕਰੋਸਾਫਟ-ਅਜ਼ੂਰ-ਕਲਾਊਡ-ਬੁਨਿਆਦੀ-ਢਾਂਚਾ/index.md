# ਆਰਕੀਟੈਕਚਰ ਫੈਸਲਾ ਰਿਕਾਰਡ: Microsoft Azure ਕਲਾਊਡ ਬੁਨਿਆਦੀ ਢਾਂਚਾ" 

ਫੈਸਲੇ ਦਾ ਸਿਰਲੇਖ: ਸਾਡੀ ਸੰਸਥਾ ਲਈ ਕਲਾਊਡ ਬੁਨਿਆਦੀ ਢਾਂਚੇ ਵਜੋਂ Microsoft Azure ਅਪਣਾਉਣਾ

ਫੈਸਲਾ ਲੈਣ ਵਾਲਾ: ਮੁੱਖ ਸੂਚਨਾ ਅਧਿਕਾਰੀ

ਮਿਤੀ: 2021-10-15

ਸਥਿਤੀ: ਮਨਜ਼ੂਰ

## ਪਿਛੋਕੜ

ਸੰਸਥਾ ਰਵਾਇਤੀ ਆਨ-ਪ੍ਰੀਮਾਈਸ ਬੁਨਿਆਦੀ ਢਾਂਚੇ ਤੋਂ ਕਲਾਊਡ ਬੁਨਿਆਦੀ ਢਾਂਚੇ ਵੱਲ ਜਾਣ ਦੀ ਯੋਜਨਾ ਬਣਾ ਰਹੀ ਹੈ। ਇਹ ਹਾਸਲ ਕਰਨ ਲਈ, ਸੰਸਥਾ ਨੇ Amazon Web Services (AWS), Google Cloud Platform (GCP), Microsoft Azure ਅਤੇ IBM Cloud ਵਰਗੇ ਕਈ ਕਲਾਊਡ ਸੇਵਾ ਪ੍ਰਦਾਤਾਵਾਂ ਦਾ ਮੁਲਾਂਕਣ ਕੀਤਾ ਹੈ। ਹਰ ਪ੍ਰਦਾਤਾ ਦੀਆਂ ਆਪਣੀਆਂ ਵਿਸ਼ੇਸ਼ਤਾਵਾਂ, ਫਾਇਦੇ ਅਤੇ ਕੀਮਤ ਢਾਂਚਾ ਹੈ। ਵਿਸਤ੍ਰਿਤ ਵਿਸ਼ਲੇਸ਼ਣ ਤੋਂ ਬਾਅਦ, ਇਹ ਸਿੱਟਾ ਕੱਢਿਆ ਗਿਆ ਕਿ Microsoft Azure ਸਾਡੀ ਸੰਸਥਾ ਲਈ ਸਭ ਤੋਂ ਢੁਕਵਾਂ ਵਿਕਲਪ ਹੈ।

## ਫੈਸਲਾ

ਆਪਣੀ ਸੰਸਥਾ ਲਈ ਕਲਾਊਡ ਬੁਨਿਆਦੀ ਢਾਂਚੇ ਵਜੋਂ Microsoft Azure ਅਪਣਾਓ।

## ਤਰਕ-ਆਧਾਰ

Microsoft Azure ਅਪਣਾਉਣ ਦੇ ਕਾਰਨ ਇਹ ਹਨ:

1. ਵਿਆਪਕ ਸੇਵਾਵਾਂ: Azure ਸੇਵਾ ਵਜੋਂ ਬੁਨਿਆਦੀ ਢਾਂਚੇ (IaaS) ਤੋਂ ਲੈ ਕੇ ਸੇਵਾ ਵਜੋਂ ਸਾਫਟਵੇਅਰ (SaaS) ਅਤੇ ਸੇਵਾ ਵਜੋਂ ਪਲੇਟਫਾਰਮ (PaaS) ਤੱਕ ਕਲਾਊਡ ਸੇਵਾਵਾਂ ਦੀ ਪੂਰੀ ਲੜੀ ਦਿੰਦਾ ਹੈ। ਇਹ ਸਾਨੂੰ ਸੰਸਥਾ ਦੀਆਂ ਲੋੜਾਂ, ਜਿਵੇਂ ਕਿ ਸਟੋਰੇਜ, ਕੰਪਿਊਟ, ਨੈੱਟਵਰਕਿੰਗ ਅਤੇ ਵਿਸ਼ਲੇਸ਼ਣ, ਹੱਲ ਕਰਨ ਲਈ Azure ਸੇਵਾਵਾਂ ਦਾ ਲਾਭ ਲੈਣ ਦੇ ਯੋਗ ਬਣਾਉਂਦਾ ਹੈ।

2. ਵਧਣਯੋਗਤਾ ਅਤੇ ਲਚਕਤਾ: Azure ਨਾਲ, ਅਸੀਂ ਆਪਣੀਆਂ ਕਾਰੋਬਾਰੀ ਲੋੜਾਂ ਅਨੁਸਾਰ ਸਰੋਤਾਂ ਨੂੰ ਆਸਾਨੀ ਨਾਲ ਵਧਾ ਜਾਂ ਘਟਾ ਸਕਦੇ ਹਾਂ। Azure ਓਪਰੇਟਿੰਗ ਸਿਸਟਮ, ਪ੍ਰੋਗਰਾਮਿੰਗ ਭਾਸ਼ਾ ਅਤੇ ਫਰੇਮਵਰਕ ਚੁਣਨ ਵਿੱਚ ਵੀ ਲਚਕਤਾ ਦਿੰਦਾ ਹੈ।

3. ਸੁਰੱਖਿਆ ਅਤੇ ਪਾਲਣਾ: Azure ਸੁਰੱਖਿਆ ਅਤੇ ਪਾਲਣਾ ਦਾ ਉੱਚ ਪੱਧਰ ਦਿੰਦਾ ਹੈ, ਕਿਉਂਕਿ ਇਹ ISO, SOC, HIPAA ਅਤੇ PCI DSS ਵਰਗੇ ਕਈ ਉਦਯੋਗਿਕ ਮਿਆਰਾਂ ਦੀ ਪਾਲਣਾ ਕਰਦਾ ਹੈ। Azure ਨੈੱਟਵਰਕ ਸੁਰੱਖਿਆ ਸਮੂਹ, ਫਾਇਰਵਾਲ ਅਤੇ DDoS ਸੁਰੱਖਿਆ ਵਰਗੀਆਂ ਉੱਨਤ ਸੁਰੱਖਿਆ ਵਿਸ਼ੇਸ਼ਤਾਵਾਂ ਵੀ ਦਿੰਦਾ ਹੈ।

4. ਹਾਈਬ੍ਰਿਡ ਕਲਾਊਡ: Azure ਸਹਿਜ ਹਾਈਬ੍ਰਿਡ ਕਲਾਊਡ ਤਜਰਬਾ ਦਿੰਦਾ ਹੈ, ਜੋ ਸੰਸਥਾਵਾਂ ਨੂੰ ਆਪਣਾ ਆਨ-ਪ੍ਰੀਮਾਈਸ ਬੁਨਿਆਦੀ ਢਾਂਚਾ Azure ਨਾਲ ਜੋੜਨ ਦੇ ਯੋਗ ਬਣਾਉਂਦਾ ਹੈ। ਇਹ ਸਾਡੇ ਲਈ ਵਰਕਲੋਡਾਂ ਨੂੰ ਕਲਾਊਡ ਵਿੱਚ ਲਿਜਾਣਾ ਆਸਾਨ ਬਣਾਉਂਦਾ ਹੈ ਅਤੇ ਡਾਟਾ ਕਿੱਥੇ ਸਟੋਰ ਕਰਨਾ ਹੈ ਇਹ ਚੁਣਨ ਦੀ ਲਚਕਤਾ ਦਿੰਦਾ ਹੈ।

5. ਲਾਗਤ-ਪ੍ਰਭਾਵਸ਼ਾਲੀ: Azure ਵਰਤੋਂ-ਅਨੁਸਾਰ-ਭੁਗਤਾਨ ਕੀਮਤ ਮਾਡਲ ਦਿੰਦਾ ਹੈ, ਜਿਸ ਦਾ ਮਤਲਬ ਹੈ ਕਿ ਅਸੀਂ ਸਿਰਫ਼ ਵਰਤੇ ਗਏ ਸਰੋਤਾਂ ਲਈ ਭੁਗਤਾਨ ਕਰਦੇ ਹਾਂ। ਇਹ ਰਵਾਇਤੀ ਆਨ-ਪ੍ਰੀਮਾਈਸ ਬੁਨਿਆਦੀ ਢਾਂਚੇ ਦੇ ਮੁਕਾਬਲੇ ਲਾਗਤ ਬਚਾਉਣ ਵਿੱਚ ਸਾਡੀ ਮਦਦ ਕਰਦਾ ਹੈ।

## ਸਿੱਟਾ

ਆਪਣੀ ਸੰਸਥਾ ਲਈ ਕਲਾਊਡ ਬੁਨਿਆਦੀ ਢਾਂਚੇ ਵਜੋਂ Microsoft Azure ਅਪਣਾਉਣਾ ਸਾਡੀਆਂ ਕਾਰੋਬਾਰੀ ਲੋੜਾਂ ਨਾਲ ਮੇਲ ਖਾਂਦਾ ਹੈ ਅਤੇ ਵਧਣਯੋਗਤਾ, ਲਚਕਤਾ, ਸੁਰੱਖਿਆ ਅਤੇ ਲਾਗਤ-ਪ੍ਰਭਾਵਸ਼ੀਲਤਾ ਵਰਗੇ ਕਈ ਫਾਇਦੇ ਦਿੰਦਾ ਹੈ। ਇਸ ਲਈ, ਸਾਡੇ ਕਲਾਊਡ ਬੁਨਿਆਦੀ ਢਾਂਚੇ ਵਜੋਂ Azure ਅਪਣਾਉਣ ਦੀ ਸਿਫ਼ਾਰਸ਼ ਕੀਤੀ ਜਾਂਦੀ ਹੈ।
