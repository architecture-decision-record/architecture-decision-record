# Modèle d’enregistrement de décision pour le patron alexandrin

## Introduction

* Prologue (Résumé)
* Discussion (Contexte)
* Solution (Décision)
* Conséquences (Résultats)

## Détails ##

* Prologue (Résumé)
  * Énoncé de synthèse :
    * Dans le contexte de (cas d’usage)<br>
      face à (préoccupation)<br>
      nous avons opté pour (option)<br>
      afin d’obtenir (qualité)<br>
      en acceptant (inconvénient).
* Discussion (Contexte)
  * Explique les forces en jeu (techniques, politiques, sociales, de projet).
  * C’est l’histoire qui explique le problème que nous cherchons à résoudre.
* Solution
  * Explique comment la décision résoudra le problème.
* Conséquences
  * Explique les résultats de la décision à long terme.
  * Si elle a fonctionné, n’a pas fonctionné, a été modifiée, mise à niveau, etc.
