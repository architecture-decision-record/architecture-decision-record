# Zapis arhitekturne odločitve: programski jezik Python

## Kontekst

Odločiti se moramo, ali bomo za svoj projekt uporabili Python kot programski jezik. Naš projekt vključuje analizo podatkov, strojno učenje in spletni razvoj.

## Odločitev

Odločili smo se, da bomo Python uporabili kot primarni programski jezik za svoj projekt.

## Utemeljitev

Python je vsestranski programski jezik, ki se široko uporablja na področjih analize podatkov, strojnega učenja in spletnega
razvoja. Je interpretiran jezik, kar pomeni, da ga ni treba prevajati, in ima lahko berljivo ter razumljivo sintakso. Drugi pomembni dejavniki naše odločitve vključujejo naslednje:

1. **Razpoložljivost knjižnic:** Python ima ogromno zbirko knjižnic in ogrodij, kot so NumPy, Pandas in Scikit-learn, zaradi česar razvijalci lažje izvajajo algoritme strojnega učenja in analizo podatkov.

2. **Podpora skupnosti:** Python ima veliko in dejavno skupnost razvijalcev, ki prispevajo k njegovemu razvoju ter zagotavljajo podporo in smernice na različnih forumih in spletnih mestih. To začetnikom olajša iskanje pomoči in učenje jezika.

3. **Razširljivost:** Python je razširljiv, kar pomeni, da lahko obvladuje velike nabore podatkov in zapletene aplikacije. Uporabljamo ga lahko tudi za hitro izdelavo prototipov ali gradnjo majhnih aplikacij z minimalnim naporom, kar nam olajša začetek projekta in hitro iteriranje.

4. **Prilagodljivost:** Python je mogoče uporabljati za različne vrste projektov, vključno s spletnim razvojem, znanstvenim računalništvom, strojnim učenjem itd. Združljiv je tudi z drugimi programskimi jeziki, kot sta Java in C++, kar olajša integracijo z drugimi sistemi.

## Posledice

Uporaba Pythona kot programskega jezika ima nekaj možnih posledic, kot so:

1. **Zmogljivost:** Python je lahko pri izvajanju določenih algoritmov počasnejši od prevedenih jezikov, kot je C++, vendar je to mogoče omiliti z uporabo optimiziranih knjižnic ali pisanjem kritične kode v C++ in povezovanjem z njo prek Pythona.

2. **Krivulja učenja:** Čeprav ima Python sintakso, ki se jo je lahko naučiti, je lahko zahtevno naučiti se najboljših praks za pisanje učinkovite in razširljive kode. To je mogoče premagati s sledenjem konvencijam, uporabo ogrodij in knjižnic ter iskanjem smernic pri izkušenih razvijalcih.

3. **Združljivost različic:** Različne različice Pythona imajo lahko različno sintakso in zmožnosti, kar lahko otežuje vzdrževanje in posodabljanje projektov. Pomembno je izbrati različico Pythona, ki je široko podprta in združljiva z zahtevami našega projekta.
