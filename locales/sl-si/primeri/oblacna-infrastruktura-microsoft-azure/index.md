# Zapis arhitekturne odločitve: oblačna infrastruktura Microsoft Azure" 

Naslov odločitve: Uvedba Microsoft Azure kot oblačne infrastrukture za našo organizacijo

Odločevalec: direktor informatike (CIO)

Datum: 2021-10-15

Stanje: Odobreno

## Ozadje

Organizacija načrtuje selitev s tradicionalne lokalne infrastrukture na oblačno infrastrukturo. Za dosego tega je organizacija ovrednotila več ponudnikov oblačnih storitev, kot so Amazon Web Services (AWS), Google Cloud Platform (GCP), Microsoft Azure in IBM Cloud. Vsak ponudnik ima svoj nabor funkcij, prednosti in cenovno strukturo. Po podrobni analizi je bilo ugotovljeno, da je Microsoft Azure za našo organizacijo najprimernejša možnost.

## Odločitev

Uvesti Microsoft Azure kot oblačno infrastrukturo za našo organizacijo.

## Utemeljitev

Razlogi za uvedbo Microsoft Azure so naslednji:

1. Celovite storitve: Azure zagotavlja celoten nabor oblačnih storitev, od infrastrukture kot storitve (IaaS) do programske opreme kot storitve (SaaS) in platforme kot storitve (PaaS). To nam omogoča, da storitve Azure izkoristimo za rešitev zahtev organizacije, kot so shranjevanje, računanje, omrežje in analitika.

2. Razširljivost in prilagodljivost: Z Azure lahko preprosto povečamo ali zmanjšamo vire glede na poslovne zahteve. Azure ponuja tudi prilagodljivost pri izbiri operacijskega sistema, programskega jezika in ogrodij.

3. Varnost in skladnost: Azure ponuja visoko raven varnosti in skladnosti, saj je skladen z več panožnimi standardi, kot so ISO, SOC, HIPAA in PCI DSS. Azure zagotavlja tudi napredne varnostne funkcije, kot so omrežne varnostne skupine, požarni zidovi in zaščita pred DDoS.

4. Hibridni oblak: Azure zagotavlja brezhibno izkušnjo hibridnega oblaka, ki organizacijam omogoča povezavo lokalne infrastrukture z Azure. To nam olajša selitev delovnih obremenitev v oblak in nam daje prilagodljivost pri izbiri, kje shranjevati podatke.

5. Stroškovna učinkovitost: Azure ponuja cenovni model plačila po porabi (pay-as-you-go), kar pomeni, da plačamo le za uporabljene vire. To nam pomaga prihraniti stroške v primerjavi s tradicionalno lokalno infrastrukturo.

## Sklep

Uvedba Microsoft Azure kot oblačne infrastrukture za našo organizacijo se ujema z našimi poslovnimi zahtevami in ponuja več koristi, kot so razširljivost, prilagodljivost, varnost in stroškovna učinkovitost. Zato se priporoča uvedba Azure kot naše oblačne infrastrukture.
