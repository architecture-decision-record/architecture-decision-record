## Achoimre


### Saincheist

Ba mhaith linn devops a úsáid chun ár dtionscadail a thógáil, a chomhtháthú, a imlonnú, agus a óstáil. Táimid ag smaoineamh ar Microsoft Azure DevOps.

  * Ba mhaith linn go mbeadh taithí an fhorbróra tapa agus iontaofa, maidir le socrú devops m.sh. cumrú agus úsáid leanúnach m.sh. amanna tógála tapa.
  
  * Ba mhaith linn smaoineamh ar Microsoft Azure a úsáid ina iomláine, chun aipeanna tionscadail, bunachair sonraí, srl. a óstáil.


### Cinneadh

Socraíodh in aghaidh Microsoft Azure DevOps.


### Stádas

Socraithe. Oscailte d'athbhreithniú dá dtagann faisnéis shuntasach nua.


## Sonraí


### Toimhdeanna

Gach gnáthtoimhde devops, amhail sa leabhar Accelerate.

  * Is cabhair shuntasach iad tógálacha tapa. Luasghéaraíonn sé seo na lúba aiseolais.

  * Is féidir linn píosaí a mhalartú isteach/amach ó dhíoltóirí malartacha i.e. b'fhéidir gur mhaith linn ár bhfreastalaithe tógála níos tapúla féin a thabhairt linn, nó ár rogha féin de chóras rialaithe leaganacha a úsáid, nó comhordú a dhéanamh le freastalaí lánpháirtithe leanúnaigh féin-óstáilte.
  
  * Is cabhair shuntasach í inúsáidteacht ailínithe, d'eispéireas an fhorbróra, agus ar a seal do réimsí caolchúiseacha amhail comhsheasmhacht, soiléireacht, slándáil, agus éascaíocht an chuair foghlama.

  * Nuair atá aon rud briste nó fadhbach, ba mhaith linn bealach éifeachtach chun an tsaincheist a thuairisciú. Tá sé seo tábhachtach go háirithe d'aon saincheisteanna a bhaineann le slándáil.


### Srianta

Aon cheann ar eolas. Tá tiomantas foilsithe ag Azure do bheith ag obair go maith le huirlisí seachtracha.


### Seasaimh

Bhreithnigh muid Microsoft Azure Devops a úsáid seachas AWS atá i seilbh.

Rinne muid turgnamh le Azure DevOps, Azure Pipelines, Azure Repo, agus Azure ag tosú freastalaí nua trí Terraform.

Rinne muid turgnamh le tacaíocht a fháil ó ionadaithe Microsoft.

Bhailigh muid faisnéis ó chomhghleacaithe ar bhlaganna agus Hacker News.


### Argóint

Fógraíonn Azure DevOps tacar sármhaith tairiscintí, ach ní sheasann siad suas, agus ní oibríonn siad go maith le chéile, agus tá an tacaíocht lag.

Ár dtaithí dhíreach:

  * Is praiseach de chomhéadain úsáideora é socrú Azure, cuid acu ag forluí le cuntais Microsoft, cuid eile nach bhfuil. M.sh. tá síniú isteach Azure ann, síniú isteach Microsoft.com, síniú isteach Live.com, srl. agus tá siad ar fad i bhfeidhm ag an am céanna.

  * Tháinig muid ar shaincheist bheag slándála le linn an tsocraithe, agus ní bhfuair muid réiteach. Rinne muid iarracht é a thuairisciú ar go leor bealaí, d'go leor ionadaithe Microsoft, gan aon rath. D'éirigh linn é a thuairisciú do shlándáil Microsoft, a d'fhreagair le won't fix (ní dheisfear).

  * Is minic go bhfuil an doiciméadú mícheart nó as dáta. Tá cuid de seo mar gheall ar inneall cuardaigh lag Microsoft, agus cuid de mar gheall ar SEO faoi bhun an chaighdeáin.
  
  * Tá socrú Terraform doiciméadaithe go maith, agus oibríonn sé. Mar sin féin, tá tacaíocht Terraform lag i gcomparáid le AWS toisc go bhfuil Microsoft ag tógáil caidreamh gnó le díoltóirí chun samplaí socraithe Terraform slabhraithe a dhéanamh.

Taithí ár gcomhghleacaithe:

  * Tar éis dúinn ár measúnú dall féin a dhéanamh, d'fhéach muid ar thaithí comhghleacaithe. Dheimhnigh an méid a fuair muid ár dtaithí.

  * Thuairisc comhghleacaithe fadhbanna breise le hamanna tógála, agus fadhbanna le freastalaí tógála a thabhairt leat. Tá na fadhbanna seo i bhfad níos tromchúisí ná fadhbanna comhéadain úsáideora, toisc gurb é tógálacha a dhéanamh príomhchuspóir píblíne tógála, agus táimid ag súil go leor a dhéanamh in aghaidh an lae.

  * Fuair muid rannpháirtíocht den scoth ó chomhghleacaithe foirne Azure sna háiteanna plé. Bualadh bos do Microsoft as sin. Chuaigh Edward Thomson, Azure PM agus códóir, i bhfeidhm go háirithe orainn, mar gheall ar a rannpháirtíocht, a dhíreacht, agus a mhínithe teicniúla.


### Impleachtaí

## Gaolmhar


### Cinntí gaolmhara

Má roghnaímid Azure DevOps, tá go leor tairiscintí gaolmhara ann, lena n-áirítear Azure Repo, Azure Pipeline, srl. Creidimid, má roghnaímid Azure Devops, go bhféadfadh sé seo cumais Azure eile a úsáid a éascú, nó cumais díoltóirí eile a úsáid a dhéanamh níos deacra.

Creidimid go bhfuil Microsoft ag déanamh dul chun cinn mór in eispéireas an fhorbróra, agus feicimid Microsoft ag déanamh ceannacháin mhóra uirlisí forbróra (m.sh. GitHub) agus spleáchais (m.sh. Citus).

Má roghnaímid Azure DevOps, b'fhéidir gur mhaith linn béim a leagan ar thairiscintí cheannacháin Microsoft a roghnú, agus b'fhéidir gur mhaith linn freisin cur chuige a dhéanamh ar na tairiscintí ceannacháin le níos mó cúraim/measúnaithe mar gheall ar dhiúltú fíocháin féideartha m.sh. riosca láimhdeachais foirne.


### Riachtanais ghaolmhara

Ba mhaith linn go mbeadh amanna tógála an-tapa. Glacaimid le préimh ard a íoc as seo. Is amhlaidh toisc gur mian linn atriall an-tapa a dhéanamh.

Ba mhaith linn go mbeadh iontaofacht an-ard. Glacaimid le préimh ard a íoc as seo. Is amhlaidh toisc go bhfuil muid ag tástáil cásanna úsáide ard-luacha, lena n-áirítear idirbhearta airgeadais, idirbhearta rúnda, srl.

Tá meán-am chun téarnaimh i measc ár 4 KPI devops is fearr, rud a éilíonn tógálacha tapa agus iontaofacht ard.


### Déantáin ghaolmhara

Ba mhaith linn go dtáirgfidh an córas tógála déantáin atá oiriúnach le húsáid i gcórais eile, amhail Artifactory.


### Prionsabail ghaolmhara

Inaisiompaithe go héasca. Is féidir linn Azure DevOps a mheas i gcomhthráth le AWS atá i seilbh.

### Windows Development MVP

Windows Development MVP anseo. Mothaím go gcaithfidh mé cuid den fhreagracht a ghlacadh as gan a bheith níos airde faoi na saincheisteanna seo. Ach caithfidh mé a rá, tá díomá orm a chloisteáil go bhfuil “iontas” oraibh faoi na saincheisteanna UX. Bhí mé ag insint do do dhaoine go bhfuil an UX uafásach (m.sh. chomh fada siar le réamhsheoladh) agus choinnigh mé ag cloisteáil “tá a fhios againn, táimid á dheisiú”. Tosóidh mé ag foirmiú an aiseolais agus á bhrú tríd na píopaí, fan linn. Táim áitiúil freisin (Bellevue), ba bhreá liom teacht isteach agus iarracht a dhéanamh píblíne a dhéanamh dár n-aip foinse oscailte .net/wpf/uwp measartha simplí. Tá amhras orm go n-osclóidh sé súile an bheirt againn.

Roinnt samplaí:

* Ní féidir píblíne a thógáil le taisclann git ina bhfuil fo-mhodúil

* Fuair mé go raibh sé dodhéanta an PATH a chur in eagar le haghaidh roinnt uirlisí saincheaptha

* Ní dhéanann an taithí Píblíne Nua aon chiall, tiocfaidh úsáideoirí nua ag cliceáil timpeall ar an Doiciméadú mícheart ar deireadh.
