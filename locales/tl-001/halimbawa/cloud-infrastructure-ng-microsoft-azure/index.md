# Architecture Decision Record: Cloud infrastructure ng Microsoft Azure" 

Pamagat ng Desisyon: Pag-aampon sa Microsoft Azure bilang cloud infrastructure ng aming organisasyon

Gumawa ng Desisyon: Chief Information Officer

Petsa: 2021-10-15

Katayuan: Inaprubahan

## Background

Plano ng organisasyon na lumipat mula sa tradisyonal na on-premises infrastructure patungo sa cloud infrastructure. Upang makamit ito, sinuri ng organisasyon ang maraming cloud service provider tulad ng Amazon Web Services (AWS), Google Cloud Platform (GCP), Microsoft Azure, at IBM Cloud. May kanya-kanyang hanay ng mga feature, benepisyo, at istruktura ng presyo ang bawat provider. Matapos ang detalyadong pagsusuri, napagpasyahang ang Microsoft Azure ang pinakaangkop na opsyon para sa aming organisasyon.

## Desisyon

Ampunin ang Microsoft Azure bilang cloud infrastructure ng aming organisasyon.

## Rasyonal

Ang mga sumusunod ang mga dahilan sa pag-aampon ng Microsoft Azure:

1. Komprehensibong mga Serbisyo: Nagbibigay ang Azure ng kumpletong hanay ng mga cloud service mula infrastructure as a service (IaaS) hanggang software as a service (SaaS) at platform as a service (PaaS). Pinahihintulutan kaming gamitin ang mga serbisyo ng Azure para lutasin ang mga requirement ng organisasyon, tulad ng storage, compute, networking, at analytics.

2. Scalability at Flexibility: Sa Azure, madali naming mai-scale pataas o pababa ang mga resource batay sa aming mga requirement sa negosyo. Nag-aalok din ang Azure ng flexibility sa pagpili ng operating system, programming language, at mga framework.

3. Seguridad at Compliance: Nag-aalok ang Azure ng mataas na antas ng seguridad at compliance, dahil sumusunod ito sa ilang pamantayan sa industriya tulad ng ISO, SOC, HIPAA, at PCI DSS. Nagbibigay din ang Azure ng mga advanced na security feature tulad ng network security group, firewall, at proteksyon laban sa DDoS.

4. Hybrid Cloud: Nagbibigay ang Azure ng tuloy-tuloy na karanasan sa hybrid cloud, na nagpapahintulot sa mga organisasyong ikonekta ang kanilang on-premises infrastructure sa Azure. Pinadadali nito para sa amin ang paglipat ng mga workload sa cloud at nagbibigay sa amin ng flexibility na piliin kung saan iimbak ang data.

5. Matipid: Nag-aalok ang Azure ng pay-as-you-go na modelo ng pagpepresyo, na nangangahulugang magbabayad lang kami para sa mga resource na ginamit. Nakatutulong ito para makatipid kami kumpara sa tradisyonal na on-premises infrastructure.

## Konklusyon

Ang pag-aampon sa Microsoft Azure bilang cloud infrastructure ng aming organisasyon ay umaayon sa aming mga requirement sa negosyo at nag-aalok ng ilang benepisyo tulad ng scalability, flexibility, seguridad, at pagiging matipid. Samakatuwid, inirerekomendang ampunin ang Azure bilang aming cloud infrastructure.
