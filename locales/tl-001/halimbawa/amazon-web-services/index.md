# Architecture Decision Record para sa Amazon Web Services

Pamagat: Pag-aampon ng Amazon Web Services para sa Cloud Infrastructure

## Desisyon

Matapos ang masusing pagsusuri sa iba't ibang cloud infrastructure platform, napagpasyahan na ampunin ng aming organisasyon ang Amazon Web Services (AWS) para sa aming mga pangangailangan sa cloud infrastructure.

## Background

Mabilis na lumalaki ang aming organisasyon at kailangan namin ng maaasahan at scalable na cloud infrastructure para matugunan ang pangangailangan ng aming negosyo. Matapos isaalang-alang ang ilang cloud infrastructure provider, napagpasyahan na nag-aalok ang AWS ng pinakaangkop na hanay ng mga serbisyo para matugunan ang aming kasalukuyan at hinaharap na mga requirement.

## Mga Konsiderasyon

Maraming cloud infrastructure provider sa merkado na napatunayang maaasahan at mahusay. Gayunpaman, hindi lamang nag-aalok ang AWS ng komprehensibong hanay ng mga serbisyo para tugunan ang aming mga pangangailangan, kundi mayroon din itong malawak na base ng mga customer at rekord ng matagumpay na mga deployment. Nagbibigay din ang AWS ng malawak na hanay ng suporta at resources sa pagsasanay para matiyak na mabisang makakatrabaho ng aming koponan ang platform.

Higit pa rito, may malawak na pandaigdigang presensya ang AWS na may mga data center sa iba't ibang rehiyon sa buong mundo. Tinitiyak nito na ligtas ang aming data at magiging lubos na available ang aming mga application at serbisyo. May matatag ding security framework ang AWS na kritikal para sa aming negosyo.

Panghuli, nagbibigay ang AWS ng pay-as-you-go na modelo na nag-aalok sa amin ng flexibility na i-scale ang aming infrastructure ayon sa demand. Nangangahulugan ito na sisingilin lang kami sa ginagamit namin, na nagpapahintulot sa aming i-optimize ang aming mga gastos at mamuhunan sa iba pang larangan ng negosyo.

## Desisyon

Batay sa mga isinagawang pagsusuri at sa mga bentaheng iniaalok ng AWS, napagpasyahan na ampunin ang AWS para sa aming mga pangangailangan sa cloud infrastructure.

## Mga Kahihinatnan

Maaaring mangailangan ang pag-aampon ng AWS ng pagsasanay para sa aming mga koponan upang matiyak na pamilyar sila sa platform at mabisa nilang magagamit ito. Maaari ring may ilang paunang gastos sa paglipat ng aming kasalukuyang infrastructure sa AWS platform.

## Pagmamay-ari

Ang responsibilidad sa pagtiyak ng mabisang paggamit ng AWS at sa pamamahala ng mga kaugnay na panganib ay mapapasailalim sa saklaw ng cloud infrastructure team. Anumang isyung lilitaw ay dapat tugunan ng koponang ito.

## Pagrepaso

Rerepasuhin taun-taon ang desisyong ampunin ang AWS upang matiyak na patuloy nitong natutugunan ang aming mga pangangailangan at lubos na natatamo ang mga benepisyo ng platform.
