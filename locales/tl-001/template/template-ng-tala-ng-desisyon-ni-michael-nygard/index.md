# Template ng tala ng desisyon ni Michael Nygard

Ito ang template sa [Documenting architecture decisions - Michael Nygard](http://thinkrelevance.com/blog/2011/11/15/documenting-architecture-decisions).
Maaari mong gamitin ang [adr-tools](https://github.com/npryce/adr-tools) para pamahalaan ang mga ADR file.

Sa bawat ADR file, isulat ang mga seksyong ito:

# Pamagat

## Katayuan

Ano ang katayuan, tulad ng iminungkahi, tinanggap, tinanggihan, hindi na ginagamit, napalitan, atbp.?

## Konteksto

Ano ang isyung nakikita namin na nag-uudyok sa desisyon o pagbabagong ito?

## Desisyon

Ano ang pagbabagong iminumungkahi at/o ginagawa namin?

## Mga Kahihinatnan

Ano ang nagiging mas madali o mas mahirap gawin dahil sa pagbabagong ito?
