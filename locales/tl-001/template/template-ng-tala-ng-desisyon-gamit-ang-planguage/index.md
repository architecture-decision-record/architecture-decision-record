# Template ng tala ng desisyon gamit ang Planguage

Tingnan ang https://www.iaria.org/conferences2012/filesICCGI12/Tutorial%20Specifying%20Effective%20Non-func.pdf

## Ano ang Planguage?

Ang Planguage ay isang planning language na gumagamit ng mga keyword na ito:

* Tag: Isang natatangi at permanenteng identifier
* Gist: Isang maikling buod ng requirement o larangang tinutugunan
* Requirement: Ang tekstong naglalahad ng mismong requirement
* Rationale: Ang katwirang nagbibigay-katarungan sa requirement
* Priority: Isang pahayag ng priyoridad at paghahabol sa mga resource
* Stakeholders: Mga panig na materyal na naaapektuhan ng requirement
* Status: Ang katayuan ng requirement (draft, reviewed, committed, atbp.)
* Owner: Ang taong responsable sa pagpapatupad ng requirement
* Author: Ang taong sumulat ng requirement
* Revision: Isang numero ng bersyon para sa pahayag
* Date: Ang petsa ng pinakahuling rebisyon
* Assumptions: Anumang maaaring magdulot ng problema kung hindi totoo ngayon o sa hinaharap
* Risks: Anumang maaaring magdulot ng malfunction, pagkaantala, o iba pang negatibong epekto
* Defined: Ang kahulugan ng isang termino (mas mainam na gumamit ng glossary)
