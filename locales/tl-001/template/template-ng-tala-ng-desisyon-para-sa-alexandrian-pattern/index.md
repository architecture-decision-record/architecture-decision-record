# Template ng tala ng desisyon para sa Alexandrian pattern

## Panimula

* Prologue (Buod)
* Discussion (Konteksto)
* Solution (Desisyon)
* Consequences (Mga Resulta)

## Mga Detalye ##

* Prologue (Buod)
  * Pahayag na naglalagom:
    * Sa konteksto ng (use case)<br>
      na kinakaharap ang (alalahanin)<br>
      nagpasya kaming piliin ang (opsyon)<br>
      upang makamit ang (kalidad)<br>
      habang tinatanggap ang (disbentaha).
* Discussion (Konteksto)
  * Ipinapaliwanag ang mga puwersang nasa laro (teknikal, pulitikal, panlipunan, proyekto).
  * Ito ang kuwentong nagpapaliwanag sa problemang sinisikap naming lutasin.
* Solution
  * Ipinapaliwanag kung paano lulutasin ng desisyon ang problema.
* Consequences
  * Ipinapaliwanag ang mga resulta ng desisyon sa pangmatagalan.
  * Gumana ba ito, hindi gumana, binago, in-upgrade, atbp.
