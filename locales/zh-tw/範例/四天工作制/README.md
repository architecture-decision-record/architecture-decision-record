# 四天工作制的決策記錄

標題:實行四天工作制

## 背景與問題陳述

我們的組織一直在考慮改行四天工作制。目前每週工作 5 天、每天 8 小時的工作安排,已經導致生產率低下、員工倦怠和高離職率。擬議的變更旨在提高員工的滿意度、敬業度和留存率,並最終改善組織績效。

## 決策

我們決定從下個季度起,在整個組織的所有員工中實行四天工作制。

## 理由

該決策基於以下因素:

1. 員工反饋:一項針對員工的調查顯示,大家希望有更靈活的工作安排和更好的工作與生活平衡。大多數受訪者對四天工作制表示感興趣。

2. 研究發現:對已實行四天工作制的公司的研究表明,員工生產率提高,缺勤減少,工作與生活的平衡得到改善。

3. 競爭優勢:提供四天工作制可以成為對潛在員工有吸引力的福利,並有助於留住現有人才。

4. 組織目標:改行四天工作制符合我們創造更健康、更高效工作環境的組織目標。

## 實施計劃

將採取以下步驟來實行四天工作制:

1. 溝通:該決策將透過全公司郵件以及與團隊負責人的會議傳達給所有員工。

2. 排期:全職員工的新工作安排為週一至週四,兼職員工可選擇靈活的工作安排。每天的工作時間將延長至 10 小時。

3. 政策更新:人力資源政策(例如休假政策和福利)將更新,以與新的工作安排保持一致。

4. 培訓:將培訓管理者如何在新的工作安排下管理團隊,以及如何正確跟蹤員工的績效和生產率。

5. 評估:將在六個月後評估新的工作安排,以確定其對員工滿意度、敬業度和留存率的影響。

## 預期成果

實行四天工作制預計將帶來以下成果:

1. 員工的滿意度、敬業度和留存率提高。

2. 員工的工作與生活平衡得到改善。

3. 生產率提高,缺勤減少。

4. 員工福利方案更具吸引力,並在招聘市場上具備競爭優勢。

## 結論

我們相信,實行四天工作制將使我們的組織和員工受益。我們期待看到這一決策對員工以及我們整體組織績效產生的積極影響。
