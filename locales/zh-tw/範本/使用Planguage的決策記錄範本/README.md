# 使用 Planguage 的決策記錄範本

參見 https://www.iaria.org/conferences2012/filesICCGI12/Tutorial%20Specifying%20Effective%20Non-func.pdf

## 什麼是 Planguage?

Planguage 是一種規劃語言,使用以下關鍵字:

* Tag(標籤):唯一且持久的識別符號
* Gist(要點):對所涉及的需求或領域的簡要概述
* Requirement(需求):詳細說明需求本身的文字
* Rationale(理由):證明該需求合理的推理
* Priority(優先順序):對優先順序及資源佔用的宣告
* Stakeholders(利益相關者):受該需求實質性影響的各方
* Status(狀態):需求的狀態(草稿、已評審、已承諾等)
* Owner(所有者):負責實現該需求的人
* Author(作者):撰寫該需求的人
* Revision(修訂):該陳述的版本號
* Date(日期):最近一次修訂的日期
* Assumptions(假設):如果現在或將來不成立就可能引發問題的任何事項
* Risks(風險):可能導致故障、延誤或其他負面影響的任何事項
* Defined(定義):術語的定義(最好使用術語表)
