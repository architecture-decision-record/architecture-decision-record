# Michael Nygard 的決策記錄範本

這是 [記錄架構決策 - Michael Nygard](http://thinkrelevance.com/blog/2011/11/15/documenting-architecture-decisions) 一文中的範本。
你可以使用 [adr-tools](https://github.com/npryce/adr-tools) 來管理 ADR 檔案。

在每個 ADR 檔案中,撰寫以下章節:

# 標題

## 狀態

狀態是什麼,例如已提議、已接受、已拒絕、已棄用、已取代等?

## 背景

我們看到了什麼問題,促使我們做出這項決策或變更?

## 決策

我們提議和/或正在做出什麼變更?

## 後果

由於這項變更,哪些事情會變得更容易或更困難?
