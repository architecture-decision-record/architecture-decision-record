# Google Cloud Platform 嘅架構決策記錄

## 背景

Google Cloud Platform（GCP）係一個著名嘅雲端運算平台，提供多種雲端服務，包括運算、儲存同網絡方案。本 ADR 旨在記錄為我哋組織開發同實施以 GCP 為基礎嘅基礎設施所作出嘅架構決策。

## 決策

我哋組織決定用 Google Cloud Platform 作為應用程式嘅雲端基礎設施。作出呢個決策嘅主要考慮因素係：

   - 成本效益

   - 可擴展性

   - 可靠性

   - 靈活性

## 選用項目

已揀選以下 GCP 服務來滿足我哋嘅需求：

   - Compute Engine 用於虛擬機同運算資源

   - Cloud Storage 用於物件儲存同檔案託管

   - Cloud SQL 用於託管資料庫服務

   - Firebase 用於應用程式開發同託管

## 理據

   - 成本效益：Google Cloud Platform 同其他雲端平台相比，成本效益極高，對預算有限嘅組織嚟講係一個吸引嘅選擇。

   - 可擴展性：GCP 易於擴展嘅基礎設施，令佢可以即時處理任何流量。

   - 可靠性：GCP 嘅託管服務提供高可靠性，具備自動備份同災難復原能力，確保資源同數據嘅高可用性。

   - 靈活性：平台喺 AI、數據分析同 IoT 等不同領域提供多種工具同服務，用途極廣。

## 後果

遷移到 Google Cloud Platform 需要為團隊提供 GCP 服務培訓、重新設計應用程式架構令其兼容所揀選嘅服務，以及更新基礎設施程式碼以支援 GCP 服務。不過，預期遷移完成後，我哋將擁有一個高度可擴展、可靠而且具成本效益嘅基礎設施嚟託管應用程式。此外，我哋需要管理喺 GCP 上調配資源嘅持續成本。

## 結論

Google Cloud Platform 憑藉成本效益、可擴展性、可靠性同靈活性，係我哋雲端基礎設施嘅出色選擇。透過使用所揀選嘅服務，我哋可以為應用程式提供高可用性同穩健嘅基礎設施。
