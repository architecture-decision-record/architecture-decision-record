# 商業個案嘅決策記錄範本

呢個 ADR 範本強調為決策建立商業個案，包括準則、候選方案同成本。


## 頂層

* 標題
* 狀態
* 評估準則
* 要考慮嘅候選方案
* 每個候選方案嘅研究同分析
  * 符合／唔符合準則，以及原因
  * 成本分析
  * SWOT 分析
  * 意見同回饋
* 建議


## 低層次深入探討

**標題**：

  * 一個簡短嘅現在式祈使短語，少於 50 個字元，好似 git 提交訊息咁。

**狀態**：

  * 建議中、已接納、已否決、已棄用、已取代等其中之一。

**評估準則**：

  * 摘要：簡單解釋我哋想發掘咩，以及原因。

  * 具體內容

**要考慮嘅候選方案**：

  * 摘要：簡單解釋我哋點樣發掘候選方案，並提請注意任何離群項。

  * 列出所有候選方案同相關選項；我哋評估緊咩潛在解決方案？

  * 具體內容

**每個候選方案嘅研究同分析**：

  * 摘要：簡單解釋研究方法，並提請注意規律、群組同離群項。

  * 符合／唔符合準則，以及原因

    * 摘要

    * 具體內容

  * 成本分析

    * 摘要

    * 例子

      * 授權，例如合約協議同法律承諾

      * 培訓，例如技能提升同變革管理

      * 營運，例如支援同維護

      * 計量，例如頻寬同 CPU 使用量

  * SWOT 分析

    * 摘要

    * 優勢

    * 劣勢

    * 機會

    * 威脅

  * 內部意見同回饋

    * 摘要

    * 例子

      * 來自團隊，最好由當事人親自撰寫

      * 來自其他持份者

      * 質素屬性，又稱跨職能需求

  * 外部意見同回饋

    * 摘要

    * 邊個提供意見？

    * 你考慮過其他邊啲候選方案？

    * 你正建立咩？

      * 例子

        * B2B 定 B2C

        * 對外開放定只限員工使用

        * 桌面定流動

        * 試行定正式生產

        * 單體式定微服務

    * 你點樣評估候選方案？

    * 你點解揀選勝出者？

    * 自此之後發生咩事？

      * 例子

        * 勝出者表現點樣？

        * 真實生產環境嘅用戶流量有幾多百分比經過勝出者？

        * 涉及邊類整合，例如同持續交付管線、內容管理系統、分析同指標等？

        * 以你而家所知，你會建議人哋有咩唔同嘅做法？

  * 軼事

**建議**：

  * 摘要

  * 具體內容
