# Michael Nygard 嘅決策記錄範本

呢個係 [Documenting architecture decisions - Michael Nygard](http://thinkrelevance.com/blog/2011/11/15/documenting-architecture-decisions) 入面嘅範本。
你可以用 [adr-tools](https://github.com/npryce/adr-tools) 去管理 ADR 檔案。

喺每個 ADR 檔案入面，寫以下章節：

# 標題

## 狀態

狀態係點，例如建議中（proposed）、已接納（accepted）、已否決（rejected）、已棄用（deprecated）、已取代（superseded）等等？

## 背景

我哋見到咩問題，促使我哋作出呢個決策或者更改？

## 決策

我哋建議及／或者進行嘅更改係咩？

## 後果

因為呢個更改，咩事情變得更容易或者更困難？
