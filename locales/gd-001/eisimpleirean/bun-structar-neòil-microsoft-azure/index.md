# Clàr co-dhùnaidh ailtireachd: Bun-structar neòil Microsoft Azure

Tiotal a’ cho-dhùnaidh: Microsoft Azure a ghabhail mar bhun-structar neòil airson na buidhne againn

Neach-dèanamh a’ cho-dhùnaidh: Ceannard Fiosrachaidh (CIO)

Ceann-latha: 2021-10-15

Staid: Air aontachadh

## Cùl-fhiosrachadh

Tha an eagrachadh an dùil imrich bho bhun-structar traidiseanta air làrach gu bun-structar neòil. Gus seo a choileanadh, tha an eagrachadh air measadh a dhèanamh air grunn sholaraichean seirbheis neòil leithid Amazon Web Services (AWS), Google Cloud Platform (GCP), Microsoft Azure, agus IBM Cloud. Tha seata fheartan, bhuannachdan, agus structar prìsean fhèin aig gach solaraiche. Às dèidh mion-sgrùdadh mionaideach, chaidh co-dhùnadh gur e Microsoft Azure an roghainn as freagarraiche don eagrachadh againn.

## Co-dhùnadh

Microsoft Azure a ghabhail mar bhun-structar neòil airson na buidhne againn.

## Reusanachadh

Seo na h-adhbharan airson Microsoft Azure a ghabhail:

1. Seirbheisean farsaing: Bheir Azure raon iomlan de sheirbheisean neòil bho bhun-structar mar sheirbheis (IaaS) gu bathar-bog mar sheirbheis (SaaS) agus àrd-ùrlar mar sheirbheis (PaaS). Leigidh seo leinn seirbheisean Azure a chleachdadh gus riatanasan na buidhne fhuasgladh, leithid stòradh, coimpiutaireachd, lìonrachadh, agus mion-sgrùdadh.

2. So-sgèileachd agus sùbailteachd: Le Azure, is urrainn dhuinn goireasan a sgèileadh suas no sìos gu furasta a-rèir riatanasan ar gnìomhachais. Bheir Azure cuideachd sùbailteachd ann a bhith a’ taghadh an t-siostam obrachaidh, cànan prògramachaidh, agus frèamaichean.

3. Tèarainteachd agus gèilleadh: Bheir Azure ìre àrd de thèarainteachd is gèilleadh, oir tha e a’ gèilleadh ri grunn inbhean gnìomhachais leithid ISO, SOC, HIPAA, agus PCI DSS. Bheir Azure cuideachd feartan tèarainteachd adhartach leithid buidhnean tèarainteachd lìonraidh, ballachan-teine, agus dìon DDoS.

4. Neul measgaichte: Bheir Azure eòlas neul measgaichte gun fhuaigheal, a leigeas le buidhnean am bun-structar air làrach a cheangal ri Azure. Tha seo ga dhèanamh furasta dhuinn eallach-obrach imrich chun an neòil agus bheir e sùbailteachd dhuinn taghadh càite an stòraich sinn dàta.

5. Cosgais-èifeachdach: Bheir Azure modail prìsean pàigh-mar-a-chleachdas, a tha a’ ciallachadh nach pàigh sinn ach airson na goireasan a chleachdar. Cuidichidh seo sinn le bhith a’ sàbhaladh chosgaisean an coimeas ri bun-structar traidiseanta air làrach.

## Co-dhùnadh

Tha Microsoft Azure a ghabhail mar bhun-structar neòil airson na buidhne againn a’ freagairt ri riatanasan ar gnìomhachais agus a’ tabhann grunn bhuannachdan leithid so-sgèileachd, sùbailteachd, tèarainteachd, agus cosgais-èifeachdas. Mar sin, thathar a’ moladh Azure a ghabhail mar ar bun-structar neòil.
