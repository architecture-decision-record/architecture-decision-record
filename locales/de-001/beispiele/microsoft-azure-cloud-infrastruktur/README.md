# Architecture Decision Record: Microsoft-Azure-Cloud-Infrastruktur" 

Entscheidungstitel: Einführung von Microsoft Azure als Cloud-Infrastruktur für unsere Organisation

Entscheider: Chief Information Officer

Datum: 2021-10-15

Status: Genehmigt

## Hintergrund

Die Organisation plant, von der traditionellen Vor-Ort-Infrastruktur auf Cloud-Infrastruktur zu migrieren. Dazu hat die Organisation mehrere Cloud-Dienstanbieter bewertet, etwa Amazon Web Services (AWS), Google Cloud Platform (GCP), Microsoft Azure und IBM Cloud. Jeder Anbieter hat seine eigenen Funktionen, Vorteile und Preisstrukturen. Nach einer detaillierten Analyse wurde gefolgert, dass Microsoft Azure die für unsere Organisation am besten geeignete Option ist.

## Entscheidung

Microsoft Azure als Cloud-Infrastruktur für unsere Organisation einführen.

## Begründung

Die Gründe für die Einführung von Microsoft Azure sind folgende:

1. Umfassende Dienste: Azure bietet eine vollständige Palette von Cloud-Diensten von Infrastructure as a Service (IaaS) über Software as a Service (SaaS) bis zu Platform as a Service (PaaS). So können wir Azure-Dienste nutzen, um die Anforderungen der Organisation zu lösen, etwa Speicher, Rechenleistung, Netzwerk und Analytik.

2. Skalierbarkeit und Flexibilität: Mit Azure können wir Ressourcen je nach unseren Geschäftsanforderungen einfach hoch- oder herunterskalieren. Azure bietet außerdem Flexibilität bei der Wahl von Betriebssystem, Programmiersprache und Frameworks.

3. Sicherheit und Compliance: Azure bietet ein hohes Maß an Sicherheit und Compliance, da es mehrere Branchenstandards wie ISO, SOC, HIPAA und PCI DSS erfüllt. Azure bietet außerdem erweiterte Sicherheitsfunktionen wie Netzwerksicherheitsgruppen, Firewalls und DDoS-Schutz.

4. Hybrid Cloud: Azure bietet ein nahtloses Hybrid-Cloud-Erlebnis, das Organisationen ermöglicht, ihre Vor-Ort-Infrastruktur mit Azure zu verbinden. Das erleichtert uns die Migration von Workloads in die Cloud und gibt uns die Flexibilität, zu wählen, wo Daten gespeichert werden.

5. Kosteneffizient: Azure bietet ein Pay-as-you-go-Preismodell, was bedeutet, dass wir nur für die genutzten Ressourcen zahlen. Das hilft uns, im Vergleich zu traditioneller Vor-Ort-Infrastruktur Kosten zu sparen.

## Fazit

Die Einführung von Microsoft Azure als Cloud-Infrastruktur für unsere Organisation entspricht unseren Geschäftsanforderungen und bietet mehrere Vorteile wie Skalierbarkeit, Flexibilität, Sicherheit und Kosteneffizienz. Daher wird empfohlen, Azure als unsere Cloud-Infrastruktur einzuführen.
