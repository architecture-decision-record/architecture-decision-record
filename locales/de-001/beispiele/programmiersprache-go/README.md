# Architecture Decision Record: Programmiersprache Go

Titel: Einführung der Programmiersprache Go

Status: Angenommen

## Kontext

Unsere Organisation hat für den Aufbau von Webanwendungen hauptsächlich die Programmiersprache Java verwendet. Wir haben jedoch aufgrund der Wortreichheit von Java und der Komplexität einiger Frameworks einige Herausforderungen erlebt. Außerdem hat unser Team Interesse gezeigt, moderne Programmiersprachen für eine effizientere und robustere Entwicklung zu erkunden. Nach einer Recherche haben wir Go als mögliche Lösung für die Probleme identifiziert, denen wir mit Java begegnen.

## Entscheidung

Wir werden künftig die Programmiersprache Go für den Aufbau von Webanwendungen einführen.

## Begründung

1. **Einfachheit und Lesbarkeit:** Go ist für seine Einfachheit und prägnante Syntax bekannt. Das macht den Code leicht les- und schreibbar und verringert die Komplexität unseres Entwicklungsprozesses.

2. **Hohe Leistung und Skalierbarkeit:** Go wird in Maschinencode kompiliert, der nativ auf dem Server läuft. Das führt zu schnelleren Ausführungszeiten und besserer Leistung im Vergleich zu interpretierten Sprachen wie Java. Außerdem bearbeitet das Nebenläufigkeitsmodell von Go mehrere Anfragen gleichzeitig, was es hoch skalierbar macht.

3. **Starke Community-Unterstützung:** Go hat eine lebendige Entwickler-Community, die im Lauf der Jahre zu seinem Wachstum beigetragen hat. Das bedeutet, dass es viele Ressourcen, Bibliotheken und Frameworks gibt, die uns beim Einstieg und beim Aufbau robuster Anwendungen helfen.

4. **Flexibilität:** Go kann sowohl für die Frontend- als auch für die Backend-Entwicklung verwendet werden. Das heißt, wir können seine Vorteile in beiden Bereichen für unsere Entwicklungsprojekte nutzen.

## Implikationen

1. **Schulung:** Unsere Entwickler müssen geschult werden, um die Programmiersprache Go und ihre Feinheiten zu lernen.

2. **Erfahrung:**  Beim Übergang von Java zu Go können einige Herausforderungen auftreten. Es kann einige Zeit dauern, bis unsere Entwickler die neue Sprache beherrschen.

3. **Werkzeuge:**  Wir müssen neue Werkzeuge und Frameworks einführen, die spezifisch für Go sind. Wir können jedoch vorhandene Infrastruktur nutzen, um die Auswirkungen dieser Änderung zu minimieren.

4. **Herstellerabhängigkeit:**  Go ist eine Open-Source-Programmiersprache, und wir werden nicht an einen Hersteller oder Dienstleister gebunden sein.

## Fazit

Die Einführung der Programmiersprache Go wird uns helfen, unseren Entwicklungsprozess zu verbessern und robuste Anwendungen zu bauen. Wir müssen Ressourcen in Schulung und Werkzeuge investieren, um diesen Übergang zu unterstützen, glauben aber, dass die Vorteile dieser Entscheidung die Kosten überwiegen.
