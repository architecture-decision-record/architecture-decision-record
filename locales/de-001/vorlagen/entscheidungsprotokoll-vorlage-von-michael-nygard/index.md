# Entscheidungsprotokoll-Vorlage von Michael Nygard

Dies ist die Vorlage aus [Documenting architecture decisions - Michael Nygard](http://thinkrelevance.com/blog/2011/11/15/documenting-architecture-decisions).
Sie können [adr-tools](https://github.com/npryce/adr-tools) zur Verwaltung der ADR-Dateien verwenden.

Schreiben Sie in jede ADR-Datei diese Abschnitte:

# Titel

## Status

Wie lautet der Status, etwa proposed, accepted, rejected, deprecated, superseded usw.?

## Kontext

Welches Problem sehen wir, das diese Entscheidung oder Änderung motiviert?

## Entscheidung

Welche Änderung schlagen wir vor und/oder nehmen wir vor?

## Konsequenzen

Was wird aufgrund dieser Änderung einfacher oder schwieriger?
