# 架构决策记录：Tailwind CSS

决策：用 Tailwind CSS 作为 CSS 框架，来给用户界面设置样式。

## 啥是 Tailwind CSS？

Tailwind 是一个工具优先个 CSS 框架，可以快速开发搭定制用户界面。伊设计成高度可定制，让开发者可以写更加精简、更加高效个 CSS。迭个框架提供一套预定义个类，可以非常快地给 UI 设置样式。

## 背景

阿拉辣为一个客户构建 Web 应用，需要响应式、可定制个用户界面。客户要求统一又现代个样式。开发团队有用自定义 CSS 个经验，勿过想探索可以节省辰光搭精力个 CSS 框架。阿拉辣找一个容易用、可定制、而且有庞大社区提供支持个框架。

## 决策驱动因素

- **容易用：**阿拉想要一个容易学、可以集成到阿拉开发工作流里个框架。

- **可定制：**阿拉想要一个可以按客户个品牌规范搭主题来定制个框架。

- **庞大个社区支持：**阿拉想要一个有活跃个开发者搭设计师社区、需要个辰光可以提供帮助搭资源个框架。

- **节省辰光：**阿拉想要一个可以节省 UI 样式设置辰光搭精力个框架。

## 考虑过个选项

- **Bootstrap：**一个流行个 CSS 框架，有许多预构建个组件，有庞大个开发者社区。

- **Foundation：**另外一个流行个 CSS 框架，为移动优先个开发而设计。

- **Materialize：**基于 Google Material Design 语言个 CSS 框架，有用于 UI 开发个预构建组件。

- **Tailwind CSS：**一个工具优先个 CSS 框架，重点是定制搭效率。

## 决策结果

考虑了这些选项之后，阿拉决定用 Tailwind CSS，理由如下：

- **容易用：**Tailwind 个办法简单、容易懂。伊个工具类让构建 UI 更加快。

- **可定制：**Tailwind 提供一套配置文件，让开发者可以容易地修改框架个默认样式，所以允许定制。

- **庞大个社区支持：**Tailwind 有非常活跃个开发者搭设计师社区，一直辣创造新个资源、插件搭工具。

- **节省辰光：**Tailwind 可以节省辰光，让开发者可以专注辣项目个其他方面。

阿拉会用 Tailwind CSS 个工具类来构建项目个 UI。开发团队会用伊原子化、模块化个设计系统，写高效、可扩展个 CSS 代码。阿拉会利用 Tailwind 预构建个模板搭视觉组件来加快开发过程，同时用自定义样式来匹配客户个品牌搭主题。
