# Google Cloud Platform 个架构决策记录

## 背景

Google Cloud Platform（GCP）是一个著名个云计算平台，提供各种云服务，包括计算、存储搭网络方案。迭份 ADR 个目的，是记录为阿拉组织开发搭实施基于 GCP 个基础设施所做个架构决策。

## 决策

阿拉个组织决定用 Google Cloud Platform 作为阿拉应用个云基础设施。迭个决策个主要考虑是：

   - 成本效益

   - 可扩展性

   - 可靠性

   - 灵活性

## 选型

选了 GCP 里向下底几个服务来满足阿拉个需求：

   - Compute Engine，用于虚拟机搭计算资源

   - Cloud Storage，用于对象存储搭文件托管

   - Cloud SQL，用于托管数据库服务

   - Firebase，用于应用开发搭托管

## 理据

   - 成本效益：搭其他云平台比起来，Google Cloud Platform 成本效益很高，对预算有限个组织来讲是个有吸引力个选项。

   - 可扩展性：GCP 容易扩展个基础设施，让阿拉可以实时处理任何数量个流量。

   - 可靠性：GCP 个托管服务提供高可靠性，有自动备份搭灾难恢复能力，确保资源搭数据个高可用性。

   - 灵活性：平台辣 AI、数据分析搭物联网等勿同领域提供各种工具搭服务，所以用途很广。

## 后果

迁移到 Google Cloud Platform 需要培训阿拉个团队使用 GCP 服务，重新设计应用架构使伊兼容所选个服务，还要更新基础设施代码来支持 GCP 服务。勿过，预计迁移完成之后，阿拉会有一个高度可扩展、可靠又成本划算个基础设施来托管阿拉个应用。另外，阿拉还需要管理辣 GCP 上配置资源个持续成本。

## 结论

Google Cloud Platform 因为成本效益、可扩展性、可靠性搭灵活性，是阿拉云基础设施个出色选择。通过使用所选个服务，阿拉可以为阿拉个应用提供高可用、稳固个基础设施。
