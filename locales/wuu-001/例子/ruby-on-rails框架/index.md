- Ruby on Rails 是一个成熟、稳定、被广泛采用个 Web 框架，辣构建复杂 Web 应用方面已经证明了自家个有效性。

- 框架有庞大又活跃个社区，有许多可复用个模块搭插件，可以增强功能，解决常见问题。

- Ruby on Rails 支持测试驱动开发（TDD）搭行为驱动开发（BDD），让开发者可以给自家个代码写自动化测试，确保代码按预期工作，减少缺陷搭回归。
