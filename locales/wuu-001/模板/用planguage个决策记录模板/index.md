# 用 Planguage 个决策记录模板

参见 https://www.iaria.org/conferences2012/filesICCGI12/Tutorial%20Specifying%20Effective%20Non-func.pdf

## 啥是 Planguage？

Planguage 是一种计划语言，用下底迭眼关键字：

* Tag（标签）：唯一、持久个标识符
* Gist（要点）：需求或者所涉领域个简短摘要
* Requirement（需求）：详细讲明需求本身个文字
* Rationale（理据）：证明需求合理个推理
* Priority（优先级）：优先级搭对资源个主张个陈述
* Stakeholders（利益相关者）：实质上受需求影响个各方
* Status（状态）：需求个状态（草稿、已评审、已承诺等等）
* Owner（所有者）：负责实施需求个人
* Author（作者）：写需求个人
* Revision（修订）：陈述个版本号
* Date（日期）：最近一次修订个日期
* Assumptions（假设）：现在或者以后假使勿成立会引起问题个任何事体
* Risks（风险）：可能引起故障、延误或者其他负面影响个任何事体
* Defined（定义）：一个术语个定义（最好用术语表）
