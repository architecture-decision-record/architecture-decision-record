# 亚历山大模式个决策记录模板

## 简介

* 序言（摘要）
* 讨论（背景）
* 解决方案（决策）
* 后果（结果）

## 具体内容 ##

* 序言（摘要）
  * 用来概括个陈述：
    * 辣（用例）个背景下<br>
      面对（顾虑）<br>
      阿拉决定选（选项）<br>
      来达到（质量）<br>
      接受（缺点）。
* 讨论（背景）
  * 讲明在起作用个各种力量（技术、政治、社会、项目）。
  * 迭是一个故事，讲明阿拉想解决个问题。
* 解决方案
  * 讲明决策哪能解决问题。
* 后果
  * 讲明决策长期个结果。
  * 有用呢，呒没用呢，有勿有被更改、升级等等。
