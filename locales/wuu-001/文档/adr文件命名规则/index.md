# ADR 个文件命名规则

要是侬选用普通文本文件来写 ADR，可能想定一套自家个 ADR 文件命名规则。

阿拉欢喜用格式固定个文件命名规则。

例子：

  * choose-database.md

  * format-timestamps.md

  * manage-passwords.md

  * handle-exceptions.md

阿拉个文件命名规则：

  * 名字用一个现在时个祈使动词短语。迭能容易读，也搭阿拉个提交信息格式一致。

  * 名字用小写字母搭连字符（搭迭个仓库一样）。迭是可读性搭系统好用性之间个平衡。

  * 扩展名是 markdown。迭能便于排版。
