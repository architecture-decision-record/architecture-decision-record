# Modelo de registro de decisão para padrão Alexandrino

## Introdução

* Prólogo (Resumo)
* Discussão (Contexto)
* Solução (Decisão)
* Consequências (Resultados)

## Detalhes ##

* Prólogo (Resumo)
  * Declaração para resumir:
    * No contexto de (caso de uso)<br>
      diante de (preocupação)<br>
      decidimos por (opção)<br>
      para alcançar (qualidade)<br>
      aceitando (desvantagem).
* Discussão (Contexto)
  * Explica as forças em jogo (técnicas, políticas, sociais, de projeto).
  * Esta é a história que explica o problema que estamos tentando resolver.
* Solução
  * Explica como a decisão resolverá o problema.
* Consequências
  * Explica os resultados da decisão no longo prazo.
  * Funcionou, não funcionou, foi alterada, atualizada etc.
