# Registro de Decisão de Arquitetura: infraestrutura de cloud Microsoft Azure"

Título da decisão: Adoção do Microsoft Azure como a infraestrutura de cloud para nossa organização

Decisor: Chief Information Officer

Data: 2021-10-15

Status: Aprovado

## Contexto

A organização está planejando migrar de infraestrutura tradicional on-premises para infraestrutura de cloud. Para alcançar isso, a organização avaliou múltiplos provedores de serviços de cloud, como Amazon Web Services (AWS), Google Cloud Platform (GCP), Microsoft Azure e IBM Cloud. Cada provedor tem seu próprio conjunto de recursos, benefícios e estrutura de preços. Depois de uma análise detalhada, concluiu-se que Microsoft Azure é a opção mais adequada para nossa organização.

## Decisão

Adotar Microsoft Azure como a infraestrutura de cloud para nossa organização.

## Justificativa

As seguintes razões justificam a adoção do Microsoft Azure:

1. Serviços abrangentes: Azure fornece uma gama completa de serviços de cloud, de infrastructure as a service (IaaS) a software as a service (SaaS) e platform as a service (PaaS). Isso nos permite aproveitar serviços Azure para resolver os requisitos da organização, como armazenamento, computação, rede e analytics.

2. Escalabilidade e flexibilidade: Com Azure, podemos facilmente escalar recursos para cima ou para baixo com base em nossos requisitos de negócio. Azure também oferece flexibilidade na escolha do sistema operacional, linguagem de programação e frameworks.

3. Segurança e conformidade: Azure oferece um alto nível de segurança e conformidade, pois está em conformidade com vários padrões da indústria, como ISO, SOC, HIPAA e PCI DSS. Azure também fornece recursos avançados de segurança, como network security groups, firewalls e proteção contra DDoS.

4. Hybrid Cloud: Azure fornece uma experiência de hybrid cloud perfeita, permitindo que organizações conectem sua infraestrutura on-premises ao Azure. Isso facilita para nós migrar workloads para a cloud e nos fornece flexibilidade para escolher onde armazenar dados.

5. Custo-efetivo: Azure oferece um modelo de preços pay-as-you-go, o que significa que pagamos apenas pelos recursos usados. Isso nos ajuda a economizar custos em comparação com infraestrutura tradicional on-premises.

## Conclusão

Adotar Microsoft Azure como a infraestrutura de cloud para nossa organização se alinha aos nossos requisitos de negócio e oferece vários benefícios, como escalabilidade, flexibilidade, segurança e custo-benefício. Portanto, recomenda-se adotar Azure como nossa infraestrutura de cloud.
