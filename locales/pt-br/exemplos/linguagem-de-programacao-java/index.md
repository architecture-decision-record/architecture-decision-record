# Registro de Decisão de Arquitetura: linguagem de programação Java

Título: Escolha da linguagem de programação Java para o projeto

Decisão: Depois de avaliar múltiplas linguagens de programação, decidimos usar Java para nosso projeto.

### Contexto

Pretendíamos construir uma aplicação baseada na web que pudesse executar em múltiplos sistemas operacionais. Nosso projeto exigia uma linguagem que pudesse fornecer recursos fortes de segurança, lidar com concorrência, suportar bases de código grandes e ser versátil o suficiente para atender aos nossos requisitos de crescimento futuro. Avaliamos várias linguagens, considerando seus pontos fortes e limitações, antes de decidir por Java.

### Considerações

1. **Segurança:**  Java fornece excelentes recursos de segurança por meio de suas políticas de segurança e controle de acesso bem definidos. Ela também incorpora recursos como verificação de bytecode, que ajuda a impedir que software malicioso execute em um sistema.

2. **Concorrência:**  Java tem suporte integrado a multithreading, o que permite que aplicações executem várias tarefas simultaneamente. Esse recurso torna Java uma excelente escolha para desenvolver aplicações grandes e complexas com múltiplas funcionalidades.

3. **Bases de código grandes:**  Java suporta programação orientada a objetos, o que a torna uma escolha adequada para desenvolver bases de código grandes. Sua natureza modular e o uso de padrões de encapsulamento e abstração acrescentam ainda mais facilidade ao processo de desenvolvimento de software.

4. **Versatilidade:**  Java é versátil e fornece a capacidade de usar uma ampla gama de bibliotecas e frameworks, tornando-a uma excelente escolha tanto para aplicações baseadas na web quanto para aplicações de nível corporativo.

### Resultado da decisão

Decidimos usar a linguagem de programação Java para nosso projeto, considerando seus recursos de segurança, suporte a concorrência, capacidade de lidar com bases de código grandes e versatilidade. Esta decisão se alinha aos requisitos do nosso projeto, e acreditamos que escolher Java garantirá seu sucesso.

### Consequências

1. Precisaremos de desenvolvedores que tenham experiência com Java e possam usá-la com proficiência.

2. Qualquer código escrito na linguagem deve ser compatível com a Java Virtual Machine (JVM).

3. Incorporar novas funcionalidades, capacidades ou frameworks pode apresentar alguns desafios.

4. Projetos grandes e complexos em Java podem exigir mais tempo e recursos para desenvolver.
