# Registro de Decisão de Arquitetura: linguagem de programação Go

Título: Adoção da linguagem de programação Go

Status: Aceito

## Contexto

Nossa organização vem usando principalmente a linguagem de programação Java para construir aplicações web. No entanto, temos enfrentado alguns desafios devido à verbosidade do Java e à complexidade de alguns frameworks. Além disso, nossa equipe demonstrou interesse em explorar linguagens de programação modernas para um desenvolvimento mais eficiente e robusto. Depois de conduzir uma pesquisa, identificamos Go como uma solução potencial para os problemas que enfrentamos com Java.

## Decisão

Adotaremos a linguagem de programação Go para construir aplicações web daqui em diante.

## Justificativa

1. **Simplicidade e legibilidade:** Go é conhecida por sua simplicidade e sintaxe concisa. Isso facilita ler e escrever código, reduzindo a complexidade do nosso processo de desenvolvimento.

2. **Alta performance e escalabilidade:** Go é compilada para código de máquina que executa nativamente no servidor. Isso resulta em tempos de execução mais rápidos e melhor performance em comparação com linguagens interpretadas como Java. Além disso, o modelo de concorrência de Go lida com múltiplas requisições simultaneamente, tornando-a altamente escalável.

3. **Forte suporte da comunidade:** Go tem uma comunidade vibrante de desenvolvedores que contribuíram para seu crescimento ao longo dos anos. Isso significa que há muitos recursos, bibliotecas e frameworks para nos ajudar a começar e construir aplicações robustas.

4. **Flexibilidade:** Go pode ser usada tanto para desenvolvimento frontend quanto backend. Isso significa que podemos aproveitar suas vantagens em ambas as áreas para nossos projetos de desenvolvimento.

## Implicações

1. **Treinamento:** Nossos desenvolvedores precisarão passar por treinamento para aprender a linguagem de programação Go e suas nuances.

2. **Experiência:**  Podemos enfrentar alguns desafios ao fazer a transição de Java para Go. Pode levar algum tempo para nossos desenvolvedores se tornarem proficientes na nova linguagem.

3. **Ferramental:**  Precisaremos adotar novas ferramentas e frameworks que sejam específicos de Go. No entanto, podemos aproveitar a infraestrutura existente que temos em vigor para minimizar o impacto dessa mudança.

4. **Vendor lock-in:**  Go é uma linguagem de programação open-source, e não ficaremos presos a nenhum fornecedor ou provedor de serviços.

## Conclusão

A adoção da linguagem de programação Go nos ajudará a melhorar nosso processo de desenvolvimento e construir aplicações robustas. Precisaremos investir recursos em treinamento e ferramentas para apoiar essa transição, mas acreditamos que os benefícios desta decisão superam os custos.
