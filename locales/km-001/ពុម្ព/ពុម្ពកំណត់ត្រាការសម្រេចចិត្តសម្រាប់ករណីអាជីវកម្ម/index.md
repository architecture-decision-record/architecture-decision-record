# ពុម្ពកំណត់ត្រាការសម្រេចចិត្តសម្រាប់ករណីអាជីវកម្ម

ពុម្ព ADR នេះសង្កត់ធ្ងន់លើការបង្កើតករណីអាជីវកម្មសម្រាប់ការសម្រេចចិត្តមួយ រួមទាំងលក្ខណៈវិនិច្ឆ័យ បេក្ខភាព និងថ្លៃដើម។


## កម្រិតកំពូល

* ចំណងជើង
* ស្ថានភាព
* លក្ខណៈវិនិច្ឆ័យវាយតម្លៃ
* បេក្ខភាពដែលត្រូវពិចារណា
* ការស្រាវជ្រាវ និងការវិភាគបេក្ខភាពនីមួយៗ
  * បំពេញ/មិនបំពេញលក្ខណៈវិនិច្ឆ័យ និងមូលហេតុ
  * ការវិភាគថ្លៃដើម
  * ការវិភាគ SWOT
  * ការយល់ឃើញ និងមតិកែលម្អ
* អនុសាសន៍


## ការស្វែងយល់ជ្រៅកម្រិតទាប

**ចំណងជើង**៖

  * ឃ្លាបញ្ជាកាលបច្ចុប្បន្នខ្លី តិចជាង 50 តួអក្សរ ដូចសារ git commit។

**ស្ថានភាព**៖

  * មួយក្នុងចំណោម បានស្នើ បានទទួលយក បានបដិសេធ លែងប្រើ ត្រូវបានជំនួស ។ល។

**លក្ខណៈវិនិច្ឆ័យវាយតម្លៃ**៖

  * សេចក្តីសង្ខេប៖ ពន្យល់ដោយសង្ខេបអំពីអ្វីដែលយើងចង់ស្វែងរក និងមូលហេតុ។

  * ព័ត៌មានលម្អិត

**បេក្ខភាពដែលត្រូវពិចារណា**៖

  * សេចក្តីសង្ខេប៖ ពន្យល់ដោយសង្ខេបអំពីរបៀបដែលយើងរកឃើញបេក្ខភាព ហើយបង្វែរចំណាប់អារម្មណ៍ទៅករណីលើកលែងណាមួយ។

  * រាយបេក្ខភាព និងជម្រើសពាក់ព័ន្ធទាំងអស់ តើយើងកំពុងវាយតម្លៃអ្វីជាដំណោះស្រាយដែលអាចមាន?

  * ព័ត៌មានលម្អិត

**ការស្រាវជ្រាវ និងការវិភាគបេក្ខភាពនីមួយៗ**៖

  * សេចក្តីសង្ខេប៖ ពន្យល់ដោយសង្ខេបអំពីវិធីសាស្ត្រស្រាវជ្រាវ ហើយបង្វែរចំណាប់អារម្មណ៍ទៅគំរូ ក្រុម និងករណីលើកលែង។

  * បំពេញ/មិនបំពេញលក្ខណៈវិនិច្ឆ័យ និងមូលហេតុ

    * សេចក្តីសង្ខេប

    * ព័ត៌មានលម្អិត

  * ការវិភាគថ្លៃដើម

    * សេចក្តីសង្ខេប

    * ឧទាហរណ៍

      * អាជ្ញាប័ណ្ណ ដូចជាកិច្ចព្រមព្រៀងកិច្ចសន្យា និងកាតព្វកិច្ចផ្លូវច្បាប់

      * ការបណ្តុះបណ្តាល ដូចជាការបង្កើនជំនាញ និងការគ្រប់គ្រងការផ្លាស់ប្តូរ

      * ប្រតិបត្តិការ ដូចជាការគាំទ្រ និងការថែទាំ

      * ការវាស់ស្ទង់ ដូចជាកម្រិតបញ្ជូន និងការប្រើ CPU

  * ការវិភាគ SWOT

    * សេចក្តីសង្ខេប

    * ចំណុចខ្លាំង

    * ចំណុចខ្សោយ

    * ឱកាស

    * ការគំរាមកំហែង

  * ការយល់ឃើញ និងមតិកែលម្អផ្ទៃក្នុង

    * សេចក្តីសង្ខេប

    * ឧទាហរណ៍

      * ដោយក្រុម ជាការល្អសរសេរដោយបុគ្គលពិតប្រាកដ

      * ពីភាគីពាក់ព័ន្ធផ្សេងទៀត

      * គុណលក្ខណៈគុណភាព ឬហៅថា តម្រូវការឆ្លងមុខងារ 

  * ការយល់ឃើញ និងមតិកែលម្អខាងក្រៅ

    * សេចក្តីសង្ខេប

    * តើអ្នកណាជាអ្នកផ្តល់ការយល់ឃើញ?

    * តើបេក្ខភាពផ្សេងទៀតដែលអ្នកបានពិចារណាមានអ្វីខ្លះ?

    * តើអ្នកកំពុងបង្កើតអ្វី? 

      * ឧទាហរណ៍

        * B2B ឬ B2C

        * បែរទៅខាងក្រៅ ឬសម្រាប់តែនិយោជិត

        * កុំព្យូទ័រ ឬទូរស័ព្ទ

        * សាកល្បង ឬផលិតកម្ម

        * monolith ឬ microservices

    * តើអ្នកវាយតម្លៃបេក្ខភាពដោយរបៀបណា?

    * ហេតុអ្វីអ្នកជ្រើសអ្នកឈ្នះ?

    * តើមានអ្វីកំពុងកើតឡើងចាប់តាំងពីពេលនោះ?

      * ឧទាហរណ៍

        * តើអ្នកឈ្នះដំណើរការយ៉ាងដូចម្តេច?

        * តើចរាចរអ្នកប្រើផ្ទាល់ក្នុងផលិតកម្មប៉ុន្មានភាគរយកំពុងហូរកាត់អ្នកឈ្នះ?

        * តើមានការរួមបញ្ចូលប្រភេទអ្វីខ្លះ ដូចជាជាមួយបំពង់ដឹកជញ្ជូនជាបន្តបន្ទាប់ ប្រព័ន្ធគ្រប់គ្រងមាតិកា ការវិភាគ និងរង្វាស់ ។ល។?

        * ដោយដឹងអ្វីដែលអ្នកដឹងឥឡូវនេះ តើអ្នកនឹងណែនាំមនុស្សឱ្យធ្វើអ្វីខុសគ្នា?

  * រឿងរ៉ាវ

**អនុសាសន៍**៖

  * សេចក្តីសង្ខេប
