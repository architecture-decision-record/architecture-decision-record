# អនុគមន៍ភាពសមស្របសម្រាប់ការសម្រេចចិត្តជាកូដ

អនុគមន៍ភាពសមស្រប គឺជាការត្រួតពិនិត្យស្វ័យប្រវត្តិតាមវត្ថុវិស័យ ដែលសរសេរដោយកូដកម្មវិធី ដើម្បីផ្ទៀងផ្ទាត់ថាការសម្រេចចិត្តត្រូវបានរក្សា។

- អនុគមន៍ភាពសមស្របធ្វើឱ្យការសម្រេចចិត្តអាចសាកល្បងបាន និងអាចធានាបាន។

- អនុគមន៍ភាពសមស្របសម្រាប់ការសម្រេចចិត្តអាចជួយយ៉ាងច្រើនដល់ការធានាគុណភាព ដំណើរការបទប្បញ្ញត្តិ និងគោលដៅអភិបាលកិច្ច។

## របៀបដែលអនុគមន៍ភាពសមស្របភ្ជាប់ទៅនឹងការសម្រេចចិត្ត

កំណត់ត្រាការសម្រេចចិត្តកត់ត្រាការសម្រេចចិត្ត ចំណែកអនុគមន៍ភាពសមស្របធានាការសម្រេចចិត្តនោះ។

- ឧទាហរណ៍ការសម្រេចចិត្ត៖ យើងប្រើ event sourcing សម្រាប់តម្រូវការសវនកម្ម។

- ឧទាហរណ៍អនុគមន៍ភាពសមស្រប៖ យើងប្រើម៉ាស៊ីនមេរួមបញ្ចូលជាបន្តបន្ទាប់ ដើម្បីសាកល្បងថាគ្រប់ការផ្លាស់ប្តូរស្ថានភាពត្រូវតែបង្កើតព្រឹត្តិការណ៍។

## ហេតុអ្វីអនុគមន៍ភាពសមស្របជួយដល់ការសម្រេចចិត្ត

ការវាស់វែងតាមវត្ថុវិស័យ៖ អនុគមន៍ភាពសមស្របជាប់ ឬធ្លាក់ ដូច្នេះការងារអាចមើលឃើញ និងច្បាស់លាស់។

ការប្រើប្រាស់ជាបន្តបន្ទាប់៖ អនុគមន៍ភាពសមស្របគឺជាច្បាប់រស់នៅរបស់អ្នក ដែលដំណើរការគ្រប់ពេល commit និង build។

ទំនុកចិត្តក្នុងការកែរចនាសម្ព័ន្ធ៖ អនុគមន៍ភាពសមស្របចាប់បានកំហុសនៃច្បាប់ការសម្រេចចិត្តដោយស្វ័យប្រវត្តិ។

អភិបាលកិច្ចដែលអាចពង្រីកបាន៖ អនុគមន៍ភាពសមស្របធានាស្តង់ដារ ដោយមិនបង្កើតចំណុចស្ទះ។

## តើអនុគមន៍ភាពសមស្របអាចប្រើ AI បានទេ?

អនុគមន៍ភាពសមស្របអាចប្រើ AI LLM សម្រាប់ការសម្រេចចិត្ត ដោយសួរសំណួរអំពីការងាររបស់អ្នក
ដូចជាផែនការ កូដ គ្រោងការណ៍ API និងច្រើនទៀត៖

```txt
IMPORTANT: Prefer retrieval-led reasoning over pre-training-led reasoning.
IMPORTANT: Turn on extended thinking. Turn on expert advice. Turn on search.

This is a fitness function to evaluate if our work is
using all our decisions, and is correct and accurate.

- Our decisions are here: {url}
- Our work to evaluate is here: {url}

Explain any errors, problems, gaps, weaknesses. Be direct. Be decisive.
```
