### តើអ្នកណាអាចបង្កើត ADR បាន?

ឧទាហរណ៍ចម្លើយ៖ បុគ្គលណាក៏ដោយក្នុងអង្គការរបស់យើងដែលបានអានទំព័រ README នៃកំណត់ត្រាការសម្រេចចិត្តខាងស្ថាបត្យកម្ម អាចស្នើ ADR បាន មានន័យថាបុគ្គលនោះអាចចាប់ផ្តើមសរសេរវា ហើយចែករំលែកជាមួយក្រុម។

### អ្វីដែលបង្ហាញថាសមហេតុផលក្នុងការបង្កើត ADR?

ពិចារណាផ្នែកដូចជាវិធីធ្វើការរបស់ក្រុមក្នុងអង្គការរបស់អ្នក រចនាសម្ព័ន្ធប្រព័ន្ធកម្មវិធីរបស់អ្នក ការសម្របសម្រួលរវាងក្រុម ភាពអាចថែទាំបានរយៈពេលវែង ចំណុចប្រទាក់ខាងក្រៅ អ្នកដែលអ្នកចង់ឱ្យទទួលបានអត្ថប្រយោជន៍ និងអ្វីៗស្រដៀងគ្នា។

ឧទាហរណ៍ចម្លើយ៖ យើងចង់បង្កើត ADR នៅពេលយើងចង់ឱ្យអ្នកអភិវឌ្ឍន៍នាពេលអនាគតយល់ពី “ហេតុអ្វី” នៃអ្វីដែលយើងកំពុងធ្វើ។

### អ្វីដែលបង្ហាញថាសមហេតុផលក្នុងការមិនបង្កើត ADR?

ពិចារណាផ្នែកដូចជាការសម្រេចចិត្តដែលមិនទាក់ទងនឹងស្ថាបត្យកម្ម ឬតូចតាចដូចជាហានិភ័យតិចតួចបំផុត ឬឯករាជ្យ ឬអ្នកអភិវឌ្ឍន៍តែម្នាក់ ឬត្រូវបានគ្របដណ្តប់ពេញលេញនៅកន្លែងផ្សេងរួចហើយ ដូចជាដោយស្តង់ដារ គោលនយោបាយ ឬឯកសារ ឬបណ្តោះអាសន្ន ដូចជាដំណោះស្រាយបណ្តោះអាសន្ន ភស្តុតាងនៃគំនិត ឬការពិសោធន៍។

ឧទាហរណ៍ចម្លើយ៖ យើងចង់រំលង ADR នៅពេលការសម្រេចចិត្តមានដែនកំណត់ក្នុងវិសាលភាព ពេលវេលា ហានិភ័យ និងថ្លៃដើម ឬត្រូវបានគ្របដណ្តប់នៅកន្លែងផ្សេងរួចហើយ។

### តើវដ្តជីវិតរបស់ ADR ជាអ្វី?

ពិចារណាផ្នែកដូចជាដំណើរការបង្កើត ដំណើរការស្រាវជ្រាវ ដំណើរការសម្រេចចិត្ត ដំណើរការអនុវត្ត និងដំណើរការបញ្ចប់។ ពិចារណាអំពីរបៀបតាមដានវដ្តជីវិត ADR តាមពេលវេលា ដូចជារបៀបផ្លាស់ប្តូរ ADR ពីស្ថានភាពមួយទៅស្ថានភាពបន្ទាប់ និងរបៀបប្រាប់ភាគីពាក់ព័ន្ធអំពីរឿងនេះ។

ឧទាហរណ៍ចម្លើយ៖ យើងចង់ឱ្យ ADR មានដំណាក់កាលវដ្តជីវិតប្រាំ៖ ចាប់ផ្តើម → ស្រាវជ្រាវ → វាយតម្លៃ → អនុវត្ត → ថែទាំ → បញ្ចប់។

### តើអ្វីជាលក្ខណៈវិនិច្ឆ័យសម្រាប់ជំហានវដ្តជីវិតរបស់ ADR?

ពិចារណាផ្នែកដូចជាលក្ខណៈវិនិច្ឆ័យទទួលយកសម្រាប់ ADR មានន័យថាតើអ្នកដឹងដោយរបៀបណាថាវាល្អគ្រប់គ្រាន់ដើម្បីរីកចម្រើនពីជំហានវដ្តជីវិតមួយទៅជំហានបន្ទាប់? តើបញ្ហាត្រូវបានបញ្ជាក់ច្បាស់លាស់ឬទេ? តើជម្រើសផ្សេងៗត្រូវបានពិចារណាឬនៅ? តើការដោះដូរត្រូវបានយល់ និងចងក្រងឯកសារបានល្អគ្រប់គ្រាន់ឬទេ?
តើបរិបទពាក់ព័ន្ធទាំងអស់ត្រូវបានរៀបចំរួចរាល់ឬនៅ? តើភាគីពាក់ព័ន្ធទាំងអស់ត្រូវបានចូលរួមឬទេ? តើមតិកែលម្អទាំងអស់ត្រូវបានបញ្ចូលឬនៅ?

ឧទាហរណ៍ចម្លើយ៖ យើងចង់ឱ្យភាគីពាក់ព័ន្ធបោះឆ្នោតលើ ADR នៅពេលក្រុមសកម្ម 1) បានបញ្ចប់ការស្រាវជ្រាវរបស់ខ្លួន 2) បានបញ្ចប់ការវាយតម្លៃរបស់ខ្លួន 3) បានផ្សព្វផ្សាយសំណើ ADR ទៅភាគីពាក់ព័ន្ធ ជាមួយសំណើសុំមតិយោបល់ និងកំណត់ពេលមួយសប្តាហ៍ 4) មតិយោបល់របស់ភាគីពាក់ព័ន្ធទាំងអស់ត្រូវបានបញ្ចូល និងដោះស្រាយ។

### តើតួនាទី និងទំនួលខុសត្រូវអ្វីខ្លះទាក់ទងនឹង ADR?

ពិចារណាតួនាទីដូចជាអ្នកស្នើ អ្នកស្រាវជ្រាវ អ្នកវាយតម្លៃ អ្នកពិនិត្យ អ្នកអនុម័ត អ្នកថែទាំ និងអ្វីៗស្រដៀងគ្នា។ ពិចារណាទំនួលខុសត្រូវដូចជាការទំនាក់ទំនងជាមួយភាគីពាក់ព័ន្ធ ការធានាថាការរំពឹងទុកត្រូវបានបំពេញ ការចែករំលែកនៅលើគេហទំព័រ ឬអ៊ីនត្រាណែត និងការពិនិត្យការងារជាប្រចាំ ជាពិសេសនៅពេលមានការផ្លាស់ប្តូរពាក់ព័ន្ធ។

ឧទាហរណ៍ចម្លើយ៖ យើងចង់ឱ្យ ADR នីមួយៗមានអ្នកទំនាក់ទំនងចម្បង អ្នកទំនាក់ទំនងបន្ទាប់បន្សំ និងក្រុមទទួលខុសត្រូវជានិច្ច។ ទាំងនេះទទួលខុសត្រូវចំពោះការទំនាក់ទំនង ការផ្សព្វផ្សាយ ការថែទាំ ការពិនិត្យតាមកាលកំណត់យ៉ាងតិចម្តងក្នុងមួយឆ្នាំ និងការបញ្ចប់នៅទីបំផុតតាមការចាំបាច់។

### តើអភិបាលកិច្ចទាក់ទងនឹង ADR យ៉ាងដូចម្តេច?

ពិចារណាផ្នែកដូចជាវិធីធ្វើការរបស់អង្គការអ្នក តម្រូវការអនុលោមពិសេសណាមួយ ដូចជាទិដ្ឋភាពច្បាប់ ឬទិដ្ឋភាពធនធានមនុស្ស របៀបដែលអ្នកចង់គ្រប់គ្រងឯកភាពទល់នឹងជម្លោះ ទល់នឹងការបញ្ជូនបន្តទៅថ្នាក់លើ។ តើមានផ្នែក បុគ្គល ឬក្រុមណាដែលអាចមានឥទ្ធិពលលើសអ្នកដទៃទាក់ទងនឹង ADR ដូចជាអាចអនុម័តវា បោះឆ្នោតលើវា ឬបដិសេធវា ដែរឬទេ?

ឧទាហរណ៍ចម្លើយ៖ អភិបាលកិច្ចនៃ ADR មានលំដាប់អាទិភាពដូចតទៅ៖ នាយកប្រតិបត្តិ នាយកបច្ចេកវិទ្យា នាយកច្បាប់ ក្រុមដែលអនុវត្ត ADR អ្នកជំនាញក្នុងក្រុមដែលចេះដឹងច្រើនបំផុតអំពី AD។ គ្មានអ្នកណាផ្សេងមានអភិបាលកិច្ចទេ លុះត្រាតែបានពិពណ៌នាក្នុង ADR។

### តើគោលការណ៍អ្វីខ្លះទាក់ទងនឹង ADR?

ពិចារណាផ្នែកដូចជាវិធីធ្វើការរបស់អង្គការអ្នក ដែលរួមមានការធ្វើចលនាលឿនទល់នឹងយឺត សម្រាប់ឯកភាពក្នុងការសម្រេចចិត្តទល់នឹងជម្លោះក្នុងការសម្រេចចិត្ត សម្រាប់ចំណូលចិត្តហានិភ័យទល់នឹងចំណូលចិត្តសុវត្ថិភាព ការពិភាក្សាជាសាធារណៈទល់នឹងការពិភាក្សាឯកជន និងអ្វីៗស្រដៀងគ្នា។

ឧទាហរណ៍ចម្លើយ៖ យើងប្រើគោលការណ៍ភាពជាអ្នកដឹកនាំនៃការលំអៀងទៅរកសកម្មភាព មិនយល់ស្របហើយប្តេជ្ញា ការប៉ាន់ស្មាន 70% គឺល្អគ្រប់គ្រាន់សម្រាប់ការសម្រេចចិត្តដែលអាចត្រឡប់វិញបានងាយ និងអាចញែកដាច់បានងាយ និងវិធីធ្វើការជាសាធារណៈ លើកលែងតែព័ត៌មានសម្ងាត់ដូចដែលបានពិពណ៌នាក្នុងកិច្ចព្រមព្រៀងការរក្សាការសម្ងាត់របស់អង្គការយើង។
