# របៀបចាប់ផ្តើមប្រើ ADR ជាមួយ git

ប្រសិនបើអ្នកចូលចិត្តប្រើប្រព័ន្ធត្រួតពិនិត្យកំណែ git នេះជារបៀបដែលយើងចូលចិត្តចាប់ផ្តើមប្រើ ADR ជាមួយ git សម្រាប់គម្រោងកម្មវិធីធម្មតាដែលមានកូដប្រភព។

បង្កើតថតមួយសម្រាប់ឯកសារ ADR៖

```sh
$ mkdir adr
```

សម្រាប់ ADR នីមួយៗ បង្កើតឯកសារអត្ថបទមួយ ដូចជា `choose-database.md`៖

```sh
$ vi choose-database.md
```

សរសេរអ្វីក៏បានដែលអ្នកចង់បានក្នុង ADR។ សូមមើលពុម្ពនៅក្នុង repository នេះសម្រាប់គំនិត។

Commit ADR ទៅក្នុង git repo របស់អ្នក។
