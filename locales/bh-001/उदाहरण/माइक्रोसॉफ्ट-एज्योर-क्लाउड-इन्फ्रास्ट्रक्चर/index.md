# आर्किटेक्चर फैसला रिकॉर्ड: Microsoft Azure क्लाउड इन्फ्रास्ट्रक्चर" 

फैसला के शीर्षक: अपना संगठन खातिर क्लाउड इन्फ्रास्ट्रक्चर के रूप में Microsoft Azure अपनावल

फैसला लेवे वाला: मुख्य सूचना अधिकारी

तारीख: 2021-10-15

स्थिति: मंजूर

## पृष्ठभूमि

संगठन पारंपरिक ऑन-प्रिमाइसेस इन्फ्रास्ट्रक्चर से क्लाउड इन्फ्रास्ट्रक्चर में माइग्रेट करे के योजना बना रहल बा। एकरा के पावे खातिर, संगठन कई क्लाउड सेवा प्रदाता, जइसे Amazon Web Services (AWS), Google Cloud Platform (GCP), Microsoft Azure, आ IBM Cloud, के मूल्यांकन कइले बा। हर प्रदाता के आपन फीचर, फायदा, आ कीमत ढाँचा बा। विस्तृत विश्लेषण के बाद, ई निष्कर्ष निकलल कि हमनी के संगठन खातिर Microsoft Azure सबसे उपयुक्त विकल्प ह।

## फैसला

अपना संगठन खातिर क्लाउड इन्फ्रास्ट्रक्चर के रूप में Microsoft Azure अपनावल।

## तर्क

Microsoft Azure अपनावे के कारन ई बा:

1. व्यापक सेवा: Azure infrastructure as a service (IaaS) से लेके software as a service (SaaS) आ platform as a service (PaaS) तक क्लाउड सेवा के पूरा रेंज देला। एकरा से हमनी संगठन के जरूरत, जइसे भंडारण, कंप्यूट, नेटवर्किंग, आ विश्लेषण, हल करे खातिर Azure सेवा के फायदा उठा सकीले।

2. पैमाना बढ़ावे के क्षमता आ लचीलापन: Azure से, हमनी कारोबारी जरूरत के आधार पर संसाधन आसानी से बढ़ा चाहे घटा सकीले। Azure ऑपरेटिंग सिस्टम, प्रोग्रामिंग भाषा, आ फ्रेमवर्क चुने में भी लचीलापन देला।

3. सुरक्षा आ अनुपालन: Azure ऊँच स्तर के सुरक्षा आ अनुपालन देला, काहेकि ई ISO, SOC, HIPAA, आ PCI DSS जइसन कई उद्योग मानक के पालन करेला। Azure नेटवर्क सुरक्षा समूह, फायरवॉल, आ DDoS सुरक्षा जइसन उन्नत सुरक्षा फीचर भी देला।

4. हाइब्रिड क्लाउड: Azure एगो निर्बाध हाइब्रिड क्लाउड अनुभव देला, जे संगठन के अपना ऑन-प्रिमाइसेस इन्फ्रास्ट्रक्चर के Azure से जोड़े देला। एकरा से हमनी के कार्यभार क्लाउड में माइग्रेट करल आसान हो जाला आ डेटा कहाँ राखल जाए ई चुने के लचीलापन मिलेला।

5. किफायती: Azure इस्तेमाल के हिसाब से भुगतान वाला कीमत मॉडल देला, मतलब हमनी बस ओही संसाधन के पइसा देबे जे इस्तेमाल कइनी। एकरा से पारंपरिक ऑन-प्रिमाइसेस इन्फ्रास्ट्रक्चर के मुकाबले लागत बचावे में मदद मिलेला।

## निष्कर्ष

अपना संगठन खातिर क्लाउड इन्फ्रास्ट्रक्चर के रूप में Microsoft Azure अपनावल हमनी के कारोबारी जरूरत से मेल खाला आ पैमाना बढ़ावे के क्षमता, लचीलापन, सुरक्षा, आ किफायतीपन जइसन कई फायदा देला। एहसे, Azure के अपना क्लाउड इन्फ्रास्ट्रक्चर के रूप में अपनावे के सिफारिश कइल जाला।
