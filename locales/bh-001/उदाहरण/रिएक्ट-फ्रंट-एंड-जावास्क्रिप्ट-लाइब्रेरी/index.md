# आर्किटेक्चर फैसला रिकॉर्ड: रिएक्ट फ्रंट-एंड JavaScript लाइब्रेरी

## संदर्भ

हमनी के अपना एप्लिकेशन खातिर एगो फ्रंट-एंड JavaScript लाइब्रेरी चुने के पड़ी ताकि प्रतिक्रियाशील आ इंटरैक्टिव उपयोगकर्ता इंटरफेस विकसित कइल जा सके।
  
## विचार कइल गइल विकल्प

1. React
  
2. Vue

3. Svelte
   
## फैसला

हमनी React के अपना फ्रंट-एंड JavaScript लाइब्रेरी के रूप में इस्तेमाल करब।
  
## तर्क

1. **घटक-आधारित आर्किटेक्चर:**  React एगो घटक-आधारित आर्किटेक्चर देला जे हमनी के UI के छोट फेर-इस्तेमाल-योग्य घटक में तोड़े देला। एकरा से हमनी के कोड के मॉड्यूलरता सुधरेला आ एप्लिकेशन के संभाले, पैमाना बढ़ावे, आ अपडेट करे के आसान हो जाला।
  
2. **घोषणात्मक प्रोग्रामिंग:**  React प्रोग्रामिंग के घोषणात्मक शैली इस्तेमाल करेला जे हमनी के कोड के जादा सहज आ पढ़े में आसान बनावेला। ई एगो वर्चुअल DOM भी देला, जे हमनी के कोड के जादा तेज आ कुशलता से चले देला।
  
3. **बड़ समुदाय:**  React लग बड़ आ सक्रिय समुदाय बा, आ ई सबसे लोकप्रिय फ्रंट-एंड लाइब्रेरी में से एक ह। एकर मतलब ई ह कि हमनी के एप्लिकेशन जादा तेज आ कुशलता से विकसित करे में मदद कर सके वाला ढेर संसाधन, औजार, आ लाइब्रेरी उपलब्ध बा।
  
4. **बेहतर प्रदर्शन:**  React एक-तरफा डेटा प्रवाह इस्तेमाल करेला, जे एप्लिकेशन तर्क के सरल बनावे में मदद करेला आ एकरा के जादा कुशल बनावेला। ई सर्वर-साइड रेंडरिंग भी देला, जे हमनी के एप्लिकेशन के प्रदर्शन आ SEO सुधारे में मदद करेला।
  
5. **लचीलापन:**  React के आउर लाइब्रेरी आ फ्रेमवर्क के साथ इस्तेमाल कइल जा सकेला, जे हमनी के अपना परियोजना के जरूरत के हिसाब से सबसे नीमन तकनीकी स्टैक चुने के आजादी देला।
  
## नतीजा

1. **सीखे के कठिनाई:**  React लग सीखे के कठिनाई बा, आ जे डेवलपर React में नया बाड़ें उनके रफ्तार पकड़े में कुछ समय लग सकेला।
  
2. **बिल्ड औजार:**  React के Babel आ Webpack जइसन अतिरिक्त बिल्ड औजार चाहीं, जे विकास प्रक्रिया में जटिलता जोड़ सकेला।
  
3. **ब्राउजर संगतता:**  React के पुरान ब्राउजर संगे संगतता के समस्या बा काहेकि ई ES6 फीचर इस्तेमाल करेला जे पुरान ब्राउजर में समर्थित नइखे।
  
 4. खड़ा सीखे के कठिनाई: जे डेवलपर React से परिचित नइखे उनके एकरा के कुशलता से इस्तेमाल करे के सीखे में समय लग सकेला, जे धीमा विकास समय तक ले जा सकेला।

## निष्कर्ष

हमनी अपना एप्लिकेशन के फ्रंट-एंड JavaScript लाइब्रेरी खातिर React इस्तेमाल करे के तय कइनी। भले एकरा लग सीखे के कठिनाई हो सकेला, React के देल फायदा, जइसे एकर घटक-आधारित आर्किटेक्चर, घोषणात्मक प्रोग्रामिंग शैली, बेहतर प्रदर्शन, लचीलापन, आ बड़ समुदाय, संभावित कमी से जादा बा।
