# आर्किटेक्चर फैसला रिकॉर्ड: जावा प्रोग्रामिंग भाषा

शीर्षक: परियोजना खातिर जावा प्रोग्रामिंग भाषा चुनल

फैसला: कई प्रोग्रामिंग भाषा के मूल्यांकन के बाद, हमनी अपना परियोजना खातिर Java इस्तेमाल करे के तय कइनी।

### पृष्ठभूमि

हमनी एगो वेब-आधारित एप्लिकेशन बनावे चाहत रहनी जे कई ऑपरेटिंग सिस्टम पर चल सके। हमनी के परियोजना के अइसन भाषा चाहीं जे मजबूत सुरक्षा फीचर दे सके, समवर्तीता संभाल सके, बड़ कोडबेस के समर्थन कर सके, आ आगे के हमनी के विकास जरूरत पूरा करे खातिर काफी बहुमुखी होखे। हमनी Java तय करे से पहिले कई भाषा के उनकर ताकत आ सीमा पर विचार करत मूल्यांकन कइनी।

### विचार

1. **सुरक्षा:**  Java अपना साफ-साफ परिभाषित सुरक्षा नीति आ पहुँच नियंत्रण के जरिए बहुत बढ़िया सुरक्षा फीचर देला। एमे बाइटकोड सत्यापन जइसन फीचर भी शामिल बा, जे दुर्भावनापूर्ण सॉफ्टवेयर के सिस्टम पर चले से रोके में मदद करेला।

2. **समवर्तीता:**  Java लग मल्टीथ्रेडिंग खातिर अंतर्निहित समर्थन बा, जे एप्लिकेशन के एके साथे कई काम करे देला। ई फीचर Java के कई फीचर आ कार्यक्षमता वाला बड़, जटिल एप्लिकेशन विकसित करे खातिर बहुत बढ़िया चुनाव बनावेला।

3. **बड़ कोडबेस:**  Java वस्तु-उन्मुख प्रोग्रामिंग के समर्थन करेला, जे एकरा के बड़ कोडबेस विकसित करे खातिर उचित चुनाव बनावेला। एकर मॉड्यूलर स्वभाव आ एनकैप्सुलेशन आ अमूर्तन पैटर्न के इस्तेमाल सॉफ्टवेयर विकास प्रक्रिया के आसानी आउर बढ़ावेला।

4. **बहुमुखी:**  Java बहुमुखी ह आ लाइब्रेरी आ फ्रेमवर्क के बड़ रेंज इस्तेमाल करे के क्षमता देला, एहसे ई वेब-आधारित आ उद्यम-स्तर दूनो एप्लिकेशन खातिर बहुत बढ़िया चुनाव ह।

### फैसला के नतीजा

हमनी अपना परियोजना खातिर Java प्रोग्रामिंग भाषा इस्तेमाल करे के तय कइनी, एकर सुरक्षा फीचर, समवर्तीता समर्थन, बड़ कोडबेस संभाले के क्षमता, आ बहुमुखी स्वभाव पर विचार करत। ई फैसला हमनी के परियोजना के जरूरत से मेल खाला, आ हमनी के भरोसा बा कि Java चुनला से एकर सफलता पक्का होई। 

### नतीजा

1. हमनी के अइसन डेवलपर चाहीं जिनका लग Java के अनुभव होखे आ जे एकर कुशलता से इस्तेमाल कर सके।

2. एह भाषा में लिखल कवनो भी कोड Java Virtual Machine (JVM) के साथे संगत होखे के चाहीं।

3. नया फीचर, कार्यक्षमता, चाहे फ्रेमवर्क के शामिल करे में कुछ चुनौती आ सकेला।

4. Java में बड़, जटिल परियोजना के विकसित करे में जादा समय आ संसाधन के जरूरत पड़ सकेला।
