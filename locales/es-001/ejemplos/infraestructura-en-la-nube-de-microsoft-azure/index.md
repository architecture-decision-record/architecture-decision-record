# Registro de decisión de arquitectura: infraestructura en la nube de Microsoft Azure

Título de la decisión: adopción de Microsoft Azure como infraestructura en la nube de nuestra organización

Responsable de la decisión: director de sistemas de información (CIO)

Fecha: 2021-10-15

Estado: Aprobado

## Antecedentes

La organización planea migrar de la infraestructura local tradicional (on-premises) a una infraestructura en la nube. Para lograrlo, la organización ha evaluado varios proveedores de servicios en la nube, como Amazon Web Services (AWS), Google Cloud Platform (GCP), Microsoft Azure e IBM Cloud. Cada proveedor tiene su propio conjunto de funciones, beneficios y estructura de precios. Tras un análisis detallado, se concluyó que Microsoft Azure es la opción más adecuada para nuestra organización.

## Decisión

Adoptar Microsoft Azure como la infraestructura en la nube de nuestra organización.

## Justificación

Las siguientes son las razones para adoptar Microsoft Azure:

1. Servicios integrales: Azure ofrece una gama completa de servicios en la nube, desde infraestructura como servicio (IaaS) hasta software como servicio (SaaS) y plataforma como servicio (PaaS). Esto nos permite aprovechar los servicios de Azure para resolver los requisitos de la organización, como almacenamiento, cómputo, redes y análisis.

2. Escalabilidad y flexibilidad: con Azure podemos aumentar o reducir fácilmente los recursos según nuestras necesidades de negocio. Azure también ofrece flexibilidad para elegir el sistema operativo, el lenguaje de programación y los frameworks.

3. Seguridad y cumplimiento: Azure ofrece un alto nivel de seguridad y cumplimiento normativo, ya que cumple varios estándares del sector, como ISO, SOC, HIPAA y PCI DSS. Azure también proporciona funciones de seguridad avanzadas, como grupos de seguridad de red, firewalls y protección contra DDoS.

4. Nube híbrida: Azure ofrece una experiencia de nube híbrida fluida, que permite a las organizaciones conectar su infraestructura local con Azure. Esto nos facilita migrar cargas de trabajo a la nube y nos da la flexibilidad de elegir dónde almacenar los datos.

5. Rentabilidad: Azure ofrece un modelo de precios de pago por uso, lo que significa que solo pagamos por los recursos utilizados. Esto nos ayuda a ahorrar costos en comparación con la infraestructura local tradicional.

## Conclusión

Adoptar Microsoft Azure como la infraestructura en la nube de nuestra organización se alinea con nuestros requisitos de negocio y ofrece varios beneficios, como escalabilidad, flexibilidad, seguridad y rentabilidad. Por lo tanto, se recomienda adoptar Azure como nuestra infraestructura en la nube.
