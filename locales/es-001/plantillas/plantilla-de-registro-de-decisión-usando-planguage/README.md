# Plantilla de registro de decisión usando Planguage

Véase https://www.iaria.org/conferences2012/filesICCGI12/Tutorial%20Specifying%20Effective%20Non-func.pdf

## ¿Qué es Planguage?

Planguage es un lenguaje de planificación que usa estas palabras clave:

* Tag (etiqueta): un identificador único y persistente
* Gist (esencia): un breve resumen del requisito o del área que se aborda
* Requirement (requisito): el texto que detalla el requisito en sí
* Rationale (justificación): el razonamiento que justifica el requisito
* Priority (prioridad): una declaración de prioridad y de reclamo de recursos
* Stakeholders (partes interesadas): las partes afectadas de manera sustancial por el requisito
* Status (estado): el estado del requisito (borrador, revisado, comprometido, etc.)
* Owner (propietario): la persona responsable de implementar el requisito
* Author (autor): la persona que escribió el requisito
* Revision (revisión): un número de versión del enunciado
* Date (fecha): la fecha de la revisión más reciente
* Assumptions (supuestos): cualquier cosa que pueda causar problemas si no es cierta ahora o más adelante
* Risks (riesgos): cualquier cosa que pueda causar un mal funcionamiento, un retraso u otros impactos negativos
* Defined (definido): la definición de un término (es mejor usar un glosario)
