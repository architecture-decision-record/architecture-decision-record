# Plantilla de registro de decisión para el patrón alejandrino

## Introducción

* Prólogo (Resumen)
* Discusión (Contexto)
* Solución (Decisión)
* Consecuencias (Resultados)

## Detalles ##

* Prólogo (Resumen)
  * Enunciado para resumir:
    * En el contexto de (caso de uso)<br>
      ante (inquietud)<br>
      decidimos optar por (opción)<br>
      para lograr (cualidad)<br>
      aceptando (desventaja).
* Discusión (Contexto)
  * Explica las fuerzas en juego (técnicas, políticas, sociales, del proyecto).
  * Es la historia que explica el problema que buscamos resolver.
* Solución
  * Explica cómo resolverá la decisión el problema.
* Consecuencias
  * Explica los resultados de la decisión a largo plazo.
  * Si funcionó, no funcionó, se modificó, se actualizó, etc.
