# Plantilla de registro de decisión de Michael Nygard

Esta es la plantilla de [Documenting architecture decisions - Michael Nygard](http://thinkrelevance.com/blog/2011/11/15/documenting-architecture-decisions).
Puede usar [adr-tools](https://github.com/npryce/adr-tools) para gestionar los archivos ADR.

En cada archivo ADR, escriba estas secciones:

# Título

## Estado

¿Cuál es el estado: propuesto, aceptado, rechazado, obsoleto, sustituido, etc.?

## Contexto

¿Cuál es el problema que vemos y que motiva esta decisión o cambio?

## Decisión

¿Cuál es el cambio que proponemos o estamos realizando?

## Consecuencias

¿Qué se vuelve más fácil o más difícil de hacer a causa de este cambio?
