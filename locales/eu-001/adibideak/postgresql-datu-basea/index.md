# Arkitektura-erabakien erregistroa: PostgreSQL datu-basea

Izenburua: PostgreSQL datu-basearen erabilera

## Testuingurua

Gure erakundea gure hurrengo proiekturako erabiliko den datu-base kudeaketa sistema egokiena zein den aztertzen ari da. Gure bilaketa bi aukeratara mugatu dugu: PostgreSQL eta MySQL. Arretaz pentsatu ondoren, PostgreSQL erabiltzea erabaki dugu bere ezaugarri aurreratuengatik eta errendimendu-gaitasunengatik.

## Erabakia

PostgreSQL erabiliko dugu gure erakundearen hurrengo proiekturako nahiago dugun datu-base kudeaketa sistema gisa.

## Justifikazioa

PostgreSQL eta MySQL-ren ezaugarriak aztertu eta alderatu ondoren, ondorioztatu dugu PostgreSQL dela aukera hobea arrazoi hauengatik:

1. **Ezaugarri aurreratuak:**  PostgreSQL-k ezaugarri aurreratu sorta zabala du, hala nola JSON euskarria, testu osoko bilaketa eta datu espazialen kudeaketa, gure proiekturako ezinbestekoak direnak.

2. **Errendimendua:**  PostgreSQL-k errendimendu-gaitasun bikainen frogatutako ibilbidea du, eta horrek gure proiektua errendimendu-arazorik gabe leunki exekutatzen dela ziurtatuko du.

3. **Komunitatearen laguntza:**  PostgreSQL-k komunitate handi eta aktiboa du, eguneraketa erregularrak eta laguntza ematen dituena, eta horrek proiektuaren garapen-fasean sortzen den edozein arazo konpontzea errazten du.

4. **Eskalagarritasuna:**  PostgreSQL oso eskalagarria da, eta datu kopuru handiak erraz kudeatu ditzake, gure proiekturako ezinbestekoa izango dena.

5. **Segurtasuna:**  PostgreSQL-k segurtasun-mekanismo sendoa du, gure proiektuaren datuak une oro seguru daudela ziurtatuko duena, eta gure erakundearen segurtasun-eskakizun guztiak betetzen ditu.

## Alternatibak

Aztertu dugun beste aukera MySQL izan zen. MySQL ere datu-base kudeaketa sistema oso gaitua da, baina PostgreSQL-k eskaintzen dituen ezaugarri aurreratu batzuk falta ditu, eta bere errendimendu-ahalmena ez da PostgreSQL-rena bezain ona.

## Ondorioa

Gure analisian oinarrituta, PostgreSQL erabiltzea erabaki dugu gure hurrengo proiekturako nahiago dugun datu-base kudeaketa sistema gisa. Erabaki hau arretaz pentsatu ondoren hartu da, eta uste dugu proiektuaren helburuak modu eraginkor eta eraginkorrean lortzen lagunduko digula.
